# 感冒、发烧、咳嗽:一次讲清怎么应对

> 一句话定位:宿舍里最常见的三种症状,这篇帮你分清"是哪种病、自己怎么扛、买什么药、什么情况必须去医院"。

> ⚠️ 免责声明:本文为科普整理,不构成医疗建议;具体诊疗与用药请遵医嘱/咨询药师;出现急重症立即拨打 120。

---

## 🎯 核心速览(TL;DR)

1. **普通感冒是自限病**,一般 7~10 天自己好;吃药只能缓解症状,不能缩短病程。
2. **体温高低 ≠ 病情轻重**。判断要不要去医院,重点看**精神状态**:能吃能睡能聊天,多数不用慌。
3. **一般 38.5℃ 以上或明显不舒服**才吃退烧药;两种常用退烧药二选一:**对乙酰氨基酚**或**布洛芬**,别叠加、别混吃,间隔和上限以说明书为准。
4. **物理降温不搞酒精擦浴、不捂汗**;温毛巾擦拭、少穿盖、多喝水即可。
5. **流感 ≠ 感冒**:高热+全身肌肉酸痛+乏力是流感典型表现,症状重、传染强,最好 48 小时内就医评估抗病毒治疗。
6. **咳嗽是保护反射**,轻度咳嗽不必止咳;干咳、湿咳、夜间咳的应对侧重不同。
7. **复方感冒药(如各种"氨酚XX""XX伪麻片")里常已含对乙酰氨基酚**,不要再单吃退烧药,否则容易过量伤肝。
8. 咽痛、鼻塞可用**淡盐水漱口、生理盐水洗鼻、热蒸汽熏鼻**等低成本方法缓解。
9. 红旗信号:**呼吸困难、胸痛、咳血、持续高热超过 3 天、精神萎靡、意识模糊**——立即就医。
10. 宿舍是传染重灾区:**戴口罩、勤洗手、开窗通风、不共用水杯餐具**,比吃什么药都管用。

## 一、先分清:普通感冒 vs 流感 vs 新冠

三者都是呼吸道病毒感染,处理方式差别很大。对照下表初步判断(确诊靠抗原检测或医院检查):

| 对比项 | 普通感冒 | 流感 | 新冠 |
|---|---|---|---|
| **常见病原** | 鼻病毒、冠状病毒、腺病毒等多种 | 甲/乙型流感病毒 | 新型冠状病毒(毒株持续变异) |
| **起病速度** | 较缓,1~2 天渐重 | **急骤**,几小时内爆发 | 起病急缓不一 |
| **发热** | 少见或低中度,1~3 天 | **高热 39~40℃**,持续 3~5 天 | 中低热到高热均有 |
| **典型症状** | 鼻塞、流涕、打喷嚏、咽干痒 | **头痛、全身肌肉酸痛、明显乏力**,呼吸道症状反而轻 | 发热、咳嗽、乏力、肌痛,部分人**嗅觉/味觉减退** |
| **全身症状** | 轻 | **重**,影响上学上班 | 中到重,个体差异大 |
| **病程** | 5~10 天自愈 | 1~2 周,乏力可持续更久 | 因个体与毒株差异较大 |
| **并发症风险** | 低 | 较高(肺炎、心肌炎,高危人群) | 高危人群可发展为肺炎 |
| **处理差异** | 对症缓解即可 | **建议 48 小时内就医**,评估抗流感病毒药物 | 对症+休息;高危人群监测血氧 |

**简单判断口诀**:打喷嚏流鼻涕为主→多半是普通感冒;高烧+浑身酸痛起病猛→警惕流感;发热咳嗽+味嗅觉异常→可以做个新冠/流感抗原自测。

**学生特别提示**:流感季节(北方冬春季、南方还有夏季小高峰)室友接连中招,大概率是流感而非普通感冒,症状重应尽早就医,并主动戴口罩隔离。

## 二、发烧的正确认识

### 2.1 发烧本身不是病,是免疫反应

发烧是身体对抗感染的机制之一,**适度发热有助于免疫系统工作**。所以:

- 不要一见烧就慌,更不要一烧就吃退烧药压下去。
- 退烧的目的是**让你舒服一点**,而不是把体温"治"到正常。

### 2.2 判断病情轻重:看精神状态,不只看体温

| 体温 | 精神状态好 | 精神状态差 |
|---|---|---|
| <38.5℃ | 多喝水、休息、观察,可不用药 | 对症处理+密切观察 |
| ≥38.5℃ 或明显不适 | 可服退烧药,继续观察 | 可服退烧药,**尽快就医** |
| >39.5℃ 持续不降 | 服退烧药,若 2~3 天仍反复应就医 | **立即就医** |

**多数指南建议**:是否用药的门槛是"38.5℃ 或明显不适",两者满足其一即可用药;低于 38.5℃ 但头痛酸痛难受,也可以用药(以说明书/医嘱为准)。

### 2.3 退烧药怎么选:两种常用示例二选一

| 项目 | 对乙酰氨基酚(如泰诺林等) | 布洛芬(如美林、芬必得等) |
|---|---|---|
| 特点 | 退热镇痛,胃肠刺激小 | 退热镇痛+抗炎 |
| 适用 | 多数人首选 | 无胃溃疡/肾病者适用 |
| 主要风险 | **过量伤肝**(饮酒、空腹、叠加复方感冒药时风险高) | **伤胃、伤肾**,脱水时慎用;痛经/肌肉痛效果更好 |
| 使用间隔与上限 | **严格按说明书** | **严格按说明书** |

**关键规则**:

1. **二选一,不叠加、不常规交替**。交替使用容易记混时间导致过量。
2. **看复方感冒药成分表**:"氨酚"=对乙酰氨基酚。吃了复方感冒药就别再单吃退烧药。
3. 服药后 15~30 分钟起效,别吃完 20 分钟没退烧就加量。
4. 胃不好、拉肚子脱水的人选对乙酰氨基酚更稳妥;布洛芬要随餐或饭后吃。

> 具体剂量因剂型(片、缓释胶囊、混悬液)差异很大,一律以说明书/医嘱为准。

### 2.4 物理降温:正确做法 vs 错误做法

| 做法 | 判断 | 说明 |
|---|---|---|
| 温水擦拭额头、颈部、腋窝、腹股沟 | ✅ 推荐 | 水温 37℃ 左右,擦完不要立刻吹风 |
| 适当减少衣物、被盖 | ✅ 推荐 | 利于散热,别捂 |
| 多喝温水/电解质水 | ✅ 推荐 | 发烧出汗丢失水分,脱水会更烧 |
| **酒精擦浴** | ❌ 禁止 | 可致酒精经皮吸收+血管收缩寒战,已淘汰 |
| **捂汗** | ❌ 禁止 | 影响散热,可能捂出高热甚至脱水;尤其寝室被窝里捂汗很危险 |
| 冰水灌肠、冰水澡 | ❌ 禁止 | 刺激过强引起寒战,反而升温 |

## 三、咳嗽:分类应对

咳嗽本身是保护反射(排出痰和异物),**轻度咳嗽不必强行止咳**。

| 类型 | 特点 | 处理思路 |
|---|---|---|
| **干咳**(无痰) | 咽痒刺激感,常见于感冒后期、病毒感染后气道敏感 | 蜂蜜水(睡前 1 勺,1 岁以下婴儿禁用蜂蜜)、多喝温水;影响睡眠可咨询药师用镇咳药 |
| **湿咳**(有痰) | 咳痰,痰白稀或黄稠 | **别强行镇咳**,多喝水稀释痰液;可咨询药师是否用祛痰药 |
| **夜间咳加重** | 平躺后痰液倒流/鼻涕倒流/胃酸反流 | 垫高枕头;伴反酸者参考《02-肠胃问题》;持续 >2 周就医 |
| **感冒后咳嗽** | 感冒好了还咳 3~8 周 | 多为气道高反应,通常自愈;迁延不愈就医 |

### 咳嗽就医指征

- 咳嗽**超过 2~3 周**不缓解或加重;
- 咳**黄绿浓痰**伴发热(可能细菌性感染,需医生判断,不要自行吃"消炎药");
- **夜间咳醒、喘息、胸闷**;
- 痰中带血丝(哪怕一次也应就医查明)。

## 四、咽痛、鼻塞:低成本缓解法

### 咽痛

- **温盐水漱口**:一杯温水+半勺盐,每天数次,缓解明显且零成本。
- 含服润喉片(常见示例:西地碘含片等),以说明书为准。
- 多喝温水,避免辛辣、烫食、烟酒(宿舍聚会撸串请节制)。

### 鼻塞

- **生理盐水洗鼻/喷鼻**:药店有洗鼻器和生理盐水,便宜好用;自己配用 0.9% 无碘盐水、35~37℃ 温度。
- **热蒸汽熏鼻**:洗热水澡或一杯热水用鼻子吸蒸汽(小心烫伤)。
- 睡觉垫高枕头,减轻鼻黏膜充血。
- 减充血剂鼻喷雾(常见示例:羟甲唑啉等)**连用不超过 3~7 天**,否则会药物性鼻炎越喷越堵(以说明书为准)。

## 五、普通感冒的正确打开方式(学生版流程)

1. **第 1 天**:咽干、打喷嚏 → 多喝水、早睡,不熬夜打游戏。
2. **第 2~3 天**:症状顶峰 → 对症用药(鼻塞用喷鼻剂,发热用退烧药,咽痛盐水漱口);**戴口罩保护室友**;食堂打饭注意营养,别靠外卖炸鸡续命。
3. **第 4~7 天**:症状渐退 → 继续休息,症状消失≠完全恢复,别立刻猛练体测。
4. **任何阶段出现红旗信号**(见下文)→ 立即就医。

**家庭参考**:家中长辈感冒,同样适用"观察精神状态"原则;老人(尤其 65 岁以上)和有基础病者发热,建议更积极就医。

## ⚠️ 常见误区

- **误区:发烧会"烧坏脑子",必须马上退烧。→ 真相:**普通感染性发热本身不会烧坏脑子;脑膜炎等严重疾病是"病"而非"烧"造成的,看精神状态和红旗信号,而非死盯体温计。
- **误区:输液好得快。→ 真相:**普通感冒输液不会缩短病程,能口服不肌注、能肌注不输液是基本原则。
- **误区:吃"消炎药"(抗生素)治感冒。→ 真相:**感冒是病毒感染,抗生素杀不了病毒,滥用只伤菌群、催生耐药;是否合并细菌感染由医生判断。
- **误区:感冒是冻出来的。→ 真相:**感冒由病毒感染引起;受凉、熬夜、压力可能降低抵抗力增加感染机会,但"穿少点就感冒"并不成立。
- **误区:多种感冒药一起吃好得快。→ 真相:**很多复方感冒药成分重叠,叠加服用极易过量(尤其对乙酰氨基酚),伤肝风险大。
- **误区:捂一身汗就好了。→ 真相:**出汗是退烧的结果不是原因;捂汗阻碍散热,可能加重高热脱水。
- **误区:维生素 C 防感冒。→ 真相:**常规补充维 C 不能预防普通感冒;规律作息、洗手、流感疫苗才是靠谱的预防手段。

## ✅ 行动清单

- [ ] 宿舍常备小药箱:对乙酰氨基酚或布洛芬(二选一即可)、生理盐水洗鼻器、润喉片、体温计、口罩
- [ ] 学会看复方感冒药成分表,确认是否含"氨酚"
- [ ] 记住判断就医的核心:精神状态 > 体温数字
- [ ] 感冒期间:多喝水、戴口罩、餐具水杯分开、开窗通风
- [ ] 每年秋冬季接种流感疫苗(参考《06-疫苗与预防接种》)
- [ ] 手机存好校医院和附近医院急诊电话

## 🚨 什么时候必须就医(红线)

出现以下任一情况,**不要硬扛,立即就医;危急时拨打 120**:

1. **呼吸困难、气促、喘不上气**(安静坐着的呼吸也费力);
2. **胸痛、胸闷持续不缓解**(警惕心肌炎、肺炎);
3. **持续高热 >3 天**不退,或退烧药无效;
4. **精神萎靡、嗜睡叫不醒、意识模糊、抽搐**;
5. **咳血或痰中带血**;
6. 剧烈头痛、颈项强直(低头困难)伴发热(警惕脑膜炎);
7. 发热伴**皮疹、尿少、明显脱水**(吃不下喝不下);
8. 原有基础疾病(哮喘、糖尿病等)明显加重;
9. 退烧后再度高热、咳嗽加重咳脓痰(警惕继发细菌感染)。
