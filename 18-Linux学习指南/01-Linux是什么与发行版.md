# 第1章 认识 Linux

> 本章不敲多少命令，先帮你把"Linux 到底是什么、我为什么要学它、打开终端之后那一行东西是什么"这三件事讲明白。

## 本章你将学会

- 说清楚操作系统、内核、发行版三者的区别
- 知道 Ubuntu / Debian / CentOS / Rocky / Fedora / Arch 各自是什么，以及我们为什么选 Ubuntu
- 知道 Linux 实际用在哪些地方（和你将来找实习有什么关系）
- 分清终端、Shell、Bash、CLI、GUI 这几个天天听人说的词
- 打开终端，认出提示符 `$` 和 `#` 的含义，写出第一条命令
- 会用 `--help` 和 `man` 查命令用法，会读懂最常见的报错信息

## 1.1 操作系统、内核、发行版——先把三个词掰扯清楚

你每天在用 Windows，对吧？你打开"此电脑"能看到 C 盘，你双击图标能打开软件——这一整套东西，Windows 是一个**操作系统**。

操作系统是一个大管家：它管理你的 CPU、内存、硬盘、键盘、显示器，然后在上面给你（和你的软件）提供一个"好用的桌面"。

但操作系统最底下、最核心的那一小块，叫**内核（Kernel）**。内核直接和硬件打交道：硬盘读写、内存分配、进程调度，全是它干的。外面那层带窗口、带图标、带开始菜单的东西，只是"穿着西装的内核"。

> 📌 **注意：严格来说，"Linux"这个词指的只是内核。** 1991 年，一个叫 Linus Torvalds 的芬兰大学生写出了这个内核，起名为 Linux。但光有内核你什么也干不了——你得有文件管理、有命令行、有 C 编译器、有一堆小工具，才能真正用起来。

而这些"小工具"，最早是 Richard Stallman 在 GNU 计划里写的（GNU 是一个递归缩写，意思是 "GNU's Not Unix"，1984 年开始，目标是做一个完全自由的类 Unix 操作系统）。所以严格讲，你现在用的系统应该叫 **GNU/Linux**。这个命名之争在学术圈还挺有名，但日常没人这么叫，大家就说 Linux。

那"发行版（Distribution，简称 distro）"又是什么？你可以这么理解：

> 📌 **内核 + 一堆常用软件 + 一个包装/升级/卸载软件的工具 + 一个装得上去就能用的安装包 = 一个发行版。**

就像同样一块主板（内核），有人给它配成游戏主机，有人配成办公机，有人配成服务器。Ubuntu、Debian、CentOS 都是这样"配"出来的不同版本，它们内核是同一个，但带的软件、包管理工具、默认配置都不一样。

## 1.2 常见发行版对比——为什么我们选 Ubuntu

市面上发行版有几百个，你只要认识下面这六个就够了：

| 发行版 | 包管理 | 定位 | 和你的关系 |
|---|---|---|---|
| **Ubuntu** | `apt` / `dpkg` | 桌面、服务器、云、WSL 全都做 | **本教程的主力**，你 WSL 里装的就是它 |
| Debian | `apt` / `dpkg` | 极其稳定、保守的社区发行版 | Ubuntu 的"亲妈"，Ubuntu 是基于 Debian 改的 |
| CentOS | （旧版 `yum`，已停止维护） | 曾经的企业服务器标配 | 已经死了（2022 年底官方停止维护），别学它了 |
| Rocky Linux | `dnf` / `rpm` | CentOS 的精神续作，企业服务器 | 去传统企业运维可能碰到，命令和 Ubuntu 大部分相通但包管理不同 |
| Fedora | `dnf` / `rpm` | Red Hat 的"试验田"，新技术先进来 | 个人玩可以，服务器少用 |
| Arch Linux | `pacman` | 极度极客、滚动更新、自己拼装 | 网上很多"大神教程"是 Arch 的，新手别碰 |

> 💡 **小技巧：** 看到老教程里写 `yum install xxx`，那是 CentOS/RHEL 系的写法。在你 Ubuntu 里对应的是 `sudo apt install xxx`。包管理这块第 8 章会专门讲。

**为什么选 Ubuntu？** 三个理由：

1. **WSL 默认就给你 Ubuntu。** 微软和 Canonical（Ubuntu 的公司）合作得最好，`wsl --install` 一条命令下来装好的就是它。
2. **资料最多。** 你在 Google、Stack Overflow、B站搜到的 80% 的 Linux 教程都是 Ubuntu/Debian 系的，报错也好搜。
3. **它就是云服务器上最常用的系统。** AWS、阿里云、腾讯云最便宜的学生机默认镜像基本都有 Ubuntu LTS。你在 WSL 里学的命令，将来租一台云服务器直接一模一样用，不用重新适应。

LTS 是什么意思？Long Term Support，长期支持版。Ubuntu 每两年出一个 LTS（比如 24.04），官方支持 5 年。我们用的就是 **Ubuntu 24.04 LTS**，代号 Noble Numbat。

## 1.3 Linux 到底用在哪——和你找实习有什么关系

说几个你熟悉的场景：

- **服务器：** 全世界前 500 台最快的超级计算机 100% 跑 Linux。你刷的抖音、你上的淘宝、你查成绩的教务系统，后台九成以上跑在 Linux 服务器上。
- **云：** 阿里云、腾讯云、AWS 上租的虚拟机，默认操作系统就是 Linux。
- **容器：** Docker 的底层就是 Linux 容器。你将来做后端，部署服务绕不开 Docker。
- **WSL：** 就是你现在要用的东西——在 Windows 里跑一个真正的 Linux，不用装双系统。
- **嵌入式：** 路由器、智能电视、安卓手机里也有 Linux 内核。这块我们一句带过，因为你方向是后端开发/运维，不碰开发板、驱动、内核裁剪。

> 📌 **一句话总结：你将来写好一个后端程序，要部署到服务器上让人访问，那台服务器就是 Linux。** 所以学 Linux 不是学一个"备选技能"，是后端方向的基本功。

## 1.4 终端、Shell、Bash、CLI、GUI——五个词一次分清

这几个词新手最晕，我一次给你讲清：

| 词 | 是什么 | 类比 |
|---|---|---|
| **GUI** | 图形界面，靠鼠标点图标操作 | Windows 的桌面 |
| **CLI** | 命令行界面，靠敲字操作 | 黑框框 |
| **终端（Terminal）** | 那个让你敲字的窗口程序本身 | 黑框框这个"窗口" |
| **Shell** | 你敲完字回车之后，帮你解释执行的那个程序 | 黑框框里的"翻译官" |
| **Bash** | 现在最主流的一种 Shell（GNU Bash） | 翻译官里最常见的那位 |

也就是说：你打开一个"终端"窗口，窗口里跑着一个叫 Bash 的 Shell，你敲的命令被 Bash 翻译后交给内核执行。除了 Bash 还有 zsh、fish 等别的 Shell，但 Ubuntu 默认就是 Bash，本教程也只用 Bash。

## 1.5 打开你的终端，认识提示符

> 📌 **本章先不要求你已经装好 WSL。** 如果你还没装，先翻到第 2 章把 WSL2 + Ubuntu 装好，再回来敲本章后面的命令。概念部分你现在就可以读懂。

装好之后，打开 Ubuntu（Windows Terminal 里点 Ubuntu，或者开始菜单搜 Ubuntu），你会看到一行类似这样的东西：

```text
username@DESKTOP-ABC123:~$
```

我们拆开看：

| 部分 | 例子 | 含义 |
|---|---|---|
| `username` | `ubuntu` | 你登录的用户名（你第一次装的时候自己设的） |
| `@` | `@` | 就是"at"，分隔用户和主机名 |
| `DESKTOP-ABC123` | 主机名 | 这台机器叫什么名字，WSL 默认是你电脑名 |
| `:~` | `~` | **你当前所在目录**。`~` 是"家目录"的缩写，现在你在家目录里 |
| `$` | `$` | 提示符，表示"你现在是普通用户，可以敲命令了" |

> 📌 **注意：`$` 后面那个光标才是你输入命令的地方。`$` 本身不要你敲。** 后面教程里我写 `$ ls`，意思是"在 `$` 提示符后面输入 `ls`"，你只要敲 `ls` 再回车。

那 `#` 是什么？如果你切到 root（超级管理员）用户，提示符会变成 `#`：

```text
root@DESKTOP-ABC123:/home#
```

> 💡 **小技巧：** 看到教程里命令前面是 `#`，说明这条命令需要管理员权限。在 Ubuntu 的普通用户下，你一般不直接切 root，而是在命令前面加 `sudo`（superuser do）。比如 `# apt update`，你就敲 `$ sudo apt update`。sudo 会问你密码——就是你装系统时设的那个密码，输的时候屏幕上**不会显示任何字符**（连星号都没有），这是正常的，盲打完回车就行。

## 1.6 命令的格式：命令、选项、参数

Linux 命令长得很有规律，几乎都是这个结构：

```bash
$ 命令  选项  参数
```

拿 `ls -l /home` 举例：

- `ls`：命令本身，干什么（list，列出）
- `-l`：选项（option），怎么干（长格式）。选项一般以 `-` 开头，一个字母；两个字母以上的选项用 `--`，比如 `--help`
- `/home`：参数（argument），对谁干（列出哪个目录）

三个部分之间用空格隔开。空格很重要：`ls-l` 会被当成一个不存在的命令，`ls -l/home` 也会出错。

## 1.7 你的第一条命令

好，现在真的来敲。打开 Ubuntu 终端，输入：

```bash
$ echo "hello, linux"
```

回车，你会看到：

```text
hello, linux
```

`echo` 的作用就是"把后面的内容打印到屏幕上"。你刚刚完成了人生中第一条 Linux 命令：告诉系统"把 hello, linux 这串字显示出来"，系统照做了。成就感不用很大，但这就是一切的开始。

再试一个：

```bash
$ whoami
```

输出应该是你自己设的用户名。这条命令问系统"我现在是谁"。

## 1.8 怎么求助：--help、man、tldr

你不可能记住所有命令的所有选项，没人能住。所以 Linux 从设计第一天就把"说明书"内置进了系统。

**第一招：`--help`。** 几乎所有命令都带这个选项，它会打印一个简短用法说明：

```bash
$ ls --help
```

**第二招：`man`。** `man` 是 manual（手册）的缩写，它打开完整的说明书：

```bash
$ man ls
```

打开之后你会看到一屏英文。操作方法：

- 按 `↑` / `↓` 或 `PgUp` / `PgDn` 翻页
- 按 `/` 然后输入关键词再回车，可以搜索
- 按 `q` 退出

man 手册分章节，第 1 章是普通命令，这是你最常看的。

**第三招：`tldr`。** man 手册写得太啰嗦，很多人嫌烦，于是社区搞了 tldr（too long; didn't read）——每条命令只给几个最常用的例子。它默认没装，等你学完第 8 章装软件后，可以用 `sudo apt install tldr` 装上。现在先知道有这东西。

> 💡 **小技巧：** 命令忘了，先 `命令 --help`；看不懂再 `man 命令`；想快速看例子就 `tldr 命令`。三层求助体系。

## 1.9 怎么读报错

新手最怕看到红字。其实 Linux 的报错写得非常友好，你只要养成"先读最后一行"的习惯就行。看几个典型：

```text
$ lss
Command 'lss' not found, did you mean:
 command 'ls' from deb coreutils
Try: sudo apt install <deb name>
```

这句话翻译成人话："没有叫 lss 的命令，你是不是想打 ls？"——拼错了而已。

```text
$ cat /etc/shadow
cat: /etc/shadow: Permission denied
```

翻译："你权限不够，看不了这个文件。"想看得加 `sudo`。

```text
$ cd Nonexistent
bash: cd: Nonexistent: No such file or directory
```

翻译："这个目录不存在。"——检查你路径拼对没有、大小写对不对（**Linux 区分大小写**，`Home` 和 `home` 是两个东西）。

> 📌 **注意：Linux 的报错格式一般是 `命令: 出问题的东西: 原因`。** 把这三部分读一遍，八成问题自己就有答案了。实在看不懂，把最后一行整句复制到 Google 搜索，前几条 Stack Overflow 一定有人踩过同样的坑。

## ⚠️ 危险操作与安全红线

本章还没碰任何危险命令。但先立一条规矩，后面反复用：

> ⚠️ **警告：在你完全理解一条命令干什么之前，不要在前面加 `sudo` 运行它。** `sudo` 等于"以管理员身份"操作系统，它不会问你"真的要这样吗"，你回车它就执行。网上复制来的命令，先读懂再跑。

## 常见报错与排查

| 现象 | 原因 | 解决 |
|---|---|---|
| `Command not found` | 命令拼错，或软件没装 | 检查拼写；真没装就 `sudo apt install 包名` |
| `Permission denied` | 当前用户权限不够 | 在命令前加 `sudo`（仅限系统管理类命令） |
| `No such file or directory` | 路径不对 / 大小写错了 | `ls` 看看当前目录到底有什么，注意大小写 |
| 输密码时屏幕一动不动 | 这是正常的，不是卡死 | 盲打完直接回车 |
| 卡在 `man` 或 less 里出不来 | 不知道退出键 | 按 `q` |

## 动手练习

1. 打开终端，敲 `whoami`、`pwd`、`ls` 三条命令，看看输出分别是什么。（验收：三条都有正常输出）
2. 敲 `echo "我的第一行 Linux 命令"`，把输出截图存下来。
3. 用 `ls --help` 看看 `ls` 有哪些选项，试着找出 `-a` 选项是干什么用的。
4. 敲 `man echo`，然后按 `/` 搜索 `-n`，看看这个选项是干嘛的，按 `q` 退出。
5. 故意敲错一个命令（比如 `pwdx`），看看报错长什么样。
