# 数据科学与可视化

> **一句话**：把原始数据变成洞察与叙事的学科——上游是统计学，下游是沟通，中间是一段代码。
> **带走什么**："图形优先"的本能——任何数字结论先画出来看，图表往往比 p 值更早说真话。

## 为什么电信工程人值得了解

- 你天天看的频谱仪、星座图、瀑布图，就是数据可视化的经典范例——工程师早就在做 DS，只是没意识到。
- 通信网络产生了海量数据（信令、日志、KPI），运营商与设备商的数据岗常年缺"懂通信的数据人"。
- 可视化是跨学科学习的加速器：一张好图胜过十页文字（还记得 FFT 把时域乱麻变成一根根谱线的那一课吗）。
- 它是最实用的"第二技能"：Excel → Python → BI 工具，三个月就能在实习里变现。

## 可迁移的"学科内核"

- **探索性数据分析（EDA）**：先看数据再谈假设——图坦卡蒙式谦逊：让数据先说话。
- **数据→墨水比**：用最少的墨水表达最多的信息——Chartjunk（图表垃圾）是设计的失败。
- **好的可视化=好问题**：图不是装饰，是一个问题的答案。
- **叙事结构**：数据故事的三幕剧（背景-冲突-解决）——分析师与码农的分界线。

## 三档入门路径

- 🍵 **浅尝（1-2 周）**：《用数据讲故事》通读（薄，讲"怎么把图做对"）+ 用 Python 把自己的课程成绩/日常开销做成 5 张图。
- 📚 **成体系（2-3 个月）**：《Python数据科学手册》跟着敲 + Kaggle Learn 的 5 门免费微课（Python/Pandas/Visualization/Intro ML/Data Cleaning）。
- 🏔 **深入（半年+，可选）**：打一次完整 Kaggle 比赛（看团队讨论区比做题更重要）+ 学一个 BI 工具（Tableau Public 免费/Power BI）+ 《Storytelling with Data》进阶篇。

## 交叉玩法：电信工程 × 数据科学

- **网络 KPI 分析**：运营商大数据岗——基站日志、信令数据的城市人流分析，通信背景直接对口。
- **频谱监测可视化**：频谱占用、干扰定位的实时大屏—— RF 数据的老家就在这里。
