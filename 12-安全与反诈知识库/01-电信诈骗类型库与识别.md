# 01 · 电信诈骗类型库与识别

> 底层数据：公安部公布的十大高发电诈类型（刷单返利、虚假购物、虚假网络投资理财、冒充电商物流客服、虚假贷款、冒充公检法、虚假征信、网络游戏产品虚假交易、冒充熟人领导、婚恋交友）**合计约占全部电诈案件 85%**，其中**刷单返利发案量最大、损失最多**（公安部，2026-04 新华网转引）。
> 最高法披露：2021–2025 年一审诈骗刑事案件从 5.2 万件升至 9.3 万件，增长 81.2%（2026-02）。
> 使用方式：不必背，每学期开学/放假前通读一遍；遇到可疑情况回来对照。

---

## 一、十大高发类型逐个拆解

### 1. 刷单返利（发案量第一）
- **套路**："动动手指日入500" → 小额任务真返利建立信任 → 大额"连单/垫付" → 以"卡单/任务未完成"为由不让提现 → 要求继续充值"解冻"。
- **识别要点**：① 所有刷单本身违法，且 100% 是诈骗；② 先给甜头再收割是标准节奏；③ **凡要求垫资即停**。

### 2. 虚假购物 / 游戏账号交易
- **套路**：闲鱼等平台低价引流 → 诱导脱离平台私下转账，或引到"假交易平台" → 提现时以"冻结"为由要充值解冻。
- **典型案例**：南开一学生闲鱼购拍立得被骗 220 万（2026-06 报道）。
- **识别要点**：只走官方担保交易；**凡提"解冻金/保证金/认证金"即诈骗**。

### 3. 冒充电商物流客服
- **套路**：非法获取订单信息后冒充客服，称"商品质量问题理赔/快递丢失赔付"，诱导开**共享屏幕**、提供**验证码**。
- **识别要点**：主动来电的"客服"一律存疑；理赔只走官方 App；**共享屏幕 = 把所有密码交给对方**。

### 4. 冒充公检法
- **套路**：冒充警察/检察官称你"涉案"，出示假通缉令制造恐慌，要求转入"安全账户"自证清白。
- **识别要点**：公检法**不会电话办案**、**不存在"安全账户"**、**不会要验证码**；可挂断后拨 110 核实。

### 5. 注销校园贷（大学生定向）
- **套路**：冒充网贷平台客服，谎称"校园贷账户未注销会影响征信"，诱导去各平台贷款转入"安全账户"。
- **识别要点**：国家反诈中心明确——**不存在"注销网贷账户"这种操作**，按时还款就不影响征信；征信不由任何客服说了算。

### 6. 杀猪盘 / 虚假投资理财
- **套路**：网恋/交友"完美对象"养信任 → 透露"投资赚钱" → 假平台小额可提现 → 大额投入后卷款。
- **识别要点**：网上没见过面就荐股荐币 = 诈骗；"稳赚不赔/内部消息/跟单导师"全是话术。

### 7. 机票退改签
- **套路**：冒充航司客服称"航班取消可理赔"，诱导提供银行卡+验证码或交"手续费"。
- **识别要点**：改签只走购票原渠道 App/官方电话；"航班取消"先在购票 App 里自己查。

### 8. 助学金 / 奖学金诈骗（开学季高发）
- **套路**：冒充教育部门/学校资助中心，称"发放助学金需先交手续费/核对银行卡"。
- **识别要点**：**正规助学金发放不需要预先交任何费用**；拿不准就打学校资助中心官方电话核实。

### 9. AI 换脸拟声（新骗术，增速快）
- **套路**：微信/视频通话实时换脸+拟声冒充熟人（导师/家长/同学）借钱。
- **数据**：2025Q1 此类案件环比激增 45%（公安部通报）。
- **识别要点**：要求对方**转头、按脸、挥手**，或提问只有本人知道的问题；**转账前电话回拨原号码核实**（不回拨对方发来的号码）。

### 10. 兼职陷阱 / 帮信红线 ⚠️
- **套路**：高薪"兼职"实为出借银行卡、收款码、手机卡帮人"走流水"，沦为洗钱工具。
- **后果**：可能构成**帮信罪**（详见 [13库-05-法律红线与求助渠道](#/doc/d356)），即使不构罪也有"断卡"信用惩戒。
- **识别要点**：**凡借用你的卡/码/手机"走流水"即违法**，直接拒绝并举报。

## 二、通用识别公式（比记类型更有用）

无论话术怎么变，诈骗最终都收敛到以下几个动作之一。**出现任意一条，按诈骗处理**：

1. 💸 要你**转账/垫资/充值解冻/交保证金**；
2. 🔢 要你提供**短信验证码**；
3. 🖥️ 要你**开共享屏幕**、下载指定 App（非官方商店）、点指定链接；
4. 🤫 要求**保密、不许告诉任何人**（家人/辅导员/警察）；
5. ⏰ 制造**紧迫感**（"马上冻结""2小时内不处理就…"）；
6. 🏦 引导你**脱离官方平台**私下交易。

> 反过来记：**真机构不怕你挂电话去核实。** 挂断 → 打官方电话 → 问辅导员，永远来得及。

## 四、几个具体场景的"标准答案"

| 场景 | 标准动作 |
|---|---|
| "客服"来电说快递丢失要理赔 | 挂断 → 打开购票/购物官方 App 查订单状态 → 有问题自己发起售后 |
| "导师/领导"微信/视频让转账 | 电话回拨原号码核实 + 视频里让对方按脸转头 + 当面确认 |
| "公检法"说你涉案 | 挂断 → 拨 110 核实 → 真警察会约你到所里当面处理 |
| 兼职群发"点赞/刷单/打字员" | 直接退群；给送上门的高薪兼职默认按诈骗处理 |
| 陌生链接说"你的包裹有问题" | 不点链接；快递问题只看官方 App 物流通知 |
| 网恋对象带你"投资" | 拉黑；没见过面谈钱 = 100% 杀猪盘 |
