## 知识整理

### 解释型语言与运行方式

Python 与 C++ 最大的流程差异是不需要编译：.py 文件直接由解释器执行，"运行到哪里执行到哪里"，没执行到的函数不会被转成机器码。若你已在 C 课上熟悉"解释 vs 编译"，这段对比可略。代价是执行慢，收益是开发效率高——讲师的经验：追求性能（如数据结构作业）用 C++，功能型任务用 Python；AI 方向的 NumPy、PyTorch 等库也都经由 Python 调用。

运行方式有两种：终端敲 `python` 进交互式解释器即时执行（也适合快速检验环境里某个库装好没有）；或写成脚本 `python example.py` 运行，不生成中间文件。

新手第一课是读 traceback：它逐层递归给出文件、行号与函数，中间的库调用帧可忽略，重点看最底一行的错误类型（如 ZeroDivisionError）与消息。

### 动态类型与基础语法

Python 动态类型又强类型：变量类型随赋值改变，但自动转换很有限——`int("3")` 按值转换而非查 ASCII 码，字符串 `+` 是拼接，乱转就 ValueError。附赠一个福利：整数超限自动扩容，不像 C++ 会溢出回绕，写数据结构作业少一类"莫名其妙的 bug"。布尔值注意 True/False 首字母必须大写。

语句层面：行尾不强制分号，长语句用反斜杠或括号换行；`if __name__ == "__main__"` 相当于 C++ 的 main，仅文件被直接运行时其下语句才执行。分支与循环用缩进（四空格）划界，逻辑运算用 and/or/not；while 同 C++ 但没有 do-while。`for i in range(5)` 枚举 0~4，range(start, stop, step) 左闭右开、step 可为负；for 更多用于遍历容器，enumerate 可同时拿索引与元素。

字符串：单双引号等价但不能混用；前缀 r 得原始字符串；没有 char 类型，单字母也是字符串；f-string 用大括号插变量。运算符：`/` 真除法、`//` 取整、`**` 幂；is 比地址、== 比值——所有 None 共享同一内存，判空用 is None；小整数 -5~256 有缓存，`x is 3` 恒真而 `x is 666` 不然（面试向细节）。

### 容器类型与生成式

list 元素可异构、可嵌套。切片 `a[1:3]` 左闭右开，负索引 -1 为倒数第一，`[start:stop:step]` 省略默认到头，`[::-1]` 反转。增删改要分清"原地 vs 新建"：append/insert/extend 原地修改，`+`、`*2` 返回新列表；pop 按索引删、remove 按值删、clear 清空；切片还能批量替换。字符串不可变，`s[0]='h'` 直接报错。

tuple 小括号、不可变；函数 return 多个值就是元组，`a,b,c = f()` 解包，变量交换同理。set 大括号、无序、自动去重，in/not in 判断，add/remove 增删。dict 键值对：`d[k]` 键不存在抛 KeyError，`d.get(k, default)` 给默认值更鲁棒；key 必须可哈希——记"set 不能当 key"即可。

生成式（推导式）是 Python 招牌的简洁性：一行构建容器，可带 if 过滤，字典也能推导（`{i: i*i}`），比 C++ 逐元素赋值省事得多。

### 函数与面向对象

函数用 def + 冒号 + 缩进划界；没有 return 就没有返回值，函数体暂空用 pass 占位。参数有四种：位置参数按序传；关键字参数可乱序但必须放在位置参数之后（建议要么全带等号、要么全不带）；默认参数不传则用默认值；*args 收任意多个位置参数，**kwargs 以键值对收集。

面向对象用 class + 缩进定义：`__init__` 是构造函数；可在类外补挂类属性，实例未单独赋值时共享它；成员变量前加双下划线即私有，类外访问报错、类内方法可访问。继承本讲略过。

### 模块、环境与协作

import 之后要带 `math.sqrt` 这样的前缀；`import x as m` 起别名；`from math import sqrt` 直接用函数名。模块分内置（装好即有，仍需 import）与第三方（先 pip install）。装包遇到国外源卡住，加 `-i` 换清华源——命令不必背，问 AI 就行。学新库的路子：读官方文档（费时）、看样例与经典项目、看 IDE 提示；讲师最推荐直接把需求说给 AI，让它选库给用法。

自定义层面：一个 .py 文件即一个模块；文件夹要做包必须有 `__init__.py`（可为空），否则不被当作包；引用用点表示从属关系，不是路径斜杠。多项目共存的版本冲突由 conda 解决：`conda create -n example python=3.9` 建独立环境（不指定版本可能不是最新），activate/deactivate 切换，包只装进当前激活的环境。协作时一人导出 requirements.txt 上传 GitLab，协作者 `pip install -r requirements.txt` 一次装齐——暑培项目仓库本身就带这个文件可参考。

### 异常处理、调试与文件

try/except/else/finally 的典型场景是"长跑任务"：爬虫过夜、训练实验的重复循环，外层包一层 try，单条报错不影响整体。断点调试用 breakpoint() 进入 pdb 交互终端：查看变量、设条件断点，c 继续、q 退出。文件操作推荐 with open，缩进块结束自动关闭；模式 r 只读、w 只写（会清空原文件——小心别毁掉实验结果）、a 追加；读有 read/readline/readlines 三种。
