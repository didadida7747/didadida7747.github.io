# 第 4 分册：开源自建 Personal Agent 方案（OpenClaw / Hermes Agent）

> 读者：中国高校计算机/电子信息专业本科生（大一~大三）。
> 信息基准日：2026-10-20。开源项目迭代极快，本文 star 数、价格、命令均为当天核实值，使用前请以官方仓库最新 README 为准。

## 1. 一句话定位与适用人群

**一句话定位：OpenClaw 和 Hermes Agent 是两个「开源、免费、跑在你自己电脑/VPS 上、住在 Telegram/Discord/微信桥等聊天软件里」的个人智能体框架——软件本身一分钱不收，你只为背后的大模型 API 按量付费，数据和记忆全部存在你自己硬盘上。**

**谁适合自建：**

- 计算机专业、会装环境、看得懂报错的同学——这是你的主场；
- 在意隐私，不想把聊天记录交给商业公司的人；
- 想把 agent 接到 Telegram/Discord 这种自己常用聊天软件的人；
- 想学习 agent 架构（网关/记忆/工具/cron/多 agent）、顺便写简历项目的人。

**谁不建议自建：**

- 连「环境变量」「端口」是什么都要现查的同学——先用豆包/扣子这类零代码产品（社区教程显示扣子 10 分钟就能做出第一个 agent），别上来就折腾 [（社区视频，2026-10）](https://www.iesdouyin.com/share/video/7694666660619953649)；
- 只想要「打开 App 就能用」的人——直接看 Today AI / Grok Bot 分册。

## 1.5 30 分钟上手最短路径（以 OpenClaw 为例）

目标：从零到在自己手机 Telegram 里跟自建 agent 说上第一句话。

1. 注册 DeepSeek 开放平台（platform.deepseek.com），充 ¥10，创建一个 API key，复制保存。
2. 打开电脑终端（Windows 用 PowerShell），跑安装命令：`iwr -useb https://openclaw.ai/install.ps1 | iex`（mac/Linux 换成 curl 那条）。
3. 跑 `openclaw onboard --install-daemon`，向导里模型选 OpenAI 兼容/DeepSeek，粘贴 key。
4. 浏览器自动打开 `openclaw dashboard`，在网页控制台发一句「现在几点，今天西安天气如何」——它能调用工具查出来，说明大脑通了。
5. Telegram 找 @BotFather 创建 bot，把 token 填进渠道配置，给自己 bot 发消息，终端跑 `openclaw pairing approve telegram <code>` 批准。
6. 手机 Telegram 里发：「每天早上 8 点把西安天气和今日课程安排发到这个聊天」——让它建第一个定时任务。

顺利的话 30~60 分钟；卡在哪一步就翻 §8 排查表。

## 3. OpenClaw 完整部署步骤

### 3.1 它是什么（先搞懂架构再动手）

OpenClaw = 跑在你自己电脑上的 AI 助手，核心是一个叫 **Gateway** 的本地进程：所有渠道（Telegram/Discord/网页控制台）的消息都汇到 Gateway，由它调度 Agent 大脑 → Skills 工具箱 → Memory 记忆。你跟它的对话发生在聊天软件里，干活的是你自己的电脑 [（GitHub README，2026-10-20）](https://github.com/openclaw/openclaw)。

抖音社区总结的模块分工（可当架构图看）：AGV 网关鉴权路由 / Channels 多渠道统一消息格式 / Agent 大脑（观察-思考-计划-执行-反思闭环）/ Skills 工具箱 / Memory 短期上下文+长期存储 / Nodes 跨设备手脚 / Heartbeat 主动巡逻 / Cron 定时任务 [（社区视频，2026-04）](https://www.iesdouyin.com/share/video/7632620197828431738)。

**隐私要点（官方声明）：** State、memory、credentials 存在你自己的硬件上；提示词只发往你配置的模型商和聊天平台；默认每天只做一次版本检查，可用 `update.checkOnStart: false` 关掉 [（GitHub README，2026-10-20）](https://github.com/openclaw/openclaw)。

### 3.2 环境准备

| 项 | 要求 |
|---|---|
| 系统 | macOS / Linux / WSL2 / Windows（官方一键脚本会自动装配套的 Node.js 运行时，无需你手动装） |
| Node.js | 自己管理时需 24.16+ 或 26.1+（推荐 26）；用官方安装脚本则不用管 |
| 模型 API key | 至少一个：DeepSeek / OpenRouter / OpenAI / Anthropic 任选其一（价格见 §5） |
| 聊天软件（可选） | Telegram 账号（最推荐）、Discord 账号等 |
| 网络 | 国内直连 GitHub/npm 可能慢，建议配好代理或镜像；DeepSeek/百炼 API 国内直连无障碍 |

### 3.3 安装（命令原文照抄）

**macOS / Linux / WSL2：**

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

**Windows PowerShell：**

```powershell
iwr -useb https://openclaw.ai/install.ps1 | iex
```

**已经自己装好了 Node.js 的同学（npm 全局装）：**

```bash
# npm 12 或 npm 11.16+
npm install -g openclaw@latest --allow-scripts=openclaw
# npm 11.15 及更早：去掉 --allow-scripts=openclaw
```

以上命令均为官方 README 原文 [（GitHub README，2026-10-20）](https://github.com/openclaw/openclaw)。

**从源码开发（想读源码/改代码的）：**

```bash
git clone https://github.com/openclaw/openclaw.git
cd openclaw
pnpm install
pnpm build
pnpm ui:build
```

注意：仓库是 pnpm workspace，根目录直接 `npm install` 不支持。

### 3.4 初始化向导与验证

```bash
openclaw onboard --install-daemon   # 装完后跑引导向导：验证模型访问、建 workspace、配 Gateway
openclaw gateway status             # 看网关状态
openclaw dashboard                  # 打开网页控制台，在里面发一条消息确认助手活着
```

onboarding 向导是交互的，会一步步让你填模型 provider 和 API key——按提示走即可。

### 3.5 接入聊天软件（以 Telegram 为例）

OpenClaw 支持 Discord、iMessage、Slack、Teams、Telegram、WhatsApp 等 20+ 渠道，每个渠道都在向导或 Channels 文档里配置 [（GitHub README，2026-10-20）](https://github.com/openclaw/openclaw)。Telegram 的通用流程：

1. 在 Telegram 里找 `@BotFather`，发 `/newbot`，按提示创建 bot，拿到 **Bot Token**；
2. 把 Bot Token 填进 OpenClaw 的渠道配置（向导中选 Telegram，或按官方 Channels 文档编辑配置文件）；
3. 给自己的 bot 发任意消息——OpenClaw 默认对陌生 DM 发送者走**配对机制**，你需要在终端批准：

```bash
openclaw pairing approve <channel> <code>   # 例：openclaw pairing approve telegram ABC123
```

4. 批准后即可在 Telegram 里跟它对话，它在你电脑上干活。

> 国内无 Telegram 的同学：社区已有微信桥方案（如 HermesClaw 这类社区桥接工具可让 agent 共用一个微信号），也有用户对接飞书/钉钉的实践 [（GitHub README，2026-10-20）](https://github.com/NousResearch/hermes-agent) [（社区视频，2026-04）](https://www.iesdouyin.com/share/video/7632620197828431738)。

各渠道速查（以官方 README 列出的为准，配置入口均为 onboarding 向导或 Channels 文档页）：

| 渠道 | 配置要点 | 国内可用性 |
|---|---|---|
| Telegram | BotFather 建 bot 拿 token + pairing 批准 | 需自备网络条件 |
| Discord | 在 Developer Portal 建 bot 拿 token，加进自己服务器 | 需自备网络条件 |
| WhatsApp / Signal / iMessage / Teams | 官方支持列表内，按 Channels 文档配置 | WhatsApp/Signal 需自备网络条件 |
| 微信 / 飞书 / 钉钉 | 官方列表外，靠社区桥接 | 微信桥需自行找社区方案；飞书/钉钉有用户实践 |
| 网页控制台（Control UI / dashboard） | 装好即有，免配置 | ✅ 直接用，最适合入门第一步 |

### 3.6 模型 API key 配置要点

- 模型和 agent harness（Claude、Codex、本地模型）都是**插件化可替换**的，在向导或 Models 文档页配置；
- 建议学生党先用 **DeepSeek** 或 **通义百炼** 的 key（国内直连、极便宜，价格见 §5），跑顺了再换 Claude/GPT；
- key 存在本地配置里，**不要**把含 key 的配置文件传到公开 GitHub（会被扫描器秒偷）。

### 3.7 插件 / Skills 机制

- **Tools / Skills / Plugins** 三层扩展：新能力通常写成插件，发布到社区市场 **ClawHub**；
- 官方 Control UI 偏简陋（只能看状态、不能编辑文件），社区已出现 5+ 第三方可视化面板：龙虾图书馆（2D 像素风资产控制室）、3D 世界会话看板、OpenClaw Control Center（数据大屏 + 多 agent 群聊协作）、agent monitor（办公室看板 + token 用量统计）、openclaw-admin [（社区视频，2026-04）](https://www.iesdouyin.com/share/video/7623794383699053830)；
- 多 agent 玩法：可以直接用自然语言让 OpenClaw 自己读配置文档、引导你填 APP ID/Secret，3 分钟搭一个新 agent [（社区视频，2026-03）](https://www.iesdouyin.com/share/video/7615242484712590638)。

### 3.8 安全红线（官方明确写的）

- 把所有入站消息当**不可信输入**——聊天软件里任何人都能给你的 bot 发消息；
- 工具默认直接跑在宿主机上，暴露 Gateway 到公网之前，必须先读官方 security / exposure / sandboxing 三篇文档；
- 李开复在社区视频里点名：**安全短板和多 agent 编排错误叠加**是 OpenClaw 当前最大的坑 [（社区视频，2026-03）](https://www.iesdouyin.com/share/video/7613725607263735075)。

## 4. Hermes Agent 完整部署步骤

> ⚖️ **分工注（2026-10-25）**：本节为速览；安装/排坑/手机连通的**唯一维护版**在 [`hermes-agent-guide/`](/22-Hermes-Agent指南/)（02 安装、05 常见坑、07 手机连通），两处冲突时以那边为准。

### 4.1 它是什么

Nous Research 2026 年 2 月发布的开源自主 agent。和 OpenClaw 的差异点：**自带学习闭环**——它会从复杂任务里自动总结出 skill、用的过程中自我改进、定期提醒你沉淀知识、用 FTS5 全文检索自己的历史会话，跨会话越用越懂你。可以跑在 $5/月的 VPS、GPU 集群或 serverless（空闲时几乎不花钱），从 Telegram 指挥它干活 [（官网，2026-10）](https://www.hermes-agent.org/) [（GitHub README，2026-10-20）](https://github.com/NousResearch/hermes-agent)。

### 4.2 环境准备

- 支持 Linux / macOS / **WSL2**，也支持 **原生 Windows**（无需 WSL，CLI/gateway/TUI/工具全原生）；Android/Termux 有专用 APT 包；
- 官方安装器会自动装好 Python 3.14、Node.js、npm、ripgrep、FFmpeg 及 Python 依赖，无需你手动准备；
- 至少一个模型 API key（或直接订阅 Nous Portal 全包）。

### 4.3 安装（命令原文照抄）

**Linux / macOS / WSL2：**

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

**Windows 原生 PowerShell：**

```powershell
iex (irm https://hermes-agent.nousresearch.com/install.ps1)
```

安装后初始化：

```bash
source ~/.bashrc   # 或 source ~/.zshrc
hermes             # 开始聊天
```

Windows 原生安装目录在 `%LOCALAPPDATA%\hermes`；WSL2 下在 `~/.hermes`。以上均为官方 README 原文 [（GitHub README，2026-10-20）](https://github.com/NousResearch/hermes-agent)。

### 4.4 配置模型、工具与记忆

```bash
hermes model       # 选择 LLM provider 和模型（Nous Portal / OpenRouter / OpenAI / 自建 endpoint）
hermes tools       # 配置启用哪些内置工具（40+ 个：终端、文件、网页、浏览器等）
hermes config set  # 单项设置
hermes setup       # 全量配置向导（一次性配完所有东西）
hermes doctor      # 出问题先跑它，自动诊断
```

**持久记忆怎么开：** 记忆是默认开启的核心功能（agent-curated memory + MEMORY.md / USER.md 沉淀 + FTS5 会话检索），不需要额外装插件；你只要在对话里正常用，它会主动提醒「要不要把这条经验存成 skill」。最佳实践见官方 Memory 文档页。

**想省事不想收集 5 个 API key？** Nous Portal 一个订阅包圆 300+ 模型 + 网页搜索 + 画图 + TTS + 云浏览器：

```bash
hermes setup --portal    # OAuth 登录，自动配好一切
hermes portal info       # 随时查看接了哪些
```

### 4.5 接入 Telegram / Discord 等聊天网关

```bash
hermes gateway setup    # 配置消息网关（Telegram/Discord/Slack/WhatsApp/Signal/Email）
hermes gateway start    # 启动后给 bot 发消息即可对话
```

会话内斜杠命令（CLI 和聊天端通用）：`/new` 新会话、`/model` 换模型、`/personality` 换人设、`/compress` 压缩上下文、`/usage` 看用量、`/skills` 浏览技能库 [（GitHub README，2026-10-20）](https://github.com/NousResearch/hermes-agent)。

### 4.6 定时任务（cron）

内置 cron 调度，自然语言配置，产物可投递到任意平台：每日天气/新闻播报、夜间备份、每周周报—— unattended 运行。这是 Hermes 相比一般聊天机器人的杀手级功能。

### 4.7 从 OpenClaw 迁过来（可选）

```bash
hermes claw migrate            # 交互式迁移全部配置
hermes claw migrate --dry-run  # 先预览会迁什么
```

自动导入：SOUL.md 人设、MEMORY.md/USER.md 记忆、自建 skill、命令白名单、各聊天平台配置、API keys（Telegram/OpenRouter/OpenAI/Anthropic/ElevenLabs）[（GitHub README，2026-10-20）](https://github.com/NousResearch/hermes-agent)。

## 4.8 实战场景与可复制指令

装好后别只会「你好」，下面四个场景直接抄：

**场景 A：每日早起简报（cron）**

- 指令原文：「每天早上 7:30 给我推送：西安今天天气、今日课程表、一条技术新闻。天气查准确的实时数据，不要猜。」
- 预期效果：Hermes 用内置 cron 建定时任务，到点自动跑到聊天窗口推送。

**场景 B：学习资料整理**

- 指令原文：「我把一个 PDF 发给你，你帮我提炼每章要点，整理成 Markdown 存到我的 workspace 的 notes 目录，文件名用『章节名.md』。」
- 预期效果：agent 调文件/工具完成读写，顺便沉淀成一个可复用 skill。

**场景 C：每周代码复盘**

- 指令原文：「每周日晚上 9 点，扫一遍我本周 git commit 记录，按项目总结我写了什么、哪里改了三次以上（说明没写好），发给我。」
- 预期效果：自动化审计，不用自己回忆。

**场景 D：隐私敏感操作加审批**

- 指令原文：「凡是要发消息给别人、要付款、要删除文件的操作，先停下来问我确认，我同意了再执行。」
- 预期效果：把高危动作纳入人工确认，对应官方安全文档的 command approval 机制。

### 5.2 学生用量月度估算示例

> 算法：月成本 ≈ 月输入 token × 输入单价 + 月输出 token × 输出单价。Agent 场景输入远大于聊天（系统提示+记忆+工具结果都进上下文），按 2.5:1 输入输出比估算。

| 用量档 | 月 token 量 | DeepSeek flash | 通义 qwen-long | Grok 4.20 | Claude Sonnet 5.5 |
|---|---|---|---|---|---|
| **轻度**（每天 20~30 条消息，偶尔工具调用） | 输入 5M / 输出 2M | **¥13/月** | **¥6.5/月** | $11.25 ≈ ¥80 | $30 ≈ ¥215 |
| **中度**（挂 Telegram 网关 + cron 日报 + 每周几次编程任务） | 输入 20M / 输出 8M | **¥52/月** | **¥26/月** | $45 ≈ ¥320 | $120 ≈ ¥860 |

**结论：学生自建，用国产模型月花费 ¥5~60；用海外旗舰模型会跳到 ¥300+/月。** 省钱三件套：①默认用 DeepSeek/qwen-long，只有重任务切好模型；②开缓存（DeepSeek 缓存读取 ¥0.1/M）；③在 `hermes`/OpenClaw 里用 `/usage` 盯用量、在阿里云/DeepSeek 控制台设额度提醒。

## 6. 自建 vs 官方产品（Today AI / Grok Bot）取舍表

| 维度 | 自建（OpenClaw / Hermes） | Today AI / Grok Bot 这类官方产品 |
|---|---|---|
| 隐私 | ⭐⭐⭐ 记忆、聊天、凭证全在自己硬盘/自己 VPS | 数据在厂商云端，按厂商政策留存 |
| 成本 | 软件免费，只付模型 API 费；轻度 ¥5~20/月，中度 ¥30~60/月（国产模型） | 订阅制，通常 $10~30/月，用量不限但不可换模型 |
| 门槛 | ⭐ 需会命令行、配 API key、排报错；首次折腾半天~两天 | ⭐⭐⭐ 注册即用 |
| 能力 | 模型随便换、插件/skill 生态自由扩展、可接 20+ 聊天渠道 | 开箱即用但能力边界由厂商定 |
| 稳定性 | 自己负责升级（`openclaw onboard`/`hermes update`），踩坑靠社区 | 厂商维护，几乎零操心 |
| 网络环境 | DeepSeek/百炼国内直连；Telegram 需自备网络条件 | 多数官方产品需海外网络/支付方式 |

**一句话取舍：** 怕麻烦、只想要效果 → 用官方产品；学技术、要隐私、想白嫖便宜 API → 自建，计算机专业学生建议先花一个周末把 OpenClaw 在自己笔记本上跑通，这本身就是一份写简历的 agent 项目经历。

**商业同类对照（详见 `附录-调研原始笔记/同类产品.md`）：** Meta Muse（Meta，2026-09 美国首发，muse.ai/WhatsApp，国内不可用）、Macaron（Pro $9.99/月起）、Lindy（免费 $50 额度 7 天，Team $29.99/人/月）都是「云端托管、免运维」路线；国内对照物是豆包/扣子（免费、零代码、直接可用）。自建路线与它们的本质差别：数据在谁手里、谁付订阅费。

## 8. 常见报错与排查

| 症状 | 可能原因 | 处理 |
|---|---|---|
| Windows 杀软把 Hermes 的 `uv.exe` 隔离/报毒 | 误报（Rust 编译的 Python 包管理器，ML 引擎常误判） | 官方 README 给了校验脚本：用 `gh attestation` 验证 astral-sh/uv 签名；并把 `%LOCALAPPDATA%\hermes\bin` 整个目录加白（加目录而非文件 hash，因为 uv 随版本更新） [（GitHub README，2026-10-20）](https://github.com/NousResearch/hermes-agent) |
| OpenClaw 装好但发消息没反应 | Gateway 没起来 / 渠道 token 填错 | `openclaw gateway status` 看状态；Telegram 检查 BotFather token；陌生 DM 需 `openclaw pairing approve <channel> <code>` |
| 花钱超预期 | Agent 上下文巨大，输入 token 爆炸 | `/usage` 看用量；`/compress` 压缩上下文；默认模型换 DeepSeek flash；控制台设额度上限 |
| npm install 卡住 / 权限报错 | 国内网络 + 根目录 npm | 换 pnpm 或官方安装脚本（自动配 Node 环境）；配 npm 镜像源 |
| 收不到好友发来的消息 | 配对/安全机制默认拦截 | 官方设计如此，逐个批准配对请求；不要为了省事把 Gateway 裸暴露公网 |
| Hermes 一切异常 | — | 先跑 `hermes doctor`，官方自带诊断 [（GitHub README，2026-10-20）](https://github.com/NousResearch/hermes-agent) |
| `curl ... | bash` 在国内超时 | GitHub/官方域名访问慢 | 配代理或换网络；安装脚本只下载一次，装好后日常使用不依赖它 |
| API key 填了还是 401 | DeepSeek 等国产模型要选「OpenAI 兼容」接入点，base_url 不是 openai.com | 在模型配置里把 base_url 改成服务商给的兼容地址（DeepSeek 为 https://api.deepseek.com） |
| Agent 越用越「健忘」 | 会话上下文被压缩/重置 | Hermes 用 `/new` 前先确认重要事项已被它记进 memory；OpenClaw 检查 memory 文件是否正常写入 workspace |
| 多 agent 同时跑很卡 | 主进程扛不住 + token 翻倍 | 官方与社区都指出多 agent 编排是当前短板，先单 agent 跑顺再拆 [（社区视频，2026-03）](https://www.iesdouyin.com/share/video/7613725607263735075) |
| 笔记本关机后 bot 失联 | Gateway 跑在本机，关机即停 | 长期挂着用就租 $5/月 VPS 跑 Linux 版；Hermes 官方明确支持这种用法 [（官网，2026-10）](https://www.hermes-agent.org/) |
| 想升级又怕搞坏 | — | `hermes update` / OpenClaw 每日版本检查；升级前备份 `~/.hermes` 或 `~/.openclaw` 目录（记忆都在里面） |

## 8.5 隐私与安全边界（自建不等于绝对安全）

自建的隐私优势是真实的——记忆、对话、凭证默认在你自己硬盘，OpenClaw 官方声明除每日版本检查外不回传数据 [（GitHub README，2026-10-20）](https://github.com/openclaw/openclaw)。但边界要认清：

1. **提示词仍要过模型商**：你发的每条消息都送给 DeepSeek/OpenAI 等服务商，自建只解决「框架留存」，不解决「模型商留痕」。敏感数据（身份证、银行卡密码）不要喂给它。
2. **聊天软件等于公开入口**：bot 挂到 Telegram 后，理论上任何人都能找到它发消息。务必保持 pairing 审批、限制只服务自己账号。
3. **工具默认有宿主机权限**：agent 能读写你硬盘上的文件、执行命令。别把包含隐私目录（如浏览器密码库）的文件夹交给它当 workspace。
4. **API key 就是钱**：泄露后被刷接口扣费，设置月度额度上限，key 不要传公开仓库。
5. **VPS 部署要加固**：跑在公网 VPS 上时，别裸奔 Gateway 端口，按官方 exposure runbook 配访问控制。

## 8.6 高频 FAQ

- **Q：我没有 GPU 能跑吗？** 能。这两个项目调的都是云端 API，本地只跑网关和工具，普通笔记本甚至 $5/月 VPS 就够。
- **Q：能完全离线用本地模型吗？** OpenClaw 官方把本地模型列为可插拔模型 provider，但前提是你自己有能力部署开源模型并接进来；新手别上来就玩本地模型。
- **Q：跟 ChatGPT/豆包网页版有啥区别？** 网页版只回答问题；自建 agent 住在你聊天软件里、有记忆、会主动定时干活、能操作你电脑上的文件。
- **Q：两个都装会不会冲突？** 不会，端口和目录各自独立；Hermes 还提供一键从 OpenClaw 迁移。
- **Q：会不会哪天项目停更？** 截至 2026-10-20 两者都高度活跃（数万 commits、5k+ open issues、非营利/知名团队背书），但开源项目都有风险，重要配置记得备份。
- **Q：学生党第一步到底选哪个？** 想要热闹生态和中文教程 → OpenClaw；看重持久记忆和定时任务 → Hermes。装错了可以互迁。
