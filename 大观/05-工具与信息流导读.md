## A. 软件使用\（AI 编程工具选型）

### README.md（选型总入口，2026-08-13 版）
- **TL;DR**：明确的工程任务优先 **Codex**（工作流完整）；已配好 Grok 环境就用 Grok Build；需要多模型路由/比较/故障回退才上 **OMP**；没明确工程目录时先普通聊天。
- **要点**：六步安全闭环——先只读、小步改、看 diff、实测验证、不贴密钥；OMP 是"工具壳"不是模型，订阅不能想当然替代 API 额度。
- **怎么读**：选工具犹豫时读；日常任务直接 Codex，不必再纠结。

## B. 每日视野简报\（已运转的流水线）

- **定位**：AI 半自动化每日 10 分钟中文信息简报：政策、经济金融、科技产业、科学能源、公共安全。
- **TL;DR**：流水线四段——`scripts/collect.py` 采集（`config/sources.json` 一手来源）→ Codex 按 `prompts/每日任务提示词.md` 筛选撰写 → `scripts/validate.py` 校验 → 周日生成周报。产出结构固定："今日一句话 → 三点先读 → 今日重点（事实/为什么重要/可能影响/不确定性/来源五段）"。
- **要点**：质量纪律——每天 8-12 条、一级来源优先（政府/央行/国际组织/论文原站）、每条必须带来源和"不确定性与反方证据"字段、采集失败不得静默丢弃、不构成投资建议。
- **怎么读**：日常只读 `reports/daily/` 当天报告（现有 9 份，08-15 至 09-06）；想复刻或维护时读 README 的"工作方式"和"质量边界"。

## C. 公众号精选\（待运行的流水线）

- **定位**：微信订阅号自动抓取与导读流水线：全文留本地、导读上站。
- **TL;DR**：三步工作法——wewe-rss 把订阅号变 RSS → `config/feeds.json` 登记地址 → `npm run wx:sync` 拉全文更新导读。版权边界：`articles/` 全文被 gitignore 永不上站，公开页面只放标题/摘要/链接 + 自己写的精读笔记。
- **要点**：目录里 `scripts/wx_sync.mjs` 是同步脚本；日常节奏每 1-2 天同步一次、每周让 AI 扫导读挑精读篇目。
- **怎么读**：README 是完整搭建运维手册。**注意：`articles/` 和 `导读/` 当前为空——流水线已搭好但尚未有产出，处于待运行状态**（想用起来：先跑 wewe-rss，再执行 wx:sync）。

## 本组要点

- **工具决策树**：有明确工程目录 → Codex；想多模型比较 → OMP；学 ZCode 本身 → zcode使用\ 手册。都装了但没用起来的，从 codex使用\ 的 30 分钟 onboarding 开始。
- **信息流决策**：每日视野简报已稳定，保持每天 10 分钟读日报即可；公众号流水线跑不跑起来需要你决定（要 wewe-rss 常驻，有维护成本）。
- **联动**：简报的"五段式"（事实/为什么重要/影响/不确定性/来源）是很好的批判性阅读模板，可以借用到读任何 AI 生成的资料上。
