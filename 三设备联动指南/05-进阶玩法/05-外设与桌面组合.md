# 外设与桌面组合:一套键鼠、一块屏,三台设备共用

## 一、USB-C"一线通"扩展坞:先避坑 ★

- **多数拯救者的 USB-C 口 = 数据 + DP 视频输出,不支持 PD 充电输入**——插扩展坞传视频文件没问题,但给笔记本供电仍要走方口电源(2023 后个别新机型支持 140W PD 3.1,查你自己型号的官方规格页)。
- 判断方法:联想官网搜你的具体型号 → 规格 → 是否标注"USB-C 支持 PD 输入/充电"。
- 结论:想靠一根线"显示+供电"的一线通桌面,拯救者大概率落空;桌面上老老实实方口电源 + 一根 USB-C/DP 线出显示。

## 二、一套键鼠控制三设备

| 方案 | 体验 | 说明 |
|---|---|---|
| **罗技 MX 系列 Easy-Switch**(MX Keys S / MX Master 3S / K380) | 手动一键切换 | 三通道:拯救者/一加/iPad 各占一个,Fn+数字秒切;iPadOS 指针支持让 MX 鼠标在 iPad 上体验尚可。**注意:罗技 Flow 的自动漫游+跨机剪贴板仅限 Windows/macOS 之间,不含 iPadOS**;Bolt 接收器 iPad 用不了,必须走蓝牙 |
| KVM 功能显示器(技嘉 M27Q、明基 PD、戴尔 P 系列等) | 切换即切画面+键鼠 | 多数只有 2 个上行口,三设备需再配 KVM 切换器;适合"拯救者+一台主机"为主、iPad 偶尔上桌的布局 |
| 软件 KVM(Barrier/Input Leap/Deskflow) | — | ❌ 都不支持 iOS,此路不通 |
| 蓝牙多点耳机 | 同时连 2 台 | 绝大多数耳机"双设备同时连接",三台要手动切换,别指望无缝三连 |

- 剪贴板跨机:软件层用 KDE Connect/SyncClipboard 补(见 [03-2](#/doc/d372))。

## 三、显示组合

- **桌面固定工位**:拯救者外接显示器(USB-C/DP/HDMI 均可出画面)+ iPad 支架当第二屏(spacedesk/Sunshine 虚拟屏,见 [01-1](#/doc/d366))。
- **出差轻装**:拯救者 + iPad = 双屏(Spacedesk 免费或 Duet USB 稳);拯救者 + 一加 = scrcpy 大屏反控;酒店电视 = Moonlight/Steam Link 手柄玩游戏(需电视盒支持安装或带个投屏器)。
- **iPad 支架建议**:可调角度磁吸/铝管支架,把 iPad 摆在显示器旁当竖屏副屏(文档/聊天/监控),这是三件套日常使用率最高的组合。

## 四、网络基础(串流/同步体验的地板)

- **5GHz / Wi-Fi 6 优先**,2.4G 留给 IoT;串流设备尽量连同一台路由/交换机;
- **Mesh 必须有线回程**:无线回程会占空口,串流抖动明显;没条件布线就把拯救者和常用串流设备放在主路由旁边;
- 拯救者**网线直插千兆交换机/路由**(局域网 Moonlight 要求网络延迟 <5ms);
- 路由器 QoS 给串流设备/拯救者提优先级;
- 路由器关闭"AP 隔离/访客网络隔离",否则 LocalSend/Tailscale 局域网发现全废(排错详见 [06/常见问题](#/doc/d381))。
