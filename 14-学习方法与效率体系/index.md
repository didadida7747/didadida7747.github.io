# 14 · 学习方法与效率体系（怎么学，比学什么更值钱）

> 定位：**01 管工具怎么装，07 管课程学什么，本库管"学习这件事本身的操作系统"**——循证方法、记忆系统、笔记体系、时间精力、AI 辅助、信息饮食、复盘模板，七件套。
> GitHub star 数为 2026-10-03 API 实查；B站资源给搜索关键词。

---

## 一、为什么需要这个库

你现在同时开着多条线：课内绩点、大模型自学、六级、竞赛、项目。**多线并行时，拼的不是总时长，是单位时间的转化率**——这正是学习科学研究的对象：哪些方法有证据、哪些是伪科学（反复通读、划线、抄笔记都属于后者）。

## 三、最小起步（本周就能做）

1. 读 01 篇，把「主动回忆」用到一门正在上的课上（关上 PPT 自己复述一遍）；
2. 装 Anki，为六级词汇建第一副牌（02 篇有制卡法）；
3. 把 05 篇的「苏格拉底导师」prompt 存进备忘录，下次复习前用一次；
4. 在滴答清单建「收集箱」，所有杂事只进这一个入口（04 篇）。
