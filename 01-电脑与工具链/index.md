## 二、推荐阅读 / 使用顺序

1. **第一周**：通读总纲，重点执行附录 C「新手第一周必做清单」（Windows 优化、磁盘规划、必备软件）。
2. **上专业课 / 做课设时**：查总纲第三章装专业软件，**安装前先看其磁盘规划建议**；搭开发环境查总纲第四章（VS Code + Git + Python + WSL2）。
3. **电脑卡、想提速时**：总纲第二章；剪视频、联网、升级硬件时：总纲第五~七章。
4. **养护与故障**：以保养手册的日历表为准；送修信号看保养手册。
5. **多设备协同**（iPad/手机投屏、互传、远程）：直接看三设备联动指南。

## 三、三条核心提醒

- **16GB 内存是最大短板**：跑 Vivado 全量工程、本地大模型前建议升级到 32GB 双通道。
- **1TB 硬盘要规划分区**：EDA/仿真软件体积巨大（Vivado 全装 100GB+），一律装 D 盘，路径不含中文和空格。
- **EDA 不吃显卡、AI 才吃**：RTX 4060 的价值在剪辑 NVENC、本地大模型和 AI 编程，不必为专业软件纠结显卡设置。
