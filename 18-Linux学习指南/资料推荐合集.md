# Linux 学习资料推荐合集（文档优先版）

> 适用读者：准零基础、Windows 11 + WSL2 + Ubuntu 24.04、目标后端开发 / 服务器运维方向的大学生
> 调研日期：2026-10-13
> 本版定位：**以文档阅读为主线**，视频仅作卡点时的选看补充。

---

## 这份资料怎么用

如果你更习惯看文档、看书、自己查，而不是跟着视频一节节看，那么这份合集就是为你准备的。**文档驱动是默认第一主线**，视频只在「某章卡住、想快速看一眼别人怎么操作」时选看。

### 纯文档学习顺序（三步走）

1. **读主线讲义**：先读本文件夹 01–15 章正文（本身就是文档讲义），逐章精读，每章配合 WSL2 终端实操。
2. **遇到概念 / 细节，查配套文字资料**：每章遇到不懂的概念，按方向查——
   - 官方文档 / 手册（WSL、Bash、systemd、Docker、NGINX、Ubuntu Manpages）
   - 经典文字教程（MIT Missing Semester 中文版、TLCL、鸟哥、Linux 就该这么学）
   - 中文博客速查（廖雪峰 Git、阮一峰 SSH / rsync / systemd、菜鸟命令大全）
   - GitHub 高星文字教程（the-art-of-command-line、linux-command、linuxtools_rst）
   - Arch Wiki（通用 Linux 知识最权威的社区文档，虽源自 Arch 但 Ubuntu 同样适用）
3. **到在线练习站动手**：Bandit 闯关、Killercoda / LabEx 沙箱实验，把读到的命令变成肌肉记忆。

### 视频什么时候看

**只在卡住时选看**：某一章读了文档还是不懂、想快速看一眼别人怎么敲命令、某个配置步骤卡住了——这时候才去 B 站 / YouTube 找对应专题视频。**不要把视频当主线**，视频太慢、节奏被人带着走，不适合喜欢自己掌控速度的人。

### 五层搭配速查

| 层级 | 角色 | 对应资料 | 用法 |
|------|------|----------|------|
| 主线 | 系统讲义 | 本文件夹 01–15 章正文 | 逐章精读，每章配合终端实操 |
| 查漏 | 文档 / 书籍补深度 | 官方手册、TLCL、鸟哥、Linux 就该这么学、MIT Missing Semester | 遇到概念不懂时翻对应章节，不必从头通读 |
| 速查 | 日常翻字典 | linux-command、the-art-of-command-line、manpages.ubuntu.com、Arch Wiki | 命令忘了就查，常备浏览器标签页 |
| 动手 | 在沙箱里犯错 | Bandit、Killercoda、Linux Journey | 闯关 / 做实验，把命令变成肌肉记忆 |
| 补充 | 卡点时选看 | B 站 / YouTube / 抖音 / 小红书 | 某章卡住才看，不作为主线 |

**核心原则：文档为主、动手为辅、视频兜底。选一条文档主线跟到底，不要同时开三套课。**

## 一、官方文档与权威手册（遇到问题先查）

> 报错、概念拿不准时，先查官方文档，再去搜博客。Arch Wiki 虽然源自 Arch Linux 项目，但内容覆盖通用 Linux 知识，被公认为整个 Linux 世界最好的用户文档，Ubuntu 同样适用。

| 名称 | 维护方 | 适合阶段 | 推荐理由 | 篇幅 |
|------|--------|----------|----------|------|
| [WSL 官方文档（简体中文）](https://learn.microsoft.com/zh-cn/windows/wsl/) | 微软 | 入门 | 本项目环境本身，第一天就该读，排错权威出处；[安装页](https://learn.microsoft.com/zh-cn/windows/wsl/install) 一句话 `wsl --install` | 安装配置约 1 小时 |
| [Ubuntu 在线 Manpages](https://manpages.ubuntu.com/) | Ubuntu | 入门→实战 | 浏览器版 man，不用本地装就能查，对应你 WSL 里的 Ubuntu 版本 | 常备查阅 |

## 三套按需搭配方案

### 方案一：文档驱动型（首选，推荐）

适合习惯看文档、看书、自己掌控节奏的同学。这是本合集的默认推荐路线。

1. **环境搭建（半天）**：照 [WSL 官方文档](https://learn.microsoft.com/zh-cn/windows/wsl/install) 装好 WSL2 + Ubuntu。
2. **主线讲义（每天 1~2 章，约 3~4 周）**：读本文件夹 01–15 章正文，每章读完在 WSL2 里实操一遍。
3. **命令行基础（2~3 周，与主线并行）**：选一本经典文字教程配合——
   - 中文选：[《鸟哥的 Linux 私房菜基础篇》](https://linux.vbird.org/)（讲解最细）
   - 英文选：[《The Linux Command Line》](https://www.linuxcommand.org/tlcl.php)（命令行哲学最透彻）
   - 运维导向选：[《Linux 就该这么学》](https://www.linuxprobe.com/chapter-00.html)（紧贴 RHCSA 考点）
   
   每天读一章，配合 [Linux Journey](https://labex.io/zh/linuxjourney) 做对应练习。
4. **工程工具能力（1 周）**：读 [MIT Missing Semester 中文版](https://missing-semester-cn.github.io/)，打通 Shell + Git + Vim。Git 部分配合 [廖雪峰 Git 教程](https://liaoxuefeng.com/books/git/introduction/index.html) 边学边练。
5. **运维深入（2 周）**：读 [阮一峰 Systemd 入门](https://www.ruanyifeng.com/blog/2016/03/systemd-tutorial-commands.html) + [Docker 官方 Get Started](https://docs.docker.com/get-started/) + [NGINX 官方指南](https://docs.nginx.com/nginx/admin-guide/)；遇到概念不懂就查 [Arch Wiki](https://wiki.archlinux.org/)。
6. **闯关巩固**：[OverTheWire Bandit](https://overthewire.org/wargames/bandit/) 34 关全部通关。
7. **真实云主机实战**：领 [阿里云学生券](https://www.aliyun.com/activity/ecs/student-benefits) 或 [腾讯云学生计划](https://cloud.tencent.com/act/campus) 开一台 ECS，自己装 Nginx + 部署一个简单网站。
8. **常备速查**：[linux-command](https://jaywcjlove.github.io/linux-command)、[the-art-of-command-line](https://github.com/jlevy/the-art-of-command-line)、[manpages.ubuntu.com](https://manpages.ubuntu.com/)、[Arch Wiki](https://wiki.archlinux.org/) 放浏览器标签页。

### 方案二：文档为主 + 卡点看视频跟练（次选）

**文档为主线，只在看不懂的章节看视频跟练。** 适合想试一下文档驱动，但某些章节光看文字实在转不过弯的同学。

1. **环境搭建（半天）**：照 [WSL 官方文档](https://learn.microsoft.com/zh-cn/windows/wsl/install) 装好 WSL2 + Ubuntu。如果文档装不上，再看 B 站 [Reaper_6 WSL Ubuntu 24.04 合集](https://www.bilibili.com/video/BV1qbQGYPEg7/)。
2. **主线讲义 + 书籍（3~4 周）**：读本文件夹 01–15 章正文，配合 [鸟哥](https://linux.vbird.org/) 或 [TLCL](https://www.linuxcommand.org/tlcl.php)。某章读不懂时，挑 B 站系统课（[韩顺平](https://www.bilibili.com/video/BV1Sv411r7vd) / [黑马](https://www.bilibili.com/video/BV1n84y1i7td/)）里对应那一集看一遍，**不要整套看**。
3. **Shell + Vim + Git（1 周）**：读 [MIT Missing Semester 中文版](https://missing-semester-cn.github.io/) + [廖雪峰 Git](https://liaoxuefeng.com/books/git/introduction/index.html)；Shell 脚本写不出来时看 [老男孩 Shell](https://www.bilibili.com/video/BV1Xh4y1h7kL) 对应集；Vim 用不起来时看 [Vim 保姆级教程](https://www.bilibili.com/video/BV1cCRgBKEMM/)。
4. **运维中间件（2 周）**：读 [Docker 官方文档](https://docs.docker.com/get-started/) + [NGINX 官方指南](https://docs.nginx.com/nginx/admin-guide/)；Dockerfile 写不对时看 [尚硅谷 Docker](https://www.bilibili.com/video/BV1FJ411r7kB)；Nginx 配置卡住时看 [Nginx 性能优化](https://www.bilibili.com/video/BV1UY7C6nErp/)。
5. **闯关 + 实战**：[Bandit](https://overthewire.org/wargames/bandit/) 闯关 + 开学生云主机部署项目。
6. **长期速查**：同方案一。

### 方案三：实战驱动型（边做 Bandit / Killercoda 边查文档）

适合讨厌按部就班、喜欢在解决问题中学习的同学。本质上还是文档驱动——只是文档是按需翻，不是按章读。

1. **环境搭建（半天）**：`wsl --install` 装好 Ubuntu 24.04，跑通基本命令。
2. **命令行闯关（2~3 周）**：直接开 [OverTheWire Bandit](https://overthewire.org/wargames/bandit/)，遇到不会的命令就查 [linux-command](https://jaywcjlove.github.io/linux-command)、[Ubuntu Manpages](https://manpages.ubuntu.com/) 或 [Arch Wiki](https://wiki.archlinux.org/)。34 关打完，命令行基本功就有了。
3. **沙箱实验（2 周）**：在 [Killercoda](https://killercoda.com/) 上做 Linux / Docker 场景实验；[LabEx](https://labex.io/zh) 做中文项目制实验。
4. **按需查文档补概念**：
   - 服务管理 → [systemd 官方文档](https://www.freedesktop.org/wiki/Software/systemd/) + [阮一峰 Systemd 入门](https://www.ruanyifeng.com/blog/2016/03/systemd-tutorial-commands.html)
   - 文件同步 → [阮一峰 rsync 教程](https://www.ruanyifeng.com/blog/2020/08/rsync.html)
   - SSH 登录 → [阮一峰 SSH 原理](https://www.ruanyifeng.com/blog/2011/12/ssh_remote_login.html)
   - Git → [廖雪峰 Git 教程](https://liaoxuefeng.com/books/git/introduction/index.html)
5. **真实云主机实战**：领 [阿里云学生券](https://www.aliyun.com/activity/ecs/student-benefits) 或 [腾讯云学生计划](https://cloud.tencent.com/act/campus) 开一台 ECS，自己装 Nginx + 部署一个简单网站。
6. **长期速查**：[tldr](https://github.com/tldr-pages/tldr)（命令行 `tldr 命令名` 直接出示例）、[the-art-of-command-line](https://github.com/jlevy/the-art-of-command-line)、[Arch Wiki](https://wiki.archlinux.org/)。
