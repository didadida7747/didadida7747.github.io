# 四大慢病管理:高血压、糖尿病、血脂异常、高尿酸/痛风

> 一句话定位:写给年轻人和自己家人——慢病已不是"老年病",这篇讲清四大慢病的诊断标准、日常管理循环、低血糖急救与痛风忌口,帮你当好自己和父母的健康管理员。

> ⚠️ 免责声明:本文为科普整理,不构成医疗建议;具体诊疗与用药请遵医嘱/咨询药师;出现急重症立即拨打 120。

---

## 🎯 核心速览(TL;DR)

1. **慢病正在年轻化**:外卖高油盐、含糖饮料、熬夜、久坐,让 20 岁出头的脂肪肝、高尿酸、血压偏高越来越常见——现在的生活方式,决定十年后的指标。
2. **高血压诊断标准(中国高血压防治指南 2024 年修订版)**:未服降压药时,**诊室血压非同日 3 次 ≥140/90 mmHg**;**家庭自测 ≥135/85 mmHg**(家庭标准首次纳入诊断依据);24 小时动态血压平均 ≥130/80 mmHg。
3. 血压正确自测:坐位安静休息 5 分钟、袖带与心脏同高、测前 30 分钟不喝咖啡/不运动/不吸烟,早晚各测、记录数据。
4. 确诊高血压后**药物依从性是生命线**:不自行停药、换药、加减量;"没症状≠没伤害"。
5. **低血糖比高血糖更急**:糖尿病患者血糖 ≤3.9 mmol/L 即为低血糖,意识清醒时用 **"15-15 规则"**——立即补 15g 快糖(葡萄糖片/含糖饮料),**15 分钟后复测**,不达标再来一轮;意识不清**禁止喂食**,立即送医。
6. 血脂管理的核心指标是 **LDL-C(低密度脂蛋白胆固醇,"坏胆固醇")**;他汀类需长期规律服用,**不能自行停药**。
7. **高尿酸/痛风**:急性发作时大脚趾根部红肿热痛剧痛;忌口(内脏、浓肉汤、啤酒白酒、含糖饮料)+每天足量饮水是基础,但**忌口只能降一部分尿酸,持续超标需药物**(遵医嘱)。
8. 四大慢病共同处方:**规律监测+记录、戒烟限酒、每周 150 分钟中等强度运动、控制体重、按时服药复查**。
9. 给父母健康管理:帮忙记录血压血糖数据、陪诊整理用药清单、提醒年度体检(眼底/尿微量白蛋白/足部/血脂)。
10. 红旗:血压 **≥180/120 mmHg 伴头痛胸痛视物模糊**、低血糖意识不清、痛风伴发热、糖尿病足破溃感染——立即就医。

## 一、为什么年轻人也要关心慢病

- **趋势**:痛风发病年轻化是明确的;2 型糖尿病、脂肪肝、高血压在青年中检出率持续上升。
- **逻辑**:高血压、糖尿病、血脂异常、高尿酸都是"沉默"的——**十年不加管理的血管,用中风、心梗、肾衰、失明来结算**;而青年期干预收益最大。
- **你的角色**:① 用本篇知识自查自管(体测血压、体检报告解读);② 当父母的"健康管理员"(下文每节都有"帮家人做"清单)。

## 二、高血压

### 2.1 诊断标准(中国高血压防治指南 2024 年修订版)

在**未使用降压药**情况下:

| 测量方式 | 诊断标准 |
|---|---|
| 诊室血压 | **非同日 3 次**测量,收缩压(SBP)≥140 mmHg 和/或舒张压(DBP)≥90 mmHg |
| **家庭自测血压** | **≥135/85 mmHg**(2024 版首次纳入诊断依据) |
| 24 小时动态血压 | 平均 ≥130/80 mmHg |

- 一般高血压患者控制目标:诊室血压 <140/90,可耐受者进一步 <130/80;家庭自测控制目标相应为 **<135/85**(具体以医生评估为准)。
- **一次测量偏高 ≠ 高血压**:紧张、熬夜、咖啡、憋尿都会推高读数,非同日多次测量确认才算数。

### 2.2 正确自测方法(七步)

1. 测前 30 分钟:不喝咖啡浓茶、不吸烟、不剧烈运动、排空膀胱;
2. 安静坐着休息 **5 分钟**;
3. 坐位,背有靠、双脚平放,臂带绑在上臂(与心脏同一水平),下缘距肘窝 2~3cm;
4. 首次建议**两侧都测**,以较高一侧为准(以后固定测这侧);
5. 测量时不说话、不活动;
6. 每次测 2~3 遍取平均,间隔 1 分钟;
7. **早晚各一次**(早:起床后 1 小时内、服药前;晚:睡前),记录到表格。

### 2.3 生活方式处方(确诊前预防和确诊后基础治疗通用)

| 措施 | 具体目标 |
|---|---|
| 减盐 | 每日食盐 **<5g**(一啤酒瓶盖);警惕外卖、咸菜、火腿肠等隐形盐 |
| 控制体重 | BMI <24,腰围男 <90cm、女 <85cm |
| 运动 | 每周 5~7 天、每天 30 分钟中等强度(快走、慢跑、骑行) |
| 戒烟限酒 | 戒烟是硬要求;最好不饮酒 |
| 规律作息 | 熬夜推高血压和心率;保证 7 小时睡眠 |
| 心理减压 | 长期紧张焦虑升血压,规律运动与睡眠是最好的解药 |
| 饮食模式 | 多蔬果、全谷物、低脂奶(参考得舒 DASH 饮食思路) |

### 2.4 确诊后:药物依从性是生命线

- **不自行停药、不自行换药、不自行加减量**——血压正常正是药物在起效,停药后反弹更危险;
- 便宜的降压药不等于差,适合自己、血压达标、能坚持吃的就是好药;
- 每次复诊带上**血压记录本**;出现干咳、脚踝水肿、头晕等不适,复诊调整而不是直接停药;
- 季节变化血压波动大时,加强监测并咨询医生。

### 2.5 日常管理循环(一图流)

```
        ┌──────────────────────────────┐
        │      高血压日常管理循环          │
        └──────────────────────────────┘
   ①测(早晚自测记录)
        ↓
   ②记(血压本/App:日期+数值+心率)
        ↓
   ③行(减盐、运动、减重、睡眠)
        ↓
   ④服(每天固定时间服药,不漏不断)
        ↓
   ⑤查(定期复诊;每年查血脂血糖、肾功能、心电图)
        ↓
   异常?(家庭血压持续≥135/85 或出现不适)→ 提前复诊
   极端值(≥180/120 伴症状)→ 急诊(见红线)
```

## 三、2 型糖尿病

### 3.1 认识与诊断概念

- 典型症状"**三多一少**":多饮、多尿、多食、体重减少;但 2 型糖尿病早期**常无症状**,多靠体检发现。
- 诊断概念(具体数值判读由医生完成):空腹血糖 ≥7.0 mmol/L、口服葡萄糖耐量 2 小时 ≥11.1 mmol/L、随机血糖 ≥11.1 mmol/L 伴典型症状、或 HbA1c ≥6.5%——**异常结果需复查确认**。
- 高危人群(该定期查血糖):超重/肥胖、直系亲属糖尿病、多囊卵巢、妊娠糖尿病史、长期久坐+含糖饮料。

### 3.2 日常管理与监测记录

| 项目 | 内容 |
|---|---|
| 饮食 | 定时定量、主食粗细搭配、少含糖饮料奶茶(这是青年糖尿病的"快进键")、先菜后饭 |
| 运动 | 每周 ≥150 分钟中等运动+抗阻 2 次;餐后走 30 分钟有利控糖 |
| 监测 | 遵医嘱测空腹/餐后血糖并**记录**(时间点+数值);每 3 个月查 HbA1c |
| 并发症年检 | **眼底**(视网膜病变)、**尿微量白蛋白**(肾)、**足部检查**(神经与血管)、血脂血压 |
| 皮肤足部 | 每天看脚(破口、水疱、颜色);鞋袜合脚;足部破损不愈→就医 |

### 3.3 低血糖:识别与"15-15 规则"(重点,要背下来)

**识别**:心慌、手抖、出冷汗、头晕、饥饿感、注意力涣散、行为异常;**糖尿病患者血糖 ≤3.9 mmol/L 即按低血糖处理**(非糖尿病者 <2.8 mmol/L 才属低血糖)。

**处置(完整操作步骤、糖的种类与禁忌、意识不清的禁令)统一见 [03-急救与应急/02-常见意外处理 · 六](/11-健康与用药知识库/03-急救与应急/02-常见意外处理)**(2026-10-05 去重,以急救篇为唯一可执行版):清醒→15g 快糖、15 分钟后复测、不达标再来一轮;**意识不清绝对禁止喂食**,立即 120。

### 3.4 日常管理循环(一图流)

```
        ┌──────────────────────────────┐
        │      糖尿病日常管理循环          │
        └──────────────────────────────┘
   ①测(血糖/体重,遵医嘱频次)
        ↓
   ②记(时间点+数值+特殊情况如低血糖)
        ↓
   ③吃(定时定量、戒含糖饮料)
        ↓
   ④动(每周150分钟+餐后走)
        ↓
   ⑤药(遵医嘱,胰岛素注意冷藏与注射技术)
        ↓
   ⑥查(每3个月HbA1c;每年眼底+尿微量白蛋白+足部)
        ↓
   低血糖?→ 15-15 规则;足部破溃/视力骤降 → 及时就医
```

## 四、血脂异常

### 4.1 核心认知

- **LDL-C(低密度脂蛋白胆固醇)是主指标**——"坏胆固醇"沉积血管壁形成斑块,是动脉粥样硬化的核心推手;HDL-C("好胆固醇")与甘油三酯是配套指标。
- 目标值因人而异(取决于风险分层:有无糖尿病、吸烟、既往心血管病等),**由医生按指南划定**,不是"参考范围在正常区间就万事大吉"。
- 年轻人体检发现血脂偏高:先查生活方式(奶茶、外卖、久坐、肥胖),多数轻中度异常可通过减重+运动+饮食改善;**是否用药由医生评估**。

### 4.2 生活方式处方

| 措施 | 要点 |
|---|---|
| 饮食 | 少油炸食品、肥肉、动物内脏;黄油椰子油也限量;多用蒸煮炖;增加燕麦、豆类、深海鱼、坚果(适量) |
| 运动 | 有氧为主,每周 150 分钟以上;提高 HDL-C 最有效的是规律有氧 |
| 戒烟 | 吸烟拉低 HDL-C、损伤血管内皮 |
| 减重 | 超重者减重 5%~10% 可明显改善血脂 |

### 4.3 他汀:不能自行停

- 他汀类是降 LDL-C、稳定斑块的主力药;**需长期规律服用,自行停药后 LDL-C 反弹、斑块失去保护**;
- 用药期间遵医嘱复查血脂、肝功、肌酶;出现不明原因的**肌肉酸痛、乏力、酱油色尿**要及时告知医生;
- 他汀与西柚汁相互作用,服药期间避免大量饮用;不与大量酒精并行。

### 4.4 日常管理循环(一图流)

```
        ┌──────────────────────────────┐
        │      血脂日常管理循环            │
        └──────────────────────────────┘
   ①查(体检血脂四项,记录 LDL-C)
        ↓
   ②知(明确自己的目标值,问医生)
        ↓
   ③吃(少油少反式脂肪,多纤维鱼类)
        ↓
   ④动(每周150分钟有氧)
        ↓
   ⑤药(他汀遵医嘱规律吃,不自行停)
        ↓
   ⑥随(按医嘱复查血脂/肝功/肌酶)
```

## 五、高尿酸血症与痛风

### 5.1 认识

- 血尿酸持续超标(一般男性 >420 μmol/L、女性 >360 μmol/L 为界,具体判读遵医嘱)即为高尿酸血症;**多数人无症状**,但尿酸盐结晶悄悄沉积关节和肾脏。
- **痛风急性发作**:常在夜间/凌晨突发,**第一跖趾关节(大脚趾根部)**或踝、膝、足背**红、肿、热、剧痛**,痛到"被风吹过都疼";多在暴食海鲜/喝啤酒/剧烈运动/受凉后诱发。
- 年轻化趋势明显:含糖饮料+啤酒+外卖+肥胖,是年轻痛风的标配剧本。

### 5.2 急性发作怎么办

1. **制动+抬高患肢**,冷敷(不要热敷、不要揉搓按摩);
2. **大量饮水**(无禁忌时每天 2000ml 以上,促进尿酸排泄);
3. 尽早就医,医生常用**秋水仙碱、NSAIDs(如依托考昔、双氯芬酸)或糖皮质激素**控制炎症(均为处方药,**遵医嘱按疗程用,勿自行加量**);
4. **发作期不要开始或自行停掉降尿酸药**——降尿酸方案的调整交给医生(突然升降血尿酸都可能诱发或延长发作);
5. 记录诱因(吃了什么、喝了什么),写进自己的"痛风日记"。

### 5.3 间歇期管理:忌口清单 + 分级观念

依据国家卫健委《成人高尿酸血症与痛风食养指南(2024 年版)》等整理:

| 类别 | 具体 | 建议 |
|---|---|---|
| ❌ 严格限制 | 动物内脏(肝、肾、脑)、浓肉汤/火锅汤、部分海鲜(沙丁鱼、凤尾鱼、贝类等) | 尽量不吃 |
| ❌ 严格限制 | **啤酒、白酒** | 不喝(啤酒尤甚) |
| ❌ 严格限制 | **含糖饮料、果汁**(高果糖促进尿酸生成) | 基本戒断——这是年轻人最该砍的一项 |
| ⚠️ 限量 | 普通肉类、部分鱼类(总量控制) | 每天肉类不超过一掌心;煮肉弃汤吃肉 |
| ⚠️ 注意 | 生冷(冰淇淋、生冷海鲜) | 少吃 |
| ✅ 推荐 | **低脂牛奶、酸奶、鸡蛋** | 乳蛋白促进尿酸排泄,每天一杯低脂奶 |
| ✅ 推荐 | 蔬菜(绝大部分嘌呤不高)、充足主食 | 放心吃 |
| ✅ 大量 | **白水、淡茶** | 每天 2000ml 以上 |
| ✅ 关键 | **减重+规律运动**(避免剧烈运动后脱水诱发) | 减重本身降尿酸 |

**核心观念**:食物约占尿酸来源的 20%~30%,其余多为体内生成——**"忌口只能降一部分尿酸";血尿酸持续超标、痛风反复发作的患者,需要医生评估长期降尿酸药物**(如别嘌醇、非布司他、苯溴马隆等,处方药,各有适应证与监测要求)。忌口是基础,不是全部。

### 5.4 日常管理循环(一图流)

```
        ┌──────────────────────────────┐
        │    高尿酸/痛风日常管理循环        │
        └──────────────────────────────┘
   ①测(定期查血尿酸;记录发作日记)
        ↓
   ②戒(内脏/浓汤/酒/含糖饮料)
        ↓
   ③饮(每天 2000ml 以上水)
        ↓
   ④减(减重+规律中等强度运动)
        ↓
   ⑤药(发作期消炎镇痛遵医嘱;
       持续超标者评估长期降尿酸药)
        ↓
   ⑥随(复查血尿酸至目标值并维持)
        ↓
   急性发作 → 制动+冷敷+饮水+尽早就医
```

## ⚠️ 常见误区

- **误区:年轻人不会得高血压/糖尿病/痛风。→ 真相:**三大慢病都在明显年轻化;体检单上的临界值就是身体在敲警钟。
- **误区:血压降到正常就可以停药。→ 真相:**血压正常是药物起效的表现;自行停药导致血压反弹波动,中风心梗风险反而升高。调药只能由医生决定。
- **误区:没症状就等于没伤害。→ 真相:**高血压、糖尿病、高血脂、高尿酸都被称为"沉默杀手",伤害在症状出现前已累积多年。
- **误区:低血糖了吃巧克力救急最快。→ 真相:**巧克力脂肪多、升糖慢,应选葡萄糖片、普通含糖饮料;等 15 分钟复测,不是猛吃到撑。
- **误区:保健品能"降三高",可以代替药物。→ 真相:**没有任何保健品被证实可替代降压、降糖、降脂、降尿酸药物;"纯天然无副作用"是营销话术。
- **误区:他汀伤肝伤肌肉,能不吃就不吃。→ 真相:**总体安全性良好、获益明确;按医嘱复查即可监控罕见副作用;自行停药的代价是心梗中风风险回升。
- **误区:痛风只是"吃出来的",忌口就能治好。→ 真相:**饮食只占尿酸来源的一部分;持续超标、反复发作者需要长期降尿酸药物管理。
- **误区:痛风缓解期啥都能吃了。→ 真相:**间歇期正是管理窗口——忌口、饮水、减重坚持得越好,发作越少、药物需求越低。

## 🚨 什么时候必须就医(红线)

**高血压急症信号(任一→立即 120/急诊)**:

1. 血压**≥180/120 mmHg 并伴**剧烈头痛、胸痛胸闷、视物模糊、恶心呕吐、肢体麻木无力、口齿不清;
2. 血压极高且持续不降,即使暂无症状也应尽快就医;
3. 突发剧烈背痛伴血压异常(警惕主动脉问题)。

**糖尿病红线**:

4. 低血糖**意识不清、抽搐、无法吞咽**——禁止喂食,立即 120;
5. 血糖极高伴恶心呕吐、腹痛、呼吸深快有烂苹果味、意识改变(警惕酮症酸中毒);
6. **足部破溃、发黑、红肿流脓**(糖尿病足,拖不得);
7. 视力骤降、眼前大片黑影。

**痛风/尿酸红线**:

8. 急性发作**伴高热寒战**(警惕关节感染,需与痛风鉴别);
9. 多关节同时发作、剧痛无法行动;
10. 长期高尿酸伴腰痛、少尿、血尿(警惕尿酸性肾损害)。

**血脂**:一般无急症,但**胸痛胸闷压榨感、活动后胸痛**(提示心绞痛)→ 立即 120。
