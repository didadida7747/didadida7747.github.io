## 知识整理

### 爬虫是什么

爬虫是自动化程序，模拟人类浏览网页的行为：发 HTTP 请求 → 解析提取数据 → 批量存储。应用很广：搜索引擎、数据分析、市场调研、内容聚合，乃至樱花动漫这类免费影视站。Python 对爬虫的支持比 C++/Java/JS 都全面，是事实上的首选——讲师大一小学期的 Python 大作业就是爬虫加 Django（转写"jungle"）建网页。

### 合规底线：robots.txt 与"君子协定"

任何网址后加 /robots.txt 可查看站点的爬虫政策。以 B 站为例，文件分三部分：全体爬虫禁入的路径、允许的搜索引擎/官方爬虫、其余一律不允许。要注意技术上无法彻底阻止爬虫，robots.txt 更像君子协定；但越线有真实代价——抓视频商用或侵权可能被封 IP，樱花动漫经营者甚至被抓（讲师引的新闻，细节存疑）。落到使用的建议：动手前先看 robots.txt，无法确定是否侵权就别做；哪怕允许爬也要控制频率。

### 七步工作流与四大组件

一个规范爬虫的完整流程：①构造请求（设置 User-Agent/Cookie，选 GET/POST）→ ②接收响应（看状态码 200/404/500）→ ③解析（HTML 交给 DOM 解析器得到树状结构，JSON/XML 类似键值对字典）→ ④提取（CSS 选择器/XPath 定位节点，正则匹配文本）→ ⑤清洗 → ⑥存储（CSV/JSON/TXT 或数据库）→ ⑦从页面发现新链接，去重后放入待爬队列循环。支撑流程的是四大组件：HTTP 客户端（requests，session 维持登录态、代理池、重试机制）、HTML 解析器（BeautifulSoup/lxml）、数据提取器（结构化表格与 JSON、非结构化文章评论、时间戳作者等元数据）、存储引擎（文件 → 缓存二进制 → 数据库，规模越大越结构化）。

### 网易云实战：三级爬法

基础版（base.py）用 requests 直接请求排行榜页面，能拿到 100 首歌名与相对路径网址，与 music.163.com 拼接即得详情页。对照实验 base_cookie.py 只差带不带 Cookie：带上后返回里多了用户 id/名称/头像——有的网站凭 Cookie 即视为已登录、给出更多内容，但网易云此处差异不大。基础版的天花板引出全讲最核心的概念——**动态加载**：未登录看不到评论还在其次，关键是评论根本不在初始 HTML 里；F12 的 Elements 里能看到，是因为浏览器执行 JS 后才插入。这也正是 02 讲 JS 交互的另一面：把 HTML 扒下来，JS 还没跑，内容自然没有。

进阶版（pro_music.py）换思路：不爬肉眼所见的页面，改访问网站的 API 接口直接拿 JSON。收益巨大——一个 URL 一次拿到 100 首歌的名字/id/排名/创作者/专辑/时长毫秒/热度/发布时间，而基础版要访问 100 次详情页。接口怎么找：这次的接口是问 AI 得知的，通用方法是 F12 → Network 面板筛选关键词（如 comment）→ 刷新页面 → 点开请求看 Headers 里的 request URL 与请求参数；知道参数、过安全验证（评论 API 有密钥加密）即可拿 response，response 末尾的热门评论与页面内容对得上。Cookie 有两种取法：主请求 Headers 里直接复制，或 Application 面板的 Cookies 分类查看（更整洁）。改 limit 值即控制抓取条数（示例约 100 条、翻到第六页）。

高级版是浏览器自动化：Selenium + WebDriver 控制真实浏览器模拟滚动/点击/拖拽，能执行 JS，专门处理动态加载；适合 SPA 单页应用与重度依赖 Ajax 的网站；headless 模式用于无图形界面的 Linux 服务器。不过网易云登录验证极严（二维码 → 密码 → 滑块 → 短信），讲师自己也没能写出可用的演示代码，鼓励大家尝试。

### 反反爬军备清单

网站会反爬，爬虫就反反爬，常见八般武艺：User-Agent 轮换（多个 UA 随机切换模拟不同设备）；请求头伪造（把 F12 看到的 headers 抄全，让服务器以为是真人）；Cookie/Session 管理（维护登录态、处理 CSRF 令牌与过期更新）；验证码处理（图像识别对文字/点选，行为验证对滑动/拼图）；分布式爬虫（主控节点任务队列分发、负载均衡、故障转移与健康检查）；代理 IP 池（轮换避免单 IP 高频被封）；数据管道优化（哈希/时间戳增量去重、异常数据清洗标准化——讲师把每歌五六十行原始 JSON 精简到十来行）；风控规避（随机休眠 1~2 秒、指数退避、监控 IP 被封与验证码增多）。此节纯概念罗列、无代码演示，实践中用到再回来查即可。

### 方法论与开源警示

两条经验：一是不会写就问会写的同学或问 AI——把需求写清楚，数百行级代码 AI 能成熟完成，讲师习惯让 AI 打框架再自己删改、多轮交流修错；二是推崇开源——结尾案例 NeteaseCloudMusicApi 曾是收集网易云各类 API 的 GitHub 开源项目，后因网易发法律通知（项目虽开源非盈利但被人用于侵权）停止维护并删库，正是合规主题的最好注脚。讲师鼓励爬感兴趣的数据做分析、开源成自己的项目。
