# 疼痛管理与常用药:头痛、牙痛、腰颈痛、痛经

> 一句话定位:止痛不是"忍一忍"也不是"一把药丸"——这篇教你识别常见疼痛的类型、用对止痛药、认出必须就医的危险信号。

> ⚠️ 免责声明:本文为科普整理,不构成医疗建议;具体诊疗与用药请遵医嘱/咨询药师;出现急重症立即拨打 120。

---

## 🎯 核心速览(TL;DR)

1. **止痛药不是洪水猛兽**:布洛芬等 NSAIDs 常用且安全,不会成瘾;该吃就吃,痛到影响学习生活就别硬扛。
2. 但 NSAIDs **不能叠加使用**(两种 NSAIDs 一起吃=毒副作用加倍),也要**避开空腹**,胃不好者随餐服。
3. 头痛两大类:**紧张型**(双侧紧箍感、压力大熬夜引起)vs **偏头痛**(单侧搏动性跳痛、怕光怕吵、可伴恶心)。处理策略不同。
4. 偏头痛发作**越早用药越好**;每月止痛药别超过 15 天,否则可能诱发"药物过度使用性头痛"越吃越痛。
5. **牙痛没有"自愈",只有"拖大"**:应急止痛后必须尽快看牙医;拖延的代价是根管、拔牙、更贵更痛。
6. 久坐腰颈痛的核心处方:**每 45~60 分钟起身活动+调整坐姿+规律锻炼**;贴膏药热敷只能缓解。
7. **原发性痛经吃 NSAIDs 有效,关键是提前/初起就吃**(抑制前列腺素生成,疼起来再吃效果差);痛经进行性加重要查子宫内膜异位症。
8. 外用止痛药(膏药、凝胶、喷剂)是轻中度肌肉关节痛的好选择,全身吸收少;但**皮肤破损处不用**,对成分过敏停用。
9. 头痛红旗:**"一生中最剧烈"的突发头痛、伴发热颈强直、伴肢体无力/口齿不清/视物异常**——立即 120。
10. 所有具体剂量一律以说明书/医嘱为准。

## 一、头痛:先分型,再处理

### 1.1 紧张型头痛 vs 偏头痛(对照表)

| 对比项 | 紧张型头痛 | 偏头痛 |
|---|---|---|
| 疼痛部位 | **双侧**,后脑/额头/太阳穴 | 多**单侧**,太阳穴/眼眶旁 |
| 疼痛性质 | 紧箍感、压迫感、"戴紧箍咒" | **搏动性跳痛**,一跳一跳和脉搏同步 |
| 程度 | 轻到中度 | 中到重度,发作时想躺平 |
| 伴随症状 | 一般没有 | **怕光、怕吵、恶心**;部分人发作前有"先兆"(眼前闪光、暗点、锯齿线) |
| 诱因 | 熬夜、压力、久盯屏幕、颈肩僵硬 | 睡眠不足/过多、漏餐、月经、红酒奶酪、强光、天气变化 |
| 持续时间 | 30 分钟到数天 | 4~72 小时 |
| 好发人群 | 人人可发 | 女性多见,常有家族史 |
| 处理重点 | 放松、休息、改善姿势 | **早用药**+躲进暗静房间休息+记录诱因 |

### 1.2 发作时怎么办

1. **越早用药越好**:疼痛刚起时服药比忍到"痛疯了"再服效果好得多。
2. 轻中度:常见示例为布洛芬、对乙酰氨基酚(剂量以说明书为准)。
3. 中重度偏头痛:非处方药无效时,医生可能开**曲普坦类**(如佐米曲普坦、利扎曲普坦等)——这是针对偏头痛的特异性处方药;先兆期用未证实有效,**头痛发作时用**。
4. 环境调整:拉窗帘、安静躺 30~60 分钟;冷敷太阳穴/前额对偏头痛有帮助,热敷颈肩对紧张型更舒服。
5. 补水补觉:脱水、缺觉、漏餐都是常见诱因。

### 1.3 头痛日记(偏头痛患者的利器)

连续记录 4~8 周:**发作日期、持续时长、疼痛程度(1~10 分)、伴随症状、当天吃了什么/睡了几小时/发生了什么**。就医时带上,能显著帮助医生判断类型、找出诱因;手机备忘录即可。

### 1.4 防止"越吃越痛"

- 非特异性止痛药(NSAIDs 类)**每月使用不超过 15 天**;曲普坦类**不超过 10 天**(多数指南建议)。
- 超过这个频率还不停地吃,可能发展成**药物过度使用性头痛(MOH)**——止痛药本身成了头痛的原因。
- 每月发作 ≥4 次、严重影响生活的偏头痛,应就医评估**预防性治疗**(需要规律处方用药,不是止痛药)。

## 二、牙痛:应急可以,看牙必须

### 2.1 为什么牙痛要尽快看牙

牙痛多为龋齿进展到牙髓、根尖周炎、智齿冠周炎、牙周脓肿等——**结构性问题不会自己好**。拖下去的路线通常是:补牙(几百元)→ 根管治疗(几千元)→ 拔牙+种植(上万)。**越早处理,越省钱少受罪。**

### 2.2 应急缓解(给自己争取到看牙前的时间)

| 措施 | 做法 |
|---|---|
| 止痛药 | 布洛芬等 NSAIDs 对牙痛效果较好(以说明书为准);**不要把阿司匹林直接贴在牙/牙龈上**(会灼伤组织) |
| 温盐水漱口 | 一杯温水+半勺盐,每天数次;有助于减轻牙龈炎症 |
| 冷敷脸颊 | 脸颊外侧冷敷 15~20 分钟,缓解肿胀疼痛(别热敷,可能加重化脓) |
| 保持清洁 | 认真刷牙+牙线清理该区域,食物残渣嵌塞本身就能引起剧痛 |
| 睡觉垫高头 | 减少头部充血,缓解夜间跳痛 |

### 2.3 牙科红旗(不等常规预约,直接挂急诊)

- 面部明显肿胀、张口困难、吞咽困难(感染可能向间隙扩散,**有窒息风险**);
- 发热伴牙痛(感染扩散);
- 外伤致牙齿折断、脱落(整颗牙脱落:捏住牙冠、别碰牙根,可含在牛奶或口中保存,**30 分钟~1 小时内**就医仍有再植机会)。

## 三、肌肉酸痛与久坐腰颈痛(大学生场景)

### 3.1 常见来源

- **伏案/考研姿势**:低头含胸+脖子前伸,颈肩肌肉持续紧张;
- **游戏/手机**:低头族颈椎压力成倍增加;
- **运动过量**:第二天"延迟性肌肉酸痛"(DOMS),正常现象;
- **床/枕头不对**:床垫过软、枕头过高过低,晨起腰颈僵。

### 3.2 应对方案

| 层次 | 具体措施 |
|---|---|
| **立即缓解** | 热敷颈肩腰 15~20 分钟;洗热水澡;外用止痛药(见下文) |
| **姿势调整** | 屏幕上沿与视线平齐;腰后垫靠枕;双脚踩实地面;笔记本电脑架高+外接键盘 |
| **活动处方** | **每 45~60 分钟起身活动 2~5 分钟**(番茄钟设提醒);课间去走廊走一走 |
| **锻炼预防** | 每周 2~3 次核心训练(平板支撑、臀桥)+颈肩拉伸(收下巴、扩胸);规律运动是唯一"根治"途径 |
| **运动后酸痛** | 48~72 小时内自行缓解;轻度活动(散步、拉伸)比完全躺平恢复更快 |

### 3.3 何时就医

- 疼痛**放射到手臂/腿部并伴麻木、无力**(警惕椎间盘问题);
- 夜间痛醒、与姿势无关的持续痛;
- 外伤后腰痛、大小便功能异常(急症,立即就医);
- 自我处理 2 周无改善。

## 四、痛经:正确用药能救每个经期

### 4.1 分清原发与继发

| | 原发性痛经 | 继发性痛经 |
|---|---|---|
| 机制 | 前列腺素分泌过多→子宫痉挛性收缩 | 器质性疾病(子宫内膜异位症、子宫腺肌症、盆腔炎等) |
| 特点 | 初潮后 1~2 年即开始,经期第 1~2 天痛,程度相对稳定 | **逐渐加重**、经期外也痛、可能伴性交痛/不孕 |
| 处理 | NSAIDs+热敷+运动,多可良好控制 | **必须就医查病因**,止痛药只是临时对症 |

### 4.2 原发性痛经:NSAIDs 的正确用法

- **原理**:NSAIDs 抑制前列腺素的**生成**;对已经生成的前列腺素无能为力——所以**疼起来再吃效果差**。
- **正确时机**:月经来潮前 1~2 天,**或疼痛刚出现的第一时间**服用,之后按说明书间隔规律服 1~2 天。
- 常见示例:布洛芬、萘普生(剂量以说明书为准);胃肠敏感者随餐服。
- 辅助:下腹部热敷(与药物叠加有效)、规律运动、保证睡眠;姜茶等有一定证据但较弱。
- 复方口服避孕药对原发性痛经也有效——属处方药,由妇科医生评估。

### 4.3 就医指征

- 痛经**逐年加重**、止痛药原来管用后来不管用;
- **经期外也痛**、性交痛、经量明显增多;
- 止痛药足量使用仍无法正常上课生活;
- 上述任一情况都要查**子宫内膜异位症**等继发原因——早诊断早处理,别信"生个孩子就好了"。

## 五、NSAIDs(非甾体抗炎药):一类药的共同纪律

NSAIDs 家族:布洛芬、阿司匹林、萘普生、双氯芬酸、依托考昔等——很多感冒药、痛经药、膏药里都是它们。

**共同注意事项**:

1. **不叠加**:两种 NSAIDs 不同时吃(包括不同名同类,如布洛芬+阿司匹林);止痛效果不加倍,胃肠出血/肾损伤风险加倍。
2. **不与对乙酰氨基酚冲突**(后者不属于 NSAIDs,胃肾负担小,同一天错开使用是医生认可的做法,但都别超说明书上限)。
3. **避开空腹**:随餐或饭后服;有胃溃疡/幽门螺杆菌感染者慎用,必要时配合抑酸药(遵医嘱)。
4. **护肾**:腹泻脱水、剧烈运动大量出汗后慎用;**不与大量咖啡/能量饮料同服**。
5. **看成分**:复方感冒药常含 NSAIDs 或对乙酰氨基酚,别重复吃。
6. 哮喘患者部分人对阿司匹林敏感,用药前确认;备孕/孕晚期女性禁用 NSAIDs(需遵医嘱)。

### 外用止痛药常识

- 常见示例:双氯芬酸凝胶(如各种"扶他林"类)、洛索洛芬贴剂、辣椒碱贴膏、中药膏药。
- 优点:局部浓度高、全身吸收少,胃肠负担小——**轻中度肌肉关节痛优先外用**。
- 注意:皮肤破损处不用;对成分过敏(贴后红痒起疹)即停;同一部位别叠加多种外用药+内服药中的 NSAIDs 也要算总量;孕妇等特殊人群先咨询。

## ⚠️ 常见误区

- **误区:止痛药"吃了会上瘾",忍着更好。→ 真相:**布洛芬、对乙酰氨基酚等常规止痛药**不会成瘾**;成瘾风险属于阿片类(处方管控药)。长期硬扛痛反而影响睡眠情绪、加重病情。
- **误区:两种止痛药一起吃更管用。→ 真相:**两种 NSAIDs 叠加只增加毒性;确实需要联合的方案(如 NSAIDs+对乙酰氨基酚)也应遵医嘱按固定间隔,不自行加码。
- **误区:偏头痛忍忍就过去了,不用记什么日记。→ 真相:**不识别诱因、不早用药,发作会越来越难控制;头痛日记是医生最想看到的东西。
- **误区:牙痛吃几天消炎药就行。→ 真相:**抗生素对多数牙源性疼痛治标不治本,感染源(龋坏牙髓/脓肿)不处理会反复发作并扩散。
- **误区:痛经忍忍就好,吃药伤身。→ 真相:**按规范使用 NSAIDs 安全有效;"忍"可能掩盖继发性痛经(如子宫内膜异位症)的进展。
- **误区:腰痛就躺平不动。→ 真相:**急性期短期休息可以,长期卧床恢复更慢;在能耐受范围内保持活动+核心锻炼才是康复方向。
- **误区:头痛=脑子里长了东西。→ 真相:**绝大多数头痛是紧张型/偏头痛等良性头痛;真正危险的头痛有明确红旗特征(见下文),符合才需紧急排查。

## ✅ 行动清单

- [ ] 宿舍药箱:布洛芬(或对乙酰氨基酚)+ 一种外用 NSAIDs 凝胶/贴剂,均在有效期内
- [ ] 吃任何药前先看成分表,确认没有与其他药叠加 NSAIDs
- [ ] 养成"疼痛刚起就用药"的习惯,而不是"痛到崩溃才吃"
- [ ] 手机/笔记本开一个头痛(或痛经)日记,记录发作与诱因
- [ ] 电脑屏幕架高、脚下垫凳、番茄钟设 50 分钟起身提醒
- [ ] 每周 2~3 次核心+颈肩锻炼,把它当课程排进课表
- [ ] 痛经逐年加重的女生:预约妇科,主动提"子宫内膜异位症筛查"
- [ ] 牙痛超过 2 天不缓解 → 挂口腔科,别等它"自己好"

## 🚨 什么时候必须就医(红线)

**头痛红旗(符合任一立即就医/120)**:

1. **突发"一生中最剧烈"的头痛**(炸裂样,几秒到几分钟达到顶峰——警惕蛛网膜下腔出血);
2. 头痛**伴发热+颈项强直**(低头下巴够不到胸口)、皮疹、畏光(警惕脑膜炎);
3. 头痛**伴肢体无力/麻木、口齿不清、口角歪斜、视物成双、意识模糊**(警惕脑血管事件);
4. 头部外伤后新发头痛、呕吐;
5. 50 岁后新发型头痛、进行性加重的每日头痛;
6. 从睡梦中痛醒的剧烈头痛。

**其他疼痛红线**:

7. **胸痛/胸闷**(压榨感、放射到左臂下颌——按心脏病处理,立即 120);
8. 牙痛伴**面部肿胀、张口困难、吞咽困难、发热**;
9. 腰痛伴**下肢麻木无力、大小便失禁或潴留**;
10. 剧烈腹痛(参考《02-肠胃问题》红线);
11. 疼痛使用足量常规止痛药完全无效,或持续超过预期病程。
