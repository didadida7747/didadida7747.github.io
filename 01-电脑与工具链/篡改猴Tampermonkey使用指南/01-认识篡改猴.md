# 01 · 认识篡改猴：原理、边界与管理器选型

## 一、它到底是什么

篡改猴（Tampermonkey）是一个**用户脚本管理器（Userscript Manager）**浏览器扩展。

- **用户脚本（Userscript）**：一个 `.user.js` 文件，本质是一段 JavaScript，头部用注释声明元数据（名字、版本、在哪些网站运行、需要什么权限）。
- 当你访问的网址命中脚本的 `@match` / `@include` 规则时，篡改猴会在页面加载阶段把脚本注入网页执行。脚本运行在页面的上下文里，因此能用 DOM API 改写页面，也能通过管理器提供的 `GM_*` API 实现跨域请求、本地存储、文件下载等普通网页脚本做不到的事。

一个最小的用户脚本长这样：

```javascript
// ==UserScript==
// @name         我的第一个脚本
// @namespace    https://example.com
// @version      1.0
// @description  打开百度时在控制台打印一句话
// @match        https://www.baidu.com/*
// @grant        none
// ==/UserScript==

(function () {
  'use strict';
  console.log('脚本已运行：' + location.href);
})();
```

## 二、工作原理（简版）

```
浏览器加载网页
   │
   ├─ 篡改猴读取所有已启用脚本的 @match 规则
   │
   ├─ 命中当前网址？→ 按 @run-at 时机注入脚本（默认 DOMContentLoaded 前后）
   │
   └─ 脚本执行：
        ├─ 普通 DOM 操作（改页面、加按钮、去广告）
        └─ 经用户授权后调用 GM_* API（跨域请求、存储、下载等）
```

理解这张图就理解了安全模型的关键：
- 脚本的权限 = 它在命中网页上的页面权限 + 头部声明的特殊权限；
- 一个脚本在 `@match https://mail.qq.com/*` 运行时，理论上能读到该页面里你的邮件内容——所以**谁写的脚本、在哪些网站运行，极其重要**。

## 三、"四只猴子"：管理器选型对比

| 管理器 | 开源情况 | 收费 | 兼容性 | 特点 | 适合谁 |
|---|---|---|---|---|---|
| **Tampermonkey（篡改猴）** | 闭源 | 核心功能免费；作者推出付费订阅（赞助/解锁部分高级功能，如部分云同步能力），不付费也完全够用 | 最好，复杂脚本几乎都以它为测试对象 | 功能最全、内置 CodeMirror 编辑器、ESLint 语法检查、脚本同步、黑名单、中文界面 | 大多数人的首选 |
| **Violentmonkey（暴力猴）** | 完全开源（MIT） | 免费 | 较好，极少数脚本有兼容问题 | 轻量、界面简洁、直接同步 GitHub Gist、Chrome 商店版已适配 Manifest V3 | 在意开源/免费、脚本数量不多的人 |
| **Greasemonkey（油猴本体）** | 开源 | 免费 | 仅 Firefox | 2005 年的鼻祖，更新慢，如今只在 Firefox 上 | Firefox 怀旧用户 |
| **ScriptCat（脚本猫）** | 开源（国产） | 免费 | 兼容大部分油猴脚本 | 中文生态、自带脚本市场、有订阅式后台脚本等特色能力 | 国内用户、想要中文市场一体化体验 |

> 实际建议：**主力用 Tampermonkey**，遇到它弹付费提示而你又不想付费时，记住日常功能本来就免费；追求完全开源透明就装 **Violentmonkey**。脚本互通，同一脚本在各管理器里格式一致。

## 四、能力边界：合理预期

**擅长：**
- 改变网页的外观与交互（CSS/ DOM 改造）；
- 自动化你在网页上的重复操作（填表、批量点击、提取数据）；
- 给网页"嫁接"功能（快捷键、下载按钮、翻译、Markdown 导出）；
- 拦截、替换页面发起的部分请求；
- 本地持久化设置（`GM_setValue`）。

**不擅长 / 做不到：**
- 操作浏览器 UI 之外的东西（文件系统、其他程序）；
- 解密网站服务端逻辑（视频 VIP 解析类脚本走的是第三方解析接口，随时失效，且属侵权）；
- 对抗网站主动的反自动化措施（容易导致账号异常）；
- 替代正经扩展：需要后台常驻、强网络拦截（如广告拦截 uBlock Origin）、代理能力时，专用扩展更可靠。

## 五、Manifest V3 与篡改猴的现状（背景知识）

- Chrome 推出 Manifest V3 扩展规范后，**禁止扩展加载远程托管代码**，理由是安全。这直接影响油猴类扩展"运行任意用户脚本"的核心模式。
- 目前 Tampermonkey、Violentmonkey 均已发布适配 MV3 的商店版本，通过把脚本作为扩展运行时处理的方式继续工作；主流脚本仍可正常使用，但个别依赖远程代码加载的脚本受限。
- 对普通用户的实际影响：**照常使用即可**，但要从正规商店安装新版扩展；遇到"脚本无法运行"的新问题，先检查扩展和脚本是否为最新版。
