## 二、怎么用

1. **第一次 / 想系统规划** → 通读「大学生活规划指南」00→01→02，再按需翻 03–06，本校同学读 07。
2. **每学期开学 / 期末** → 用「大学四年自我提升全景手册」对表、做复盘五问。
3. **想认识人、求教学长** → 用「向上社交行动手册」的模板和 30 天计划。
4. **做志愿 / 社会实践 / 支教，或想了解研支团、西部计划** → 方法与节奏看「志愿服务与社会实践行动手册」（先读第一、二节，之后按年级查时间线与政策速查表）；找具体平台、组织、赛事、经验帖，翻「志愿服务与社会实践资源库」按板块取用。
> 2026-10-05 精简：旧《04-生活与自我管理导读.md》（基于旧库路径，内容被指南与各专项手册覆盖）与《规划指南/index.html》（与分节 md 100% 等价）移入 `历史备份与日志/重构备份_2026-10-05/`。它留下的唯一结论：**指南（教材）与手册（对表工具）共用同一套行动框架——定目标 → 拆周预算 → 留证据 → 期末复盘五问**。

5. 健身、英语、投资等专项的系统手册在 [`09_课外技能学习资源库/`](/09-课外技能/)；电脑保养在 [`01_电脑使用与工具链/`](/01-电脑与工具链/)。
