## 2. 建议学生上手顺序（【编者推断】，贴合本校学生场景）

### Day 1（~2 小时，跑通最小闭环）

1. Windows 开 WSL2（`wsl --install`，管理员 PowerShell，重启）。
2. WSL2 内跑：

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

3. `hermes model` 选一个便宜云模型（DeepSeek / Kimi / GLM 之一），填 API key（学生先别开 Portal 订阅）。
4. 进 `hermes`，完成一次多轮对话 + 让它调一次内置工具。
5. 明说「remember this for next time」，然后 `cat ~/.hermes/memories/MEMORY.md` 确认它真的写了。

**目标**：理解"对话 → 工具 → 记忆"闭环。别在第一天碰 gateway/cron。

### Week 1（~4 小时，接消息 + 定时任务）

1. `hermes gateway setup` 接 **Telegram**（BotFather 建 bot，用小号），`hermes gateway start`。
2. 手机 Telegram 给 bot 发指令，验证远程派任务。
3. 建第一个 cron：「每天早 9 点查 HN 发 Telegram 摘要」。
4. `/sethome` 指定主聊天。
5. 把常用背景写进 `~/.hermes/SOUL.md`；把项目通用指令写进项目根 `AGENTS.md`。

**目标**：把它从"终端玩具"变成"手机随时可用的助手"。

### 进阶（按兴趣）

- 想玩自进化：`hermes config set memory.persistent true` + `skills.autogen true`，然后**定期审查 `~/.hermes/skills/`**（见 05 文件 F3）。
- 想自托管 24/7：旧笔记本或便宜 VPS（$5/月级）跑 `hermes gateway install` 用户服务；或 Modal serverless 后端（实测 ~$1.40/两周）。
- 想玩本地模型：有 24GB+ GPU 再考虑 Ollama 32B；记住 `-c 65536`，且本地模型没有 web 工具能力。
- 想二次开发：读官方 Architecture → Adding Tools → Creating Skills；符合 agentskills.io 开放标准。

## 4. 术语表

| 术语 | 含义 |
|---|---|
| Hermes Agent | 本项目：Nous Research 开源 CLI/TUI 自主智能体（注意与 Nous 的 Hermes 系列大模型区分） |
| CLI / TUI | `hermes` 经典命令行 / `hermes --tui` 现代文本界面 |
| profile | 记忆/会话隔离单元；`hermes profile create <名> --clone` 复制母体 |
| Memory（MEMORY.md / USER.md） | 有界持久记忆文件（~800 / ~500 token），会话启动时作冻结快照注入 |
| Skills | 按需加载的流程文档，符合 agentskills.io 开放标准；`/learn` 可自创 |
| Curator | 后台对自建 skill 做 active→stale→archived 生命周期管理的组件 |
| Cron | 定时任务，由 gateway 守护进程每 60 秒 tick 执行 |
| Tool Gateway | Nous 托管的付费工具后端（搜索/画图/TTS/浏览器） |
| Messaging Gateway | 单进程连 20+ 聊天平台的后台进程 |
| BYOK | Bring Your Own Key：用自己的模型 API key，而非 Nous Portal |
| `hermes claw migrate` | 从 OpenClaw 一键导入 SOUL.md/memory/skills/key |
| OpenClaw | 最常被对比的同类 agent（"养虾"），skill 生态更大 |
| Modal serverless | 另购 add-on：空闲休眠的云端后端，极省钱 |
| DM pairing | 陌生人发私信时的一次性配对码（1 小时过期） |

## 5. 成本说明（不编造单价）

【官方】Hermes Agent 软件本身 MIT 开源、免费。成本来自三处：

1. **模型调用费**：按你选的 provider API 计费（DeepSeek / Kimi / GLM / OpenRouter / Anthropic / OpenAI 等）。官方未在抓取页列单价，**请查各 provider 官方定价页**，本指南不给编造数字。
2. **Nous Portal 订阅**（可选）：300+ 模型 + Tool Gateway 用量从订阅扣费。**具体价格档位本次未抓取**，请查 Nous Portal 官网定价页。
3. **托管/硬件**：若要 24/7 常驻，需要旧主机 / VPS / Modal。

**社区实测参考区间（均带来源，非官方定价）**：

| 场景 | 成本 | 来源 |
|---|---|---|
| Modal serverless ~120 次对话/两周 | ~$1.40 | andrew.ooo |
| Hetzner CX11 VPS + DeepSeek V3 + Telegram | ¥50–80/月 | 51CTO |
| 个人 30 次/天 | $15–30/月 | dplooy |
| 旧 Dell OptiPlex 24/7 | 一次性 $175 | Reddit u/kenmazaika（官方 user-stories 转述） |
| 书店双 agent（glm5.3+kimi k3+deepseek flash） | <$10/月 | Reddit u/jack-dawed（同上） |

**学生省钱姿势（【官方】Tips + 社区）**：优先 DeepSeek/Kimi/GLM/OpenRouter 等便宜模型；保持 system prompt 稳定吃 prompt cache；长会话 `/compress`；用 `/usage`、`/insights` 盯消耗；后台 review 路由到便宜模型（约低 3–5×）；cron 用 `no_agent` 脚本模式省 token。
