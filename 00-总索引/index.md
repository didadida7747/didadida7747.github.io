## 五、自动更新机制

资料库的定时任务由 **ZCode 自动化**执行（两张独立任务卡，在 ZCode 中查看/编辑，需 ZCode 应用处于运行状态）：

| 任务 | 频率 | 内容 | 脚本 / 日志 |
|---|---|---|---|
| 每日雷达+视野简报 | **每天 07:30** | 先跑科技雷达生成 `output/latest.html`，再按 `prompts/每日任务提示词.md` 采集、核验、写当日简报（周日加周报） | `04_前沿科技雷达/tech_radar.py`；简报产物 `04_前沿科技雷达/每日视野简报/reports/`，日志 `每日视野简报/logs/` |
| 竞赛周更+手机版重建 | **每周一 09:00**（独立任务） | 竞赛官网复查、时间轴 HTML/Excel 重新生成、就业动态联动更新；随后重建 `资料库手机版.html` | `03_竞赛与就业作战总资料包/竞赛规划资料包/自动化脚本/weekly_update.py`，日志在「历史备份与日志/更新日志/」；手机版日志 `_手机网站构建/rebuild.log` |

> 想立刻更新（不等周一）：双击 `_手机网站构建/一键重建网站.bat`；雷达与简报可在 ZCode 自动化页面手动单次触发，或按上表脚本直接运行。
> 任务没有触发（如电脑未开机）时，开机后打开 ZCode 补跑即可；脚本全部使用资料库内相对路径，整个文件夹移动后仍可用。

## 六、资料库维护约定

为长期保持整洁，新增资料时请遵守：

1. **对号入座**：新文件放进对应编号文件夹，不要直接堆在根目录（主业/深造→07，省钱→08，技能→09，变现→10）。**工程 / 代码项目（依赖、构建产物、git 历史）归入下划线开头的工程目录**（如 `_知识站构建（VitePress）`），不与内容资料混放、也不被手机版收录。
2. **命名规范**：用「主题_具体内容」中文名，不加空格、不堆砌日期（归档报告除外）。
3. **临时文件**：作业、截图、草稿一律放 `99_课程作业与临时/`，定期清理。
4. **改动前备份**：覆盖文档前，先复制到该文件夹或其「历史备份」目录。
5. **更新索引**：新增重要文件后，在本 README 或对应子 README 补一行说明。
6. **链接均为相对路径**：整个 `ai资料(豆包)` 文件夹可整体拷贝 / 同步到网盘或其他电脑，内部链接不会断。
7. **手机网站自动收录**：成品文件放进对应分类文件夹即可被每周自动重建收录；数据源、构建脚本、备份、自检截图等请保持放在约定的排除目录中，不会被收录。
8. **数字要可溯源**：政策、比例、收入、价格等关键数字标注来源与时点；拿不准的写"以官方当年文件为准"，不臆造。
