# 实习指标与故障注入

指标必须来自自己的实验。2026-08-13 已先锁定 V0.5 的测量口径；结果仍需后续实测填写。

## 性能指标

| 指标 | 测量方法 | 最低交付 | 实测结果 |
| --- | --- | --- | --- |
| 周期与抖动 | 优先用调试 GPIO + 逻辑分析仪/示波器；没有仪器时用定时器/DWT 时间戳并说明测量扰动 | 目标周期、最小/最大/平均值 |  |
| 采样丢失率 | 期望采样计数、完成计数和错误计数对比 | 连续运行 10 分钟，报告丢失数/总数 |  |
| UART 吞吐与错误 | 固定时间统计有效字节、错误帧、超时和重同步次数 | 至少 1000 帧 |  |
| RAM/Flash | Keil map/Build Output | 记录 V1.0 占用和芯片总量 |  |
| CPU/主循环余量 | 空闲计数、DWT 或任务运行时间；说明方法限制 | 一个可复现估算 |  |
| 故障恢复时间 | 从注入故障到恢复/安全停机计时 | 至少测 3 次 |  |

## 必做故障注入

1. 拔掉或屏蔽 BMP280/I2C：系统超时、记录错误并保持可响应。
2. 发送错误长度、错误校验、截断和连续 UART 帧：解析器拒绝坏帧并重新同步。
3. 制造任务卡死/停止喂狗：记录看门狗复位和重启后的状态。

## 条件故障

- 输入超范围或传感器读数异常。
- 上位机断线、重复命令或参数越界。
- PWM 输出限幅和恢复；有电机时增加急停。
