# 2025科协暑培 · 科研入门（王浩然, BV1zPegzFELs, 约25分钟）

> 发布于 2025-08-20；讲师王浩然（清华计算机系）。

## 定位

科研总论讲：科研是什么、与课业如何平衡、何时进组怎么联系老师、怎么读论文，以 LLM 方向举例但声明方法可泛化。适合刚开始想碰科研的本科生；与 2026 暑培"进组邮件""读论文"两讲高度同源，重合段已标⏭️可跳过。

## 内容脉络

- [0:03] 开场与叠甲：以"门外汉"视角讲入门；用 LLM 方向举例仅因个人方向，先"找准热爱且擅长的方向"再长期投入。目录：打破科研神话→科研与学业关系→如何做科研→如何读论文。
- [1:24] 科研两个关键词："系统的方法"与"新"。研究三型：①学他人已验证的技术供日后所用（"我辈复登临"式）；②在他人方法的瑕疵上改进；③做别人没关注过的新场景——例：2017 年 transformer 提出（Attention Is All You Need）前后的架构更替。
- [2:48] 课业 vs 科研：课业是结构化、被广泛验证、经简化提炼的知识；科研现学现卖，不知道明天任务用什么技术。
- [3:17] 科研不神秘：计组/编译/OS 等课程作业有"评分标准之外的探索"空间；判据——没人做过且自己认为有价值即是一段研究，可缺消融实验。
- [3:46] 案例：大三人工神经网络小组作业——分析 transformer 泛化性，任务分简单函数（sin/cos）与复合任务（加法/乘法组合），对比 GT、只用简单函数训练的 baseline、加训一种组合后的模型：加训后模型在其他组合上泛化也被激活。"设计实验→完成→比较→结论"就是科研，不必进实验室。
- [5:41] 平衡：时间与精力有限，"白天上课晚上通宵"绝大多数人不行；大作业 DDL 撞投稿 DDL 先保课业。
- [6:10] 两种科研型与冲刺期：寓教于乐型（只为能力提升，对本科生更应期待）vs 孜孜不倦型（大投入冲会议/期刊）；冲刺期=截稿逼近连轴转收尾，非冲刺期保持领域敏感即可（每天推进一点、读前沿 paper）。
- [8:01] 讲师晒绩点曲线：高强度跑实验后成绩持续下滑——"以为两件事都能弄过来，事实告诉我不可以"。
- [8:31] 进组时机：大一别进组、大二也不建议（专业课没学过），较好时机是大二下结束。
- [9:23] 联系老师：系官网教职工名录→个人主页→Google 搜名字看近期论文→发邮件（一般加不到微信）；Google Scholar 按引用排序看研究方向（以吴建平院士主页为例）。⏭️可跳过：2026"进组邮件"一讲覆盖同样流程且更细。
- [10:20] 工程/刷榜/研究三分：工程=复现代码搭功能，不产生新知识，"把工程精力算进研究只有自我感动"；刷榜=方法 A 换更大算力（1B→100B）或搬到大数据集（CIFAR-10 方法复现到 ImageNet-22K）就发文——不 make sense，刻意隐瞒结果是选择性汇报、"涉嫌诈骗"。
- [12:43] 学术不端自查清单：抄袭、自我抄袭、篡改、代写买卖、捏造数据、cherry picking（十组实验只放最好一组）、过度美化、数据挖掘到过拟合、拼凑式研究、滥用生成式 AI 冒充亲写。
- [13:41] 前置知识："哪里不会学哪里"可行，但至少先会 Linux 服务器基本操作；LLM 方向需知道 Adam、transformer、BERT 等基本概念。
- [14:35] 入门 flow 四步：①围绕一篇经典论文，搞懂本身+关键引用+核心概念，哪里不懂查哪里；②缺啥补啥（缺数学补数学、缺编程学编程），目标明确效率高；③尝试复现核心图表与结果，倒逼搞清全部细节；④提出小问题（"换个数据会怎样"），这是研究的最初起点。入门三能力：具体兴趣点、主动性、立刻动手别拖延。
- [16:31] 读论文观：大部分论文同质化不需要细读，有价值的论文一遍也读不透；论文是数据库不是书，非线性别线性读。⏭️可跳过：以下至 22:14 与 2026"读论文"一讲高度重合，本讲更简略。
- [17:28] 论文结构：标题/摘要（做了什么+结果）/introduction/related works（不引领域内重要工作可直接成为拒稿理由）/method/实验/结论+limitation。
- [18:51] 1~3 分钟决定下载还是关掉：只看标题、摘要、图表标题、结论首末段（识破夸大写作）。
- [20:19] 细读策略：第一遍只求知道文章在干什么——跳过大段背景与非核心综述、先不啃数学证明、不看服务器版本号类细节（复现时才重要）、不看未来工作；聚焦 introduction 末段列点贡献、method 核心公式与图、results 核心图表。
- [22:14] 总原则：先摘要结论建框架，带着"作者如何实现"跳读方法与实验，始终掌握主动权。
- [22:42] 工具三件套：arXiv（康奈尔维护，按 cs.AI 等分类刷最新）；Zotero 文献管理；arXiv daily——订阅后每天调用大模型 API 总结文章与代码发进邮箱（需自备 API，如硅基流动或智谱免费 API）。
