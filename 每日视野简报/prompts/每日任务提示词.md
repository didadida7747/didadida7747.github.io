# Codex 每日任务提示词

你正在维护本地项目 `D:\ai资料\日常与规划\每日视野简报`。目标是生成一份约 10 分钟读完、证据可追溯的中文每日视野简报；每逢周日，再生成本周趋势回顾。

## 边界

- 仅访问无需登录的公开页面。不得登录、付费、绕过验证码或访问限制，不得提交表单、留言、发消息、下载可疑文件。
- 不读取或输出任何 `.env`、Cookie、令牌、账户信息或其他秘密。
- 每个固定来源最多采集一次；失败后记录失败，不要自动重试，不要因某个来源失败而编造替代内容。
- “固定来源采集一次”指对 `config/sources.json` 中的入口只运行一次采集；对拟入选的不同原文页可各访问一次用于核验。不要重复打开同一原文页，也不要把候选包、RSS 日期或 URL 中的日期当作已核验的原文发布日期。
- 新闻聚合、社交媒体、热搜和自媒体只能发现线索，不能单独支撑日报结论。
- 金融内容只解释事实、机制、风险与不确定性，不给个性化投资建议，不输出买入、卖出、加仓、减仓指令。
- 不把脚本退出码为 0 当作任务完成；必须检查产物并运行校验器。

## 质量门槛

评分前，每个候选必须同时通过以下门槛；未通过者不能作为“今日重点”，即使来源级别高或题材热门：

- **原文可核验**：已打开原始页面，且标题、事实、关键数字、适用地区和上下文都能在页面正文或原始附件中找到。不得只根据候选标题、摘要或常识补写数字、版本、政策细节或因果关系。
- **日期可追溯**：发布日期以原文页明确标示的日期为准；原文未标明时必须写 `发布日期：页面未标明`。不得从 URL、RSS、采集时间或搜索结果推断日期。
- **时效合格**：普通新闻、数据和公告原则上须在报告日及此前 7 个自然日内发布；法规、规划、统计公报等可放宽至 14 天，但须说明其尚未被前序日报覆盖。超过期限的材料只能作为背景或“继续观察”的上下文，不能充当当天新增重点。
- **相对前日报有新增**：先阅读最近 3 份实际存在的日报。标题、原始链接或核心事实与其中任一条实质相同的内容默认排除；只有出现新的官方数据、执行日期、版本、事件进展或相互矛盾的证据时才可跟进，并在标题和事实中明确写出“更新”及新增部分。
- **事实强度足够**：只有“某机构发布了某文件”而没有可说明的新增规则、数据、范围或事件变化时，通常不单列；除非该发布本身已生效、覆盖面显著或构成重要制度节点。

## 每日流程

1. 以 Asia/Shanghai 时区确定今天日期 `YYYY-MM-DD`，进入项目目录。
2. 检查 `README.md`、`config/sources.json`、日报模板以及当天是否已有产物。若当天已有通过校验的完整日报，不重复采集，只报告已有路径和校验结果。
3. 当天尚未完成时，只运行一次：

   ```powershell
   .\scripts\run_daily.ps1 -Date YYYY-MM-DD
   ```

4. 读取当天 `data/raw/YYYY-MM-DD/research_packet.md` 与 `collection_summary.json`，并读取最近 3 份实际存在的日报。候选只是线索；先按“质量门槛”过滤，再对拟入选条目打开原始页面，核对标题、发布日期、关键数字、适用地区和上下文。
5. 为每个拟入选条目在工作笔记中形成“来源 -> 可写事实”对应关系：数字必须能定位到原始表格或正文，政策必须能定位到条款、附件或权威解读，科技结论必须区分研究、预印本、产品发布与已部署能力。原文出现访问错误、正文缺失、日期冲突或主张无法定位时，放弃该条，不用候选摘要补齐。
6. 对影响重大的政策、宏观数字、市场规则、冲突、安全事件和突破性科技声明，尽量补充一个独立高质量来源。两个来源若结论、口径、时间或适用范围冲突，不自行调和，写明差异；若只有单一来源，必须在“不确定性与反方证据”中说明该限制。
7. 按以下标准打分筛选，但不要把分数写进最终报告。评分不能推翻“质量门槛”：

   - 影响范围 0～3：是否影响大量人群、重要行业、政策或全球关系。
   - 证据质量 0～3：原始文件/数据最高，可靠媒体次之，线索最低。
   - 新颖变化 0～2：是否出现可验证的新变化，而非旧闻重复。
   - 与读者相关 0～2：优先 AI、机器人、芯片、先进制造、就业环境和基础金融素养，但不能挤掉真正重要的综合议题。
   - 仅保留总分较高且信息增量明确的条目，同一事件合并去重。

8. 写入 `reports/daily/YYYY-MM-DD.md`，使用 `templates/日报模板.md` 的结构：

   - 目标 6～9 条、约 1,800～2,800 个汉字；覆盖由当天高质量信息决定，不为分类平均而扩写低价值材料。
   - 重要性优先，不为分类平均而保留低价值信息。
   - 证据不足、时效不足或去重后不足时可写 5～7 条，但必须原样包含“证据不足而不凑数”；不得为了凑条目复用前日报、使用过期材料或只有标题的发布。
   - 每条严格包含“事实、为什么重要、可能影响、不确定性与反方证据、来源”。
   - “事实”最多 2 句，只写来源可直接支持的内容；“为什么重要”解释机制或覆盖范围，不把推测伪装成事实；“不确定性与反方证据”必须写具体限制，不能只写“仍待观察”。
   - “可能影响”必须用条件性语言；不要把预测写成事实。
   - 来源行必须包含可点击的原始链接和 `发布日期：YYYY-MM-DD`；页面没有日期则写 `发布日期：页面未标明`。
   - YAML 元数据中的 `items` 必须等于正文条目数；`sources_succeeded` 和 `sources_failed` 必须取自当天采集汇总。

9. 对日报运行：

   ```powershell
   .\scripts\run_daily.ps1 -Date YYYY-MM-DD -ValidateReport .\reports\daily\YYYY-MM-DD.md
   ```

   若校验失败，只修正文档并重新校验，不重新运行采集。校验通过后再人工复查：正文条目数与 YAML 一致、每条都有已核验原文日期、没有超期或与最近 3 份日报实质重复的条目。直到校验和复查均通过，或明确记录无法完成的原因。

## 周日流程

若今天是周日，在日报校验通过后，读取最近 7 天实际存在的日报，按 `templates/周报模板.md` 写入 `reports/weekly/YYYY-Www.md`：

- 只使用本周日报及其原始链接，不重新包装七份日报。
- 提炼本周最重要的 5 个趋势，说明证据、变化方向、反例和下周观察指标。
- 标出本周被后续证据修正或仍未证实的判断。
- 若本周少于 4 份有效日报，仍可生成，但必须标为 `partial` 并说明覆盖不足。

## 最终汇报

用简短中文报告：日报路径、条目数、成功/失败来源数、校验结果、周报路径（若有）以及失败来源名称。不要把未完成说成完成。
