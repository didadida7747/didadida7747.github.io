# 强化学习基础速读

这一份的目标是让你先把强化学习的语言体系建立起来。  
你现在最需要的不是记很多算法，而是先理解“智能体到底在学什么”。

## 强化学习最核心的一张图

强化学习里最重要的只有一个闭环：

1. 智能体观察环境
2. 智能体选择动作
3. 环境发生变化
4. 环境返回奖励
5. 智能体根据奖励调整策略

这就是你后面看 DQN、PPO、甚至多智能体方法时都不会变的主线。

## 你必须先懂的词

### 1. agent

就是做决策的主体，也就是“智能体”。

### 2. environment

就是智能体所处的世界。  
它接收动作，更新状态，并返回反馈。

### 3. state / observation

- `state`：世界的完整状态
- `observation`：智能体实际能看到的信息

很多时候代码里直接把输入叫 state，但更严格地说，智能体常常拿到的是 observation。

### 4. action

智能体在当前时刻做出的选择。

### 5. reward

环境给智能体的反馈信号。  
它不一定直接告诉你“正确答案”，但会告诉你当前行为是更好还是更差。

### 6. policy

策略就是“看到什么情况时，倾向于做什么动作”的规则。

### 7. return

不是某一步的奖励，而是一段时间内累计得到的总回报。

## 智能体到底在学什么

你可以先用一句非常朴素的话理解：

智能体在学一套决策习惯，让自己在长期里拿到更多累计奖励。

所以强化学习和监督学习最大的不同是：

- 监督学习通常有明确标签
- 强化学习没有人一步步告诉你标准答案，只给你反馈信号

## 为什么 reward 能驱动学习

因为 reward 给了智能体一个优化方向。  
虽然单步奖励可能很局部，但如果算法设计合理，智能体会逐渐学会哪些行为更容易带来更高的长期回报。

你不用把 reward 想得太神秘，它本质上就是“把任务目标数值化”。

## MDP 你现在怎么理解就够了

`MDP` 可以先理解成：

一个任务被抽象成“状态、动作、转移、奖励”组成的决策过程。

你现阶段只要知道，很多 RL 任务都被放在这个框架里讨论，就够了。

## 先看哪个算法

入门时推荐顺序：

1. 先懂概念
2. 再看 `DQN`
3. 再理解 `PPO`

原因很简单：

- `DQN` 很适合和 `CartPole` 这类离散动作任务配合，容易跑起来
- `PPO` 是后来你接触更主流深度强化学习和多智能体时很常见的基础

## DQN 你先知道什么

你只要先知道这句话：

`DQN` 让网络去估计“在当前状态下做某个动作值不值得”。

做法上，它会对每个动作给一个分数，然后倾向于选择分数更高的动作。

## PPO 你先知道什么

你现在先抓住这一句：

`PPO` 是一种策略梯度方法，它直接优化策略，但会限制每次更新不要太猛。

TorchRL 官方教程对 PPO 的描述很直接：它是一种策略梯度算法，先收集一批数据，再在约束下直接训练策略去最大化期望回报。  
来源：TorchRL PPO Tutorial。  
链接：https://docs.pytorch.org/rl/stable/tutorials/coding_ppo.html

## 最适合你现在跑的代码

优先选：

- `CartPole-v1`

原因：

- 任务简单
- 离散动作
- 官方教程成熟
- 能很快看到训练效果

PyTorch 官方 DQN 教程明确就是在 `CartPole-v1` 上训练一个 DQN agent。  
来源：PyTorch DQN Tutorial。  
链接：https://docs.pytorch.org/tutorials/intermediate/reinforcement_q_learning.html

这个任务里，智能体只有两个动作：让小车向左或向右移动，目标是尽量让杆子保持平衡更久。  
来源：PyTorch DQN Tutorial。  
链接：https://docs.pytorch.org/tutorials/intermediate/reinforcement_q_learning.html

## 看 RL 代码时你要盯的主干

你现在读 RL 代码，只看下面 5 个位置：

1. 环境是怎么创建的
2. `reset()` 在哪里
3. `step(action)` 在哪里
4. 动作是怎么选出来的
5. 参数更新在哪一段发生

只要把这 5 个点找到，整个训练循环就开始清楚了。
