# 09 · 学生实战手册：这套能力对本校大二电子信息到底值多少

> 本章回答一个问题：**学的这些东西，怎么落到你的课表、竞赛、科研和前途上。**
> 时效信息（价格/赛程/政策）均标注"以官方为准"，核查时间 2026-10-24。

## 9.1 你的起点盘点（本机实况）

| 资产 | 现状 | 含义 |
|---|---|---|
| Codex CLI | 241 个会话，config.toml 在用 | 你已是重度用户，缺的是体系 |
| Claude Code | 148 个会话，ZCF 框架、6 套 output-styles | 深度定制在门口，只差临门一脚 |

| codex-learning 六章 | 入门+工作流+CLI 速查已成 | 本手册直接续高阶 |

**结论**：你不是"学 AI 编程工具"，你是"把已有 80 分的底子补成 95 分"——路径完全不同：不扫盲，直接上 §10 练习和高阶章。

## 9.2 课程对照表（每门课的 Agent 打开方式）

> 课程按电子信息大类大二-大三典型课表，**以你的培养方案为准**。每行给"工作流"，命令细节跳 §07。

| 课程 | Agent 工作流 | 提示词要点 |
|---|---|---|
| 数据结构与程序设计（C/C++） | 课设脚手架 → debug（贴报错+最小复现）→ 对拍找反例 → `/code-review` 收尾 | "先讲思路再给代码""只给修这一处的 diff" |
| 面向对象程序设计 | 设计模式讲解 + 重构练习：让它重构你写的烂代码，再对比学习 | "重构后逐条解释改了什么、为什么" |
| 电路分析 / 模电 | 计算校验脚本（Python sympy 列方程）、LTspice 网表注释与参数扫描脚本 | "列 KVL/KCL 方程过程，别只给答案" |
| 数字逻辑 / 数电 | Verilog 模块+**testbench** 生成、时序图解释、综合报错误翻译 | "先给状态转移图再给代码" |
| 信号与系统 | MATLAB/scipy 脚本（卷积、傅里叶、滤波器）+ **可视化讲解**：让每张图配物理解释 | "用 /verify 思路：跑出来图对不对你判断" |
| 概率论与数理统计 | 蒙特卡洛数值实验、分布对比图、习题验算 | "模拟 10^6 次验证解析解" |
| 大学物理实验 | 数据处理脚本（误差传递、最小二乘）、报告图表统一模板（做成 skill，§04） | 模板化后每次一条命令出图 |
| （大三前瞻）通信原理/DSP | 端到端仿真链路（调制→信道→解调→误码率曲线） | "逐模块讲清参数物理含义" |
| （大三前瞻）嵌入式/FPGA | STM32 HAL 驱动脚手架、寄存器配置代码、上位机（Python serial）；**烧录调试永远你自己来**（§01.6 边界） | "只生成代码和接线说明，硬件我操作" |

**通用纪律**：作业代码**先自己写**，Agent 只做 review 和讲解——这是防拐杖化的第一条线，也是诚信底线（§9.7）。

## 9.3 竞赛工作流

### 全国大学生电子设计竞赛（NUEDC）——你的主战场
- **时机**：单数年国赛（2027 年是国赛年，近年口径 9 月前后、四天三夜，**以当年官方通知为准**）；2027 年 9 月你正值**大二升大三黄金窗口**。多所高校 2026 年 9 月已启动 2027 届选拔培训——**现在就该盯本校校赛/培训通知**（本校正是陕西赛区官网所在地，校园网内网系统
- **AI 工作流**（赛前把流程固化成 skill，赛场只管调用）：
  1. 驱动脚手架："给 STM32F103 HAL 工程：TIM3 PWM + ADC1 采样 + USART2 上位机协议"；
  2. PID 调参：贴波形数据让它估参数初值 + 讲调参顺序；
  3. 视觉题：OpenCV 靶识别管线 + 距离估算标定脚本；
  4. 上位机：Python serial 实时绘图（半天工作量压到 1 小时）；
  5. 设计报告：模板 skill + 图表自动化。
- **并行分工**：§08.3 "电赛赛前两周" 流程直接照抄。
- **注意**：赛场网络/设备受限，赛前把依赖环境打包离线；竞赛规则若对 AI 工具有限制，**以规则为准**。

### 数学建模（国赛每年 9 月 / 美赛年初，以官方为准）
- `/batch` 参数扫描（20 组参数并行子代理）；求解脚本（scipy/pulp）；论文图表自动化；摘要润色。
- 诚信红线：模型和论文主体必须你们自己做，AI 用于代码实现、画图、语言润色并在队内明确记录。

### 蓝桥杯（每年春季）/ ICPC-CCPC
- 练题复盘：贴题解让它讲多种解法复杂度对比；**对拍脚本**（暴力解 + 随机数据）是无敌找错器（§06.6）。

### 集创赛（集成电路创新创业）
- FPGA/IC 代码辅助（Verilog/VHDL 模块+testbench）、答辩 PPT（CC `/slides` 技能）、技术报告。

### 大创 / SRTP
- 申报书结构建议与润色（内容原创性自己负责）；实验数据批处理（§06）；中期/结题报告图表管线复用课设 skill。

## 9.4 科研入门：论文代码复现工作流（大创/进组通用）

```text
第 1 步（只读侦察）：
"克隆 <repo>。先不要修改任何文件：1) 对照论文讲清方法与代码模块的对应关系；
2) 列出运行依赖与硬件要求；3) 给出本地复现步骤清单（含可能的坑）。"

第 2 步（跑通）：按清单逐步执行，每步失败贴报错，让它只修当前一步。

第 3 步（验证）：复现论文关键图表，与原文对比："这张图和论文 Fig.3 差在哪，
可能是什么原因（随机种子/超参/数据版本）？"

第 4 步（为己用）：换你的数据 → 封装成 skill（§04）→ 组会演示。
```
这套流程的价值：进课题组时你能直接产出，而"会复现论文"正是导师招本科生的核心期待。

## 9.5 成长时间线（大二 → 毕业）

| 阶段 | 工具力目标 | 里程碑 |
|---|---|---|
| **现在（大二上，2026 秋）** | 练完 §10 的 12 个练习；GitHub 学生包认证；课设全部 git 化 + AGENTS.md | 技能仓建立（3 个自写 skill） |
| 大二下（2027 春） | 蓝桥杯；大创申报；电赛校赛选拔 | **第一个开源贡献**（给 awesome 合集提中文技能/修文档） |
| 大二暑假-大三上（2027） | 电赛国赛冲刺+参赛；数模国赛 | 省级以上奖项；竞赛 skill 库成型 |
| 大三（2027-28） | 复盘沉淀：把竞赛流程写成可复用资产；实习冲刺（数据结构手写能力+工程能力双线） | 大创出中期成果；GitHub 作品集（知识站+技能仓+竞赛仓库） |
| 大三暑假（2028） | 暑期实习：无头自动化/CI 技能直接对标企业工作流 | 一段实习经历 |
| 大四上（2028-09） | 保研面试 / 秋招 | **差异化叙事**：harness 源码精读 + context engineering + 竞赛成果 + 开源作品——同龄人几乎没有的组合 |

**为什么是复利**：工具力放大其他一切能力——同样的课设，你多出的时间用于理解原理；同样的竞赛，你的并行分工多试三版方案；同样的面试，你有别人讲不出的底层细节。晚一年开始，每个环节都在付利息。

## 9.7 学术诚信与使用边界

**原则清单（当导师，不当枪手）**：
1. 先自己想 15 分钟，再问 AI——保持"想"的肌肉；
2. 交付的每一行代码你都能逐行讲清——讲不清=不会=风险；
3. 课程/竞赛若要求声明 AI 使用，**如实声明**（§08.3 大创流程已含此步）；
4. 考试、闭卷、机试等明确禁止场合，零使用。

**学校规定自查路径**（本手册**不代读**本校具体规定，避免编造）：
学校教务处/学院官网 → 培养方案与课程教学大纲 → 任课教师课程说明；有疑义直接问老师——这一问本身就是好印象。

**保密意识**：
- 实验室未发表代码/数据、竞赛未公开方案、含个人信息的文件——**不发云端 API**（传输即出校门）；
- API key/token 永不进 git（`.gitignore` + 提交前扫一遍；`/security-review` 也能查）；
- 公开仓库前 `/security-review`（§06）是固定动作。
