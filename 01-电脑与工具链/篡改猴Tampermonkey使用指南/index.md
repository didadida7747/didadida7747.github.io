# 篡改猴（Tampermonkey）合理使用完全指南

> 整理时间：2026-10-20
> 资料来源：Tampermonkey 官网与官方文档、GitHub、Greasy Fork、脚本猫（ScriptCat）、油猴中文网、掘金、脚本之家、奔跑中的奶酪、B站、抖音、YouTube 等（各文件内附链接）
> 适用对象：零基础可上手；开发章节面向有 JavaScript / 前端基础的同学（电子信息、计算机方向友好）

## 一句话说明

**篡改猴（Tampermonkey）是一个浏览器扩展，用来安装、管理和运行"用户脚本"（Userscript）——一小段 JavaScript 代码，在你打开指定网页时自动执行，从而给网页加功能、去干扰、改样式。**

- 俗称"油猴"。严格说"油猴"最早指 Firefox 上的 Greasemonkey（2005 年），如今 Tampermonkey（篡改猴）才是主流，Violentmonkey（暴力猴）是开源替代品。
- 全球用户超 1000 万，支持 Chrome、Edge、Firefox、Safari、Opera，手机端也有方案。

## 30 秒结论（TL;DR）

1. **装什么**：电脑端 Chrome / Edge 应用商店搜 **Tampermonkey** 安装（兼容性最好）；偏好开源免费可选 **Violentmonkey** 或国产 **脚本猫**。
2. **去哪找脚本**：**Greasy Fork**（https://greasyfork.org ，国内打不开用镜像 `greasyfork.icu` 或 `greasyfork-zh.org`），其次 GitHub、油猴中文网。
3. **三条安全铁律**：
   - 只从 Greasy Fork / GitHub 高 star 项目等**可信来源**装脚本，安装前看一眼**评分、评论数、安装量、更新时间**；
   - 看脚本头的权限：`@match`（在哪些网站运行）范围是否合理、有没有 `@require` 外部代码、`@connect` 陌生域名、`GM_xmlhttpRequest` 跨域请求——**功能与权限对不上的脚本不要装**（一个"视频解析"脚本没有理由访问你的社交/网银网站）；
   - 全局脚本（`@match *://*/*`）少而精，不用就禁用，定期清理，开启自动更新。
4. **合规红线**：页面美化、去广告、自动化自己的工作流、辅助学习写代码 = 合理使用；**VIP 视频解析、刷网课、网盘破解、付费音乐下载、脚本中夹带返利劫持 = 侵权 / 违规 / 恶意，别碰**（大学生刷课被查到有处分风险，见 [05-安全与合规指南](/01-电脑与工具链/篡改猴Tampermonkey使用指南/05-安全与合规指南)）。
5. **脚本出问题怎么排查**：先在篡改猴管理面板逐个禁用二分定位；改了网页打不开/排版错乱，90% 是脚本不兼容，禁用即可。

## 快速上手（5 分钟）

| 步骤 | 操作 |
|---|---|
| ① 装扩展 | 浏览器扩展商店搜 "Tampermonkey" → 添加 → 右上角出现黑色猴子图标 |
| ② 找脚本 | 打开 Greasy Fork（或镜像站），搜索想要的功能（如 "知乎增强"） |
| ③ 安装 | 点脚本页"安装此脚本" → 跳转篡改猴编辑器 → 再点"安装" |
| ④ 验证 | 打开目标网页，点篡改猴图标能看到"正在运行的脚本"，即生效 |
| ⑤ 管理 | 点图标 →"管理面板"，可启用/禁用/编辑/导出脚本 |

## 它能做什么 / 不能做什么

**能做（合理使用的典型场景）：**
- 网页净化：去广告弹窗、去掉"打开 APP 才能看"、自动展开全文、屏蔽不感兴趣的内容；
- 浏览增强：自动翻页、解除复制/右键限制（仅限你有权访问的内容）、链接净化、黑夜模式、宽屏显示；
- 学习科研：网页转 Markdown、文献页面增强、字幕翻译、自定义快捷键；
- 开发者工具：GitHub 增强、接口调试辅助、给自己常用的内部系统写自动化；
- 自己写脚本：实现任何"打开某网页后自动执行一段 JS"的个性化需求。

**不能 / 不该做：**
- 不能突破浏览器本身的安全沙箱去攻击网站、读取你没有权限的数据；
- 不能用来窃取他人账号信息（恶意脚本反而可能这样对付你，这是重点防范对象）；
- 不应破解付费内容、刷课代考、批量爬取违反网站协议的数据——这些在 [05](/01-电脑与工具链/篡改猴Tampermonkey使用指南/05-安全与合规指南) 里有详细说明。
