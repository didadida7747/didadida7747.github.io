# 用药基础常识:看懂药盒、读懂说明书,是安全用药的第一步

> 一句话定位:教你认处方药/非处方药、"国药准字"批准文号,读懂说明书,掌握服药时间、送服方式、剂型常识、漏服处理和药品储存,建立用药安全的底层能力。
>
> ⚠️ 免责声明:本文为科普整理,不构成医疗建议;具体诊疗与用药请遵医嘱/咨询药师;出现急重症立即拨打 120。

---

## 🎯 核心速览(TL;DR)

1. **先看药盒右上角**:印"OTC"是无需处方的非处方药,红底 OTC 是甲类(相对安全系数低些,药店凭药师指导买),绿底 OTC 是乙类(安全性更高,超市便利店也能买到);没印 OTC 的一般是处方药,必须凭医生处方。
2. **认准"国药准字"**:合法药品包装上都有"国药准字 H/Z/S/B + 8位数字"批准文号(H=化学药,Z=中药,S=生物制品),没有批准文号或写着"消字号""健字号"的都不是药,不能当药治病。
3. **说明书重点读五处**:适应症(治不治我的病)、用法用量、禁忌、不良反应、药物相互作用;剂量一律以说明书/医嘱为准。
4. **送服只认温开水**(约 200 毫升);茶、牛奶、果汁、酒、咖啡都可能让药失效或加重副作用。
5. **西柚(葡萄柚)是"药克星"**:会影响多种降压药、他汀类降脂药代谢,服药期间整个避开,别只想着"错开时间吃"。
6. **缓释片、控释片、肠溶片不可掰开、嚼碎、碾碎**;说明书注明"可沿刻痕掰开"的除外。
7. **漏服的处理原则:想起来时距下次服药还远就补,快到下次时间就跳过,绝不一次吃双倍剂量**(抗生素等有特殊要求,以说明书为准)。
8. **症状好了要不要停药,看药物类型**:感冒退烧止痛类是"按需"吃,症状消失就停;抗生素类要"按疗程"吃足,自行停药易催生耐药;慢病药(降压药等)绝不能自行停。
9. **药品储存看说明书**:常温(10~30℃)、阴凉(不超过20℃)、凉暗(避光且不超过20℃)、冷处(2~10℃);大多数药别放卫生间和车里。
10. **每半年清点一次药箱**,过期药按"有害垃圾"处理,别吃也别随手扔。

## 一、先分清:处方药 vs 非处方药(OTC)

### 1.1 两类药的根本区别

| 对比项 | 处方药(Rx) | 非处方药(OTC) |
|---|---|---|
| 是否需要医生处方 | **必须**凭执业医师处方购买 | 不需要,可自行判断购买 |
| 药盒标识 | 无 OTC 标识 | 药盒上有醒目的 **OTC 专有标识** |
| 常见例子 | 抗生素(阿莫西林、头孢类)、降压药、降糖药、安眠药 | 布洛芬、对乙酰氨基酚(部分剂型)、氯雷他定、蒙脱石散 |
| 风险程度 | 潜在风险高,需医生评估病情后使用 | 相对安全,按说明书使用一般风险低 |

### 1.2 OTC 还分甲类(红)和乙类(绿)

OTC 根据安全性进一步分为两类(依据国家药品监管部门对非处方药的分类管理):

| 对比项 | 甲类 OTC(红色 OTC 标识) | 乙类 OTC(绿色 OTC 标识) |
|---|---|---|
| 标识颜色 | 红底白字 OTC | 绿底白字 OTC |
| 安全性 | 相对较低,需更谨慎 | 更高,不良反应更少 |
| 销售渠道 | 具备《药品经营许可证》、配备执业药师(或药师以上人员)的社会药店和医疗机构药房 | 除药店外,还可以在**超市、便利店、百货商店**等销售 |
| 使用提示 | 建议在药师指导下购买使用 | 一般可自行选购 |

> 💡 记忆法:**"红要人管(药师指导),绿能自助(超市自买)"**。无论红绿,都应按说明书用药;症状持续或加重就要就医,而不是继续买药硬扛。

### 1.3 处方药为什么不能自行购买使用

- 处方药需要医生先诊断:比如"咳嗽"可能是普通病毒感染,也可能是肺炎、哮喘,用药完全不同。
- 抗生素、激素、安眠药等处方药自行滥用后果严重(耐药、依赖、掩盖病情),详见本模块《03-常见用药误区与安全红线》。
- 网上代购、微商售卖的"处方药"没有监管,真假和储存条件都无法保证,是重大安全红线。

## 二、"国药准字":一秒钟辨别是不是真药

### 2.1 批准文号的格式

中国境内合法上市的药品,包装上必须印有批准文号,格式为:

```
国药准字 + 1位字母 + 8位数字
例:国药准字H20040345
```

| 字母 | 含义 | 常见例子 |
|---|---|---|
| **H** | 化学药品(西药) | 布洛芬缓释胶囊、阿莫西林 |
| **Z** | 中药(中成药、中药饮片等) | 板蓝根颗粒、藿香正气水 |
| **S** | 生物制品 | 部分疫苗、胰岛素制剂 |
| **B** | 保健药品(历史遗留类别,已逐步整顿) | 少量旧批号 |

### 2.2 警惕"非药品"冒充药品

| 你看到的字样 | 它是什么 | 能当药吃吗 |
|---|---|---|
| 国药准字 | 真药品 | ✅ 可以(按说明书) |
| 械字号 | 医疗器械(如某些敷贴) | ❌ 不是药 |
| 消字号 | 消毒产品 | ❌ 不能治病,更不能内服 |
| 健字号 / 蓝帽子 | 保健食品 | ❌ 不能替代药物 |
| 无任何批号、"纯天然""祖传秘方" | 来路不明 | ❌ 红线:坚决不买不吃 |

> 🔎 查询渠道:国家药品监督管理局官网(NMPA, www.nmpa.gov.cn)可查询药品批准文号与注册信息;部分电商平台的扫码验真功能只能辅助,以官方查询为准。

## 三、说明书怎么读:五个重点 + 三个可跳过

拿到一盒药,不必逐字读完,但以下五栏**必须看**:

### 3.1 必看五栏

| 栏目 | 看什么 | 常见坑 |
|---|---|---|
| **适应症** | 这药治什么病,对照自己的症状 | "治风寒感冒的药治风热感冒"属于不对症 |
| **用法用量** | 一次几片、一天几次、饭前饭后 | 掰着感觉吃、"多吃点好得快"是大忌 |
| **禁忌** | 哪些人绝对不能用 | 孕妇禁用、12岁以下儿童禁用、对本品过敏者禁用——看到自己符合,直接不用 |
| **不良反应** | 可能出现哪些不舒服 | 列得多≠药不安全,反而说明研究更充分;出现严重反应(呼吸困难、大面积皮疹、面部肿胀)立即停药就医 |
| **药物相互作用** | 和哪些药/食物不能同用 | 同时吃几种药时必看;拿不准就问药师 |

### 3.2 也值得扫一眼的栏目

- **成分**:复方感冒药尤其要看,避免与其他药重复(详见 03 篇"对乙酰氨基酚叠加")。
- **注意事项**:常有"服药期间不得驾驶机、车、船""不得饮酒"等硬性提示。
- **贮藏、有效期**:决定你怎么存这盒药(见第六节)。

### 3.3 相对可以慢看的栏目

药理毒理、药代动力学、临床试验数据等属于专业内容,普通人了解即可,不必纠结。

## 四、服药时间与送服方式

### 4.1 服药时间的含义

| 说明书表述 | 意思 | 常见例子 |
|---|---|---|
| 空腹 | 餐前 1 小时以上,或餐后 2 小时以上(胃里基本没食物) | 部分抗菌药、驱虫药 |
| 饭前服 | 餐前 15~30 分钟 | 部分胃动力药、抑酸药 |
| 餐中/随餐 | 与食物同服 | 某些降糖药 |
| 饭后服 | 餐后 15~30 分钟 | 布洛芬等对胃有刺激的药 |
| 睡前服 | 睡前 15~30 分钟 | 部分他汀类、安眠药 |

> ⚠️ 加餐之后不算空腹。如果说明书要求空腹而你的胃一直有东西,药效会打折扣或刺激加重。

### 4.2 送服:只认温开水

| 送服物 | 问题 |
|---|---|
| **茶水** | 茶多酚、鞣酸可能与药物成分结合,影响吸收 |
| **牛奶** | 钙离子可与部分药物(如某些抗菌药)结合;可能破坏胃黏膜保护作用 |
| **果汁**(尤其西柚汁) | 酸性环境可能加速某些药溶解;西柚详见下文 |
| **酒/含酒精饮料** | 与多种药物发生严重反应(头孢+酒可致命,见 03 篇) |
| **咖啡/可乐** | 咖啡因可能加重某些药物的兴奋、心悸反应 |

**正确做法**:用一整杯温水(约 200 毫升)送服。水量太少,药片容易黏在食道,刺激甚至损伤黏膜——吃完药别立刻躺平,坐/站几分钟。

### 4.3 西柚(葡萄柚):重点警惕的"水果药物相克"

- 西柚中的**呋喃香豆素**等成分会抑制肝脏代谢酶(CYP3A4),让经此酶代谢的药物在体内蓄积,相当于"变相过量"。
- 受影响的常见药物类别(多数指南建议服药期间避免):部分**钙拮抗剂降压药**(如硝苯地平类)、部分**他汀类降脂药**(如辛伐他汀、阿托伐他汀)、部分免疫抑制剂、部分镇静催眠药等。
- **西柚的影响可持续较久,"隔开几小时吃"不可靠,服药期间整个避开最稳妥**;柚子(普通葡萄柚以外的柚类)也可能含类似成分,建议一并谨慎。
- 给家里吃降压药、他汀的长辈提个醒,秋冬"柚子季"尤其注意。

## 五、剂型常识:哪些药片"动不得"

| 剂型 | 外观/特点 | 正确用法 | 为什么 |
|---|---|---|---|
| 普通片 | 无特殊标注 | 可整片吞,多数可掰(有刻痕的沿刻痕掰) | — |
| **缓释片/缓释胶囊** | 名字带"缓释" | **整片/整粒吞服,不可掰、嚼、碾** | 特殊结构让药物缓慢释放;破坏后药物瞬间大量释放,血药浓度骤升,可能中毒 |
| **控释片** | 名字带"控释" | 同上,更严格 | 控释结构(如某些"零级释放"外壳)被破坏则完全失效,药量一次性倾泻 |
| **肠溶片/肠溶胶囊** | 名字带"肠溶" | **整片吞服**,通常建议餐前(以说明书为准) | 外衣保护药物不被胃酸破坏、并减少对胃的刺激;嚼碎会让药物在胃里被破坏或刺激胃 |
| 泡腾片 | 遇水冒泡 | **必须完全溶解于水后再喝**,严禁直接口服或含服 | 直接吞服可能在口腔、咽喉产生大量气体,有窒息风险 |
| 含片/咀嚼片 | — | 含片含服不嚼;咀嚼片嚼碎后咽 | 各按设计用途 |

> 例外提示:少数缓释片有中央刻痕、说明书明确"可沿刻痕掰开",才可以掰,但仍不可嚼碎。**一切以说明书为准,拿不准就整片吞、问药师。**

## 六、漏服怎么办、症状好了要不要停药

### 6.1 漏服的通用处理原则

```
想起来时,先看时间:
├─ 距下次服药时间还长(如超过半个用药间隔)
│    → 尽快补服一次,之后的服药按原时间表
└─ 已经很接近下次服药时间
     → 跳过这次,下次正常吃
❌ 绝对不要:一次吃双倍剂量"补回来"
```

- 举例:一天两次(早晚 8 点)的药,中午 12 点想起来 → 补服,晚 8 点照常;晚上 7 点才想起来 → 跳过,次日早 8 点照常。
- 特殊药物(如某些口服避孕药、胰岛素、抗凝药)漏服处理规则不同,以说明书为准,必要时咨询医生。

### 6.2 "按需"还是"按疗程":决定停不停药

| 类型 | 逻辑 | 例子 | 症状好了怎么办 |
|---|---|---|---|
| **按需用药** | 有症状才吃,症状消失即停 | 退烧药(布洛芬/对乙酰氨基酚)、抗过敏药(部分)、外用止痛膏 | 可停,但注意每日最大次数限制 |
| **按疗程用药** | 必须吃满规定天数 | **抗生素**(医生明确开的)、部分抗病毒药 | **吃足疗程再停**;自行停药易致病情反复和细菌耐药 |
| **长期规律用药** | 每天定时吃,自行停药危险 | 降压药、降糖药、抗抑郁药等慢病用药 | **绝不自行停/减**,任何调整都先问医生 |

> ⚠️ 抗生素"感觉好了就剩着不吃"和"这次剩的下次接着吃",是推动细菌耐药的典型行为。开多少吃多少,不够就复诊,别囤。

## 七、药品储存与效期管理

### 7.1 说明书上的储存术语(依据《中国药典》通行定义)

| 术语 | 含义 |
|---|---|
| 常温 | 10~30℃(说明书没写储存条件时一般按常温) |
| 阴凉处 | 不超过 20℃ |
| 凉暗处 | 避光且不超过 20℃ |
| 冷处(冷藏) | 2~10℃(家庭冰箱冷藏室一般 2~8℃,可用) |
| 避光 | 避免日光直射 |
| 密封 | 防止风化、吸潮、挥发 |

### 7.2 家庭存放的实操建议

- **放哪里**:阴凉、干燥、避光的固定高处抽屉/柜子(如卧室高位抽屉);开封后保留原包装盒和说明书(铝塑板比药瓶瓶装更防潮,能不拆就不拆)。
- **卫生间不理想**:潮湿高温会加速药物变质,很多人习惯放浴室柜,建议改。
- **车内、阳台、暖气旁**:夏天车内可达 50℃ 以上,冬天暖气片旁同样是"药效杀手",都不要放。
- **需冷藏的药**(以说明书为准,如某些生物制剂、胰岛素未开封时):放冰箱冷藏室,别贴着内壁(可能冻住,冻过的某些药会失效);同时务必与食物分区,最好加锁或放在孩子够不到的位置。
- **眼药水/糖浆等开封后**:多数开封后使用期限远短于盒上有效期(常见"开封后 1 个月"甚至更短,少数如某些眼用制剂开封后仅数周),以说明书"开封后稳定期"为准,建议开封时在包装上写下开封日期。

### 7.3 效期管理三步法

1. **先放先用**:新买的药放后面,旧药放前面;写购买/开封日期。
2. **每半年清点**:固定日期(如换季的 4 月/10 月)把药箱全部拿出来,查有效期,扔掉过期和变质的(变色、粘连、潮解、异味、液体浑浊)。
3. **过期药处理**(详见《02-家庭药箱配置指南》):投递到药店/社区回收点,或密封破坏后按"有害垃圾"投放;不要整盒原样丢弃,防止被转售误用。

## ⚠️ 常见误区

- **误区:OTC 是"保健品"一样随便吃的东西。** → 真相:OTC 也是药,过量同样有害(如对乙酰氨基酚过量可致肝损伤),必须按说明书剂量与次数使用。
- **误区:药盒好看、广告多、进口的才是好药。** → 真相:有无"国药准字"、是否对症、用法对不对,才是判断标准;同通用名的国产仿制药通过一致性评价后疗效有保障。
- **误区:"国药准字 B"或"食字号"的东西也是药。** → 真相:只有"国药准字 H/Z/S"等才是药品;消字号、健字号不能宣称治病。
- **误区:用茶、牛奶、果汁送药更"养胃"。** → 真相:送服首选温开水;这些饮品可能结合或破坏药物成分。
- **误区:药片太大不好咽,掰一半吃。** → 真相:缓释/控释/肠溶剂型掰开会破坏释放结构,造成药物突释或失效;先看说明书是否允许。
- **误区:忘了吃药,下顿吃两片补上。** → 真相:双倍剂量可能直接过量中毒;按"还远就补、就近就跳"处理。
- **误区:药放冰箱总没错。** → 真相:只有说明书要求冷处的药才冷藏;多数药在冰箱里反而受潮。
- **误区:药过期一两个月,看着没坏,吃了没事。** → 真相:过期药有效成分可能已降解、杂质可能升高,失效事小,变质伤身事大;坚决不吃。

- [ ] 学会看药盒 OTC 标识:红色甲类 / 绿色乙类 / 无标识可能是处方药
- [ ] 把最近吃的一种药的说明书拿出来,找到"适应症、用法用量、禁忌、不良反应、相互作用"五栏各读一遍
- [ ] 检查自己常用的送服方式:是不是温水?有没有用茶/奶/果汁送过药?
- [ ] 确认家中长辈是否在吃他汀类/降压药,提醒他们暂停吃西柚和柚子
- [ ] 给家里所有开封过的糖浆、眼药水写上开封日期
- [ ] 把药箱从卫生间/车里挪到阴凉干燥的固定位置
- [ ] 在手机日历里设一个"每半年清点药箱"的循环提醒
