# 02：STM32 与调试

## 当前硬件事实

基线工程是 STM32F103C8Tx，PC13 配为推挽输出，PB14 配为浮空输入，系统时钟使用 HSE + PLL 72 MHz。PC13 在很多 Blue Pill 板上是低电平点亮，但必须实测，不能假设。

## 当前两套工程

- `00-STM32硬件基线`：HAL + CubeMX，只用于确认 GPIO、EXTI、定时器、生成代码和下载链路。
- `01-STM32实时采集与设备控制器`：标准外设库，是 8 月作品主线。

两者共享硬件原理和调试方法，不复制库相关初始化代码。

## 8 月必须做到

- 能从 `.ioc` 找到芯片、引脚、时钟、工具链和外设配置。
- 能区分“编译失败、下载失败、引脚电平错误、接线错误、逻辑错误”。
- HAL 基线每次改 CubeMX 后，只在 `USER CODE BEGIN/END` 区域保留手写代码。
- 标准库项目能定位启动文件、中断入口、BSP/驱动、业务层和构建输出。
- 能测定时周期、采样计数、UART 错误和看门狗恢复，而不仅是“现象能跑”。

## 练习顺序

1. S00：HAL 基线完成 EXTI 事件模型和非阻塞心跳。
2. S01：标准库项目完成 UART 与固定周期任务表。
3. S02：完成一项真实采集和一项 PWM/设备输出。
4. S03：协议、错误码、看门狗和故障注入。
5. S04：测指标、冻结功能、发布项目一。

## 使用资料

芯片原理和手册使用 `R-STM-01`；HAL 基线参考 `R-STM-02`；视频只按 `R-STM-03` 指定分集；标准库项目以 `R-LOCAL-01` 为唯一源码起点。
