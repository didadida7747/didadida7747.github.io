## A. AI学习\（LLM/RL 入门线）

**定位**：从零搞懂大模型与强化学习原理（而非只会调 API），服务"与老师/课题组展开交流"的近景目标。

**推荐顺序（难度递增）**：
1. `强化学习基础速读.md` — agent/state/reward/policy/return 五词 + 交互闭环；读 RL 代码只盯 5 个位置（建环境、`reset()`、`step(action)`、选动作、参数更新）。
2. `大模型基础速读.md` — Transformer 六模块直觉（token、embedding、self-attention、Q/K/V、残差、LayerNorm），不推公式；明确列出"现阶段不要陷进去"的内容。
3. `多智能体强化学习速读.md` — MARL 三难点（非平稳性、观测/目标复杂、训练组织）+ CTDE 框架；`MAPPO`/`MADDPG`/`QMIX` 先混脸熟。
4. `LLM与RL代码实践指南.md` — 统一五步代码阅读法（入口→模型定义→数据输入→主训练循环→loss 与更新）；每次跑代码必须留运行记录。
5. `MLP手搓达标自测.md` — 达标线：不看模板 1 小时从零手写 PyTorch MLP 并解释每行；这是 PPO 讲解的前置门槛。
6. `PPO_CartPole逐行讲解.md`（最难，31KB）— 先读第 1-3 节全局（Actor 管决策、Critic 管估值、`clip` 限制更新幅度），跳过逐行部分；能独立跑通 RL 脚本后再精读 9.4（`ratio` 与 clip：advantage=2 时 ratio 被截到 1.2，不再奖励"推得更猛"）和 9.5（总损失 = 策略项 + 0.5×价值项 − 熵奖励）。
7. `两模型辩论项目实录.md` — 全库唯一"完整项目"级材料（CrewAI + uv，两模型辩论 + 裁判，成本 <0.1 元/场）；踩坑表（Git Bash、schannel 证书、Python 3.14 alpha、C 盘重定向）对 Windows 环境普遍有用；任何阶段可穿插读。
8. `第一小时视频清单.md` — 7 天视频排期（3Blue1Brown → David Silver → PettingZoo），看完只答既定问题，不刷推荐流。
9. `嵌入式AI转型路线图.md` — 大一暑期能力基线快照；核心判断"缺的不是知道更多，而是工程闭环、可验证成果"；AI 使用规范含三个可复用 prompt 模板（学习型/调试型/代码审查型）。

**自测**：
1. `loss.backward()` + `optimizer.step()` 是什么？——算梯度，再按梯度更新参数。
2. 为什么"每天不同、当天固定"的随机推荐用日期做种子？——同一天种子相同结果可复现，换天种子变序列全变。（这是辩论项目/知识站共用的 PRNG 思路）
3. PPO 的 clip 解决什么问题？——限制新策略偏离旧策略的幅度，防止单次更新过大破坏训练稳定。

## B. STM32工作流\（AI 协作工作流 + 排错检查单）

**定位**：Windows + STM32 + CubeMX + VS Code 的轻量 AI 协作系统；三条流：学习流、开发流（AI 草稿→人工审核→上板验证）、调试流（记录现象→AI 排查树→逐步验证→归档）。

| 文件 | 用途 |
|---|---|
| README.md | 三条工作流定义 + 每天最低 4 动作 |
| STM32学习路径.md | 9 主题顺序：启动流程→时钟树→GPIO→UART→定时器→中断→DMA→I2C/SPI→FreeRTOS，每主题五问 |
| 启动流程与main函数.md | 最详实一篇：`main()` 不是入口——向量表→MSP→`Reset_Handler`→`SystemInit()`→`.data/.bss` 初始化→main；5 类坑排查 |
| 中断模型知识卡.md | 30 秒读完：外设请求→NVIC 仲裁→ISR 尽量短；四误区（忘开 NVIC、清标志顺序、ISR 里打印、忘 `volatile`） |
| UART常见坑检查单.md | 串口五类场景排障；坑的沉淀格式（现象/复现/根因/修复/下次如何早发现） |
| 嵌入式AI提示词五件套.md | **实用价值最高**：排查/学习/读码/评审/写码五个模板，共同原则"先复述再动手、给最小验证动作、区分已验证和草稿" |
| 工具链检查清单.md | 六项必备工具 + 六条最小验证动作，新环境/换电脑时过一遍 |

**怎么读**：出 bug 先过检查单再问 AI；提示词五件套复制即用。当前战略下此库低频维护，但**提示词方法论对任何领域通用**。

## C. 嵌入式体系\（离开条件闸门制）

**定位**：纪律性最强的卡片库——每一步以"能独立交付什么"为离开条件，资源编号 `R-XX-NN` 精确到阶段，杜绝收藏式学习。

**结构**：README（总目录）→ 方法论 7 篇（能力地图、资源索引、AI 协作模板、作品集发布标准、简历与面试证据、实习指标与故障注入、技术取舍记录）→ 能力课程 7 门按依赖排序：

```
C工程化(01) → STM32与调试(02) → 通信与协议(03) → 实时系统与FreeRTOS(04)
→ Linux与C++(05) → ROS2与机器人(06) → AI与强化学习(07)
```

**关键卡片**：
- `嵌入式能力地图.md`：依赖链路 + 7 单元离开条件 + 寒假投递优先级（注意：写在旧嵌入式主线下，投递优先级已被 09-03 战略取代）。
- `作品集发布标准.md`：9 项硬清单（演示视频、测试、指标、已知限制等）——对任何方向的发布都适用。
- `简历与面试证据.md`：无实测数据前强制留空；写"设计并实现……测得……"而非"学了九个外设"。
- `实时系统与FreeRTOS.md`：先证明裸机实时性，满足三条件才准上 RTOS（典型的闸门思维）。
- `C工程化实习专项练习.md`：C01-C10 十道题（volatile、环形缓冲、GDB 等）。

**怎么读**：重新激活嵌入式方向时先读 README + 能力地图；平时抽`作品集发布标准`和`简历与面试证据`的方法论部分复用到新主线。
