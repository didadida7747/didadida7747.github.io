## A. 大学四年自我提升全景手册.md（顶层框架）

- **定位**：工科本科四年成长总纲；入学/新学期读一遍，每学期末复盘。
- **要点**：七板块三层——学业+能力+实践=硬实力，关系+身心+生活=支撑系统，方向=选桌能力；GPA 分档：不保研/出国则以"前 30%"为目标，但数据结构/OS/计网/计组/数据库/离散六门核心课无论如何学透；硬指标：大一结束 500+ 行项目 + 力扣 100-200 题；每学期 3 次当众发言、每月一篇千字文；竞赛/项目/科研/实习四类经历四年各至少一次；身心底线：每周 3 次运动、23:30 前睡 7h+；反面清单：绩点至上、社团过多、收藏=学会、熬夜式努力。
- **怎么读**：总框架、四年时间线、附录速查是必须通读的骨架；身心/生活/误区属查表型；每学期末只做"复盘五问"。
- **自测**：不保研时 GPA 目标多少、哪些课例外？——前 30%，六门核心课除外必须学透。

## B. 大学生向上社交行动手册.md（关系板块）

- **定位**：结识学长/研究生/从业者的操作手册；第一次开口前读，之后当模板查。
- **要点**：四字原则——先做再问、小步请求、执行反馈、长期守信；选"最接近你下一步的人"而非最厉害的人；20 秒自我介绍公式（身份+方向+已做过什么+为何联系）；好问题四部分（目标+已做尝试+具体卡点+请对方判断的一个选择），3-10 分钟能答；15 分钟线下交流流程表；被帮后四件事（24h 致谢、执行、反馈、保密）；30 天训练计划（第 1 周列 15 人证据包 → 第 2 周联系 3 位学长 → 第 3 周执行建议并反馈 → 第 4 周联系研究生/从业者）；量化：每周定制联系 2-3 人不群发、建议执行率 >70%、每周约 90 分钟固定投入。
- **怎么读**：第一、三、四节必须通读；第五节模板联系谁查谁；30 天计划和台账是执行期每周填的工具表。
- **自测**：消息没回复怎么办？——等 5-7 天补发一次，仍无回复停止，不跨平台围堵。

## C. 健身指导手册_从入门到进阶.md（身心板块）

- **定位**：从零到一年的完整指南；开始前通读前 3 章，之后按第 4 章阶段课表执行。
- **要点**：三铁律——渐进超负荷、动作质量大于重量、恢复是训练的一部分；四阶段：适应期（1-4 周，每周 3 次全身）→ 成长期（5-12 周，全身 A/B 交替 + **双重渐进法**：全部组达标次数上限就加重最小一档）→ 分化期（3-6 个月，每周 4 次上下分化，毕业标准卧推/深蹲/硬拉 ≈ 体重 0.75/1.0/1.25 倍）→ 进阶期（6 个月后推拉腿）；饮食：蛋白质 1.5-2.0g/kg/天，增肌盈余 200-500 kcal/月涨 0.5-1kg，减脂缺口 300-500 kcal/周掉 0.5-1kg 且必须保力量训练；安全：大重量必须有保护、关节尖锐痛立即停、新手不用腰带、肌酸每天 3-5g；一个计划至少执行 8-12 周再评估。
- **怎么读**：第 1-3 章开始前通读；第 4 章课表每周照抄；6-9 章遇问题查。
- **自测**：双重渐进法是什么？——所有组标准完成次数上限时，下次加重最小一档（哑铃 1-2kg、杠铃 2.5-5kg），次数回落下限重爬。

## D. 英语听说能力12周提升计划.md（语言技能）

- **定位**：为"哑巴英语"型高分考生定制；不重学单词语法，直接建"文字→声音→表达"通道。
- **要点**：第 0 天 30 分钟基线（盲听+听写+录音），选材"无字幕理解 50%-70%"最合适；标准 30 分钟配比：精听 40% / 影子跟读 20% / 复述 20% / 词块 10% / 泛听 10%；12 周路线：辨音意群 → 60 秒复述 → 真实语速（BBC）→ 3 秒开口 → 第 8 周首次 10-15 分钟交流 → 第 12 周复测；**最低规则：每周至少 4 次训练、其中 3 次开口录音**；连续两天忙做 10 分钟保底不补债；词块间隔复习（当天/次日/第 3 天/第 7 天）累计 30-50 个个人高频词块；保留第 0/4/8/12 周录音作对照。
- **怎么读**：第一、二节开始前必须通读；路线图和周模板打印每周对照；救场句型卡壳时查。
- **自测**：每周最低承诺？——4 次训练、3 次开口录音，只听不说不算完整训练。

## E. 投资与金融素养入门计划.md（财务素养）

- **定位**：零经验 8 周入门（每周 2-3 小时），目标是看懂产品和风险，**不以赚钱为验收**。
- **要点**：先立 8 条边界（学费生活费不投资、不借钱不用杠杆、"保本高收益"按骗局处理）；8 周流程：认识产品→学会软件→读基金→读公司→估值波动→模拟决策→总结；产出全是模板卡（资金边界、产品比较表、基金阅读卡、公司观察卡）；**产品分析五问**：收益来源—主要风险—持有期限—退出方式—费用；软件三阶段（只看→记录→虚拟模拟）；验收：8 概念 + 3 比较 + 2 基金卡 + 1 公司卡 + 4 周记录 + 5 种骗局话术；红线：不碰杠杆/荐股群/排行榜追涨。
- **怎么读**：启动前通读边界和能力标准；之后每周只读当周内容；模板卡是每周填写的工具。
- **自测**：五问是什么？第 1 周产出？——收益来源/风险/期限/退出/费用；《我的资金边界》。

## F. 黑客松与可交付项目增收行动指南.md（实践增收）

- **定位**：12 周增收与项目计划（**2026-08-17 至 11-08**），回答"能否靠黑客松赚钱"。
- **TL;DR**：黑客松不是稳定副业，是"有奖金上行空间的项目加速器"；收入三层：底层每周推进可复用项目、中层小额技术交付、上层选择性参赛。**现金目标 0 元也算合格，验收的是项目底座 v1.0 本身**。
- **要点**：普通周 ≤8h（原理 3+实现 3+测试文档 1.5+筛选 0.5）；时间边界：赛前定制 ≤12h、比赛本体 ≤36h、赛后整理 ≤6h；首场自费上限 300 元；两个决策公式（现金期望值、综合价值，四个复用问题 <3 个"是"不参加）；赛事评分 `总分=6M+5R+4D+3C+2T`，75-100 可参加、60-74 仅当总准备 ≤12h、<60 放弃；项目底座：STM32 采集+串口协议（序号/CRC/超时）+状态机+ROS2 bridge；**注意：底座是嵌入式方向，09-03 战略切换后需复评是否沿用**；小额交付报价 = 工时×50 元/h + 实报 + 20% 余量，付款 30/40/30 三节点，不接代写；36 小时比赛流程表（0-2h 冻结问题 → 2-8h 骨架 → … → 28-34h 演示 3 分钟）。
- **怎么读**：决定做不做通读第一至三节；第五节筛赛事用；第六、七节是执行主轴每周对照；第十节接单前必读。
- **自测**：普通周 8 小时怎么分？现金目标多少？——3+3+1.5+0.5；0 元合格，验收 v1.0 底座 + 20 次有意义提交 + 3 类故障注入 + 一人成功复现。

## G. 联想拯救者电脑保养手册.md（工具维护）

- **定位**：用了约 1 年的拯救者保养指南；看到当天先做"首次保养清单"。
- **要点**：8 原则（硬桌面、高负载接原装电源出风口 10cm 无遮挡、不长期用到 0%、不装第三方管家、BIOS 更新期间绝不断电、重要文件两份备份）；C 盘保留 15%-20% 可用、最低不低于 30GB；电池养护模式限 55%-80% 属正常，**不需要每月深度放电**；Fn+Q 按场景选性能模式；保养日历：每天观察 1 分钟/每周重启+备份/每月更新+检测/每 2-3 月外部清洁/每 6-12 月温度对比；**内部清灰 12-18 个月一次交官方售后**，不按年份强制换硅脂（可能含相变材料/液金）；立即送修信号：电池鼓包、风扇异响、频繁蓝屏、进水（立即断电不用米吸）。
- **怎么读**：首次通读第一、二节执行清单；第五节时间表打印贴墙；第七节异常时查。
- **自测**：长期插电怎么保护电池？——开养护模式（55%-80% 正常），不要每月深度放电。

## H. LEARNING.md + HANDOFF.md（个人知识站双文档）

两者分工：**LEARNING 是"为什么"（原理书），HANDOFF 是"怎么干"（操作手册）**，互相引用。

### LEARNING.md
- **定位**：知识站（VitePress）开发全复盘，写给"假设只记得基础语法的未来的自己"。
- **TL;DR**：记录把十几篇笔记改造成带星空 Canvas、每日知识点、闯关游戏的知识站全过程：技术栈选型理由、架构与数据流、5 段核心代码精读、13 个踩坑记录，外加罕见的 Prompt 复盘（点评 12 条提示词提炼 5 原则）。
- **要点**：
  - 技术栈：VitePress + Vue 3 SFC + localStorage + Canvas。
  - 每日知识点机制：日期字符串做种子，FNV 哈希 + xorshift 伪随机，30 条抽 10 条——"每天不同、当天固定"。
  - **"如果只记三条"**：① 构建期没有浏览器（`window/localStorage` 只能进 `onMounted`）；② 别猜框架内部（以真实 DOM 和产物为准）；③ 验证环境会骗人（缓存/异步挂载/节流，先怀疑观察再怀疑代码）。
  - 最大返工：工程目录必须在**工作区根目录**（Vite 向上找 node_modules，套子目录导致 `vue/server-renderer` 解析失败）。
  - 反教科书结论：平滑滚动用 `setInterval(16ms)` 而非 rAF（后台标签页 rAF 被节流）。
  - Prompt 复盘五原则：需求带参照物和动机；纠偏用"不是 X 而是 Y"；约束+许可+兜底一起给；多需求编号分级；范围切割控制成本。
- **怎么读**：开发前按 HANDOFF 要求先读第 4 节 13 坑；想懂原理/排查 bug 读第 2、3 节；写提示词没头绪读第 7 节。
- **自测**：为什么读 localStorage 的代码必须包在 `onMounted` 里？——VitePress 构建期在 Node 环境预渲染，没有浏览器 API，顶层访问直接崩溃。

### HANDOFF.md
- **定位**：站点交接与二次开发指南，"不读完全部代码也能安全改站"；任何要动站点的场合先通读（仅 106 行）。
- **要点**：站点已上线 https://didadida7747.github.io/（push 到 main 自动部署）；命令就三条（`npm run dev` 写笔记 / `npm run rebuild` 杀旧预览再构建 / `npm run build` 只出产物）；**隐私红线：`资料库` 含真实姓名/手机号/校名的文件永不拷入站点，拷贝前先 grep**；六条硬规则首条最致命（主题代码里浏览器全局对象绝不出现在模块顶层）；文件地图含导航/侧边栏/主题组件的改法；第 7 节有可直接复制的新对话开场模板。
- **怎么读**：加内容看第 3 节，改功能查第 5 节，动手前背第 4 节硬规则。

**注意**：LEARNING.md 第 5、6 节的"待办"（git init、错题本、部署）已被 HANDOFF 确认完成，视为历史快照；HANDOFF 内部 09-03 与 09-05 两层描述（深色星空 → 浅色扁平主色 `#2f4fe0`），以新日期行为准。
