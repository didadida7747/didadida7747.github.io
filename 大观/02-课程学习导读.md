## A. SI100+（上科大计算机科学导论 2026 夏）

### SI100+ 2026夏合集_大二学生学习文档.md
- **定位**：18 集视频（约 15.5 小时）的"地图+教练"，按大二处境重排了优先级。
- **TL;DR**：合集重排成三条线——入门线（会不会）、成长线（怎么走）、心法线（怎么学）。知识课部分大二只需补漏（搜索方法论、Python 细节坑），真正的大二价值在经验分享：curve 给分、培养方案重排、进组时机、AI 使用边界。
- **要点**：
  - 上科大规则：一年三学期；A 档上限 40%、curve=按排名取前 40%，少数课绝对分且"老师不捞人"；挂科重修前按 0 分计 GPA；三轮选课；六大去向保研率 40%+；评优 = 75% GPA + 10% 综合 + 15% 创新。
  - **培养方案（大二必看）**：143 学分是下限不是上限；课程三分法（推免前必修 / 高阶课前 3 年修掉 / 通识放大四）；**推荐课表太保守**——第一门高阶课大三上才开始，与"论文写一年 + 推免大三暑假"冲突；重排原则：先修链不变、每学期 ≤24 分、专业课 ≤4 门、给科研留大块时间；概率论大二上务必修掉。
  - Python 坑：`0.1+0.2 != 0.3`（IEEE 754）、`//` 向下取整、`int(-5.9)=-5`、input 永远返回 str、**边遍历边修改列表导致 7 被跳过**、elif 命中即停、单元素元组要加逗号。
  - AI 时代素养："卡住才是作业里最有价值的部分"；学的四层次（结果→为什么→迁移→**判断**）；"可以把答案外包，永远无法将思考外包"；**课程作业用 AI = 把思考外包，个人项目放胆用**。
  - 荣誉班：GPA 3.5 斩杀线；核心结论——"专业课前移"模式普通 CS 可直接抄，不必付斩杀线代价。
  - 科研：仅 5.5% 本科生有一作；进组前打听人品；杂活是入场券但设止损；"护城河是能对 AI 产出做判断"。
  - 整理者指出的合集盲区：学术英语写作、算法深度、心理健康。
- **怎么读**：开学初和每学期选课前通读第一、三章 + 第四章行动线；Python 部分当字典查漏。
- **自测**：
  1. curve 下为什么"从 B+ 挤进 A-"比"A- 挤进 A"回报大？——3.3→3.7 跨档收益巨大；A- 与 A 同档，零和内卷无增量。
  2. `0.1+0.2==0.3` 为 False 的根因与解法？——IEEE 754 无法精确表示；四舍五入或 `decimal.Decimal`。
  3. 遍历列表时 `remove` 为什么跳过元素？——删除致后续前移、迭代索引错位。

## B. 科协暑培 2026 合集（清华科协 13 讲）

- **定位**：工程线 + AI 线 + Cyber 线 + 科研线的全景导览，附逐集时间戳与 500 行勘误表。
- **TL;DR**：把 13 讲组织成四条线并按"大二、会 C/Python、开学前"校准出精看（第 7、8 讲 + 科研两讲，约 4.5h）、略读、可跳过三档。三条主线：工具链正被 AI 重写、AI 技术"数学建模/架构/数据/benchmark"四层范式、人与 AI 的分工边界。
- **要点**：
  - 第 1-2 讲：信息检索三渠道；Linux 四件套（man/tldr、环境变量、tmux、SSH）；**agent loop = ReAct 循环**，上下文三板斧 **compact / sub-agent / file-based memory（CLAUDE.md）**。
  - 第 3-4 讲：前端四层地图、页面=状态、六要素 prompt 模板；REST、中间件洋葱模型、JWT、Redis、Docker、CI/CD。
  - 第 5-6 讲：四层分析框架；Roofline 推出 batch size ≥(总参/激活参)×(flops/带宽)，"显卡与模型严重不适配"。
  - **第 7 讲（精看）**：预训练→中训练→后训练；SFT/PPO/GRPO 对比（GRPO 无 value model、组内相对奖励）；"数据、算法、Infra 三要素，算法越来越不是瓶颈"。
  - **第 8 讲（精看）**：Claude Code 泄露版源码——五层结构、query loop、约 90% 上下文阈值触发 auto compact。
  - 第 9-10 讲（寒假探测）：VAE→DDPM→DDIM→Flow Matching→DiT→Sora；具身智能 VLA、行为克隆两坑、diffusion policy。
  - **科研两讲（精看）**：进组=一封邮件、实验不 work 列 assumption 做 ablation、1-2 天一次对齐频率；第一篇论文的真实坎坷。
- **怎么读**：开学前读总纲定计划；精看第 7、8 讲与科研两讲；其余用蒸馏笔记替代重看；第 9/10/11 讲留寒假。回看视频报错先查文末勘误表。
- **自测**：
  1. compact、sub-agent、file-based memory 各解决什么？——压缩历史、并行探索分摊上下文、跨会话持久记忆。
  2. GRPO 砍掉了什么、靠什么给信号？——砍 value model，组内相对奖励加权。
  3. DDIM 为什么不用改训练就能跳步？——训练损失不依赖马尔可夫性，σ=0 时路径确定。

## C. 生成式软件工程 2026 秋（南大新课）

- **定位**：不是领域知识而是**元技能**——怎么与 AI 共事、怎么问、怎么验证。
- **TL;DR**：第一讲是"诊断书"（三个空间：intention→specification→implementation 段段有 gap，模型被训成 reward hacker）；第二讲是"处方笺"（上下文工程：好 prompt = 完整 spec + 可验证 verifier）。两讲关系即诊断 + 处方。
- **要点**：
  - **零分简历批判**：没有 GitHub/主页/preprint 的"完美简历"=零分；可验证的真东西 > 漂亮包装。
  - **上下文的真身**：system prompt、AGENTS.md（当 memory）、skills 索引按需加载、工具定义、对话历史、环境注入；"每句话加个喵"是检测上下文截断的 canary。
  - **verifier 是杠杆**：可验证 → agent 不计代价迭代到完成；不可验证 → 用"切块 + subagent"算力换智力。
  - **读论文对齐法**：逻辑自洽文本污染注意力极强；先声明自己知识水平、用已学概念重构增量，再读论文。
  - 行动线：装 agent + API、建简历三件套（GitHub/主页/AGENTS.md）。
- **怎么读**：按"时间预算三选一"——完整 3.2h / 核心 1.5h（第二讲全程 + 第一讲 1:24:35 起）/ 极速 40min（只读文档 + 四段时间戳）。编者思考的"行动线"和"缺口"两类逐条照做。
- **自测**：
  1. "三个空间"是什么？为何需求段杠杆最大？——intention/specification/implementation；上游 spec 错则整体错，模型补不了 intent→spec gap。
  2. 怎么判断给 agent 的任务有没有"模拟器"？——任务内嵌 verifier（测试、跑通标准）；不可验证即漂移。
  3. 直接把论文丢给 AI 总结为什么危险？——注意力被作者逻辑污染；先对齐再重构增量。

## D. 计算机组成原理_全景导学笔记.md

- **定位**：B 站《计组大观》整理的导学笔记，覆盖 408 计组全部章节，兼作期末复习与考研一轮导学。
- **TL;DR**：全课挂一句总纲"计算机如何执行指令？如何高效地执行指令？"；核心学习观"计算机是人设计的，没有黑科技"——每个机制都问"为什么需要它"，推得出的结论不用背。
- **要点**：
  - 补码的钟表模型：省掉一整套减法电路，CPU 只留加法器（化归思想贯穿全课）。
  - 存储金字塔：速度/容量/价格不可兼得；Cache 三大问题（映射、替换、一致性）；**虚拟存储不在金字塔里**——它是 OS+硬件营造的抽象。
  - CPU 四代演进：单总线多周期 → 单周期（快但被最慢指令拖累、现实不可行）→ 多周期 → 五段流水线；三类冒险（结构/数据/控制）与转发、分支预测；**流水线提升吞吐率而非单条延迟**。
  - 轮询→中断→DMA 演进 = CPU 时间越来越贵，不断把"等外设"剥离出去；中断是计组与 OS 的枢纽概念。
  - 四条暗线：抽象与层次、trade-off、问题驱动演进、化归。
  - 考情：2026 真题考单周期 CPU 数据通路（袁春风教材原图级）——只刷辅导书不看教材会吃亏。
- **怎么读**：开课前读第一、二节建框架；每章开课对照第三节；学完做"回填"+ 画三张图（存储金字塔、流水线时空图、指令四周期）。
- **自测**：
  1. 用硬件成本解释补码价值？——减法复用加法器，省一套减法电路。
  2. 单周期 CPU 为何现实不可行？——时钟迁就最慢访存指令，快指令陪跑。
  3. 虚拟存储为何不在金字塔里？——不是物理硬件，是抽象。

## 难度梯度与总路线
