# 技术取舍

## 标准库与 HAL

现有综合项目已基于标准外设库积累阶段代码；HAL 基线工程已证明 CubeMX/HAL 使用能力。为了在 2026-08-30 前完成可测系统，V1.0 保留标准库，不进行全面 HAL 移植。

可复用的是状态机、协议、错误码、测试方法和纯 C 算法；不可直接复用的是初始化函数、头文件依赖、中断入口和板级配置。

## FreeRTOS

FreeRTOS 是加分项，不是 V1.0 发布阻塞项。只有裸机任务表已写清周期、共享数据和最坏执行时间后才接入；否则在 `_能力实验/FreeRTOS最小实验` 完成队列、互斥和 ISR 交互证据。

## 电机、编码器与 PID

项目当前硬件重点是环境采集和设备输出，不声称完成闭环电机控制。有编码器和驱动器后可添加控制分支；此前用周期、PWM、协议、故障恢复和指标构成真实证据。
