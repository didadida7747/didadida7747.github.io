### B 站辨别标准（三看）
1. 看播放/日期比：老视频播放高只能说明它火过，新视频（3 个月内）才可能讲当前版本；
2. 看简介区：放 GitHub 链接、参考文章链接的 UP 主，通常更扎实；
3. 看评论区置顶：愿意承认视频里讲错并修正的 UP 主，长期关注价值高。

## 二、抖音 / 小红书：用搜索词捞真金

这两个平台的 CC 内容以切片/图文为主，直接给清单意义不大（时效极差），给**搜索词策略**和**筛选器**更有用。

### 搜索词（由泛到精，窄词信噪比更高）

1. `Claude Code 教程`、`Claude Code 安装` —— 入门最多，也最容易撞上课贩子
2. `Claude Code 源码`、`Claude Code 原理` —— B 站深度内容的切片搬运入口
3. `vibe coding 氛围编程` —— 概念+踩坑复盘
4. `AI编程 复盘`、`我用AI做了一个App` —— 真实项目记录（比"教程"更像亲手做过的人）
5. `CLAUDE.md`、`上下文工程` —— **极窄词，命中即高手**（用这个词的人大概率有一线经验）
6. `agent 工作流`、`多智能体 协作` —— 原理向
7. `Cursor 对比 Claude Code` —— 对比实测通常比单吹信息量大

### 筛选器：五步判断一条内容值不值得看完

1. **有凭据吗？** BV 号、GitHub 链接、报错截图、token 账单——有"失败过程"的复盘 > 全绿截图
2. **评论区质量**：技术追问多且作者接得住 = 真用过的概率高；清一色"求私/带带" = 快跑
3. **引流信号**：标题带"变现/月入/99%的人不知道"、正文导向"资料包/训练营" = 课贩子
4. **交叉验证**：拿它的说法对照 Anthropic 官方 best practices 或宝玉译文，官方完全没提又讲得玄乎的多半是编的
5. **形态偏好**：小红书收藏"图文长笔记"（步骤可复核），抖音看"实操录屏"（过程可见），口播视频慎入

## 四、一个反向建议

国内平台内容有个系统性偏差：**讲"怎么装、怎么用"的多，讲"为什么这样设计"的少**。所以本库的分工是：中文平台给你直觉和社区温度，01/02/03 章给你设计层的深度，两者缺一不可。刷到好内容别只收藏——回到对应章节补原理，才算真正吃下。
