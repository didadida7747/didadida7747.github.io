# 精华卡 · Linux 学习指南

> WSL2 + Ubuntu 24.04 的 15 章"面对面讲"式讲义，12 周从零到能用 Docker 部署项目 ｜ 提炼：2026-10-25 ｜ 底稿：该分类 24 篇（含调研工作稿）

## 30 秒用法
- 想系统学：读 00 章定路线 → 从 01 章顺序读到 15 章，每章练习亲手敲完再进下一章；视频只是卡点时的救火队员，不是主课。
- 只想先把环境装好：直接做第 2 章，约 1-2 小时装好 WSL2 + Ubuntu 24.04。
- 报错急救翻第 15 章；找官方文档/书籍/练习站开资料推荐合集；想先看全程地图双击学习路线图.html。

## 核心结论
1. 路线是 12 周三阶段（入门 1-4 周 / 进阶 5-8 周 / 实战 9-12 周），每阶段有硬验收：阶段一独立完成"建目录树→查找→打包→备份"，阶段三用一条 docker compose up -d 把含数据库/反代的 Web 应用跑起来（00-学习路线与使用说明.md）。
2. 环境选 WSL2 而非双系统/虚拟机：微软官方方案、跑真 Linux 内核、与 Windows 无缝集成；一条 wsl --install 装好，Ubuntu 里开启 systemd、apt 换清华源（02-WSL2安装配置指南.md）。
3. 第 2 章预先收集了三个经典报错：0x800701bc、0x80370102、忘记密码，卡住直接对号入座（02-WSL2安装配置指南.md）。
4. 学习方式定为"文档驱动"：主线是 01-15 章讲义，配套资料里文档排前（官方手册、MIT 缺失的一课、TLCL、鸟哥），视频只在反复看不懂时选看（README.md）。
5. 排错五步法：完整读报错原文→看日志→最小复现→二分定位→记录；command not found / Permission denied / Address already in use 等关键词可直接跳对应小节（15-常见问题排查手册.md）。
6. 资料推荐合集收 90 余条经 2026-10-13 实际检索核实的资料，按"文档与动手为主线"组织，含 OverTheWire Bandit、Linux Journey、Killercoda 练习站与云学生机（资料推荐合集.md）。
7. 本指南有意不覆盖：嵌入式 Linux/驱动/内核裁剪、桌面美化替代 Windows、Kubernetes 运维进阶（README.md）。

- 全部命令在 Ubuntu 24.04 (WSL2) 下核对；外部链接核实于 2026-10-13，个别失效按资料名在对应平台搜索即可（README.md 学习约定）。
