# 05 · 安全与合规指南（合理使用的核心）

> 一句话：**篡改猴本身是干净的工具，风险 100% 来自你安装的脚本。** 本文件解决两个问题：怎么识别恶意脚本；怎么用才合法合规。

## 一、脚本的权限从哪来：看懂元数据头部

在 Greasy Fork 点"安装"后跳转的审查页，或在管理面板点开任意脚本，最上方的注释块就是权限声明。重点看这几项：

| 字段 | 含义 | 危险信号 |
|---|---|---|
| `@match` / `@include` | 脚本在哪些网站运行 | 一个"视频下载"脚本却匹配 `*://*/*`（所有网站），尤其匹配网银、邮箱、社交、支付、学校认证系统 |
| `@connect` | 允许 GM_xmlhttpRequest 跨域访问的域名 | 出现与功能无关的陌生域名、短链域名、`*`（允许所有域名） |
| `@require` | 运行前加载的外部 JS（CDN 库、第三方代码） | 引用陌生域名上的 js、非固定版本 URL（远程代码随时可以被换成恶意版本） |
| `@grant` | 申请的特殊 API | 用不到 `GM_xmlhttpRequest`、`GM_download`、`GM_setValue` 却申请了 |
| `@resource` | 预加载外部资源 | 陌生 URL 资源 |
| `@run-at document-start` | 在页面所有脚本之前最早执行 | 配合全局匹配时风险加倍 |
| `@antifeature` | 作者自曝的"附加行为"（如 ads、tracking、referral-link 返利） | 不看就装等于默认接受返利/广告植入 |

## 二、恶意脚本常见套路（对照检查）

1. **权限与功能不符**：号称"视频解析"，却 `@match` 全部网站、`@connect` 一堆域名。
2. **动态执行远程代码**：脚本本体很短，但运行时 `eval` / `Function()` / 插入 `<script src>` 加载外部地址的代码——这是 Greasy Fork 明确禁止的行为，看到即可判定高危。2025 年油猴中文网曝光的 **"FCQ 木马脚本"**即属此类，它没有在 Greasy Fork 发布，只在镜像站和其他市场传播。
3. **数据外发**：把页面里的 Cookie、localStorage、表单数据（含账号密码）通过 `GM_xmlhttpRequest` 或图片请求发到外部服务器。
4. **混淆代码**：一大段十六进制/base64/Unicode 转义堆砌、变量名全是 `_0x1a2b`——Greasy Fork 禁止混淆代码，混淆即有鬼。
5. **劫持返利/钓鱼**：在淘宝、京东、外卖链接中偷换推广参数；或在页面注入假登录框。
6. **大杂烩搬运**：功能列表写得天花乱坠，实为抄袭多个开源脚本再植入私货，更新即投毒，且难以审计。

> 学术界的系统研究证实过风险规模：《Monkey-in-the-Browser: Malware and Vulnerabilities in Augmented Browsing Script Markets》（ASIACCS 2014）发现了数十个恶意脚本和数千个有可被利用漏洞的良性脚本，其中 58 个严重到可绕过同源策略窃取用户数据。论文：https://securitee.org/files/monkey_asiaccs2014.pdf

## 三、安装前 60 秒审查清单（建议照做）

- [ ] 来源是否为 Greasy Fork / GitHub 正规项目 / 官方渠道？（不明网盘、QQ 群文件、镜像站"独家" = 不装）
- [ ] 安装量、评分、评论数、最近更新时间是否可信？
- [ ] 作者是否有其他长期维护的脚本/项目？
- [ ] `@match` 范围是否与功能匹配？
- [ ] 有没有 `@require` / `@connect` 指向陌生域名？
- [ ] 代码是否公开、无混淆、能搜到关键动作（搜 `eval`、`Function(`、`innerHTML`、`cookie`、`GM_xmlhttpRequest`、`http://` 等关键词）？
- [ ] 页面底部有无 Antifeature 声明（返利、广告）？
- [ ] 装完第一次使用时，篡改猴弹出跨域授权框，域名是否与功能一致？**不认识就点拒绝。**

看不懂代码时的简化策略：**只装高安装量 + 高评分 + 近一年更新 + 作者可信的脚本，数量控制在 10 个以内**——能规避 99% 的风险。

## 四、安装后的防护设置

1. **配置黑名单**（见 [02](/01-电脑与工具链/篡改猴Tampermonkey使用指南/02-安装与初始化配置)）：银行/支付、学校统一认证与教务、邮箱、内网系统一律禁止脚本运行。
2. **保持自动更新开启**：恶意脚本被举报下架后，Greasy Fork 会在更新时同步从你的浏览器移除。
3. **敏感操作时用干净环境**：进行网银操作、输密码、填身份证信息时，可在无痕窗口使用（默认禁用扩展），或临时关闭篡改猴。
4. **不用全局脚本装功能**：能用网站专用脚本就别用全局脚本。
5. **定期审查**：每月打开管理面板，检查是否还认识每个脚本、是否仍需要。
6. **备份与审计**：导出 Zip 备份；发现异常（浏览器变卡、网站自动跳转、账号异地登录）时，先停用全部脚本再逐个排查。

## 五、Greasy Fork 平台安全机制（了解即可）

- 脚本代码必须公开，禁止混淆和压缩；
- 有自动化静态检查、代码格式策略；
- 社区举报 → 管理员人工审查 → 下架 → 推送删除；
- 但**不做**逐个人工审计和沙箱试跑，所以最终把关人是用户自己。
- 脚本猫文档同样给出官方建议：只从可信站点安装、查看评分评论、理解权限要求、拒绝不明来源文件。
- 参考：https://lintedcode.com/is-greasy-fork-safe-what-users-need-to-know/

## 六、合规红线：哪些事不该做

"合理使用"不只是安全问题，还涉及法律、平台规则和校纪。

### 1. 著作权与付费内容（法律风险）

- ❌ **VIP 视频解析、付费影视下载、付费音乐下载、盗版图书/课程下载**：绕过付费墙获取受版权保护的内容，侵犯信息网络传播权；提供这类功能的脚本本身也多被权利人投诉下架。
- ❌ 把下载的视频、音乐、文章二次上传传播。
- ✅ 正当边界：下载**你自己发布的内容**、明确标注 CC/可下载授权的内容、平台条款允许的离线缓存；做字幕翻译供自己学习、给公开网页做笔记与排版增强。

### 2. 学术诚信（与你直接相关，重点）

- ❌ 用脚本刷网课时长、自动答题、代看视频：属于代学/课程作弊，平台有行为日志检测，学校按课程考核与学生纪律规定处理，后果包括成绩清零、记过等。
- ❌ 用脚本批量下载论文再转交他人、在考试中用脚本访问题库。
- ✅ 正当边界：用脚本管理你自己的学习流程、做网页阅读增强、看合法回放时调节倍速、整理公开文献的引用信息。

### 3. 平台服务协议与账号安全

- ❌ 批量自动签到、抢购、爬虫式采集、批量私信、自动养号：几乎所有平台协议禁止，触发风控会导致**封号**；情节严重的还可能涉及不正当竞争或破坏计算机信息系统。
- ❌ 破解网盘限速、伪造会员身份、破解软件付费验证。
- ✅ 对自己的账号做页面级增强（排版、快捷键、筛选）。

### 4. 数据与他人权益

- ❌ 用脚本抓取、兜售他人个人信息；
- ❌ 把夹带返利劫持的脚本推荐给别人；
- ✅ 给自己浏览的网页做个性化改造，不影响他人。

### 5. 一个好判断标准

问自己三个问题：
1. **这个功能是不是在"我本来就有权看的内容"上改善体验？** 是 → 基本合理；
2. **如果网站运营方看到这段操作，会判定为正常使用还是攻击/白嫖？** 后者 → 别做；
3. **脚本申请的权限和它声称的功能对得上吗？** 对不上 → 不装。

## 七、出事后的应急处理

1. 立即在扩展管理页**停用篡改猴**（所有脚本随之停止）；
2. 打开管理面板，按最近安装时间倒序，逐个禁用排查；
3. 确认恶意脚本后卸载，并在 Greasy Fork/对应市场**举报**；
4. 若已输入过敏感信息：修改相关网站密码（从干净浏览器/官方客户端操作）、检查账号登录记录与授权应用；
5. 浏览器全盘扫描恶意扩展，必要时重置浏览器。
