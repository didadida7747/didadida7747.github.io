# 03 · OpenCode 与 Codex CLI：平台化与沙箱两条路

> 这两家放一篇，因为它们各代表一个"非典型"方向：OpenCode 把 Agent 做成平台，Codex 把"安全执行"做成信仰。篇幅从简，重点看两个独特设计。

## 一、OpenCode（sst/opencode）：Agent 的 client/server 分离

### 架构

```
┌──────────┐   ┌──────────┐   ┌──────────┐
│ 终端 TUI  │   │ IDE 插件  │   │ 你自己写的 │     ← 多客户端
└────┬─────┘   └────┬─────┘   └────┬─────┘
     └──────────────┼──────────────┘
                    ▼
            ┌──────────────┐      ┌─────────────┐
            │  headless    │ ───► │ 各家模型 API  │
            │  server(核心) │      │ (provider 抽象)│
            └──────────────┘      └─────────────┘
             会话/工具/权限/LSP 都在这层
```

### 三个值得偷的设计

1. **核心无头化**：Agent 内核是一个常驻 server，会话状态、工具执行全在里面。终端只是个视图。→ 换 UI（TUI/IDE/Web）不用重写内核；会话可以远程恢复。Claude Code 后来的"CLI+扩展共享内核"证明这是对的。
2. **Provider 抽象层**：模型是配置项不是绑定项（CC 长期绑定 Anthropic 模型，OpenCode 天生多供应商+故障切换）。当模型能力趋同，**harness 的可移植性成为竞争点**——这是 2025-2026 年明显的行业趋势。
3. **LSP 当工具**：把语言服务器协议（跳转/引用/诊断）暴露给模型。模型不再靠 grep 猜"这个函数在哪被用了"，直接问 LSP。**给模型接"确定的索引"优于让它"概率地搜索"**——这个思路对所有代码 Agent 都适用。

### 代价（思考题的答案预告）

server 常驻带来进程管理、状态同步、版本兼容的复杂度；单机场景下"启动一个 server"的仪式感也增加了上手成本。**平台化是一笔"先付成本、后收利息"的架构投资。**

## 二、Codex CLI（openai/codex）：把沙箱做成第一公民

### 1. OS 级沙箱，不靠提示词求饶

- macOS：Seatbelt（`sandbox-exec`）——文件系统写白名单、网络默认禁；
- Linux：Landlock + seccomp——内核级限制系统调用和文件访问。

执行 shell 时进程跑在沙箱里，越界的写/网直接被内核拦下。对比 CC 的"权限门+沙箱可选项"，Codex 把沙箱做成了默认路径。

【为什么值得单独学】Agent 的终极形态是"无人值守跑长任务"（2026 年各家都在做的 background agent），而无人值守的前提就是**执行环境可控**。看 Codex 的沙箱配置（approval modes + sandbox 模式的组合矩阵），等于看"怎么让组织敢让 Agent 无人值守"的答案卷。

### 2. AGENTS.md：把项目说明书标准化

Codex 与多家工具共同推动 `AGENTS.md` 作为跨工具标准（Claude Code 也兼容读取）。内容约定：构建命令、测试方式、代码规范、目录导览。

【为什么标准化重要】团队里有人用 CC 有人用 Codex 有人用 Cursor，一个 AGENTS.md 全覆盖 = 项目知识只写一遍。**当多个 Agent 工具抢市场时，受益的是"开放标准"的使用者**——这是你选型时该利用的格局。

### 3. Rust 单二进制

启动快、零依赖、好分发。看似小事，但 CLI 工具的"秒开"直接影响用户会不会高频使用它——**工具的形态（CLI/IDE/云）会反过来塑造使用模式**。

## 三、一句话总结四家

- 学**循环与上下文** → Claude Code（理念）+ Gemini CLI（代码）
- 学**协议与打磨** → Aider（edit format + repo map + benchmark）
- 学**平台化** → OpenCode（client/server + provider 抽象 + LSP）
- 学**安全执行** → Codex CLI（OS 沙箱 + AGENTS.md 标准）

四家读完，你自己造 Agent 时的每个零件都有两三个"已验证的实现"可以抄。
