# 第5章 查看与编辑文件

> 本章教你两件事：怎么在终端里"看"一个文件（包括在几百兆的日志里找一句话），以及怎么"改"一个文件。重定向和管道是本章的灵魂，学会它们你才算真正入门 Shell。

## 本章你将学会

- 用 `echo` / `cat` / `less` / `head` / `tail` 查看文件内容
- 理解标准输入 / 标准输出 / 标准错误三条流
- 用 `>` `>>` `2>` `&>` 重定向，用 `|` 管道把命令串起来
- 用 `grep` 在一堆文本里搜关键词
- 用 `cut` / `sort` / `uniq` / `wc` / `tr` / `tee` / `xargs` 做简单文本处理
- 用 `sed` 做替换、用 `awk` 按列取数（点到为止）
- 会用 `nano` 改文件
- 掌握 Vim 的最小可用集（能编辑、能保存、能退出）

## 5.1 echo 和 printf —— 输出点东西

`echo` 你第 1 章就用过了，就是把后面的内容打印出来：

```bash
$ echo "hello"
hello
```

它真正的用处不是打印，是配合重定向**写文件**（5.5 节讲）。

`printf` 和 `echo` 类似，但格式化更强（类似 C 语言的 printf）：

```bash
$ printf "名字: %s, 年龄: %d\n" "张三" 20
名字: 张三, 年龄: 20
```

新手记 `echo` 就够，`printf` 写脚本时再用。

## 5.2 cat / tac / nl —— 一次看完小文件

`cat`（concatenate）把文件内容全部打印到屏幕：

```bash
$ cat /etc/hostname
```

适合看几行、几十行的小文件。文件一长，内容会刷得你眼花缭乱，那时候用 `less`。

`cat` 还有个常见用法：把几个文件拼到一起：

```bash
$ cat a.txt b.txt > all.txt
```

`tac` 是反过来，倒着打印（反写 cat），偶尔用。`nl` 打印时顺便带上行号：

```bash
$ nl /etc/passwd
```

## 5.3 less —— 看大文件的正确姿势

看配置文件、看日志，别用 `cat`，用 `less`：

```bash
$ less /var/log/syslog
```

打开后你会进入一个分页查看器。常用按键：

| 按键 | 作用 |
|---|---|
| `空格` / `PgDn` | 下一页 |
| `b` / `PgUp` | 上一页 |
| `↓` / `↑` | 上下一行 |
| `/关键词` 回车 | 向下搜索 |
| `?关键词` 回车 | 向上搜索 |
| `n` / `N` | 下一个 / 上一个匹配 |
| `g` | 跳到文件头 |
| `G` | 跳到文件尾 |
| `q` | 退出 |

> 💡 **小技巧：`man` 命令打开的就是 less。** 所以你按 q 退出 man 的肌肉记忆，在 less 里完全通用。

## 5.4 head / tail —— 看头看尾

文件太大不想全文翻，只看开头几行：

```bash
$ head -n 20 /etc/passwd
```

看结尾：

```bash
$ tail -n 20 /var/log/syslog
```

`-n` 可以省略，直接 `head -20`。

**`tail -f` 是看日志的神器。** 它会盯着一个文件，有新内容写进来就实时显示：

```bash
$ tail -f /var/log/syslog
```

你跑一个后端服务，另开一个终端 `tail -f` 它的日志，服务输出什么你这边实时能看到。按 `Ctrl+C` 退出。

## 5.5 三条流：标准输入、标准输出、标准错误

这是本章最核心的概念，必须讲透。

每个命令启动时，系统会自动给它开三个"管道"：

| 名字 | 编号 | 通俗理解 |
|---|---|---|
| 标准输入（stdin） | 0 | 程序从哪读数据（默认是键盘） |
| 标准输出（stdout） | 1 | 正常结果往哪送（默认是屏幕） |
| 标准错误（stderr） | 2 | 报错信息往哪送（默认也是屏幕） |

为什么要分两条输出？因为你可能想"把正常结果存进文件，但报错还是显示在屏幕上"——如果混在一起，就分不开了。

```bash
$ ls notexist
ls: cannot access 'notexist': No such file or directory
```

这句话走的是 **stderr**，不是 stdout。

## 5.6 重定向：> >> 2> &>

默认输出到屏幕，你可以让它改去文件。这叫**重定向**。

**`>` 覆盖写入：**

```bash
$ echo "第一行" > test.txt
```

把 `echo` 的 stdout 送进 `test.txt`，**原来的内容被清空**。

**`>>` 追加写入：**

```bash
$ echo "第二行" >> test.txt
```

不清空，在文件末尾加一行。

> ⚠️ **警告：`>` 会静默覆盖原文件！** 写之前想清楚。养成用 `>>` 的习惯，想覆盖时再改 `>`。

**`2>` 重定向错误：**

```bash
$ ls notexist 2> error.txt
```

报错信息写进 error.txt，屏幕上啥都没有。

**`&>` 正确错误都写进文件：**

```bash
$ ls / > all.txt 2>&1
```

`2>&1` 的意思是"把 stderr 改成和 stdout 同一个地方"。`&> 文件` 是简写，等价于 `> 文件 2>&1`。

> 📌 **注意顺序：`> file 2>&1` 里 `2>&1` 必须写在 `> file` 后面。** 它的意思是"把错误输出，跟着现在标准输出的去向走"。写反了不生效。新手记 `&> file` 这个简写就行。

**`<` 输入重定向（从文件读而不是键盘）：** 用得少，知道有这回事即可。

## 5.7 管道 | —— 把命令串起来

管道是 Shell 的精髓。竖线 `|` 的意思：

> 📌 **把左边命令的 stdout，作为右边命令的 stdin。**

```bash
$ ls -l /etc | less
```

`ls -l /etc` 输出一大堆，直接刷屏；加个 `| less`，就变成在 less 里慢慢翻。

```bash
$ ls /etc | grep ssh
```

列出 `/etc` 下所有文件，再用 `grep` 挑出含 ssh 的。

管道可以一根接一根：

```bash
$ ls -l /var/log | grep ".log" | head -5
```

这就是 Linux 哲学：每个小工具只干一件事，用管道把它们拼成强大的流水线。

## 5.8 grep —— 在文本里搜关键词

`grep` 是全局搜索文本的瑞士军刀。基本用法：

```bash
$ grep "error" /var/log/syslog
```

在文件里找出所有含 "error" 的行。

常用选项：

| 选项 | 作用 |
|---|---|
| `-i` | 忽略大小写 |
| `-n` | 显示行号 |
| `-r` | 递归搜索目录里所有文件 |
| `-v` | 反向，显示**不**匹配的行 |
| `-E` | 支持扩展正则表达式 |

例子：

```bash
# 在整个项目目录里搜 "TODO"，显示文件名和行号
$ grep -rn "TODO" myproject/

# 忽略大小写搜 Error/error/ERROR
$ grep -ri "error" /var/log/syslog

# 配合管道，从 ps 输出里找 nginx 进程
$ ps aux | grep nginx
```

> 💡 **小技巧：`grep -rn "关键词" .` 是后端开发每天敲十遍的命令。** `.` 表示当前目录。

## 5.9 文本处理小工具们

下面这些命令都是"吃一行文本，吐一行文本"，配合管道用极爽：

| 命令 | 作用 | 例子 |
|---|---|---|
| `cut` | 按列切 | `cut -d: -f1 /etc/passwd`（按冒号切，取第 1 列） |
| `sort` | 排序 | `sort names.txt` |
| `uniq` | 去重（要先 sort） | `sort names.txt \| uniq` |
| `wc` | 统计行数/词数/字符数 | `wc -l file.txt`（数行数） |
| `tr` | 替换字符 | `echo "ABC" \| tr 'A' 'a'` |
| `tee` | 既显示又存文件 | `ls \| tee list.txt` |
| `xargs` | 把输入变成后面命令的参数 | `find . -name "*.tmp" \| xargs rm` |

举个真实例子：统计你家目录下有多少个文件：

```bash
$ ls -1 ~ | wc -l
```

再举一个：把一个文件里所有大写字母变小写：

```bash
$ cat input.txt | tr 'A-Z' 'a-z' > output.txt
```

## 5.10 sed 和 awk —— 点到为止

这两个是文本处理的大杀器，各自能写一本书。这里只给你两个最常用的入门招式：

**sed 替换：**

```bash
$ sed 's/旧词/新词/' file.txt
```

把每行第一个"旧词"换成"新词"。加 `g` 换每行所有：

```bash
$ sed 's/旧词/新词/g' file.txt
```

想直接改文件内容，加 `-i`：

```bash
$ sed -i 's/localhost/127.0.0.1/g' config.ini
```

> ⚠️ **警告：`sed -i` 直接改原文件，没有备份。** 先不加 `-i` 跑一遍看输出对不对，确认了再加。

**awk 按列打印：**

```bash
$ awk '{print $1}' file.txt
```

把文件每行按空格切分，打印第 1 列。`$1` 第 1 列、`$2` 第 2 列、`$0` 整行。

更复杂的筛选：

```bash
$ awk '$3 > 100 {print $1, $3}' data.txt
```

翻译：第 3 列大于 100 的行，打印第 1 和第 3 列。

> 📌 **注意：sed/awk 先混个脸熟就行，以后真要写复杂脚本再深入。** 第 11 章 Shell 编程还会再提。

## 5.11 nano —— 最容易上手的编辑器

改配置文件时，新手先别碰 Vim，用 `nano`：

```bash
$ nano test.txt
```

打开后直接打字编辑。底部那行是快捷键：

| 按键 | 作用（底部显示的 ^ 代表 Ctrl） |
|---|---|
| `Ctrl+O` | 保存（Write Out），按回车确认文件名 |
| `Ctrl+X` | 退出 |
| `Ctrl+K` | 剪切一整行 |
| `Ctrl+W` | 搜索 |

> 💡 **小技巧：nano 底部显示的 `^O` 就是 `Ctrl+O`。** 新手第一次用 nano 不知道怎么退出时，就盯着底部提示按。

## 5.12 Vim 最小可用集

服务器上不一定装 nano，但**几乎一定装了 vim**。所以你至少要会"在 vim 里改几个字、保存退出"。深入学 Vim 在第 14 章，这里只教救命组合。

### 5.12.1 Vim 的核心哲学：模式

Vim 和普通编辑器最大的不同：**它有模式。**

- **普通模式（Normal）：** 一打开就在这。按键是命令，不是输入文字
- **插入模式（Insert）：** 按键才是真输入文字

刚打开文件你以为键盘坏了——因为你在普通模式，敲的字都被当成命令了。别慌。

### 5.12.2 救命组合（背下来）

```bash
$ vim test.txt
```

打开后：

| 你想干嘛 | 按什么 |
|---|---|
| 进入输入模式，开始打字 | 按 `i` |
| 打完字，回到普通模式 | 按 `Esc` |
| 保存并退出 | 普通模式下敲 `:wq` 回车 |
| **不保存，强制退出** | 普通模式下敲 `:q!` 回车 |
| 删一整行 | 普通模式下按 `dd` |
| 复制一整行 | 普通模式下按 `yy` |
| 粘贴 | 普通模式下按 `p` |
| 搜索关键词 | 普通模式下敲 `/关键词` 回车，`n` 下一个 |

> ⚠️ **警告：新手最常见的惨剧——进了 vim 不知道怎么退出，最后长按关机。** 记住三个键位就够用一辈子：`i` 进插入，`Esc` 回普通，`:wq` 保存退出。如果改乱了，`:q!` 不保存强退，文件原封不动。

> 💡 **小技巧：想正经学 Vim，装好后跑一遍 `vimtutor` 命令，20 分钟官方交互式教程。** 但现在别花时间，先把上面那 9 个键位记住够用。

## 5.13 file / stat / wc —— 看文件底细

顺便补几个杂项：

```bash
$ file notes.txt     # 这文件到底是什么类型
$ stat notes.txt     # 详细元数据（大小、权限、时间戳）
$ wc -l notes.txt    # 数行数（-w 数词，-c 数字节）
```

## ⚠️ 危险操作与安全红线

- > ⚠️ **`>` 覆盖写文件是静默的。** 写之前确认目标文件不存在或不需要保留。
- > ⚠️ **`sed -i` 直接改原文件。** 先不加 `-i` 预览。
- > ⚠️ **`vim :wq` 是保存退出，`:q!` 是不保存退出——想清楚再按。** 误按 `:wq` 把配置改坏了要能改回来。
- > ⚠️ **`xargs rm` 和管道接删除命令威力巨大。** 先 `| xargs echo` 看看它会删什么，再真删。

## 常见报错与排查

| 现象 | 原因 | 解决 |
|---|---|---|
| vim 里打字全是奇怪命令 | 没按 `i` 进插入模式 | 先按 `Esc`，再按 `i` |
| vim 退不出来 | 不知道 `:q!` | 按 `Esc`，敲 `:q!` 回车 |
| `>` 后文件变成空的 | 不小心用 `>` 覆盖了原文件 | 养成先备份、多用 `>>` |
| 管道命令"卡住"没反应 | less/more 等待输入 | 按 `q` 退出 |
| grep 搜不到明明存在的内容 | 大小写不对 / 路径不对 | 加 `-i`；先确认文件在不在 |

## 动手练习

1. 用 `echo` 写 5 行内容到 `fruits.txt`（用 `>>` 一行一行加），用 `cat` 看一眼。
2. 用 `less` 打开 `/etc/services`，搜一下 "ssh"，翻几页，按 `q` 退出。
3. `tail -f` 打开 `/var/log/syslog`，另开一个终端随便敲几条命令，看日志有没有动静，`Ctrl+C` 退出。
4. 用 `grep -rn "bash" /etc` 搜一下系统里哪些配置提到了 bash。
5. 把 `fruits.txt` 内容全部转成大写，存到 `fruits_upper.txt`（提示：用 `tr`）。
6. 用 `nano` 编辑 `fruits.txt`，加一行 "grape"，保存退出。
7. 用 `vim fruits.txt` 打开，按 `i` 在最后加一行 "mango"，按 `Esc`，敲 `:wq` 保存退出。

## 本章小结

| 命令 | 作用 |
|---|---|
| `cat` / `less` / `head -n` / `tail -n` | 看文件（小/大/头/尾） |
| `tail -f` | 实时看日志 |
| `>` `>>` `2>` `&>` | 重定向输出 / 追加 / 错误 / 全部 |
| `\|` | 管道，把前一个命令的输出接给后一个 |
| `grep -rniE` | 文本搜索 |
| `cut sort uniq wc tr tee xargs` | 文本处理流水线 |
| `sed 's/a/b/g'` | 批量替换 |
| `awk '{print $1}'` | 按列取 |
| `nano` | 新手编辑器 |
| `vim` | i 进插入 / Esc 回普通 / :wq 存 / :q! 不存 |
