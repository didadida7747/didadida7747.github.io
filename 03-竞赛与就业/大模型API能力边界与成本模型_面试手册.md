# 大模型 API 能力边界与成本模型：面试手册

> 数据日期：**2026-10-09**。价格、型号更新极快，面试前请对照各厂商官方定价页复核（链接见附录）。

## 〇、先读：怎么读这份手册

### 0.1 数据核实状态标签（每个数字后面都带）

| 标签 | 含义 | 面试里能不能直接说 |
|---|---|---|
| 【直读】 | 我用浏览器直接读取官方页面（Claude、OpenAI、Gemini、Grok） | 可以，说“官方定价页” |
| 【复核】 | 官方页面经 WebFetch 摘要读到，并与原稿一致（国产模型） | 可以，但建议说“约”，面试前再看一眼官网 |
| 【自报】 | 厂商自己公布的基准分数，没有独立复测 | 必须说“厂商自报” |
| 【二手】 | 只来自搜索摘要、新闻、聚合站 | 不建议报具体数字；要说就说“据报道” |
| 【未核实】 | 查不到或来源互相矛盾 | **不要说**；被问到就坦白“我没核实到” |
| 【计算】 | 我用公式算的 | 可以，说清公式 |
| 【假设】 | 我设定的前提 | 必须说明是假设 |

### 0.2 一个重要的坦白（面试时可以主动讲，加分）

1. **社区实测评价没有做到**：B 站、知乎、YouTube、Reddit 上的开发者实测，调研员全部没有找到可用内容。所以“用起来手感如何”这类问题，本手册**不提供一手结论**。
2. **基准分数大多是厂商自报**，缺少独立复测。
3. **国产模型的参数量、开源协议多源冲突**，本手册只写官方页能确认的部分。
4. 本轮复核用的是 WebFetch 摘要，不是逐字原文，所以国产模型标【复核】，不标【直读】。

### 0.3 币种说明
美元价格和人民币价格**不能直接比数字**。我没有核实当日汇率。需要比量级时，本手册会明确写“**假设 1 美元 ≈ 7 元**”，这是假设值，不是核实值，你换成当天汇率重算即可。

## 一、全景格局与选型地图

### 1.1 一句话格局（可作为开场白）

> 目前可以把主流 API 分成四档：**第一档是旗舰推理**（Claude Fable 5.1、GPT-6 Astra，每百万 token 输入 $10、输出 $50）；**第二档是主力档**（Claude Opus 5.5 / Sonnet 5.5、GPT-6.1 Sol、Gemini 3.8 Flash、Grok 4.7，输入 $0.75–$4）；**第三档是便宜量大档**（Claude Haiku 5.5、GPT-6 Luna，输入 $0.10）；**第四档是国产与开放权重**，价格从 DeepSeek 的 $0.15 输入到 Kimi K3 的 ¥20 输入，差距很大。选型不是找“最强”，而是在“任务难度、延迟、预算、合规”四个约束下找最合适。

类比：就像请人干活——旗舰是“资深专家”，按小时收高价；主力档是“熟练工”；便宜档是“实习生，批量干重复活”；国产和开源是“外包团队，价格灵活，但要看合同（协议）和数据安全”。

## 二、各厂商能力边界

> 写法约定：每个厂商按“定位 → 规格 → 计费特点 → **能力边界与限制** → 未核实”展开。能力边界部分只写官方文档明确写出的限制，这是面试最稳妥的说法。

### 2.1 OpenAI（GPT-6 系列）

**定位与规格**【直读】
- 三个主力：**GPT-6 Astra**（最强，2026-09-03 发布）、**GPT-6.1 Sol**（接近 Astra、更便宜，约 2026-09-29 发布，发布日期来自 changelog 但年份由标题推断）、**GPT-6 Luna**（高吞吐低成本，约 2026-09-22 发布）。
- 三者上下文 1.05M，最大输出 128K；知识截止 Astra 与 Sol 为 2026-04-30，Luna 为 2026-05-18。
- 输入：文本 + 图片；输出：文本。工具：函数调用、Web search、File search、Computer use。
- Astra 推理档位 low / medium / high / xhigh / max。
- 2026-10-06 起速率限制由五档改为 Build / Launch / Grow 三档；标准限额例：Build 档 Astra/Sol 5,000 RPM / 1,000,000 TPM，Grow 档 15,000 RPM / 40,000,000 TPM。

**计费特点**【直读】
- 档位：**Batch 与 Flex 为标准价 5 折，Fast（原 Priority，2026-07-30 更名）为 2 倍**；Ultrafast 数字推算约 6 倍【计算：Astra 60÷10】，官方页没有文字写倍数。
- **超过 272K 输入的请求，整次请求按输入 2 倍、输出 1.5 倍计费**（Astra 官方模型页原文；$10→$20、$50→$75 与此吻合）。
- 缓存：默认自动开启；Astra 命中价为输入的 0.1 倍，Sol 为 0.05 倍；**GPT-5.6 及之后缓存写入为输入价 1.25 倍**；最小可缓存长度 1,024 可见输入 token；生命周期至少 30 分钟（命中会刷新）；缓存按机器保存，单机流量超过约 15 RPM 可能溢出路由、降低命中率。
- 工具：Web search $10/千次；File search 调用 $2.50/千次、存储 $0.10/GB/天（1GB 免费）；容器按会话计费。区域数据驻留加收 10%。

**能力边界与限制**
- 官方页明确写出的：GPT-6 系列输入只有文本和图片（没有音频、视频输入）；OpenAI 在关闭 fine-tuning 平台，新用户不可访问。
- 幻觉率：Vectara 摘要一致性榜上 GPT-6 Sol 6.5%、Astra 8.7%、GPT-5.6 Sol 12.4%【二手：GitHub PR 摘要，主榜未核实】。**这只测“短文档摘要”场景**，不代表所有场景。
- 其他短板（长上下文衰减、延迟、拒答）：官方无系统性说明，**【未核实】**。

### 2.2 Anthropic（Claude 5 家族）——资料最完整

**定位与规格**【直读】

| 型号 | 定位 | 延迟 | 默认 effort |
|---|---|---|---|
| Fable 5.1 | 最复杂推理与长程 Agent | 最慢 | high |
| Opus 5.5 | 长时间 Agent 编程与知识工作 | 中等 | medium |
| Sonnet 5.5 | 速度与智能最佳平衡 | 快 | high |
| Haiku 5.5 | 高并发低延迟：分类、抽取、路由 | 最快 | medium |

- 四款均 1M 上下文、128K 最大输出，知识截止 2026-06。

**计费特点**【直读】
- 缓存写入：5 分钟 1.25 倍，1 小时 2 倍。
- **缓存读取倍率因型号而异**：通用 0.1 倍；Opus 5.5 与 Sonnet 5.5 为 0.05 倍；Fable 5.1 为 0.025 倍（这是面试里很容易被问倒的细节）。
- **Batch 5 折，可与缓存叠加**（倍率相乘）。
- **1M 上下文无长上下文溢价，唯一例外是 Haiku 5.5**：提示超过 100K 时，整个请求按 5 倍价（$0.50/$2.50），且缓存命中也不豁免。
- 快速模式（研究预览，仅第一方）：Opus 5.5 为 8/40，不能与 Batch 同用。
- `inference_geo: "us"` 美国境内推理全部计费项乘 1.1。
- Web search $10/千次；Web fetch 无额外费用；Managed Agents 另加 $0.08/会话小时。

**能力边界与限制（官方文档明确，可直接引用）**
1. **思考无法关闭**（Fable 5.1、Opus 5.5），只能降低 effort。含义：简单任务也会有思考 token，成本和延迟偏高。
2. **禁用强制工具调用**：Fable 5.1、Opus 5.5、Sonnet 5.5 上 `tool_choice` 设为 `any` 或 `tool` 会返回 400，要改用 `auto` + `strict: true` 或结构化输出。
3. **不支持助手预填充**（5 系列均 400）；格式控制改用结构化输出。
4. `thinking.budget_tokens` 已不能用，改用 `thinking: {type: "adaptive"}` + `effort`。
5. **Haiku 5.5 的 100K 价格悬崖**（5 倍），长文档场景要先估算。
6. **Fable 5.1 要求 30 天数据保留**，不支持零数据保留（除非 Anthropic 明确授权），对合规敏感场景是限制。
7. 安全分类器可能返回 `stop_reason: "refusal"`，建议配置服务器端 `fallbacks`。
8. Opus 5.5、Sonnet 5.5、Fable 5.1 不支持 Priority Tier。

**未核实**：官方基准（SWE-bench Pro 的 Opus 5.5 89.9% 是厂商自报且仅来自聚合站摘要）；幻觉、长上下文衰减、延迟实测；Rate limit 分级；Bedrock、Vertex 的价格差异；Claude 新分词器相比旧版多耗 token 的官方倍数（有说法 1.0–1.35 倍，第三方实测更高，**均未核实**，要用 token counting 接口实测）。

### 2.3 Google Gemini

**定位与规格**【直读】
- 当前稳定主力：**Gemini 3.8 Flash**（`gemini-3.8-flash`，官方定位“最智能的 Flash，面向长程软件工程、自主 Agent 与复杂企业工作流”）。
- 输入：文本、图片、视频、音频、PDF；输出：仅文本。输入约 1M token，输出 65,536。
- 思考支持 low / medium / high，**不支持 minimal（会报错）**。
- **Pro 档目前仍是 Gemini 3.1 Pro 预览版**（`gemini-3.1-pro-preview`），没有稳定的 Pro；**价格未核实**（定价页抓取时无法按型号区分）。
- Gemini 2.5 系列只对过去用过的用户开放，新项目官方建议用 3.5 Flash-Lite 或 3.8 Flash。

**计费特点**【直读】
- 3.8 Flash：标准价促销 $0.75/$3.75，**2027-01-01 起翻倍**；Batch 与 Flex 为 5 折；优先级约 1.8 倍。
- 缓存：除命中价外，还有**按小时的存储费**（3.8 Flash 为 $0.50/百万 token/小时，2027 起 $1.00）——与 Claude、OpenAI、DeepSeek 不同。
- Google 搜索接地：Gemini 3 系列每月 5,000 次免费，超出 $14/千次；代码执行免费；URL 上下文免费。

**能力边界**
- 不支持：音频生成、图像生成、Live API（3.8 Flash 本身）【直读】。
- 长上下文是否分段计价、各 Flash-Lite 价格：**未核实**。
- **Gemini 4 Argon**：2026-09-30 宣布，推广价 $2/$10，之后 $4/$20；**尚未对公众开放 API**（先给受信任网络防御者与 Google AI Ultra 订阅用户），输入窗口与模型 ID 未公布【二手：搜索摘要，未能打开 Google 博客】。**所以“榜单上有它”不等于“你能调用它”**。

### 2.4 xAI Grok

**以官方模型页为准**（页面标注更新于 2026-09-21）【直读】：
- 主力 **grok-4.7**：上下文 **500K**（不是 1M）；输入 $2、输出 $6；知识截止 2026-05；推理可配置。
- 模型本身**没有实时事件知识**，需开启服务器端搜索工具（Web Search / X Search）；搜索工具计费、缓存价、批量价、速率限制均**未核实**。
- 接口细节：Responses API 总是返回加密推理内容；grok-4.20 及更新模型不支持 logprobs。
- 另有语音（$0.08/分钟）与图像视频生成 API（图像起价 $0.02/张）。

### 2.5 国产大模型

> 总体印象（面试表述）：国产模型的特点是**价格带宽、1M 长上下文普及、纷纷主打 Agent 编程、普遍提供 OpenAI 兼容接口**；风险点是**多数能力数字是厂商自报、独立复测少、数据出境与合规条款我没有核实**。

#### DeepSeek【复核】
- 最新：**V4.1-Flash**（2026-09-10，API 名 `deepseek-flash`）与 **V4-Pro**（GA 2026-08-13，`deepseek-v4-pro`）。Flash 支持视觉输入，Pro 不支持。
- 上下文 1M，最大输出 384K（官方页标注）；思考强度 low / high / max。
- **特色：价格最低，且有峰谷价**（谷价 = 峰价一半）；缓存自动、命中价约为未命中的 1/50（Flash：$0.003 对 $0.15）【计算】。
- 提供 OpenAI 兼容与 Anthropic 兼容接口；官方页无 Batch、无阶梯、无人民币价。
- 旧名 `deepseek-chat` / `deepseek-reasoner` 已于 2026-07-24 下线。
- 厂商自报基准（节选）：V4.1-Flash 的 Terminal-Bench 2.1 为 90.6、GPQA Diamond 90.9【自报】。

## 三、成本模型

### 3.1 计费单位：token

- token 是模型处理文本的“计量块”。类比：**像按“字数”收翻译费，但“字”的切法每家不同**。API 按“每百万 token”计价，**输入和输出分开收费**。
- 中文：1 个汉字约 0.6–1.2 token，不同厂商差异可达 ±50%【二手估算，未核实】。**结论：预算前必须用各家计数工具实测**（Claude 用 token counting 接口，OpenAI 用 tiktoken，国产看返回的 usage 字段）。
- **输出价通常是输入价的 3–10 倍**：Claude 5 倍（$2→$10）、DeepSeek V4.1-Flash 4 倍、GPT-6.1 Sol 5 倍、Grok 4.7 3 倍、Qwen3.8-Max 3 倍、Kimi K3 5 倍、豆包 Seed 2.1-Pro 5 倍【计算】。这个比例直接决定“省输出比省输入更值”。

### 3.2 六大价格杠杆（面试可直接背）

| 杠杆 | 机制 | 数字（已核实部分） |
|---|---|---|
| ① 提示缓存 | 重复的前缀只付“读取价” | Claude 读取 0.025–0.1 倍、写入 1.25（5 分钟）/2（1 小时）倍；OpenAI GPT-6 读取 0.05–0.1 倍、写入 1.25 倍；DeepSeek 命中约 1/50 且无写入费；Gemini 读取 0.1 倍但**另收存储费** |
| ② Batch / Flex | 异步、不要求实时，换折扣 | Claude、OpenAI、Gemini 均 5 折；Claude 可与缓存叠加；Qwen 多数模型半价（原稿：批处理与缓存不叠加）；DeepSeek 官方页无 Batch |
| ③ 长上下文阶梯 | 输入越长，单价越高 | OpenAI >272K：输入 2 倍、输出 1.5 倍；Claude 仅 Haiku 5.5 >100K 为 5 倍；Qwen 按请求输入长度整次分档；Kimi K3 官方称不按长度分段 |
| ④ 思考 token | 推理过程按**输出价**计费，且不可见 | Claude Fable 5.1 / Opus 5.5、GLM-5.3、Kimi K3 思考不可关闭；要看 `usage` 里的推理 token 数 |
| ⑤ 工具 | 搜索、检索、代码执行单独计 | Web search：Claude 与 OpenAI 均 $10/千次，Gemini 超免费额度后 $14/千次，智谱 $0.01/次 |
| ⑥ 服务档位与地域 | 低延迟、数据驻留要加价 | OpenAI Fast 2 倍；Claude 快速模式 Opus 5.5 约 2 倍；数据驻留 Claude 与 OpenAI 均加 10%；Qwen 美国/新加坡高于中国区 |

### 3.3 成本公式（可套用）

```
单次请求成本 =
    未缓存输入  × 输入价
  + 缓存写入    × 输入价 × 写入倍数      （Claude 5 分钟 1.25；OpenAI GPT-6 1.25；DeepSeek 无）
  + 缓存命中    × 缓存读取价
  + (可见输出 + 思考 token) × 输出价

月成本 = 单次成本 × 月请求数 × (1 + 重试率)

Agent 多轮：第 k 轮的输入 = 初始上下文 + 每轮新增 × (k−1)
          → 总输入随轮数近似平方增长（轮数翻倍，总输入约 4 倍）
```

- 对标 API：假设混合价 $2/百万 token → 盈亏点约 **1,380 百万 token/月**，约 **530 token/秒**满载持续运行【计算+假设】。**单卡实际吞吐未核实，需实测**；若对标便宜 API（如 gpt-oss-120b 在 Groq 约 $0.15/$0.60，聚合站说法，未核实），盈亏点会高很多。
- **没算进去的隐性成本往往最大**：运维人力、模型升级、高可用冗余（至少 2 卡）、合规与监控。
- 面试结论：**低量、波动大 → API；持续高负载、数据不能出境、需要微调或锁版本 → 才考虑自建**。

## 四、场景化选型与降本手册

### 4.1 降本手段速查（按“投入产出比”排序）

| 顺序 | 手段 | 做法 | 依据 / 注意 |
|---|---|---|---|
| 1 | **稳定前缀 + 缓存** | 把系统提示、工具定义、知识库放最前，保持字节级一致 | Claude 渲染顺序 tools→system→messages，前缀任意字节变化会使其后缓存失效；OpenAI 单机流量过大可能降低命中率；Gemini 要算存储费 |
| 2 | **Batch** | 不要求实时的任务走批处理 | 5 折；Claude 可与缓存叠加 |
| 3 | **控制输出** | 设 `max_tokens`、要求精简格式 | 输出价是输入价 3–10 倍 |
| 4 | **模型路由 / 级联** | 简单问题走便宜档，不确定时升级 | 价格差数十倍（算例）；**路由阈值要用自己的数据校准** |
| 5 | **降低思考强度** | 用 effort（low / medium） | Fable 5.1、Opus 5.5 不能关闭思考，只能降 effort |
| 6 | **控制 Agent 上下文** | 定期压缩历史、截断工具结果 | 算例 B：上下文累积导致近似平方增长 |
| 7 | **错峰** | DeepSeek 谷时调用 | 谷价为峰价一半【复核】 |
| 8 | **监控 usage** | 记录缓存命中、推理 token、重试 | 账单偏差往往来自思考 token 和重试 |

### 4.2 三个常见“取舍”，各给两个方案（由你按场景决定）

**取舍 1：用国产便宜模型 还是 海外旗舰？**
- 方案 A（国产为主）：价格低一到两个数量级；类比“本地外包”，便宜、沟通顺畅，但**合规条款、稳定性、独立评测我没有核实**。
- 方案 B（海外旗舰为主）：能力与文档成熟；类比“国际大所”，贵，且可能遇到访问、数据驻留、保留期（如 Fable 5.1 的 30 天保留）限制。
- 折中：**路由**——简单任务走国产便宜档，难任务走旗舰；两边都用 OpenAI 兼容接口，换起来成本低（DeepSeek、Kimi、智谱均提供兼容接口）。

**取舍 2：API 还是自建？** 见 3.5。类比：API 是“打车”，自建是“买车”——一年跑得少就打车划算，天天满载才买车，还要算司机和保养。

**取舍 3：要不要用 Batch / 异步？** 有 5 折，代价是延迟不可控（OpenAI Batch 的完成窗口本轮**未核实**）；适合离线标注、清洗、摘要，不适合在线对话。

### 4.3 选型的“五问”（面试可当框架）
1. 任务难度如何？（简单分类 → 便宜档；复杂 Agent → 旗舰）
2. 延迟要求？（Fable 5.1 最慢；Haiku 5.5 最快；AA 中位输出速度：Sonnet 5.5 约 141 token/秒、Opus 5.5 约 96、Fable 5.1 约 70、GPT-6 Astra 约 44；来源是 AA 页面抓取，**页面未标注日期**，只作量级参考）
3. 预算？（先估算 token，再用 3.3 公式算）
4. 合规？（数据保留、出境、驻留；国内合规我没调研）
5. 能否被替换？（避免被单一厂商锁定：用兼容接口、做路由）

## 五、面试高频问题与参考答法

> 每题给“30 秒答法”和“可展开的要点”。凡是未核实的，答法里已写明说法。

### Q1：请介绍一下主流大模型 API 的格局？
**30 秒**：分四档——旗舰推理（Claude Fable 5.1、GPT-6 Astra，$10/$50）、主力（Sonnet 5.5、GPT-6.1 Sol、Gemini 3.8 Flash、Grok 4.7）、便宜量大（Haiku 5.5、GPT-6 Luna，$0.10 输入）、国产与开放权重（DeepSeek、Qwen、Kimi、GLM 等，价格带很宽）。**选型是约束优化，不是找最强。**
**展开**：引 1.2 价格表与 1.3 选型地图。

### Q2：Claude、GPT、Gemini 各自的能力边界是什么？
**30 秒**：我只讲官方文档明确的限制。**Claude**：思考不可关闭、禁用强制工具调用、不支持预填充、Haiku 5.5 超 100K 价格涨 5 倍、Fable 5.1 要 30 天数据保留。**GPT-6**：输入只有文本和图片；超 272K 输入整次请求输入 2 倍、输出 1.5 倍；fine-tuning 平台在关闭。**Gemini**：3.8 Flash 输入多模态但只输出文本，Pro 档还是预览版，当前价格是促销价、2027 年翻倍。
**坦白点**：幻觉率、长上下文衰减、延迟等“软能力”，我没有一手实测，只引用了公开榜单并标明来源。

### Q3：贵的模型一定更好吗？怎么衡量性价比？
**30 秒**：不一定。AA（Artificial Analysis）综合指数上 Claude Opus 5.5（max）58、Sonnet 5.5（max）56、GPT-6 Astra（max）53、Fable 5.1（max）53，即最贵的 Fable 5.1 分数并不是最高；按“指数÷每任务成本”自算，Astra 约 16.3、Sonnet 5.5 约 10.3、Opus 5.5 约 9.7、Fable 5.1 约 6.9【AA 页面抓取，日期未标注；性价比为我自算，不是 AA 官方指标】。**所以要用“任务通过率 ÷ 成本”衡量，而且要用自己的任务实测。**

### Q4：怎么估算一个应用的月成本？
**30 秒**：先拆请求类型，估每类请求的输入、输出、缓存命中、思考 token，再套公式（见 3.3），乘月请求量，再加重试率。再用 Batch、缓存做敏感性分析。**举例**：日 1 万次客服 RAG，用 Sonnet 5.5，无缓存约 $3,000/月，有缓存约 $1,860/月。**会说“这是下限”**，因为没算思考 token 和重试。

### Q5：提示缓存是什么？怎么用好？有哪些坑？
**30 秒**：重复的前缀只付折扣价。类比“把常用资料夹放在桌面，下次直接拿”。用法：**稳定内容放前面、保持字节一致**。坑：①读取倍率因型号而异（Claude Fable 5.1 为 0.025 倍，Sonnet 与 Opus 5.5 为 0.05 倍，其余 0.1 倍）；②缓存写入要多付 1.25 倍（5 分钟）或 2 倍（1 小时）；③Gemini 另收按小时存储费；④Haiku 5.5 的 100K 阈值把缓存读写也算入提示长度；⑤OpenAI 缓存按机器保存，单机流量过大会降低命中率。

### Q6：长上下文是不是越大越好？
**30 秒**：不是。三层原因：①**价格**——OpenAI 超 272K 整次涨价、Haiku 5.5 超 100K 涨 5 倍、Qwen 按输入长度分档；②**实际可用**——标称 1M 不等于 1M 下都能可靠检索。一篇 2026-03 的对比（yage.ai，**仅二手摘要，且是上一代模型**）显示 1M 档 8-needle 检索分数在 26%–76% 之间，**我不会拿它代表最新模型**；③**延迟和成本**随长度增长。

### Q7：什么是“思考 token”？为什么账单会比预期高？
**30 秒**：推理模型会先“内部思考”，这些 token 不显示但按**输出价**计费。Claude Fable 5.1 / Opus 5.5、GLM-5.3、Kimi K3 的思考都关不掉，只能调 effort（low/medium/high）。**所以要看 `usage` 里的推理 token，而不是只看答案长度。**

### Q8：为什么 Agent 特别烧钱？怎么控？
**30 秒**：每轮都把历史对话重新送一遍，总输入随轮数近似平方增长（20 轮的算例总输入约 77 万 token，Sonnet 5.5 无缓存约 $1.74，有缓存约 $0.44）。控法：缓存稳定前缀、压缩历史、截断工具结果、限制最大轮数、对简单子任务用小模型。

### Q9：国产模型怎么评价？你会用吗？
**30 秒**：优势是**价格**（DeepSeek V4.1-Flash 谷时输入 $0.15、Qwen3.8-Flash ¥0.8）和 **1M 长上下文普及**，普遍兼容 OpenAI 接口。风险是：基准多为厂商自报、独立复测少；合规与数据出境条款我没核实；部分模型思考不可关（Kimi K3、GLM-5.3），简单任务成本偏高。**策略**：在可替换的位置用，保留海外备选，用自己的评测集决定。
**别说**：具体的 Kimi K3 激活参数、Qwen3.8-Max 参数/开源协议、DeepSeek 开源协议——这些我都没核实到。

### Q10：开源自建还是调 API？
**30 秒**：看四条——数据能否出境、调用量是否持续高负载、是否需要微调或锁版本、延迟要求。多数团队低量波动大，API 更划算；自建盈亏点需用“GPU 月租 ÷ API 单价”估算（见 3.5），且隐性成本（人力、冗余、合规）常被低估。**要提醒**：开放权重不等于“随便商用”，要读许可证（Llama 4 有 7 亿月活门槛，gpt-oss 在 Apache 2.0 之上有使用政策）。

### Q11：怎么看榜单？为什么“榜单第一”不等于“可以用”？
**30 秒**：六条看榜纪律：①**同一模型的不同档位是不同条目**（AA 的 max / xhigh / high 是推理强度，不是不同模型）；②**厂商自报 ≠ 独立复现**——脚手架不同，不可混排；③聚合站数字互相矛盾，要以官方页为准并记日期；④Arena 是用户偏好榜，偏好长、格式好看的回答；⑤老基准接近饱和，要看更难更新的；⑥用量榜反映“被选择”而非“最强”。
**例子**：Gemini 4 Argon 出现在 Arena 与 AA 榜单上，但 2026-09-30 宣布时**没有对公众开放 API**——榜单第一，你调不到。另外，Arena 文本榜第一名在不同来源间不一致（Argon 与 Claude 之争），我不下定论。

### Q12：怎么设计模型路由与降级？
**30 秒**：三层——①按任务类型路由（分类→便宜档，复杂推理→旗舰）；②按置信度升级（便宜档不确定再升）；③故障降级（限流或拒答时换厂商，Claude 官方建议配置 `fallbacks`）。**前提**：统一用 OpenAI 兼容接口、统一日志、统一评测集；路由阈值必须用自己的数据校准，我没有现成的最优阈值数字。

### Q13：数据安全与合规怎么考虑？
**30 秒**：看三点——**数据保留**（Claude Fable 5.1 要求 30 天保留，不支持零保留，除非授权）、**数据驻留**（Claude 美国境内推理与 OpenAI 区域端点均加收 10%）、**训练使用**（Gemini 免费层数据会用于改进产品，付费层不会）。聚合平台 OpenRouter 的 ZDR 是看上游 endpoint 的政策。**国内的备案、等保、数据出境我没有调研**，面试遇到就说需要法务共同评审。

### Q14：价格会怎么变？你怎么应对？
**30 秒**：三个信号：①**促销价会到期**（Gemini 3.8 Flash 2027-01-01 翻倍；GPT-5.6 Sol 促销到至少 2026-11-21）；②**型号迭代快，旧名下线**（DeepSeek `deepseek-chat` 已于 2026-07-24 下线；阶跃 step-2x-large 2026-10-10 下线）；③长期趋势下行——Epoch AI 称“同等性能的价格”每年约降 40 倍，但**区间宽（9–900 倍/年）、是 2025-03 的研究、对象是特定基准**，不能直接套用。应对：预算按到期后价格算、模型名走配置、保留可切换的第二选择。

### Q15：你的数据可靠吗？怎么保证的？（反问型，展示严谨）
**30 秒**：价格类数据我分成五级标签——官方页直读、官方页摘要复核、厂商自报、仅二手、未核实；**每个数字都带标签**。比如 Gemini 3.1 Pro 预览版的价格、Kimi K3 的激活参数、各家社区实测，我明确标“未核实”。同时发现过冲突并更正：比如豆包 Lite 的输出价 ¥2.4 与 ¥2.7 两个说法，复核后以 ¥2.7 为准。

### Q16：快速判断题（陷阱题清单）
- “Claude 的缓存读取一律是 0.1 倍？” → 不是，因型号而异（0.025 / 0.05 / 0.1）。
- “Claude 1M 上下文一律不加价？” → Haiku 5.5 超 100K 例外，涨 5 倍。
- “Gemini 3.8 Flash 一直是 $0.75/$3.75？” → 2027-01-01 起翻倍。
- “Grok 4.7 是 1M 上下文？” → 官方页是 500K。
- “GPT-6 Astra 能直接输入音频？” → 官方页只写文本与图片输入。
- “Claude 5 系列能关思考？” → Fable 5.1 与 Opus 5.5 不能，只能调 effort。
- “Qwen4 已发布？” → 仅宣布训练中，不是在售。
- “Kimi K3 激活参数是多少？” → 官方页没写，我不报。

## 六、数据时效与局限

### 6.1 时效
- 数据日期 2026-10-09；价格与型号会变，**面试前请重新核对附录中的官方页**。
- 官方页本身多无发布日期；AA 榜单页面日期未标注。

### 6.2 方法局限
1. 国产模型复核用 WebFetch 摘要，非逐字原文；Hugging Face 页面两次读取失败。
