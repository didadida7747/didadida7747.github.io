# 常见问题与排错

## 连接/发现类

### Q1:LocalSend / spacedesk / Moonlight 找不到对方设备
按命中率排查:
1. 两端是否在**同一 Wi-Fi 网段**(主网 vs 访客网、2.4G vs 5G 有的是隔离网段);
2. 路由器**关闭"AP 隔离/客户端隔离/访客网络隔离"**;
3. Windows 防火墙:首次运行时勾选允许"专用网络";手动放行对应端口(LocalSend 53317/UDP+TCP,Moonlight TCP 47989 + UDP 47998-48000,spacedesk 28252 等);
4. 第三方安全软件(火绒/管家)拦截,加白名单;
5. 重启两端 App(刷新发现)。

### Q2:Moonlight 找得到主机但连不上/闪退
- 管理界面 `https://localhost:47990` 是否能打开(Sunshine 没跑起来);
- 手柄没反应 = 没装虚拟手柄驱动,回 Sunshine 管理界面点 Troubleshooting;
- 新版 Sunshine 输入后端有迁移,异常可回退旧版。

### Q3:scrcpy 黑屏/只能看不能控
- 必须**同时**开启"USB 调试"和"USB 调试(安全设置)"(ColorOS);部分一加需登录账号后才能开"安全设置"里的子开关;
- 无线连不上:先 USB 连一次,`scrcpy --tcpip=手机IP`,确认手机和电脑同网段;
- 手机弹窗授权没点(每次重装/换线会再弹)。

### Q4:Phone Link 连接失败/投屏按钮灰
- 手机端"链接至 Windows"App 需在后台运行(电池白名单);
- 通话功能要求手机蓝牙与电脑配对;
- 投屏功能依赖机型支持列表(一加主流机型均支持),手机端每次要手动确认"允许投屏";
- 系统更新 Phone Link 与"链接至 Windows"到最新版再试。

## 网络/组网类

### Q5:Tailscale 连得上但很卡(tailscale status 显示 relay)
- 打洞失败回落境外 DERP 中继;优化:路由器开 UPnP、NAT 调宽松、两端尽量有线;
- 进阶:自建国内 DERP 或 Headscale(见 [05-1](#/doc/d376));
- 实在不行:frp 转发固定端口。

### Q6:iPad 上 Tailscale 和代理冲突
- iPadOS 同一时间只允许一个 VPN 配置,两者互斥,切换即可;快捷指令可以自动化"离开家开 Tailscale/回家关"。

### Q7:外网串流画质糊/卡顿
- 先确认 `tailscale status` 是 direct;
- 码率降到 20-30 Mbps、1080p 起步,稳定再加;
- 家宽上行带宽是瓶颈:拯救者端上行 ≥ 码率+2Mbps 才稳。

## 系统类

### Q8:Windows 家庭版开不了远程桌面
- 家庭版无 RDP 主机端。方案:升级专业版,或改用 RustDesk/ToDesk/向日葵(见 [05-2](#/doc/d377));不建议 RDP Wrapper 补丁。

### Q9:远程唤醒失败
- 检查三件套:BIOS WoL 开、网卡"魔术包唤醒"勾选、**快速启动关闭**;
- 确认是睡眠而非关机(S5 不可靠);
- 魔术包不穿 VPN:局域网内需常驻设备发(UpSnap),见 [05-2](#/doc/d377)。

### Q10:一加后台 App(Tasker/LocalSend/链接至Windows)老被杀
- 自启动白名单 + 关闭电池优化 + 最近任务锁定;仍被杀上 Shizuku;ColorOS 的"睡眠待机优化"对常用工具关闭。

### Q11:扩展坞插上不充电
- 多数拯救者 USB-C 不支持 PD 输入(见 [05-5](#/doc/d380)),不是坞的错;电源走方口。

## 数据类

### Q12:iCloud 照片在 Windows 上同步慢/不全
- 大库首次同步本来就慢;检查"照片"App 里的 iCloud 设置;国内网络对 Apple 云服务敏感,换时段/网络再试;备选路径:iPad 装 LocalSend/Syncthing 批量回传。

### Q13:Syncthing iOS 端不同步
- iOS 后台挂起即停:进入 App 手动刷新;把它当"定期对账"而非实时同步;重活放电脑↔一加这条线。

### Q14:Obsidian 库冲突文件满天飞
- 别用 iCloud Drive 在 Windows 端同步库;换坚果云 WebDAV(Remotely Save)或官方 Sync(见 [03-3](#/doc/d373))。
