## 四、遇到问题的通用顺序（先记住这个）

```
留证据（截图/合同/转账记录）→ 12348 或 12333 免费咨询定性
→ 属地行政投诉（12315 等）→ 劳动仲裁 / 小额诉讼 → 高校法援 / 律师
```

> 大多数纠纷走到"行政投诉"就解决了；诉讼是最后手段，但**知道它存在**本身就是谈判筹码。
