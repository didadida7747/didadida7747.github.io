## 七、如何正确看榜（方法论提示）

1. **同一模型不同档位是不同条目**：AA 的 max/xhigh/high 是推理强度设置，不是不同模型。
2. **厂商自报 ≠ 独立复现**：SWE-bench Pro 的 89.9% 为厂商脚手架结果，Scale 标准化结果约 61.5%，二者差距巨大。
3. **聚合站互相矛盾**：同一周的 AA 分数在不同站点相差 1–5 分，应以官方页面为准，并记录抓取日期。
4. **用户偏好榜（Arena）有风格偏好**：长、格式好看的回答容易得分高，不等于正确性。
5. **基准饱和与数据污染**：头部模型在老基准上接近满分，需看更难、更新的基准（如 SWE-bench Pro）。
6. **用量榜反映“被选择”而非“能力最强”**：OpenRouter 用量受价格、免费额度、路由影响。

## 十六、BenchLM 的 GPT-5.6 Sol 58.9% 与 Artificial Analysis 的冲突

**结论：Artificial Analysis 官方页面更可信。BenchLM 的数字不作为榜单依据。**

理由：
1. **AA 官方页面的 Top 15 中没有 GPT-5.6 Sol**，最低分 51 分（已抓取，https://artificialanalysis.ai/leaderboards/models）。如果它真有 58.9 分，应该排在第 1 位，与 AA 页面不符。
2. **BenchLM 自己说明**其数据是"厂商自报 + 二手报道汇总，仅用于展示，不影响整体排名"（仅摘要，https://benchlm.ai/benchmarks/artificialanalysis ）。
3. 数字来源是厂商自报，不是 AA 在统一配置下的独立复现。

仍需注意：
- AA 的指数会改版（当前为 v4.3 系列），**58.9 可能是旧版口径**，此点**未核实**。
- 所以结论是"在当前 AA 页面上找不到 GPT-5.6 Sol 58.9 的证据，且 BenchLM 本身不作为依据"，而不是"AA 证明它是 53 分"。
