## 三、提示词框架与模板库

**框架三选一**：
1. **四段式**：角色 → 任务 → 要求 → 示例（日常够用）；
2. **CO-STAR**：Context 背景 / Objective 目标 / Style 风格 / Tone 语气 / Audience 受众 / Response 格式（重要产出用）；
3. **LangGPT 结构化**：Markdown 写"角色-技能-约束-工作流"（复用型固定任务）。

**GitHub 提示词库**（2026-10-03 API 核验）：

|---|---|---|

## 五、合规与隐私红线（用之前 30 秒）

**作业边界**：AI 可用于解释概念、生成提纲、润色**自己写的**初稿；让 AI 代写并提交 = 学术不端——《学位法》（2025-01-01 施行）下情节严重可撤销学位；多校毕业论文已引入 AIGC 检测，部分要求 AI 率 ≤10%（以本校规定为准）【需自行核实本校文件】。完整红线见 [`13库-04`](/13-法律与权益常识库/04-软著专利与学术诚信)。

**隐私红线**（对云端模型一律不输入）：
- 身份证号/家庭住址/密码；
- 成绩单、奖学金等未公开个人信息；
- 实验室未发表数据、实习单位内部资料；
- 他人隐私；求职敏感材料（offer、薪资）。

**降低泄露**：各助手设置里关闭"对话用于改进模型"类选项；特别敏感内容本地处理或不用 AI；免费版按"**输入即公开**"的心理预期使用。
