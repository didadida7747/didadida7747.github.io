# iPad 远程控制拯救者

> 场景:躺在沙发上/出门在外,用 iPad 操作家里的拯救者(写代码、跑训练、挂机、点游戏下载)。
> 结论:电脑是**专业版**就用微软官方 **Windows App(RDP)**,画质触控最好;**家庭版**用 **RustDesk**(开源)或 ToDesk/向日葵(开箱即用)。游戏场景不用远程桌面,直接用 Moonlight 串流(见 [04-1](/三设备联动指南/04-游戏与媒体/01-Sunshine与Moonlight游戏串流))。

## 先搞清楚:你的拯救者是家庭版还是专业版

- **专业版及以上**:支持被微软 RDP 协议远程控制 → 首选官方方案。
- **家庭版**:不支持 RDP 被控(RDP Wrapper 补丁随系统更新易失效且有合规风险,不建议) → 用第三方工具,它们走自己的协议,家庭版无碍。
- 查看方法:设置 → 系统 → 关于 → Windows 规格。

## 方案对比总表

| 方案 | 价格 | 开源 | 画质/延迟 | 亮点 | 短板 |
|---|---|---|---|---|---|
| **Windows App**(微软官方,原 Remote Desktop) | 免费 | 否 | 最好(原生 RDP) | 触控适配好、iPadOS 26 可窗口化多开 | 需电脑专业版;外网需配合组网(见 05-1) |
| **RustDesk** | 免费 | [是(≈125k★)](https://github.com/rustdesk/rustdesk) | 好 | 可自建中继、隐私可控、家庭版可用 | 公共中继速度一般,重度建议自建 |
| Chrome Remote Desktop | 免费 | 否 | 一般 | 5 分钟上手,临时救急最方便 | 功能简陋 |
| ToDesk | 免费版限 1080P/30帧 | 否 | 中 | 国内节点快、开箱即用、文件传输快 | 免费版画质/时长受限 |
| 向日葵 | 免费不限时长 | 否 | 中 | 生态有开机插座等硬件 | 免费版限速限画质 |
| Parsec | 免费 | 否 | 极好(解码) | — | ❌ **无 iOS/iPadOS 客户端**,iPad 不可用 |
| Moonlight+Sunshine | 免费开源 | 是 | 游戏级 | 高刷、手柄 | 是"串流"不是完整远程桌面(不显示桌面级 UI 操作场景也够用) |

## 上手步骤

### Windows App(RDP,专业版首选)
1. 电脑:设置 → 系统 → 远程桌面 → 开启;记下电脑名/用户名;
2. iPad:App Store 装 **Windows App**(微软官方,原"Microsoft 远程桌面"已改名,旧商店版 2025 年已下架);
3. 局域网内直接连电脑名;外网先连 Tailscale 再连(见 [05-1](/三设备联动指南/05-进阶玩法/01-Tailscale三端组网));
4. iPadOS 26 起支持窗口化,远程会话可与本地 App 并排、互相拖拽——"iPad 当 Windows 终端"体验明显变好。

### RustDesk(家庭版/开源党)
1. 两端都装 RustDesk(电脑从 [rustdesk.com](https://rustdesk.com) 下,iPad App Store);
2. 记下电脑端的 ID + 永久密码,iPad 输入即连;
3. 重度使用:自建中继(hbbs/hbbr,Docker 几条命令)或利用 Tailscale 直连,速度大幅提升。

### ToDesk / 向日葵(求省事)
- 官网 [todesk.com](https://www.todesk.com) / [sunlogin.oray.com](https://sunlogin.oray.com),两端装机输码即用。
- 适合给家里长辈电脑排障、自己临时应急;免费版画质帧率有上限,不适合长时间日用。

## 组合建议

- **外网办公主力**:Tailscale + Windows App(RDP)。延迟最低、最省电, iPad 上打字建议配个折叠键盘。
- **不想折腾/家庭版**:RustDesk,进阶自建中继。
- **玩游戏/看视频**:不要用远程桌面,用 Moonlight 串流(画质帧率完全不是一个量级)。
- **临时帮别人/被帮**:Chrome Remote Desktop 或 ToDesk,5 分钟解决。
