# 08 大学生上手路线图（4 周计划）

> 读者：中国高校计算机/电子信息方向大一~大三同学，会折腾软件，但 personal agent 是新手。
> 信息基准日期：2026-10-20。本计划的所有任务均出自 02（Today AI）、03（Grok Bot）、04（开源自建）三份分册，命令与步骤可直接照做。
> 计划主干默认走 **Today AI**（国内可直接访问、现阶段免费），第 2 周和第 4 周给出 Grok 与自建分支。

**时间预算**：每周投入 3-5 小时即可——第 1 周是「连续养成」（每天 15-30 分钟），第 2-3 周是「派任务后等结果」（碎片时间看审批卡），第 4 周集中半天排错。忙季可暂停，长期追踪任务挂在云端不会停。

---

## 0. 开始之前先选分支

| 分支 | 适合谁 | 4 周路径一句话 |
|---|---|---|
| **纯使用派** | 只想把 AI 助理用起来，不碰代码 | 4 周全部在 Today AI / Grok Bot 官方产品里加深用法 |
| **折腾派** | 计算机专业，想搞懂 agent 架构 | 前 2 周用官方产品建立体感，第 3-4 周转入自建（04 分册） |
| **求职/竞赛派** | 想把这段经历变成简历项目 | 按折腾派节奏走，第 4 周把部署过程整理成作品集 |

三个分支共用第 1 周；从第 2 周开始分叉。

## 第 1 周：Today AI 入门（所有人统一）

**周目标**：完成注册→喂上下文→连接邮箱日历→派第一个长期任务→看到第一次早报。这一周不追求花哨，只求「养」起来。

| 天 | 任务（照 02 分册 §2 / §4.5 执行） | 具体动作 |
|---|---|---|
| Day 1 | 下载注册 + 自我介绍 | 手机浏览器打开 https://todayai.cn/downloads 下载；手机号注册（送 1 亿 Tokens + 1 个月 Pro，官网下载页，2026-10）；把 02 分册 §2 第 3 步那段「自我介绍」模板改成你的真实情况发进去 |
| Day 2 | 接第一个连接器 | 右侧面板「能力」Tab → 设置连接应用 → 先接**学习邮箱（小号）+ 日历**（02 §4.6 表格：邮箱实测全程只读，安全） |
| Day 3 | 派第一个长期任务 | 照抄 02 §2 第 5 步的「每周一早 8 点简报」任务，把方向换成你真正关心的（如「STM32 PID 竞赛」） |
| Day 4 | 看第一次早报 + 第一次纠错 | 打开 App 右侧「Today」Tab；挑出 1 条它说对的、1 条说错的，说错的立刻进「记忆」Tab 改正（02 §5.8 节奏） |
| Day 5 | 跑通第一个真实场景 | 用 02 场景 3（日程与待办治拖延）：把这学期死线（期中考/答辩/作业）发给它，要求晚 10 点晚报 |
| Day 6 | 再接一个应用 | 接飞书/腾讯文档（在用就接）或绑定微信（02 §4.6：微信绑定后可在微信里直接给它发语音/图片/文件） |
| Day 7 | 记忆审计 + 周复盘 | 进「记忆」Tab 逐条核对它归纳的画像；统计这一周它主动推的消息里几条真帮忙、几条是打扰（验收标准见下） |

**本周验收标准（全部打勾才算过）**：

1. ✅ 收到至少 2 次早报，且早报里出现了你真实的课程/日程信息；
2. ✅ 「记忆」Tab 里能看到关于你的条目，且你手动改过至少 1 条；
3. ✅ 有一个长期追踪任务在跑（每周/每天自动执行）；
4. ✅ 能用一句话回答：「它这周帮我提前处理了什么？」——答不出就按 02 §7 的避坑表收紧连接和推送。

> 新手最容易犯的错：把它当普通聊天框，问一个问题就关掉。Today 的价值在「长期养」，前三天上下文越足，第四天的早报越准（02 §2）。

## 第 2 周：高级玩法（按分支分叉）

### 分支 A（纯使用派 / 折腾派主干）：Today AI 高级玩法

**周目标**：连接器生态、定时任务、云端电脑三件武器上手。

| 天 | 任务 | 出处 |
|---|---|---|
| Day 1-2 | 给它派一个「重活」：课件整理 | 02 场景 1：把本周课件 PDF 发进去，要求整理成带小节标题的复习笔记，每周日汇总「没搞懂的知识点」 |
| Day 3-4 | 用云端电脑跑一次代码任务 | 02 场景 6：发一个仓库 zip，让它在云端构建、翻译注释、生成中文 README——体验「长任务不用自己电脑开机」 |
| Day 5 | 再挂一个定时任务 | 02 场景 10：英语听力口语陪练（每周二/四晚 8:30 发 3 分钟对话练习），套用官网定时任务示例 |
| Day 6-7 | 账单/订阅监控（可选但推荐） | 02 场景 9：盯付款/账单类邮件，陌生扣费标「可疑」——实测同类玩法「安心感拉满」（阑夕，2026-09-24） |

**验收标准**：云端电脑任务你能在侧边栏看到它的执行过程；定时任务连续跑满一周没断。

### 分支 B（想玩 Grok Bot 的人）：Grok Bot 订阅与建 Bot

**周目标**：装 App、注册、建第一个 Bot、跑通最短路径。

按 03 分册 §3 的 10 步执行，本补充注意三点：

1. **先验证网络再注册**：大陆可用性存在新旧口径矛盾（旧：无法直连，读懂马斯克 2026-07；新：实测不需科学上网、可支付宝开通，36氪 2026-10-13）——注册前先用自己网络验证一次（03 §2）。
2. **免费套餐起步**：额度 7 天重置；激活免费试用需绑信用卡，Free 模式不主动扣款（腾讯云教程，2026-10）。
3. **第一个 Bot 别贪全**：名字/岗位/描述三字段，描述写「岗位契约」不写操作步骤（03 §5.1）；执行型和咨询型 Bot 分开建（03 §5.2）。

**本周每日节奏**：

| 天 | 任务 |
|---|---|
| Day 1 | x.ai/bot 下载桌面端 → Grok/X/Cursor 账号登录 → 浏览器认证回跳；第一次弹窗问 Gmail 先跳过（03 §3 第 4 步） |
| Day 2 | 建第一个 Bot（如「课代表小郭」），写岗位描述；发 03 §3 第 6 步那段「搜索 STM32 教程整理成 Markdown」任务 |
| Day 3 | 右栏「电脑」标签看它开 Chrome 干活；遇到审批卡点一次「只放行这一次」；**绝不把验证码贴进聊天框**（03 §3 第 8 步） |
| Day 4 | 手机端登同账号，远程发一句「把刚才那份笔记重发我一份」，验证手机链路（03 §3 第 9 步） |
| Day 5 | 说一句「把刚才这套搜索整理流程存成 Skill」，把成功流程沉淀（03 §3 第 10 步） |
| Day 6-7 | 翻 Settings → Usage & Billing 看免费额度用了多少；故意造一次「先询问」规则感受 Auto-Review（03 附录 A 第 2 周节奏） |

**验收标准**：手机 App 与桌面端登同一账号，找到同一个 Bot，互相能收到消息；练习一次「看屏旁观 + 审批接管」手感（03 §7）。

## 第 3 周：工作流自动化（跑通 3 个个人工作流）

**周目标**：把第二周的单点功能串成自动运转的流水线。以下 3 个工作流均出自分册已有场景（与 05 实战工作流分册对应），选定你的常用工具链执行。

### 工作流 1：信息盯梢周报（竞赛/实习方向）

- **怎么做**：Today AI 版用 02 场景 8（盯目标公司校招 + 面经更新，每周三早发简报）；Grok Bot 版用 03 场景 1（每天早 8 晚 8 巡检官网，有更新才说话）。
- **关键规则写进指令**：「没有就别发」「每条一句话说清这对我有什么用」。
- **验收**：连续 7 天，它按约定时间点推送，漏推/错推不超过 1 次。

### 工作流 2：学习笔记流水线（长文/课件 → 结构化笔记）

- **怎么做**：Today AI 版用 02 场景 1；Grok Bot 版用 03 场景 2（英文长文→中文 Markdown 笔记 + 术语中英对照）。
- **关键规则写进指令**：「连续两周没发资料就主动提醒我是不是落下了」（02 场景 1 原文）。
- **验收**：产出一份你真的拿去复习/参考的笔记，而不是看完就删。

### 工作流 3：日报 + 账单分诊（收束型工作流）

- **怎么做**：Grok Bot 版用 03 场景 3（晚 10 点固定三块日报）+ 场景 7（邮件只做归档/星标/草稿，发信必审批）；Today AI 版用 02 场景 9 + 场景 3 的晚报。
- **关键规则写进指令**：「永远不要未经审批直接发信」（03 场景 7 原文）。
- **验收**：你连续 3 天没手动整理过收件箱和待办，也没漏掉一封老师/组委会邮件。

> 纯使用派本周结束即到站：你已经拥有一套自动运转的个人系统。折腾派继续第 4 周。

## 第 4 周：开源自建（折腾派 / 求职派）

**周目标**：按 04 分册在自己电脑部署 OpenClaw 或 Hermes Agent，完成一个接 Telegram（或微信桥）的 bot。

| 天 | 任务（照 04 分册执行） | 出处 |
|---|---|---|
| Day 1 | 注册 DeepSeek 开放平台，充 ¥10，创建 API key | 04 §1.5 第 1 步 |
| Day 2 | 装 OpenClaw（Windows PowerShell：`iwr -useb https://openclaw.ai/install.ps1 \| iex`），跑 `openclaw onboard --install-daemon`，网页控制台发通第一条消息 | 04 §3.3 / §3.4 |
| Day 3 | 接 Telegram：@BotFather 建 bot 拿 token，`openclaw pairing approve telegram <code>` 批准，手机里说上第一句话 | 04 §3.5 |
| Day 4 | 挂第一个定时任务：「每天早 8 点发西安天气和今日课表」 | 04 场景 A |
| Day 5 | （可选对比）装 Hermes Agent：`iex (irm https://hermes-agent.nousresearch.com/install.ps1)`，体验 `hermes doctor`、持久记忆与 cron 的差异 | 04 §4.3 / §4.4 |
| Day 6-7 | 排错 + 写总结：卡壳先翻 04 §8 排查表（网关没起来/pairing 拦截/401 base_url/杀软误报 uv.exe 等） | 04 §8 |

**验收标准**：

1. ✅ 手机 Telegram 里你的 bot 能回消息、能执行定时任务；
2. ✅ 用 `/usage`（Hermes）或控制台查过一次 token 用量，算得出自己月成本（参考 04 §5.2：轻度用国产模型 ¥5~20/月）；
3. ✅ 安全红线全部确认：Gateway 没裸暴露公网、配对审批开启、API key 没传公开仓库（04 §3.8 / §8.5）。

> 国内没有 Telegram 的同学：社区已有微信桥方案（如 HermesClaw 类桥接工具可让 agent 共用一个微信号），也有对接飞书/钉钉的用户实践（04 §3.5）——注意微信桥需自行找社区方案，配置成本高于 Telegram。

## 求职 / 竞赛派：把项目沉淀为简历作品

第 4 周结束后，多加这一步：

1. **写一篇技术博客/GitHub 项目**：含架构图（Gateway/Channels/Skills/Memory 四层，参考 04 §3.1）、踩坑记录、成本账单（04 §7 第 4 周原文建议）。
2. **作品集整理建议**：
   - 仓库 README 写清「解决什么问题 + 我的 agent 住在哪 + 每周花多少钱」；
   - 附 1-2 个可演示截图：Telegram 里的定时日报、云端电脑跑代码的过程；
   - 写明技术选型理由（OpenClaw vs Hermes，照 04 §2 对比表讲）；
   - 标注局限：官方产品（Today/Grok）做不到的点你是怎么自己补上的——这比「我会装环境」有说服力得多。
3. **简历条目写法示例**（照这个颗粒度写，不写空话）：
   ```
   个人项目 · 自建 Telegram 个人助手（OpenClaw / Hermes Agent）
   - 在 Windows/VPS 部署开源 agent 框架，接入 Telegram 与 DeepSeek API，
     实现每日天气课表简报、学习笔记整理两个无人值守工作流；
   - 对比评估 OpenClaw 与 Hermes Agent（391k / 253k stars），按持久记忆与
     cron 需求选型；实测月 token 成本 ¥13（DeepSeek flash）并写入成本文档；
   - 处理过网关未启动、API key 401（base_url 配置）、杀软误报 uv.exe 等
     环境问题，排查过程沉淀为 README FAQ。
   ```
4. **面试话术素材**：03 分册附录 C 的对照表可直接用于回答「你怎么看云端托管 vs 自托管」——成本、数据主权、运维责任三个维度；07 分册的权限模型与审批机制部分，可用于回答「让 AI 代你操作账号安全吗」——连接器优先、高危动作先询问、凭证走沙箱三件套。

## 常见放弃原因与对策

| 放弃原因 | 真实出处 | 对策 |
|---|---|---|
| **新鲜感消退，一周后不打开了** | 晚点 LatePost：用户画像两极分化，「要么粘性非常高，要么用不起来、很快放弃」（2026-10-16） | 用 02 §5.8 的验证方法：一周后回看，有几条提醒真帮你提前处理了问题？前者多就继续养；同时第 1 周只接 1-2 个连接器，别贪多 |
| **单一长对话不适应** | 有用户下载手机端两分钟就卸载（晚点 LatePost，2026-10-16）；用惯 ChatGPT「一事一开窗」的人会觉得乱 | 复杂任务让它自动拆到「任务」栏，主对话只用来聊（02 §7.1）；Grok 侧对应做法：执行型/咨询型 Bot 分开建，群聊里 @ 分工 |
| **报错卡住，翻不动** | 自建侧：npm 卡住、API key 401、Gateway 发消息没反应、杀软误报（04 §8 排查表）；Grok 侧：时不时不响应要重置云电脑（腾讯云教程，2026-10-09） | 自建先跑 `hermes doctor` / `openclaw gateway status` 再求助；401 先查 base_url 是不是填了 DeepSeek 兼容地址；Grok 卡死再重置，重置前先把重要文件移出资料库 |
| **它太笨/太笃定地错** | Today 汉化 mod 自信连错指令折腾用户一小时（极客公园十天实测，2026-10-08） | 硬知识任务命令它「先查官方文档再回答」，关键步骤自己复核——这不是 bug 是使用姿势 |
| **推送变打扰** | 项目取消了它还每天催（抖音测评，2026-10-02） | 推错一次就说「这条以后不用提醒我」；追踪任务指令写死「没有就别发」 |
