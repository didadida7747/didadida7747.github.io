# 个人健康记录模板集:一套可以填一辈子的表格

> 一句话定位:11个即拷即用的 markdown 模板,覆盖健康档案、自测记录、症状日记、就医准备、用药与体检对照、年度计划和紧急信息卡——复制到你的笔记工具(备忘录/语雀/Notion/Obsidian 均可),按月或按年填写。
>
> ⚠️ 免责声明:本文为科普整理,不构成医疗建议;记录数据仅供自己和医生参考,具体诊疗请遵医嘱。

---

## 🎯 使用说明

- **怎么用**:每个模板复制到自己的笔记工具,建议建一个"健康记录"文件夹,按模板分文件;表格行不够就往下复制空行。
- **填写频率**:模板①一次性填+每半年核对;②③④按测量频次填;⑤每周填一次;⑥症状出现时填;⑦每次就医前填;⑧每次用药变动时填;⑨⑩每年一次;⑪一次性填+每年更新。
- **三个原则**:
  1. **记事实,不记诊断**——"下午3点头疼,7分,像戴了紧箍咒"比"我觉得我脑子有病"有用一百倍;
  2. **少而持续**——每周一条比每天打卡坚持三个月然后放弃强;
  3. **就医必带**——模板⑥⑦⑧是看医生的"作弊小抄",直接照着说。

## 模板② 血压自测记录表

> 填写说明:适用于医嘱要求监测血压,或家里有高血压史的日常观察。测前静坐5分钟,袖带与心脏同高,**同一时间、同一侧手臂**连测;记录1-2次测量中后一次的值。家里一次偶测偏高别慌,连测一周看趋势;高血压诊断须由医生做出。

## 模板③ 血糖自测记录表

> 填写说明:适用于血糖偏高者按医嘱自测,或孕期/家族史监测。"空腹"指隔夜8小时以上未进食;餐后2小时从**吃第一口饭**开始计时。每次连测记录1次即可。偶发偏高先复查;诊断糖尿病只能由医生做。

## 模板④ 体重腰围月记录表

> 填写说明:每月固定1天(如1号早晨、晨起空腹、如厕后)测量并记录。体重秤放硬地,腰围经肚脐水平绕一圈(呼气末读数)。**BMI = 体重(kg) ÷ 身高(m)²**,18.5~23.9 为成人合适范围(中国标准,示意);腰围男 <90cm、女 <85cm 较理想(示意)。看趋势,不看单日波动。

## 模板⑥ 症状日记(就诊前记录)

> 填写说明:任何反复出现或持续的不适,每次发作填一行;**坚持记3-7天再去看医生,效果翻倍**。程度1-10分(1=几乎没感觉,10=这辈子最痛)。这表直接回答医生必问的问题:什么时候开始、多疼、多久、什么诱因、吃了什么药有没有用。配合《05-就医与体检/01-就医全流程指南》的描述模板使用。

## 模板⑦ 就医问题清单

> 填写说明:每次看病前花2分钟写好**最多5个问题**(超过5个医生也答不完),按重要性排序,把最想解决的放第一个。进诊室先说清单第一条;医生的答复当场记在"答复"栏,出诊室再看一遍确认都问了。别不好意思念小抄——医生反而喜欢准备好的病人。

**就诊基本信息:** 日期:____ 医院/科室:____ 医生:____

| # | 我想问的问题 | 医生的答复 |
|---|---|---|
| 1(最重要) | 例:我反复胃痛3周,最可能是什么原因?需要做什么检查? | |
| 2 | 例:这个药饭前还是饭后吃?要吃多久? | |
| 3 | 例:出现什么情况必须马上回来复诊? | |
| 4 | 例:日常生活要注意什么(忌口/运动/熬夜)? | |
| 5 | 例:多久后复查?复查前要做什么准备? | |

**离开前自查三件事**:① 我知道"这可能是什么"了吗?② 药怎么吃、吃多久清楚吗?③ 危险信号和复诊时间记下了吗?→ 补充医嘱:________________

## ⚠️ 常见误区

| 误区 | 正解 |
|---|---|
| "记录要完美,断了一天就重头再来" | 健康记录是看趋势的,断断续续也比没有强;补一行"漏记"继续 |
| "数据自己看着办" | 模板②③④的自测数据要**定期给医生看**,自测的意义是提供诊疗参考,不是自我诊断 |
| "症状日记太麻烦,看病时口头说" | 口头回忆会漏时间线和诱因,而医生诊断恰恰最依赖这些;门诊几分钟,小抄是效率最高的沟通工具 |
| "体检指标抄下来没用" | 三年对照表能暴露单年看不出的缓慢趋势(尿酸逐年爬升、LDL-C慢慢抬头),这是体检报告本身做不到的 |
| "紧急信息卡是老年人的事" | 年轻人运动损伤、低血糖、哮喘发作时同样需要;过敏史那一行对急救最重要 |
| "把所有隐私都写进卡里" | 紧急卡只放急救必需信息;详细档案放笔记工具并注意账号安全 |
