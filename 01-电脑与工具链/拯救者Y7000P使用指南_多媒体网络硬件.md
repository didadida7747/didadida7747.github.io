# 拯救者 Y7000P 使用指南（i7 + RTX 4060 + 16GB + 1TB）

> 读者画像：电子信息工程大二学生，电脑基础薄弱，本文所有操作均按"小白能跟着做"的标准写。

# 第一部分：多媒体创作与娱乐

## 一、视频剪辑

你的 RTX 4060 支持 **NVIDIA NVENC 硬件编码**，视频导出速度比纯 CPU 编码快 3～5 倍，这是 40 系显卡做剪辑最大的福利。下面四款软件按"从新手到专业"排序。

### 1. 剪映专业版（强烈推荐入门首选）

- **官网下载**：<https://www.capcut.cn/> （点首页"下载客户端"→ Windows 版）
- **价格**：基础功能永久免费；SVIP 会员约 30 元/月，主要解锁 4K 导出、部分特效素材，学生党不买也够用。
- **为什么适合你**：中文界面、自动字幕、AI 抠像、模板一键套用，上手 10 分钟就能剪出一条带字幕的 vlog。
- **核心功能**：时间线剪辑、自动语音转字幕、转场特效、文字模板、绿幕抠像、色度键。
- **4060 加速**：剪映会自动调用 NVENC 导出，4K 短视频导出约 1～2 分钟一条，无需手动设置。

### 2. DaVinci Resolve（达芬奇）—— 免费版即专业级

- **官网下载**：<https://www.blackmagicdesign.com/products/davinciresolve/> （页面底部"Download"，选 **DaVinci Resolve** 免费版，不要选 Studio 付费版）
- **价格**：免费版功能已覆盖 95% 的个人使用场景；Studio 付费版一次性约 2000 元，解锁 4K 以上时间线、神经网络引擎全功能，学生暂不需要。
- **特色**：全球调色行业标准，色彩科学远超剪映和 Premiere；自带 Fairlight 音频调音台、Fusion 节点特效合成。
- **学习成本**：比剪映陡，建议 B 站搜"达芬奇 20 分钟入门"先过一遍流程。
- **4060 加速**：**强烈建议在偏好设置里手动开启**——菜单 `DaVinci Resolve → 设置 → 系统 → 内存和 GPU`，把 GPU 处理模式改成"OpenCL"或"CUDA"，勾选 RTX 4060。开启后时间线实时回放、调色节点都不卡。

### 3. Adobe Premiere Pro（行业标准）

- **官网**：<https://www.adobe.com/cn/products/premiere.html>
- **价格**：按月订阅约 98 元/月；**学生优惠**见 <https://www.adobe.com/cn/creativecloud/buy/students.html>，凭 `.edu.cn` 邮箱学信网验证，首年约 18 元/月（含 Photoshop、Illustrator 等 20+ 软件全家桶），大二学生非常划算。
- **适合谁**：未来想进 MCN、广告公司、新媒体岗位的同学；和 After Effects、Photoshop 联动最顺。
- **4060 加速**：PR 在"文件 → 项目设置 → 常规 → 渲染程序"选 **Mercury Playback Engine GPU 加速（CUDA）**，导出时勾选"使用硬件编码编码"。

### 4. OBS Studio —— 录屏 / 直播

- **官网下载**：<https://obsproject.com/> （首页绿色按钮"Windows"）
- **价格**：完全免费、开源、无水印。
- **用途**：
  - **课程录屏**：录老师的板书、录自己做实验的过程、录单片机演示视频。
  - **直播**：B 站直播、游戏直播。
- **新手最简设置**：
  1. 打开 OBS → 来源左下角"+"→"显示器采集"（录整个屏幕）或"窗口采集"（只录某个窗口）。
  2. 若要录自己说话：来源"+"→"音频输入采集"→ 选麦克风。
  3. 右下角"设置 → 输出"：输出模式选"简单"，录像质量选"高质量，近似无损"，录像格式选 **mkv**（崩溃不丢文件，录完可用 OBS 自带"重新混合"转 mp4）。
  4. "设置 → 视频"：基础分辨率 1920×1080，帧率 30 FPS（录课够用）。
- **4060 加速**：设置 → 输出 → 输出模式切"高级"→ 录像 → 编码器选 **NVENC H.264**，画质拉满，CPU 占用极低。

### 5. 四款软件配置要求与 4060 支持一览

| 软件 | 内存建议 | 硬盘占用 | RTX 4060 加速 | 你的 16GB 内存够吗 |
|---|---|---|---|---|
| 剪映专业版 | 16GB 起 | ~5GB | NVENC 自动 | 够，但建议加到 32GB |
| DaVinci Resolve | **32GB 起**（强烈建议） | ~3.5GB | CUDA/OpenCL，必须开 | **16GB 会卡**，尤其 4K 工程 |
| Premiere Pro | 16GB 起，32GB 舒服 | ~2GB/版本 | CUDA 水银引擎 | 16GB 可做 1080p |
| OBS Studio | 8GB 起 | ~150MB | NVENC 编码 | 完全够 |

> **提示**：你现在 16GB 内存跑剪映、OBS、PR 1080p 没问题；但一旦上 DaVinci Resolve 剪 4K 或者同时开着微信+浏览器+PR，就会开始吃硬盘虚拟内存（卡顿）。**升级到 32GB 是这本子最值得花的一笔钱**，详见第三部分。

## 二、图像处理

### 1. Adobe Photoshop

- **官网**：<https://www.adobe.com/cn/products/photoshop.html>
- **价格**：学生全家桶（见上方 PR 学生链接）已包含 PS，不用单独买。单买 PS 约 34 元/月。
- **用途**：课程海报、证件照排版、电路图截图美化、抠图、修产品图。
- **4060 加速**：PS 的"滤镜 → Neural Filters（神经网络滤镜）"会调用 GPU，AI 抠图、AI 生成式填充在 4060 上速度不错。

### 2. GIMP —— 免费开源 PS 替代品

- **官网下载**：<https://www.gimp.org/downloads/> （选 Windows 安装包）
- **价格**：完全免费、开源。
- **适合**：偶尔做个简单修图、不需要 PS 高级功能、不想订阅 Adobe 的同学。界面和 PS 高度相似，快捷键可改。
- **局限**：对 PSD 复杂图层兼容偶有问题，没有 AI 生成式填充。

### 3. Krita —— 数字绘画 / 插画

- **官网下载**：<https://krita.org/en/download/>
- **价格**：免费开源（官网可自愿捐款）。
- **适合**：喜欢画插画、做手书、画分镜的同学；笔刷系统比 PS 更适合手绘，压感支持好。

### 4. 格式转换工具

批量改尺寸、转格式、压缩图片体积，别一张张手动改：

- **XnConvert**（图形化界面，新手推荐）：<https://www.xnview.com/en/xnconvert/>
  - 拖入一整个文件夹 → 左侧选操作（调整大小、改格式、加水印）→ 右侧选输出 → 转换。
- **ImageMagick**（命令行，进阶）：<https://imagemagick.org/script/download.php>
  - 适合需要批量处理几百张图的场景，例如 `magick *.jpg -resize 50% output/%03d.png`。

## 三、游戏性能优化

### 1. 拯救者 Y7000P 自带开关（最优先做这一步）

Y7000P 有两个硬件级开关，用键盘上方的 **Fn + Q** 循环切换性能模式：

| 模式 | 风扇 | CPU/GPU 功耗 | 适用场景 |
|---|---|---|---|
| 安静模式（蓝灯） | 低噪 | ~30W | 图书馆写作业、看视频 |
| 均衡模式（白灯） | 适中 | ~60W | 日常上网、轻度游戏 |
| **野兽模式（红灯）** | 起飞 | 满血 ~140W+ | 玩 3A 大作、剪视频导出 |

**独显直连（MUX Switch）必开**：
1. 打开自带的 **联想电脑管家**（任务栏右下角救星图标，或开始菜单搜"联想电脑管家"）。
2. 进入"硬件设置"→"显示设置"→ 把 **混合模式** 切到 **独显直连模式**，重启生效。
3. 原理：默认混合模式下画面要先经过核显再输出，有一帧损耗；独显直连让 RTX 4060 直接输出到屏幕，游戏帧数通常高 10%～20%。代价是略费电，插电玩时再开即可。

### 2. NVIDIA 控制面板优化

桌面右键 → "NVIDIA 控制面板" → 左侧"管理 3D 设置" → "程序设置"标签页，逐个游戏添加：

- **电源管理模式**：选"**首选最高性能**"（防止游戏中途降频）。
- **低延迟模式**：选"**超高**"（竞技网游如 CS2、Valorant 降低输入延迟）。
- **纹理过滤-质量**：选"高性能"（帧数优先）。
- **垂直同步**：游戏内关掉，控制面板也关（除非画面撕裂严重再开 G-SYNC）。

**DLSS / 帧生成（Frame Generation）**：
- RTX 4060 支持 **DLSS 3 帧生成**。游戏内画质设置里把 DLSS 模式切到"**质量**"档（1080p/2K 下画质损失极小，帧数提升 50%～100%）。
- 支持的游戏：《赛博朋克 2077》《黑神话：悟空》《原子之心》《星空》等新 3A；老游戏不支持。
- 设置位置：游戏内"图像/显示"菜单 → DLSS 超分辨率 → 质量档；"帧生成"开关单独打开。

### 3. 常见游戏画质平衡建议（2K 165Hz 屏）

| 设置项 | 建议 | 原因 |
|---|---|---|
| 分辨率 | 原生 2560×1600 | 不要乱拉分辨率缩放 |
| 预设画质 | 高（不是极致） | "极高"和"高"肉眼几乎无差，帧数差 20% |
| 阴影质量 | 中/高 | 阴影最吃性能，收益最低 |
| 体积云/体积光 | 中 | 同上 |
| 抗锯齿 | TAA + DLSS 质量 | DLSS 自带抗锯齿 |
| 纹理质量 | 高 | 4060 有 8GB 显存，撑得住 |
| 视距 | 高 | 影响竞技性 |

### 4. 游戏帧数监控工具

- **MSI Afterburner + RivaTuner Statistics Server（RTSS）**：
  - 下载：<https://www.msi.com/Landing/afterburner/graphics-cards> （注意：MSI 官方警告只有 msi.com 和 Guru3D 是正版，其他都是钓鱼站）
  - 安装时勾选"RivaTuner"。装完后：
    1. 打开 Afterburner → 点齿轮"设置"→"监控"标签。
    2. 勾选"帧率""GPU 温度""GPU 使用率""CPU 温度""内存使用率"，每项都勾上"在 OSD 上显示显示速率"。
    3. 进游戏后屏幕左上角就有实时帧数/温度叠加层。
- **NVIDIA FrameView**（轻量替代）：
  - 下载：<https://www.nvidia.cn/geforce/technologies/frameview/>
  - 由 NVIDIA 官方出，测帧数和功耗更准，体积小。

## 四、游戏串流与远程游玩

> **背景知识**：NVIDIA 曾在 GeForce Experience 里内置 GameStream 串流功能，但**官方已于 2023 年停更**。现在的开源方案是 **Sunshine（服务端，装在 Y7000P 上）+ Moonlight（客户端，装在平板/电视/另一台电脑上）**。

### 1. Sunshine —— 服务端（装在 Y7000P 上）

- **项目地址（GitHub）**：<https://github.com/LizardByte/Sunshine>
- **下载**：进 Releases 页，下载 `SunshineWindows.exe` 安装包，一路下一步。
- **首次启动**：
  1. 会弹出一个网页管理后台（`https://localhost:47990`），首次设置用户名和密码。
  2. 在"应用"标签里添加你想串流的游戏（比如 Steam 大图标路径）。
  3. 保持 Y7000P 插电、连路由器网线（或 5GHz WiFi）。

### 2. Moonlight —— 客户端（装在平板/手机/电视上）

- **官网**：<https://moonlight-stream.org/>
- **GitHub**：<https://github.com/moonlight-stream>
- **下载**：
  - Windows / macOS / Linux：官网首页下客户端。
  - 安卓：应用商店搜"Moonlight Game Streaming"。
  - iPad / iPhone：App Store 搜 Moonlight。
  - 电视：Android TV 版直接装；Apple TV 也有客户端。
- **配对步骤**：
  1. 电脑和平板连**同一个路由器**（最好都走 5GHz WiFi 或网线）。
  2. 打开 Moonlight，会自动发现 Y7000P，点击它。
  3. 屏幕上出现一个 4 位 PIN 码，输入到 Sunshine 网页后台的"PIN"栏里确认配对。
  4. 之后在 Moonlight 里点游戏图标就能串流启动。
- **推荐参数**：分辨率 1080p、帧率 60FPS、码率 20～40 Mbps（WiFi 好就拉满）。延迟通常 10～30ms，玩单人游戏完全无感。

### 3. Steam Link —— 更简单的备选

- **官网/下载**：<https://store.steampowered.com/app/353380/Steam_Link/>
- 如果你只玩 Steam 游戏，Steam Link 开箱即用，不用装 Sunshine，直接在同一局域网下发现你的 Steam。
- 缺点：只串 Steam 库里的游戏，非 Steam 启动器（Epic、战网）需要在 Steam 里"添加非 Steam 游戏"才行；延迟比 Moonlight 略高。

# 第二部分：网络与安全

## 一、校园网与网络配置（本校专属）

> 以下信息来自本校信息网络技术中心官网（校园网内网系统

### 1. 连接方式

**无线网络**：
- 学生搜索 SSID：**`stu-xdwlan`**
- 教工搜索 SSID：`xd-wlan`
- 翼讯用户（学生）：`xd-yixun`
- 连接后：打开浏览器访问任意网址（如 `1.1.1.1`），会自动跳转到认证页面。
- **账号**：你的学号；**初始密码**：身份证后六位（若末位是 X 则大写）。首次登录后务必改密码。
- 认证方式：第一次手动页面认证后，系统会记住设备，下次自动连（无感知认证）。

**有线网络**：
- 宿舍网口插网线后，Windows 设置 → 网络 → 拨号 → 设置新连接 → **宽带（PPPoE）**。
- 输入学号 + 密码拨号即可。
- 官方说明：<https://校园网内网系统

**资费**：校园网有月流量套餐（迎新网说明每月基础 10GB，超出后需叠加包，具体以信息中心当期通知为准）。

### 2. 认证客户端

本校校园网**不需要装任何第三方拨号客户端**（不同于某些学校的 Dr.COM）。Windows 自带 PPPoE 拨号和浏览器 Portal 认证就够了。如果学校后续推出"一网通办"App 或网页认证插件，按信息中心通知安装即可。

### 3. DNS 优化

校园网默认 DNS 偶尔抽风（解析慢、某些网站打不开）。手动改成公共 DNS 能改善：

- **阿里 DNS**：`223.5.5.5` 和 `223.6.6.6`
- **腾讯 DNSPod**：`119.29.29.29`

**设置方法**：
1. 右下角网络图标右键 → "网络和 Internet 设置"→ 高级网络设置 → 更多网络适配器选项。
2. 右键当前网卡（WLAN 或 以太网）→ 属性。
3. 双击"Internet 协议版本 4 (TCP/IPv4)"。
4. 选"使用下面的 DNS 服务器地址"，首选填 `223.5.5.5`，备用填 `119.29.29.29`。

### 4. 关于私接路由器

> **重要**：本校信息中心提供了路由器配置手册（<https://校园网内网系统 PPPoE 方式在路由器 WAN 口拨号，而不是把校园网当二级交换机转发。

- 学校手册里明确写了 TP-Link、小米路由器的 WAN 口接法：WAN 口接墙上网线，上网方式选"宽带拨号（PPPoE）"，输入学号密码。
- **不要**把校园网进线插路由器 LAN 口当交换机用——这会导致 IP 冲突、整层楼断网，被信息中心检测到可能封号。
- 宿舍多人共享一个账号：理论上一个账号同时在线设备数有限制，建议和室友各办各的，不要试图用路由器破解。

## 二、远程访问

### 1. Windows 远程桌面（RDP，仅连同网段 Windows 专业版）

- **开启被控端**（被连接的电脑）：设置 → 系统 → 远程桌面 → 打开。注意：**Windows 家庭版没有 RDP 服务端**，只有专业版/企业版能被远程；你的 Y7000P 出厂是家庭中文版，所以这台只能当主控，不能被 RDP 连。
- **使用**：另一台 Win 专业版电脑按 `Win + R` → 输入 `mstsc` → 输入对方 IP。
- 局限：只能同局域网，且被控方必须是 Win 专业版。

### 2. Tailscale —— 异地组网神器（强烈推荐）

- **官网**：<https://tailscale.com/>
- **原理**：基于 WireGuard 协议的零配置虚拟局域网。装完登录同一个账号，你在宿舍、在教室、在回家的高铁上，所有设备就像在同一个 WiFi 下一样互访，不需要公网 IP，不需要配端口映射。
- **使用场景**：
  - 在宿舍用平板串流 Y7000P 上的游戏（Moonlight + Tailscale 可实现外网串流）。
  - 从笔记本连回实验室的服务器。
  - 手机和电脑互传大文件。
- **使用方法**：
  1. 电脑去官网下载 Windows 客户端安装。
  2. 用 Google / Microsoft / GitHub 账号登录。
  3. 手机也装 Tailscale App，登录同一账号。
  4. 两台设备会各拿到一个 `100.x.x.x` 的虚拟 IP，互 ping 即可。
- **价格**：个人免费版最多 100 台设备，学生完全够用。

### 3. ToDesk / 向日葵 —— 国内远程桌面

| 对比项 | ToDesk | 向日葵（贝锐） |
|---|---|---|
| 官网 | <https://www.todesk.cn/> | <https://sunlogin.oray.com/> |
| 免费版限制 | 每月有免费时长，个人偶尔用够 | 免费版限速 30 帧，画质一般 |
| 优势 | 国内节点多、延迟低、界面简洁 | 生态全（开机棒、智能硬件多） |
| 适合 | 偶尔帮别人修电脑、自己临时远程 | 需要远程开机、企业运维 |
| 注意 | 仅从官网下载，百度搜出来的假冒站很多 | 官方域名必须以 `.oray.com` 结尾 |

**建议**：装一个 ToDesk 备用即可，比向日葵清爽。

### 4. SSH 远程连接实验室服务器

大二进实验室后，师兄师姐大概率会给你一台 Linux 服务器的 IP 和账号。Windows 上操作：

1. 开始菜单搜"**PowerShell**"或装一个 Windows Terminal。
2. 直接输入：
   ```
   ssh 用户名@服务器IP
   ```
3. 首次连接输 `yes` 确认指纹，然后输密码（输入时屏幕不显示字符，正常现象）。
4. 传文件用 `scp` 命令，或装 WinSCP（<https://winscp.net/>）图形化拖拽。

## 三、安全防护

### 1. Windows Defender 够不够？

**够了。** 2026 年的 Windows Defender（现在叫 Microsoft Defender）在 AV-TEST、AV-Comparatives 等独立测评里常年排第一梯队，对学生党完全够用。

**不建议装的**：
- 360 安全卫士、腾讯电脑管家、金山毒霸——弹窗多、捆绑多、占资源，反而拖慢游戏本。
- 两个以上杀毒软件同时装——会互相打架。

**建议**：保持 Defender 默认开启，Windows 安全中心里把"实时保护""云提供的保护"都打开就行。

### 2. 防火墙基本设置

- Windows 自带防火墙默认开启，不要关。
- 第一次运行某个软件（如游戏、OBS）弹"是否允许访问网络"时，**家庭/专用网络勾允许，公用网络不勾**。
- 不要用"防火墙一键关闭"类优化脚本。

### 3. 浏览器安全习惯

- 认准地址栏 `https://` 和小锁图标。
- **绝对不要**从"下载站"（太平洋下载、ZOL、当下下载之类）下载破解软件、激活工具、"绿色版"PS——90% 捆绑木马、挖矿程序、浏览器劫持。
- 要下软件只去：**官网**、**Microsoft Store**、**Steam**、**Microsoft 官方站**。
- 浏览器装一个 **uBlock Origin** 扩展（Chrome/Edge 商店搜），去广告同时挡恶意脚本。

### 4. Bitwarden —— 密码管理器

- **官网**：<https://bitwarden.com/>
- **为什么你需要它**：
  - 校园网、微信、QQ、邮箱、B站、Steam、银行卡、各种选课系统……一个学生至少有 20+ 个账号。
  - 人类记不住 20 个不同强密码，结果就是所有网站用同一个密码——**一个网站泄露，全部账号被盗**。
  - Bitwarden 帮你给每个网站生成随机强密码，你只需要记一个"主密码"。
- **价格**：免费版无限设备、无限密码库，完全够用。
- **使用流程**：
  1. 官网注册账号，设置一个**超长主密码**（至少 16 位，这个一定要记牢，忘了谁也救不回来）。
  2. 浏览器装 Bitwarden 扩展。
  3. 以后注册新网站，扩展会自动生成密码并保存；登录时自动填充。
  4. 手机也装 App，指纹解锁。

### 5. 两步验证（2FA）

开完密码管理器后，给最重要的账号再上一层保险：

- **必开 2FA 的账号**：邮箱（QQ/163/Outlook）、微信、支付宝、银行卡 App、Steam、Bitwarden 本身。
- **怎么开**：账号设置 → 安全 → 两步验证/身份验证器。
- **推荐用 Bitwarden 自带的 TOTP 功能**（它本身就能当身份验证器 App 用），不用再装 Google Authenticator。
- **一定要备份恢复码**：开 2FA 时会给你一串恢复码，手抄下来放钱包里，手机丢了能救命。

## 四、数据备份策略

### 1. 3-2-1 备份原则

业界黄金法则，记住三句话：
- **3** 份数据副本（原文件 + 2 份备份）。
- **2** 种不同介质（比如电脑硬盘 + 移动硬盘 + 网盘）。
- **1** 份异地备份（不在宿舍，比如云端网盘或家里的硬盘）。

学生最容易丢的是：毕业论文、课程设计、代码仓库、照片。这些文件别只存在 C 盘。

### 2. Windows 文件历史记录（免费自动备份）

- 设置 → 账户 → Windows 备份；或控制面板搜"文件历史记录"。
- 插一块 U 盘/移动硬盘，开启后它会自动定时备份"桌面、文档、图片、下载"这几个文件夹。
- 优点：全自动；缺点：只备份库文件夹，且硬盘得一直插着。

### 3. 外接硬盘 / 移动 SSD（推荐主力备份）

- **推荐**：三星 T7 / 致态 木星 移动 SSD（1TB 约 400～500 元），USB-C 接口，速度 1000MB/s，比机械移动硬盘快 5 倍。
- 每周把"文档、课程、代码"文件夹手动拷一次过去。
- 机械移动硬盘（如西部数据 My Passport 2TB）更便宜，但怕摔、震，宿舍桌面不稳慎选。

### 4. 网盘备份

| 网盘 | 免费空间 | 适合 |
|---|---|---|
| OneDrive | 5GB（Office 365 学生版可能送 1TB） | 本校学生若通过学校激活了微软 Office，先去 <https://www.office.com/> 看看有没有送 1TB OneDrive |
| 百度网盘 | 2TB（需手机 App 领） | 存冷数据、分享大文件，下载限速烦人 |
| 阿里云盘 | 免费空间大、不限速 | 视频、照片备份首选 |

**原则**：网盘只做"异地副本"，不要把网盘当主存储（同步盘经常出现"一边删了另一边也同步删了"的惨案）。

### 5. 重要文件加密

- **VeraCrypt**（开源免费）：<https://www.veracrypt.fr/>
- 用途：给移动硬盘/U 盘建一个加密卷，丢了别人也读不出来。
- 场景：论文、证件扫描件、私密照片放进 VeraCrypt 加密盘，出门带着不慌。
- 用法：创建加密卷 → 设置密码 → 挂载成一个新盘符 → 把文件拖进去 → 退出卸载。

# 第三部分：硬件维护与升级

## 一、散热与温度管理

### 1. HWiNFO64 —— 看温度最准的工具

- **官网下载**：<https://www.hwinfo.com/download/> （选"Installer"或"Portable"都行）
- 打开后选"Sensors only"，你能看到：
  - CPU 每一个核心的温度、功耗、频率。
  - GPU 核心温度、热点温度、功耗、显存频率。
  - 主板温度、电池放电率、硬盘通电时间。
- **用法**：玩游戏时最小化挂后台，切出来瞄一眼温度即可。

### 2. MSI Afterburner —— 显卡监控

- 下载地址见前面游戏帧数监控部分。
- 它的曲线编辑器可以调风扇转速曲线（比如让风扇 70°C 以上就猛转），**但不建议小白拉核心频率/显存频率超频**——笔记本散热余量有限，超频收益小、风险大。只用来监控温度和调风扇曲线即可。

### 3. 正常温度范围（Y7000P 2024，i7-14650HX + RTX 4060）

| 状态 | CPU 温度 | GPU 温度 | 说明 |
|---|---|---|---|
|  idle（桌面浏览） | 40～55°C | 35～45°C | 正常 |
| 看视频 / 写代码 | 55～70°C | 45～55°C | 正常 |
| 满载游戏（野兽模式） | **85～95°C** | **75～85°C** | 正常，游戏本撞 95°C 墙是设计如此 |
| 待机超过 70°C / 游戏 CPU 撞 100°C 降频 | — | — | 该清灰换硅脂了 |

> 游戏本 CPU 满载 90°C 左右**不是问题**，Intel HX 系列的温度墙就是 100°C。别被网上"CPU 超过 80 度就要炸"的说法吓到。

### 4. 散热底座 / 抽风式散热器有用吗？

- **散热底座**（吹风式，垫在电脑下面）：效果约 3～5°C，聊胜于无，主要作用是把笔记本垫高、进风更顺畅。50～100 元的即可，没必要买太贵。
- **抽风式散热器**（卡在出风口）：效果明显，能降 8～12°C，但噪音大、长期用可能对风扇轴承有影响，且 2024 款 Y7000P 是后方出风，抽风式安装不太方便。
- **真正有用的三件事**：① 野兽模式打游戏；② 保证进风口不被枕头/被子堵住（桌面硬平处使用）；③ 半年到一年清一次灰。这三条比任何散热器都管用。

## 二、清灰与保养

### 1. 清灰周期

- 宿舍环境灰尘大，建议 **6～12 个月**清一次。
- 信号：风扇明显比新买时吵、同样的游戏帧数变低、CPU 满载温度长期 95～100°C 不降。

### 2. 清灰步骤（概述，动手前先看 B 站对应型号视频）

> **Y7000P 2024 拆机注意**：后盖螺丝全部是 **Phillips #0 十字螺丝**（不是手机那种三角，也不是大号）。底壳一圈约 10 颗螺丝，其中靠近转轴的几颗螺丝是**防掉设计**——拧松后不会掉出来，但不要硬拔。撬开底壳用塑料撬片，不要用一字螺丝刀硬撬（会留痕）。

步骤：
1. **关机、拔电源、拔掉所有外设**。
2. 拧下底壳所有螺丝，按位置摆好（不同长度螺丝装错会顶穿主板！建议在纸上按位置摆）。
3. 用塑料撬片沿缝隙撬开底壳，揭开。
4. **第一件事：断开电池排线**（用塑料撬棒把电池排线插头从主板上拔起来），这一步不断电有短路风险。
5. 用软毛刷 + 吹气球（或低压吹风机冷风吹）清理风扇叶片、散热鳍片出风口的灰尘。
6. 若同时换硅脂：拧下散热模组螺丝（对角线顺序松），取下铜管，用无尘纸巾擦掉旧硅脂，CPU 和 GPU 芯片上挤绿豆大小新硅脂，装回铜管，对角线顺序拧紧。
7. 接回电池排线，盖回底壳，拧螺丝。

### 3. 硅脂推荐

- **信越 7921**（约 30 元/小管）：经典款，偏硬，需要用力压平，效果稳定。
- **利民 TFX**（约 50 元）：粘度低、好涂，导热系数 12.8 W/mK，新手友好。
- **相变片（如 PTM7950）**：B 站最近很火，撕膜贴上即可，不会干，但操作要冷藏后再撕膜。
- 别买杂牌"含银硅脂"，大多是坑。

### 4. 自己清灰 vs 售后清灰

- **联想官方售后清灰**：保内通常收费 100～199 元（具体看服务站报价），优点是不动你保修、有问题能找。
- **自己清**：成本 0（硅脂 30～50 元），但有风险——撬断外壳卡扣、碰掉小元件、装回去多螺丝。
- **建议**：第一次清灰**先去售后**，站在旁边看一遍工程师怎么拆；第二次以后再自己动手。
- **保修问题**：联想官方明确说明——拯救者用户自行升级内存/SSD **不影响整机保修**（<https://newsupport.lenovo.com.cn/>），且全国服务站可以免费帮你安装自购的内存和硬盘；但**自行拆机清灰过程中造成的损坏不在保修范围**。

## 三、硬件升级（这本子最大的优势）

Y7000P 2024 的内部设计对升级非常友好：**两个内存插槽、两个 M.2 SSD 插槽**，出厂只插了一根 16GB 内存和一块 1TB SSD，留给你大量升级空间。

### 1. 内存升级（最优先做）

- **现状**：单根 16GB DDR5 5600MHz SO-DIMM（笔记本内存条，和台式机不通用）。
- **推荐方案**：**再加一根 16GB DDR5 5600MHz**，组成 32GB 双通道。
  - 优先买和原厂同频率（5600MHz），品牌不限（镁光、海力士、三星颗粒都行）。
  - **具体型号推荐**：
    - 金百达 16GB DDR5 5600 笔记本内存（约 180 元，国产长鑫颗粒，性价比高）
    - 光威（Gloway）天策 16GB DDR5 5600（约 180 元）
    - 三星 16GB DDR5 5600 SODIMM（约 250 元，最稳妥）
  - 别买 DDR5 4800 或 6400——4800 会降频亏性能，6400 在 14650HX 上也会被降到 5600 跑，浪费钱。
- **为什么是 32GB**：大二开始跑 Keil、STM32、MATLAB、多开虚拟机、再开 PR/达芬奇，16GB 会告急；32GB 能稳到毕业。
- **安装**：底壳拆开（见上文），内存插槽在屏蔽盖下面，拨开两侧金属卡扣，新内存斜插入、按下即可自动锁定。

### 2. SSD 升级

- **现状**：1TB M.2 2280 NVMe PCIe 4.0 SSD 已占用主插槽；**第二个 M.2 2280 插槽空闲**（出厂已配好固定螺丝柱）。
- **推荐方案**：加一块 **2TB PCIe 4.0 NVMe SSD**，把游戏、视频素材、虚拟机镜像扔到第二块盘。
  - **具体型号推荐**：
    - **致态 TiPlus 7100 2TB**（约 850 元）：长江存储颗粒，国产首选，无缓设计但温控好，兼容笔记本。
    - **三星 990 EVO 2TB**（约 900 元）：老牌稳定，五年质保。
    - **西数 SN850X 2TB**（约 1000 元）：性能天花板，但笔记本上发热略大。
  - **别买**：SATA 协议 M.2（插上去不认）、QLC 颗粒杂牌盘（掉速严重）。
- **安装后**：
  1. 开机进系统，右键开始菜单 →"磁盘管理"。
  2. 会提示"初始化磁盘"，选 **GPT**。
  3. 右键未分配空间 →"新建简单卷"→ 一路下一步，给个盘符（比如 D:）。
  4. 不需要装系统，不需要迁移——新盘直接当仓库盘用即可。
  5. 旧系统盘不动，开机照常进 Windows。

### 3. 关于保修

- 联想拯救者系列**允许用户自行升级内存和硬盘**，不影响保修（联想官方知识库明确说明）。
- 如果你不想自己动手，带着自购的内存/SSD 去任意联想服务站，工程师**免费帮你装**（不含数据迁移和系统安装）。
- 但要注意：自己拆机导致的外壳损坏、排线断裂不在保修范围；去服务站升级最省心。

## 四、外接显示器方案

### 1. Y7000P 视频接口

- 机身左侧 **HDMI 2.1 全功能口**：支持外接 4K 120Hz 或 2K 165Hz 显示器，一线通。

- **尺寸**：27 寸是甜点（24 寸字太小，32 寸 2K 颗粒感略重）。
- **接口**：必须有 HDMI 2.0/2.1 或 DP 输入。

### 3. 性价比型号推荐

- **Redmi 27 寸 2K 165Hz**（约 900 元）：学生党性价比之王，IPS 屏，色准够用。
- **KTC H27T22**（约 800 元）：同价位竞品，165Hz，支架一般。
- **AOC Q27G3S**（约 1100 元）：品牌售后好，旋转升降支架。
- **LG 27GS85Q**（约 2000 元）：预算充足的话，Nano IPS 色质越级。

### 4. 双屏设置

- 插上显示器后：设置 → 系统 → 显示 →"多显示器设置"选"**扩展这些显示器**"。
- 效率用法：笔记本屏放聊天/微信/网课，外接大屏放 IDEA/VS Code/仿真软件；写代码时一边看文档一边写代码。
- 记得在外接显示器设置里把刷新率选到 165Hz（默认可能只给 60Hz）。

## 五、电池保养

### 1. 电池养护模式（最重要）

Y7000P 长期插电当台式机用，**必须**开启充电阈值保护，否则电池常年 100% 满电状态，2 年就鼓包。

**设置方法**：
1. 打开 **联想电脑管家**。
2. 进"硬件设置"→"电源设置"。
3. 找到"**电池养护模式**"或"充电阈值"，开启。
4. 推荐设置：充电上限 **60%**（长期插电不带走时）或 **80%**（每周会带出门时）。
5. 开启后，插电时电池充到 60% 就不再充，由电源直接给主板供电，电池几乎不参与循环，寿命大大延长。

### 2. 长期插电使用的正确方式

- 插电时一定要开野兽模式或均衡模式，让电池不参与供电。
- **不要**把电池用到自动关机再充——锂电池怕过放。
- 每个月至少做一次完整的充放电循环（用到 20% 再充满），防止电池电量计漂移。

### 3. 查看电池健康度

- **方法一**：联想电脑管家 → 硬件信息 → 电池，会显示"电池损耗"百分比。
- **方法二**（命令行）：开始菜单搜 PowerShell，输入：
  ```powershell
  powercfg /batteryreport
  ```
  会生成一个 HTML 报告路径，用浏览器打开，看"设计容量"和"完全充电容量"的比值。新机器应在 95% 以上；用两年掉到 80% 以下就该考虑换电池了。

### 4. 外出省电技巧

- Fn+Q 切到安静模式。
- 设置 → 系统 → 电源 → 屏幕 5 分钟关闭、睡眠 10 分钟。
- 关掉独显直连（切回混合模式），浏览网页用核显更省电。
- 音量、键盘背光调小。
