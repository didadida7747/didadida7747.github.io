# 第4章 文件与目录操作命令

> 本章是命令量最大的一章。学完你就能在终端里完成"新建项目、整理文件、删东西、找文件、打包备份"这一整套日常操作——这是后端开发每天都在做的事。

## 本章你将学会

- 用 `pwd` / `cd` 在目录间自由穿梭
- 用 `ls` 看清楚一个目录里所有东西的详细信息
- 用 `mkdir` / `touch` / `cp` / `mv` / `rm` 增删改文件和目录
- 用 `ln -s` 建软链接
- 用 `find` 在整棵文件树里按名字/类型/大小找文件
- 用通配符批量操作一堆文件
- 用 `tar` / `zip` / `gzip` 打包压缩
- 综合练习：从零搭一个项目目录树并打包备份

## 4.1 pwd —— 我现在在哪

在 GUI 里你看着窗口标题就知道自己在哪。终端里你看不见，所以第一个要学的是 `pwd`（print working directory，打印当前工作目录）：

```bash
$ pwd
/home/zhangsan
```

就这么简单。迷路了就敲一下。

## 4.2 ls 全解 —— 看目录里有什么

这是你这辈子敲得最多的命令。风格规范里那个样板就是它，我们完整过一遍。

```bash
$ ls
Desktop  Documents  Downloads  Music  Pictures  Public  Templates  Videos
```

光秃秃的文件名信息量太少。配合 `-l` 长格式：

```bash
$ ls -l
```

```text
total 36
drwxr-xr-x 2 zhangsan zhangsan 4096 Oct 13 10:21 Desktop
-rw-r--r-- 1 zhangsan zhangsan  892 Oct 13 09:05 notes.txt
```

逐字段拆给你看：

| 字段 | 示例 | 含义 |
|---|---|---|
| 第 1 个字符 | `d` / `-` | 类型：`d` 目录，`-` 普通文件，`l` 软链接 |
| 后面 9 位 | `rwxr-xr-x` | 权限位（第 6 章细讲，现在眼熟即可） |
| 硬链接数 | 2 | 暂时不管 |
| 属主 | zhangsan | 文件主人 |
| 属组 | zhangsan | 所属组 |
| 大小 | 4096 | 字节，目录一般显示 4096 |
| 日期 | Oct 13 10:21 | 最后修改时间 |
| 名字 | Desktop | 文件名 |

常用选项表：

| 选项 | 作用 |
|---|---|
| `-l` | 长格式详细信息 |
| `-a` | 显示所有文件，**包括 `.` 开头的隐藏文件** |
| `-h` | human-readable，大小显示成 K/M/G，**要和 `-l` 搭配** |
| `-t` | 按修改时间排序，最新的在前 |
| `-r` | 反序（配合 `-t` 用就是最老的在前） |
| `-R` | 递归列出所有子目录（文件多的时候慎用） |

```bash
$ ls -lh /etc
$ ls -lht
$ ls -la
```

> 💡 **小技巧：选项可以合并，`ls -l -a -h` = `ls -lah`。** 很多环境里 `ll` 是配好的 `ls -alF` 别名，敲 `ll` 更好使（第 12 章教你自己配）。

## 4.3 cd 全家桶 —— 切换目录

`cd`（change directory）你已经用过了。补全几个变体：

| 命令 | 作用 |
|---|---|
| `cd /var/log` | 切到绝对路径 |
| `cd project` | 切到当前目录下的 project |
| `cd ..` | 上一级 |
| `cd ../..` | 上两级 |
| `cd ~` 或 `cd` 回车 | 直接回家目录 |
| `cd -` | 回到上一次待过的目录 |

> 💡 **小技巧：直接敲 `cd` 回车，不带任何参数，等于 `cd ~`。** 不管你在哪个犄角旮旯，一键回家。

## 4.4 mkdir 和 rmdir —— 建/删空目录

```bash
$ mkdir myproject
$ cd myproject
```

一次建多层目录用 `-p`（parents）：

```bash
$ mkdir -p src/utils/config
```

不加 `-p` 的话，`src` 不存在时这条命令会报错。加了 `-p`，它会把中间缺的层级一起建好。

`rmdir` 用来删目录，但**只能删空目录**：

```bash
$ rmdir myproject
```

里面有东西它会拒绝。真要删整个非空目录，用下面的 `rm -r`。

## 4.5 touch —— 新建空文件

```bash
$ touch hello.txt
```

如果文件不存在，它就建一个空文件；如果已经存在，它只更新一下文件的修改时间（不删内容）。这个命令在项目里常用来"占位"——先建个空文件再说。

## 4.6 cp —— 复制

基本用法：

```bash
$ cp hello.txt hello_backup.txt
```

复制目录要加 `-r`（recursive）：

```bash
$ cp -r myproject myproject_backup
```

常用选项：

| 选项 | 作用 |
|---|---|
| `-r` / `-R` | 递归复制目录（复制目录必加） |
| `-i` | interactive，覆盖前问你一下 |
| `-a` | archive，连权限、时间戳一起复制（备份常用） |

> 💡 **小技巧：** 不确定会不会覆盖原文件时加 `-i`，它会问你 `overwrite?`，输 `y` 才真覆盖。

## 4.7 mv —— 移动 / 重命名

`mv`（move）一身二用：

```bash
# 重命名
$ mv hello.txt hello_world.txt

# 移动位置
$ mv hello_world.txt docs/
```

目标是同目录下的新名字 = 重命名；目标是另一个目录 = 移动。`mv` 不需要 `-r`，目录直接移。

## 4.8 rm —— 删除（本章最重要的安全节）

```bash
$ rm hello.txt
```

删文件用 `rm`。删目录要加 `-r`：

```bash
$ rm -r myproject_backup
```

选项：

| 选项 | 作用 |
|---|---|
| `-r` | 递归删除目录及其内容（删目录必加） |
| `-f` | force，不问你直接删（危险！） |
| `-i` | 每个文件都问你一遍（安全） |

> ⚠️ **警告：`rm -rf` 是 Linux 里最危险的组合拳，没有之一。**
>
> - `-r` 是递归删整个目录树，`-f` 是"别问我直接删"。
> - Linux 的删除**不进回收站**，删了就是真没了，没有"右键撤销"。
> - 如果你在错误的目录下敲了 `sudo rm -rf /`，整个系统就没了。
>
> **安全守则三条：**
> 1. 删之前先 `ls` 看一眼要删的东西到底是什么，确认无误再删。
> 2. 没把握的时候用 `rm -ri`（加 i），让它一个个问你。
> 3. **绝对不要把 `rm -rf` 和通配符 `*` 组合起来瞎试**，比如 `rm -rf * .txt`——那个空格会让它先把当前目录全删了再删 .txt。
> 4. 永远先敲 `rm --help` 或 `man rm` 确认选项，别凭记忆。

## 4.9 ln —— 建链接

第 3 章讲过概念了，现在动手。建软链接（最常用）：

```bash
$ ln -s /home/zhangsan/data/project /home/zhangsan/shortcut
```

意思是：在你家目录建一个叫 `shortcut` 的软链接，指向 `data/project`。以后 `cd ~/shortcut` 就等于 `cd ~/data/project`。

建硬链接（了解即可）：

```bash
$ ln notes.txt notes_hard.txt
```

`ls -l` 看到链接那一行开头是 `l`，后面会跟一个 `->` 指向原文件：

```text
lrwxrwxrwx 1 zhangsan zhangsan 20 Oct 13 11:00 shortcut -> data/project
```

## 4.10 find —— 全局找文件

你在 GUI 里用 Windows 搜索框找文件，命令行里用 `find`。它的语法稍微特殊一点：

```bash
find 从哪找 找什么 怎么找
```

最常见的几种用法：

**按文件名找：**

```bash
$ find /home/zhangsan -name "*.txt"
```

意思是：在 `/home/zhangsan` 下面，找所有名字匹配 `*.txt` 的文件。`-name` 区分大小写，想不区分用 `-iname`。

**按类型找：**

```bash
$ find /var/log -type f -name "*.log"
```

`-type f` 只要文件；`-type d` 只要目录。

**按大小找：**

```bash
$ find /home/zhangsan -size +100M
```

`+100M` 是大于 100MB；`-10k` 是小于 10KB。

**按修改时间找：**

```bash
$ find /home/zhangsan -mtime -7
```

`-mtime -7` 是 7 天内修改过的；`+30` 是 30 天以前。

**找到之后执行命令（-exec，入门）：**

```bash
$ find /home/zhangsan -name "*.tmp" -exec rm {} \;
```

翻译：找出所有 `.tmp` 文件，对每一个执行 `rm`。其中 `{}` 代表找到的每个文件，结尾 `\;` 是固定写法。

> ⚠️ **警告：`find ... -exec rm` 组合威力巨大。** 先用不带 `-exec` 的命令跑一遍，看看它找到哪些文件，确认列表对，再加 `-exec rm`。

## 4.11 通配符 —— 批量操作

Shell 自带几个通配符，帮你一次匹配多个文件：

| 符号 | 匹配什么 | 例子 |
|---|---|---|
| `*` | 任意长度任意字符 | `*.txt` 所有 txt 文件 |
| `?` | 单个任意字符 | `fig?.png` 匹配 fig1.png、figa.png |
| `[abc]` | 方括号里任选一个 | `file[123].txt` 匹配 file1/2/3.txt |
| `{a,b,c}` | 展开成 a、b、c 三个 | `cp a.txt{,.bak}` 备份成 a.txt.bak |

试一下：

```bash
$ ls *.txt
$ rm *.tmp
$ mkdir {src,docs,tests}
```

最后一条会一次建三个目录：`src`、`docs`、`tests`。`{}` 展开是写脚本的常用技巧。

## 4.12 tree —— 树形看目录结构

`tree` 默认没装，先装一下（第 8 章会细讲 apt）：

```bash
$ sudo apt install tree
```

然后：

```bash
$ tree
.
├── docs
│   └── note.txt
└── src
    └── main.py
```

一眼看清目录结构。加 `-L 2` 限制只显示两层，目录深的时候别全展开。

## 4.13 du —— 看谁占了空间

`df -h` 看整个磁盘用了多少（第 9 章细讲），`du` 看某个目录占了多少：

```bash
$ du -sh /var/log
120M    /var/log
```

`-s` 是 summary（只总结一行），`-h` 是人类可读。想找当前目录下哪个子目录最占空间：

```bash
$ du -sh */ | sort -h
```

## 4.14 tar —— 打包压缩

Linux 里最常用的打包工具是 `tar`（tape archive）。它的选项字母组合看起来吓人，其实就两组：

**打包 + 压缩（.tar.gz）：**

```bash
$ tar -czvf project.tar.gz project/
```

**解包：**

```bash
$ tar -xzvf project.tar.gz
```

**只看不解（列出内容）：**

```bash
$ tar -tvf project.tar.gz
```

选项含义：

| 字母 | 含义 |
|---|---|
| `-c` | create，创建打包文件 |
| `-x` | extract，解包 |
| `-t` | list，列出内容 |
| `-z` | 用 gzip 压缩（.gz） |
| `-j` | 用 bzip2 压缩（.bz2，压缩率更高但更慢） |
| `-J` | 用 xz 压缩（.xz，压缩率最高最慢） |
| `-v` | verbose，显示处理了哪些文件 |
| `-f` | file，后面紧跟文件名（必须放最后） |

> 💡 **小技巧：记不住就死记两个组合——`czvf` 打包、`xzvf` 解包。** 看到 `.tar.gz` 就用 z，看到 `.tar.bz2` 把 z 换成 j，看到 `.tar.xz` 换成 J。

## 4.15 zip / unzip / gzip

`tar` 打的包 Windows 资源管理器也能打开，但和 Windows 用户传文件时用 `.zip` 更保险：

```bash
$ sudo apt install zip unzip
$ zip -r project.zip project/
$ unzip project.zip
```

`gzip` 只压单个文件（不打包），压完原文件变成 `.gz`：

```bash
$ gzip notes.txt        # 压成 notes.txt.gz，原文件消失
$ gunzip notes.txt.gz   # 解回来
```

> 📌 **注意：`gzip` 不打包，只能压一个文件；要"多个文件打包在一起再压缩"，用 `tar -z`。** 这就是为什么大家都用 `.tar.gz`——tar 负责打包，gzip 负责压缩。

## 4.16 综合练习：搭一个项目目录树并打包

下面我们从头到尾做一遍。假设你要搭一个叫 `myblog` 的项目：

```bash
# 1. 回家
$ cd ~

# 2. 一次建多层目录
$ mkdir -p myblog/{src,docs,tests}

# 3. 在里面建几个空文件
$ touch myblog/src/main.py
$ touch myblog/src/utils.py
$ touch myblog/docs/readme.md
$ touch myblog/tests/test_main.py

# 4. 随便写点东西进去
$ echo "# My Blog" > myblog/docs/readme.md

# 5. 树形检查
$ tree myblog

# 6. 打包备份到家目录外面
$ tar -czvf myblog_backup.tar.gz myblog/

# 7. 验证备份内容
$ tar -tvf myblog_backup.tar.gz

# 8. 删掉原目录，从备份恢复试试
$ mv myblog myblog_old
$ tar -xzvf myblog_backup.tar.gz
$ ls
```

整个流程走一遍，你就把本章 80% 的命令都用过了。

## ⚠️ 危险操作与安全红线

- > ⚠️ **`rm -rf` 不可恢复，删前先 `ls`。** 本章 4.8 节那四条安全守则再读一遍。
- > ⚠️ **`find ... -exec rm` 威力大，先 dry-run（不带 -exec）看结果。**
- > ⚠️ **`sudo rm` 比 `rm` 危险十倍**——它不仅删你的文件，还能删系统文件。能不用 sudo 删东西就不用。

## 常见报错与排查

| 现象 | 原因 | 解决 |
|---|---|---|
| `rm: cannot remove 'xxx': Is a directory` | 删目录忘了 `-r` | 加 `-r` |
| `cp: omitting directory 'xxx'` | 复制目录忘了 `-r` | 加 `-r` |
| `No such file or directory` | 文件名打错 / 大小写错 / 路径错 | `Tab` 补全 + `ls` 现场看 |
| `Permission denied` | 要操作的文件不归你 | 加 `sudo`（先确认是不是真的该这么做） |
| `find: paths must precede expression` | find 语法顺序写反了 | 记住顺序：`find 路径 条件` |

## 动手练习

1. 在你家目录建一个 `practice` 目录，里面建 `a/`、`b/` 两个子目录，`touch` 三个空文件。
2. 用 `cp -r` 把 `practice` 复制成 `practice2`，再用 `rm -r` 删掉 `practice2`。
3. 用 `find` 在你家目录找出所有最近 1 天内修改过的文件。
4. 用 `ln -s` 把 `/etc/nginx`（如果装了 nginx）软链接到你家目录，用 `ls -l` 看那个 `->`。
5. 用 `tar -czvf` 把 `practice` 目录打包成 `practice.tar.gz`，移到 `/tmp/` 下，再从 `/tmp/` 解包回来。
6. 用 `du -sh` 看看 `/etc` 占了多大空间。

## 本章小结

| 命令 | 作用 |
|---|---|
| `pwd` / `cd` | 看当前位置 / 切换目录 |
| `ls -lah` | 长格式看目录（人、大小、隐藏文件） |
| `mkdir -p` / `rmdir` | 建（多层）/ 删空目录 |
| `touch` | 新建空文件 |
| `cp -r` / `mv` | 复制 / 移动+重命名 |
| `rm -r` | 删除（-rf 危险！） |
| `ln -s` | 建软链接 |
| `find 路径 -name -type -size` | 找文件 |
| `tar -czvf / -xzvf` | 打包压缩 / 解包 |
| `zip -r / unzip` | 兼容 Windows 的压缩包 |
| `du -sh` | 看目录占多大 |
