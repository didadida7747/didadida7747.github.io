# 看见世界 · 活法与通识地图

一座离线可浏览的 HTML 小站。核心理念：**人无法成为自己没有见过的人，无法拥有没有见过的生活**。小站以「活法」为主线、通识打底，每个主题都落到真实的人和真实生活状态——他们做什么工作、过什么日子、付出什么代价、拿到什么回报，并附可继续深挖的真实延伸入口。

## 文件夹路径

```
E:\ai资料(豆包)\看见世界-活法与通识地图\
```

## 目录结构

| 文件 | 内容 |
|---|---|
| `首页.html` | 站点入口：理念陈述、四大板块导航、使用说明、三条定制阅读路径 |
| `板块一-职业阶层与财富.html` | 15 个主题：行业全景、体制内外、阶层流动、财富认知、房产与消费 |
| `板块二-科技AI与产业趋势.html` | 15 个主题：AI 产业链、大模型应用、Agent、远程工作、期权与职业阶梯 |
| `板块三-社会运行与商业规则.html` | 16 个主题：劳动合同、仲裁、法律常识、征信、户口医保、人情规则、防骗 |
| `板块四-人文心理与全球视野.html` | 16 个主题：各国民生、留学移民、心理学、原生家庭、审美哲学、信息素养 |
| `_shots/` | 各页面的桌面端与移动端自检截图及报告（过程产物，保留备查） |

合计 **62 个主题**，每个主题统一包含四个部分：

1. **是什么**：简明概念与事实框架；
2. **真实的人怎么活**：至少 2 个人物样本，明确写出回报与代价；
3. **关键认知**：3–5 条判断要点，每篇至少 1 条点出农村出身的信息差；
4. **延伸入口**：3–5 个真实存在的书籍、纪录片、网站、报告或人物。

## 如何使用

1. 双击打开 `首页.html`（任意现代浏览器，无需安装任何东西）；
2. 从首页四大板块卡片进入，或沿顶部导航切换；
3. 每个板块页有目录锚点，窄屏手机上目录折叠在「本板块主题目录」中；
4. 页面间链接、底部上一板块/下一板块导航均可直接点击；
5. 小站离线可浏览；仅字体需联网加载，网络失败时自动回退系统字体，不影响阅读。
