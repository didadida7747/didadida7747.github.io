# 04 · 精选脚本推荐（按场景，附合规标注）

> **使用方法**：到 Greasy Fork（或镜像站）按脚本名搜索，优先选**安装量大、评分高、作者明确、近期更新**的同名条目；GitHub 项目直接给出仓库地址。
>
> 标注说明：✅ 放心用（功能正当、社区口碑好）｜⚠️ 按需用（仔细看权限或有返利等副作用）｜❌ 不建议（侵权、违规或高风险，理由见文末）。
>
> 脚本生态变化快，个别脚本可能改名或停更，按"功能关键词"搜索同类替代即可。

## 一、阅读与网页净化 ✅

| 脚本 | 作用 |
|---|---|
| 网页限制解除 | 解除大多数网站的复制、右键、选择限制（仅限你有权访问的内容，尊重版权） |
| 文本选中复制 | 专门对付百度文库、道客巴巴、语雀等禁止复制的站点 |
| 自动展开全文 / 自动展开隐藏 | 去掉"展开阅读全文""打开 APP 查看"、自动展开折叠内容 |
| 骚扰拦截 | 拦截"打开 APP"弹窗、悬浮按钮、下载弹窗 |
| 东方永页机 / 自动无缝翻页 | 自动翻页/瀑布流加载，后者支持 600+ 网站 |
| 拒绝二维码登录 | 让 12306、QQ 等站点默认密码登录 |
| 网页宽屏 | 宽屏显示器上把窄版网页拉宽 |
| 能不能好好说话？ | 把微博、贴吧、B站评论里的拼音缩写（xswl、yyds 等）还原成中文 |
| Dark Reader（也有扩展版） | 全站黑夜模式；扩展版性能更好，二选一 |

> 提示：去广告优先用 **uBlock Origin** 等专用扩展（网络层拦截，更省资源）；脚本适合处理扩展覆盖不到的个性化页面元素。

## 五、学习与科研（学生重点）✅

| 脚本 | 作用 |
|---|---|
| 下载文章为 Markdown / 网页转 MD | 把 CSDN、知乎、公众号、B站专栏等文章一键导出为 Markdown/Word，便于归档到你的知识库 |
| 知乎增强 | 移除登录弹窗、屏蔽首页视频、默认收起回答、净化页面 |
| CSDN 人性化脚本 | 免登录阅读、去外链重定向、页面净化（配 uBlock 效果更好） |
| 学术科研网页辅助工具 | 文献站点去广告、精简排版、快速操作（到 Greasy Fork 搜"学术"按评分挑选） |
| 文献库增强类 | 知网、Google Scholar、IEEE、ACM 等页面的下载入口聚合（如 KBS-Panda 等校园网场景脚本）——**仅在你通过学校授权合法访问的前提下使用** |
| 网课视频倍速/按键控制类 | 给网页播放器加快捷键与倍速（自己看录播、回放时用） |
| MD Viewer | 浏览器直接渲染 Markdown 文件 |

> **❌ 明确不建议：刷课/代看类脚本**（如自动挂超星/学习通、自动答题、自动刷视频时长）。
> 理由不是技术问题，而是**学术诚信与校规风险**：各平台有行为检测，学校会通报、清除成绩直至处分；本校对课程考核违纪有明确处理办法。倍速看自己有权看的回放 = 效率，脚本替你"上课" = 代学作弊，界限要清楚。

## 八、购物类 ⚠️

- 历史价格/比价类脚本（商品页显示价格走势）：功能正当，但**这是 Antifeature（返利声明）高发区**——脚本可能在购物链接里夹带返利参数，作者拿佣金。
- Greasy Fork 允许返利功能但**必须明确标注**。安装前到脚本页底部查看"Antifeature"声明；对"一个脚本号称集合几十个功能"的大杂烩尤其谨慎，这类多为搬运拼接，冲突和失效概率高。
- 真正的比价需求可以用口碑更好的独立扩展替代。

## 九、安装量参考思路

Greasy Fork 没有"官方榜单"，但可以这样判断：
1. 安装量数万以上 + 评分人数多 + 好评为主；
2. 作者主页有多个长期维护的脚本；
3. 评论区近期还有有效反馈、作者在回复；
4. 最近更新时间在 1 年以内（网站频繁改版，超过 2 年不更新的脚本大概率失效）。
