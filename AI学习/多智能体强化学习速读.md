# 多智能体强化学习速读

这一份是帮你从“单智能体 RL”过渡到“多智能体 RL”的。  
你现阶段的目标不是复现复杂论文，而是先理解：多智能体到底比单智能体多了什么难点。

## 什么叫多智能体

如果一个环境里不止一个决策主体，而且这些主体会彼此影响，就进入了多智能体强化学习的范围。

最常见的两类场景：

- 协作：多个 agent 共同完成任务
- 竞争：一个 agent 的收益会影响另一个 agent

当然也可能是混合场景，有合作也有对抗。

## 为什么它比单智能体更难

你现阶段只需要抓住下面 3 个难点：

### 1. 其他智能体也在变

在单智能体 RL 里，环境通常被看成相对固定。  
但在多智能体里，其他 agent 也在学习，所以你的环境等于一直在变。

这就是“非平稳性”最直观的来源。

### 2. 观测与目标更复杂

每个 agent 看到的信息可能不一样，目标也可能不完全一致。  
有的任务要求共享信息，有的任务要求博弈。

### 3. 训练组织更麻烦

你不仅要考虑“一个策略怎么更新”，还要考虑：

- 多个 agent 是不是共用参数
- 谁和谁共享信息
- 奖励怎么设计
- 训练时用全局信息还是局部信息

## 你现在只要先懂的几个词

### 协作

多个 agent 朝同一个大目标努力。

### 竞争

一个 agent 做得更好，可能意味着另一个 agent 更差。

### 非平稳性

因为其他 agent 也在变化，所以你看到的环境分布不是固定的。

### CTDE

`CTDE` 是 `Centralized Training, Decentralized Execution`。  
可以先把它理解成：

- 训练时允许用更多全局信息
- 真正执行时每个 agent 只按自己的局部观测行动

这是一类非常常见的多智能体思路。

## 这些方法名你先混个脸熟

你当前阶段不用硬啃公式，只要知道它们存在、常见、各有风格：

- `MAPPO`
- `MADDPG`
- `QMIX`

你现在最重要的不是区分论文细节，而是知道：

- 它们都是多智能体领域常见方法
- 训练和执行的信息组织方式很关键

## 你为什么现在不用急着复现复杂项目

因为你现在的目标是尽快形成“老师愿意继续带你”的状态。  
对这个目标来说，多智能体阶段最重要的是：

- 知道它研究什么
- 知道它为什么难
- 知道一个典型环境和交互方式长什么样

这已经足够支撑你和老师展开下一步交流。

## 看多智能体环境时该盯什么

你看 demo 或文档时，只看这几个问题：

1. 一共有几个 agent
2. 每个 agent 什么时候轮到自己行动
3. 每个 agent 能看到什么
4. 每个 agent 能做什么动作
5. 奖励是共享还是各自独立

## PettingZoo 为什么适合你现在看

因为它是很常见的多智能体环境库，而且文档清楚、接口明确，适合入门建立感觉。

PettingZoo 的基本使用文档展示了一个非常直观的交互方式：  
环境 `reset()` 后，通过 `agent_iter()` 轮到不同 agent 依次行动；当前 agent 用 `last()` 获取观测、奖励和结束状态，再通过 `step(action)` 推进环境。  
来源：PettingZoo Basic Usage。  
链接：https://pettingzoo.farama.org/content/basic_usage/

这个接口和单智能体 Gym 风格很像，但多了“轮到哪个 agent 行动”的组织方式。  
这正是你应该重点感受的地方。

## 你看多智能体 demo 时，不要要求自己做到什么

现在先不要要求自己：

- 复现论文成绩
- 完整读懂复杂训练框架
- 一次性搞懂所有方法差异

你只需要做到：

- 知道多智能体的研究对象是什么
- 能说清它比单智能体难在哪里
- 看懂一个基础环境的交互流程
