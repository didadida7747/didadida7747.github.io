# CS 自学指南（csdiy.wiki）

> 官方站点：\<https://csdiy.wiki/> ｜ 作者：PKUFlyingPig（北京大学信科本科生，CSAPP 助教）
> 开源免费，源码在 GitHub `PKUFlyingPig/cs-self-learning`，可 star / 提 PR。

## 这份资料是什么

一本开源的**计算机自学指南**：作者大一时从零基础开始自学，把三年里亲身体验过的国内外高质量 CS 课程逐一写成导读——这门课讲什么、难度如何、作业工作量多大、自学要注意什么。作者自评它"更像一个**根据我的体验来排序的课程搜索引擎**"。

关键特征：

- **只收录作者亲自学完/跟过的课**，几乎每门课都有独立 GitHub 仓库维护资料与作业实现；
- 覆盖从入门到进阶的完整路线，且**每门课都告诉你"怎么自学"而不只是"学什么"**；
- 免费开源，持续更新（当前版本已加入深度生成模型/大语言模型路线）。

- **UCB CS61A**——作者的"梦开始的地方"，零基础友好的 Python 入门；
- **CMU 15-213 (CSAPP)**——计算机系统基础经典；
- **MIT 6.S081 / UCB CS162**——操作系统；**Stanford CS144 / UCB CS168**——计算机网络；

- **GAMES101**——图形学入门；**Harvard CS50x**——编程通识入门。

## 怎么用（大二版建议）

1. **当地图，不当教材**：不要从第一页读到最后一页。正确姿势是——本学期上计组，就去查"计算机系统/体系结构"板块，看有没有值得平行跟的公开课和实验；
2. **每门课的"自学建议"先读**：作者会写清这门课的坑（比如作业量大、需要什么前置），帮你判断现在跟是不是时候；
3. **配合求职方向用**：结合本站 [求职研究 · 技术栈优先级](/02-职业方向规划/求职研究/技术栈优先级)，锁定 2–3 个方向板块深耕，而不是全图点亮；
4. **工具板块现在就补**：Git / Make / Docker / 信息检索四篇与 [MIT Missing Semester](/07-学业与深造/自学资源/MIT-Missing-Semester) 互为补充，一个讲原理一个讲实操。
