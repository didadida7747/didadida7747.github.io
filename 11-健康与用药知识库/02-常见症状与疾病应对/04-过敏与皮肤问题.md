# 过敏与皮肤问题:鼻炎、荨麻疹、湿疹、痘痘、晒伤、脚气

> 一句话定位:从打喷嚏到烂脸再到过敏性休克——这篇把年轻人最高发的过敏与皮肤问题一次讲清,重点是"保湿是基础治疗、激素不可怕、严重过敏要会识别"。

> ⚠️ 免责声明:本文为科普整理,不构成医疗建议;具体诊疗与用药请遵医嘱/咨询药师;出现急重症立即拨打 120。

---

## 🎯 核心速览(TL;DR)

1. 过敏性鼻炎的规范处理是"**洗鼻+鼻用激素喷雾+远离过敏原**";鼻用激素是第一线,**不是"猛药"**,规范使用全身吸收很少,但要**朝鼻腔外侧壁喷、别对着鼻中隔**。
2. 荨麻疹首选**第二代抗组胺药**(氯雷他定、西替利嗪等):一天一次、不嗜睡或轻嗜睡;第一代(扑尔敏等)嗜睡明显,不再作首选。
3. **湿疹/特应性皮炎:保湿是基础治疗**,不是"锦上添花"——每天多次、洗完澡 3 分钟内大量涂;激素药膏短期规范用是安全有效的,"激素恐惧"导致不治才是更大的坑。
4. 严重过敏反应(喉头水肿、面色苍白、血压下降、昏厥)**进展只要几分钟**——立即 120;有休克史者应随身携带**肾上腺素自动注射笔**(处方药,概念了解)。
5. 痤疮按"粉刺→丘疹→脓疱→结节囊肿"分级:**中重度该就医就就医**,越拖越留疤;过氧化苯甲酰"白天用"、阿达帕林"晚上用",别同时涂。
6. **别挤痘痘、别挤危险三角区**;防晒贯穿战痘全程;医美"刷酸"是医疗行为,与涂抹低浓度酸的护肤品不是一回事。
7. 晒伤先冷敷+大量保湿;**硬防晒(遮阳伞、防晒衣、墨镜)优先于防晒霜**;SPF 是防UVB的时间倍数,PA 是防UVA等级。
8. 足癣(脚气)用抗真菌药要**坚持足疗程**(症状消失后仍需继续 1~2 周),否则极易复发;鞋袜透气、袜子单独洗。
9. 接触性皮炎的关键是**找出并避开接触物**(项链镍、染发剂、新的洗护产品),再对症用药。
10. 所有具体药品剂量以说明书/医嘱为准。

## 一、过敏性鼻炎:洗鼻+激素喷雾是主线

### 1.1 识别

每年固定季节发作(花粉,春秋高发)或常年发作(尘螨、宠物皮屑、霉菌):**阵发性喷嚏、清水样鼻涕、鼻痒鼻塞、眼痒**——与感冒的区别:不发热、不全身酸痛、持续数周、有明确诱因。

### 1.2 处理阶梯

| 阶梯 | 措施 | 要点 |
|---|---|---|
| 1️⃣ 避开过敏原 | 螨虫:床品每周热水洗+晒;花粉季:关窗、出门戴口罩;宿舍不养毛绒宠物 | 花粉高峰期(晴天上午/傍晚)减少户外 |
| 2️⃣ 生理盐水洗鼻 | 洗鼻器+0.9% 生理盐水,水温 35~37℃ | 身体前倾、头偏一侧、张口呼吸,盐水从一侧鼻孔进另一侧出;每天 1~2 次 |
| 3️⃣ 鼻用激素喷雾 | 糠酸莫米松、布地奈德等(常见示例,OTC/处方均有) | 过敏性鼻炎**一线用药**,起效需数天到 1 周,**要坚持规律用**而非"堵了才喷" |
| 4️⃣ 口服抗组胺药 | 第二代:氯雷他定、西替利嗪等 | 眼痒喷嚏明显时配合使用 |
| 5️⃣ 就医评估 | 规律用药 2~4 周仍反复 | 考虑过敏原检测、脱敏(免疫)治疗 |

### 1.3 鼻用激素喷雾的正确用法(重点)

1. **先洗鼻、后喷药**(分泌物清掉,药物才能接触黏膜)。
2. 摇匀药瓶;头稍前倾,喷嘴插入鼻孔前端即可,**不要完全伸进鼻腔**。
3. **喷嘴朝向鼻腔外侧壁(外眼角方向)**,另一只手按住对侧鼻翼——**不要正对鼻中隔(两个鼻孔中间的隔板)喷**,长期直喷可能导致鼻中隔黏膜损伤甚至穿孔。
4. 喷的同时轻轻吸气,喷完不要立刻仰头或擤鼻涕。
5. 规范使用时全身吸收很少,常见副作用是局部干燥、少量鼻出血——**这与"激素恐惧"担心的全身激素副作用是两回事**。

## 二、荨麻疹:风团来了怎么办

### 2.1 识别与应对

- 表现:**风团**(凸起的红色/苍白色水肿斑块,像被蚊子咬了一大圈)+剧痒,一小时内起、24 小时内消退但此起彼伏;诱因包括食物、药物、感染、冷热刺激、压力、物理摩擦等,很多找不到明确原因。
- 急性处理:
  1. 停止接触可疑诱因(刚吃的药/食物、新用的洗涤剂);
  2. **第二代抗组胺药**是首选(常见示例:氯雷他定、西替利嗪,以说明书为准);
  3. 冷敷止痒;穿宽松棉质衣物;别抓(抓了更痒、风团更多)。

### 2.2 抗组胺药:第一代 vs 第二代

| | 第一代(氯苯那敏/扑尔敏、苯海拉明等) | 第二代(氯雷他定、西替利嗪、依巴斯汀等) |
|---|---|---|
| 嗜睡 | **明显**,影响学习驾驶 | 很轻(西替利嗪部分人有轻微嗜睡) |
| 服药次数 | 每天多次 | 多为每天 1 次 |
| 地位 | 不再作首选,仅短期辅助 | **慢性荨麻疹一线** |
| 实用建议 | 晚上实在痒到失眠时偶用 | 白天要上课/骑车选氯雷他定;西替利嗪止痒可能稍强,可晚间服 |

- 常规剂量效果不佳时,二代药**加量需医生指导**,不自行翻倍。
- 风团**反复超过 6 周**为慢性荨麻疹,建议就诊皮肤科排查。

## 三、接触性皮炎

- 表现:接触部位**边界清楚**的红斑、水疱、瘙痒——比如新换的洗衣液接触的衣领、金属项链/表带(镍)、染发剂(头皮发际线)、劣质耳饰。
- 处理:
  1. **立刻停用可疑接触物并用清水冲洗**——这是根本,比任何药都重要;
  2. 轻度:冷敷+保湿;渗液明显时就医;
  3. 遵医嘱短期外用激素药膏;
  4. 反复发作可做斑贴试验找过敏原。

---

## 四、严重过敏反应:必须会识别(保命技能)

接触过敏原(食物如花生海鲜、药物如青霉素、蜂蜇等)后**几分钟到 1 小时内**出现以下**两项以上**,即按严重过敏反应处理:

| 系统 | 危险信号 |
|---|---|
| 皮肤黏膜 | 大面积荨麻疹+**口唇、眼睑、舌体迅速肿胀**,咽喉发紧 |
| 呼吸 | **声音嘶哑、犬吠样咳嗽、呼吸困难、喘鸣**(提示喉头水肿/气道痉挛) |
| 循环 | **面色苍白、冷汗、头晕、晕厥、脉搏摸不到**(休克) |
| 胃肠 | 突发剧烈腹痛、反复呕吐 |

**急救步骤**:

1. **立即拨打 120**,明确说"严重过敏反应/过敏性休克";
2. 立即脱离/停止接触过敏原;
3. **肾上腺素是唯一首选急救药**,肌肉注射——这是处方场景,但每个人都该知道这个概念:有严重过敏史者应由医生评估**随身携带肾上腺素自动注射笔**(如"肾上腺素笔"),并定期检查有效期;**不要等待、不要先吃抗组胺药观察**;
4. 让患者平卧、双腿抬高(呼吸困难者取舒适半坐位),呕吐时头偏向一侧防误吸;
5. **就算症状缓解也必须就医观察**——过敏反应可能在数小时后"双相"复发。

## 五、湿疹(特应性皮炎):保湿是基础治疗

### 5.1 保湿=治疗,不是护理

- 皮肤屏障受损是核心机制,**每日多次涂抹保湿霜是所有指南共识的基础治疗**;不保湿,再好的药也是"边治边漏"。
- 做法:**洗澡水 37℃ 以下、时间 10 分钟内、用温和低敏清洁剂,擦干后 3 分钟内全身大量涂抹保湿霜**(凡士林、含神经酰胺/尿素类低敏产品均可);平时干燥就补涂。
- 宿舍提示:少用搓澡巾、避免水太烫(烫澡一时爽,屏障火葬场)。

### 5.2 激素药膏:分级与"激素恐惧"

| 强度 | 常见示例 | 适用 |
|---|---|---|
| 弱效 | 氢化可的松乳膏 | 面部、皮肤薄嫩部位、轻度 |
| 中效 | 丁酸氢化可的松、糠酸莫米松(艾洛松)等 | 躯干四肢、中重度发作(常用) |
| 强效/超强效 | 卤米松等 | 一般不用于面部,需医生指导 |

- **正确认知**:在医生/药师指导下、按部位选择合适强度、短期规范使用外用激素,**是安全有效的**,副作用主要是皮肤变薄、色素改变——多与长期、大面积、高强度滥用有关。
- **"激素恐惧"的代价**:很多家长和年轻人因为害怕激素,只用保湿硬扛,导致湿疹反复加重、感染、影响睡眠——**这比规范用药危险得多**。
- 用药节奏:发作期激素药膏+保湿;好转后激素渐停、**保湿永续**;皮肤破损感染者(流黄水、脓疱)先就医。

## 六、痤疮(痘痘):分级而治

### 6.1 分级(依据《中国痤疮治疗指南》)

| 分级 | 表现 | 处理方向 |
|---|---|---|
| 轻度(Ⅰ级) | 只有**粉刺**(黑头/白头) | 外用药为主:外用维A酸(阿达帕林凝胶等)或过氧化苯甲酰 |
| 中度(Ⅱ级) | **炎性红色丘疹** | 外用维A酸+过氧化苯甲酰±外用抗生素(遵医嘱) |
| 中度(Ⅲ级) | 出现**脓疱** | 上面基础+口服抗生素(如多西环素,处方),可考虑医疗机构化学换肤 |
| 重度(Ⅳ级) | **结节、囊肿**,疼痛硬结 | **尽快皮肤科就诊**,首选口服异维A酸(处方、有致畸等严格管理要求) |

> Ⅱ级以上、或外用药 8~12 周无效、或已经在留痘印痘疤——**就医不丢人,越拖越留疤**。

### 6.2 两种核心外用药常识(常见示例)

| 药物 | 作用 | 用法要点 |
|---|---|---|
| 过氧化苯甲酰(BPO,2.5%/5%常见) | 杀痤疮丙酸杆菌、溶解粉刺 | **早晨/白天用**;初期有刺激感,从少量隔天用开始建立耐受;**会漂白衣物床品** |
| 阿达帕林(外用维A酸) | 疏通毛孔、抑制微粉刺、抗炎 | **晚上用**(避光);豌豆大小全脸薄涂;前几周可能有"爆痘期",坚持+保湿;**孕期禁用** |
| 两者关系 | **不能同一时间点同时涂**(BPO 会使维A酸降解) | 一早一晚分开用,是经典组合 |

### 6.3 护理与"刷酸的边界"

- **防晒**:维A酸类药物会让皮肤光敏;防晒还能减轻痘印加深——硬防晒+温和防晒霜。
- **别挤**:手上脸上都是菌;尤其**面部"危险三角区"(鼻根到两口角)**的痘,挤压可能把感染挤进静脉回流至颅内(海绵窦感染,极罕见但可致命)。
- **刷酸**:医疗机构化学换肤用**高浓度果酸(20%~70%)、水杨酸(20%~30%)**,由专业人员操作;护肤品里的低浓度酸是另一回事,不能混同;刷酸期间屏障脆弱,更要保湿防晒,痘痘活跃期先控制炎症。
- 生活:少熬夜(熬夜→雄激素/皮脂→爆痘)、高糖高奶制品摄入可能加重(个体差异大)、毛巾枕套勤换、护肤做减法。

## 七、日晒伤与防晒常识

### 7.1 晒伤处理

1. **冷敷**:冷毛巾或冷水瓶敷 10~20 分钟,多次;冷水澡(别用冰)。
2. **大量保湿**:晒后凝胶/芦荟胶/保湿乳,趁皮肤微湿涂;**水疱不要挑破**。
3. 补水+解热镇痛:晒伤本质是皮肤炎症,布洛芬等 NSAIDs 可缓解疼痛炎症(以说明书为准)。
4. 脱皮期让它自然脱落,**别手撕**。
5. 出现大面积水疱、发热、恶心、剧痛不减→就医。

### 7.2 防晒:硬防晒优先

| 手段 | 要点 |
|---|---|
| **硬防晒(首选)** | 遮阳伞、防晒衣(UPF50+)、宽檐帽、墨镜——物理遮挡稳定不补涂 |
| **防晒霜** | 军训、海边、户外运动必带 |
| 使用量 | 全脸约一元硬币大小;**每 2 小时补涂**(出汗游泳后立即补);出门前 15~30 分钟涂 |
| SPF 含义 | 防 UVB(晒伤)的时间倍数:日常 SPF30+ 足够,户外 SPF50 |
| PA 含义 | 防 UVA(晒黑、晒老)等级:PA+++ 起步,+++ 到 ++++ |
| 选购 | 敏感痘肌选温和配方;防水型需卸妆清洁到位 |

## 八、足癣(脚气):坚持疗程才不复发

- 表现:脚趾缝糜烂脱皮、足底水疱脱屑、剧痒;**抓破后可继发细菌感染(红肿流脓、丹毒)**;也可传染到手(体癣)、指甲(灰指甲)。
- 处理:**外用抗真菌药**(常见示例:联苯苄唑、特比萘芬、酮康唑类乳膏/喷剂,以说明书为准):
  1. 每天 1~2 次,**症状消失后继续用 1~2 周**(真菌还在皮肤深层,见好就收=复发根源);
  2. 涂药范围比皮损大一圈;
  3. 累及指甲或外用 4 周无效→就医(可能需口服抗真菌药,处方+肝功监测)。
- 防复发:棉袜每天换(**袜子与内衣分开洗**)、鞋轮换穿并晾晒/喷抗真菌散剂、公共澡堂泳池穿自己的拖鞋、脚擦干(尤其趾缝)再穿袜。

## ⚠️ 常见误区

- **误区:鼻用激素喷雾是激素,不敢长期用。→ 真相:**规范喷鼻时全身吸收极少,是过敏性鼻炎一线治疗;真正的风险是不规范使用(对着鼻中隔喷、随便停停用用)。应规律使用并定期复诊。
- **误区:湿疹用激素药膏会"上瘾/依赖"。→ 真相:**激素药膏没有成瘾性;"激素恐惧"导致不治疗,湿疹只会反复更重。该用则用、按疗程用、好转渐停。
- **误区:湿疹要"干爽",少涂东西。→ 真相:**湿疹恰恰要**保湿**,洗完澡 3 分钟内大量涂抹是基础治疗。
- **误区:荨麻疹是"排毒"或"受风",忍忍就好。→ 真相:**是过敏/免疫反应;反复发作应排查诱因;**伴随喉头水肿、休克征象时是急症**。
- **误区:痘痘挤掉好得快。→ 真相:**挤压加重炎症、留痘印痘疤,危险三角区还有颅内感染风险。
- **误区:护肤品刷酸=医美刷酸。→ 真相:**医疗化学换肤是 20%~70% 高浓度酸、专业人员操作;自己在家叠涂高浓度酸产品容易烂脸。
- **误区:防晒霜 SPF 倍数越高越好,涂一次管一天。→ 真相:**足量+及时补涂比倍数更重要;硬防晒永远优先。
- **误区:脚气好了就停药。→ 真相:**症状消失时真菌未除尽,坚持再用 1~2 周才是"除根"的关键;复发多因疗程不足+鞋袜不处理。

## ✅ 行动清单

- [ ] 药箱补充:生理盐水洗鼻器、第二代抗组胺药(氯雷他定或西替利嗪)、保湿霜(大容量)、阿达帕林或过氧化苯甲酰(按自己肤质选一)、足部抗真菌药
- [ ] 学会鼻喷雾的正确姿势:朝外侧壁,不对鼻中隔
- [ ] 记住严重过敏反应急救口诀:**识别两项以上→打 120→脱离过敏原→平卧**
- [ ] 有严重过敏史的家人/同学:提醒其随身肾上腺素笔(医生评估后配备)
- [ ] 湿疹/干皮:洗澡后 3 分钟内涂保湿霜,坚持 4 周对比效果
- [ ] 痘痘自查分级,Ⅱ级以上或留疤倾向 → 预约皮肤科
- [ ] 军训/户外周检:防晒霜、遮阳伞、补水
- [ ] 被褥、枕套、毛巾、袜子:每周一洗,分开洗晒

## 🚨 什么时候必须就医(红线)

1. **严重过敏反应征象**(见第四节):声音嘶哑/呼吸困难/面色苍白/晕厥/口唇舌肿胀——**立即 120**;
2. **皮肤感染征象**:红肿热痛迅速扩散、流脓、发热、皮肤上出现疼痛红线向近心端蔓延(淋巴管炎)——当天就医;
3. **大面积晒伤伴水疱、发热、呕吐**;
4. 湿疹**渗液、脓疱、剧痒影响睡眠**,或规范保湿+用药 2 周无改善;
5. 痤疮出现**疼痛结节囊肿**、或正在快速加重留疤;
6. 荨麻疹**反复超过 6 周**,或常规抗组胺药无效;
7. 足癣**抓破感染**(红肿流脓),或出现丹毒样表现(大片红肿热痛+发热);
8. 皮肤新生物、不愈溃烂、快速变大的色痣(另行专科评估)。
