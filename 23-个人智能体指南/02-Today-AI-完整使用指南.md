> 面向高校计算机/电子信息专业学生的个人智能体实战手册。

## 2. 30 分钟上手最短路径（从注册到跑通第一个任务）

按这个顺序做，30 分钟内你能跑通「认识它 → 喂上下文 → 派第一个长期任务」：

1. **下载安装（5 分钟）**：手机浏览器打开 https://todayai.cn/downloads ，iOS 点「前往 App Store 下载」，安卓/Mac/Windows/Linux 选对应包。Mac 要求 Apple 芯片 + macOS 14 以上（官网下载页，2026-10）。
2. **注册领福利（2 分钟）**：手机号注册。注册即送 **1 亿 Tokens + 1 个月 Pro 权益**，基础版永久免费（官网下载页，2026-10；乱翻书播客官方简介，2026-09-30）。
3. **先别问问题，先做自我介绍（5 分钟）**：在对话里一次性发给它你的基本盘，例如：
   ```
   我是西安某高校计算机专业大二男生。主要身份：学生 + 学校创业团队成员。
   本学期核心项目：一个面向高校的嵌入式/STM32 方向创业项目，我负责技术。
   长期目标：学好高数（线代、三重积分）、找一段暑期实习。
   偏好：回复要短、直接给结论，不要废话铺垫；日程安排优先保证晚上 8-11 点的整块学习时间。
   ```
4. **连接第一个应用（8 分钟）**：右侧面板切到「记忆」或「能力」Tab →「设置连接应用」/「连接应用」，先接 **邮箱**（学生邮箱/QQ 邮箱/163）和 **日历**。国内版已支持邮箱、飞书、钉钉、腾讯文档（极客公园，2026-10-01）。接得越多，它对你的判断越准。
5. **派第一个「长期盯着」的任务（5 分钟）**：不要派一次性问题，要派它会持续跟进的事，例如：
   ```
   帮我盯着「STM32 PID 控制」和「大学生嵌入式竞赛」两个方向的信息：
   每周一早上 8 点给我一份简报，有新的竞赛报名、好用的开源项目、重要教程才说，
   没有就简单说一句「本周无重要更新」。其他时间不要打扰我。
   ```
6. **明天早上看早报（5 分钟等待）**：打开 App，右侧「Today」Tab 就是它基于你的日程和上下文整理的当日简报。这一步是体验分水岭——你会第一次感到「它比我先想了一遍」。

> 新手最容易犯的错：把它当普通聊天框，问一个问题就关掉。Today 的价值在「长期养」，前三天上下文越足，第四天的早报越准。

## 3. 核心能力详解

以下能力均来自官网与实测报道，不夸大。

### 3.1 Living Memory（鲜活记忆）
- 它会持续记住三类东西（官网 + 量子位，2026-09）：
  1. **长期画像**：你是谁、认识的人、偏好、目标；
  2. **未完成的事**：任务存续状态，标记「待处理」，出现新信息时主动拾起继续推进；
  3. **从连接器读到的上下文**：邮件里的项目进展、日历里的空档、飞书文档里的在写稿件。
- **你能管它的记忆**：右侧「记忆」Tab 里可查看、修改、删除任意一条记忆（官网原文：「所有上下文都由你掌控」）。
- 实测证据：用户随口说过「晚饭后想散步」，几天后排晚间计划时没再提，Today 仍把半小时散步排在最前（阑夕实测，2026-09-24）。
- 实测翻车：记者发现它对个人情况的归纳「并不完全准确」，节奏卡片可能只是根据有限信息的推断（极客公园，2026-10-01）。**所以：定期进「记忆」Tab 纠错，是必修课。**

### 3.2 主动服务（Proactive）
- **早晚报**：早报结合当天日程 + 近期关注，挑出值得注意的事；晚报收束一天推进了什么、还有什么没结束（量子位，2026-09-24）。
- **节奏卡片**：它自己从你连接的邮箱/飞书里归纳出你的高效时段（实测示例：高产窗口 9-14 点），生成「按我的节奏排今天」按钮，点一下就把建议变成任务（极客公园，2026-10-01）。
- **变化追踪**：你长期跟进某类事（行业政策、竞赛、订阅账单、球队动态），相关变化出现时它主动同步。实测：接邮箱监管 Cloudflare 账单和车险，漏交/异常续订第一时间提醒（阑夕，2026-09-24）。
- **分寸感**：官方设计原则是「不是通知中心」——流程是：收进变化 → 扔掉没用的 → 合并重复的 → 不急的先放着 → 只在值得打断你时才出现（抖音技术拆解视频，2026-10-10）。实测它会补一句「不用的话我就不打扰」（阑夕，2026-09-24）。

### 3.3 任务系统（多任务并行 + 定时任务）
- 同一对话框里先后交代多件事，Today 自动拆成独立任务扔后台并行跑，任务栏并排显示「运行中」，对话不被卡住（极客公园，2026-10-01）。
- 任务详情里能看到它给自己写的执行说明（按什么标准筛选、哪些要单列），过程透明。
- 支持**定时任务**：实测设置「每天早上 9 点推送栏目选题」长期生效（极客公园十天实测，2026-10-08）。官网示例：「邮件整理每 2 小时」「西班牙语练习周二/周四 20:30」。
- 复杂任务会自动移到独立任务里执行，后续结果同步回主对话（晚点 LatePost，2026-10-16）。

### 3.4 连接器生态（把你的 App 接进来）
| 版本 | 已接入（报道证实） |
|---|---|
| 国内版 | 邮箱、飞书、钉钉、腾讯文档（极客公园，2026-10-01）；实测可绑定微信，在微信里给它发语音/图片/文件（极客公园十天实测，2026-10-08） |
| 国际版 | Gmail、Google Calendar、Notion、Slack；官网展示过 GitHub、Figma、Google、Dropbox、Microsoft（量子位，2026-09-24） |

- 官方「能力」Tab 还有「连接聊天工具」入口（官网截图，2026-10）。

### 3.5 云端电脑（Cloud Computer）
- 给 Agent 配的一台 24 小时在线的云电脑，可自己打开浏览器、处理文件、运行代码（官网，2026-10）。
- 实测：发一个游戏 mod 的 zip 压缩包给它，它自行拆包读文档、调用 Claude Opus 5 在云端完成汉化，15 分钟出结果，侧边栏可见整个代码重构过程（极客公园十天实测，2026-10-08）。
- **对计算机学生的意义**：长任务不用自己电脑开机，挂在云端跑。

### 3.6 交付物与分享
- 结果不塞回聊天框，可生成 HTML 页面一键分享（实测：邮箱未读按票务/银行/订阅/系统安全分类的仪表盘页面）（极客公园，2026-10-01）。
- 社区 Skill 生态：深度研究、HRV 健康分析、会议纪要等工作流可由社区开发者封装成 Skill 接入（官网 + 量子位）。

### 3.7 交互形态
- **单一长对话**：没有会话列表、不分话题，所有事情在一段对话里继续——聊工作中途插一句游戏发售了没，它接得住再回工作（极客公园十天实测，2026-10-08）。
- 可给它**取名、选形象、设对话风格**（实测用户取名 Geekt；官网展示名为 Spark/momo 等）。
- 它会给自己写「日记」，记录每天和你的对话；实测用户每天能看到它总结的当日记录（极客公园十天实测，2026-10-08）。

### 3.8 它「不做什么」（边界要说清）
- 不替你做高风险动作而不问：发邮件、改日历、付款前会先请求确认（抖音实测，2026-10-10）。
- 不保证信息全准：排日程会算错缓冲、归纳画像会出错，关键事以你自己核对为准（抖音实测，2026-09-26；极客公园，2026-10-01）。
- 不是免费版 ChatGPT：它强在长期上下文和主动，纯问答速度/知识广度未必比专门模型强；复杂编程题它也是转给后台前沿模型跑（实测调 Claude Opus 5，2026-10-08）。

## 4. 注册 / 安装 / 配置详细步骤（分平台）

### 4.1 iOS
1. Safari 打开 https://todayai.cn/downloads → 点「前往 App Store 下载 Today」。
2. App Store 搜索「Today」（认准开发者 Today AI 官方；下载前核对）。
3. 安装后手机号注册，自动到账 1 亿 Tokens + 1 个月 Pro。

### 4.2 Android
1. 浏览器打开 https://todayai.cn/downloads → 点「Android」下载 APK。
2. 系统提示「未知来源应用」时按提示允许本次安装。
3. 国内应用商店（华为/小米等）是否上架：截至 2026-10-20 未能从公开信源确认，以下载页直链为准。

### 4.3 macOS（Apple 芯片）
1. 下载页点「Mac」（标注：Apple 芯片 · macOS 14 或更高版本）。
2. 下载 .dmg → 拖入 Applications。
3. 首次打开若提示「无法验证开发者」：系统设置 → 隐私与安全性 → 仍要打开。
4. Mac 版是体验最全的端：左侧对话 + 右侧 Today/任务/记忆/能力四栏。

### 4.4 Windows / Linux
1. 下载页点对应入口下载安装包。
2. Windows 双击安装；Linux 按下载页说明的包格式（截至 2026-10-20 未逐字核实具体格式，安装前看官网说明）。

### 4.5 初始配置清单（装完必做）
1. 右侧「记忆」→「更快设置记忆」三个入口全走一遍：**添加与你有关的文件**（培养方案、课程表、简历、项目文档都可以喂）、**设置连接应用**、**和它聊聊**。
2. 连接优先级建议：**邮箱 → 日历 → 飞书/腾讯文档（若在用）→ 微信**。
3. 进「记忆」Tab 检查它自动归纳的画像，**逐条改错**。
4. 给它取名、定风格：
   ```
   以后你就叫「小塔」。回复风格：像懂技术的学长，先结论后理由，控制在三行内，
   不要用表情和客套话。涉及考试、截止日期的事，必须在早报里置顶提醒。
   ```

### 4.6 各连接器接入要点（按实测）

| 连接器 | 实测效果 | 注意事项 |
|---|---|---|
| 邮箱（163/QQ/Gmail 等） | 自动归拢未读、按类型分类、可长期盯账单/续订 | 实测任务全程只读，不删不改不回；异常扣费会提醒（阑夕，2026-09-24） |
| 日历 | 知道你什么时候有空、什么时候有会，排计划参考 | 实测排期会算错缓冲，重要会议自己核对（抖音实测，2026-09-26） |

| 微信 | 在微信里直接给它发语音/图片/文件，它在微信里回 | 实测用户后来把它当微信好友用（极客公园十天实测）；属「连接聊天工具」入口 |

## 5. 实战场景与可复制提示词（大学生版）

每个场景：场景说明 + 可直接复制的指令原文 + 预期效果。

### 场景 1：课程资料 / 课件整理成复习笔记
- **说明**：把这周的课件 PDF / 课堂截图批量喂给它，让它持续跟进一门课的复习进度。
- **指令原文**：
  ```
  这学期我在学《信号与系统》和《数据结构》。我会陆续把课件 PDF 和课堂笔记截图发给你。
  请你：1）每收到一批就整理成一份带小节标题的复习笔记，标注重点公式和易错点；
  2）每周日晚上汇总一次「本周没搞懂的知识点」清单给我；
  3）如果我连续两周没发这门课的资料，主动提醒我是不是落下了。
  ```
- **预期效果**：无需每次重讲背景，它把同一门课的资料累积成一条复习线；周日自动出清单；断更会主动喊你（依据：记忆累积 + 定时任务 + 变化提醒，官网/实测能力）。

### 场景 2：长文 / 论文速读 + 选题追踪
- **说明**：计算机学生每周要读英文论文/技术博客，让它按你的标准筛，而不是每天丢新闻。
- **指令原文**：
  ```
  帮我长期跟进「嵌入式 AI 部署」「RISC-V」两个方向。标准：只有出现
  （a）可跑的开源项目 或（b）和课程设计/竞赛直接相关的教程 才推给我；
  纯行业八卦、融资新闻不要。每周一早上 8 点发一次简报，每条一句话说清
  「这对我有什么用」。我要是说某篇「已读不用再推」，记住。
  ```
- **预期效果**：实测同类玩法——用户第二天只发一句修正标准，Today 后续就按新标准判断（抖音实测，2026-09-05）；它会记住你的筛选偏好，越用越准。

### 场景 3：日程与待办（治拖延）
- **说明**：把截图相册/飞书待办扔给它，让它每天收束未完成事项。
- **指令原文**：
  ```
  我这学期的死线：11 月 15 日期中考、12 月 20 日创业项目中期答辩、每周五交高数作业。
  请你：每天晚上 10 点给我一份晚报——今天推进了什么、还有什么没收尾；
  距离任何死线不足 7 天时，在早报第一条置顶提醒；
  安排学习时间时，优先保晚上 8-11 点整块时间给高数和项目。
  ```
- **预期效果**：早晚报 + 死线追踪（官网早晚报机制）；实测它能记住「优先保晚上学习时间」这类偏好并落实到排期（阑夕实测，2026-09-24）。

### 场景 4：创业团队的信息追踪与会议纪要
- **说明**：接入飞书后，让它盯团队文档、自动出纪要。
- **指令原文**：
  ```
  我接上了咱们团队的飞书。请你读一遍我近一周的飞书文档，搞清楚我们创业项目
  现在卡在哪；以后每次团队会议结束，把纪要整理成：决策 / 待办（负责人+死线）/
  风险 三部分，发到对话里；有超过 3 天没动的待办，标红提醒。
  ```
- **预期效果**：实测同类——接飞书后它自动读出在写的两篇稿子和日更栏目，之后每天早 9 点自动推选题并追问进度（极客公园十天实测，2026-10-08）；社区还有「会议纪要」Skill 可装。

### 场景 5：写作辅助（周报/推文/答辩稿）
- **说明**：让它记住你的文风，以后所有写作不用重新交代要求。
- **指令原文**：
  ```
  以后我让你写的东西都遵守这个标准：技术向、写给大学生看；先一句话结论，
  再分点；每点不超过三行；术语第一次出现要解释一句。风格参考我发你的这篇
  范文（附上范文链接/文件）。写好后自己检查一遍有没有违反上面的标准再发我。
  ```
- **预期效果**：实测——用户第二次让它写同类内容，它沿用了上一轮的受众和标准，不用重新交代（抖音技术拆解视频，2026-10-10）。

### 场景 6（加练）：云端电脑跑代码任务
- **说明**：计算机学生专属——长任务挂云端。
- **指令原文**：
  ```
  这个仓库（发 zip 或 GitHub 链接）里有一份 STM32 寄存器级驱动代码，注释全是英文。
  请你：在你的云端环境里跑一遍构建，把关键函数注释翻译成中文、生成一份中文 README，
  完成后把整个改好的项目打包给我。过程中如果构建报错，把报错和你的修复过程记录下来。
  ```
- **预期效果**：实测同类型——发 zip 给它，它自行拆包、调前沿模型完成代码级任务，15 分钟出活，过程在侧边栏可见（极客公园十天实测，2026-10-08）。

### 场景 7：健康 / 运动习惯的长期跟随
- **说明**：接上手机健康数据后，它不再只是提醒「该运动了」，而是根据你的恢复状态调整建议。
- **指令原文**：
  ```
  我想每周跑 3 次步。请你：接上我的手机健康数据后，不要机械提醒，
  而是结合前一天睡眠和我的恢复状态给建议——睡够了就提醒我去跑，
  没睡够就建议改成拉伸或休息；每次跑完记录一下，每周日出一份简单的周小结。
  ```
- **预期效果**：官网展示睡眠/HRV/步数卡片；阑夕实测接入 HealthKit 后，它排计划会主动绕开运动高峰（2026-09-24）。社区还有现成的「HRV 分析」Skill 可装（官网，2026-10）。

### 场景 8：实习 / 秋招信息追踪与面试准备
- **说明**：计算机学生秋招战线长，让它盯目标公司动态 + 帮你做面试前准备。
- **指令原文**：
  ```
  我目标是明年找嵌入式 / 后端开发实习，目标公司是华为、大疆、小米、中科创达。
  请你：1）盯这几家的校招官网和牛客/github 上的面经更新，每周三早上发一次简报；
  2）我每次说「明天面试 XX 公司」，你就在当晚按这个岗位方向给我出一份
  10 个高频技术问题 + 参考答案要点；3）我的简历在附件里，以后所有内容都以
  我简历上写的项目经历为准来包装。
  ```
- **预期效果**：齐俊元本人高频用法——面试、见投资人前的准备由它完成，沟通质量明显提升（晚点 LatePost 访谈，2026-10-16）。简历喂进去后它会长期记住你的项目经历，写作不用重讲。

### 场景 9：账单 / 订阅 / 敏感邮件的异常监控
- **说明**：大学生也常有各种自动扣费（云服务器、网盘、视频会员），让它长期盯着。
- **指令原文**：
  ```
  把我两个邮箱都接上，只做一件事：长期盯「付款、账单、续订、发票」类邮件。
  出现新的扣费或续订提醒时第一时间告诉我金额和去向；
  如果是我不认识的服务扣费，直接标「可疑」。每周日汇总一次本周所有支出类邮件。
  ```
- **预期效果**：实测——用户让它长期监管 Cloudflare 账单和车险，漏交、异常续订第一时间通知，「安心感拉满」（阑夕，2026-09-24）。注意：它是只读监控，不会替你付款（实测邮箱任务全程只读，不做标记/删除/回复）。

### 场景 10：英语听力 / 口语的长期陪练
- **说明**：官网案例里有「西班牙语练习」这类长期学习项，学生可套用在英语上。
- **指令原文**：

## 5.6 计算机学生专属：开发者向玩法

## 5.8 给新手的「一周养成节奏」

Personal AI 是养出来的，不是装出来的。参考节奏：

- **Day 1**：注册 + 自我介绍 + 接邮箱和日历，派第一个长期追踪任务（见 §2）。
- **Day 2**：看第一次早报。挑出 1 条它说对的、1 条它说错的，说错的地方立刻进「记忆」Tab 纠正。
- **Day 3**：再接一个应用（飞书/腾讯文档/微信）。把这周课程表、死线发进去。
- **Day 4-5**：派第一个「重活」——一份课程论文速读、一份课件整理（用场景 1/2 的指令原文）。
- **Day 6-7**：做一次记忆审计 + 调整推送规则。把它推错的提醒明确关掉。
- **判断它对你有没有用的标准**（来自抖音测评博主建议，2026-10-02）：一周后回看，有几条提醒真帮你提前处理了问题？有几条只是打扰？前者多就继续养，后者多就收紧连接和推送规则。

## 7. 限制、翻车点与避坑

1. **它会「很笃定地说错」**：实测汉化 mod 时，它自信地连续给出错误的目录结构指令，害作者重启游戏测试一小时；直到被命令「去官方文档查」才解决（极客公园十天实测，2026-10-08）。**避坑：涉及配置、路径、命令这类硬知识，让它「先查官方文档再回答」，关键步骤自己复核。**
2. **记忆可能记错，且错记忆会放大**：记者实测它对个人情况的归纳不完全准；有用户发现自己删了 9 条过时身份记忆，但「不知道它为什么这么想，删一句不一定改掉后面的判断」（极客公园，2026-10-01；抖音拆解视频，2026-10-10）。**避坑：每周进一次「记忆」Tab 做审计。**
3. **日程/缓冲计算会算错**：实测排日程时第一次把会议也算进了空档，用户指出后它才纠正（抖音实测，2026-09-26）。**避坑：重要安排以你自己日历为准，它排的先核对。**
4. **单一长对话不适应**：用惯 ChatGPT「一事一开窗」的人会觉得乱，有用户下载手机端两分钟就卸载（晚点 LatePost，2026-10-16）。**避坑：复杂任务让它自动拆到「任务」栏，别都堆主对话。**
5. **主动推送可能变打扰**：项目取消了它还在催、判断不准时卡片会越来越多（抖音测评，2026-10-02）。**避坑：它推错一次就明确说「这条以后不用提醒我」；设置追踪类任务时写死「没有就别发」。**
6. **国内 App 权限墙**：微信等生活信息入口开放程度有限，它对你的理解容易集中在已接入的办公场景（极客公园，2026-10-01）。
7. **产品太新**：国内版 2026-09-24 才上线，B 站/知乎教程生态尚未形成，遇到问题可参考资料少；功能随时可能改。
8. **硬件要求**：Mac 端必须 Apple 芯片 + macOS 14+，老 Mac 用不了桌面端，只能手机/网页（官网下载页，2026-10）。

### 7.1 避坑速查表

| 场景 | 错误做法 | 正确做法 |
|---|---|---|
| 让它装环境/配路径 | 它说啥你照做 | 命令它「先查官方文档再回答」，结果自己复核 |
| 它记错你偏好 | 重开对话再讲一遍 | 去「记忆」Tab 找到那条记忆改掉/删掉 |

## 8. 隐私与安全边界

- **它读什么**：你主动连接的应用（邮箱、日历、飞书、钉钉、腾讯文档、微信等）里的内容 + 你们的对话。接得越多越懂你，但暴露面也越大（官网 + 实测）。
- **你能控制什么**：所有记忆条目可查看、修改、删除（官网原文「所有上下文都由你掌控」）。
- **高风险操作要授权**：实测发邮件、改日历这类动作，它不会擅自做，会先回来问你（抖音拆解，2026-10-10）。社区普遍建议：**支付、发送、删除三类权限要盯紧**（抖音选型建议，2026-10-02）。
- **隐私建议（学生向）**：
  1. 先接不重要的邮箱/工作账号练手，再决定要不要接主邮箱；
  2. 别把身份证、银行卡、报销敏感信息主动喂给它；
  3. 它要代你发邮件/改日历/动文件时，逐条看它生成的内容再批准；
  4. 官方隐私政策原文页面（todayai.cn 域名下）截至 2026-10-20 未能在本次检索中逐字精读，**注册前务必自己去官网底部点开隐私政策和用户协议读一遍**。
- **一个你要知道的权衡**：Personal AI 的价值 = 上下文深度；上下文深度 = 隐私暴露。齐俊元自己也承认「如果你担心个人隐私会不会被泄露，那就仁者见仁智者见智」（引述自抖音测评视频转述的行业讨论，2026-10-10）。

## 结语

Today 是国内第一个把「Personal Agent」做成独立产品、且免费开放给普通用户的尝试（晚点 LatePost，2026-10-16）。它现在还很糙——会算错日程、会记错你、会自信地给错指令。但它代表的方向是真的：AI 从「你找它」变成「它记住你、先想一步」。对计算机方向的学生，它还有额外价值：云端电脑跑任务、社区 Skill 自己写，这正是你们能玩出花的地方。按本指南的 30 分钟路径装一次，养一周，再决定要不要把它留在你手机里。
