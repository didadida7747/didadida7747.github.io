# STM32 Learning Path

## 推荐顺序

1. 启动流程与 `main()`
2. 时钟树基础
3. GPIO 输入输出
4. UART 基础通信
5. 定时器基础
6. 中断模型与 NVIC
7. DMA 传输
8. I2C / SPI
9. FreeRTOS 最小系统

## 每个主题都要回答

- 这个外设解决什么问题
- 初始化依赖什么时钟或中断
- 数据流向是什么
- 常见失败点在哪里
- 最小验证方法是什么
