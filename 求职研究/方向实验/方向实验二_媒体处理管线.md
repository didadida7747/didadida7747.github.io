# 方向实验二：可测量媒体处理管线

定位：音视频工程 6-8 小时体验项目。它验证对格式、参数、性能、质量和兼容性调试的兴趣，不要求从零实现编解码器或播放器。

## 用户故事

给定一个文件或目录，工具用 ffprobe 读取媒体信息，按预设批量处理并输出结果与报告。输入非法、参数冲突、输出已存在或 FFmpeg 失败时给出可定位错误，不静默跳过。

## 最小功能

1. 探测容器、视频/音频编码、分辨率、帧率、码率和时长。
2. 在批量转码、裁剪、水印、抽帧中选择两项。
3. 提供 2-3 个显式参数预设，命令可打印并记录。
4. 生成 CSV/JSON 结果：输入、预设、退出码、耗时、输出体积和错误类型。

## 对比实验

使用同一公开或自制样本比较两组设置。至少记录耗时与输出体积；质量可选择 PSNR/SSIM/VMAF 中当前环境可行的一项，或明确说明只做人工视觉对比。不能用不同输入比较参数优劣。

## 测试与故障

至少覆盖：正常文件、非媒体文件、损坏/不完整文件、输出冲突、FFmpeg 不存在或命令失败中的四项。命令执行设置超时；路径参数不能直接拼接为不受控 shell 字符串。

## 交付

```text
src/        探测、处理、预设和结果记录
tests/      固定样例与错误路径测试
samples/    小体积自制或来源明确的样本说明
results/    参数、环境、耗时、体积和质量结果
README.md   安装、运行、媒体概念、取舍与限制
```

## 禁止扩展

本周不做实时美颜、GPU 算子、完整播放器、WebRTC 服务、直播系统和自研编码器。完成最低证据线后有余力，只允许增加一种失败输入或改进一项测量。
