# 02 · 实习与劳动权益

> 你的时间线：大二暑期实习 → 大三暑期大厂实习 → 大四秋招三方+劳动合同。这一篇覆盖**每次"签东西"之前该核对的条款**和**出纠纷时怎么走流程**。
> offer 层面的横向对比（竞业/N+1/违约金谈判）见 [`03库/软实力权益决策指南.html`](/03-竞赛与就业/泛AI软件就业作战资料包/软实力权益决策指南.html)；本篇聚焦法定底线。

## 一、实习协议：签之前逐条核对（重点）

在校生日常实习一般为**劳务关系**（见第四节），权益主要靠协议约定——**协议就是你的全部护甲，逐条看**：

| 条款 | 核对要点 | 红旗信号 |
|---|---|---|
| 期限与岗位 | 起止日期、岗位内容写明 | 口头承诺"先来再说"不落纸 |
| 报酬 | 数额、发放日、发放方式（日结/月结） | "面议""看表现"、无薪"试工期"（法律无此概念） |
| 保密 | 范围是否合理 | 全公司一切信息无限期保密 |
| 解除 | 提前通知期与条件 | 高额违约金（学生实习违约金明显过高的要警惕） |
| 保险 | 是否购买**意外伤害险/雇主责任险** | 完全不提——实习期间受伤没有工伤保险，这份保险很重要 |
| 押金/证件 | — | **收押金、扣身份证/学生证 = 违法**，直接走人 |

> 签字前拍照留底；对不合理的条款，当场提出修改，对方拒绝就权衡要不要去。

## 二、三方协议 vs 劳动合同（大四秋招用）

| | 三方协议（就业协议书） | 劳动合同 |
|---|---|---|
| 性质 | 毕业生、用人单位、学校三方的就业意向文书 | 劳动关系的法定凭证 |
| 依据 | 毕业生就业工作相关规定 | 《劳动合同法》（2008 施行，2012 修正） |
| 有效期 | 签订到毕业报到为止 | 入职即签，试用期包含在合同期内 |
| 关键点 | **不能替代劳动合同**——入职后一个月内单位必须签劳动合同（第10条），不签可主张二倍工资（第82条） | — |

> 三方里的**违约金条款**要重点看（部分单位约定数千元违约金），签前与 offer 待遇一起权衡。

## 三、试用期法定规则（《劳动合同法》第19、20条）

| 劳动合同期限 | 试用期上限 |
|---|---|
| 不满 3 个月 / 以完成任务为期限 | **不得约定试用期** |
| 3 个月以上不满 1 年 | ≤ 1 个月 |
| 1 年以上不满 3 年 | ≤ 2 个月 |
| 3 年以上 / 无固定期限 | ≤ 6 个月 |

- 试用期工资下限：≥ 本单位同岗位最低档工资 **或** 约定工资的 **80%**，且 ≥ 当地最低工资标准；
- 同一单位同一劳动者**只能约定一次试用期**；
- 只签"试用期合同"的 → 试用期不成立，该期限直接视为劳动合同期限。

## 四、大学生实习到底受不受《劳动法》保护（主流口径）

- **原则**：在校生利用业余时间勤工助学、完成学校安排的实习，**不认定劳动关系**（原劳动部《关于贯彻执行〈劳动法〉若干问题的意见》第12条）→ 纠纷走《民法典》**劳务关系**，主张劳务报酬、人身损害赔偿；
- **例外**：名为实习实为就业——已满16周岁、以就业为目的入职、明确约定岗位报酬的，可认定劳动关系（人民法院报/北京西城法院典型案例方向）；
- **对你的意义**：日常实习维权主要靠**协议 + 民法典**，所以第一节那纸协议才那么重要；毕业后正式入职才完全进入劳动法保护圈。

## 五、五险一金（入职前看懂 offer）

| 项目 | 单位缴纳 | 个人缴纳 |
|---|---|---|
| 养老 | 16% | 8% |
| 医疗（生育多已并入） | 约 8% | 2% |
| 失业 | 约 0.5% | 约 0.5% |
| 工伤 | 0.2%–1.9%（按行业） | 0 |
| 公积金 | 5%–12% | 5%–12%（同比例） |

- **基数** = 本人上年月平均工资，上下限为当地社平工资的 **60%–300%**；每年 7 月左右调整，以当地社保局/公积金中心公布为准（各地有差异）。
- **对比 offer 时的常识**：税前工资相同，公积金比例 12% 的 offer 实际更优（公积金是自己的钱）；"不上社保"的创业公司 offer 要把风险算进去。

## 六、实习报酬的个税（拿工资时的疑问)

- **依据**：国家税务总局公告 2020 年第 13 号——全日制学历教育学生因实习取得**劳务报酬**，扣缴单位可按**累计预扣法**计算（每月减除 5000 元）→ 月收入 ≤ 5000 元通常**无需预扣税款**；
- 申报项目仍是"劳务报酬所得"；毕业签劳动合同后转"工资薪金"；
- 年度汇算时多退少补（个税 App 自行操作，几分钟）。

## 七、出了纠纷：劳动仲裁基本流程

| 项 | 内容 |
|---|---|
| 适用 | 劳动关系纠纷（毕业后）；学生实习纠纷走民事诉讼，但仲裁院常能给指引 |
| 时效 | **1 年**（自知道权利被侵害起） |
| 管辖 | 单位所在地/劳动合同履行地的劳动人事争议仲裁院 |
| 材料 | 仲裁申请书（按被申请人人数+副本）+ 企业注册信息 + 关系证据（工牌、工资流水、排班表、沟通记录） |
| 节奏 | 立案 → 受理/调解 → 开庭 → 裁决（一般 45 日，可延 15 日）；不服 15 日内起诉 |
| 费用 | 仲裁不收费 |
| 咨询 | **12333** 人社热线（说明城市转属地） |

## 八、简历之外的三个动作习惯

1. 每份工作（含实习）开始当天：确认协议已签、留存一份；
2. 工作期间：工资流水、考勤、工作成果随手存档（云盘一文件夹）；
3. 结束时：离职/结项证明要一份（下一份实习的背调材料）。
