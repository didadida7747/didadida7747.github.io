# 一加 ↔ 拯救者:文件传输与实用玩法

## 一、文件传输通道(按场景选)

| 通道 | 适用场景 | 要点 |
|---|---|---|
| **LocalSend**(推荐) | 日常互传照片/文件/文本 | 开源免费,同一 Wi-Fi 自动发现,详见 [03-1](/三设备联动指南/03-三端协同/01-文件互传与同步) |
| **数据线 MTP** | 大批量传输、最稳兜底 | 插线后手机通知栏选"文件传输"模式,资源管理器直接拖拽 |
| **O+互联/跨屏互联** | 国行一加日常 | 电脑与手机窗口直接拖拽互传,见 [02-1](/三设备联动指南/02-一加×拯救者/01-互联方案) |
| **微信文件传输助手网页版** | 临时/公用电脑 | 浏览器开 [filehelper.weixin.qq.com](https://filehelper.weixin.qq.com),手机扫码,**电脑不用登录微信客户端** |
| QQ"我的电脑" | 国内通用兜底 | 手机 QQ → 我的电脑,双向传 |
| ~~Google Quick Share~~ | — | ❌ 国行 ColorOS 无 GMS(Nearby 依赖),基本不可用;国际版 OxygenOS 可用([Windows 版下载](https://www.android.com/better-together/quick-share-app/)) |
| ~~互传联盟~~ | — | 只解决手机↔手机,没有统一 PC 客户端 |

## 二、一加当拯救者的摄像头/麦克风

开会、直播、录网课时,用一加的镜头给电脑当"外接高清摄像头"。

| 方案 | 价格 | 要点 |
|---|---|---|
| **DroidCam** | 免费版够用 | WiFi/USB 均可,电脑端装客户端后出现虚拟摄像头;官网 [dev47apps.com](https://www.dev47apps.com) |
| **Iriun Webcam** | 免费、无广告、支持 4K | 手机 App + 电脑端 [iriun.com](https://iriun.com),最简单 |
| Camo Studio | 免费+Pro | 画质/调校最好,Android 支持已具备,[官网](https://reincubate.com/camo/) |

- 建议:**直播/长时间会议用 USB 连接**(零延迟掉帧、边用边充电)。
- ColorOS 是否内置"手机当电脑摄像头":截至调研未查到官方功能页(华为/荣耀有此功能),以第三方 App 为准。

## 三、一加当拯救者的"随身网络"

- 路径:设置 → 连接与共享 → **个人热点**(可切 2.4/5GHz 频段;给拯救者用选 **5GHz**,延迟低干扰少)。
- **USB 网络共享**(同页):数据线直连,延迟最低、不耗手机无线电台、边玩边充——笔记本没网时的最佳方案。
- 蓝牙共享网络:应急即可,速度慢。
- 注意流量套餐额度;拯救者在家建议始终走有线/家里 Wi-Fi,热点是移动场景兜底。

## 四、2025-2026 一加/ColorOS 新玩法备忘

- **ColorOS 16**(2025-10 OPPO 开发者大会发布,OPPO/一加同步):一碰互联(NFC 碰一碰传文件,支持与 iPhone/iPad 高速互传,1GB 约 15 秒)、跨屏互联 PC 端最多 5 窗口、深度兼容苹果生态(iPhone 来电/短信/通知可同步到 OPPO 系手机)。
- **微软 × OPPO/一加合作深化**:Phone Link/Link to Windows 集成持续更新(2026 年 7 月 Link to Windows 新增手机端管理关联 PC)。
- 一碰互联对"非 OPPO 系电脑"(拯救者)的支持方式未见官方明确文档,需在手机"设置 → 连接与共享"里实测。
