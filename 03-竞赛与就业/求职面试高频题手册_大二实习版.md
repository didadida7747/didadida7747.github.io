## 二、计算机网络高频题

### 1. TCP 和 UDP 的区别？（出现率几乎 100%）

**答题钩子：连接 → 可靠性 → 报文/字节流 → 拥塞控制 → 首部开销 → 使用场景**

- TCP 面向连接（三次握手），UDP 无连接
- TCP 可靠交付（不丢、不重、按序），UDP 尽最大努力交付
- TCP 面向字节流（有黏包问题），UDP 面向报文
- UDP 无拥塞控制，网络拥塞也不降速——所以 IP 电话、直播用 UDP
- TCP 首部 20 字节，UDP 仅 8 字节
- 场景：TCP 用于网页、文件传输；UDP 用于视频、游戏、DNS

### 2. TCP 为什么是三次握手，不是两次？

**答题钩子：确认双方的收发能力 → 防止失效连接请求**

- 两次握手无法确认"客户端能收到服务端的消息"，只有三次才能让双方都确认对方的发送和接收能力正常
- 防止历史失效的连接请求报文突然到达服务端而建立错误连接

### 3. TCP 为什么挥手要四次？

**答题钩子：全双工 → 两个方向分别关闭**

- TCP 全双工，两个方向的数据通道要分别关闭
- 服务端收到 FIN 后可能还有数据没发完，所以 ACK 和 FIN 分开发送（中间隔着数据传输）——这是"三次能握手、四次才挥手"的根本原因

### 4. TIME-WAIT 为什么要等 2MSL？

- 保证最后一个 ACK 能到达服务端：若丢失，服务端会重传 FIN，客户端还能重传 ACK
- 让本连接的所有旧报文在网络中消失，避免污染下一次连接

### 5. HTTP 常见状态码？

**答题钩子：1xx 信息 / 2xx 成功 / 3xx 重定向 / 4xx 客户端错 / 5xx 服务端错**

- 200 OK；301 永久重定向；400 请求语法错误；401 未认证；403 权限不够；404 资源不存在；500 服务器内部错误；502/504 网关错误、网关超时

### 6. 从输入 URL 到页面显示，发生了什么？（开放综合题之王）

**答题钩子：DNS 解析 → TCP 连接 → 发送 HTTP 请求 → 服务器处理响应 → 浏览器渲染**

能串起 DNS、TCP、HTTP 三块知识，答得越完整越加分。

## 三、操作系统高频题

### 1. 进程和线程的区别？（出现率几乎 100%）

**答题钩子：资源分配 vs 调度 → 地址空间 → 切换开销 → 通信方式**

- **进程是资源分配的独立单位，线程是资源调度的独立单位**
- 进程有独立地址空间；线程共享进程的堆、全局变量，但栈和寄存器私有
- 进程切换开销大，线程切换快
- 一个线程崩溃会拖垮整个进程；进程之间互不影响

### 2. 进程间通信方式（IPC）有哪些？

**答题钩子：管道 → 信号量 → 消息队列 → 共享内存 → 套接字**

- 管道（匿名管道限亲缘进程、单向；命名管道无此限制）
- 信号量：计数器，用于同步访问共享资源
- 消息队列：内核中的消息链表
- 共享内存：最快，无须复制，但需要自己处理同步
- 套接字 Socket：跨机器通信

### 3. 死锁产生的四个必要条件？

**答题钩子：互斥、请求和保持、不剥夺、环路等待**

- 破坏任意一个条件即可预防死锁；银行家算法是典型的"避免"策略

### 4. 页面置换算法有哪些？

- OPT（最佳，理论基准）、FIFO（先进先出）、LRU（最近最久未使用，最常考）、Clock（时钟）

## 四、数据结构与算法高频题

### 1. 常见排序算法复杂度？（必考）

| 算法 | 平均 | 最差 | 稳定性 |
|---|---|---|---|
| 快速排序 | O(n log n) | O(n²) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | 稳定 |
| 堆排序 | O(n log n) | O(n log n) | 不稳定 |
| 冒泡/插入/选择 | O(n²) | O(n²) | 冒泡/插入稳定 |

### 2. 红黑树的特征？

**答题钩子：节点红或黑 → 根黑 → 叶子黑 → 红节点必双子黑 → 任一路径黑高相同**

应用：STL 的 map/set 底层。与 B+ 树对比：B+ 树矮胖、叶子存数据并用链表串联，适合数据库索引。

### 3. 哈希冲突怎么解决？

- 链地址法（拉链法，最常用）、开放定址法（线性探测、二次探测）

## 五、HR / 行为面试题（每个面试必问）

### 1. 自我介绍（1 分钟版怎么准备）

**结构：我是谁 → 我做过什么（1-2 个具体项目/成绩）→ 我为什么来**

大二月份的版本可以直接用《实习速成方法论》的框架：年级 + 专业 + 一句"我为什么对这个方向感兴趣" + 一个能证明的成果。

### 2. "你有什么项目经历？"——大二没做过项目怎么答

- 承认现状 + 展示在学习的东西（诚实是加分项）
- 把课程作业、自学的小 demo、本站知识库这种"自驱项目"讲清楚：解决了什么问题、你怎么拆解的
- 引用《实习速成方法论》的"项目逐字倒推追问树"：每个项目准备好"为什么做 → 怎么做 → 遇到什么坑 → 学到什么"

### 3. "你的缺点是什么？"

- 说真实但不致命的缺点 + 正在怎么改进，避免"我太追求完美"这类套话

### 4. 反问环节问什么？

- 问工作内容/技术栈（体现岗位兴趣）、问 mentor 制度/成长路径（体现长期意愿）
- 大二实习生不问薪资细节，问学习机会
