# 剪贴板、通知、浏览器接力

> 结论:**一加↔电脑的剪贴板+通知,一套 KDE Connect(或 Phone Link)解决**;iPad 参与剪贴板用 SyncClipboard(快捷指令),推送通知到 iPad 用 Bark(电脑一条命令);浏览器接力统一用 **Edge"发送到设备"**。

## 一、剪贴板三端同步

### 现实约束先说清
- iPadOS 禁止第三方 App 常驻后台,所以**任何方案在 iPad 上都做不到"无感全自动"**,要么 App 在前台,要么走快捷指令手动触发。
- Windows↔Android 之间可以完全无感。

### 推荐组合

| 组合 | 覆盖 | 说明 |
|---|---|---|
| **KDE Connect** | 一加 ↔ 电脑,无感双向 | 复制即可在另一端粘贴;顺带通知镜像、文件互传、远程输入。开源免费,Windows 版在 Microsoft Store(官方注明非 Linux 平台非官方支持,偶有抽风) |
| **SyncClipboard**(开源) | 三端,iPad 半自动 | 电脑端常驻(或部署在常开设备),iOS 用官方**快捷指令**一键上传/下载剪贴板;支持文本/图片/文件。[GitHub](https://github.com/Jeric-X/SyncClipboard) |
| 微软云剪贴板(Win+V) | 仅 Windows 之间 | 解决不了三端,仅备忘 |
| 土办法 | 全端 | LocalSend 发"剪贴板文本"/微信传输助手粘一段话 |

- 建议落地:日常 KDE Connect(一加↔电脑);iPad 偶发场景用 SyncClipboard 快捷指令或干脆 LocalSend 传文本。
- iOS 侧注意:跨 App 读取剪贴板系统会弹提示,属正常。

## 二、通知与消息接力

| 方案 | 方向 | 能做什么 | 备注 |
|---|---|---|---|
| **Phone Link**(手机连接) | 一加 → 电脑 | 电脑上看/回通知、收发短信、接打电话、浏览照片 | 系统自带,一加官方支持,首选;见 [02-1](/三设备联动指南/02-一加×拯救者/01-互联方案) |
| **KDE Connect** | 一加 ↔ 电脑 | 通知镜像+快捷回复 | 与剪贴板一套解决 |
| **Bark** ★ | 电脑 → iPad/iPhone | 电脑脚本/任务完成时**推送通知到 iOS** | 开源,发送端就是一条 HTTP 请求;[GitHub](https://github.com/Finb/Bark) |
| ~~Pushbullet / Join~~ | — | — | 维护停滞/依赖 GMS,国行一加排除 |

### Bark 上手(把电脑事件推到 iPad)
1. iPad App Store 装 Bark,打开得到一个专属 Key;
2. 电脑上任意能发 HTTP 的地方都能推,例如 PowerShell:
   ```powershell
   Invoke-RestMethod "https://api.day.app/你的Key/下载完成/资源A已入库"
   ```
   或 curl:`curl "https://api.day.app/你的Key/标题/内容"`
3. 结合 Windows 任务计划(下载完成/脚本结束/训练跑完触发),iP­ad 实时收到推送;
4. 在意隐私或官方服务器不稳时,可 Docker 自建 [bark-server](https://github.com/Finb/bark-server)(配合 [05-3 家庭服务器](/三设备联动指南/05-进阶玩法/03-拯救者变家庭服务器))。

## 三、浏览器接力(标签页/链接三端流转)

| 浏览器 | 接力能力 | 国行可用性 |
|---|---|---|
| **Edge** ★ | 登录同一微软账号 → 手机/iPad/电脑互推链接("发送到你的设备"),还有 **Drop** 文件速传 | ✅ 全部可用,最顺 |
| Vivaldi | 自建账号同步书签/密码/标签页 | ✅ |
| Chrome | 标签页接力齐全 | ❌ 国行一加无法登录/推送(无 GMS),放弃主力位 |
| Safari | 仅苹果设备间 | ❌ 与 Windows 不互通,别指望 |

- 实用动作:电脑看到长文 → 右键/分享"发送到你的设备" → iPad 上继续读;iPad 刷到的链接 → 推回电脑打开。
- 稍后读进阶(全文离线、高亮标注)可再加 Cubox/Notion 类工具,此处不展开。

## 四、汇总:三端"接力"配置清单(推荐最终形态)

1. 一加 + 电脑:Phone Link(消息)+ KDE Connect(剪贴板/通知)。
2. iPad:Edge 登录(浏览器接力)+ Bark(接收电脑推送)+ LocalSend(互传)。
3. 电脑:SyncClipboard(可选,iPad 剪贴板)+ 任务计划 + Bark 推送脚本。
