# 第3章 文件系统与目录结构

> 本章带你认识 Linux 的"硬盘地图"。学完你再看到别人敲 `cd /var/log` 时，脑子里能浮现出这个目录在整个系统里的位置，而不是一串无意义的字符。

## 本章你将学会

- 理解 Linux "一切皆文件"这句话是什么意思
- 说出 `/` 根目录下十几个常见文件夹各自存什么
- 分清绝对路径和相对路径，熟练用 `.`、`..`、`~`、`-`
- 会用 `Tab` 补全，知道它为什么是命令行效率的关键
- 理解 Linux 隐藏文件的规则
- 通俗理解 inode 和软/硬链接是怎么回事（动手建链接在第 4 章）
- 明白"挂载"这个概念（第 9 章细讲）

## 3.1 一切皆文件

Windows 里你要区分"这是文件""那是文件夹""那是个硬盘""那是个 USB""那是个进程"。Linux 里有一句著名的话：

> 📌 **在 Linux 里，一切皆文件。**

硬盘是文件（在 `/dev/` 下），键盘是文件，显示器是文件，正在跑的进程也是文件（在 `/proc/` 下）。你读硬盘就是读一个文件，发网络数据本质也是读写一个特殊文件。

这个设计哲学带来一个好处：**操作所有东西的接口是统一的。** 学会了读写文件，你就学会了操作半个系统。代价是——目录树看起来特别庞大，因为所有东西都要塞进同一个"文件树"里。

## 3.2 没有 C 盘，只有一个根目录 `/`

Windows 里你打开"此电脑"，看到 C 盘、D 盘、E 盘，每个盘有自己独立的目录树。Linux 完全不同：

> 📌 **Linux 只有一棵目录树，最顶端叫根目录 `/`。** 所有硬盘、U盘、移动设备，最终都要"挂"到这棵树的某个文件夹上，才能被访问。没有盘符这回事。

你在 WSL 里敲 `ls /` 看一眼：

```bash
$ ls /
```

```text
bin   dev   home   lib64       media  proc  sbin   sys   usr
boot  etc   lib    lost+found  mnt    root  srv    tmp   var
```

一堆看不懂的文件夹？正常。下面我逐个讲，你不用背，混个脸熟，用多了自然记住。

## 3.3 FHS 目录树逐个讲

FHS（Filesystem Hierarchy Standard，文件系统层级标准）规定了每个目录大概存什么。我们按"你会常打交道的程度"排序：

| 目录 | 存什么 | 你以后会怎么用它 |
|---|---|---|
| `/home/` | 普通用户的家目录 | **你的文件都在这**，`/home/你的用户名` 就是 `~` |
| `/root/` | root 用户的家目录 | 不是 `/home/root`，是单独的 `/root`，普通用户进不去 |
| `/etc/` | 系统级配置文件 | 装 Nginx、改网络配置、改 apt 源都在这下面，极高频 |
| `/var/` | 会变化的数据：日志、数据库、缓存 | `/var/log` 看日志、`/var/lib` 存数据库文件 |
| `/tmp/` | 临时文件，重启可能清空 | 写个临时脚本扔这，没人会管 |
| `/usr/` | 你装的软件（只读） | `/usr/bin` 里是大多数命令的真身，不用手动改 |
| `/bin` `/sbin` | 最核心的命令（ls、cp 等） | 现在它们其实是指向 `/usr/bin` 的链接，了解即可 |
| `/opt/` | 第三方软件的"自留地" | 有些绿色软件（如某些 IDE）默认装这 |
| `/boot/` | 开机引导文件 | WSL 里基本不用管，真机装双系统才碰 |
| `/dev/` | 设备文件 | `/dev/sda` 是硬盘，`/dev/null` 是"黑洞"（写进去就消失） |
| `/proc/` `/sys/` | 内核和进程的实时信息 | 虚拟文件系统，东西是内存里实时生成的，不是真存在硬盘上 |
| `/mnt/` `/media/` | 临时挂载点 | U 盘、外接硬盘挂这下面 |
| `/srv/` | 对外服务的数据 | 做 Web 服务器时网站文件有时放这（现在更多放 `/var/www`） |

> 💡 **小技巧：** 新手只要先记住三个就够了：
> - 你自己的东西 → `/home/你/`
> - 改配置 → `/etc/`
> - 看日志 → `/var/log/`
>
> 其他目录知道是干嘛的就行，用多了自然熟。

## 3.4 绝对路径 vs 相对路径

路径就是"怎么找到那个文件"。分两种写法：

**绝对路径：从根 `/` 开始写，不管你现在在哪都成立。** 比如：

```text
/etc/apt/sources.list
/home/zhangsan/myproject/main.py
```

**相对路径：从你当前所在目录开始算。** 你现在在 `/home/zhangsan`，想找 `myproject` 里的 `main.py`，直接写：

```text
myproject/main.py
```

系统会自动拼成 `/home/zhangsan/myproject/main.py`。

> 📌 **判断标准很简单：路径以 `/` 开头就是绝对路径，否则是相对路径。**

## 3.5 三个特殊符号：`.`、`..`、`~`、`-`

写路径时有几个"简写"，必须掌握：

| 符号 | 含义 | 例子 |
|---|---|---|
| `.` | 当前目录 | `./main.py` = 当前目录下的 main.py |
| `..` | 上一级目录 | `cd ..` 回到上一层；`../other` 表示隔壁文件夹 |
| `~` | 当前用户的家目录 | `cd ~` 直接回家；`~/myproject` = `/home/你/myproject` |
| `-` | 上一次所在的目录 | `cd -` 在两个目录之间来回切 |

`..` 可以连用：`../../` 就是往上爬两层。

试一下：

```bash
$ pwd
/home/zhangsan
$ cd /var/log
$ pwd
/var/log
$ cd -
/home/zhangsan
$ cd -
/var/log
```

`cd -` 就像"视频播放器的上一个频道"，来回切。

## 3.6 Tab 补全——命令行效率的第一基石

在终端里敲长路径是噩梦，但 Linux 有个救命功能：**`Tab` 键自动补全**。

- 敲 `cd /h` 然后按一下 `Tab`，它会自动补成 `cd /home/`
- 如果你敲 `cd /ho` 时下面有多个候选（比如 `/home/` 和 `/hosts/`），按一下 Tab 没反应，**快速按两下 Tab**，它会列出所有候选，让你接着敲几个字母再补
- 文件名、命令名、选项都能补全

> 💡 **小技巧：从今天起，养成习惯——每个命令敲到一半就按 `Tab`。** 不要把整个文件名敲完。这一个动作能帮你避开 90% 的"文件名打错"错误，还能让你摸清楚目录里到底有什么。

## 3.7 隐藏文件

Linux 里没有 Windows 那种"隐藏属性"开关，规则简单粗暴：

> 📌 **文件名以 `.` 开头的，就是隐藏文件，`ls` 默认不显示。**

比如你家目录下的 `.bashrc`、`.vscode-server` 都是隐藏的。想看到它们，用 `ls -a`（a = all）。

这不是安全机制，就是个"别把用户目录搞得乱糟糟"的约定——配置文件太多了，默认隐藏眼不见心不烦。

## 3.8 文件类型（不用记全，认前三种就行）

第 4 章讲 `ls -l` 时你会看到长格式输出的第一个字符，它代表文件类型：

| 第一个字符 | 类型 |
|---|---|
| `-` | 普通文件（文本、图片、可执行程序……） |
| `d` | 目录（directory） |
| `l` | 软链接（link），类似 Windows 的快捷方式 |
| `c` `b` | 设备文件（字符/块设备，在 `/dev` 下） |

其他类型（socket、pipe）你现在不用管。

## 3.9 inode 是什么（通俗版）

这个概念有点抽象，我尽量三句话讲清。

你可以把硬盘想象成一个巨大的档案室。每个文件有两样东西：

1. **inode（索引节点）：** 一张档案卡片，登记了这个文件的"身份证信息"——大小、属主、权限、修改时间、数据存在档案室哪个柜子哪一格。但**不登记文件名**。
2. **文件名：** 只是贴在目录上的一个标签，告诉系统"这个名字对应哪个 inode"。

> 📌 **所以文件名和文件内容其实是分开的。** inode 才是文件的真身，文件名只是个挂在目录里的"引用"。

这有什么用？马上就要讲——它解释了软链接和硬链接的区别。

## 3.10 软链接 vs 硬链接（概念，第 4 章动手建）

因为"文件名只是指向 inode 的标签"，所以你可以给同一个 inode 贴好几个标签。这就是链接。

**硬链接：** 多个文件名直接指向同一个 inode。就像同一个人有两个大名——删了一个大名，人还在；只有把所有大名都删了，文件才真正消失。特点：不能跨分区、不能链接目录。

**软链接（symbolic link）：** 更像 Windows 的快捷方式——它是一个独立的小文件，里面写着"我指向某某路径"。原文件删了，软链接就变成"断链"（红色闪烁）；但软链接可以跨分区、可以链接目录，所以**实际开发里 99% 用的是软链接**。

| | 硬链接 | 软链接 |
|---|---|---|
| 像什么 | 同一个人的两个大名 | Windows 快捷方式 |
| 原文件删了 | 链接还能用（inode 还在） | 链接失效 |
| 能不能跨分区 | 不能 | 能 |
| 能不能链目录 | 不能 | 能 |
| 你会用到吗 | 几乎不会 | 经常（装软件版本切换、配快捷路径） |

> 📌 **记住结论就行：以后你敲 `ln -s 原文件 链接名`，那个 `-s` 就是软链接。** 第 4 章会带你建一个试试。

## 3.11 挂载（预告）

开头说了，Linux 没有 C 盘 D 盘，所有设备都要"挂"到根目录树的某个点上。这个动作叫**挂载（mount）**：

- Windows 的 C 盘在 WSL 里挂到了 `/mnt/c/`
- 你将来插个 U 盘，系统会把它挂到 `/mnt/` 或 `/media/` 下面某个文件夹
- 你将来租云服务器，加一块新硬盘，也要手动 `mount` 到某个目录才能用

> 📌 **现在你只要记住：挂载 = 把一个设备的内容"接到"目录树的某个文件夹上。** 具体命令 `mount`、`umount`、开机自动挂载的 `/etc/fstab`，第 9 章磁盘与挂载专门讲。

## 3.12 实战：在目录树里导航一遍

光看表记不住，我们现在用第 4 章才会细讲的 `cd` / `ls` 走一遍这棵树，你照做就行：

```bash
# 1. 从家目录出发，看看根
$ cd /
$ ls
# 2. 进 /etc 看看配置文件都长什么样
$ cd /etc
$ ls
# 3. 回到家
$ cd ~
# 4. 用相对路径从家进到 /var/log，再用 - 切回家
$ cd /var/log
$ pwd
$ cd -
$ pwd
```

走完这一圈，你应该能在脑子里形成一张地图：

```text
/
├── home/
│   └── zhangsan/        ← 你的地盘，随便折腾
├── etc/                 ← 系统配置
├── var/
│   └── log/             ← 日志
├── usr/                 ← 装的软件
└── ...
```

以后看到别人教程里写 `cd /etc/nginx`，你脑子里应该立刻反应过来："哦，去系统配置目录下找 nginx 的配置。" 看到 `cd ~/myproject`："回我自己家目录下的项目。"

## ⚠️ 危险操作与安全红线

本章还没有可执行的危险命令。但提前立一条规矩：

> ⚠️ **警告：不要因为本章讲了 `/proc`、`/sys` 是"实时信息"就去里面乱删东西。** 这些目录里的文件不是普通文件，它们是内核暴露出来的接口。删 `/tmp` 下的东西无所谓，删 `/etc`、`/bin`、`/lib` 下的东西系统就起不来了。记住：**你自己的东西只放 `/home/你/`，系统目录只在明确知道在做什么时才动。**

## 常见报错与排查

| 现象 | 原因 | 解决 |
|---|---|---|
| `cd: /xxx: No such file or directory` | 路径写错、大小写错 | `Tab` 补全，或一层层 `ls` 进去看 |
| 路径里有空格，命令报错 | 空格被当成参数分隔符 | 整个路径用引号包起来，或者空格前加 `\` |
| `Permission denied` 进某个目录 | 不是你的家目录，权限不够 | 加 `sudo`，或者老实待在自己家目录 |
| 按 `Tab` 没反应 | 没有歧义时直接补全；有歧义时要按两下 | 敲两个字母再按两下 Tab 看候选 |

## 动手练习

1. 用 `ls /` 列出根目录，对照本章 3.3 的表格认出一半以上的目录。
2. 依次执行 `cd /etc`、`cd ..`、`cd ~`、`cd -`，每一步 `pwd` 看自己在哪，理解绝对/相对路径。
3. 敲 `cd /etc/apt/s` 然后按两下 `Tab`，看它提示你什么；接着补全成 `cd /etc/apt`。
4. 在你家目录敲 `ls -a`，和 `ls` 对比，找出至少 3 个隐藏文件。
5. 解释一下：为什么 `.bashrc` 这个文件默认用 `ls` 看不到？（验收：能说出"以点开头是隐藏文件"）

## 本章小结

| 知识点 | 一句话 |
|---|---|
| 一切皆文件 | 硬盘、进程、键盘在 Linux 里都是文件 |
| 根目录 `/` | 没有 C/D 盘，所有东西挂在一棵树下面 |
| 三大高频目录 | 你的文件在 `/home/你/`，配置在 `/etc/`，日志在 `/var/log/` |
| 绝对/相对路径 | 以 `/` 开头是绝对路径，否则相对当前目录 |
| `.` `..` `~` `-` | 当前 / 上一层 / 家目录 / 上一次目录 |

| 隐藏文件 | 以 `.` 开头，`ls -a` 才显示 |
| inode / 链接 | 文件名只是 inode 的标签；软链接像快捷方式，最常用 |
