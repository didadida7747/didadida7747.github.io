# 03 · 竞赛与就业作战总资料包

> 面向本校电子信息工程本科生的竞赛规划 + 泛AI软件就业备战一体化作战资料包，覆盖从大二到毕业求职、再到工作后深造的完整路径。

---

## 一、个人定位

| 维度 | 内容 |
|------|------|
| 学校 / 专业 | 本校（本校）· 电子信息工程 |
| 年级 | 2025级，2026年9月大二上 |
| 技术主线 | **Python + Go** 双语言 |
| 岗位方向 | **大模型应用开发为主**（RAG / Agent / AIGC工程化 / LLM后端），AI后端兜底 |
| 就业策略 | 本科直接就业，**不保研**；实习优先一线城市（北上广深杭），正式工作接受西安 |
| 远期分叉（Plan B） | 工作1–2年后赴香港 / 新加坡攻读1年制授课型硕士（CS / AI / DS方向） |
| 差异化优势 | 本校电子信息硬件背景 + AI工具熟练 + 软硬结合视角 |

## 三、推荐阅读顺序

### 第一步：建立全局认知（第1周）
1. 先看 **[优质资源导航](/03-竞赛与就业/泛AI软件就业作战资料包/优质资源导航.html)** —— 了解有哪些优质开源教程、B站视频、工具，建立"学什么、去哪学"的地图
2. 再看 **[泛AI软件就业作战地图](/03-竞赛与就业/泛AI软件就业作战资料包/泛AI软件就业作战地图.html)** —— 岗位地图、公司分档、技能树、学期行动时间线，建立"目标是什么、怎么到达"的全局

### 第二步：学技术 + 做项目（大二上 → 大三上）
3. 按 **[大模型应用技术全景图](/03-竞赛与就业/泛AI软件就业作战资料包/大模型应用技术全景图.html)** 的六层结构逐层学习，每个节点都指向具体的开源教程章节和B站视频
4. 跟着 **[项目实操指南](/03-竞赛与就业/泛AI软件就业作战资料包/项目实操指南.html)** 做项目：基础后端 → RAG/Agent大模型应用 → 微调/推理优化 → 开源/竞赛产品化；优先"二开成熟开源项目 + 差异化改造"

### 第三步：对接求职（大三下 → 大四）
5. 用 **[岗位JD深度研究](/03-竞赛与就业/泛AI软件就业作战资料包/岗位JD深度研究.html)** 对照真实JD查漏补缺，按"JD要求→学习内容→项目证据"三列对照表补齐
6. 按 **[实习求职实操指南](/03-竞赛与就业/泛AI软件就业作战资料包/实习求职实操指南.html)** 准备刷题、八股、简历、投递
7. 用 **[行业认知与面试深度库](/03-竞赛与就业/泛AI软件就业作战资料包/行业认知与面试深度库.html)** 准备LLM系统设计、项目深挖、各公司面试流程

### 贯穿全程
8. 竞赛按 **[竞赛时间轴图谱](/03-竞赛与就业/竞赛规划资料包/全年高含金量竞赛时间轴图谱.html)** 穿插参加，就业导向优先软件/AI类赛事（华为软挑、飞桨黑客松、天池、GPLT、中国软件杯等）
9. 人脉与内推参考 **[校友资源作战指南](/03-竞赛与就业/泛AI软件就业作战资料包/校友资源作战指南.html)**
10. 权益保障与offer决策参考 **[软实力权益决策指南](/03-竞赛与就业/泛AI软件就业作战资料包/软实力权益决策指南.html)**

### Plan B（工作后）
11. 若工作1–2年后考虑深造，参考 **[工作后深造指南](/03-竞赛与就业/泛AI软件就业作战资料包/工作后深造指南.html)**

### 两条线如何配合
- **竞赛是项目经验和简历背书的来源之一**，竞赛项目可产品化写入GitHub
- **就业资料包是主线**，竞赛选择以"对大模型应用开发求职有帮助"为标准
- 追踪表Excel统一管理竞赛、项目、技能、投递、offer全流程

### 每周更新内容

1. **竞赛官网复查**：94项赛事官网可访问性检查，检测报名时间/状态变化
2. **竞赛HTML/Excel重新生成**：数据更新后自动重新生成时间轴图谱和明细清单
3. **就业动态（联动job_update.py）**：
   - 10家重点公司招聘官网检查，检测大模型岗位关键词（LLM/Agent/RAG等）
   - 牛客网面经板块检查
   - 港新院校项目页面（每年9–12月申请季自动启用）
4. **GitHub仓库监控（3组分批轮换）**：
   - 核心组 / 应用组 / 工具组各10个仓库，按ISO周数%3轮换，三周轮完
   - 24小时缓存，不重复查询
   - 403/429限流时等待重试，仍失败记录"下周重试"，不覆盖基线
5. **B站 / 微信公众号**：按月检查（不在每周任务中）

### 日志位置

- 竞赛日志：`竞赛规划资料包\历史备份与日志\更新日志\`
- 就业日志：`泛AI软件就业作战资料包\历史备份与日志\更新日志\`

### 停办赛事处理逻辑

- 官网连续无法访问 → 标记"疑似停办"，不立即删除
- 官方公告确认停办 → 状态改为"已停办"，从推荐列表移除但保留历史数据
- 已确认停办赛事：阿里全球数学竞赛、京东JDATA、滴滴DiTech、Google Kick Start/HashCode等
