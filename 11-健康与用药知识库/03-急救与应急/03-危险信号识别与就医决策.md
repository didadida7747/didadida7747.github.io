# 危险信号识别与就医决策:何时 120、何时急诊、何时观察

> 一句话定位:一张"危险信号总表"+ 一套就医层级决策法 + 打 120 的标准话术 + 急救包与急救信息卡模板。

> ⚠️ 免责声明:本文为科普整理,不能替代专业急救培训;建议尽快报名线下实操培训(红十字会/急救中心);紧急情况立即拨打 120。

---

## 🎯 核心速览

- **一句话判法则**:出现"要命的器官(心/脑/肺/大血管)突然出问题"的任一信号 → 直接 120,不要纠结。
- **拿不准 = 当危险处理**:症状轻微但性质吓人(如持续胸痛、剧烈头痛),宁可虚惊一场。
- 就医层级:**校医院/社区门诊(小毛病)→ 普通门诊(48小时内应看的病)→ 急诊(数小时内必须看的病)→ 120(几分钟内就要救命的病)**。
- 打 120 前 30 秒在心里排好话:**地址(精确到门牌/楼层/地标)→ 病情 → 电话 → 保持畅通 → 清通道**。

## 一、全身危险信号总表:出现即 120 / 直奔急诊

以下信号提示可能危及生命,**不要**观望、不要"睡一觉再说":

| # | 危险信号 | 提示什么 | 动作 |
|---|---|---|---|
| 1 | 胸痛/胸闷,压榨感、放射至肩臂下颌,伴大汗恶心 | 心梗、主动脉夹层、肺栓塞 | 立即 120,静卧,别自行驾车(见 01 篇) |
| 2 | 严重呼吸困难:喘不上气、口唇发紫、说不出整句话 | 哮喘急性发作、气胸、心衰、肺水肿、严重过敏 | 立即 120;坐位,随身气雾剂按医嘱使用 |
| 3 | 意识改变:呼之不应、意识模糊、抽搐不止 | 心搏骤停、中风、癫痫持续状态、低血糖昏迷、中毒 | 无呼吸→立即CPR+取AED;有呼吸→侧卧,120 |
| 4 | 突发"一生中最剧烈"的头痛(炸裂样) | 脑出血、蛛网膜下腔出血 | 立即 120,不要自行用药 |
| 5 | 口齿不清、口角歪斜、一侧肢体无力/麻木 | 中风 | 立即 120,记录发病时间(BEFAST,见 01 篇) |
| 6 | 大出血:喷射状、按压不止、血浸透多层敷料 | 动脉/大血管损伤 | 持续直接压迫,立即 120;四肢可加压包扎 |
| 7 | 剧烈腹痛:持续加重、板状腹(按不得)、呕血便血 | 消化道穿孔、胰腺炎、宫外孕、肠梗阻 | 立即急诊/120;禁食禁水,不要自行服止痛药 |
| 8 | 高热(≥39-40℃)伴精神差、抽搐、颈项强直、皮疹不褪色 | 重症感染、脑膜炎、脓毒症 | 立即急诊;婴幼儿高热抽搐→120 |
| 9 | 严重过敏反应:喉头发紧、声音嘶哑、呼吸困难、全身荨麻疹、头晕 | 过敏性休克(食物/药物/蜂蜇) | 立即 120;有肾上腺素笔立即使用,平卧抬腿 |
| 10 | 头外伤后意识不清、呕吐、抽搐、耳鼻流清水/血 | 颅骨骨折、颅内出血 | 立即 120;不要随意搬动头颈部 |
| 11 | 孕期出血、剧烈腹痛、胎动明显减少、抽搐 | 宫外孕、流产、胎盘早剥、子痫 | 立即 120 |
| 12 | 疑似一氧化碳中毒/药物过量/化学品中毒 | 中毒 | 见 02 篇;带好药瓶/毒物包装,120 |
| 13 | 大面积烧烫伤、电击伤、高处坠落、车祸重伤 | 多发创伤 | 120;勿随意移动(防脊柱损伤),除非环境危险 |
| 14 | 突发单眼无痛性失明、视野缺损 | 视网膜血管栓塞、卒中 | 尽快急诊(黄金时间短) |

> 使用提示:本表覆盖"概率上最致命"的情形,不追求穷尽。**符合"突发的、严重的、影响呼吸/意识/循环的"三要素之一,就按急诊对待。**

## 二、就医层级决策:四级阶梯怎么选

```
该去哪一层?
│
├─ 会死/会残的风险,几分钟~几十分钟内恶化 → 拨 120(急诊中的急诊)
│   胸痛、中风、呼吸困难、大出血、昏迷、抽搐>5分钟、严重外伤、过敏性休克
│
├─ 数小时内需要医生处理,自己去有风险或来不及 → 急诊(步行到院/打车)
│   高热≥39.5℃不退、剧烈呕吐腹泻脱水、骨折、深伤口缝合、
│   眼部化学伤(先冲洗)、动物咬伤(先冲洗15分钟,狂犬疫苗常在犬伤门诊/急诊)、
│   剧烈疼痛但生命体征平稳、孕期不适
│
├─ 1-2 天内需要看,不紧急 → 普通门诊(社区医院/校医院/医院门诊部)
│   感冒咳嗽、皮疹、扭伤后想拍片、体检报告解读、开药复诊、伤口拆线
│
└─ 自我照护即可观察 → 校医院/社区门诊/线上问诊(丁香医生、腾讯医典等)
    轻微擦伤、小面积一度烫伤(红而不起泡)、轻度鼻出血已止住、
    轻症感冒、轻度腹泻无脱水
```

### 帮助决策的四个问题
1. **问题出在哪个器官?** 心、脑、肺、大血管、孕产 → 优先往高档走。
2. **起病有多急?** "突发"比"慢慢加重"危险等级高。
3. **症状在变好还是变坏?** 进行性加重 → 升级就医层级。
4. **这个人是谁?** 老人、孕妇、婴幼儿、慢病患者、免疫力低下者 → 同样症状标准放宽一档。

### 大学生校园场景提示
- 宿舍急性情况:先评估再搬动,昏迷/可疑骨折者不要摇晃、不要背下楼(疑颈/脊柱伤要等专业人员),身边人分工:一人 120、一人取 AED/急救包、一人到校门接车。
- 夜间校医院停诊:直接考虑急诊;路程远或有危险信号 → 直接 120。
- 不确定时:校医院值班电话、120 调度员、"当地医院急诊科"电话都可以问——**打电话咨询不丢人**。

## 三、拨打 120 的标准动作

### 通话模板(照着说)
1. **地址最优先**:「我在 ××市××区××路××号 ×× 小区 ××栋××单元××楼××室 / ××大学××校区××楼××层」+ 附近明显地标(如"东门保安亭旁""××超市对面")。
2. **病情一句话**:「患者是 ×× 岁 × 性,突发胸痛/昏迷/大量出血,大约 × 分钟前发生」+ 病人人数。
3. **留电话**:报上可打通的手机号;听清调度员是否说"救护车已派出"。
4. **接受电话指导**:调度员可能指导你做 CPR/止血——照做,电话开着。
5. **等车与准备**:
   - 派人穿显眼衣服到路口/小区门口接救护车;
   - 清理通道:电梯停到一楼待命?楼道杂物挪开?大门打开?
   - 收拾好:医保卡/身份证、既往病历、正在吃的药、陪护的现金/手机充电宝;
   - **别先挂断**,让调度员先挂;情况变化(患者呼吸停止)再次拨打更新信息。

### ❌ 常见错误做法
- ❌ 只说"快来××大学!"不说楼栋楼层——救护车找不到人,浪费黄金时间。
- ❌ 慌乱中先挂电话。
- ❌ 一边等一边围着患者七嘴八舌、拍视频——留出操作空间,保持空气流通。
- ❌ 隐瞒自杀/服毒等情况——如实告知,决定救治方案。

## 四、急诊就诊流程与分诊(不慌,照流程走)

1. **预检分诊台**:进急诊先到"预检/分诊台",简述主诉(谁、哪里不舒服、多久了、有无危险信号),护士会测生命体征(心率/血压/血氧/体温)并给红/黄/绿等级:
   - 红(濒危/危重):立即抢救室;
   - 黄(急重):优先就诊;
   - 绿(轻症):候诊——**等得久不代表被忽视,红黄优先级在前**。
2. **挂号与陪同**:分诊台通常同步/后续挂号;带身份证、医保卡(或电子医保凭证)、既往用药清单。
3. **候诊期注意**:患者出现新发胸痛、意识变差、呕血等,立刻回分诊台呼叫,不要干等叫号。
4. **沟通要点**:医生问诊时按"时间线"讲(何时开始→怎么发展→用过什么药→过敏史→基础病)。
5. **检查与缴费**:抽血/CT/心电图等常需往返,留好单据;病情变化随时找分诊台。
6. **留观/住院/离院**:听医嘱;离院时问清"回家后出现什么情况必须回来"。

## 五、家庭/宿舍急救包清单

### 耗材类
- [ ] 无菌纱布块、纱布绷带(各 2-3 卷)
- [ ] 弹力绷带(加压/固定扭伤)
- [ ] 创可贴(大/小号)、医用胶带
- [ ] 碘伏棉签/碘伏液(比酒精温和)
- [ ] 生理盐水(小瓶,冲洗伤口/眼睛)
- [ ] 无菌手套 2 副、一次性口罩
- [ ] 三角巾/大块干净布料(悬吊手臂、覆盖大面积烧伤)
- [ ] 保鲜膜(临时覆盖烧烫伤创面)
- [ ] 剪刀、镊子(圆头)

### 器械类
- [ ] 体温计(电子)
- [ ] 血压计(家有老人建议备)
- [ ] 冰袋/速冷冰袋(扭伤、中暑、鼻出血)
- [ ] 手电筒(查瞳孔、停电、引虫出耳)
- [ ] 救护毯/太空毯(保温)

### 药品类(遵说明书与医嘱使用,注意有效期)
- [ ] 退热止痛:对乙酰氨基酚 或 布洛芬(二选一,不叠加)
- [ ] 抗过敏:氯雷他定 或 西替利嗪
- [ ] 止泻/口服补液盐(腹泻脱水)
- [ ] 藿香正气/人丹等防暑用品(仅清醒者使用;藿香正气水含酒精,开车前勿服)
- [ ] 个人慢病用药(哮喘气雾剂、硝酸甘油、胰岛素等,遵医嘱存放)
- [ ] 有严重过敏史者:肾上腺素自动注射笔(处方药,咨询医生)
- [ ] 每半年检查一次效期,过期及时更换

### 信息类
- [ ] 本篇"急救信息卡"(每人一张,见下)
- [ ] 紧急联系人电话卡(钱包/手机壳内)
- [ ] 火警 119 / 报警 110 / 急救 120 / 交通事故 122 贴纸(冰箱贴或门后)

## 七、手机里的急救功能:让手机成为"救命的证件"

### iPhone
1. **紧急 SOS**:按住侧边键+音量键(或连按 5 次侧边键,依版本)→ 滑动呼救,自动呼叫紧急服务,并可通知紧急联系人、发送位置。
2. **医疗急救卡(Health 健康 App)**:健康 App → 右上头像 → 创建"医疗急救卡",填写血型、过敏、用药、紧急联系人 → **设置"锁定时显示"**,锁屏状态下施救者从"紧急"入口即可看到,无需解锁。
3. 提前把爸妈设为"紧急联系人"。

### 安卓(各品牌大同小异)
1. **紧急 SOS**:多数机型为"连按 5 次电源键"(设置 → 安全和紧急/SOS 紧急求助)→ 呼叫紧急号码并推送位置给紧急联系人;部分品牌支持语音触发。
2. **锁屏紧急信息**:"紧急信息/SOS"设置里可填写医疗信息与紧急联系人,锁屏"紧急呼叫"界面可见;小米/华为/OPPO/vivo/三星均内置类似功能(路径名称略有差异,搜索"紧急"即可找到)。
3. **位置共享**:和家人开通微信"位置共享"/手机家人共享,紧急时快速定位。

### 通用设置思路(现在就花 10 分钟做)
- [ ] 设置锁屏"紧急呼叫"中的紧急联系人与医疗信息
- [ ] 锁屏壁纸/壁纸上备注血型、过敏史(贴纸或文字壁纸)
- [ ] 微信"应急联系人":我 → 设置 → 账号与安全(用得上时省去翻找)
- [ ] 下载"AED地图"小程序并收藏;记下学校/小区最近的 AED 位置
- [ ] 把 120、学校校医院、社区医院号码存为常用联系人并加标签
- [ ] 教会爸妈使用各自手机的 SOS(打一次视频电话演示)
