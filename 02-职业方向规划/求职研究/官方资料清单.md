# 官方资料清单

| 主题 | 入口 | 用法 |
|---|---|---|
| ROS2      | https://docs.ros.org/en/jazzy/      | 按教程完成节点、话题、服务、参数、TF 和 rosbag |
| PX4       | https://docs.px4.io/main/en/        | 了解飞控架构、仿真、MAVLink 和调参流程 |
| PyTorch   | https://pytorch.org/tutorials/      | 学张量、数据集、训练、评估和保存模型 |
| Python    | https://docs.python.org/3/          | 按项目问题查标准库、异常、数据处理和环境行为 |
| FastAPI   | https://fastapi.tiangolo.com/       | 完成请求模型、JSON 接口、错误处理和接口测试 |
| HTTP      | https://developer.mozilla.org/en-US/docs/Web/HTTP | 理解方法、状态码、请求响应和缓存等接口基础 |
| Git       | https://git-scm.com/docs            | 查询分支、提交、差异和协作命令的真实语义 |
| GCC       | https://gcc.gnu.org/onlinedocs/gcc/ | 编译选项、警告、调试和链接问题 |
| OpenCV    | https://docs.opencv.org/4.x/        | 图像读取、特征和基础视觉实验 |
| FreeRTOS  | https://www.freertos.org/           | 任务、队列、同步和内存管理概念 |
| STM32     | https://www.st.com/                 | 以目标芯片的 Reference Manual、Datasheet、Cube/HAL 文档为准 |

资料使用原则：先由当前项目暴露问题，再查对应官方 API、协议文档或芯片手册；教程只补必要背景。ROS2、PX4、OpenCV 等资料不会因为出现在清单里就自动成为本学期任务，是否启动遵循规划优先级。
