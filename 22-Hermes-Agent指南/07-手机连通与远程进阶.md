## 0. 场景全景图

手机触达 Hermes 只有**三条路径**，理解了就不会乱：

| 路径 | 干什么 | 是否需要公网入站 | 适合谁 |
|---|---|---|---|
| ① 消息网关 bot | 手机在 Telegram/飞书/微信等聊天里发文字/语音/图片，agent 回；cron 结果也推到这里 | **完全不需要**（长轮询/WebSocket/反向连接） | 绝大多数学生：随手派任务 |
| ② 远程终端 SSH | 手机开 SSH 客户端，远程敲命令、改文件、看日志 | 需要网络可达（可用 Tailscale 私网） | 想完整操控 agent 运行环境 |
| ③ Dashboard / Web UI | 手机浏览器看状态、Chat、Logs、Cron、成本面板 | 默认仅 localhost；远程要自己解决鉴权+通道 | 调试与可视化管理 |

**一条安全红线【官方】**：bot token、登录二维码、dashboard 凭据就是你这台 agent 的"钥匙"。不要截图外发二维码（抖音多条教程原文警示"二维码是登录凭证，千万别截图外发"）【社区】\<https://www.iesdouyin.com/share/video/7684097605734911267>；不要把有终端权限的 bot 裸奔到公网；绝不要在终端 bot 上开 `GATEWAY_ALLOW_ALL_USERS=true`。

## 1. 消息网关接手机（最核心）

### 1.1 通用流程（【官方】，所有平台共用）

```bash
hermes gateway setup     # 交互向导：选平台、填 token、检测连通、写 ~/.hermes/.env
hermes gateway           # 前台跑（调试用）
hermes gateway start     # 以后台服务方式启动
hermes gateway status    # 查看各平台连接状态（含 registration drift）
hermes gateway stop      # 排空并停止
```

来源：\<https://hermes-agent.nousresearch.com/docs/user-guide/messaging> 及各平台子页。

- 凭据统一存 `~/.hermes/.env`（Windows 原生为 `%LOCALAPPDATA%\hermes\.env`）。
- **白名单机制**：`<PLATFORM>_ALLOWED_USERS=数字ID` 逐个放行；未配置任何 allowlist 时**默认拒绝所有入站消息**（安全兜底）；未知 DM 会收到一次性配对码（1 小时过期），用 `hermes pairing approve <platform> <CODE>` 批准。
- 手机端多媒体能力（【官方】综合各平台页）：

| 手机发/收 | 官方支持 |
|---|---|
| 发语音给 agent | 自动 STT：本机 faster-whisper（免费）/ Groq Whisper（需 `GROQ_API_KEY`）/ OpenAI Whisper |
| agent 回语音 | TTS（Edge TTS 默认免费，需本机 ffmpeg 转 Opus；OpenAI/ElevenLabs/Gateway TTS） |
| 发图片/截图 | 网关下载缓存后交给视觉模型 |
| 发文件（PDF/Office） | 支持；小文本文件自动提取内容 |
| agent 回文件 | 回复里写 `MEDIA:/路径`，网关转成平台原生附件 |

### 1.2 Telegram（国内学生首选的"国际版"，自备网络环境）

【官方】\<https://hermes-agent.nousresearch.com/docs/user-guide/messaging/telegram>

1. 手机 Telegram 找 **@BotFather**（t.me/BotFather）→ 发 `/newbot` → 起名字 → 起一个以 `bot` 结尾的 username → 拿到 token（形如 `123456789:ABCdef...`）。
   - 可选：`/setcommands` 配命令菜单（官方建议起始集 help / new / sethome）；群里用要 `/setprivacy` 关隐私模式（或把 bot 提为群管理员），**改完必须把 bot 移出群再加回才生效**。
2. 给 **@userinfobot** 发消息，拿到你自己的数字用户 ID。
3. 写 `~/.hermes/.env`（或让 `hermes gateway setup` 自动写）：

```bash
TELEGRAM_BOT_TOKEN=123456789:ABCdef...
TELEGRAM_ALLOWED_USERS=123456789
```

4. `hermes gateway` 启动，手机 DM bot 验证。
- 网络限制环境支持代理：`TELEGRAM_PROXY=socks5://127.0.0.1:1080`。
- 云部署可选 webhook 模式（`TELEGRAM_WEBHOOK_URL` + 必填 `TELEGRAM_WEBHOOK_SECRET`）；**家用电脑默认长轮询即可**，不用公网。
- 大文件上限 20MB（官方给出自建 local telegram-bot-api 升到 2GB 的教程）。

### 1.3 Discord

【官方】\<https://hermes-agent.nousresearch.com/docs/user-guide/messaging/discord>

1. Discord Developer Portal → New Application → Bot 页。
2. **Privileged Gateway Intents 必开两个**：Server Members Intent + **Message Content Intent**——不开则 Discord 直接拒绝连接，bot 永远不上线（官方称这是 #1 故障原因）。
3. Bot 页 → **Reset Token**（只显示一次）→ 复制。
4. 开发者模式右键自己头像 → Copy User ID。

```bash
DISCORD_BOT_TOKEN=...
DISCORD_ALLOWED_USERS=284102345871466496
```

- DM 必响应；服务器频道默认需 @提及；共享频道内默认按用户隔离会话。

### 1.4 Slack（Socket Mode，无需公网 URL）

【官方】\<https://hermes-agent.nousresearch.com/docs/user-guide/messaging/slack>

```bash
hermes slack manifest --agent-view --write   # 生成官方 manifest JSON
```

然后：api.slack.com/apps → Create New App → From an app manifest → 粘贴 JSON → 开 **Socket Mode** → 建 App-Level Token（`xapp-` 开头）→ Install to Workspace → 拿 Bot Token（`xoxb-`）。

```bash
SLACK_BOT_TOKEN=xoxb-...
SLACK_APP_TOKEN=xapp-...
SLACK_ALLOWED_USERS=U01ABC2DEF3
```

### 1.5 WhatsApp（官方明示封号风险）

【官方】\<https://hermes-agent.nousresearch.com/docs/user-guide/messaging/whatsapp>

1. `hermes whatsapp` → 终端显示 QR → 手机 WhatsApp → Settings → **Linked Devices** → Link a Device → 扫码（需 Node.js v18+）。
2. 桥是内置 **Baileys**（模拟 WhatsApp Web，**非官方 Business API**）。
3. 官方封号警示：非官方 bridge 有被封号可能——**用专门副号、不群发、不主动外发**。会话文件 `~/.hermes/platforms/whatsapp/session` 等同密码，`chmod 700`。

### 1.6 飞书 / Lark（国内学生首选，WebSocket 无需公网 webhook）

【官方】\<https://hermes-agent.nousresearch.com/docs/user-guide/messaging/feishu>

1. **最简**：`hermes gateway setup` 选 **Feishu / Lark** → 手机飞书 App **扫二维码自动建应用**并写好凭据。
2. 手动：open.feishu.cn（国内）建应用 → 拿 App ID + App Secret → 开 Bot 能力 → 加 scope（`im:message`、`im:message:send_as_bot` 等）→ 订阅 `im.message.receive_v1` → **必须发布版本**才生效。

```bash
FEISHU_APP_ID=cli_xxx
FEISHU_APP_SECRET=secret_xxx
FEISHU_DOMAIN=feishu               # 国内；国际版用 lark
FEISHU_CONNECTION_MODE=websocket   # 推荐，无需公网
FEISHU_ALLOWED_USERS=ou_xxx
```

- 危险命令审批在飞书里是**交互式卡片按钮**（Allow Once/Session/Always/Deny）。
- 媒体双向全支持。群策略默认 allowlist。

### 1.7 后台常驻（三平台）

**Linux 服务器**（【官方】）：

```bash
hermes gateway install                 # 注册为 systemd 用户服务
sudo hermes gateway install --system   # 开机自启系统服务（仍以你用户身份跑）
hermes gateway start / stop / status
journalctl --user -u hermes-gateway -f   # 看日志
sudo loginctl enable-linger $USER        # 注销后用户服务仍运行
```

**Windows 原生**（【官方】）：`hermes gateway install` 注册 **Hermes_Gateway** 计划任务（登录时触发），`hermes gateway start` 隐藏窗口启动。

**WSL2 常驻（学生高频坑）**（【官方】\<https://hermes-agent.nousresearch.com/docs/user-guide/windows-wsl-quickstart>）：

1. 先开 systemd：写 `/etc/wsl.conf`：

```ini
[boot]
systemd=true
[interop]
enabled=true
appendWindowsPath=true
```

   然后 PowerShell 执行 `wsl --shutdown` 重启生效。`hermes gateway setup` 向导会主动询问是否安装 systemd 用户单元。

2. **为什么会掉线**：WSL2 VM 在没有进程占用时会退出 → VM 一停，里面的 gateway 就停。官方保活方案：Windows 任务计划程序加一个"用户登录时"触发的任务：
   - 程序：`C:\Windows\System32\wsl.exe`
   - 参数：`-d Ubuntu --exec /bin/sh -c "sleep infinity"`
3. 官方另提醒：WSL2 休眠/唤醒后时钟会漂移（`sudo hwclock -s` 修复），会导致 OAuth/HTTPS 证书类连接出错。

【社区】相关 issue：#90769（笔记本睡眠/唤醒后 gateway 假死，已修）、#106742（统一 gateway runtime，2026-10-14 merged）。\<https://github.com/NousResearch/hermes-agent/issues?q=gateway+wsl2+drop+disconnect>

## 2. 微信桥接（官方 iLink Bot API 方案）

【官方】\<https://hermes-agent.nousresearch.com/docs/user-guide/messaging/weixin>

1. `hermes gateway setup` 选 **Weixin** → 终端出 QR → **手机微信扫码** → 凭据自动存 `~/.hermes/weixin/accounts/`。
2. 走腾讯 **iLink Bot API**（\<https://ilinkai.weixin.qq.com>），**不是** gewechat/wechaty 第三方 hook；HTTP 长轮询收消息，**无需公网 IP、无需 webhook**。

```bash
WEIXIN_ACCOUNT_ID=...
WEIXIN_TOKEN=...            # 扫码后自动保存
WEIXIN_DM_POLICY=open
WEIXIN_ALLOWED_USERS=user_id_1,user_id_2
```

### 关键限制（【官方】原话要点）

- 扫码得到的是 iLink bot 身份（形如 `xxx@im.bot`），**不是可完全脚本化的普通个人微信号**；
- **通常进不了普通微信群、收不到群消息事件**；
- 实际上**只有 DM（私信）可靠**——群消息收不到是 iLink 侧限制，不是 Hermes bug；群策略默认 `disabled`；
- 会话过期（errcode=-14）需重新扫码；图片/视频/文件/语音全支持（微信 CDN 加密自动解密）。

### 封号风险（如实区分）

- 【官方】：封号警示**只在 WhatsApp 页明示**；微信页没有单列封号风险段落。
- 【社区】：B站专栏（老马）明确警告"把个人微信号变成机器人号，微信查到肯定会封号"，并指第三方插件宣传有误导 \<https://m.bilibili.com/opus/1193571862593929220>；抖音教程口径"走腾讯官方 iLink、不是野路子逆向，但**先用小号测试、主力号不着急**"【未看正片，博主口播】\<https://www.iesdouyin.com/share/video/7627542076154072362>。
- 【编者推断】综合：通道比第三方 hook 正规，但仍是个人号走非官方 Bot API，**风控风险客观存在**；未检索到"微信号被封"的一手亲历帖，风险程度**暂未核实**。
- **建议**：小号先行、二维码不外发、私信为主、群聊别指望；不想担风险就用飞书/Telegram/QQ 替代。

## 3. 手机远程终端（SSH，可照做）

> 本节命令均来自官方文档：Ubuntu Server OpenSSH 文档、Termux Wiki、Microsoft Learn WSL 网络文档。

### 3.1 手机端 App 选择

- **Android 客户端**：Termux（`pkg install openssh` 后当 SSH 客户端用）或 JuiceSSH（图形化、存多主机）。【Termux Wiki：\<https://wiki.termux.com/wiki/Remote_Access>】
- **iOS 客户端**：iOS **没有**自带终端 App，用第三方 SSH 客户端，如 Termius、a-Shell 等（按 App Store 评价自选）。

### 3.2 在 WSL2 里装并启动 SSH 服务端（【官方·Ubuntu】\<https://www.ubuntu.com/server/docs/how-to/security/openssh-server/>）

```bash
# 1. 安装（Ubuntu 官方命令）
sudo apt install openssh-server

# 2. （可选但建议）改端口，避免与 Windows 自带的 OpenSSH 冲突
#    编辑 /etc/ssh/sshd_config，把 Port 改为 2222（或 23）；也可在 /etc/ssh/sshd_config.d/ 下放片段

# 3. 改完配置先检查语法，再重启（Ubuntu 官方顺序）
sudo sshd -t
sudo systemctl restart ssh.service

# 4. 查 WSL2 本机 IP（另一台机器连进来时要用）
ip addr
```

- Ubuntu 官方要点：配置文件是 `/etc/ssh/sshd_config`（或 `/etc/ssh/sshd_config.d/*.conf` 片段，片段优先）；**改配置后先 `sudo sshd -t` 检查再重启**，否则可能把自己锁在外面；排查问题看 `sudo journalctl -fu ssh.service`。
- 【官方提示·Microsoft Learn】Windows 也自带 OpenSSH 客户端/服务，若你在 Windows 侧开了 sshd，WSL2 的 22 端口会与之冲突——建议 WSL2 里把 sshd 改到 2222，或停掉 Windows 的 sshd 服务。

### 3.3 密钥登录（推荐，最短步骤）

在**手机（或你的电脑）**上生成密钥对（Ubuntu 官方推荐 ed25519）：

```bash
ssh-keygen -t ed25519          # 一路回车即可
```

把公钥装进 WSL2 的 authorized_keys：

```bash
ssh-copy-id -p 2222 你的WSL用户名@WSL的IP
chmod go-w ~/.ssh/authorized_keys    # Ubuntu 官方：仅本人可写
```

之后手机直接连：

```bash
ssh -p 2222 你的WSL用户名@WSL的IP
```

- 密码登录只作下策：简单但会被全网扫描爆破，**仅限同一可信局域网临时用**；上云服务器或暴露到外网前务必换成密钥并关掉密码登录（`PasswordAuthentication no`）。

### 3.4 手机连 WSL2 的两条链路（【官方·Microsoft Learn：\<https://learn.microsoft.com/en-us/windows/wsl/networking>】）

**链路一：同一 WiFi 局域网（不用外网）**

WSL2 默认 NAT，手机不能直接连 WSL IP，需在 Windows **管理员** PowerShell 做端口转发：

```powershell
wsl hostname -I    # 查 WSL 的 IP（大写 -I）
netsh interface portproxy add v4tov4 listenport=2222 listenaddress=0.0.0.0 connectport=2222 connectaddress=<wsl的IP>
```

再在 Windows 防火墙放行 2222 端口。手机连 `Windows宿主IP:2222`。**WSL2 IP 重启会变**，portproxy 要跟着更新；嫌麻烦就开 mirrored 模式（见 §4.3，Win11 22H2+ 后互访直接 localhost）。

**链路二：外网（宿舍外也能连）**

不要把 2222 裸奔到公网。装 Tailscale（Windows 宿主装一份，见 §4.2），手机装 Tailscale App 同一账号，手机直接 `ssh -p 2222 用户@<WSL/宿主的 tailscale 地址>`——WireGuard 加密私网，不用开路由器端口。

**云服务器**：厂商控制台给 root 密码/密钥，手机 Termius/JuiceSSH 直连 IP 即可（云厂商已处理网络）。

### 3.5 反向：把安卓旧手机当服务器（可选，【官方·Termux Wiki】）

想让手机 7×24 被你 SSH 进来：

```bash
pkg upgrade
pkg install openssh
passwd          # 给 Termux 设密码（登录用）
sshd            # Termux 的 SSH 服务默认端口 8022
```

手机连电脑/另一设备：`ssh -p 8022 手机IP`。官方建议配公钥后在 `$PREFIX/etc/ssh/sshd_config` 把 `PasswordAuthentication` 改为 `no` 更安全。

## 4. 外网可达与内网穿透

### 4.1 方案对比（命令均来自各官方文档，2026-10-20 抓取）

| 方案 | 需要公网服务器？ | 免费额度 | 安全模型 | 适合场景 |
|---|---|---|---|---|
| **Tailscale** | 否（组私有 tailnet） | 个人免费版 | WireGuard 加密私网，设备间互信 | **首选**：手机组网直连 WSL2/VPS |
| **Cloudflare Tunnel** | 否 | quick tunnel 免费（临时） | 出站长连接；可套 Cloudflare Access 鉴权 | 临时分享 dashboard、长期绑定域名 |
| **frp** | **是**（公网 IP 服务器） | 开源自建 | 自管；stcp 私密模式 | 已有云服务器、要暴露固定端口 |
| **ngrok** | 否 | 有免费档 | 官方网关 | 与 cloudflared 同类，**素材不足，未展开** |

### 4.2 Tailscale 推荐链路

【官方】WSL2 专页：\<https://tailscale.com/docs/install/windows/wsl2>

**反直觉关键建议（官方）**：**只在 Windows 宿主上装 Tailscale，不要在 WSL2 里再跑一份**——"WSL2 里的 Tailscale 包套在 Windows 宿主的 Tailscale 包上，包套包传不通"。

```bash
# （WSL2 内安装命令仅作参考；按官方建议优先装 Windows 宿主侧）
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up
```

- 手机端：iOS/Android 装 Tailscale App，同一账号登录即入 tailnet，手机可直接访问 WSL2/VPS 的 100.x.x.x 地址。
- `tailscale up --ssh` 后，手机直接 `ssh user@<机器tailscale名>`，不用开 22 端口公网（官方功能，SSH 专页未精读）。
- 【社区·国内替代】国内网络下 Tailscale 直连可能不稳，有博主演示国内可用的 Headscale 自建方案（云雀通）\<https://www.bilibili.com/video/BV1hLVH6UERY/>【未看正片】。

### 4.3 WSL2 网络细节（【官方】Microsoft Learn：\<https://learn.microsoft.com/en-us/windows/wsl/networking>）

- 默认 NAT 模式：Windows 访问 WSL2 直接 `localhost:<端口>`；局域网其他机器访问 WSL2 需在 Windows **管理员** PowerShell 转发：

```powershell
wsl hostname -I    # 查 WSL 的 IP（大写 -I）
netsh interface portproxy add v4tov4 listenport=4000 listenaddress=0.0.0.0 connectport=4000 connectaddress=<wsl的IP>
```

   还需放行 Windows 防火墙对应端口。**WSL2 IP 重启会变**，portproxy 要随之更新（或用 mirrored 模式）。

- Mirrored 模式（Windows 11 22H2+，官方推荐）：写 `C:\Users\<你>\.wslconfig`：

```ini
[wsl2]
networkingMode=mirrored
```

   `wsl --shutdown` 重启；效果：WSL 与 Windows 共享网络栈，互访直接用 `localhost`，WSL 可直接被局域网访问。还需管理员 PowerShell 放行 Hyper-V 防火墙：

```powershell
Set-NetFirewallHyperVVMSetting -Name '{40E0AC32-46A5-438A-A0B2-2B479E8F2E90}' -DefaultInboundAction Allow
```

### 4.4 Dashboard（【官方】\<https://hermes-agent.nousresearch.com/docs/user-guide/features/web-dashboard>）

```bash
hermes dashboard              # 默认 http://127.0.0.1:9119，自动开浏览器
hermes dashboard --port 8080
hermes dashboard --host 0.0.0.0
```

- 页面：Status / Chat（浏览器里跑 TUI）/ Config / API Keys / Sessions / Logs / Analytics / Cron。
- **`/chat` 标签页仅 POSIX 可用**：原生 Windows 上不可用，官方会挂横幅让你用 WSL2。
- **绑非回环地址强制鉴权（fail-closed）**：没配 auth 就绑 0.0.0.0 → 启动直接拒绝（exit 78）。需在 `~/.hermes/.env` 配：

```bash
HERMES_DASHBOARD_BASIC_AUTH_USERNAME=admin
HERMES_DASHBOARD_BASIC_AUTH_PASSWORD=choose-a-strong-password
HERMES_DASHBOARD_BASIC_AUTH_SECRET=<openssl rand -base64 32>
```

- **官方文档未提供 HTTPS/TLS 选项**【官方事实】。远程访问姿势（【编者推断】综合官方+第三方）：
  - 优先：保持 loopback 绑定 + `ssh -L 9119:localhost:9119` 隧道，或走 Tailscale 私网；
  - 必须公网暴露时：basic auth + Cloudflare Access（Zero Trust）邮箱 OTP 前置，**不要裸奔**。
- Dashboard 与 gateway 是两个独立长驻进程，远程接 Desktop 时要分别常驻。

### 4.5 临时隧道与 frp 示例

**Cloudflare quick tunnel**（【官方】\<https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/do-more-with-tunnels/trycloudflare/>）：

```bash
cloudflared tunnel --url http://localhost:9119
```

自动生成随机 `https://xxx.trycloudflare.com`。限制：仅测试/开发；并发 200 in-flight，超了 429；不支持 SSE；无 SLA。

**frp 最小配置**（【官方】\<https://github.com/fatedier/frp>）：需要一台公网服务器跑 `frps`。

```toml
# 公网服务器 frps.toml
bindPort = 7000
```

```toml
# 内网机器 frpc.toml（暴露 SSH）
serverAddr = "x.x.x.x"
serverPort = 7000
[[proxies]]
name = "ssh"
type = "tcp"
localIP = "127.0.0.1"
localPort = 22
remotePort = 6000
```

不想暴露公网端口时用 `type="stcp"` + `secretKey`（访问端也要跑 frpc 当 visitor），适合只给自己手机用。

## 5. 手机高级玩法

### 5.1 iOS 快捷指令 / 任何 HTTP 客户端派任务（【官方】Telegram Bot API：\<https://core.telegram.org/bots/api#sendmessage>）

端点：`https://api.telegram.org/bot<TOKEN>/sendMessage`，必填 `chat_id` + `text`。GET 直拼 URL（快捷指令"获取 URL 内容"动作即可）：

```
https://api.telegram.org/bot<TOKEN>/sendMessage?chat_id=<CHAT_ID>&text=<URL编码的文本>
```

拿 chat_id：给 bot 发一条消息后访问 `https://api.telegram.org/bot<TOKEN>/getUpdates`，从 `message.chat.id` 读。【编者推断】iOS 快捷指令做法为基于上述 API 标准用法。

### 5.2 cron 定时摘要/提醒推到手机（【官方】）

- 概念：**home channel** = cron job 默认投递目的地。在某个聊天里发 `/sethome`，或 `.env` 预配（`TELEGRAM_HOME_CHANNEL=...` / `FEISHU_HOME_CHANNEL=oc_...` 等各平台 env 命名一致）。
- 例子："每天早 9 点查 HN，把摘要发到 Telegram"——agent 自动建 cron job，触发时经 gateway 推给你。网关有持久化 delivery ledger，崩溃后至少一次送达。
- 【社区·实战】抖音博主演示 Tavily 抓 AI 热点总结 → 飞书生成云文档定时推送（标题挂课程广告，内容本身真实操作）\<https://www.iesdouyin.com/share/video/7677348370331077914>【未看正片】。

### 5.3 语音 / 拍照 / 截图

- 语音：手机发语音条自动 STT；agent 回 TTS 语音气泡。【社区】`/voice on` 一行开语音功能 \<https://www.iesdouyin.com/share/video/7644118521227676943>【未看正片】。
- 拍照：手机发截图/照片给 bot，网关交给视觉模型处理（如"帮我看看这张电路图错在哪"）。
- 【社区·手机硬件控制实测】有博主用 agent 口头指令打开 App、前后摄像头拍照、开关闪光灯——但同时划红线"只能用在你授权的设备和账号上" \<https://www.iesdouyin.com/share/video/7631070350928054523>【未看正片】。

### 5.4 多设备/多人共用一个 agent（【官方】）

- 白名单按平台独立，每个平台 `<PLATFORM>_ALLOWED_USERS` 列 ID；新用户首次 DM 收配对码，管理员 `hermes pairing approve` 放行。
- admin（可改 bot 设置）/ 普通用户（只能用白名单斜杠命令）两级。
- 群聊内默认按用户隔离会话，互不污染上下文。

## 6. 安全清单（照着过一遍）

1. 公网暴露任何服务必须鉴权：dashboard 绑 0.0.0.0 必须配 basic auth；优先 SSH 隧道/Tailscale 私网。【官方】
2. bot token 与扫码二维码保密：二维码不外发、不截图；泄露立即在 BotFather / 对应平台重置。【官方+社区】
3. 默认白名单；**不开** `GATEWAY_ALLOW_ALL_USERS`。【官方】
4. WhatsApp/微信走第三方通道：用小号、专用号码、不群发、不主动外发。【官方 WhatsApp 页 + 社区】
5. cron 与无人值守任务：危险命令默认 deny（cron 下 YOLO 也不生效），权限最小化（见 03 文件 §3）。【官方】
6. 只用官方安装脚本：社区流传的第三方一键安装包有被安全机制拦截的案例（供应链风险）\<https://www.iesdouyin.com/share/video/7662328653765758208>【未看正片】。
7. Tailscale 私网 vs 公网隧道：能私网就私网；要公网隧道就必须叠加鉴权（basic auth / Cloudflare Access）。【编者推断】

## 7. 学生最省事组合（【编者推断】，基于以上官方文档组合）

### 链路 A：无公网服务器（宿舍 Windows + WSL2）

```
手机 Telegram/飞书 App
   │（长轮询/WebSocket，无需公网）
   ▼
Windows 笔记本 ── WSL2（开 systemd + /etc/wsl.conf）
   │              └─ hermes gateway（systemd 用户服务）
   │              └─ 任务计划程序 wsl.exe ... sleep infinity 保活
   └─ Windows 宿主装 Tailscale（手机 App 同一账号 → 私网直连 SSH/dashboard）
```

- 国内网络：网关选**飞书**（WebSocket，国内直连）；自备网络环境：选 Telegram。
- 手机随时 DM bot 派任务；cron 结果 `/sethome` 推到同一聊天。

### 链路 B：有云服务器（¥24–40/月轻量 2核4G）

```
手机 Telegram/飞书 App
   │
   ▼
Linux 轻量云（一键镜像或官方 install.sh）
   └─ sudo hermes gateway install --system（开机自启）
   └─ journalctl --user -u hermes-gateway -f 看日志
```

- 【社区】腾讯云 Lighthouse 有官方 Hermes 应用镜像，2核4G ~90 秒开机 \<https://cloud.tencent.cn/developer/article/2750408>【软文·云厂商教程】；阿里云有预装专题页 \<https://developer.aliyun.com/article/1731281>【软文】。
- 可选：frp / cloudflared 仅当你要把 dashboard 暴露给他人时才加。

### 链路 C：安卓旧手机单机跑（Termux 路线）

- 【社区】B站/抖音有多条保姆级教程：GitHub 下 Termux APK（**不要用 Google Play，版本太旧**）→ `pkg update && pkg upgrade` → 官网安装命令一条 bash \<https://www.bilibili.com/video/BV1Cb556SEBR/>【未看正片】；抖音同路线 \<https://www.iesdouyin.com/share/video/7633084381066906033>【未看正片】。
- 【社区】已知限制：Termux 环境下会跳过浏览器自动化和语音功能（缺安卓翻译轮子）\<https://www.iesdouyin.com/share/video/7630260424218250546>【未看正片】；要关掉安卓电池优化、锁定后台进程防 Doze 杀进程。
- 定位：旧手机变 7×24 实验节点；主力推荐仍是链路 A/B。
