# GitHub·宝藏仓库地图（面向电信工程人）

> **一句话**：GitHub 不只是代码仓库，它是"自学者的图书馆"——awesome 系列、开源课程、开源教材，全都免费且长期有人维护。

## 这个平台的正确打开方式

1. 用它是"查库"不是"刷库"：按学科找 1-2 个 awesome 清单，从里面挑资源，不要试图逛完。
2. 判断一个仓库质量的三看：Star 数（>5k 算优质）、最近提交时间（半年内更新为佳）、README 是否成体系。
3. 英文仓库别怕：README 里的词高度重复，配合划词翻译完全可读；很多大仓库有中文翻译分支。

## 按学科群分类的宝藏仓库

### 总入口（先收藏这两个）
- **sindresorhus/awesome** — 所有 awesome 清单的总目录：想学什么，先来这里搜"awesome ×××"。
- **EbookFoundation/free-programming-books** — 全球免费编程类书籍清单（有完整的中文分支），计算机类资源的天花板。

### 计算机与算法
- **ossu/computer-science** — 开源世界大学：完整的 CS 学位课程体系，免费、有序、社区活跃。
- **krahets/hello-algo** — 《Hello 算法》中文图解数据结构与算法，动画化讲解，开源免费，中文首选。
- **TheAlgorithms/Python**（及 C/C++ 等各语言分支） — 算法的多语言参考实现库。
- **CyC2018/CS-Notes** — 中文 CS 基础知识汇总（注意：偏面试向，学习时可当"复习提纲"，别当教材）。
- **库内配套**：[`07_学业与深造/自学资源/`](/07-学业与深造/自学资源/) — csdiy 与 MIT Missing Semester 的中文精读笔记已就位，与本图互补。

### 人工智能与数据科学
- **microsoft/ML-For-Beginners** — 微软出品，26 课的机器学习入门课程， quizzes + 项目。
- **microsoft/AI-For-Beginners** — 同系列 AI 入门。
- **fastai/fastbook** — 《fastai 深度学习》配套书，代码先行路线。
- **microsoft/Data-Science-For-Beginners** — 同系列数据科学入门（10 周 20 课）。

### 学习方法与工具
- **selfteaching/TeachYourselfCS-CN** — 《自学计算机科学》中文翻译，自学路线的权威指南。
- **ruanyf/weekly** — 阮一峰科技爱好者周刊：每周筛一轮全网好资源，跨学科灵感的固定水源。

### 语言与人文（GitHub 的弱项，但有几颗遗珠）
- **ruanyf/document-style-guide** — 阮一峰《中文文案排版指北》：写作与排版的中文规范，工程师写作必读。
- **free-programming-books 的中文分支里也有非编程类**（数学、演讲、写作），翻它的多语言目录能捡到宝。

## awesome 系列的正确用法

1. 在 GitHub 搜索框输入 `awesome 学科英文关键词`（如 awesome economics、awesome neuroscience）。
2. 打开清单后不要从头看到尾：先看目录，挑"Getting Started"或"Introductions"分组。
3. 收藏仓库 ≠ 读了内容：给每个 awesome 仓库限定"只挑 3 个资源"的配额，防止新式收藏癖。

## 使用技巧

- **浅看用网页，深看用克隆**：真打算啃的仓库 `git clone` 下来当本地文件夹读，比网页快。
- **Watch 的正确用法**：不 watch 通知（会淹死），只对 1-2 个核心仓库开 Release 通知。
- **Issues 是隐藏讨论区**：很多仓库的 issue 区有中文学习者踩坑记录，搜问题先搜 issue。

## 防坑与使用提醒

- Star 高 ≠ 适合入门：很多神仓库是给从业者查阅的，先确认自己站对门槛。
- 警惕"面试八股仓库"：那类仓库只服务跳槽，与"非应试通识学习"的目标相反。
- 仓库可能删库或改向：发现优质仓库可 fork 一份自留。

> 资源整理时间：2026-10；平台内容可能更新，请以实际为准。
