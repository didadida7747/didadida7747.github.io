### 命名规则与命名法 [6:33]
- 标识符（identifier）就是"名字"，可唯一标识一个对象。规则：第一个字符必须是字母或下划线（如 SI100P、_tap 合法；`123abc`、`~` 开头不合法）；其余部分由字母、数字、下划线组成；不能含空格（`cat dog` 会被认成两个标识符）、不能含加减号（会被当成表达式）。
- [7:22] 标识符区分大小写：SI100p 与 SI100P 是两个不同变量（notebook 2.1.1 演示，print 出来是两个结果）；以数字开头会直接报不合法。违反命名规则不一定报错，但 VS Code 会给警告。
- [8:54] 主流命名法：驼峰命名法（第一个单词小写、后续单词首字母大写）、匈牙利命名法（变量名前写明类型，如今不太主流，了解即可）、下划线命名法（单词间用下划线分隔）、帕斯卡命名法〔字幕"pass卡命名法"，疑为：帕斯卡〕（每个单词首字母都大写，相当于驼峰再加大写首字母）。[9:39] PEP 8 规范〔字幕"PP8"〕中 Python 官方建议用下划线命名法，做 SI100B 期末 project 也建议统一。

### 关键字、缩进与注释 [10:28]
- 关键字是对 Python 有特殊含义的词，不能作标识符；内置模块 `keyword` 记录了当前版本所有关键词（`import keyword` 可打印出来）。直接拿 `and` 当标识符会报"不合法的表达式"，因为解释器把它当成了表达式，不知道你想表达什么。
- [11:15] Python 用缩进确定代码块（与 C/C++ 等用括号的语言不同）：同一列的语句属于同一代码块（如 a=10 与 b=10 在一个块里，缩进不同的 print 就不在）。VS Code 中 Tab 缩进、Shift+Tab 或删除键取消缩进。
- [12:51] 注释（comment，"评论"）是不会被执行的文本，是对代码的解释。[13:37] 严格来说 Python 只有单行注释：`#` 开头直至行尾；编辑器里注释显示为灰色。[15:08] 没有"官方的多行注释"，通常用三个单/双引号的多行字符串达成近似效果——它本质上是一个字面量（后面会讲到）。
- [14:23] VS Code 中 Ctrl+/（macOS 为 Cmd+/）注释/取消注释，注释时会实时变灰。
- 讲者反复强调：一定要养成写注释的习惯。

### 字面值、赋值语句与变量 [15:53]
- 字面值（literal value）：代码中写明的、临时使用的值，如 `x = 1.5` 中的 1.5；用完后解释器就把它释放掉（"用完就扔"）。三引号多行字符串能当"多行注释"，正因为它只是个用完即扔的字符串字面量。
- [17:26] 复杂计算需要保存中间步骤和结果，把字面值（及其计算结果）赋给变量的语句叫赋值语句：`x = 1.5`，理解为"令 x 等于 1.5 / 把 1.5 付给 x"。
- [18:15] 变量是存储数据的容器，可类比高中数学的未知数，可随时更改、存任意东西；名字即标识符，要尽可能有意义并反映实际用途（如 age=25、height=175.5 是浮点数、name="Alice"、是否学生=True）。
- [19:48] 与 C/C++ 可以只声明不赋值（`int a;`）不同，Python 的变量声明必须伴随赋值（初始值可以为"空"，如空字符串），声明和赋值通常在同一条语句完成。
- [33:07] 变量可被重复赋值（age 先后赋 15、20）；`age + 10` 这类表达式的结果是字面量，没有赋给任何变量就用完扔掉，不影响 age 本身（age 仍是 20）。
- [33:52] notebook 特性：代码块最后一行若以变量结尾，执行后会自动输出该变量的值（普通 Python 代码不能这么写）。

### 基本数据类型 [20:34]
- 三大类：数字（number）、字符串（string）、布尔（bool）。类型不同用途不同：数字 25 可以做四则运算，字符串 "25" 更像编号/标识。
- [22:53] 数字类型共四种，课程只讲两种：整型（int，正/负/零，无小数部分）和浮点型（float，带小数：3.14、0.001、2.0）。互动问题：整型 2 和浮点型 2.0 有区别吗？
- [24:29] 交互式终端：直接输入 `python`（macOS 为 `python3`）进入解释器；不行就先激活 uv 建的 `.venv` 虚拟环境（Windows 执行 `.venv/Scripts/activate.ps1`〔字幕口述 scripts/activate.ps1〕，macOS `source .venv/bin/activate`）。`type(2)`→int、`type(2.0)`→float、`type(2/1)`→float——只要涉及除法运算，结果总是浮点型。
- [27:35] 字符串：由一系列字符组成的文本数据，外面包引号，单双引号都行但两端必须一致；建议整个项目统一同一种引号风格（引号套引号的情况以后会遇到）。[28:25] 字符串支持加法：`"SI" + "100P"` → `"SI100P"`（回答了开头"字符串能不能四则运算"的悬念：加法可以）。[29:11] 字符串乘整数：`"SI100P" * 3` 重复三遍变长字符串；字符串乘字符串不可行（很难想象效果）；字符串里可以有引号，还提到反斜杠转义；留作业：如何让字符串同时包含单双引号（搜索后发 Piazza）。
- [31:31] 布尔型只有 True / False 两个值，表示二元状态（如开关、是否），常用于条件判断和逻辑运算；首字母必须大写，小写 true 不是合法的布尔型。

### 浮点数误差 [33:52]
- 神秘现象：`x = 0.1; y = 0.2; print(x + y)` 输出 0.30000000000000004，且 `x + y == 0.3` 为 False。
- [35:23] 原因：计算机以二进制存储一切数据，浮点数采用类似科学计数法 M×2^E 的表示，现代计算机遵循 IEEE 754〔字幕"HOE的754"，疑为：IEEE 754〕标准；运算都在二进制中进行——0.1 和 0.2 是在二进制形式上相加，而 Python 里的 0.3 实际存的也不是精确的 0.3（约 0.2999…），于是 0.1+0.2 ≠ 0.3。这就是舍入误差。
- [36:10] 课上放了"0.1+0.2 机器人验证码"漫画（答对就欢迎加入秘密机器人网络）；[36:57] 推荐了一个可视化浮点存储的网站（数据类型选 double——Python 浮点型即以 double 精度存储）。
- [38:32] 解决：一般四舍五入保留小数点后有限位；精度要求高时用 `decimal` 模块高精度存储（如 `x = Decimal("0.1")`），用 decimal 计算 0.1+0.2 就能正常输出 0.3。

### 运算符与优先级 [39:19]
- 基本运算符：`+ - * /`、`//`（整除）、`%`（取余/取模）、`**`（指数，Python 引入那节课用 5 的 14 次方演示过两个乘号）。
- [40:05] `//` 是向下取整，不是向零取整：5//3=1（一余二）；而 -5//3=-2，因为 -5 = -2×3 + 1——整除保证余数为正数；于是课堂提问 -5 % 3 = 1（同学答对了）。
- [40:52] `**` 指数：`5 ** 3` 即 5 的三次方。
- [41:37] 优先级：求指数 > 正负号 > 乘除/整除/取模 > 加减；有括号先算括号内，同层级算优先级高的，相同则从左至右（同高中数学）。经典迷惑例子：`-2**2` 结果是 -4——指数优先级更高，先算 2**2=4 再求正负号；优先级表可看菜鸟教程的文章。
- [42:23] 分步示例：先算括号，除法在 Python 中给出浮点型 0.5（很多语言整型相除会得 0），再算乘方、乘法、取模，最后相加；[43:09] 整个算式只要涉及除法，结果类型就是 float（现场验证）。

### 基本输入输出与文件 IO [54:21]
- 程序三件事：输入、处理、输出（IO = input/output）；IO 分标准输入输出流（绝大部分情况是直接与用户交互，目标是命令行控制台/终端）和文件 IO（目标是磁盘文件）。
- [55:08] `input()`：输入前先输出提示语，再接收用户输入保存到变量；注意 input 会把一切输入作为字符串处理。`print()`：打印变量，结尾默认附加换行，可用 `end="..."` 改结尾（改成 `end=""` 就什么都不加，即不换行）；`print(x, y, ...)` 逗号分隔会自动以空格间隔依次输出。notebook 2.4.3 演示：输入 2026 后按自定义格式输出。
- [57:27] 文件 IO：`f = open("test.txt", "r")` 以 read 模式打开；f 的类型不是基本数据类型（是个复杂对象，是什么留作探究发 Piazza）；`f.read()` 把文件内容读成字符串存入 content；`f.close()` 关闭。`"w"` 是覆写模式——直接覆盖文件原内容而不是追加；`"a"` 是 append/追加模式——从文件末尾写入、不覆盖原有内容；`\n` 是换行符。notebook 完整演示：读 test.txt（原文 hello SI100plus）→ 覆写为 "hello world\nthis is text" → 追加输入的字符串（如 2026）→ 再读出来。
- [1:02:05] 讲者说明：这种 open/close 写法并不是现在 Python 标准的文件操作方式，现在会用 `with`〔字幕"用vs去管理"，疑为：with〕管理文件生命周期；SI100B 大概率不考文件 IO，真正要用时再查文档即可。

### A+B 问题与强制类型转换 [1:03:37]
- 用户输入两个整数求和：输入 123、456 却输出 "123456"——因为 input 默认以字符串保存，a、b 都是 str，`+` 变成了字符串拼接。
- [1:04:23] 强制类型转换：`typename(x)`，如 `int()`、`float()`、`str()`；`int("123")` 得到整型 123，而原变量 a 的类型仍是 str。转换会创建新值，不影响原变量的类型和值；[1:07:31] 可理解为 `int(a)` 用 a 创建了一个新的 int 类型的字面量（可扔掉或赋给新变量），并非所有类型都能相互转换。
- [1:05:55] 典型用途：字符串与数字互转（"4.2" ↔ 4.2）；以及"移除浮点数小数部分"：`int(5.9)` 是 5——这个用途很重要，之后课程会遇到相关题目。课堂提问 `int(-5.9)` 是多少？很多人猜 -6，实际是 -5——它是"非常暴力"地直接砍掉小数部分，与向下取整不一样，此处比较坑。
- [1:08:16] 可以在 input 时直接转换：`b = int(input(...))`——input 创建字符串字面量，转成 int 字面量后再赋给 b，效果相同。

### 比较运算符与布尔运算 [1:09:04]
- 比较运算符：`==` 判相等（一个等号在绝大部分语言里是赋值；也不要认为所有语言都用两个等号判相等，可搜索了解）、`!=` 判不等、`>`、`<`、`>=`。结果是一个布尔值，代表该比较是否成立。
- [1:10:34] 布尔运算（高中"与或非"/真值表）：`and` 当且仅当左右两侧均为 True 结果才为 True；`or` 左右任意一侧为 True 结果即为 True；`not` 是一元运算符（只需一个变量），把右侧布尔值取反，而 and/or 是二元运算符。
- [1:12:52] 短路求值：`a and b and c ...` 中只要有任何一处为 False，整个表达式必然为 False，后面没必要再算；`or` 链同理遇 True 即停。本质是"偷懒"，能有效加速运算；Python 解释器很聪明，会做这种优化。参数从左至右求值，一旦可确定结果就不再继续。
- [1:13:37] 验证：`True or (1/0) or print(123)` 正常输出 True——既没抛 1/0 的异常也没执行 print（1/0 本会抛异常，print(123) 本会打印）；`False and (1/0) and print(123)` 同理返回 False。print 的返回值是 None（None 表示"空"，是 NoneType 类型）。中间还玩了 KFC"V我50"梗：今天是否星期四 or 你有没有钱 or 我有没有钱 or 我饿不饿 or 周围有没有 KFC or 是否 V 我 50——满足任意一个就输出 True。
- [1:15:55] 逻辑表达式：判断多个条件是否满足某种逻辑关系并返回布尔值，由比较运算符和布尔运算符组成，如 `has_ticket and age > 18`（命名有意义所以可读性好）。notebook 2.5.5 示例：变量为 已登录=True、是管理员=False、通过审核=False、余额=2000；购买权限 = 已登录 且 通过审核 且 余额 > 1000×2，或者 是管理员——结果 False；把审核状态改成 True 后翻转为 True。
- [1:17:29] 提醒：把 print 或 1/0 塞进布尔链只为演示短路，属于"没有定义的行为"，不建议大家这么做、不要学习这种写法。
- [1:18:19] 常见运算符优先级：类型转换 > 算术运算 > 比较运算符 > 布尔运算符（and/or/not）> 其他（细节可搜索）。
