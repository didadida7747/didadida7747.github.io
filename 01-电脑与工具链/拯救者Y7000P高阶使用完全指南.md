### 一、Windows 系统深度优化

#### 1.1 电源模式与拯救者野兽模式

**Windows 自带电源模式切换：**

1. 按 `Win + i` 打开「设置」
2. 左侧点击「系统」→ 右侧点击「电源和电池」
3. 找到「电源模式」下拉框，有三个选项：
   - **最佳能效**：插电也省电，适合图书馆写作业、看视频时用，风扇安静
   - **平衡**：系统自动调节，日常默认即可
   - **最佳性能**：CPU 不降频，适合跑仿真、编译、游戏时用

**拯救者野兽模式（更重要）：**

- 直接按键盘上的 `Fn + Q` 即可循环切换三种散热模式：
  - **安静模式**（图标像小猫/叶子）：风扇转速低，适合图书馆、深夜写作业，性能受限
  - **均衡模式**（图标像平衡/箭头）：日常默认，风扇和性能折中
  - **野兽模式**（图标像红色野兽/闪电）：CPU 满血释放，风扇全速，打游戏、跑大型软件时开
- 也可以打开任务栏右下角的 **Legion Zone** 软件，在首页点大图标切换。

> 小白建议：上课带电脑去图书馆按 `Fn+Q` 切安静模式，插电玩游戏切野兽模式。

#### 1.2 虚拟内存（页面文件）配置

你的电脑是 16GB 内存，打大型游戏或开很多网页时可能吃紧。虚拟内存是在硬盘上划一块空间当"备用内存"用。

**推荐配置步骤：**

1. 按 `Win + S`，搜索「高级系统设置」，点击「查看高级系统设置」
2. 在弹出的「系统属性」窗口，点击「高级」选项卡 → 「性能」区域的「设置」按钮
3. 再点「高级」选项卡 → 「虚拟内存」区域点「更改」
4. **取消勾选**顶部的「自动管理所有驱动器的分页文件大小」
5. 选中你的 C 盘（通常是 SSD），选「自定义大小」：
   - **初始大小 (MB)**：填 `16384`（即 16GB）
   - **最大值 (MB)**：填 `32768`（即 32GB）
6. 点「设置」按钮 → 点「确定」→ **重启电脑**生效

> 说明：16GB 物理内存配 16~32GB 页面文件是游戏本的稳妥方案。如果你的 C 盘空间紧张（剩余少于 50GB），可以把最大值降到 24576。**不要把页面文件关掉**，很多游戏和软件会报错。

#### 1.3 启动项管理

开机自启的软件越多，开机越慢、内存占用越高。

**操作步骤：**

1. 按 `Ctrl + Shift + Esc` 打开「任务管理器」
2. 点击左侧（或顶部）的「启动应用」标签页
3. 你会看到一列开机自启的程序，看「启动影响」这一列：
   - **高**：建议禁用
   - **中/低**：看你需不需要

**可以安全禁用的典型项目：**

| 程序名 | 能不能禁 | 说明 |
|---|---|---|
| 各种游戏平台（Steam、Epic、WeGame） | 建议禁 | 打游戏时手动打开即可 |
| 聊天软件（微信、QQ、钉钉） | 看需求 | 要收消息就留着 |
| 云盘（百度网盘、OneDrive） | 建议禁 | 用的时候再开 |
| 显卡控制面板（NVIDIA GeForce Experience） | 可禁 | 不影响打游戏 |
| 各种"助手""管家""更新程序" | 建议禁 | 没用还占资源 |
| 联想 Legion Zone | **不要禁** | 要靠它切野兽模式 |
| Windows 安全中心 | **不要禁** | 系统杀毒 |

**禁用方法**：右键点某一项 → 选「禁用」。随时可以再右键「启用」。

#### 1.4 服务优化（谨慎操作）

按 `Win + S` 搜索「服务」，打开「服务」应用（图标像两个齿轮）。**双击某一项**，把「启动类型」改成「禁用」或「手动」，然后点「停止」→「确定」。

> ⚠️ **警告**：以下服务只列了你大概率用不到的。改之前看清楚名字，**拿不准的就别动**。改坏了随时可以改回「自动」。

| 服务名称（显示名） | 服务名 | 建议 | 说明 |
|---|---|---|---|
| 连接用户体验和遥测 | DiagTrack | 禁用 | 收集你的使用数据发给微软，禁用不影响任何功能 |
| Windows 错误报告服务 | WerSvc | 禁用 | 程序崩溃后上报微软，普通用户用不到 |
| 传真 | Fax | 禁用 | 现在没人用传真了 |
| 电话 | TapSrv | 手动 | 用于拨号上网/电话应用，不用就改手动 |
| 远程桌面服务 | TermService | 手动 | 不用远程控制别人电脑就改手动 |
| 传递优化 | DoSvc | 手动 | 局域网内给其他电脑传 Windows 更新，你只有一台电脑就改手动 |
| Windows  Insider 服务 | wisvc | 禁用 | 没参加微软预览体验计划就禁用 |
| PrintNotify | PrintNotify | 手动 | 打印机通知，没打印机就改手动 |
| Xbox 实时管理 | XboxGipSvc | 手动 | 不用 Xbox 手柄/应用就改手动（用手柄打游戏就别禁） |

**绝对不要碰的服务**（碰了系统会出问题）：
- Windows Update（系统更新）
- Windows 安全中心服务 / Windows Defender 防火墙
- 网络连接相关服务（Network Connections 等）
-即插即用（Plug and Play）
- 加密服务（Cryptographic Services）

#### 1.5 游戏模式、硬件加速 GPU 计划、内存完整性

**开启游戏模式：**

1. `Win + i` → 「游戏」→「游戏模式」
2. 把开关拨到「开」
3. 作用：打游戏时 Windows 自动暂停后台更新、通知，把资源优先给游戏

**开启硬件加速 GPU 计划（HAGS）：**

1. `Win + i` → 「系统」→「屏幕」→「显示卡」（或「图形」）
2. 点击「更改默认图形设置」
3. 打开「硬件加速 GPU 计划」
4. **重启电脑**生效
5. 作用：让 GPU 自己管理显存，降低延迟，对 RTX 4060 有小幅提升

**内存完整性（核心隔离）——建议关闭以提升游戏性能：**

1. `Win + i` → 「隐私和安全性」→「Windows 安全中心」
2. 点「设备安全性」→「内核隔离详细信息」
3. 把「内存完整性」**关闭**
4. 重启生效

> 说明：内存完整性是安全功能，但会占用一部分性能（游戏帧率可能掉 5~10%）。你的电脑装了杀毒软件、不随便下奇怪软件的话，可以关掉换性能。如果经常下破解软件/浏览不明网站，就保持开启。

#### 1.6 Windows 更新、存储感知、临时文件清理

**Windows 更新管理：**

1. `Win + i` → 「Windows 更新」
2. 点「高级选项」→「主动检查更新」调成「可调](不要选最积极)
3. 打开「活跃小时」：设为你通常用电脑的时间段（比如 8:00~24:00），系统不会在这个时间段自动重启更新
4. **不要用第三方工具彻底关闭 Windows 更新**，安全补丁还是要打的

**开启存储感知（自动清理垃圾）：**

1. `Win + i` → 「系统」→「存储」
2. 打开「存储感知」开关
3. 点进去设置：
   - 运行存储感知：选「每周」
   - 删除我的应用未使用的临时文件：开
   - 回收站文件删除：设为「30 天后」
   - 下载文件夹：设为「30 天后」（**注意**：如果你下载文件夹里有重要文件，改成「从不」）

**手动清理临时文件：**

1. `Win + i` → 「系统」→「存储」→「临时文件」
2. 勾选：Windows 清理传递、临时文件、缩略图、回收站（确认不要了再勾）
3. 点「删除文件」

> 小白建议：每个月清理一次即可。C 盘剩余空间保持在 50GB 以上。

#### 1.7 显示设置（刷新率、HDR、缩放）

**你这块屏是高刷屏，一定要确认刷新率拉满：**

1. 桌面右键 → 「显示设置」
2. 拉到最下面点「高级显示器」
3. 「选择刷新率」→ 选最高的那档（Y7000P 通常是 144Hz / 165Hz / 240Hz，看具体批次）
4. 如果只选到 60Hz，检查是不是 Legion Zone 里把显示模式切到了混合模式，或者线插对了（笔记本屏不需要接线）

**缩放比例：**

1. 同一个「显示设置」页面
2. 「缩放」选 **125%** 或 **150%**（Y7000P 是 16 英寸 2.5K 屏，125% 最舒服，字不会太小也不会太大）
3. 不要选 100%，字太小费眼睛

**HDR：**

- 如果你的屏幕支持 HDR，在「显示设置」里可以打开「使用 HDR」
- 但**看视频、写作业时建议关掉**，因为 Windows 的 HDR 对 SDR 内容优化不好，日常用会发灰
- 只在玩支持 HDR 的游戏、看 HDR 片源时开

### 二、必装效率软件清单

> 以下所有链接均为官网，复制到浏览器地址栏打开即可。**不要从百度搜索结果里下载**，容易带捆绑软件。

#### 2.1 Everything —— 秒搜全电脑文件

- **下载官网**：\<https://www.voidtools.com/zh-cn/downloads/>
- **用途**：Windows 自带搜索慢得要命，Everything 能在 1 秒内搜遍你整个硬盘的所有文件名
- **核心功能**：
  - 安装后，在任意位置按 `Ctrl + 双击` 桌面空白，或打开 Everything 窗口直接输文件名
  - 支持拼音搜索：输入 `wjl` 能找到 `成绩单.pdf`
  - 支持模糊匹配：输 `zhang san` 能找到 `张三简历.docx`
- **小白入门建议**：
  1. 下载「Everything-1.4.x.x64-Setup.exe」（64 位安装版）
  2. 安装时勾选「加入右键菜单」和「随系统启动」
  3. 以后找文件不要再点进 C 盘 D 盘一层层翻，直接开 Everything 输关键词

#### 2.2 Microsoft PowerToys —— 微软官方效率工具箱

- **下载官网**：\<https://github.com/microsoft/PowerToys/releases>
- **用途**：微软出的免费开源增强工具集，把 Windows 变成 macOS 一样顺手
- **安装方法**：在 Releases 页面往下翻到「Assets」，下载 `PowerToysSetup-0.xx.x-x64.exe`，双击安装
- **必开模块**：

| 模块 | 作用 | 默认快捷键 |
|---|---|---|
| **FancyZones** | 窗口分屏：把屏幕用快捷键切成几块，软件窗口自动贴进去 | 拖窗口时按住 `Shift` |
| **PowerRename** | 批量重命名：选中一堆文件右键，一键改名 | 右键菜单 |
| **Keyboard Manager** | 改键：比如把无用的 `Caps Lock` 改成 `Ctrl` 或 `Esc` | 设置里配 |
| **Text Extractor** | 截图 OCR 取文字：图片上的文字直接抠出来复制 | `Win + Shift + T` |
| **Quick Accent** | 打特殊字符（á、é、€） | 长按字母键 |
| **File Locksmith** | 看哪个程序占用了文件 | 右键文件 |

- **小白入门建议**：先只开 FancyZones 和 Text Extractor，其他模块用熟了再开。FancyZones 里选「模板」→「Priority Grid」，写作业时左边放资料右边放 Word 特别爽。

#### 2.3 Snipaste —— 截图 + 贴图神器

- **下载官网**：\<https://www.snipaste.com/>
- **用途**：比 Windows 自带截图强 10 倍，能把截图钉在屏幕上当参考
- **核心快捷键**：
  - `F1`：截图（截完可以标注、画箭头、打码）
  - `F3`：贴图（把刚截的图钉在屏幕最前面，写作业时一边看题一边写答案特别方便）
  - `Ctrl + F1`：截图到剪贴板不弹窗
- **小白入门建议**：
  1. 下载 Windows 64 位便携版，解压到 `D:\Tools\Snipaste` 文件夹
  2. 把 Snipaste 发送快捷方式到桌面，设置开机自启
  3. 以后不需要按 `PrtSc` 然后画图里粘贴了，直接 `F1`
  4. 免费版个人使用完全够，不需要买 Pro

#### 2.4 Listary —— 文件搜索 + 程序启动器

- **下载官网**：\<https://www.listary.com/download>
- **用途**：在任意文件夹里直接打字搜索，还能快速启动软件
- **核心功能**：
  - 在任意打开的文件夹窗口，**直接敲键盘**就会弹出搜索框
  - **连按两次 `Ctrl`** 呼出启动器，输 `wechat` 就能打开微信，输 `dianlu` 就能找到电路课文件夹
  - 支持在「另存为」对话框里直接输路径跳转，不用一层层点
- **小白入门建议**：免费版够用。装好后什么都不用设置，默认连按两次 Ctrl 呼出。和 Everything 不冲突——Everything 搜文件名更猛，Listary 是在文件夹里快速跳转更顺手。

#### 2.5 7-Zip —— 免费无广告解压软件

- **下载官网**：\<https://www.7-zip.org/>
- **用途**：替代 Windows 自带的解压，支持所有压缩格式，无广告无捆绑
- **核心功能**：
  - 解压 `.zip` `.rar` `.7z` `.tar.gz` 等所有格式
  - 右键菜单直接「解压到当前文件夹」
  - 可以给压缩包设密码加密
- **小白入门建议**：
  1. 主页点「Download 7-Zip 26.xx (2026-xx-xx) for Windows x64」下载
  2. 安装时默认即可
  3. 以后下载的课件压缩包，右键 → 7-Zip → 解压到"xxx\"
  4. **不要再装好压、2345 压缩、WinRAR 破解版**，全是广告

#### 2.6 Obsidian —— 本地笔记软件（推荐）

- **下载官网**：\<https://obsidian.md/download>
- **用途**：用 Markdown 格式记笔记，文件全部存在你自己电脑上，不依赖网络，不会被封号
- **核心功能**：
  - 笔记之间可以互相链接（比如「模电笔记」链接到「三极管」概念页）
  - 左边文件树管理课程笔记
  - 支持插入图片、公式（LaTeX）、代码块
  - 完全离线可用，本校校园网再差也不影响
- **小白入门建议**：
  1. 下载 Windows 版安装
  2. 第一次打开选「新建仓库」，仓库位置选 `D:\Notes\大学笔记`
  3. 按课程建文件夹：`模拟电子技术/`、`数字信号处理/`、`C语言/`
  4. 文件名用 `2026-09-28 模电 第三章笔记` 这种格式
  5. 个人使用免费，不需要付费同步

> 如果你更喜欢在线同步、手机电脑同步，可以用 **Notion**：下载地址 \<https://www.notion.com/zh-cn/desktop/windows>，免费版够用，但国内访问偶尔慢。

#### 3.4 避免 C 盘爆满的方法

#### 6.2 独显直连（MUX Switch）是什么？怎么切？

**通俗解释**：

你的 Y7000P 有两块显卡：
- **核显**（CPU 自带的 Intel 显卡）：省电，性能弱
- **独显**（RTX 4060）：费电，性能强

- **混合模式（默认）**：日常上网用核显，打游戏自动切独显。屏幕画面要经过独显→核显→屏幕，多一道中转，损失 5~10% 性能，但省电
- **独显直连**：独显直接连屏幕，跳过核显中转，游戏帧率提升 10% 左右，但续航变短

**切换方法**：

1. 打开 Legion Zone
2. 找到「显示设置」或「显卡模式」
3. 选「独显模式」（就是独显直连）或「混合模式」
4. **需要重启电脑才能生效**（老款 DDG1.0）；新款支持热切换不用重启
5. 也可以在「联想电脑管家」→ 游戏模式 → 显卡模式里切

**什么时候用哪个**：
- 去图书馆写作业、看视频、带电池出门 → **混合模式**（省电）
- 插电玩 3A 大作、跑 GPU 仿真 → **独显直连**（性能）

---

#### 6.3 三种散热模式使用场景

| 模式 | 风扇噪音 | 性能释放 | 适用场景 |
|---|---|---|---|
| 安静模式 | 几乎无声 | CPU 约 35W | 图书馆、深夜写作业、看视频、打字 |
| 均衡模式 | 轻微风声 | CPU 约 60W | 日常上课、写 Word、上网课、编程 |
| 野兽模式 | 明显起飞声 | CPU 约 90W+ | 打游戏、跑大型仿真、渲染、编译 |

> 小白口诀：**上课安静，日常均衡，打游戏野兽**。按 `Fn+Q` 一键切。

### 〇、写在最前面：你的电脑能扛住多少

你的 Y7000P 在本科生里属于"游戏本级"配置，跑本科到研究生阶段的绝大多数 EDA/嵌入式/仿真软件都没问题，但有三个硬约束要心里有数：

| 资源 | 现状 | 注意事项 |
|---|---|---|
| CPU | i7（6~8 核） | Vivado/ADS 综合、HFSS 求解主要吃 CPU 多核 |
| 内存 | **16 GB** | 这是最大短板。Vivado 全装 + 开工程建议 32 GB；本科阶段只装 Artix-7 Kintex-7 器件包，不装 Versal/Zynq UltraScale，16 GB 能跑 |
| 显卡 | RTX 4060 8GB | 对 EDA 几乎无加成（EDA 基本不吃 GPU），8GB 显存只影响 AI 类工具，不影响本指南 |
| 硬盘 | 1TB SSD | **最大问题**。Vivado 全装 100GB+、ADS 80GB+、MATLAB 全家桶 60GB+，**必须规划分区，绝不能全塞 C 盘** |

**磁盘规划建议**（联想拯救者一般 C 盘是系统盘，先在"磁盘管理"里看一下 D 盘多大）：

- `C:\`（系统+常用小软件）：保留 80~120 GB 空闲
- `D:\EDA\`：Altium、KiCad、立创EDA、Multisim
- `D:\Embed\`：Keil、STM32CubeIDE、Arduino、IAR、串口工具
- `D:\FPGA\`：Vivado、Quartus、ModelSim
- `D:\Math\`：MATLAB、Octave
- `D:\RF\`（后期按需）：ADS、HFSS、Ansys 学生版
- 所有软件安装路径**一律不要中文、不要空格**，例如 `D:\EDA\Altium` 而不是 `D:\软件\Altium Designer`

### 五、信号处理与通信仿真

#### 5.1 MATLAB 在数字信号处理中的应用（大二核心）

信号与系统 + 数字信号处理两门课都靠 MATLAB：
- **FFT 频谱分析**：`fft()`、`fftshift()`、画双边/单边谱；
- **滤波器设计**：`fir1()`、`filterDesigner` 工具箱界面（直接拖窗函数出系数）、`butter()`；
- **采样/混叠**：`stem()` 画离散序列；
- **通信原理**：`comm.RectangularQAMModulator`、眼图 `eyediagram()`、误码率仿真。

**练手建议**：用 MATLAB 录一段自己的声音（`audiorecorder`），做 FFT 看频谱，再设计低通滤波器滤掉高频——这是 DSP 课设经典题。

#### 7.3 环境变量常见问题

- **ARM GCC / 工具链**：装 Keil/CubeIDE 时会自动配好 PATH，**不要手动改**；
- **Java**：Vivado 启动需要 Java runtime，安装 Vivado 时会自动装捆绑版，不要自己乱装 JDK 导致冲突；
- **串口工具找不到 COM 口**：设备管理器看端口号，没识别就是 ST-Link 驱动没装；
- **中文路径报错**：几乎所有 EDA 工具都怕中文路径，工程文件夹也放 `D:\Projects\STM32\LED\` 这种纯英文。

---

#### 7.4 多版本共存

- **Keil 多版本**：Keil v5 和 v4 可以共存，装在不同目录；但同一个 pack 只装一份；
- **Vivado 多版本**：可以同时装 2021.1 和 2024.1（不同目录），但**磁盘吃不消**，本科阶段一个版本就够；
- **MATLAB 多版本**：不同 R20XXx 可以共存，但占空间，建议只装一个最新学生可用版本。

### 一、VS Code 全面配置

VS Code 是微软出的免费代码编辑器，轻量、插件丰富，是目前学生写代码的首选。**不要**一开始就装 Visual Studio 那个几个 G 的巨无霸。

```json
  "telemetry.telemetryLevel": "off"
```

### 二、Git 与 GitHub 工作流

Git 是代码版本管理工具，相当于"代码的后悔药 + 云备份"。GitHub 是全球最大的代码托管网站。**大二开始所有课程作业、课设都应该用 Git 管起来**，这是求职时的硬通货。

#### 1. Git 安装

- 官网下载：\<https://git-scm.com/download/win> （打开后会自动开始下载 64 位安装包）
- 安装时一路默认即可，**唯一要确认的一步**：选择 "Git from the command line and also from 3rd-party software"（让 Git 加入系统命令行）。

装完后右键桌面 → "Git Bash Here"，输入 `git --version` 能看到版本号就成功了。

#### 2. 基础配置

打开 Git Bash 或 PowerShell，依次执行（换成你自己的信息）：

```bash
git config --global user.name "你的名字或英文名"
git config --global user.email "你的邮箱@example.com"
```

**生成 SSH 密钥并绑定 GitHub**（这样 push 代码不用每次输密码）：

```bash
ssh-keygen -t ed25519 -C "你的邮箱@example.com"
```

一路回车（默认路径、不设密码）。然后把公钥内容复制出来：

```bash
cat ~/.ssh/id_ed25519.pub
```

打开 GitHub → 右上角头像 → **Settings** → 左侧 **SSH and GPG keys** → **New SSH key**，标题随便填，把刚才复制的公钥粘贴进去保存。

验证：`ssh -T git@github.com`，第一次输入 `yes`，看到 `Hi xxx!` 就绑定成功。

#### 3. 核心命令速查表

```bash
# 新建仓库（在项目文件夹里）
git init

# 克隆远程仓库到本地
git clone git@github.com:用户名/仓库名.git

# 查看当前状态（改了哪些文件）
git status

# 把改动加入暂存区
git add 文件名          # 加单个文件
git add .              # 加全部改动

# 提交到本地仓库（-m 后面是说明）
```

### 四、WSL2 与 Linux

电子信息工程以后大概率要接触 Linux（实验室服务器、交叉编译、跑开源算法）。WSL2 是 Windows 里内嵌的真实 Linux 子系统，**比虚拟机轻量得多**，启动快、能直接访问 Windows 文件。

#### 1. 启用步骤

**管理员身份**打开 PowerShell（右键开始按钮 → 终端管理员 / Windows PowerShell 管理员），执行：

```powershell
wsl --install
```

这条命令会自动：
- 开启"虚拟机平台"和"适用于 Linux 的 Windows 子系统"两个 Windows 功能
- 安装默认的 Ubuntu 发行版

装完**重启电脑**。重启后会自动弹出 Ubuntu 窗口，让你设置用户名和密码（这个密码是 Linux 里的 sudo 密码，和 Windows 密码无关）。

> 如果 `wsl --install` 报错，先手动开启功能：
> ```powershell
> dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
> dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
> ```
> 然后重启再执行 `wsl --install -d Ubuntu`。

#### 2. 推荐发行版

**Ubuntu**（22.04 LTS 或 24.04 LTS）—— 资料最多、遇到问题 Google 一搜全是答案，新手无脑选它。

其他发行版可以在 Microsoft Store 搜 "Linux" 安装（Debian、Fedora 等），但你不需要。

#### 3. WSL2 与 Windows 文件互访

- **在 Windows 里看 Linux 文件**：资源管理器地址栏输入 `\\wsl$` → 进入 Ubuntu → home → 你的用户名。
- **在 Linux 里看 Windows 文件**：Windows 的 C 盘 D 盘挂载在 `/mnt/` 下，比如 `cd /mnt/e/ai资料` 就能访问 E 盘。
- **注意**：**代码项目不要放在 `/mnt/c/` 里开发**（从 Linux 访问 Windows 盘很慢）。把项目放在 Linux 自家目录（`~/`）下，速度最快。

#### 4. WSL2 vs 虚拟机 vs 双系统，怎么选

| 方案 | 适合场景 | 你的建议 |
|---|---|---|
| **WSL2** | 日常写代码、跑 Linux 命令、用 GPU 做深度学习 | **首选**。你 90% 的需求它都能搞定 |
| 虚拟机（VMware/VirtualBox） | 需要完整 Linux 桌面、测网络拓扑、嵌入式仿真环境 | 偶尔用，装一次放着 |
| 双系统 | 需要独占 GPU 做重负载训练、对延迟要求极高 | **不要装**。16GB 内存 + 学生党，切换系统成本太高 |

#### 5. Docker Desktop（可选）

Docker 把应用打包成"容器"，环境一键复现。以后做 Web 项目、跑别人开源代码时会用到。

- 下载：\<https://docs.docker.com/desktop/install/windows-install/> → 下载 Docker Desktop Installer
- 安装时勾选 **"Use the WSL 2 based engine"**（默认就是勾上的）。
- 装完启动，设置里确认 Resources → WSL Integration 里打开了你的 Ubuntu 发行版开关。
- 验证：PowerShell 执行 `docker run hello-world`，看到欢迎信息即成功。

> 提醒：Docker Desktop 对内存有占用，**不用的时候右键托盘图标 Quit 掉**，否则后台吃内存。你只有 16GB 内存，要省着用。

- **官网下载**：\<https://www.blackmagicdesign.com/products/davinciresolve/> （页面底部"Download"，选 **DaVinci Resolve** 免费版，不要选 Studio 付费版）
- **价格**：免费版功能已覆盖 95% 的个人使用场景；Studio 付费版一次性约 2000 元，解锁 4K 以上时间线、神经网络引擎全功能，学生暂不需要。
- **特色**：全球调色行业标准，色彩科学远超剪映和 Premiere；自带 Fairlight 音频调音台、Fusion 节点特效合成。

### 三、游戏性能优化

#### 1. 拯救者 Y7000P 自带开关（最优先做这一步）

Y7000P 有两个硬件级开关，用键盘上方的 **Fn + Q** 循环切换性能模式：

| 模式 | 风扇 | CPU/GPU 功耗 | 适用场景 |
|---|---|---|---|
| 安静模式（蓝灯） | 低噪 | ~30W | 图书馆写作业、看视频 |
| 均衡模式（白灯） | 适中 | ~60W | 日常上网、轻度游戏 |
| **野兽模式（红灯）** | 起飞 | 满血 ~140W+ | 玩 3A 大作、剪视频导出 |

**独显直连（MUX Switch）必开**：
1. 打开自带的 **联想电脑管家**（任务栏右下角救星图标，或开始菜单搜"联想电脑管家"）。
2. 进入"硬件设置"→"显示设置"→ 把 **混合模式** 切到 **独显直连模式**，重启生效。
3. 原理：默认混合模式下画面要先经过核显再输出，有一帧损耗；独显直连让 RTX 4060 直接输出到屏幕，游戏帧数通常高 10%～20%。代价是略费电，插电玩时再开即可。

#### 2. NVIDIA 控制面板优化

桌面右键 → "NVIDIA 控制面板" → 左侧"管理 3D 设置" → "程序设置"标签页，逐个游戏添加：

- **电源管理模式**：选"**首选最高性能**"（防止游戏中途降频）。
- **低延迟模式**：选"**超高**"（竞技网游如 CS2、Valorant 降低输入延迟）。
- **纹理过滤-质量**：选"高性能"（帧数优先）。
- **垂直同步**：游戏内关掉，控制面板也关（除非画面撕裂严重再开 G-SYNC）。

**DLSS / 帧生成（Frame Generation）**：
- RTX 4060 支持 **DLSS 3 帧生成**。游戏内画质设置里把 DLSS 模式切到"**质量**"档（1080p/2K 下画质损失极小，帧数提升 50%～100%）。
- 支持的游戏：《赛博朋克 2077》《黑神话：悟空》《原子之心》《星空》等新 3A；老游戏不支持。
- 设置位置：游戏内"图像/显示"菜单 → DLSS 超分辨率 → 质量档；"帧生成"开关单独打开。

#### 3. 常见游戏画质平衡建议（2K 165Hz 屏）

| 设置项 | 建议 | 原因 |
|---|---|---|
| 分辨率 | 原生 2560×1600 | 不要乱拉分辨率缩放 |
| 预设画质 | 高（不是极致） | "极高"和"高"肉眼几乎无差，帧数差 20% |
| 阴影质量 | 中/高 | 阴影最吃性能，收益最低 |
| 体积云/体积光 | 中 | 同上 |
| 抗锯齿 | TAA + DLSS 质量 | DLSS 自带抗锯齿 |
| 纹理质量 | 高 | 4060 有 8GB 显存，撑得住 |
| 视距 | 高 | 影响竞技性 |

#### 4. 游戏帧数监控工具

- **MSI Afterburner + RivaTuner Statistics Server（RTSS）**：
  - 下载：\<https://www.msi.com/Landing/afterburner/graphics-cards> （注意：MSI 官方警告只有 msi.com 和 Guru3D 是正版，其他都是钓鱼站）
  - 安装时勾选"RivaTuner"。装完后：
    1. 打开 Afterburner → 点齿轮"设置"→"监控"标签。
    2. 勾选"帧率""GPU 温度""GPU 使用率""CPU 温度""内存使用率"，每项都勾上"在 OSD 上显示显示速率"。
    3. 进游戏后屏幕左上角就有实时帧数/温度叠加层。
- **NVIDIA FrameView**（轻量替代）：
  - 下载：\<https://www.nvidia.cn/geforce/technologies/frameview/>
  - 由 NVIDIA 官方出，测帧数和功耗更准，体积小。

### 四、游戏串流与远程游玩

> **背景知识**：NVIDIA 曾在 GeForce Experience 里内置 GameStream 串流功能，但**官方已于 2023 年停更**。现在的开源方案是 **Sunshine（服务端，装在 Y7000P 上）+ Moonlight（客户端，装在平板/电视/另一台电脑上）**。
>
> 📎 本节是单机最小集；**串流进阶（码率表、虚拟手柄、外网串流）见 `../三设备联动指南/04-游戏与媒体/`**。

#### 1. Sunshine —— 服务端（装在 Y7000P 上）

- **项目地址（GitHub）**：\<https://github.com/LizardByte/Sunshine>
- **下载**：进 Releases 页，下载 `SunshineWindows.exe` 安装包，一路下一步。
- **首次启动**：
  1. 会弹出一个网页管理后台（`https://localhost:47990`），首次设置用户名和密码。
  2. 在"应用"标签里添加你想串流的游戏（比如 Steam 大图标路径）。
  3. 保持 Y7000P 插电、连路由器网线（或 5GHz WiFi）。

#### 2. Moonlight —— 客户端（装在平板/手机/电视上）

- **官网**：\<https://moonlight-stream.org/>
- **GitHub**：\<https://github.com/moonlight-stream>
- **下载**：
  - Windows / macOS / Linux：官网首页下客户端。
  - 安卓：应用商店搜"Moonlight Game Streaming"。
  - iPad / iPhone：App Store 搜 Moonlight。
  - 电视：Android TV 版直接装；Apple TV 也有客户端。
- **配对步骤**：
  1. 电脑和平板连**同一个路由器**（最好都走 5GHz WiFi 或网线）。
  2. 打开 Moonlight，会自动发现 Y7000P，点击它。
  3. 屏幕上出现一个 4 位 PIN 码，输入到 Sunshine 网页后台的"PIN"栏里确认配对。
  4. 之后在 Moonlight 里点游戏图标就能串流启动。
- **推荐参数**：分辨率 1080p、帧率 60FPS、码率 20～40 Mbps（WiFi 好就拉满）。延迟通常 10～30ms，玩单人游戏完全无感。

#### 3. Steam Link —— 更简单的备选

- **官网/下载**：\<https://store.steampowered.com/app/353380/Steam_Link/>
- 如果你只玩 Steam 游戏，Steam Link 开箱即用，不用装 Sunshine，直接在同一局域网下发现你的 Steam。
- 缺点：只串 Steam 库里的游戏，非 Steam 启动器（Epic、战网）需要在 Steam 里"添加非 Steam 游戏"才行；延迟比 Moonlight 略高。

### 二、远程访问

> 📎 本节是单机最小集；**iPad/手机与拯救者互连、RustDesk、Tailscale 组网、远程开机（WoL）等更全更准的方案见 [`../三设备联动指南/`](#/doc/d365)**（01-iPad×拯救者/03-远程桌面、05-进阶玩法/02-远程开机与远程桌面）。

#### 1. Windows 远程桌面（RDP，仅连同网段 Windows 专业版）

- **开启被控端**（被连接的电脑）：设置 → 系统 → 远程桌面 → 打开。注意：**Windows 家庭版没有 RDP 服务端**，只有专业版/企业版能被远程；你的 Y7000P 出厂是家庭中文版，所以这台只能当主控，不能被 RDP 连。
- **使用**：另一台 Win 专业版电脑按 `Win + R` → 输入 `mstsc` → 输入对方 IP。
- 局限：只能同局域网，且被控方必须是 Win 专业版。

#### 2. Tailscale —— 异地组网神器（强烈推荐）

- **官网**：\<https://tailscale.com/>
- **原理**：基于 WireGuard 协议的零配置虚拟局域网。装完登录同一个账号，你在宿舍、在教室、在回家的高铁上，所有设备就像在同一个 WiFi 下一样互访，不需要公网 IP，不需要配端口映射。
- **使用场景**：
  - 在宿舍用平板串流 Y7000P 上的游戏（Moonlight + Tailscale 可实现外网串流）。
  - 从笔记本连回实验室的服务器。
  - 手机和电脑互传大文件。
- **使用方法**：
  1. 电脑去官网下载 Windows 客户端安装。
  2. 用 Google / Microsoft / GitHub 账号登录。
  3. 手机也装 Tailscale App，登录同一账号。
  4. 两台设备会各拿到一个 `100.x.x.x` 的虚拟 IP，互 ping 即可。
- **价格**：个人免费版最多 100 台设备，学生完全够用。

#### 3. ToDesk / 向日葵 —— 国内远程桌面

| 对比项 | ToDesk | 向日葵（贝锐） |
|---|---|---|
| 官网 | \<https://www.todesk.cn/> | \<https://sunlogin.oray.com/> |
| 免费版限制 | 每月有免费时长，个人偶尔用够 | 免费版限速 30 帧，画质一般 |
| 优势 | 国内节点多、延迟低、界面简洁 | 生态全（开机棒、智能硬件多） |
| 适合 | 偶尔帮别人修电脑、自己临时远程 | 需要远程开机、企业运维 |
| 注意 | 仅从官网下载，百度搜出来的假冒站很多 | 官方域名必须以 `.oray.com` 结尾 |

**建议**：装一个 ToDesk 备用即可，比向日葵清爽。

#### 4. SSH 远程连接实验室服务器

大二进实验室后，师兄师姐大概率会给你一台 Linux 服务器的 IP 和账号。Windows 上操作：

1. 开始菜单搜"**PowerShell**"或装一个 Windows Terminal。
2. 直接输入：
   ```
   ssh 用户名@服务器IP
   ```
3. 首次连接输 `yes` 确认指纹，然后输密码（输入时屏幕不显示字符，正常现象）。
4. 传文件用 `scp` 命令，或装 WinSCP（\<https://winscp.net/>）图形化拖拽。

### 三、安全防护

#### 1. Windows Defender 够不够？

**够了。** 2026 年的 Windows Defender（现在叫 Microsoft Defender）在 AV-TEST、AV-Comparatives 等独立测评里常年排第一梯队，对学生党完全够用。

**不建议装的**：
- 360 安全卫士、腾讯电脑管家、金山毒霸——弹窗多、捆绑多、占资源，反而拖慢游戏本。
- 两个以上杀毒软件同时装——会互相打架。

**建议**：保持 Defender 默认开启，Windows 安全中心里把"实时保护""云提供的保护"都打开就行。

#### 2. 防火墙基本设置

- Windows 自带防火墙默认开启，不要关。
- 第一次运行某个软件（如游戏、OBS）弹"是否允许访问网络"时，**家庭/专用网络勾允许，公用网络不勾**。
- 不要用"防火墙一键关闭"类优化脚本。

#### 3. 浏览器安全习惯

- 认准地址栏 `https://` 和小锁图标。
- **绝对不要**从"下载站"（太平洋下载、ZOL、当下下载之类）下载破解软件、激活工具、"绿色版"PS——90% 捆绑木马、挖矿程序、浏览器劫持。
- 要下软件只去：**官网**、**Microsoft Store**、**Steam**、**Microsoft 官方站**。
- 浏览器装一个 **uBlock Origin** 扩展（Chrome/Edge 商店搜），去广告同时挡恶意脚本。

#### 4. Bitwarden —— 密码管理器

- **官网**：\<https://bitwarden.com/>
- **为什么你需要它**：
  - 校园网、微信、QQ、邮箱、B站、Steam、银行卡、各种选课系统……一个学生至少有 20+ 个账号。
  - 人类记不住 20 个不同强密码，结果就是所有网站用同一个密码——**一个网站泄露，全部账号被盗**。
  - Bitwarden 帮你给每个网站生成随机强密码，你只需要记一个"主密码"。
- **价格**：免费版无限设备、无限密码库，完全够用。
- **使用流程**：
  1. 官网注册账号，设置一个**超长主密码**（至少 16 位，这个一定要记牢，忘了谁也救不回来）。
  2. 浏览器装 Bitwarden 扩展。
  3. 以后注册新网站，扩展会自动生成密码并保存；登录时自动填充。
  4. 手机也装 App，指纹解锁。

#### 5. 两步验证（2FA）

开完密码管理器后，给最重要的账号再上一层保险：

- **必开 2FA 的账号**：邮箱（QQ/163/Outlook）、微信、支付宝、银行卡 App、Steam、Bitwarden 本身。
- **怎么开**：账号设置 → 安全 → 两步验证/身份验证器。
- **推荐用 Bitwarden 自带的 TOTP 功能**（它本身就能当身份验证器 App 用），不用再装 Google Authenticator。
- **一定要备份恢复码**：开 2FA 时会给你一串恢复码，手抄下来放钱包里，手机丢了能救命。

### 四、数据备份策略

#### 1. 3-2-1 备份原则

业界黄金法则，记住三句话：
- **3** 份数据副本（原文件 + 2 份备份）。
- **2** 种不同介质（比如电脑硬盘 + 移动硬盘 + 网盘）。
- **1** 份异地备份（不在宿舍，比如云端网盘或家里的硬盘）。

学生最容易丢的是：毕业论文、课程设计、代码仓库、照片。这些文件别只存在 C 盘。

#### 2. Windows 文件历史记录（免费自动备份）

- 设置 → 账户 → Windows 备份；或控制面板搜"文件历史记录"。
- 插一块 U 盘/移动硬盘，开启后它会自动定时备份"桌面、文档、图片、下载"这几个文件夹。
- 优点：全自动；缺点：只备份库文件夹，且硬盘得一直插着。

#### 3. 外接硬盘 / 移动 SSD（推荐主力备份）

- **推荐**：三星 T7 / 致态 木星 移动 SSD（1TB 约 400～500 元），USB-C 接口，速度 1000MB/s，比机械移动硬盘快 5 倍。
- 每周把"文档、课程、代码"文件夹手动拷一次过去。
- 机械移动硬盘（如西部数据 My Passport 2TB）更便宜，但怕摔、震，宿舍桌面不稳慎选。

#### 4. 网盘备份

| 网盘 | 免费空间 | 适合 |
|---|---|---|
| OneDrive | 5GB（Office 365 学生版可能送 1TB） | 本校学生若通过学校激活了微软 Office，先去 \<https://www.office.com/> 看看有没有送 1TB OneDrive |
| 百度网盘 | 2TB（需手机 App 领） | 存冷数据、分享大文件，下载限速烦人 |
| 阿里云盘 | 免费空间大、不限速 | 视频、照片备份首选 |

**原则**：网盘只做"异地副本"，不要把网盘当主存储（同步盘经常出现"一边删了另一边也同步删了"的惨案）。

#### 5. 重要文件加密

- **VeraCrypt**（开源免费）：\<https://www.veracrypt.fr/>
- 用途：给移动硬盘/U 盘建一个加密卷，丢了别人也读不出来。
- 场景：论文、证件扫描件、私密照片放进 VeraCrypt 加密盘，出门带着不慌。
- 用法：创建加密卷 → 设置密码 → 挂载成一个新盘符 → 把文件拖进去 → 退出卸载。

## 第三部分：硬件维护与升级

### 一、散热与温度管理

#### 1. HWiNFO64 —— 看温度最准的工具

- **官网下载**：\<https://www.hwinfo.com/download/> （选"Installer"或"Portable"都行）
- 打开后选"Sensors only"，你能看到：
  - CPU 每一个核心的温度、功耗、频率。
  - GPU 核心温度、热点温度、功耗、显存频率。
  - 主板温度、电池放电率、硬盘通电时间。
- **用法**：玩游戏时最小化挂后台，切出来瞄一眼温度即可。

#### 2. MSI Afterburner —— 显卡监控

- 下载地址见前面游戏帧数监控部分。
- 它的曲线编辑器可以调风扇转速曲线（比如让风扇 70°C 以上就猛转），**但不建议小白拉核心频率/显存频率超频**——笔记本散热余量有限，超频收益小、风险大。只用来监控温度和调风扇曲线即可。

#### 3. 正常温度范围（Y7000P 2024，i7-14650HX + RTX 4060）

| 状态 | CPU 温度 | GPU 温度 | 说明 |
|---|---|---|---|
|  idle（桌面浏览） | 40～55°C | 35～45°C | 正常 |
| 看视频 / 写代码 | 55～70°C | 45～55°C | 正常 |
| 满载游戏（野兽模式） | **85～95°C** | **75～85°C** | 正常，游戏本撞 95°C 墙是设计如此 |
| 待机超过 70°C / 游戏 CPU 撞 100°C 降频 | — | — | 该清灰换硅脂了 |

> 游戏本 CPU 满载 90°C 左右**不是问题**，Intel HX 系列的温度墙就是 100°C。别被网上"CPU 超过 80 度就要炸"的说法吓到。

#### 4. 散热底座 / 抽风式散热器有用吗？

- **散热底座**（吹风式，垫在电脑下面）：效果约 3～5°C，聊胜于无，主要作用是把笔记本垫高、进风更顺畅。50～100 元的即可，没必要买太贵。
- **抽风式散热器**（卡在出风口）：效果明显，能降 8～12°C，但噪音大、长期用可能对风扇轴承有影响，且 2024 款 Y7000P 是后方出风，抽风式安装不太方便。
- **真正有用的三件事**：① 野兽模式打游戏；② 保证进风口不被枕头/被子堵住（桌面硬平处使用）；③ 半年到一年清一次灰。这三条比任何散热器都管用。

### 二、清灰与保养

#### 1. 清灰周期

- 宿舍环境灰尘大，建议 **6～12 个月**清一次。
- 信号：风扇明显比新买时吵、同样的游戏帧数变低、CPU 满载温度长期 95～100°C 不降。

#### 2. 清灰步骤（概述，动手前先看 B 站对应型号视频）

> **Y7000P 2024 拆机注意**：后盖螺丝全部是 **Phillips #0 十字螺丝**（不是手机那种三角，也不是大号）。底壳一圈约 10 颗螺丝，其中靠近转轴的几颗螺丝是**防掉设计**——拧松后不会掉出来，但不要硬拔。撬开底壳用塑料撬片，不要用一字螺丝刀硬撬（会留痕）。

步骤：
1. **关机、拔电源、拔掉所有外设**。
2. 拧下底壳所有螺丝，按位置摆好（不同长度螺丝装错会顶穿主板！建议在纸上按位置摆）。
3. 用塑料撬片沿缝隙撬开底壳，揭开。
4. **第一件事：断开电池排线**（用塑料撬棒把电池排线插头从主板上拔起来），这一步不断电有短路风险。
5. 用软毛刷 + 吹气球（或低压吹风机冷风吹）清理风扇叶片、散热鳍片出风口的灰尘。
6. 若同时换硅脂：拧下散热模组螺丝（对角线顺序松），取下铜管，用无尘纸巾擦掉旧硅脂，CPU 和 GPU 芯片上挤绿豆大小新硅脂，装回铜管，对角线顺序拧紧。
7. 接回电池排线，盖回底壳，拧螺丝。

#### 3. 硅脂推荐

> ⚠️ **口径更正（以 [`联想拯救者电脑保养手册.md`](#/doc/d005) 为准）**：不要按年份强制换硅脂，12～18 个月检查一次即可；**小白不建议自行拆机换硅脂**，优先售后清灰。下述 DIY 方案仅适合有动手经验者参考。

- **信越 7921**（约 30 元/小管）：经典款，偏硬，需要用力压平，效果稳定。
- **利民 TFX**（约 50 元）：粘度低、好涂，导热系数 12.8 W/mK，新手友好。
- **相变片（如 PTM7950）**：B 站最近很火，撕膜贴上即可，不会干，但操作要冷藏后再撕膜。
- 别买杂牌"含银硅脂"，大多是坑。

#### 4. 自己清灰 vs 售后清灰

- **联想官方售后清灰**：保内通常收费 100～199 元（具体看服务站报价），优点是不动你保修、有问题能找。
- **自己清**：成本 0（硅脂 30～50 元），但有风险——撬断外壳卡扣、碰掉小元件、装回去多螺丝。
- **建议**：第一次清灰**先去售后**，站在旁边看一遍工程师怎么拆；第二次以后再自己动手。
- **保修问题**：联想官方明确说明——拯救者用户自行升级内存/SSD **不影响整机保修**（\<https://newsupport.lenovo.com.cn/>），且全国服务站可以免费帮你安装自购的内存和硬盘；但**自行拆机清灰过程中造成的损坏不在保修范围**。

### 三、硬件升级（这本子最大的优势）

Y7000P 2024 的内部设计对升级非常友好：**两个内存插槽、两个 M.2 SSD 插槽**，出厂只插了一根 16GB 内存和一块 1TB SSD，留给你大量升级空间。

#### 1. 内存升级（最优先做）

- **现状**：单根 16GB DDR5 5600MHz SO-DIMM（笔记本内存条，和台式机不通用）。
- **推荐方案**：**再加一根 16GB DDR5 5600MHz**，组成 32GB 双通道。
  - 优先买和原厂同频率（5600MHz），品牌不限（镁光、海力士、三星颗粒都行）。
  - **具体型号推荐**：
    - 金百达 16GB DDR5 5600 笔记本内存（约 180 元，国产长鑫颗粒，性价比高）
    - 光威（Gloway）天策 16GB DDR5 5600（约 180 元）
    - 三星 16GB DDR5 5600 SODIMM（约 250 元，最稳妥）
  - 别买 DDR5 4800 或 6400——4800 会降频亏性能，6400 在 14650HX 上也会被降到 5600 跑，浪费钱。
- **为什么是 32GB**：大二开始跑 Keil、STM32、MATLAB、多开虚拟机、再开 PR/达芬奇，16GB 会告急；32GB 能稳到毕业。
- **安装**：底壳拆开（见上文），内存插槽在屏蔽盖下面，拨开两侧金属卡扣，新内存斜插入、按下即可自动锁定。

#### 2. SSD 升级

- **现状**：1TB M.2 2280 NVMe PCIe 4.0 SSD 已占用主插槽；**第二个 M.2 2280 插槽空闲**（出厂已配好固定螺丝柱）。
- **推荐方案**：加一块 **2TB PCIe 4.0 NVMe SSD**，把游戏、视频素材、虚拟机镜像扔到第二块盘。
  - **具体型号推荐**：
    - **致态 TiPlus 7100 2TB**（约 850 元）：长江存储颗粒，国产首选，无缓设计但温控好，兼容笔记本。
    - **三星 990 EVO 2TB**（约 900 元）：老牌稳定，五年质保。
    - **西数 SN850X 2TB**（约 1000 元）：性能天花板，但笔记本上发热略大。
  - **别买**：SATA 协议 M.2（插上去不认）、QLC 颗粒杂牌盘（掉速严重）。
- **安装后**：
  1. 开机进系统，右键开始菜单 →"磁盘管理"。
  2. 会提示"初始化磁盘"，选 **GPT**。
  3. 右键未分配空间 →"新建简单卷"→ 一路下一步，给个盘符（比如 D:）。
  4. 不需要装系统，不需要迁移——新盘直接当仓库盘用即可。
  5. 旧系统盘不动，开机照常进 Windows。

#### 3. 关于保修

- 联想拯救者系列**允许用户自行升级内存和硬盘**，不影响保修（联想官方知识库明确说明）。
- 如果你不想自己动手，带着自购的内存/SSD 去任意联想服务站，工程师**免费帮你装**（不含数据迁移和系统安装）。
- 但要注意：自己拆机导致的外壳损坏、排线断裂不在保修范围；去服务站升级最省心。

### 四、外接显示器方案

#### 1. Y7000P 视频接口

- 机身左侧 **HDMI 2.1 全功能口**：支持外接 4K 120Hz 或 2K 165Hz 显示器，一线通。
- **USB-C 口**：Y7000P 2024 的 USB-C 支持 DP 1.4 Alt Mode 视频输出，但功率传输不如雷电。
- **推荐**：用 HDMI 2.1 线直连显示器，最简单。

#### 2. 推荐参数

- **分辨率**：2K（2560×1440）。
- **刷新率**：165Hz 或以上。
- **面板**：**IPS**（别买 VA 曲面屏当主力办公，别买 TN 屏颜色烂）。
- **尺寸**：27 寸是甜点（24 寸字太小，32 寸 2K 颗粒感略重）。
- **接口**：必须有 HDMI 2.0/2.1 或 DP 输入。

#### 3. 性价比型号推荐

- **Redmi 27 寸 2K 165Hz**（约 900 元）：学生党性价比之王，IPS 屏，色准够用。
- **KTC H27T22**（约 800 元）：同价位竞品，165Hz，支架一般。
- **AOC Q27G3S**（约 1100 元）：品牌售后好，旋转升降支架。
- **LG 27GS85Q**（约 2000 元）：预算充足的话，Nano IPS 色质越级。

#### 4. 双屏设置

- 插上显示器后：设置 → 系统 → 显示 →"多显示器设置"选"**扩展这些显示器**"。
- 效率用法：笔记本屏放聊天/微信/网课，外接大屏放 IDEA/VS Code/仿真软件；写代码时一边看文档一边写代码。
- 记得在外接显示器设置里把刷新率选到 165Hz（默认可能只给 60Hz）。

### 五、电池保养

#### 1. 电池养护模式（最重要）

Y7000P 长期插电当台式机用，**必须**开启充电阈值保护，否则电池常年 100% 满电状态，2 年就鼓包。

**设置方法**：
1. 打开 **联想电脑管家**。
2. 进"硬件设置"→"电源设置"。
3. 找到"**电池养护模式**"或"充电阈值"，开启。
4. 推荐设置：充电上限 **60%**（长期插电不带走时）或 **80%**（每周会带出门时）。
5. 开启后，插电时电池充到 60% 就不再充，由电源直接给主板供电，电池几乎不参与循环，寿命大大延长。

#### 2. 长期插电使用的正确方式

- 插电时一定要开野兽模式或均衡模式，让电池不参与供电。
- **不要**把电池用到自动关机再充——锂电池怕过放。
- 每个月至少做一次完整的充放电循环（用到 20% 再充满），防止电池电量计漂移。

#### 3. 查看电池健康度

- **方法一**：联想电脑管家 → 硬件信息 → 电池，会显示"电池损耗"百分比。
- **方法二**（命令行）：开始菜单搜 PowerShell，输入：
  ```powershell
  powercfg /batteryreport
  ```
  会生成一个 HTML 报告路径，用浏览器打开，看"设计容量"和"完全充电容量"的比值。新机器应在 95% 以上；用两年掉到 80% 以下就该考虑换电池了。

#### 4. 外出省电技巧

- Fn+Q 切到安静模式。
- 设置 → 系统 → 电源 → 屏幕 5 分钟关闭、睡眠 10 分钟。
- 关掉独显直连（切回混合模式），浏览网页用核显更省电。
- 音量、键盘背光调小。

## 第八章 分阶段成长路线

> 从"电脑小白"到"熟练用户"再到"高阶玩家"，按学期推进，每阶段有明确的能力目标和行动清单。

---

### 阶段总览

| 阶段 | 时间 | 能力定位 | 核心目标 |
|---|---|---|---|
| **第一阶段** | 大二上（9月~1月） | 熟练用户 | 系统优化到位、专业软件装好、日常效率提升 |
| **第二阶段** | 大二下（2月~6月） | 进阶用户 | 嵌入式/FPGA上手、Git工作流、参与竞赛 |
| **第三阶段** | 大三全年 | 高阶玩家 | 确定方向、项目实战、硬件升级、实习准备 |
| **第四阶段** | 大四全年 | 准职业人 | 毕设、求职、作品集、工作流固化 |

### 第一阶段：大二上学期 —— 打基础，建习惯

**能力定位**：从"会开机打字"到"熟练使用电脑完成学习任务"

#### 必做行动清单

**第1~2周：系统优化与效率软件**
- [ ] 按第一章完成系统优化（电源模式、虚拟内存、启动项、刷新率）
- [ ] 安装效率四件套：Everything、Snipaste、7-Zip、PowerToys
- [ ] D 盘建立文件夹结构，浏览器默认下载改到 D 盘
- [ ] 微信/QQ 文件存储路径从 C 盘改到 D 盘
- [ ] 记住核心快捷键：Win+E、Win+L、Ctrl+Shift+Esc、Fn+Q

**第3~4周：专业软件安装**
- [ ] 通过本校正版平台（校园网内网系统 MATLAB（只装需要的工具箱）
- [ ] 安装立创EDA（画第一块板子）
- [ ] 安装 Keil MDK + XCOM 串口工具（单片机课准备）
- [ ] 安装 LTspice（模电仿真）
- [ ] 注册 GitHub 账号，安装 Git，配置 SSH 密钥

**第5~8周：编程环境与学习习惯**
- [ ] 安装 VS Code + 必备扩展（中文包、C/C++、Python、GitLens）
- [ ] 安装 Miniconda，配置 pip 清华源
- [ ] 用 Git 管理第一个课程作业仓库
- [ ] 申请 GitHub Student Developer Pack（学生邮箱验证）
- [ ] 开始用 Obsidian 记课程笔记（按课程建文件夹）

**第9~16周：课程同步实践**
- [ ] 信号与系统作业用 MATLAB 完成（FFT、滤波器设计）
- [ ] 电路CAD课用立创EDA画一块小板子并打样
- [ ] 单片机课用 Keil 写第一个 STM32 程序（LED闪烁→串口输出）
- [ ] 每周清理一次下载临时文件夹
- [ ] 开启电池养护模式（充电上限60%）

#### 阶段结束时你应该能做到
- 开机10秒内进入工作状态，不需要等一堆自启软件
- 找文件用 Everything 秒搜，不再一层层翻文件夹
- 用 MATLAB 完成信号处理作业，用 Keil 烧录 STM32 程序
- 代码用 Git 管理，知道 commit/push/pull
- 电脑 C 盘剩余空间保持在 50GB 以上

### 第二阶段：大二下学期 —— 上强度，做项目

**能力定位**：从"会用软件"到"能用软件解决实际问题"

#### 必做行动清单

**硬件升级（开学第一周）**
- [ ] **加一根 16GB DDR5 5600 内存**，组成 32GB 双通道（约180元，最值得的升级）
- [ ] 如有预算，加装 2TB SSD（致态TiPlus7100，约850元）
- [ ] 去联想服务站免费安装（不影响保修）

**专业技能深化**
- [ ] 安装 Vivado（只装 Artix-7 器件包），跟着小梅哥学 FPGA
- [ ] 完成第一个 Verilog 项目（LED流水灯→UART→VGA显示）
- [ ] 安装 Multisim（若机房没有），模电实验课前仿真
- [ ] 学习 STM32 外设：定时器、ADC、DMA、I2C/SPI
- [ ] 用 MATLAB + Simulink 完成控制系统仿真

**竞赛与项目**
- [ ] 报名全国大学生电子设计竞赛（TI杯，奇数年）或校赛
- [ ] 组队完成一个电赛题目（电源题/仪器题/控制题）
- [ ] 电赛工具链跑通：LTspice仿真→立创EDA画PCB→嘉立创打样→Keil写代码→XCOM调试
- [ ] 安装 VOFA+ 串口波形工具，调试 PID

**开发能力提升**
- [ ] 用 VS Code + PlatformIO 开发 STM32（替代 Keil 的现代方案）
- [ ] 掌握 Git 分支工作流（branch/merge/rebase 基础）
- [ ] 学习 Python 数据处理（numpy、matplotlib），替代部分 MATLAB
- [ ] 安装 WSL2 + Ubuntu，熟悉 Linux 基本命令
- [ ] 用 OBS 录实验演示视频

#### 阶段结束时你应该能做到
- 独立完成从电路仿真→PCB设计→打样→焊接→编程调试的全流程
- 用 FPGA 实现简单数字逻辑电路
- 参与一次电赛并完成作品
- 32GB 内存下同时开 MATLAB + Keil + 浏览器 + 微信不卡
- 在 Linux 命令行下完成基本操作

### 第三阶段：大三全年 —— 定方向，攒实力

**能力定位**：从"什么都懂一点"到"有一技之长"

#### 方向选择（大三上学期确定）

电子信息工程就业方向较广，根据兴趣选择一个主攻方向：

| 方向 | 核心技能 | 对应工具 | 典型岗位 |
|---|---|---|---|
| **硬件/PCB** | 高速PCB设计、信号完整性、电源 | Altium/Cadence、ADS、SI9000 | 硬件工程师、PCB工程师 |
| **嵌入式** | STM32/RTOS、驱动开发、通信协议 | Keil/CubeIDE、FreeRTOS、Logic分析仪 | 嵌入式软件工程师 |
| **FPGA/IC** | Verilog、时序约束、SOC设计 | Vivado、ModelSim、Questa | FPGA工程师、IC验证 |
| **信号/算法** | DSP、通信算法、MATLAB/Python | MATLAB、PyTorch、GNU Radio | 算法工程师、DSP工程师 |
| **软件/全栈** | C++/Python、后端、前端 | VS Code、Docker、WSL2 | 软件开发工程师 |
| **射频/微波** | 射频电路、天线、电磁仿真 | ADS、HFSS、CST | 射频工程师 |

#### 大三上学期行动清单
- [ ] 确定主攻方向，针对性学习对应工具链
- [ ] 进实验室或跟着导师做项目（本校实验室资源丰富，主动找师兄师姐）
- [ ] 如果方向是硬件/嵌入式：学习 Altium Designer 画4层板
- [ ] 如果方向是 FPGA：学习 AXI 总线、Zynq SOC 开发
- [ ] 如果方向是算法：学习 PyTorch，跑通图像分类项目
- [ ] 安装 Docker Desktop，学会用容器复现实验环境
- [ ] 开始写技术博客（CSDN/知乎/GitHub Pages），记录学习过程

#### 大三下学期行动清单
- [ ] 完成一个有分量的个人项目（放到 GitHub，写好 README）
- [ ] 准备暑期实习简历（项目经历+技能清单+GitHub链接）
- [ ] 投递暑期实习（3~4月是黄金期）
- [ ] 如有外接显示器需求：购入 27寸 2K 165Hz IPS 显示器（约900元）
- [ ] 学习远程开发：用 Tailscale + VS Code Remote-SSH 连实验室服务器
- [ ] 对 AI 感兴趣：用 Ollama 跑本地大模型辅助编程，用 Copilot 提升效率

#### 阶段结束时你应该能做到
- 有一个明确的职业方向和对应的技能栈
- GitHub 上有至少一个完整的项目（有 README、有代码、有演示）
- 有一段实验室项目或实习经历
- 能独立搭建开发环境、调试复杂问题
- 简历上有东西可写

### 避坑指南（血泪教训）

1. **不要装 360/腾讯管家/金山毒霸**：拖慢系统、弹窗多、和 Defender 冲突
2. **不要从"下载站"下软件**：90% 捆绑木马，只去官网
3. **不要把所有软件装 C 盘**：1TB SSD 也扛不住 MATLAB+Vivado+ADS 全塞 C 盘
4. **不要用盗版破解软件**：法律风险 + 病毒风险 + 求职时公司只认正版流程
5. **不要同时开 Docker + 大模型 + IDE + 50个浏览器标签**：16GB 内存会爆
6. **不要在床上/被子上用电脑**：堵住进风口，温度飙升降频
7. **不要等 C 盘红了才清理**：每月检查一次存储，保持 50GB 以上空闲
8. **不要忘记备份毕设**：每年都有学生电脑坏了论文没了的悲剧
9. **不要盲目追新软件版本**：课程指定版本就用指定的，新版可能教程少
10. **不要陷入"工具收藏癖"**：装了100个软件不如把10个用精通

### 附录 C：新手第一周必做清单（10条）

按顺序做完，你的 Y7000P 就能舒服地用四年：

1. **确认刷新率拉满**：显示设置 → 高级显示器 → 选 165Hz
2. **装效率四件套**：Everything、Snipaste（F1截图）、7-Zip、PowerToys
3. **装浏览器扩展**：AdGuard（或uBlock Origin）+ Tampermonkey + 沉浸式翻译
4. **禁用不必要的开机启动项**：任务管理器 → 启动应用，Steam/网盘/各种管家全禁
5. **微信/QQ 文件路径改到 D 盘**：不然半年后 C 盘爆红
6. **D 盘建文件夹结构**：大学课件、作业、软件安装包、下载临时，浏览器默认下载改 D 盘
7. **设置虚拟内存**：初始 16384MB，最大 32768MB，放 C 盘 SSD
8. **打开游戏模式 + 硬件加速 GPU 计划**，内存完整性按需关闭
9. **记住 Fn+Q 切模式**：图书馆安静、宿舍均衡、打游戏野兽
10. **开启电池养护模式**：联想电脑管家 → 充电上限 60%（长期插电时）

### 附录 E：常用命令速查

#### PowerShell 常用命令

```powershell
# 系统信息
systeminfo              # 完整系统信息
nvidia-smi              # N卡状态/显存占用
powercfg /batteryreport # 电池健康报告
powercfg /h off         # 关闭休眠（省C盘空间）

# 网络
ipconfig                # 查看IP
ping www.baidu.com      # 测连通性
tracert www.baidu.com   # 路由追踪

# 包管理
winget install 软件ID   # 安装软件
winget upgrade --all    # 升级所有
```

#### Git 常用命令

```bash
git init                # 初始化仓库
git clone 地址          # 克隆远程仓库
git add .               # 添加所有改动
git commit -m "说明"    # 提交
git push                # 推送到远程
git pull                # 拉取最新
git branch              # 查看分支
git checkout -b 分支名  # 新建并切换分支
git log --oneline       # 查看提交历史
```

#### Ollama 常用命令

```bash
ollama run qwen2.5:7b   # 运行通义千问7B
ollama run llama3.1:8b  # 运行Llama 3.1 8B
ollama list             # 查看已安装模型
ollama rm 模型名         # 删除模型
```
