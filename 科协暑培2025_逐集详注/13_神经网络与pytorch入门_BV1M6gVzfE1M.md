## 知识整理

### 神经网络是什么

概念层级上，人工智能是"根目录"，下辖专家系统（if-else）与机器学习；机器学习分传统算法（决策树）与神经网络；后者含浅层网络与深度学习（CNN/RNN/Transformer/GAN）。发展史速览：1943 单神经元、1958 单层网络、1969 异或问题致寒冬、1986 Hinton 反向传播、算力瓶颈二次寒冬，GPU 与数据积累后复兴，2022 ChatGPT 出圈。微观结构上，生物神经元/突触/皮层层级对应网络节点/连接权重/逐层结构；神经元 = 输入 + 权重 + 偏置 + 激活函数。

抽象定义：神经网络是"数以万计待定参数、可求偏导的高维映射" f_θ: X→Y。映射的种类定义任务——图像分类（3×256×256→1000 维概率）、大模型 next token 预测、文生图 flow matching 拟合速度场（自高斯先验演化至图片分布）。训练时不变的是训练集、可变的是参数，故把 θ 写进括号（参数与输入的对偶视角）。

### 为什么必须有激活函数，以及为什么"深"就行

无激活函数时 WX+B 的任意复合仍是线性函数，网络永远只能拟合线性映射，所以单层网络写作 O=ReLU(WX+B)。表示能力有无上限？类比泰勒展开（要求高阶光滑）与傅里叶展开（要求周期性有界）——系数虽可由求导/积分解出，但这两种条件在现实中都难满足。通用逼近定理条件宽松得多：只要求有限定义域上的连续函数，单隐藏层+非线性激活（sigmoid/ReLU）即可任意精度逼近——回答了存在性问题，证明请自行检索。

### 训练：优化目标、梯度下降与反向传播

第二个基本问题是数以亿计的参数如何求解。先定优化目标：度量 D(x,y) 判断好坏——欧氏距离、曼哈顿距离及二者拼接；用采样训练集近似有限定义域，优化目标即训练集上平均误差最小（MSE 等）。山谷比喻：随机初始化落在山谷，沿最快下降方向走到极低点——是否全局最低"看步长和运气"，训练"玄学"由此得名。形式化：方向取负梯度，步长即学习率——大了快但易在最低点附近徘徊，小了慢且易困于地形，实际由调度器动态管理。

反向传播是四步循环：前向传播→损失计算→反向传播（链式法则逐层求梯度）→权重更新，反复执行直至收敛（课件示例取自王红军老师，δ 具体形式不必深究）。课后动手环节：playground.tensorflow.org 上可视化加减层、换激活函数、调 learning rate、正则化；初始 test loss 约 0.5 即瞎猜。

### PyTorch 核心机制：计算图与自动微分

PyTorch 由 Meta（原 FAIR，杨立昆团队）开发，张量计算类似 NumPy，动态计算图+GPU 加速；另有 TensorFlow/JAX 等，但 PyTorch 应用最广。计算图是有向无环图，节点为操作/变量：前向传播时动态按需构建，内存随模型与 batch size 增长；backward 后计算图从后往前逐步销毁，`retain_graph=True` 可保留以支持多次反向传播。demo 验证：矩阵乘示例中 x.grad=z、z.grad=x；无 retain_graph 时二次 backward 报错；`detach` 将中间结果从图中剥离，可配 graphviz 可视化。

### nn.Module 体系与训练配套 API

模型继承 `torch.nn.Module`，重写 `__init__`（静态结构）与 `forward`（动态数据流）（继承与构造函数属面向对象基础，已熟可略）；常用方法有 `parameters`/`named_parameters`/`to(device)`/`train`。三个易混概念：eval 不改参数属性但不建图、关闭 dropout 等训练特性；no_grad 仅禁梯度与建图；`requires_grad_(False)` 直接改属性。存取权重用 `state_dict` + `torch.save/load`，结构不一致时用 `strict=False`；`apply` 用于自定义权重初始化。

### 数据三件套

Dataset 管源文件，重写 `__init__`/`__len__`/`__getitem__`（即 Python 序列协议的应用）；DataLoader 封装 batch size、shuffle、多进程；transforms 做 resize、旋转增强、ToTensor、Normalize 到 -1~1。torchvision 内置 MNIST、CIFAR-10 可直接下载。手撕 MNIST 流程：预处理加载→定义模型→训练/测试函数→设备选择（单卡/CPU；多卡需并行库，不演示）→超参设置→训练；课后作业要求换不同超参观察效果。

### 泛化性：一个思考题与四条原则

思考题：任意宽深 MLP 能学 [-3,3] 上的 sin(x)（通用逼近定理保证），但学不了布满整个实数轴的 sin(x)——训练集必有穷，覆盖不了无限定义域，除非换 sin/cos 等周期激活函数。提升泛化性四条：①参数越少泛化越好，逼模型理解映射本质而非死记答案；②权重模长越小越好，loss 加 L2 正则项；③训练集丰富且贴近测试分布（数据增强）；④归纳偏差越少越好——CNN 假设局部性、RNN 假设时序递归，Transformer 无此假设、更一般，故主流皆选其 scale up；更优架构是留给大家的开放问题。
