# 大模型基础速读

这一份是给你用来快速建立大模型基础框架的。  
第一目标不是推公式，而是先把 `Transformer` 的主流程和每个模块的作用讲清楚。

## 你先要知道的总图

把 Transformer 先看成一句话：

输入的 token 先变成向量，再通过注意力机制让每个位置“看见”别的位置，接着通过前馈网络继续加工，最后得到新的表示或输出。

你现阶段先记住下面 6 个词：

- `token`
- `embedding`
- `self-attention`
- `Q/K/V`
- 残差连接
- `LayerNorm`

## 每个模块到底在干什么

### 1. token

一句话会先被切成一个个最小处理单元，这些单元就是 `token`。  
模型不是直接理解汉字或单词本身，而是先把 token 编号化，再变成向量。

### 2. embedding

`embedding` 的作用就是把离散编号变成稠密向量。  
你可以把它理解为：模型把“词编号”翻译成“可以计算关系的坐标表示”。

### 3. self-attention

`self-attention` 的核心作用是：  
让句子里的每个位置都能根据需要关注其他位置。

它解决的是“一个词不能只看自己，还要看上下文”的问题。  
所以它比只按顺序读的简单结构更适合处理长距离依赖。

### 4. Q / K / V

你现在不用背公式，只要先会这套直觉：

- `Q`：我现在想找什么信息
- `K`：我这里有什么信息可以被匹配
- `V`：真正要传递过去的内容

注意力大致就是：  
先拿 `Q` 和所有 `K` 比相似度，再用这个权重对 `V` 做加权汇总。

### 5. 残差连接

残差连接的作用是：  
让信息和梯度更容易传过去，减少深层网络训练困难。

你可以先把它理解成“保留原信息，再叠加新加工结果”。

### 6. LayerNorm

`LayerNorm` 的作用是让每层输入输出更稳定。  
直觉上，它是在帮助训练过程不那么容易发散或震荡。

## 你现在应该能讲出来的主流程

你要练到能用自己的话说出下面这段：

1. 文本先分成 token
2. token 变成 embedding
3. 每个位置通过 self-attention 和其他位置交换信息
4. 结果经过前馈网络继续处理
5. 通过多层堆叠，不断得到更有上下文信息的表示
6. 最后用于分类、生成下一个 token 或其他任务

## 现阶段不要陷进去的地方

先别在这些点上花太久：

- 复杂矩阵推导
- 多头注意力细节实现优化
- 位置编码的各种变体
- 训练大模型时的工程细节

你当前目标是“入门能讲清”，不是“研究级理解”。

## 看代码时重点盯哪里

你读 Transformer 代码时，只看这 4 个点：

1. 输入张量从哪里进入
2. embedding 在哪里做
3. attention 在哪里算
4. 输出是怎么产生的

只要先把这 4 个定位出来，你就已经比“只看概念不碰代码”前进很多了。

### 为什么看它们

Hugging Face 的入门课程在第一章就把课程目标摆得很清楚，包括如何理解 Transformer 架构，以及如何区分 encoder、decoder 和 encoder-decoder 这几类结构。  
来源：Hugging Face LLM Course 第一章入口页。  
链接：https://huggingface.co/learn/llm-course/chapter1/1

PyTorch 的 `torch.nn.Transformer` API 文档明确写了，这一层的定位更偏“基础理解的参考实现”，而且它建议读者去看新的 building blocks 教程或更高层生态库。  
来源：PyTorch `torch.nn.Transformer` API 文档。  
链接：https://docs.pytorch.org/docs/stable/generated/torch.nn.Transformer.html

PyTorch 新的 Transformer Building Blocks Tutorial 更适合后续从“模块”过渡到“实现视角”，但它不适合作为你的第一份 Transformer 入门材料。  
来源：PyTorch Tutorials。  
链接：https://docs.pytorch.org/tutorials/intermediate/transformer_building_blocks.html
