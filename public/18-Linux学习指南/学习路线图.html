三阶段学习时间轴

共 15 章，从认识终端到独立部署 Web 应用。点击任意章节卡片展开「本章你将学会」；用下面的筛选按钮按阶段查看。

1-4
阶段一 · 入门

和终端成为朋友5 章

01
认识 Linux 与发行版
发行版选型终端 / Shell / Bash命令格式man 求助
01-Linux是什么与发行版.md
本章你将学会：
  • Linux 是什么、和 Windows 的区别，Ubuntu / Debian / CentOS 等发行版怎么选；
  • 终端、Shell、Bash 三者的关系，一条命令由「命令 + 选项 + 参数」怎样构成；
  • 遇到陌生命令如何用 man 手册和 --help 自助求助，建立不依赖搜索的第一反应。
02
WSL2 安装配置
wsl --installUbuntu 初始化换源Windows TerminalVS Code Remote文件互访网络代理
02-WSL2安装配置指南.md
本章你将学会：
  • 用 wsl --install 一键装好 Ubuntu 24.04，完成账号与密码初始化；
  • 把 apt 源换成国内镜像、配置 Windows Terminal 与 VS Code Remote，打通 Win/Linux 文件互访；
  • 让 WSL 走 Windows 的网络代理，解决换源慢、GitHub 连不上等第一个拦路虎。
03
文件系统与目录结构
FHS 目录树绝对 / 相对路径Tab 补全inode挂载概念
03-文件系统与目录结构.md
本章你将学会：
  • 读懂 FHS 目录树：/etc、/var、/home、/usr 各放什么，不再在系统里「迷路」；
  • 区分绝对路径与相对路径，熟练用 Tab 补全敲命令；
  • 理解 inode 与挂载的概念，为后面学磁盘和权限打地基。
04
文件与目录操作
ls / cp / mv / rm / find通配符软硬链接tar 打包
04-文件与目录操作命令.md
本章你将学会：
  • 熟练使用 ls / cp / mv / rm / find 完成目录与文件的日常增删改查；
  • 用通配符批量操作文件，理解硬链接与软链接的区别；
  • 用 tar 做打包压缩与解包，为备份和部署准备基本功。
05
查看与编辑文件
cat / less / tail管道与重定向grepnanoVim 入门
05-查看与编辑文件.md
本章你将学会：
  • 用 cat / less / tail 高效查看日志和配置文件；
  • 掌握管道 | 与重定向 > >> <，并用 grep 做文本搜索——这是运维排错的核心动作；
  • 会用 nano 应急改配置，同时迈过 Vim 入门这道坎（保存 / 退出 / 移动）。
阶段验收：不看资料独立完成「建目录树 → 写文件 → 查找 → 打包 → 备份」全流程。

阶段二 · 进阶

独立管理系统6 章

06
用户与权限
用户组sudorwxchmod / chown/etc/passwd
06-用户与权限.md
本章你将学会：
  • 理解用户 / 用户组 / sudo 的安全模型，不再无脑 root 狂奔；
  • 读懂 rwx 权限位，用 chmod / chown 精确控制文件归属；
  • 认识 /etc/passwd、/etc/group 等关键配置文件，排权限报错有据可依。
07
进程与任务管理
ps / top / htopkill 信号jobs 前后台nohup
07-进程与任务管理.md
本章你将学会：
  • 用 ps / top / htop 看清系统里每个进程在吃多少 CPU 和内存；
  • 理解 kill 信号（9 / 15 的区别），优雅停掉一个失控程序；
  • 用 jobs、前后台切换和 nohup 让任务在关掉终端后继续跑。
08
软件包管理 apt
update / upgrade装删软件dpkgsnap编译安装
08-软件包管理.md
本章你将学会：
  • 分清 apt update 与 apt upgrade，规范地安装、升级、卸载软件；
  • 认识 dpkg、snap 与源码编译安装各自的适用场景；
  • 解决「依赖损坏 / 装不上 / 卸载不干净」这一类高频问题。
09
磁盘与挂载
lsblk / df / dumount / fstabswapWSL 磁盘压缩
09-磁盘与挂载.md
本章你将学会：
  • 用 lsblk / df / du 看清磁盘分区与空间占用，回答「磁盘满了是谁吃的」；
  • 理解 mount 与 /etc/fstab 开机自动挂载，了解 swap 的作用；
  • 掌握 WSL2 虚拟磁盘只增不减的压缩方法，回收 C 盘空间。
10
网络命令与 SSH
ip / ss / curlSSH 登录与密钥GitHub 免密rsyncufw
10-网络命令与SSH.md
本章你将学会：
  • 用 ip / ss / curl 诊断网络连通性、端口监听与 HTTP 请求；
  • 配置 SSH 密钥登录、给 GitHub 配置免密推送；
  • 用 rsync 做增量文件同步，用 ufw 管理防火墙规则。
11
Shell 脚本编程
变量 / 引号条件循环函数set 安全选项crontab3 个实战脚本
11-Shell脚本编程.md
本章你将学会：
  • 写变量、条件判断、循环和函数，理解引号的坑；
  • 用 set -euo pipefail 让脚本出错即停，养成安全脚本习惯；
  • 用 crontab 做定时任务，并完成备份、批量处理等 3 个实战脚本。
阶段验收：写出带判断 / 循环的定时脚本；完成 SSH 免密登录并能用 rsync 传文件。

systemdjournalctlNginx 反代Dockerdocker compose
13-服务与部署入门.md

  • 配置 Nginx 反向代理，把后端应用暴露到 80 / 443 端口；
  • 用 Docker 和 docker compose 一条命令把 Web 应用整体跑起来。
14
Vim 与提效工具
Vim 全套tmuxrg / fzf / bat
14-Vim与提效工具.md
本章你将学会：
  • 系统掌握 Vim 的移动、编辑、寄存器与插件配置，实现「不碰鼠标改文件」；
  • 用 tmux 分屏和会话保持，远程断线不丢工作；
  • 把 rg / fzf / bat 等现代命令行工具接入日常流，显著提速。
15
常见问题排查手册
排错方法论6 类故障速查WSL 专题50 条命令速查表
15-常见问题排查手册.md
本章你将学会：
  • 建立「先看报错 → 看日志 → 缩小范围」的通用排错方法论；
  • 磁盘满、权限拒绝、连不上、服务起不来等 6 类故障的速查路径；
  • 掌握 WSL 专属问题（关机 / 磁盘 / 代理）处理法，并背熟 50 条常用命令速查表。
阶段验收：docker compose up -d 一键起 Web 应用并用 Nginx 反向代理访问；能独立排查常见故障。
