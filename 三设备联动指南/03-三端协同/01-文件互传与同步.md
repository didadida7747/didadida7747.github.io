# 三端文件互传与持续同步

> 结论:**临时互传用 LocalSend(三端全免费开源,一个 App 全解决)**;持续同步用 Syncthing(电脑↔一加)+ iCloud for Windows(iPad 照片流进电脑);文档协作再加 OneDrive 或坚果云。

## 一、临时互传( point-to-point,传完即走)

### LocalSend ★首选
- 定位:开源版"局域网 AirDrop",Windows/iPadOS/Android/macOS/Linux 全覆盖,无广告、不联网、不经服务器。[GitHub ≈9.3 万★](https://github.com/localsend/localsend),2026-10 仍在活跃更新,App Store/各大安卓商店均可装。
- 原理:局域网 REST + HTTPS,设备间自动发现,直连传输。
- 上手要点:
  1. 三端装**同一大版本**;两端连同一 Wi-Fi;
  2. 安卓首次要允许"附近设备"权限;iPad 首次要允许本地网络权限;
  3. 电脑端第一次运行会请求防火墙放行(默认端口 53317),勾上"专用网络";
  4. 发送端选文件 → 点接收端头像即可;支持文本/剪贴板内容互发。
- 排错:发现不了设备 90% 是防火墙/AP 隔离(路由器里关掉"AP 隔离/访客网络隔离"),见 [06/常见问题与排错](/三设备联动指南/06-速查表/常见问题与排错)。

### PairDrop(网页版,零安装)
- [pairdrop.net](https://pairdrop.net)([开源分支](https://github.com/schlagmichdoch/PairDrop)):三端浏览器打开即用,传输走 P2P。原版 Snapdrop 2025 年起服务不稳,直接用 PairDrop。
- 适合:借别人电脑/公用电脑临时传,不想装任何东西。

### 其他
- LANDrop:另一开源轻量跨平台方案([GitHub](https://github.com/LANDrop/LANDrop));Feem 闭源带广告,无必要。
- 微信传输助手网页版 / QQ / 数据线 MTP:见 [02-2](/三设备联动指南/02-一加×拯救者/02-文件与实用玩法)。

## 二、持续同步(文件夹级,自动双向)

### Syncthing(电脑 ↔ 一加 主力)
- 开源 P2P 持续同步,无服务器无账号,局域网直连速度=网速,外网也能中继同步。
- 客户端现状(重要):
  - Windows:官方 [syncthing.net](https://syncthing.net) + 可选图形壳 SyncTrayzor;
  - Android:**官方 App 已于 2024-12 停更下架**,改用社区维护的 [Syncthing-Fork(Catfriend1)](https://github.com/Catfriend1/syncthing-android)(F-Droid 或 GitHub APK,免 Google 服务);
  - iPad:**官方无 iOS 端**。可选 [Synctrain](https://github.com/pixelspark/sushitrain)(免费开源,2024 起持续迭代)或 Möbius Sync(付费买断)。
- iOS 短板:iOS 后台限制,App 挂起时不同步,适合"文档库/相册定期对账"而非强实时。
- 典型用法:电脑建一个"手机相册"文件夹 ↔ 一加 DCIM 双向同步,照片自动回流电脑。

### iCloud for Windows(iPad 照片流进 Windows 的唯一官方路径)
- Microsoft Store 装 [iCloud](https://apps.microsoft.com/detail/9PKTQ5699M62),开启 iCloud 照片后,Windows「照片」App 里直接出现 iPad 照片。
- 社区反馈:轻度使用可用,首次大库同步偏慢;更新 iCloud 照片对国内网络较敏感。

### OneDrive / 坚果云(文档层)
- OneDrive:三端客户端齐全,与 Windows 11 深度集成,个人版性价比高;国内直连速度因运营商而异。
- 坚果云:国内最稳 WebDAV,三端客户端齐全;免费版**每月上传 1GB/下载 3GB**(空间不限),同步笔记/文献够用,照片备份会超限。[jianguoyun.com](https://www.jianguoyun.com)
- 国内大网盘(百度/阿里):三端 App 齐全但无官方同步语义,适合冷备份,不适合做"协同数据层"。

## 三、按场景的推荐组合

| 数据类型 | 推荐组合 |
|---|---|
| 手头临时传个文件/图/文本 | LocalSend(或 PairDrop 网页) |
| 一加照片自动备份到电脑 | Syncthing(Fork)双向文件夹 |
| iPad 照片自动进 Windows | iCloud for Windows |
| 三端都要编辑的文档库 | OneDrive 或坚果云;重度 Markdown 见 [03-3 笔记](/三设备联动指南/03-三端协同/03-笔记与密码) |
| 电脑大文件下好后给手机 | LocalSend;或 qBittorrent+Syncthing 自动化(见 [05-3](/三设备联动指南/05-进阶玩法/03-拯救者变家庭服务器)) |
| 冷备份/大容量归档 | 国内网盘 + 移动硬盘 |
