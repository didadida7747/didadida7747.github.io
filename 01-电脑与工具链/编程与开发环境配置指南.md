# 编程与开发环境配置指南

> **适用对象**：电子信息工程大二学生 · 拯救者 Y7000P（i7 + RTX 4060 8GB + 16GB 内存 + 1TB SSD）· 电脑基础薄弱
>
> **定位说明**：你是电子信息工程专业，编程是**辅助技能**（单片机/STM32 嵌入式、数据处理、写小工具），不是纯软件工程。因此本指南以"够用、稳定、不折腾"为原则，避免安装一大堆用不上的重型 IDE。AI 仅作为一个子板块，不做展开。

# 第一部分：编程与开发环境

## 一、VS Code 全面配置

VS Code 是微软出的免费代码编辑器，轻量、插件丰富，是目前学生写代码的首选。**不要**一开始就装 Visual Studio 那个几个 G 的巨无霸。

### 1. 下载安装

- 官网下载页：<https://code.visualstudio.com/download>
- 选择 **Windows → User Installer x64**（用户安装版，不需要管理员密码）。
- 安装时一路下一步即可，**建议勾选以下两个选项**：
  - ✅ 将"通过 Code 打开"操作添加到资源目录右键菜单
  - ✅ 将 Code 注册为受支持文件类型的编辑器

### 2. 必备扩展推荐

打开 VS Code，点左侧第四个图标（方块形状）进入扩展市场，搜索以下扩展并安装：

| 扩展名称 | 功能说明 |
|---|---|
| **Chinese (Simplified) (Language Pack)** | 中文语言包，把界面变成中文 |
| **C/C++**（Microsoft 官方） | C/C++ 语法高亮、调试、智能提示 |
| **C/C++ Extension Pack** | 上面那个的扩展包，附带 CMake 支持 |
| **Python**（Microsoft 官方） | Python 语法、调试、自动补全 |
| **Pylance** | Python 更强的类型检查与补全（装 Python 扩展时一般会自动带上） |
| **GitLens** | 在代码每行后面显示这行最后是谁、什么时候改的，看历史很方便 |
| **Remote - SSH** | 远程连接实验室服务器 / 开发板（如 STM32 跑 Linux 的板子）写代码 |
| **Live Server** | 写网页时右键一键起本地服务器，改动自动刷新浏览器 |
| **PlatformIO IDE** | **嵌入式开发核心扩展**，后面单独讲 |
| **Error Lens** | 把红色报错信息直接显示在代码行尾，不用把鼠标移上去才看得到 |
| **Prettier** | 自动格式化代码，保持排版整齐 |

### 3. settings.json 推荐配置

在 VS Code 里按 `Ctrl + Shift + P`，输入 `Open User Settings (JSON)` 回车，把下面内容粘贴进去（已有的键保留，缺的补上即可）：

```json
{
  // 编辑器字体（ Cascadia Mono 是 Win11 自带的编程字体；没有就用 Consolas）
  "editor.fontFamily": "Cascadia Mono, Consolas, 'Courier New', monospace",
  "editor.fontSize": 14,
  "editor.lineHeight": 1.6,

  // 主题：默认深色就够用，喜欢护眼可装 "One Dark Pro" 扩展后填下面这行
  "workbench.colorTheme": "Default Dark Modern",

  // 自动保存：离开窗口就保存，防止写半天忘保存
  "files.autoSave": "onFocusChange",

  // 显示行号、代码缩进参考线
  "editor.lineNumbers": "on",
  "editor.renderLineHighlight": "line",
  "editor.guides.indentation": true,

  // 粘贴 / 打字后自动格式化
  "editor.formatOnPaste": true,
  "editor.formatOnType": false,
  "editor.formatOnSave": true,

  // 默认终端改成 PowerShell（Win11 自带，比 cmd 好用）
  "terminal.integrated.defaultProfile.windows": "PowerShell",

  // 光标处高亮同类单词
  "editor. occurrencesHighlight": "off",
  "editor.selectionHighlight": false,

  // 关闭没必要的遥测
  "telemetry.telemetryLevel": "off"
}
```

### 5. 与嵌入式开发结合：PlatformIO

你是电子信息工程，迟早要碰 STM32 / Arduino。**PlatformIO** 是 VS Code 里最流行的嵌入式开发插件，一个扩展搞定编译、烧录、库管理，不用再装 Keil / CubeMX 那一堆。

1. 在扩展市场搜索 **PlatformIO IDE** 并安装，重启 VS Code。
2. 首次启动它会自动下载核心（约 200MB，慢的话挂代理或多等一会儿）。
3. 新建工程：点左下角小蚂蚁图标 → **New Project** → 选板子（如 `WeAct Studio STM32F411CE` 或 `Arduino Uno`）→ 选框架（STM32 选 `STM32Cube`，Arduino 选 `Arduino`）。
4. 烧录：板子用 USB 接电脑，点下方工具栏的 → 箭头（Upload）即可。

> 提示：PlatformIO 下载工具链在国外服务器，**首次下载慢是通病**。如果卡很久，可以在 PlatformIO 配置里把镜像换成国内源，或先挂手机热点下载一次，之后离线就能用。

## 二、Git 与 GitHub 工作流

Git 是代码版本管理工具，相当于"代码的后悔药 + 云备份"。GitHub 是全球最大的代码托管网站。**大二开始所有课程作业、课设都应该用 Git 管起来**，这是求职时的硬通货。

### 1. Git 安装

- 官网下载：<https://git-scm.com/download/win> （打开后会自动开始下载 64 位安装包）
- 安装时一路默认即可，**唯一要确认的一步**：选择 "Git from the command line and also from 3rd-party software"（让 Git 加入系统命令行）。

装完后右键桌面 → "Git Bash Here"，输入 `git --version` 能看到版本号就成功了。

### 2. 基础配置

打开 Git Bash 或 PowerShell，依次执行（换成你自己的信息）：

```bash
git config --global user.name "你的名字或英文名"
git config --global user.email "你的邮箱@example.com"
```

**生成 SSH 密钥并绑定 GitHub**（这样 push 代码不用每次输密码）：

```bash
ssh-keygen -t ed25519 -C "你的邮箱@example.com"
```

一路回车（默认路径、不设密码）。然后把公钥内容复制出来：

```bash
cat ~/.ssh/id_ed25519.pub
```

打开 GitHub → 右上角头像 → **Settings** → 左侧 **SSH and GPG keys** → **New SSH key**，标题随便填，把刚才复制的公钥粘贴进去保存。

验证：`ssh -T git@github.com`，第一次输入 `yes`，看到 `Hi xxx!` 就绑定成功。

### 3. 核心命令速查表

```bash
# 新建仓库（在项目文件夹里）
git init

# 克隆远程仓库到本地
git clone git@github.com:用户名/仓库名.git

# 查看当前状态（改了哪些文件）
git status

# 把改动加入暂存区
git add 文件名          # 加单个文件
git add .              # 加全部改动

# 提交到本地仓库（-m 后面是说明）
git commit -m "完成了LED闪烁实验"

# 推送到 GitHub
git push

# 拉取 GitHub 上的最新代码
git pull

# 查看分支
git branch             # 本地分支
git branch -a          # 所有分支

# 新建并切换到分支
git checkout -b 功能名

# 切换分支
git checkout 分支名

# 合并分支（先切回主分支再执行）
git merge 要合并进来的分支名

# 查看提交历史
git log --oneline
```

### 4. GitHub 使用

1. **创建仓库**：登录 GitHub → 右上角 `+` → New repository → 填名字 → 不要勾选初始化 README（本地已有代码的话）→ 创建。
2. **README.md**：仓库根目录放一个 `README.md`，写清楚这个项目是干嘛的、怎么跑起来。
3. **.gitignore**：仓库根目录放一个 `.gitignore` 文件，告诉 Git 哪些文件不要上传（编译产物、大文件、密钥等）。C/C++ / Python 项目常用模板：

```gitignore
# 编译产物
*.exe
*.o
*.obj
*.out
build/
.vs/
.vscode/ipch/

# Python
__pycache__/
*.pyc
.venv/
venv/

# 嵌入式
.pio/
*.elf
*.hex

# 系统垃圾
Thumbs.db
.DS_Store
```

> 偷懒法：GitHub 新建仓库时勾选 "Add a README" 和 "Add .gitignore"，Python / C++ 模板官方都给好了。

### 5. GUI 工具推荐

命令行熟之前，可以先用图形化工具降低门槛：

| 工具 | 特点 | 地址 |
|---|---|---|
| **GitHub Desktop** | 官方出品，最简单，适合入门 | <https://desktop.github.com/> |
| **SourceTree** | 功能全，界面直观 | <https://www.sourcetreeapp.com/> |
| **GitKraken** | 颜值高，学生免费 6 个月 | <https://www.gitkraken.com/> |

**建议**：先用 GitHub Desktop 点一点理解概念，再回头学命令行。

### 6. GitHub Student Developer Pack（学生开发包）

这是 GitHub 给在校大学生的福利包，**免费**拿到一堆付费工具（包括 Copilot 学生版、各种云服务额度等）。

- 申请地址：<https://education.github.com/pack>

- 用 GitHub 账号登录 → 点 "Get benefits" → 填学校信息、上传学生证明 → 等审核（通常几小时到几天）。
- 通过后即可免费开通 **GitHub Copilot Student**（见 AI 板块）。

## 三、编程语言环境

### 1. Python（推荐 Miniconda，不要装完整 Anaconda）

电子信息工程里 Python 用来做数据处理、绘图、MATLAB 替代（numpy + matplotlib）、AI 入门。**装 Miniconda 而不是 Anaconda**——后者自带几百个用不上的包，占 3GB+；Miniconda 只有几百 MB，要用啥装啥。

- 官方下载：<https://docs.conda.io/en/latest/miniconda.html> → 选 Windows 64-bit 安装包
- 国内下载更快的镜像：<https://mirrors.tuna.tsinghua.edu.cn/anaconda/miniconda/> → 选最新的 `Miniconda3-latest-Windows-x86_64.exe`

安装时**建议**：
- 安装路径不要有中文和空格（如 `D:\Miniconda3`）。
- 勾选 "Add Miniconda3 to my PATH environment variable"（虽然官方说不推荐，但小白勾上省事；不勾就从开始菜单用 "Anaconda Prompt"）。

**配置 pip 国内镜像（清华源）**，打开 PowerShell 执行：

```powershell
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

验证：`pip config list` 能看到上面那行就成了。以后 `pip install xxx` 走清华源，速度快十倍。

**装 Jupyter Notebook**（写笔记式代码，做实验数据处理很香）：

```bash
conda install jupyter
```

启动：在项目文件夹里 PowerShell 输入 `jupyter notebook`，会自动打开浏览器。

**Hello World 验证**：

```bash
python -c "print('Hello, World!')"
```

能看到输出即成功。

### 2. C / C++（两条路线，二选一）

C/C++ 是电子专业的吃饭家伙（STM32 开发底层就是 C）。两条路线：

**路线 A：MSVC（Visual Studio Build Tools）—— 推荐，和 Windows 兼容性最好**

- 下载页：<https://visualstudio.microsoft.com/zh-hans/downloads/> → 拉到下面 "所有下载" → **Visual Studio Build Tools 2022**
- 安装时勾选 **"使用 C++ 的桌面开发"** 这一个工作负载即可，其他不选。
- 装完后开始菜单会有 "x64 Native Tools Command Prompt"，从这里进命令行就能用 `cl` 编译器。

**路线 B：MinGW-w64（GCC 编译器，轻量，和 Linux 上一致）**

- 官网：<https://www.mingw-w64.org/downloads/>
- 最省事的方式：用 **MSYS2**（<https://www.msys2.org/>），装完后在 MSYS2 终端执行：
  ```bash
  pacman -S mingw-w64-ucrt-x86_64-gcc
  ```
- **环境变量配置**：把 `C:\msys64\ucrt64\bin` 加到系统 PATH：
  1. 右键"此电脑" → 属性 → 高级系统设置 → 环境变量
  2. 在"系统变量"里找到 `Path` → 编辑 → 新建 → 粘贴上面那个路径
  3. 一路确定，重开 PowerShell

**验证**：

```bash
gcc --version
g++ --version
```

写个 `hello.c`：

```c
#include <stdio.h>
int main() {
    printf("Hello, World!\n");
    return 0;
}
```

编译运行：

```bash
gcc hello.c -o hello
./hello
```

> 嵌入式实际开发用 PlatformIO（见第一节），它自带工具链，不用自己配。上面这套是为了应付专业课作业和本地算法练习。

### 3. Java（按需安装，电子专业一般用得少）

如果你选了 Java 选修课，或者要做安卓 / 后台小项目再装。

- 推荐 **Eclipse Temurin (Adoptium)** 免费 OpenJDK：<https://adoptium.net/temurin/releases/?version=21>
- 选 **JDK 21 LTS**（长期支持版）→ Windows x64 → 下载 `.msi` 安装包。
- 安装时勾选 "Add to PATH" 和 "Set JAVA_HOME variable"，安装程序会自动配好环境变量。

**环境变量（如果 MSI 没自动配，手动检查）**：

- 变量名：`JAVA_HOME`，变量值：`C:\Program Files\Eclipse Adoptium\jdk-21.x.x.x-hotspot\`（注意改成你实际安装路径，结尾不带 `bin`）
- `Path` 里加一条：`%JAVA_HOME%\bin`

**Maven**（Java 项目构建工具）：<https://maven.apache.org/download.cgi> → 下载 Binary zip → 解压后把 `bin` 目录加进 PATH。

**验证**：

```bash
java -version
javac -version
mvn -v
```

写 `Hello.java`：

```java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

编译运行：

```bash
javac Hello.java
java Hello
```

## 四、WSL2 与 Linux

电子信息工程以后大概率要接触 Linux（实验室服务器、交叉编译、跑开源算法）。WSL2 是 Windows 里内嵌的真实 Linux 子系统，**比虚拟机轻量得多**，启动快、能直接访问 Windows 文件。

### 1. 启用步骤

**管理员身份**打开 PowerShell（右键开始按钮 → 终端管理员 / Windows PowerShell 管理员），执行：

```powershell
wsl --install
```

这条命令会自动：
- 开启"虚拟机平台"和"适用于 Linux 的 Windows 子系统"两个 Windows 功能
- 安装默认的 Ubuntu 发行版

装完**重启电脑**。重启后会自动弹出 Ubuntu 窗口，让你设置用户名和密码（这个密码是 Linux 里的 sudo 密码，和 Windows 密码无关）。

> 如果 `wsl --install` 报错，先手动开启功能：
> ```powershell
> dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
> dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
> ```
> 然后重启再执行 `wsl --install -d Ubuntu`。

### 2. 推荐发行版

**Ubuntu**（22.04 LTS 或 24.04 LTS）—— 资料最多、遇到问题 Google 一搜全是答案，新手无脑选它。

其他发行版可以在 Microsoft Store 搜 "Linux" 安装（Debian、Fedora 等），但你不需要。

### 3. WSL2 与 Windows 文件互访

- **在 Windows 里看 Linux 文件**：资源管理器地址栏输入 `\\wsl$` → 进入 Ubuntu → home → 你的用户名。
- **在 Linux 里看 Windows 文件**：Windows 的 C 盘 D 盘挂载在 `/mnt/` 下，比如 `cd /mnt/e/ai资料` 就能访问 E 盘。
- **注意**：**代码项目不要放在 `/mnt/c/` 里开发**（从 Linux 访问 Windows 盘很慢）。把项目放在 Linux 自家目录（`~/`）下，速度最快。

### 4. WSL2 vs 虚拟机 vs 双系统，怎么选

| 方案 | 适合场景 | 你的建议 |
|---|---|---|
| **WSL2** | 日常写代码、跑 Linux 命令、用 GPU 做深度学习 | **首选**。你 90% 的需求它都能搞定 |
| 虚拟机（VMware/VirtualBox） | 需要完整 Linux 桌面、测网络拓扑、嵌入式仿真环境 | 偶尔用，装一次放着 |
| 双系统 | 需要独占 GPU 做重负载训练、对延迟要求极高 | **不要装**。16GB 内存 + 学生党，切换系统成本太高 |

### 5. Docker Desktop（可选）

Docker 把应用打包成"容器"，环境一键复现。以后做 Web 项目、跑别人开源代码时会用到。

- 下载：<https://docs.docker.com/desktop/install/windows-install/> → 下载 Docker Desktop Installer
- 安装时勾选 **"Use the WSL 2 based engine"**（默认就是勾上的）。
- 装完启动，设置里确认 Resources → WSL Integration 里打开了你的 Ubuntu 发行版开关。
- 验证：PowerShell 执行 `docker run hello-world`，看到欢迎信息即成功。

> 提醒：Docker Desktop 对内存有占用，**不用的时候右键托盘图标 Quit 掉**，否则后台吃内存。你只有 16GB 内存，要省着用。

## 五、命令行工具

### 1. Windows Terminal 安装

Win11 已经自带 Windows Terminal。如果没有：

- **微软商店**搜索 "Windows Terminal" 直接安装（推荐，自动更新）
- 或 GitHub 发布页：<https://github.com/microsoft/terminal/releases>

打开后点顶部下拉箭头 → 设置 → 默认配置文件选 **PowerShell**。这样新开标签页就是 PowerShell。

### 2. PowerShell 美化（oh-my-posh）

让命令行变好看、显示 Git 分支、显示 Python 虚拟环境。

```powershell
winget install JanDeDobbeleer.OhMyPosh --source winget
```

装完**重启 PowerShell**，然后编辑配置文件：

```powershell
notepad $PROFILE
```

在打开的文件里加一行（主题任选，`jandedobbeleer` 是经典款）：

```powershell
oh-my-posh init pwsh --config "$env:POSH_THEMES_PATH\jandedobbeleer.omp.json" | Invoke-Expression
```

保存后重开 PowerShell。如果出现图标乱码，去 <https://www.nerdfonts.com/font-downloads> 下载 **CaskaydiaCove Nerd Font** 装上，然后在 Windows Terminal 设置里把字体改成它。

**PSReadLine**（命令行自动补全、历史建议，一般 Win11 自带）：

```powershell
Install-Module PSReadLine -Force
```

### 4. winget 包管理器

Win11 自带的官方包管理器，装软件不用到处找下载页。

```powershell
winget search 软件名        # 搜索

```

常用一键安装命令：

> 你的定位是电子信息工程，AI 主要用来**辅助写代码 + 跑点小实验**，不用深入研究。本节控制在最小可用范围。

## 一、本地大模型（Ollama）

本地跑大模型 = 断网也能用的"离线 ChatGPT"，隐私好。

### 1. 安装

- 官网：<https://ollama.com/download> → 下载 Windows 版一键安装。

### 2. RTX 4060 8GB 显存推荐模型

**铁律：8GB 显存只跑 7B 及以下参数、4bit 量化的模型**，再大就爆显存卡死。Ollama 拉下来的默认就是量化版，直接用：

```bash
# 推荐 1：通义千问 7B（中文最好，日常问答、写注释首选）
ollama run qwen2.5:7b

# 推荐 2：Llama 3.1 8B（英文强，代码能力不错）
ollama run llama3.1:8b

# 推荐 3：更轻量的 3B 模型（显存吃紧或想跑得快时）
ollama run qwen2.5:3b
```

首次 `run` 会自动下载模型（几 GB），下载完就能直接对话。

常用命令：

```bash
ollama list            # 看本机已有哪些模型
ollama rm 模型名        # 删模型腾空间
```

### 3. Open WebUI（可视化聊天界面，可选）

Ollama 默认是命令行对话。想要类似 ChatGPT 的网页聊天界面（支持多轮对话、上传文档）：

```bash
# 前提：已装好 Docker Desktop 并启动
docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main
```

浏览器打开 <http://localhost:3000> 即可使用。

### 4. 显存注意事项

- 跑模型时另开 PowerShell 执行 `nvidia-smi`，看 `显存占用` 这一列，别超过 7000MiB。
- 同时别开游戏、别开大型软件，16GB 内存 + 8GB 显存比较紧张。

## 三、机器学习入门（简要）

### 1. PyTorch 安装

你的 RTX 4060 支持 CUDA 12.x。**不要自己单独装 CUDA Toolkit**，PyTorch 官方 wheel 已经把 CUDA 运行时打包进去了。

- 官方安装选择页：<https://pytorch.org/get-started/locally/>
- 选择：Stable → Windows → Pip → Python → CUDA 12.1（或更新的 cu12x），页面会给你一条命令，类似：

```bash
pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

验证 GPU 可用：

```bash
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0))"
```

最后两行分别输出 `True` 和 `NVIDIA GeForce RTX 4060 Laptop GPU` 就对了。

### 2. 学习资源

- **《动手学深度学习》（李沐）**：<https://zh.d2l.ai/> —— 中文最好的 DL 入门书，免费在线，带 PyTorch 代码，B 站有配套视频。
- 前期把书跑通即可，不用一上来就调大模型。

### 3. 8GB 显存能做什么

- ✅ 图像分类（MNIST、CIFAR-10 这种小数据集）
- ✅ 简单 NLP（文本分类、小语料训练）
- ✅ 小模型微调（如 LoRA 微调 7B 模型，batch size 调小）
- ❌ 不要尝试从头训练大模型、不要本地跑 Stable Diffusion 出大图（会很卡）

按这个顺序装，每步装完验证一下再进行下一步：
