# 03 · 账号与设备安全

> 目标：把"账号被盗"从一个未知恐惧，变成一套已建好的防御工事。核心就三件事：**一个站点一个密码 + 全部重要账号开 2FA + 备份码离线保存。**
> GitHub 项目 star 数为 2026-10-03 API 实查。

---

## 一、密码管理：用管理器，别用脑子

| 工具 | 链接 | 一句话定位 | 怎么用 | 核验状态 |
|---|---|---|---|---|
| Bitwarden 客户端 | [bitwarden/clients](https://github.com/bitwarden/clients) | 官方全平台密码管理器（免费版可跨设备同步） | 装浏览器插件 + 手机 App；主密码设长句（12位+），其他密码全部让管理器生成随机串 | 已核验 13,895★，更新至 2026-10 |
| Vaultwarden（进阶） | [dani-garcia/vaultwarden](https://github.com/dani-garcia/vaultwarden) | Rust 自托管 Bitwarden 服务端 | 以后有 NAS/服务器再考虑，学生阶段用官方云即可 | 已核验 68,450★ |

**落地节奏**（不用一次迁完）：
1. 第一周：把**丢了最疼**的 6 个账号迁进去——微信/支付宝、Apple ID、GitHub、邮箱（QQ/Outlook）、一加/OPPO 账号、学信网。
2. 之后每登录一个旧站顺手存一次，一个月内基本全覆盖。
3. **主密码 + 2FA + 备份码**三件套齐了才算迁移完成（见下）。

## 二、两步验证（2FA）：防"密码泄露"的最后一道闸

| 工具 | 链接 | 定位 | 核验状态 |
|---|---|---|---|
| ente Auth | [ente-io/ente](https://github.com/ente-io/ente) | 端到端加密 2FA 验证器，支持导出防丢 | 已核验 29,221★ |
| 2FAuth（进阶） | [Bubka/2FAuth](https://github.com/Bubka/2FAuth) | 自托管网页版验证码管理，配 Vaultwarden 用 | 已核验 4,171★ |
| 微信/支付宝内置保护 | App 内设置 | 支付前二次验证、设备锁，默认开 | 系统功能 |

**要点**：
- 优先级：**微信/支付宝、Apple ID、GitHub、邮箱** 必开；短信验证码也能当第二因素，但 SIM 卡可被补办劫持，验证器 App 更稳。
- **备份码（恢复码）离线保存**：开 2FA 时每家都会给一组一次性恢复码，打印或抄在纸上放抽屉——手机丢了它就是唯一救命稻草。
- GitHub 建议：Settings → Password and authentication → 启用 TOTP + 保存 recovery codes。

## 三、泄露查询与排查

| 工具 | 链接 | 用法 | 核验状态 |
|---|---|---|---|
| Have I Been Pwned | haveibeenpwned.com | 输入邮箱查是否出现在历史泄露库（收录 178 亿+ 记录）；命中 → 改该站密码 + 开 2FA；可订阅新泄露通知 | 已核验可访问（2026-10） |

## 四、设备防丢与远程控制

| 设备 | 开启位置 | 能做什么 |
|---|---|---|
| iPad / iPhone | 设置 → Apple ID → 查找（开"查找网络"+"发送最后位置"） | 定位、丢失模式锁机留言、远程抹除 |
| 一加/OPPO | 设置 → 安全 → 查找手机 | 定位、响铃、锁死、抹除；换卡通知 |
| 拯救者（Windows） | 设置 → 隐私和安全性 → 查找我的设备 + Microsoft 账号绑定 | 定位、锁定 |
| 路由器/宿舍网 | 不在公共设备上保存密码；离机必锁屏（Win+L） | 防物理接触窃取 |

**手机丢了的第一反应**：用家人/室友设备登录「查找」→ 挂失 SIM（打运营商客服）→ 冻结支付（微信/支付宝都有紧急冻结入口）→ 改主密码。

## 五、公共 WiFi 与网络边界

- **不连无密码 WiFi**；名称可疑的仿冒热点（"FreeWiFi-XX"）直接忽略（网络安全宣传周通行提示）。
- 连了公共 WiFi 就**不做转账/网银/输主密码**；有条件用手机流量替代。
- 关闭 WiFi 自动连接功能，避免自动挂上仿冒同名热点。
- 网吧/打印店电脑：只登录一次性的账号，用完改密码；绝不在上面登支付类账号。

## 六、钓鱼识别（邮件/短信/网页）

五个特征占两个就要警惕（广州医科大学/联想知识库等通行口径）：
1. **形近域名**：`qq-mail.co`、`1coud.com`、`rnicrosoft`（r 冒充 m）；
2. **笼统称呼**："亲爱的用户"而非你的名字/学号；
3. **制造紧迫**："账号异常将于24小时后冻结""不处理将影响征信"；
4. **索要敏感信息**：任何"点链接输账号密码/验证码"的邮件——**学校与官方永远不会邮件索要密码**；
5. **附件是 exe/scr/压缩包带密码**：直接删。

**标准动作**：不点邮件内链接 → 自己敲官方网址或用官方 App 核实 → 不确定就发辅导员/打 96110。
