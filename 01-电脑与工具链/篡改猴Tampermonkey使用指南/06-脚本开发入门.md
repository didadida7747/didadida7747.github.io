# 06 · 脚本开发入门（会 JavaScript 就能写）

> 对电子信息/计算机方向的同学，篡改猴是性价比极高的前端练手项目：改的是真实网站，DOM 操作、事件、CSS、异步请求全覆盖，写完立刻有正反馈。
> 前置知识：HTML / CSS / JavaScript 基础（DOM 操作即可）；不会 JS 也可以先从第 4 节的三个示例抄改。

## 一、脚本结构：两部分

```javascript
// ==UserScript==            ← 元数据块（必须）
// @name        脚本名称
// @namespace   命名空间（通常用你的网址/GitHub）
// @version     1.0.0
// @description 功能描述
// @author      你
// @match       https://example.com/*
// @grant       GM_addStyle
// @require     https://cdn.jsdelivr.net/npm/jquery@3.7.1/dist/jquery.min.js
// ==/UserScript==

(function () {               ← 程序体
  'use strict';
  // 你的代码
})();
```

- 元数据块是 `// ==UserScript==` 与 `// ==/UserScript==` 之间的注释；
- 程序体建议用 IIFE 包裹，避免污染页面全局变量。

## 二、常用元数据（够用版）

| 字段 | 作用 | 示例 |
|---|---|---|
| `@name` | 脚本名（支持 `@name:zh-CN` 多语言） | `// @name 知乎净化` |
| `@namespace` | 命名空间，与 @name 共同唯一标识脚本 | `// @namespace https://github.com/you` |
| `@version` | 版本号，更新时必须递增 | `// @version 1.0.2` |
| `@description` | 描述 | `// @description 去登录弹窗` |
| `@match` | 运行网址（语法严格，**推荐**），可多条 | `// @match *://*.zhihu.com/*` |
| `@include` | 运行网址（语法宽松，支持正则） | `// @include https://*` |
| `@exclude` | 排除网址 | `// @exclude https://mail.qq.com/*` |
| `@grant` | 申请的 API，可多条；不用 API 写 `none` | `// @grant GM_setValue` |
| `@require` | 运行前加载外部 JS（第三方库或本地文件） | `// @require https://cdn.jsdelivr.net/npm/dayjs@1/dayjs.min.js` |
| `@resource` | 预加载静态资源 | `// @resource icon https://x.com/a.png` |
| `@connect` | 允许跨域请求的域名 | `// @connect api.example.com` |
| `@run-at` | 注入时机 | `document-start` / `document-body` / `document-end`（默认）/ `document-idle` |
| `@noframes` | 不在 iframe 中运行 | `// @noframes` |
| `@downloadURL` / `@updateURL` | 自定义更新来源（如 GitHub Raw） | 见第 7 节 |

`@match` 模式速记：`协议://域名/路径`，`*` 通配，例如 `*://*.bilibili.com/*` 表示 http/https 下 bilibili 所有子域名的所有路径。

## 三、常用 GM API

| API | 作用 | 备注 |
|---|---|---|
| `GM_addStyle(css)` | 向页面注入 CSS（`!important` 好用） | 改样式首选 |
| `GM_setValue(k, v)` / `GM_getValue(k, def)` / `GM_deleteValue(k)` | 脚本专属持久化存储（跨标签页） | 存用户设置 |
| `GM_listValues()` | 列出所有 key | 配合管理 |
| `GM_setClipboard(text)` | 写入剪贴板 | 复制链接/文本 |
| `GM_xmlhttpRequest(details)` | 跨域 HTTP 请求（绕过同源策略） | **必须配 `@connect`**，首次会弹窗向用户授权 |
| `GM_download(details)` | 下载文件到本地 | 需授权 |
| `GM_addElement(parent, tag, attrs)` | 安全创建元素（避免 CSP 限制） | 加按钮/面板 |
| `GM_getResourceText(name)` / `GM_getResourceURL(name)` | 读取 @resource 资源 | |
| `GM_registerMenuCommand(name, fn)` | 在篡改猴弹出菜单里注册一项 | 做设置入口 |
| `GM_info` | 脚本与管理器信息 | 调试 |
| `unsafeWindow` | 访问页面真实 window（脚本默认运行在隔离的沙箱 window） | 调用页面自身函数时才用 |

> Tampermonkey 同时支持 Promise 风格的新命名：`GM.xmlHttpRequest`、`GM.setValue` 等。官方 API 手册：https://www.tampermonkey.net/documentation.php?locale=zh

## 四、三个可以直接抄的实战示例

### 示例 1：解除复制/右键限制（基础 DOM 事件 + CSS）

```javascript
// ==UserScript==
// @name         自用-解除复制限制
// @namespace    https://github.com/you
// @version      1.0.0
// @description  解除右键/选中/复制限制，放开 user-select
// @match        *://*/*
// @grant        GM_addStyle
// @run-at       document-start
// ==/UserScript==
(function () {
  'use strict';
  // 1. 阻止页面拦截这些事件（捕获阶段 stopPropagation）
  ['contextmenu', 'selectstart', 'copy', 'dragstart', 'mousedown'].forEach(function (ev) {
    window.addEventListener(ev, function (e) { e.stopPropagation(); }, true);
  });
  // 2. 清掉 body/document 上常见的内联拦截
  document.addEventListener('DOMContentLoaded', function () {
    document.body.oncontextmenu = null;
    document.body.onselectstart = null;
    document.body.oncopy = null;
  });
  // 3. 放开 CSS 层面的禁止选中
  GM_addStyle('* { -webkit-user-select: auto !important; user-select: auto !important; }');
})();
```

### 示例 2：Alt+Shift+M 复制当前页 Markdown 链接（做资料整理用）

```javascript
// ==UserScript==
// @name         自用-复制MD链接
// @namespace    https://github.com/you
// @version      1.0.0
// @description  Alt+Shift+M 复制 [页面标题](URL)
// @match        *://*/*
// @grant        GM_setClipboard
// ==/UserScript==
(function () {
  'use strict';
  document.addEventListener('keydown', function (e) {
    if (e.altKey && e.shiftKey && (e.key === 'M' || e.key === 'm')) {
      var md = '[' + document.title.trim() + '](' + location.href + ')';
      GM_setClipboard(md);
      var tip = document.createElement('div');
      tip.textContent = '已复制 Markdown 链接';
      tip.style.cssText =
        'position:fixed;top:20px;right:20px;z-index:999999;' +
        'background:#1aad19;color:#fff;padding:8px 14px;border-radius:6px;' +
        'font-size:14px;box-shadow:0 2px 8px rgba(0,0,0,.2)';
      document.body.appendChild(tip);
      setTimeout(function () { tip.remove(); }, 1500);
    }
  });
})();
```

### 示例 3：元素删除器（Ctrl+Shift+X 进入点选，点谁删谁，去广告/去弹窗）

```javascript
// ==UserScript==
// @name         自用-元素删除器
// @namespace    https://github.com/you
// @version      1.0.0
// @description  Ctrl+Shift+X 开关点选模式，点击元素将其移除；按 Esc 退出
// @match        *://*/*
// @grant        GM_addStyle
// ==/UserScript==
(function () {
  'use strict';
  var picking = false;
  GM_addStyle('.__rm-hover{outline:2px dashed #f00 !important;cursor:crosshair !important}');

  function toggle(on) {
    picking = on;
    document.body.style.cursor = on ? 'crosshair' : '';
  }
  document.addEventListener('keydown', function (e) {
    if (e.ctrlKey && e.shiftKey && (e.key === 'X' || e.key === 'x')) toggle(!picking);
    if (e.key === 'Escape') toggle(false);
  });
  document.addEventListener('mousemove', function (e) {
    if (!picking) return;
    var prev = document.querySelector('.__rm-hover');
    if (prev) prev.classList.remove('__rm-hover');
    e.target.classList.add('__rm-hover');
  }, true);
  document.addEventListener('click', function (e) {
    if (!picking) return;
    e.preventDefault();
    e.stopPropagation();
    e.target.remove();
  }, true);
})();
```

## 五、本地开发环境（VSCode 开发，强烈推荐）

篡改猴内置编辑器适合小改，正式开发建议本地写：

1. 浏览器扩展管理页 → Tampermonkey 详情 → 打开 **"允许访问文件网址"（Allow access to file URLs）**；
2. 本地建工程，如 `D:\code\userscripts\my-script\my-script.user.js`，用 VSCode 写代码；
3. 在篡改猴里"添加新脚本"，只保留一个引用壳：

```javascript
// ==UserScript==
// @name         自用-开发中
// @match        https://www.baidu.com/*
// @grant        none
// @require      file:///D:/code/userscripts/my-script/my-script.user.js
// ==/UserScript==
```

> 注意 Windows 路径在 `file:///` 后写 `D:/...`（正斜杠）。之后改代码保存、刷新网页即生效。
> Chrome/Edge 对 `@require file://` 的支持偶尔有差异，若不生效可改回直接粘贴，或用篡改猴官方 Editors 扩展在 vscode.dev 里编辑。

## 六、调试技巧

1. **F12 开发者工具**：脚本注入页面后，Console 里的 `console.log`、Sources 里的断点都能用；
2. Sources 面板可找到 Tampermonkey 注入的脚本（一般在 `tampermonkey` 虚拟目录下）；
3. 脚本没运行先查：开关是否启用、`@match` 是否命中（点猴子图标看当前页脚本列表）、`@run-at` 时机对不对（元素还没生成就操作会失败，用 `DOMContentLoaded`、`MutationObserver` 或轮询等待元素）；
4. 等动态元素出现的常用写法：

```javascript
function waitFor(selector, cb, times = 50) {
  var el = document.querySelector(selector);
  if (el) return cb(el);
  if (times-- > 0) setTimeout(() => waitFor(selector, cb, times), 200);
}
waitFor('#login-box', el => el.remove());
```

5. 要调用页面自己定义的函数/框架变量时，用 `unsafeWindow`；
6. 管理面板编辑器带 ESLint 语法检查，语法错误会直接标红。

## 七、发布与更新

### 发布到 Greasy Fork

1. 注册 Greasy Fork 账号；
2. 右上"发布你编写的脚本"；
3. 粘贴代码，填写名称、描述、许可证；
4. 遵守规则：代码公开可读、**禁止混淆/压缩**、不得动态加载远程代码、Antifeature（返利等）必须声明。

### 推荐工作流：GitHub 维护 + Greasy Fork 分发

1. 本地开发测试 → 推送到 GitHub 仓库；
2. 在脚本头部加上：

```javascript
// @version      1.0.0
// @downloadURL  https://raw.githubusercontent.com/你的用户名/仓库名/main/xxx.user.js
// @updateURL    https://raw.githubusercontent.com/你的用户名/仓库名/main/xxx.user.js
```

3. 每次修改递增 `@version`，篡改猴按更新 URL 自动检查；
4. 可在 Greasy Fork 发布页选择"从 GitHub 同步"，一次配置自动更新。

## 八、进阶学习路径

1. 先把示例 2、3 改成自己的快捷键和样式；
2. 挑一个你每天用的网站（教务系统、选课系统、某刷题站），找一个让你不爽的点，写 20 行代码解决它；
3. 读 2–3 个高评分开源脚本的源码（Bilibili Evolved 是很好的大型工程样本），学习 MutationObserver、跨域请求、设置面板的组织方式；
4. 系统看官方文档与 Violentmonkey 的开发指南：https://violentmonkey.github.io/guide/creating-a-userscript/
