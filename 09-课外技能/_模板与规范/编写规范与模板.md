# 编写规范与统一模板（所有分类文件必须遵循）

## 一、用户画像（写内容时始终对照）
- 本校（本校）大二男生（2025 级、2029 届），电子信息/计算机方向，理工科背景；常住西安、宿舍生活。
- 预算有限、时间碎片化：资源优先**免费/低成本**，优先 B站/抖音/小红书/GitHub/中国大学MOOC/知乎/YouTube 上可直接获取的内容。
- 用户点名重点：**钢琴、摄影**（这两项要最详尽，其余门类"入门路径 + 精选资源 + 避坑"即可）。
- 历史上关注过：钢琴、英语口语、中文演讲口才、吉他配件、烹饪、护肤穿搭。

## 二、资源真实性（最高优先级，禁止虚构）
- 所有 UP主/账号/课程/书籍/仓库/网站必须**真实存在、可检索**。
- 每个资源在写入前，必须用搜索工具核实：名称、平台、确实存在且与该技能相关。**拿不准的一律不写**，宁可少写不可编造。
- GitHub 资源给出"仓库所有者/仓库名"或可复现的搜索关键词（如 `github.com/xxx/yyy` 或 topic 搜索路径）。
- B站资源给出准确 UP 主名或课程名；小红书/抖音给出账号名或话题词。
- 可附链接，但链接必须是搜索核实过的真实 URL；不确定确切 URL 时，只写平台 + 准确名称 + 搜索关键词，不要编造 URL。
- 涉及"本校社团/琴房/西安机位/本地店铺"等本地信息：**能确证才写**，不能确证统一标注"（建议自行核实，以学校/现场最新信息为准）"，严禁编造具体社团名、场地、地址、价格。

## 三、每个技能文件的统一结构（标题层级固定）
1. `# 技能名` 开头
2. `## 一句话简介`：这是什么、能带来什么
3. `## 适合谁 & 投入成本`：用表格或短句说明【金钱成本 / 时间成本 / 设备门槛 / 宿舍友好度】
4. `## 分阶段学习路径`：零基础入门 → 进阶（重点技能可加到精通），每个阶段给"阶段目标 + 该做什么 + 大概周期"
5. `## 精选资源`：**必须用下方表格**，按平台或阶段分组
6. `## 装备 / 器材入门建议`：给预算档位（如 0 元党 / 200 元内 / 1000 元档 / 进阶档），宿舍场景重点说明
7. `## 常见误区 & 避坑`：条目列出
8. `## 在本校 / 西安怎么练`：社群、场地、采风/机位等；不能确证的标注"建议自行核实"
9. `## 快速开始（本周就能做）`：3 条以内可立即执行的动作

重点技能（钢琴、摄影）以上每节都要充实；非重点技能可合并精简，但"学习路径 / 精选资源表格 / 装备建议 / 避坑"四项不能缺。

## 四、资源清单表格统一格式
| 资源名称（UP主/课程/仓库） | 平台 | 适合阶段 | 推荐理由 |
|---|---|---|---|
| 示例：某某UP主《零基础钢琴入门》 | B站 | 零基础 | 理由（口碑/系统/免费等） |

- 平台列写：B站 / 抖音 / 小红书 / GitHub / 知乎 / YouTube / 中国大学MOOC / Coursera / 慕课网 / 播客 / 书籍 等。
- 适合阶段列写：零基础 / 入门 / 进阶 / 全阶段。
- 每个技能精选资源控制在 5–15 条，重质量不重数量；重点技能可更多。

## 五、文件与排版
- 每个技能一个 md，文件名用中文技能名（如 `钢琴.md`、`摄影.md`）。
- 表格优先；路径、价格、周期写具体；不写空话套话。
- 只写本文件负责的技能，不越界写其他门类（避免重复）。
- 语言：简体中文，条理清晰，可适当用 emoji 作小标题图标但不要泛滥。
- 文件末尾加一行：`> 资源整理时间：2026-10；平台内容可能更新，请以实际为准。`

## 六、完成后自检（写完务必逐条核对）
- [ ] 每个资源都经过搜索核实、真实存在，无编造名称/链接
- [ ] 九节结构齐全（非重点至少含四项必备节）
- [ ] 资源用了统一表格
- [ ] 装备给了预算档位、考虑宿舍场景
- [ ] 本地信息不能确证的已标注"建议自行核实"
- [ ] 文件保存在指定分类文件夹、文件名正确
