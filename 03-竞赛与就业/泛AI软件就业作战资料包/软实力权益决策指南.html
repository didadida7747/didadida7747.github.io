① 软实力：技术沟通与职场生存

1.1 技术沟通与汇报：如何讲清楚技术方案

汇报万能结构：结论先行 → 背景 → 方案 → 风险 → 请求

第一步（30秒）：直接说结论——"我建议用RAG方案而不是微调，理由是……"
第二步（1分钟）：交代背景——"现有客服系统准确率只有60%，主要原因是知识库更新滞后"
第三步（2分钟）：讲方案对比——列2-3个方案的优劣，给推荐项
第四步（30秒）：说风险——"RAG方案的风险是召回准确率，我计划用混合检索缓解"
第五步：明确请求——"需要您批准2周调研时间/需要数据团队配合"

技术汇报三忌

❌ 只讲技术不讲业务："我用了LangChain的RecursiveCharacterTextSplitter"——领导不关心
✅ 要翻译成业务语言："我把文档切成小块喂给模型，这样回答更精准，准确率从60%提到85%"

❌ 只讲方案不讲对比：直接说"我打算做X"——领导无法判断
✅ 至少给2个选项："方案A快但效果一般，方案B慢但效果好，我推荐B"

❌ 报喜不报忧：出了问题才说——领导最愤怒的是"为什么不早说"
✅ 风险前置：主动说"这个方案有个风险是……，我的预案是……"

elevator pitch（电梯演讲）模板

30秒版："我在做一个大模型客服助手项目，目标是把人工客服量降低30%。目前用RAG方案已经在测试集跑到85%准确率，预计下周上线灰度。需要您帮忙协调客服团队提供标注数据。"

1.2 文档写作：设计文档与周报

设计文档模板（Tech Design Doc）

1. 背景与目标：为什么要做这个？解决什么问题？
2. 现状分析：现在怎么做的？痛点在哪？
3. 方案设计：整体架构图 + 模块说明 + 接口定义
4. 技术选型对比：为什么选A不选B？（至少列2个候选）
5. 风险与备选：可能出什么问题？Plan B是什么？
6. 排期与里程碑：拆成2周一个迭代，每个迭代有可验收产出
7. 上线与回滚方案：怎么灰度？出问题怎么回滚？

周报模板（STAR法则）

本周完成（Situation-Task-Action-Result）：
• 完成了RAG召回模块开发（T：提升知识库召回率；A：实现了BM25+向量混合检索；R：召回率从70%→88%）
• 修复了3个线上bug

下周计划：
• 接入FAQ自动生成
• 配合测试团队做集成测试

风险/阻塞：
• 数据标注人手不足，可能延期2天

原则：量化结果，不写流水账；主动暴露风险，不等被问

1.3 跨团队协作

  • 对齐目标：开工前先和协作方确认"我们要一起达成什么目标？成功标准是什么？"——避免各干各的
  • 明确接口：和对方约定"我什么时候给你什么？你什么时候给我什么？格式是什么？"——写在文档里，不口头约定
  • 主动同步：每周至少一次进度同步，哪怕是"本周无变化，预计下周X交付"——沉默=失控
  • 冲突处理：对事不对人，先对齐目标再讨论方案；如果方案分歧，用数据说话（POC/benchmark），不靠职级压人
  • 留痕：重要决策和结论一定要发邮件/飞书确认，"刚我们讨论的结论是……，如有异议请X天内回复"

1.4 第一份工作快速融入：30/60/90天计划

第1-30天：观察与吸收期
• 搞清楚组织架构：谁是决策人？谁是执行关键人？谁和谁是矛盾方？
• 读完团队所有相关文档（代码仓库README、历史设计文档、周报）
• 找导师/直属leader做一次"1对1"：问清楚"您对我前3个月的期望是什么？"
• 主动认领小任务：修bug、写脚本、补文档——快速建立"靠谱"印象
• 不要急着表现：前30天少说多听，理解团队的做事方式和文化
第31-60天：产出与验证期
• 独立负责一个小模块/小项目，做出可量化的成果
• 开始在周会上主动汇报——练表达，建立存在感
• 识别团队的"痛点"：什么事情大家都嫌麻烦？你能不能优化它？
• 和跨团队协作方建立关系：请喝杯咖啡，了解他们的工作
• 主动找leader做30天回顾："我做得怎么样？哪里需要改进？"
第61-90天：定位与加速期
• 明确自己的"标签"：在团队里你最擅长什么？（模型调优？工程落地？文档？）
• 提出一个改进建议并推动落地——展示你不只是执行者，还能发现问题
• 试用期转正答辩准备：整理3个月的成果（量化数据），想清楚"我为什么值得留下"
• 开始规划下一阶段：转正后想做什么方向？需要补什么技能？

1.5 向上管理与预期管理

向上管理的核心：管理老板的信息输入

老板最怕的不是坏消息，是不知道。

• 每周主动同步：不管老板问不问，每周发一次进度（好消息+坏消息+下周计划）
• 坏消息早说："这个需求可能要延期2天，原因是……，我的应对是……"——越早说，老板越有缓冲
• 带着方案提问题：不要说"这个做不了"，要说"这个做不了，但是我有两个替代方案，推荐B"
• 理解老板的KPI：你的工作怎么帮老板完成他的目标？对齐这个，你的优先级就对了

预期管理：不要过度承诺

新人最容易犯的错：老板问"这个多久能做完？"——为了表现好说"3天"，结果做了5天。

正确做法：
• 估算时间×1.5-2倍，然后说"预计一周左右，中间我会同步进度"
• 提前做完 = 惊喜；延期 = 信任崩塌

接活时三问：
1. 这个事情的优先级是什么？（如果手头有别的活，哪个先？）
2. 什么时候要？（确认deadline）
3. 做到什么程度算完？（确认验收标准）

② 权益保障：劳动法护身符

2.1 三方协议与违约金

要点说明法律依据
三方协议性质民事协议（不是劳动合同），约束"毕业后去这家公司报到"。报到签订劳动合同后，三方自动失效《普通高等学校毕业生就业工作暂行规定》
违约金上限通常约定5000元-10000元，部分企业（尤其国企）可能更高。法律未明确规定上限，但过高可协商《民法典》合同编
什么情况不用付违约金①考上公务员/研究生并被录取（部分三方协议有此条款，需看清楚）②企业未按约定提供岗位/薪资 ③企业先违约三方协议条款约定 + 《民法典》
注意事项签之前看清楚：违约金多少？有没有"升学/考公免责"条款？薪资写的是税前还是税后？有没有附加服务期？—
法条来源：《普通高等学校毕业生就业工作暂行规定》（教学〔1997〕6号），教育部官网可查。三方协议属于民事协议，不适用《劳动合同法》，违约金纠纷适用《民法典》合同编。 来源：教育部 / 中国人大网

2.2 劳动合同与试用期规定

劳动合同期限试用期上限试用期工资下限
3个月以上不满1年≤1个月不得低于本单位相同岗位最低档工资80%，或不得低于劳动合同约定工资的80%，且不得低于当地最低工资标准
1年以上不满3年≤2个月
3年以上固定期限 / 无固定期限≤6个月
以完成一定工作任务为期限 / 不满3个月不得约定试用期
法条原文：《劳动合同法》第十九条：劳动合同期限三个月以上不满一年的，试用期不得超过一个月；劳动合同期限一年以上不满三年的，试用期不得超过二个月；三年以上固定期限和无固定期限的劳动合同，试用期不得超过六个月。
第二十条：劳动者在试用期的工资不得低于本单位相同岗位最低档工资或者劳动合同约定工资的百分之八十，并不得低于用人单位所在地的最低工资标准。 来源：《中华人民共和国劳动合同法》（2012年修正），中国人大网 npc.gov.cn
⚠ 试用期辞退的法定条件（企业不能随便开人）

《劳动合同法》第二十一条：在试用期中，除劳动者有本法第三十九条和第四十条第一项、第二项规定的情形外，用人单位不得解除劳动合同。用人单位在试用期解除劳动合同的，应当向劳动者说明理由。

第三十九条（过失性辞退，无需赔偿）：
• 在试用期间被证明不符合录用条件的（注意：企业必须有明确的录用条件，且能证明你不符合）
• 严重违反用人单位规章制度的
• 严重失职，营私舞弊，给用人单位造成重大损害的

第四十条第一项（医疗期满）：患病或非因工负伤，医疗期满后不能从事原工作也不能从事另行安排的工作
第四十条第二项（不能胜任）：不能胜任工作，经过培训或调整岗位仍不能胜任（需提前30天通知或额外付1个月工资）

2.3 竞业限制与保密协议

要点法律规定
适用人员仅限高级管理人员、高级技术人员和其他负有保密义务的人员——普通应届生签的竞业限制，很多情况下可能被认定无效
期限上限解除或终止劳动合同后，竞业限制期限不得超过2年
经济补偿竞业限制期间，企业必须按月给予经济补偿（通常为离职前12个月平均工资的30%-50%）。如果企业不给补偿，你可以不遵守竞业限制
违约金按合同约定，但如果金额过高（如年薪10倍），仲裁时可请求调低
保密协议 vs 竞业限制保密协议：不能泄露商业秘密（无论在职还是离职后，无期限限制但也无补偿）；竞业限制：不能去竞争对手公司（有期限+有补偿）
法条原文：《劳动合同法》第二十三条：用人单位与劳动者可以在劳动合同中约定保守用人单位的商业秘密和与知识产权相关的保密事项。对负有保密义务的劳动者，用人单位可以在劳动合同或者保密协议中与劳动者约定竞业限制条款，并约定在解除或者终止劳动合同后，在竞业限制期限内按月给予劳动者经济补偿。劳动者违反竞业限制约定的，应当按照约定向用人单位支付违约金。
第二十四条：竞业限制的人员限于用人单位的高级管理人员、高级技术人员和其他负有保密义务的人员。竞业限制期限不得超过二年。 来源：《中华人民共和国劳动合同法》第二十三条、第二十四条

2.4 背调流程与注意事项

  • 背调时机：通常在offer发放后、入职前。正规企业会先征得你同意才做背调
  • 背调内容：学历学位验证、工作经历核实（时间、职位、离职原因）、有无犯罪记录、部分会查社保缴纳记录
  • 注意：简历上的实习时间、职位、项目描述一定要真实——背调发现造假，offer可以直接撤销，已入职的可以无偿辞退
  • 联系人：背调联系人一般是你前直属leader或HR，提前和对方打好招呼
  • 隐私保护：如果你不想让现公司知道你在找工作，可以要求背调只联系已经离职的公司

2.5 应届生身份保留

关键概念："应届生"身份主要用于校招、落户、考公、国企招聘。不同场景定义不同：
场景应届生定义说明
企业校招通常指毕业当年（如2028届=2028年毕业）部分企业接受"择业期内"（毕业后2年内未交社保）也算应届
公务员/事业单位看招考公告，多数要求"应届毕业生"（当年），部分岗位限"择业期内未落实工作单位"关键：毕业后2年内未缴纳社保，档案在学校/人才市场，通常可按应届对待
落户（北京/上海）严格要求毕业当年（如2028年6月-12月）落户名额极度有限，错过当年基本没有第二次机会
政策来源：人社部《关于做好2024年高校毕业生就业创业工作的通知》及各地人社局规定。"择业期"政策各地不同，一般为毕业2年内，未落实工作单位、档案保留在学校或人才交流机构的毕业生，可按应届高校毕业生对待。具体以目标城市人社局/招考公告为准。 来源：人力资源和社会保障部 mohrss.gov.cn / 各地人社局官网

2.6 档案派遣

去向适用情况优缺点
转到单位（有人事管理权）国企、事业单位、公务员——单位有档案保管权✓ 工龄连续计算、评职称方便
✗ 离职时转档案比较麻烦
转到单位所在地人才市场民营企业——单位无档案管理权，委托人才市场托管✓ 灵活，离职时不用转档案
✓ 部分城市落户需要档案在当地人才市场
回原籍（户籍地教育局/人才中心）暂未就业、准备考研考公、自由职业✓ 最稳妥，不会丢
✓ 保留应届生身份方便
✗ 异地办事可能需要跑腿
实操建议：如果去民企，档案一般转到单位注册地的人才市场（问HR要"档案接收函"）；如果暂时没确定，先申请档案留校2年或回原籍，不要自己拿着档案（自持档案 = 死档，人才市场不收）。

2.7 加班与裁员：劳动法常识

加班时长限制

项目法律规定
每日加班上限一般每日不得超过1小时；特殊原因每日不得超过3小时
每月加班上限不得超过36小时
加班费标准工作日加班：1.5倍工资；休息日加班又不能补休：2倍工资；法定节假日加班：3倍工资
法条来源：《劳动法》第四十一条、第四十四条。劳动部《工资支付暂行规定》第十三条。 来源：《中华人民共和国劳动法》，中国人大网

经济补偿金计算（N / N+1 / 2N）

情形补偿标准适用条件
N（经济补偿金）每满1年支付1个月工资；6个月以上不满1年按1年算；不满6个月支付半个月工资合法解除（如裁员、协商解除、不能胜任工作调岗后仍不行）
N+1（代通知金）N + 1个月工资（替代提前30天通知）《劳动合同法》第40条：医疗期满、不能胜任、客观情况重大变化——企业没提前30天通知时
2N（赔偿金）经济补偿金的2倍违法解除劳动合同（企业没有合法理由就开人）
N = 工作年限 × 离职前12个月平均工资（税前，含奖金/补贴） 举例：工作2年7个月，被裁员（合法裁员） → N = 3个月工资（满6个月按1年算） → 如果没提前30天通知：N+1 = 4个月 → 如果是违法辞退：2N = 6个月 ⚠ 社平工资3倍封顶：如果月工资 > 当地上年度职工月平均工资3倍 按3倍封顶计算，且年限最高不超过12年
法条原文：《劳动合同法》第四十七条：经济补偿按劳动者在本单位工作的年限，每满一年支付一个月工资的标准向劳动者支付。六个月以上不满一年的，按一年计算；不满六个月的，向劳动者支付半个月工资的经济补偿。
第八十七条：用人单位违反本法规定解除或者终止劳动合同的，应当依照本法第四十七条规定的经济补偿标准的二倍向劳动者支付赔偿金。 来源：《中华人民共和国劳动合同法》第四十条、第四十一条、第四十七条、第八十七条

2.8 社保公积金基数与比例

项目单位缴纳个人缴纳说明
养老保险16%8%累计缴满15年，退休后领养老金
医疗保险8%-10%2%看病报销，个人账户每月返钱

住房公积金5%-12%5%-12%单位和个人同比例缴纳，全部进个人账户。比例越高越好
基数怎么定：社保基数 = 你上一年度月平均工资（新入职按首月全薪）。基数有上下限：当地社平工资的60%-300%。
避坑：有些公司按最低基数交社保（虽然违法但常见）——这意味着你的公积金少了、医保账户返钱少了、未来养老金也少了。谈offer时问清楚："五险一金按什么基数交？"

⚠ 租房避坑

• 押金：正规是"押一付三"（1个月押金+3个月房租）。遇到"押一付一"的公寓（自如/蛋壳类），注意看是不是长租贷——不要签贷款合同！
• 看房：一定要实地看！图片可能是照骗。检查：漏水、隔音、门锁、家电是否正常、电费是民电还是商电（商电贵一倍）
• 合同：和房东签（不是二房东），看房产证原件+身份证。退租时拍照留证，避免被扣押金

3.3 存钱计划：从实习工资到正式工资

实习期（日薪200-400元，月薪4000-8000）

实习工资目标：覆盖房租+基本生活，能存下钱是bonus

• 房租控制在收入的30%以内（如月薪6000，房租≤1800）
• 吃饭：食堂/自带饭，控制在1500-2000/月
• 交通+通讯：300-500
• 目标储蓄率：10%-20%（每月存500-1500）
• 重点：实习别太抠——花钱买技能（买书、买课、参加技术活动）是回报率最高的投资

正式入职（月薪15K-30K，税前）

税后到手约为税前的75%-80%（扣社保公积金+个税）

• 房租：控制在到手收入的25%-30%
• 吃饭+日常：2000-3000
• 社交+娱乐：1000-2000
• 目标储蓄率：30%-40%
• 应急基金：先存够3-6个月生活费（约3-5万），放在货币基金里，然后再考虑理财
• 公积金：这是你的强制储蓄——基数越高，公积金账户每月进账越多（买房/租房都能提）

10-10-10法则存钱版：工资到手后，先转10%到定期/货币基金（先存后花），再安排支出。不要"花剩了再存"——通常存不下来。

④ 决策框架：offer选择与Plan B

4.1 Offer加权打分模型

面对多个offer时，不要凭感觉，用加权打分量化决策。

总分 = 薪资 × W1 + 成长 × W2 + 城市 × W3 + 稳定 × W4 + 加班 × W5 W1+W2+W3+W4+W5 = 1（权重之和为1） 每个维度按1-10分打分，乘以权重后加总。 分数高的不一定是"最好的"，但是"最符合你当前优先级的"。
维度权重参考（应届版）打分标准（1-10分）
薪资W1 = 0.2010=年薪>40W；7=25-35W；5=18-25W；3=12-18W；1=<12W
成长（技术成长/带教/项目质量）W2 = 0.3010=顶级团队+大佬带+核心项目；7=正规团队+有学习空间；5=一般团队+边缘项目；3=打杂
城市W3 = 0.1510=心仪城市+行业聚集；7=可接受；5=一般；1=完全不想待
稳定（公司存活/业务前景）W4 = 0.1510=大厂/国企稳定；7=成长期公司；5=小厂；1=创业早期
加班（WLB）W5 = 0.2010=不加班；7=大小周；5=996但有补偿；1=无限加班无补偿
怎么用：把你的每个offer按这5个维度打分，算总分。
权重可以自己调：如果你现在最缺钱，把W1调到0.35；如果你最看重学东西，把W2调到0.40。
注意：这是辅助工具，不是算命——打分时尽量客观，多问问已经工作的学长姐。

4.2 信息不足时的决策框架

可逆 vs 不可逆决策

✓ 可逆决策（可以快速试错）

• 选哪个实习？
• 先去小公司还是大公司？（干1-2年可以跳）
• 住哪个区域？（换房成本低）
• 学什么框架？（随时可以换）

策略：快速决策，先上车再调整。不要花3个月纠结一个实习offer。

✗ 不可逆决策（慎重）

• 签三方/劳动合同（违约金/档案）
• 落户（北京上海户口只有一次机会）
• 放弃校招去gap（应届生身份）
• 和公司签竞业限制协议

策略：慢决策，多问人，查清楚再签。宁可推迟一周，不要签了后悔三年。

10-10-10法则

10周后
这个选择，10周后我会怎么看？
10个月后
10个月后，这个决定还重要吗？
10年后
10年后回头看，哪个选择让我不后悔？

当你纠结两个offer时，想想10年后——你更在意"多赚了5万"还是"学到了真东西"？大多数短期痛苦（加班、搬家）在10年后都不重要，而技能积累和履历背书会一直跟着你。

4.4 求职心态与概率思维

概率思维：面试是 numbers game

把面试当概率游戏，不是对个人能力的审判：

• 投100份简历 → 20份笔试 → 10个面试 → 3个二面 → 1个offer
• 被拒是常态，不是失败——你只是在提高基数
• 每次面试后复盘：哪题答得不好？下次怎么改进？
• 不要因为一次面试挂了就否定自己——可能只是岗位不匹配、可能是面试官今天心情不好

同辈压力应对

• 别人的offer ≠ 你的价值：有人去了大厂但996，有人去了小厂但技术成长快——人生是马拉松，不是百米冲刺
• 减少社交媒体比较：朋友圈/脉脉上全是"拿到字节SP"，沉默的大多数你看不到
• 和昨天的自己比：这周比上周多会了一个技能、多面了一家公司，就是进步
• 接受不确定性：第一份工作不会定义你的一生——工作3-5年后跳槽，第一份工作的权重会快速下降

最后一句话：求职是信息收集 + 概率优化 + 心态管理。你不需要"完美"，你只需要"比昨天好一点，比平均多投一点，比多数人坚持久一点"。
