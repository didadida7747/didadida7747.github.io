# 05 · 竞赛 / 奖学金 / 科研类脑力赚钱方法

> 适用对象：本校（本校）大二，电子信息 / 计算机方向，已掌握 STM32、PID、PCB、C/Python、计算机系统基础，正在学高数 / 线代。
> 本分类的特点：**单笔金额大、与保研 / 综测 / 简历强绑定，但启动周期长、不是"兼职日结"逻辑**。对本校这种电子信息强校来说，竞赛和奖学金是"投入一次、收益三年（钱 + 保研加分 + 实习敲门砖）"的高 ROI 路径。
> 说明：本校 2026 年最新通知若未公开，均引用最近一年官方文件，**每年微调，以当年教务处 / 学生工作处 / 创新创业学院通知为准**。

## 1. 全国大学生电子设计竞赛（电赛）

- **方法说明与典型玩法**：
  电赛由教育部高教司、工信部人教司主办，**两年一届，奇数年办国赛（2025 年刚办完，下一届 2027 年）**，比赛形式为 4 天 3 夜封闭制作（命题、焊接、写 MCU 代码、调试、写报告）。本校是电赛传统强校，建有"电子设计竞赛实训基地"，由校聘教练组（王新怀、王水平、何先灯等老师）系统化带训。
  典型路径：大二上（10 月前后）报名校选拔 → 校赛 / TI 杯模拟赛练手 → 寒假–暑假集训 → 大二暑假（奇数年 7 月底）省赛 → 推国奖。**大二正是冲省一、冲国奖的黄金年级**（大一练手、大三要准备保研 / 实习）。

- **所需技能与准备成本**：
  技能：STM32 / 51 单片机、模拟电路（运放、电源）、C 语言、PID、基本 PCB 绘制——**与你当前技能栈几乎完全重合**。
  成本：报名费学校承担为主；需自购部分元器件（约 200–500 元，多数基地可报销或借用仪器）；备赛期每周约 8–15 小时。

- **启动到首笔收入周期**：
  校赛每年 5 月（TI 杯模拟电子线路设计赛暨电赛校赛），省赛 / 国赛奇数年 7–9 月出结果，学校奖励一般在年底前发放。**首笔现金收入约 8–12 个月**；但综测加分和保研资格认定在获奖当学期即生效。

- **真实收入区间**：
  - 赛事本身：TI 杯 / 赛区最高奖有企业奖杯和少量奖金（非学生大额现金）；省赛 / 国赛主要发证书。
  - 学校配套：按《本校本科生竞赛成绩优胜者表彰奖励办法（修订）》，**参赛队国家级一等奖 2000 元/队、二等奖 1000 元/队、三等奖 500 元/队；省级一等奖 1000 元/队、二等奖 500 元/队**（队奖按队分，3 人平分）。
  - 交叉验证案例：2025 年本校获**国家一等奖 7 项、国家二等奖 14 项，共 21 项国家级奖，国奖总数首次突破 20、位列全国参赛高校第一，并捧得陕西赛区最高奖 TI 杯**；陕西赛区 108 支省奖（一等 28、二等 35、三等 45）。
  - 隐性收益：省一以上在本校综测、推免加分中权重极高，是电信 / 计算机类专业保研 Top 校的硬通货。

- **具体渠道 / 平台与入驻方式**：
  关注"本校创新创业学院"（校园网内网系统 10 月前后基地发布招新通知，直接去电工电子国家级实验教学示范中心 / 电赛实训基地报名，或找已参赛学长内推。

- **代表性参考对象**：
  - 中国大学生在线·本校校园号《本校学子在 2025 年全国电赛中斩获佳绩》：https://xyh.univs.cn/a/xyh_xyh_xadzkjdx/250910/2018875.shtml
  - 本校创新创业学院《大学生学科竞赛成绩优胜者表彰奖励办法》：https://校园网内网系统

- **风险与坑**：
  - ⚠️ **挂名参赛**：校队选拔实名制、现场 4 天 3 夜封闭制作，挂名几乎不可能，但仍有"队友划水"问题，组队时务必分工明确。
  - 备赛占用大量暑期时间，需平衡绩点；电赛国赛年份（奇数年）会与数学建模国赛（9 月）撞期，需取舍。

- **本校大二匹配度**：9.5/10。
  推荐理由：技能栈（STM32+PID+PCB+C）完全对口；本校电赛基地体系成熟、教练组稳定；大二是出成绩最后窗口期（大三要冲保研 / 实习）；2027 年下一届国赛正好在你大三前的暑假。

- **来源链接**：
  1. https://xyh.univs.cn/a/xyh_xyh_xadzkjdx/250910/2018875.shtml
  2. https://校园网内网系统

## 2. 中国国际大学生创新大赛（原"互联网+"）与"挑战杯"

- **方法说明与典型玩法**：
  - **中国国际大学生创新大赛（原"互联网+"大学生创新创业大赛）**：每年一届，高教主赛道分创意组 / 初创组 / 成长组，另有"青年红色筑梦之旅"、产业命题赛道。校赛 → 省赛 → 国赛，答辩制。
  - **"挑战杯"**：奇数年办"课外学术科技作品竞赛"（大挑，偏学术），偶数年办"创业计划竞赛"（小挑，偏商业）。
  典型玩法：把已有的电赛 / 大创 / 实验室项目包装成商业计划，3–5 人团队（技术 + 商科 + 文案），找一位指导老师冲校金 → 推省金 → 冲国金。**大二最适合做"技术核心成员"而非队长**（队长通常大三）。

- **所需技能与准备成本**：
  技能：一项能演示的原型作品（你做过的 STM32 项目即可）+ 写 PPT / 商业计划书 + 路演口才。
  成本：报名费学校出；差旅、样机、展板费学校配套；时间投入约 3–6 个月，每周 5–10 小时。

- **启动到首笔收入周期**：
  校赛每年 4–6 月，省赛 7–9 月，国赛 10–11 月。获奖后学校配套奖励一般年底发放，**首笔周期约 6–10 个月**。

- **真实收入区间**：
  - 陕西省政策：《陕西省人民政府办公厅关于印发进一步支持大学生创新创业若干措施的通知》明确"对'互联网+'大赛国家级金奖和银奖项目分别给予一定奖励"（具体金额省里不公开到个人，通过学校发放）。
  - 本校校奖口径：按旧版《大学生课外学术科技竞赛表彰奖励条例》，**挑战杯国家级参赛队特等 3000 元、一等 2000 元、二等 1000 元、三等 500 元**（该办法为 2014 年版，现行标准以创新创业学院最新修订为准，每年微调）。
  - 交叉验证：西工大 2025 年在该大赛拿 16 金并列全国第一，陕西是"互联网+"竞赛强省；本校近年在该赛事上同样有金 / 银入账。
  - 隐性收益：国金 / 国银在本校推免中是"硬通货"，部分学院可直接获得推免加分或校长奖提名资格。

- **具体渠道 / 平台与入驻方式**：
  本校创新创业学院（校园网内网系统 3–4 月发校赛通知；各学院团委也会组织动员。直接联系学院负责竞赛的辅导员 / 团委老师报名，或加入已有的校赛项目组。

- **代表性参考对象**：
  - 陕西省人民政府《关于印发进一步支持大学生创新创业若干措施的通知》：http://www.shaanxi.gov.cn/zfxxgk/fdzdgknr/zcwj/nszfbgtwj/szbh/202208/t20220808_2237300_wap.html
  - 本校机电工程学院《大学生课外学术科技竞赛表彰奖励条例》（校奖励办法学院转发版）：https://校园网内网系统

- **风险与坑**：
  - ⚠️ **"为赛而赛"**：纯 PPT 项目、没有真实原型，省赛以上很难过；本校评委更看重实物。
  - ⚠️ **挂名队员**：大赛要求全员贡献度，答辩时每个队员都会被问技术细节，挂名会露馅。
  - 商业计划书注水、夸大市场规模，遇到投资人类评委容易翻车。

- **本校大二匹配度**：7/10。
  推荐理由：适合作为电赛 / 大创项目的"二次变现"路径——把已有硬件项目包装参赛，边际成本低；但纯商科背景学生更容易当队长，大二电信学生更适合做技术 CTO 角色。

- **来源链接**：
  1. http://www.shaanxi.gov.cn/zfxxgk/fdzdgknr/zcwj/nszfbgtwj/szbh/202208/t20220808_2237300_wap.html
  2. https://校园网内网系统

## 3. 数学建模（国赛 CUMCM / 美赛 MCM-ICM / MathorCup）

- **方法说明与典型玩法**：
  3 人一队，72 小时（国赛 9 月，美赛 2 月）完成"建模 + 编程 + 论文"全流程。分工：一人建模（数理）、一人编程（MATLAB / Python）、一人写作（LaTeX）。
  - **国赛 CUMCM**：每年 9 月第二个周末，本校校内赛称"北太天元杯"。
  - **美赛 MCM/ICM**：每年 2 月，英文论文，奖金少但国际认可度高。
  - **MathorCup**：企业赞助赛，有现金奖。
  典型玩法：大二下暑假参加学校组织的暑期集训（创新实践周），9 月冲国赛。

- **所需技能与准备成本**：
  技能：高数 / 线代 / 概率统计（你正在学）、MATLAB 或 Python（你已会 Python）、LaTeX 排版。
  成本：国赛报名费学校承担；美赛报名费约 100 美元/队（学校通常报销获奖队）；备赛期约 1–2 个月，每周 6–10 小时。

- **启动到首笔收入周期**：
  校赛每年 5–6 月，国赛 9 月出省奖、11 月出国奖，美赛 2 月比赛、4 月出结果。**首笔现金约赛后 2–4 个月**。

- **真实收入区间**：
  - 学校校奖：按《本科生竞赛成绩优胜者表彰奖励办法》，**参赛队国家级一等 2000 元、二等 1000 元、三等 500 元；省级一等 1000 元、二等 500 元**。
  - 参考研究生口径（本科生可参照量级）：本校研数模奖励为国家级特等 1 万元/队、一等 0.6 万元/队、二等 0.3 万元/队、三等 0.15 万元/队（仅作量级参考，本科生按上面校奖办法执行）。
  - 企业命题赛（MathorCup、美赛 O 奖）偶有现金奖 1000–5000 元，但不是主力收入。
  - 交叉验证：2026 年本校"北太天元杯"校赛有 **956 支队伍报名**，选拔出国赛集训队 393 支，规模创历史新高。

- **具体渠道 / 平台与入驻方式**：
  关注本校本科生院（校园网内网系统 6 月发布的"全国大学生数学建模竞赛校内预报名"通知；3 人自由组队，也可通过学院建模群补人。

- **代表性参考对象**：
  - 本校本科生院《关于启动 2026 年全国大学生数学建模竞赛校内预报名工作的通知》：https://校园网内网系统
  - 本校数学与统计学院《"北太天元杯"数学建模校内赛颁奖仪式》：https://校园网内网系统

- **风险与坑**：
  - ⚠️ **论文抄袭 / 代写**：国赛查重严格，被查实取消成绩并通报学院，影响学位。
  - 建模国赛与电赛国赛（奇数年）时间接近，需提前规划。
  - 美赛需英文写作，不要盲目冲 O 奖，先保 M 奖（一等奖）。

- **本校大二匹配度**：8.5/10。
  推荐理由：你正在学高数 / 线代，时间窗口正好；Python 可直接用于编程手；3 人组队门槛低；国一以上在综测和保研中权重高。缺点是现金奖励不如实习，属于"积累型"收入。

## 4. 专业赛事合集（蓝桥杯 / 集创赛 / 嵌入式 / 智能车 / FPGA-EDA / 信息安全）

- **方法说明与典型玩法**：
  把本校强相关的专业赛事合并为一类，按赛季选择 1–2 个深耕：
  - **蓝桥杯**（每年 4 月省赛、5–6 月国赛）：软件类（C/C++/Python/Java）+ 电子类（单片机设计与开发，考 STM32）。**与你 STM32 技能直接对口**。
  - **全国大学生集成电路创新创业大赛（集创赛，CICC）**：每年 3–8 月，企业冠名杯赛（华为、紫光展锐、 arm 等），分芯片设计、芯片应用、职业技能三赛项。
  - **全国大学生嵌入式芯片与系统设计竞赛**：STM32 / RISC-V 应用，与你技能栈重合。
  - **全国大学生智能汽车竞赛（恩智浦杯）**：每年 7–8 月总决赛，跑赛道 + AI 识别。
  - **FPGA / EDA 创新设计大赛、信息安全竞赛（XCTF 等）**：偏数字 IC / 网安方向。

- **所需技能与准备成本**：
  技能：C/Python、STM32、模拟电路、PCB；蓝桥杯单片机组只需 STM32+C。
  成本：蓝桥杯报名费约 300 元/人（学校常补贴）；集创赛 / 智能车需购买开发板（约 500–2000 元，学校基地多可借用）。

- **启动到首笔收入周期**：
  蓝桥杯每年 3 月报名、4 月省赛、6 月国赛，赛后 1–2 个月发校奖。
  集创赛每年 3–4 月报名、8 月总决赛，奖金赛后 1–2 个月发放。

- **真实收入区间**：
  - **集创赛**：官方章程明确"**每个杯赛设置 3 万元奖金池，一、二、三等奖金总金额均为 1 万元，按获奖团队数量平均分配**"；大赛总奖金超 100 万元。第九届（2025）全国总决赛 134 支一等奖、200 支二等奖、313 支三等奖。按平均估算，一等奖队可分得约 1000–3000 元。
  - **蓝桥杯**：官方无现金大奖，主要发证书和纪念品（全国前 30 名发 T 恤、前 5 名发鼠标垫）；**收入来自本校校配套奖励**（按校竞赛奖励办法，省一约 200–500 元、国一约 500–2000 元，具体以最新办法为准）。
  - **智能车竞赛**：早期（飞思卡尔时代）总决赛特等 3 万/队、一等 1 万/队；近年（恩智浦杯）以企业奖品 + 证书为主，现金奖励缩水，主要价值在简历。
  - 隐性收益：集创赛 / 嵌入式竞赛获奖是华为、紫光、中兴等西安本地 IC / 硬件企业实习的强敲门砖。

- **具体渠道 / 平台与入驻方式**：
  - 蓝桥杯官网：https://dasai.lanqiao.cn/
  - 集创赛官网：http://www.ciciec.com/ （学生端 http://univ.ciciec.com/ ）
  - 本校校内：通过创新创业学院、各学院科技竞赛俱乐部（如 STM32 俱乐部、集创赛本校基地）报名。

- **代表性参考对象**：
  - 集创赛官网《奖项设置》：http://www.ciciec.com/col.jsp?id=143
  - 蓝桥杯大赛官网：https://dasai.lanqiao.cn/
  - 恩智浦智能汽车竞赛介绍：https://aiotcloud.nxp.com.cn/college-competition

- **风险与坑**：
  - ⚠️ 蓝桥杯 / 集创赛都有"赛前保过班""保奖内推"收费培训，**官方从不授权任何机构保奖**，不要花几千元报班。
  - 智能车 / 嵌入式硬件调试周期长，容易在赛前一周翻车，预留充足调试时间。

- **本校大二匹配度**：9/10。
  推荐理由：本校是 IC / 电子强校，集创赛、嵌入式、智能车在本校有成熟基地和指导老师；你已会 STM32+C，蓝桥杯电子类和集创赛应用杯是"低门槛高匹配"选择；现金奖不如电赛但赛季多、可常年打。

## 5. 奖学金体系（国奖 / 励志 / 校长奖 / 校级综合发展奖）

- **方法说明与典型玩法**：
  奖学金不是"兼职"，而是"对前一学年成绩 + 综测的一次性兑现"。本校本科奖学金体系（据 2026 年迎新网公布）：
  - **国家奖学金**：特别优秀的全日制本科生，**10000 元/生·年**，发国家统一荣誉证书。
  - **国家励志奖学金**：面向家庭经济困难且品学兼优学生，**约 5000 元/生·年**（国家统一标准）。
  - **本科生校长奖**：校级最高荣誉，**每年 5 人获奖，10000 元/人**；另 7 人获校长奖提名奖，**8000 元/人**。
  - **综合发展奖学金、单项奖学金、毕业生奖学金**：每学年获奖比例约 40%。
  典型玩法：大二拼命刷绩点（专业前 5–10%）+ 竞赛加分 + 学生工作，大三冲国奖 / 校长奖。

- **所需技能与准备成本**：
  技能：无特殊技能，核心是 GPA（加权平均分）+ 综测（竞赛 / 志愿 / 学生工作）。
  成本：时间成本，需维持较高课业投入。

- **启动到首笔收入周期**：
  每学年 9–10 月评上一学年成绩，11–12 月学校公示并一次性打款到学生银行卡。**周期约 12 个月**（从你开始刷绩点到拿到钱）。

- **真实收入区间**：
  - 国奖 10000 元/年；校长奖 10000 元；校长奖提名 8000 元；励志约 5000 元/年。
  - 综合发展奖学金一等 / 二等 / 三等具体金额以《本校本科生学校奖学金管理评定办法（修订）》为准（办法原文见学生工作处）。
  - 交叉验证：本校 2026 年迎新网"本科生资助政策"页明确写"国家奖学金每生每年 10000 元"、"本科生校长奖每年评选 5 人，金额 10000 元"。
  - 注意：同一学年内国奖可与校长奖兼得，但国奖与国家励志奖学金不可兼得（据《本科生国家奖学金评审办法》第十四条）。

- **具体渠道 / 平台与入驻方式**：
  每年 9–10 月，辅导员 / 班级群发布奖学金评审通知，按综测排名学院内推荐。无需主动"应聘"，绩点和综测达标自动进入候选。

- **代表性参考对象**：
  - 本校迎新网《本科生资助政策》：https://校园网内网系统
  - 本校学生工作处《本科生学校奖学金管理评定办法（修订）》：https://校园网内网系统
  - 本校学生工作处《本科生国家奖学金评审办法》：https://校园网内网系统

- **风险与坑**：
  - ⚠️ **综测材料造假**（志愿时长、学生工作经历）：评审公示期被举报会取消资格并通报。
  - 国奖名额极少（约专业前 1–2%），不要孤注一掷；综合发展奖学金覆盖率 40%，是更现实的"零花钱"来源。

- **本校大二匹配度**：7.5/10。
  推荐理由：大二下到大三是冲国奖的关键准备期；你已在学高数 / 线代，把基础课绩点拉高是性价比最高的"赚钱"。但奖学金看的是过去一年成绩，大二开学拿到的是大一的钱，**对"现在缺钱"帮助有限**。

## 6. 大创项目 + 实验室助研 / 横向项目津贴

- **方法说明与典型玩法**：
  - **大学生创新创业训练计划（大创）**：分国家级 / 省级 / 校级，本科生组队（3–5 人）在指导老师名下做一年项目。本校办法明确：**省级大创不少于 5000 元/项，校级大创不少于 2000 元/项**；国家级按教育部标准。经费可报销元器件、差旅、专利申请费、论文版面费。
  - **本科生创新基金（基本科研业务费）**：学校按学院分档拨经费（A 档学院 11 万以上、B 档 6–10 万、C 档 5 万以下），以"科技创新俱乐部"为单位管理，结题要求为学生一作论文 1 篇 / 一作专利 1 项 / 软著 2 项（满足 1–3 项）。
  - **进实验室做助研**：主动找本院做嵌入式 / IC / 信号处理的老师，申请进组打辅助（画 PCB、调代码、测数据），部分课题组会发**助研津贴**（本科生 200–800 元/月不等，课题组自定）；横向项目（企业委托）组发津贴更常见。
  典型玩法：大二上联系一位做 STM32 / 硬件相关的导师 → 进组打杂 1–2 个月 → 争取挂名大创项目成员 → 项目经费用于买元件，部分课题组按月发补贴。

- **所需技能与准备成本**：
  技能：STM32、C、基础 PCB、会用示波器 / 电源；沟通能力（主动发邮件找老师）。
  成本：无直接费用；每周投入 6–15 小时。

- **启动到首笔收入周期**：
  大创每年 4 月立项、经费到账；助研津贴通常进组 1–2 个月后开始发。**首笔周期约 2–4 个月（助研）/ 6–12 个月（大创结题后才能算"成果收益"）**。

- **真实收入区间**：
  - 大创经费：省级 ≥5000 元/项、校级 ≥2000 元/项——**这是项目经费，不是直接打给你个人的现金**，需报销（买元件、打印、差旅），不能直接分赃。
  - 助研津贴：课题组自定，本科生常见 200–800 元/月；横向项目组可能更高。**无学校统一标准，需直接问导师**。
  - 隐性收益：大创国家级 + 一作专利 / 论文，是冲校长奖、推免、找实习的硬通货；学生为第一发明人的专利 1 项是本科生创新基金结题硬指标之一。
  - 交叉验证：本校《"大学生创新创业训练计划"管理办法（修订）》第十条明确省级 ≥5000、校级 ≥2000；2026 年基本科研业务费本科生创新基金公示中，网络与信息安全学院 8 万、人工智能学院 7 万、力感院 3 万（学院整体额度）。

- **具体渠道 / 平台与入驻方式**：
  - 大创：每年 11 月（次年校级立项）/ 4 月（国省级申报）看本科生院 校园网内网系统 和创新创业学院 校园网内网系统 通知。
  - 进实验室：查本院老师主页（校园网内网系统 / IC / 信号处理，发邮件附简历 + 成绩单 + 你做过的 STM32 项目，申请"暑期 / 学期助研"。**本校老师普遍欢迎有动手能力的本科生**。
  - 学生科研助理（毕业去向）：注意科学研究院招的"科研助理"是**毕业生岗位**（签劳动合同、不低于西安最低工资），不是大二在校生岗位，别混淆。

- **代表性参考对象**：
  - 本校创新创业学院《"大学生创新创业训练计划"管理办法（修订）》：https://校园网内网系统
  - 本校本科生院《2026 年基本科研业务费本科生创新基金拟资助项目公示》：https://校园网内网系统
  - 本校科学研究院《关于做好选聘应届毕业生担任校内科研助理工作的通知》（区分在校生助研与毕业生科研助理）：https://校园网内网系统

- **风险与坑**：
  - ⚠️ **挂名大创**：项目不做实质工作、只挂名，结题答辩会露馅；且大创经费报销有审计，虚开发票报销是违纪。
  - ⚠️ **专利署名权**：学生在实验室做出的发明，按本校《知识产权管理规定》多属职务发明，专利权归学校，学生是第一发明人但不是专利权人；不要自己私下找代理所花几千元"全包申请"，学校流程更便宜。
  - 助研津贴无标准，进组前明确问清楚"有没有补贴、多少、按月发还是按项目发"。

- **本校大二匹配度**：8.5/10。
  推荐理由：本校科研经费充足、老师带本科生传统好；你已有 STM32+PCB 动手能力，比纯绩点学生更容易被老师接收；大创 + 助研是"拿经费练手 + 攒保研简历 + 少量津贴"三合一。

## 本分类小结

- **优先级排序（对本校大二电信学生）**：电赛 / 嵌入式类专业赛（匹配度 9+）> 数学建模（8.5）> 大创+进实验室（8.5）> 奖学金（刷绩点长线）> 互联网+/挑战杯（作为已有项目的二次包装）。
- **收入结构真相**：竞赛和科研的"现金收入"其实不高（队奖多为几百到两千元），**真正的回报是保研加分、简历背书、实习内推**。把它当成"用时间换学分 + 推荐信"，而不是"兼职赚钱"。
- **时间分配建议**：大二上重点进电赛 / 嵌入式基地 + 联系一位导师进组；大二下冲数学建模校赛；暑假（奇数年）冲电赛省国赛。

## 避坑总览

| 坑 | 说明 |
|---|---|
| ⚠️ 挂名竞赛 / 大创 | 答辩和结题会露馅，取消成绩并影响综测诚信记录 |
| ⚠️ 收费保奖内推 | 任何"包过电赛 / 保集创赛一等奖"的培训班都是骗局 |
| ⚠️ 大创经费虚开发票 | 学校审计 + 计划财务处报销留痕，违纪可处分 |
| ⚠️ 专利自己花几千元"全包申请" | 职务发明走学校科技院流程，学生是第一发明人即可 |
| ⚠️ 论文 / 数模代写 | 查重 + 学术诚信档案，可导致取消学位 |
| 奖学金材料造假 | 公示期被举报即取消资格并通报学院 |
