# 04 · 中文社区实战案例：中文互联网的 CC 拆解与实战

> 中文圈不是只有二手翻译——源码泄露后，中文社区产出了成体系的深度拆解。本篇按"源码拆解 / 实战复盘 / 翻译基准线"三层介绍，全部标注可信度（[已验证]=抓取过页面，[搜索所见]=搜索结果所见，使用前建议点开复核）。

## 一、源码拆解层：中文社区在 2026 年的高光

### 1. shareAI-lab/analysis_claude_code [已验证（已 clone 到 07_源码仓库）]

- 地址：https://github.com/shareAI-lab/analysis_claude_code
- 内容：对 Claude Code v1.0.33 的深度逆向分析，还原出多 Agent 分层架构、Task 子代理分发、实时 steering（中途插话转向）机制；附中文文档。
- **为什么它是中文圈标杆**：不是"读后感"，是把混淆代码逐段还原成可读分析的系统工程。知乎问题《Anthropic 的 Claude Code Agent 效果很好，有没有人深入分析其设计？》的核心答案就是它 [搜索所见]。
- 【怎么用】对照本库 01 章：它的"多 Agent 分层"对应 05 篇子代理，"实时 steering"对应 01 篇的用户打断处理——**先建立本库的框架，再看它的还原细节，两边互相印证**。

### 2. 知乎专栏《薄模型，厚控制：Claude Code 与当下 AI 工程的真相》（2026.5）[搜索所见]

- 在知乎搜标题可达。从 51 万行泄露源码切入，提出"模型只占一小部分，控制层（harness）才是工程大头"的论点。
- 【批注】这个论点与本库 00 篇"世界观 2/3"完全同频：**读源码学的不是模型知识，是控制工程**。中文原创分析里论点最清晰的一篇。

### 3. CSDN《深度解析 Claude Code 源码（一）：整体架构与核心数据流》 [搜索所见]

- TypeScript + React + Ink、1884 个文件的还原路线图（源码泄露事件后出现，与 2026.3 泄露约 51 万行 TS 的报道相互印证）。
- 【怎么用】把它当"泄露源码的地图页"：先看这类综述建立文件级方位感，再进 07_源码仓库的归档镜像读原文。

### 4. 掘金《Claude Code Plugin 深度解析：从 plugin.json 到源码加载》（2026.5）[搜索所见]

- 讲清 Plugin 机制的实现（配置三路 merge、目录探测、frontmatter 解析），结论是"没有魔法"。
- 【批注】这篇的阅读价值在于**祛魅**：当你发现高级功能都是朴素代码组合，你就获得了"我也能造"的信心——这正是读源码的复利。

## 三、实战复盘层：跟着真人走一遍

### 数字生命卡兹克（公众号：数字生命卡兹克）

- 中文圈最擅长"把一次真实上手过程完整记录下来"的作者之一：自己跑通后的截图 + 复盘，包括用 Claude Code 做选题与写作的流程。代表文章如《全网最详细的 Codex 入门教程，手把手教你玩转 Vibe Coding》（2026.2）[搜索所见]。
- 【值得学的不是内容而是文体】：他给你的是**带失败过程的完整记录**——比"全绿截图教程"的信息含量高一个量级（对照 05 章的辨别标准）。

### 宝玉（baoyu.io [已验证]，X：@dotey）

- 中文 AI 工程翻译的事实标准：Anthropic/OpenAI 关键工程长文（含本库 01章09篇那几篇）出炉后一两天内通常有他的高质量中译+点评；也最早把 Boris Cherny 的 CLAUDE.md 团队实践引入中文圈 [搜索所见]。
- 【怎么用】英文一手资料 → 宝玉中译 → 本库批注，三层是**互补关系**：翻译保忠实，批注补"为什么"，原文保权威。

## 四、给中文学习者的一个提醒

中文内容生态的分布：**深度拆解在 GitHub/知乎（长文），直觉建设在 B 站（视频），日常追更在公众号，噪音最多在抖音/小红书（但也有真金，见 05 章搜索词策略）**。别把时间全押在一个平台——每个平台找它的"最优信息形态"。
