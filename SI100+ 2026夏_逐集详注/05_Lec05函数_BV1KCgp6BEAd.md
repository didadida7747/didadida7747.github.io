### 为什么要函数：黑箱思想 [0:47]
- 引子：一段"摄氏度转华氏度"的代码——定义变量 celsius（摄氏度）= 26.5，用换算公式求出华氏度存进变量〔字幕转写为 "PHARRIX/fahrenheit" 等，即华氏度变量〕，输出结果。问题：想换输入值就得重新打开源码、找到变量改掉再重新执行；如果这段转换只是大程序中的一小部分，还要同时改其他变量，非常麻烦。
- [2:22] 替代方案：用 input() 在终端读入字符串，再强制类型转换成浮点数存进 celsius。但如果转换只是很小的一个模块，既不想让它占用输入，最后得到的华氏度也不是最终结果、还要拿去做其他运算，也不合适。
- [3:58] 函数思想：把中间这段转换代码当作"黑箱"——"我们并不在意函数内部是怎么实现的，只在意这个黑箱的输入以及它的输出"：输入摄氏度，返回华氏度。前面一堆复杂运算算出摄氏度后，交给黑箱即可。
- [4:44] 其实早就在用函数：print、type。我们并不知道 print 的源码，只知道传给它想输出的值，它就帮我们在终端输出；type 也一样，传入 123 就输出类型。
- [5:31] 类比高中三角函数：一开始要在单位圆里画三角形、找边长关系，后来为了省去每次重复复杂定义，给它们起名 sin、cos、tangent——编程中的函数同理，防止重复代码，专业说法是"代码复用"。[7:03] 让注意力专注在更重要的内容上、隐藏函数内部复杂细节，专业说法是"代码封装"。
- [7:03] 通俗定义：函数是"一段有名字的代码"，通过函数的名字（第一节学的标识符）找到并运行对应代码；"函数就是大量代码的替身"。

### 函数调用与返回值 [7:48]
- 调用三要素：函数名 + 一对左右的圆括号 + 中间传入的参数，缺少上述部分函数就不会做事；函数可以没有参数也可以有多个参数，但括号一定要有；多个参数用逗号隔开（如 print 可传入多个元素，可以是字符串字面量也可以是变量）；[8:36] print 的 `end=""`（把结尾改为空、不换行）实际上也是一个参数。
- [9:23] `t = type(123)`：看似和调用格式不太一样，其实是把函数调用的返回值保存到变量 t 中，t 的值是 <class 'int'>——由此引入返回值。
- [10:09] 函数调用 ≈ 高中"套公式"：把计算速度的物理公式写进函数，传入重力加速度 g、大 H、小 h（这些数值可能很复杂），调用后把结果保存到 v——返回值就是公式的结果。type 的返回值就是 123 的类型。
- [11:41] 有些函数主要用于完成某些操作（如 print 向终端打印字符），并不是用来计算结果的，没有必要有返回值；但在 Python 中任何函数调用总会产生返回值——这类函数就返回 None。注意：None 也是一个值，并不是"没有返回值"。
- [12:27] 演示 `t = print("SI100plus")`：正常打印后，在交互终端直接查看 t 显示为空（None 直接查看时输出为空），用 `print(t)` 能看到 None，`type(t)` 是 NoneType——Python 基本类型之一，表示"空类型"。

### 内置函数与方法 [13:16]
- 常见内置函数：`max(a, b)` 返回最大值、`min` 同理返回最小值（都像 print 一样支持任意多个参数）、`abs` 返回绝对值；它们都有返回值。
- [13:16] 用 RTFM（read the friendly manual）精神查 Python 官方文档的内置函数总表；abs 的文档写明它返回数字绝对值，参数可以是整数、浮点数或实现了对应魔术方法的对象——前后都有双下划线的函数在 Python 中叫"魔术方法"〔字幕"魔呃魔术方法"〕，课下探究后发 Piazza。
- [14:49] `type(print)`（不加括号、不调用）显示 print 是"内置的函数或方法"——在 Python 中函数和方法是极近似的概念，所以本课并在一起介绍。
- [15:34] 方法（method）的意义：现实世界中有些功能和特定个体绑定——圆可以"求半径"，但很难定义三角形/正方形的半径。Python 用方法把某个函数绑定到具体个体，其他类型的个体调不了，避免了写出"对三角形求半径"这类毫无逻辑的代码。
- [16:21] 调用方式：元素（字面量或变量）+ 点 + 方法名 + 正常调用的括号（中间可加参数）。示例："aBc".capitalize() 返回 "Abc"（首字母大写）〔字幕口述为"AABC 点 capitalize"〕。方法区别于函数：不是随处可用的，依赖某个特定的字面量或变量。
- [17:13] 本课不讲怎么写方法，后面有 Python 进阶/面向对象的课讲类（class）的概念。
- [18:01] VS Code 补全：变量名后打一个点，会列出该类型中定义过的所有方法，直接选取即可自动补全，非常方便。

### 定义函数 [18:47]
- 定义思路：想封装逻辑 → 先让它独立成一个代码块 → 用 Tab 缩进（celsius 与华氏度两行独立成块）→ 加函数名（如 celsius_to_fahrenheit〔字幕亦转写作 celsius to fahrenheit/pararen 等〕）+ 括号 + 括号里写参数 + 冒号——任何"开启新代码块"的操作前面都要加冒号。
- [20:19] 只写 `celsius_to_fahrenheit(c_in)` 会报 "celsius_to_fahrenheit is not defined"：Python 以为你想调用它；要在前面加 `def`（define 的缩写）告诉 Python 这里是定义函数。
- [21:05] 测试：把原来的公式行替换成函数调用、传入参数、输出结果——输出却是 None！因为函数只执行了计算，没有告诉 Python 要返回什么。
- [21:51] 需要特定返回值就必须显式写 `return`（返回），如 `return fahrenheit`，返回值会回到调用处、保存到接收变量中；[22:38] 没有显式写 return 的函数都会自动返回 None（print 就是这样）。

### 类型注解与 docstring [23:25]
- 对比：官方 print 悬停能看到需要哪些参数、每个参数的类型、没传时的默认值（end 默认是 "\n"，所以默认换行）、返回值是 None、以及功能介绍；自定义函数悬停只有 "function" 和参数名，不知道参数是什么类型、返回什么类型。
- [24:12] 参数后加冒号标类型：`def celsius_to_fahrenheit(c_in: float):`，悬停即显示参数是 float，VS Code 还自动推断出返回类型也是 float；[24:58] 想显式标返回值用箭头 `->`（一个减号 + 一个右尖括号），因为冒号已被用于开启代码块。
- [25:44] 函数体内第一行放三引号字符串就是 docstring（文档字符串，字幕称"注解"），说明函数用途，可换行多写、介绍每个参数，悬停即可看到；多行字符串更长的用途正是当 docstring。
- [27:16] 重要规则：类型标注只在写代码时帮助更清晰地反映用途，真正执行时不起任何作用——故意把参数标成不匹配的类型，VS Code 会报错，但代码仍正常执行并输出。

### 定义与执行的顺序 [27:16]
- 示例：先写 `say_my_name()` 再 `def say_my_name()` → NameError: name 'say_my_name' is not defined——执行调用时通过标识符找不到对应内容。Python 默认从上到下依次执行，执行到 def 语句时才定义函数；先调用再定义就会触发 NameError。
- [28:49] 调用时的运行流程：执行 def 定义函数并跳过函数体 → 顺序执行后面的 print → 执行到调用语句时跳到函数第一行 → 在函数体内顺序执行直到代码块结束 → 带着返回值跳回调用处 → 继续执行后面的代码（如 print("你好")）。

### 形参与实参 [29:35]
- 参数是"函数沟通的桥梁"：把函数外的值传入函数内进行计算。要区分形式参数（形参，parameter）和实际参数（实参，argument）。
- 形参写在函数定义处：如 `def f(x1, x2)` 中 x1、x2；调用 f 时形参会被赋值为传入的值。实参写在调用处，可以是表达式——Python 会先运算这些表达式，把最后的结果保存到对应形参中。"参数其实就是将函数外的东西起了别名带到了函数里面"。

### 全局变量、局部变量与作用域 [31:12]
- 实验：不接收返回值，直接在函数外读函数内定义的华氏度变量 → NameError，即使前面已经调用过函数、函数内确实定义过它，外面仍然访问不到。函数体是一个代码块，最外层没有缩进的部分也是（顶层）代码块。
- [32:48] 李华例子（人人帮李华写过英语作文）：全局变量（global variable）定义在最外层，作用范围为全局——"英语卷里的李华"所有人都认识；局部变量（local variable）是函数的形参和函数体内绑定的名称，作用范围通常是当前函数——"你同学李华"通常只有你们学校认识。括号里的"所有人/你们学校"就是变量的作用域（scope）：能够访问到这个变量的范围。
- [33:33] 注意：并不是所有带缩进的代码块都创建新作用域。if 这类普通语句不创建：`if True:` 里定义 s = "SI100plus"，回到顶层 print(s) 照常输出。浅显理解：只有函数（的创建）会创建新作用域——这是比较浅的理解，Python 进阶课再扩展。
- [35:07] 示例 3.3.1：顶层全局变量"李华 = 高考英语卷（中人人都认识的李华）"，函数内定义同名局部变量（本校真有个同学叫李华）——函数内外看到的"李华"不同；即使调用了函数，外面的全局李华也没被改变，因为函数内的赋值是创建了一个新的局部变量而不是修改外部全局变量。
- [35:53] 想在函数内修改外部全局变量，要用 `global` 关键词（课上不展开，可搜索）。

### 总结 [42:01]
- 函数是代码的替身，把一段代码打包方便重复使用；定义格式：`def 函数名(参数):`——一定不要忘记冒号（开启新代码块）；调用 = 函数名 + 左右括号 + 参数（可 0 个/1 个/多个）；不写返回语句默认返回 None，希望返回特定值就显式写 `return` + 变量；还讲了全局/局部变量的区别与作用域。疑问到 Piazza 发帖。

```python
# 定义函数（换算公式字幕未逐字念出，公式行从略）
def celsius_to_fahrenheit(c_in: float) -> float:
    """将摄氏度转换为华氏度。"""
    ...  # 缩进的换算代码
    return fahrenheit   # 不写 return 则自动返回 None

f_out = celsius_to_fahrenheit(26.5)
print(f_out)

# 返回值与 None
t = type(123)           # <class 'int'>
t = print("SI100plus")  # 先正常打印，t 保存的是 None
print(t)                # None（交互终端直接查看 t 会显示为空）
print(type(t))          # <class 'NoneType'>

max(1, 2, 3, 4)         # max/min 支持任意多个参数
abs(-5)
print("aBc".capitalize())   # Abc

# 先调用后定义 → 报错
say_my_name()           # NameError: name 'say_my_name' is not defined
def say_my_name():
    print("...")

# if 不创建新作用域
if True:
    s = "SI100plus"
print(s)                # SI100plus
```
