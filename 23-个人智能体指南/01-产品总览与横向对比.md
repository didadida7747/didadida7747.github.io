# 产品总览与横向对比（个人智能体系列 · 01）

> 本篇是《个人智能体使用指南：Today AI 与 Grok Bot》的综合分册之一，所有事实均来自本系列 02（Today AI）、03（Grok Bot）、04（开源自建）分册与 `附录-调研原始笔记/同类产品.md` 调研笔记，不凭空新增。

## 1. 什么是 personal agent（个人智能体）

### 1.1 一句话定义

**Personal agent（个人智能体）= 一个长期住在你手机/电脑里、记住你是谁和你在做什么、不等你提问就主动替你盯事、并且能在真实网站和软件里替你动手干活的 AI。**

它和你用过的所有 AI 产品的根本差异，用 Today AI 分册的原话讲最清楚：

> **「豆包是你问它答，Today 是它先替你想一遍。」**（02 分册 §5.5，综合极客公园 2026-10-08 实测）

### 1.2 它和三类容易混淆的东西的区别

| 对比对象 | 典型产品 | 它和 personal agent 的本质区别 |
|---|---|---|
| **聊天机器人** | 豆包、DeepSeek、ChatGPT、Grok 聊天 | 问答型，「用完即走」：你不问它不动，下次打开它不记得你上次说了什么。没有长期记忆、不主动、不接你的邮箱日历（02 分册 §5.5） |
| **工作流自动化平台** | 扣子（Coze）、Zapier | 是「触发器→动作」的流水线：流程之间互相独立，平台不「认识你」，每次执行都是孤立任务。社区教程显示扣子 10 分钟就能做出第一个 agent，但它不会记住你的偏好并越用越准（04 分册 §1，抖音社区视频，2026-10） |
| **脚本/定时任务** | cron、Python 脚本 | 需要你写代码、自己维护；personal agent 用自然语言派活，自己拆任务、自己改 SOP（Grok Bot 的 Teach a Task 录屏示教，03 分册 §5.4） |

### 1.3 五个核心概念（先搞懂这五个，后面所有对比才有意义）

1. **长期记忆（Living Memory / Deep Memory）**：它持续记住三类东西——你的长期画像（是谁、偏好、目标）、未完成的事、从连接器读到的上下文（邮件进展、日历空档、在写的文档）。Today 的「记忆」Tab 里每条可查看/改/删（官网，2026-10）；Grok Bot 的 Bot 有跨轮长期记忆，存在加密存储里，你可以指令它「忘掉某项目相关的所有委托」（人人都是产品经理，2026-10-17）；Hermes Agent 把记忆默认开启并沉淀成 MEMORY.md/USER.md（04 分册 §4.4）；Macaron 的卖点直接叫 Deep Memory（macaron.im 博客，2026-07-27）。
2. **主动服务（Proactive）**：不等你问就推信息。典型形态是早晚报（结合当天日程+近期关注挑事）、节奏卡片（从你的使用习惯归纳高效时段）、变化追踪（长期盯的事出现新动态时主动同步）（量子位，2026-09-24；极客公园，2026-10-01）。设计原则是「不是通知中心」——只在值得打断你时才出现（抖音技术拆解，2026-10-10）。
3. **Computer use（操控电脑）**：Agent 自己开浏览器、点页面、跑终端。Today 给 agent 配了一台 24 小时在线的云端电脑（官网，2026-10）；Grok Bot 每个账号下的 Bot 共用同一台云端 Linux VM（带 Chrome、文件系统、终端）（腾讯云教程，2026-10）；Open Interpreter 走相反路线——在你**自己电脑**上跑 Python/Bash（aiagent.club 追踪站，2026-09）。
4. **多智能体协作（Multi-agent）**：多个有岗位的 Bot 组队干活。Grok Bot 支持拉 2–6 个 Bot 进群，@某个点名派活、做完自动 @下一个（腾讯云教程，2026-10）；OpenClaw 可用自然语言 3 分钟搭一个新 agent（抖音社区，2026-03）。但社区共识是：**别指望零干预，把群聊当「需要你当产品经理的初级团队」来带**（人人都是产品经理，2026-10-05 转载）。
5. **连接器 / MCP**：把你的 App 接进来的官方通道。Today 国内版已接邮箱、飞书、钉钉、腾讯文档（极客公园，2026-10-01）；Grok Bot 有 Marketplace 连接器（1Password、Notion、Canva、Gmail、GitHub 等），同时支持 MCP 服务器——和 Cursor 同一套标准（腾讯云教程，2026-10）。**原则：有连接器一律走连接器，比让它在网页上点点点可靠得多（03 分册 §8.3）。**

### 1.4 三个常见误解澄清

- **误解一：「它就是 ChatGPT/豆包 的插件版」**。错。插件还挂在聊天框里，personal agent 是独立产品：Today 是单一长对话 App、没有会话列表（极客公园十天实测，2026-10-08）；Grok Bot 长得像微信，左栏是 Bot 列表不是对话列表（腾讯云教程，2026-10）。
- **误解二：「它能替我刷手机上的 App」**。错。Grok Bot 手机端不能操控你手机里的携程、微信——它操控的是云端电脑里的浏览器（36氪实测，2026-10-13）；Today 绑定微信只是「在微信里收发消息」，**不是读你的微信聊天记录**（02 分册诚实清单第 5 条）。
- **误解三：「它 7×24 无人值守全自动」**。错。发邮件、改日历、付款前它会回来问你（抖音实测，2026-10-10）；Grok Bot 的高危动作审批卡无人值守约 10 分钟过期，过期动作不执行（腾讯云教程，2026-10-09）。它是「需要你当产品经理的初级团队」，不是甩手掌柜。

## 2. 2026 年市场全景：两大阵营一张图

截至 2026-10-20，这个市场明显分成两派：**闭源官方派**（注册即用、厂商托管、订阅收费）和**开源自建派**（软件免费、你自己部署、只付模型 API 费）。

```
personal agent 市场（2026-10）
│
├── 闭源官方派（云端托管、免运维）
│   │
│   ├── 美国/国际
│   │   ├── Grok Bot（xAI/SpaceXAI）——常驻云端数字员工，X 生态 + Cursor 联动
│   │   ├── Meta Muse（Meta）——嵌在 WhatsApp 里，2026-09-08 美国首发
│   │   ├── Macaron——mini-app 生态 + Deep Memory，$9.99/月起
│   │   ├── Lindy——偏职场工作流，$29.99/人/月起
│   │   ├── OpenAI Dot——ChatGPT 系，共享长期记忆
│   │   └── Manus Cue——有独立邮箱/电话/钱包的 agent
│   │
│   └── 中国大陆
│       ├── Today AI（齐俊元团队）——主动式个人助理，国内版免费
│       └── 豆包 / 扣子（字节）——问答 App + 零代码搭 agent，国内直连
│
└── 开源自建派（跑在你自己电脑/VPS 上）
    ├── OpenClaw——391,931 stars（GitHub API 核实于 2026-10-20），生态最火
    ├── Hermes Agent——256,881 stars（2026-10-25 核实），Nous Research，持久记忆+cron
    ├── OpenHands——约 91.2k stars，编码 agent 平台（不是生活助手）
    ├── Open Interpreter——约 68.3k stars，本地跑代码
    └── elizaOS——约 19.3k stars，偏 Web3 生态（相关度低）
```

> 注：OpenAI Dot、Manus Cue 仅在 02 分册 §5.5 被对比提及，本系列未为其单独立分册，信息以 02 分册口径为准；OpenHands/Open Interpreter/elizaOS 的 star 数为 04 分册引用的官网/追踪站数值（2026-09~10-19），非本次 GitHub API 核实值。

### 2.1 地图上每个节点值不值得你停下来看

**闭源官方派（免运维、注册即用）**

- **Today AI**：本系列主角之一。国内学生零门槛首选——手机号注册、免费、接飞书/微信/邮箱，产品原点就是「主动记住你」（晚点 LatePost，2026-10-16）。
- **Grok Bot**：另一个主角。云端数字员工团队，独特价值在原生 X 监控（2026-10-08 起）和 Cursor 联动；代价是网络口径有冲突、要 $20~30/月才够用足（36氪，2026-10-13）。
- **Meta Muse**：Meta 出品，嵌在 WhatsApp 里，2026-09-08 美国首发。产品形态和 Today 最像（长对话+记忆+云端电脑），但**国内不可用**，看它主要是用来理解「这个品类长什么样」（Zapier 博客，2026-09-30）。
- **Macaron**：主打 mini-app 生态 + Deep Memory，Pro $9.99/月起；国内需海外支付。其厂商博客把自己和 OpenClaw 前身 Moltbot 对比——注意立场（macaron.im，2026-07-27）。
- **Lindy**：偏职场工作流的 AI 员工，免费 $50 额度用 7 天不绑卡，Team $29.99/人/月；适合已经在上班的人，学生场景重叠度低（Lindy 博客，2026-10-07）。
- **豆包 / 扣子**：字节路线。豆包 App 本身是问答型；扣子（Coze）让你零代码搭一个自己的 agent 并发布到微信小程序。它不是 personal agent（不积累你的个人记忆），但它是「国内直连、免费、10 分钟出活」的最佳起点（抖音教程，2026-10-09）。
- **OpenAI Dot / Manus Cue**：前者是 ChatGPT 系、共享长期记忆；后者有独立邮箱/电话/钱包，偏任务执行、生活上下文弱于 Today（02 分册 §5.5 对比口径）。

**开源自建派（软件免费、数据在自己手里）**

- **OpenClaw**：391,931 stars（2026-10-20 GitHub API 核实），生态最火——龙虾社区、第三方可视化面板一堆、中文教程密集。一条 PowerShell 装完，住在 Telegram/Discord 等 20+ 渠道里（GitHub README，2026-10-20）。
- **Hermes Agent**：256,881 stars（2026-10-25 核实），Nous Research 出品，2026 年 2 月发布。杀招是持久记忆 + 自改进 skill 学习闭环 + 内置 cron；原生支持 Windows。和 OpenClaw 不冲突，官方提供 `hermes claw migrate` 一键互迁（GitHub README，2026-10-20）。
- **OpenHands（对照）**：约 91.2k stars，前身 OpenDevin。它是**编码 agent 平台**，干软件工程自动化——不是生活助手，别拿它盯日程（官网，2026-10-19）。
- **Open Interpreter（对照）**：约 68.3k stars，让 LLM 在你本地跑 Python/Bash，偏电脑操作自动化，没有聊天软件入口（追踪站，2026-09）。
- **elizaOS（对照）**：约 19.3k stars，偏 Web3/加密生态，与学生日常场景相关度低（追踪站，2026-09）。

### 2.2 两大阵营的本质差别（三句话）

1. **数据在谁手里**：官方派存在厂商云端；自建派的记忆、聊天、凭证默认在你自己硬盘（OpenClaw 官方声明除每日版本检查外不回传数据）。
2. **谁付订阅费**：官方派 $8~30/月订阅制；自建派软件免费，只付模型 API 费（国产模型 ¥5~60/月）。
3. **谁运维**：官方派厂商维护、几乎零操心；自建派升级、排错、加固全是你自己的事（04 分册 §6 取舍表）。

### 2.3 品类爆发时间线（2026 年 8~10 月）

personal agent 不是渐进演化出来的，而是 2026 年夏秋三个月集中爆发的——这就是为什么所有产品都「太新、教程都还没跟上」：

| 时间 | 事件 | 来源 |
|---|---|---|
| 2026-08-12~13 | Grok Bot 早期测试版发布（马斯克收购 Cursor 后首个产品） | 智源社区（2026-08-13） |
| 2026-09-08 | Today 国际版 today.ai 上线；同日 Meta Muse 美国首发 | 晚点（2026-10-16）；Layer3Labs（2026-09-27） |
| 2026-09-24 | Today 国内版 todayai.cn 上线 | 晚点（2026-10-16） |
| 2026-10-08 | Grok Bot 官宣原生搜索/阅读/监控 X | 腾讯云教程（2026-10-09） |
| 2026-10-12 | The X Subscription 上线（Bot 从 $30 Premium 档起含） | IT之家（2026-10-13） |

> 对照：OpenClaw/Hermes 等开源项目的爆发更早（抖音 #openclaw 标签 2026 年春季已有密集教程），闭源产品是看到开源社区跑通体验后才进场的——Macaron 官方博客把自己与 OpenClaw 前身 Moltbot 对比，就是这条时间线的旁证（macaron.im，2026-07-27）。

## 4. Today AI vs Grok Bot：逐项深度对比

这是本资料包的两大主角，放在一起细拆。

### 4.1 定位差异

- **Today AI = 「懂你的生活助理」**：核心卖点是**长期记忆 + 主动早晚报**。它像一个认识你的秘书，从你的邮箱、日历、飞书里归纳你的生活节奏，主动提醒你该干什么。它没有多 Bot 群聊，所有事情在一段长对话里继续（02 分册 §3.7）。
- **Grok Bot = 「你的云端数字员工团队」**：核心卖点是**一台一直开机的云电脑 + 一群有岗位的 Bot**。它像你招的兼职团队，你在手机上派活，它在云上跑；独特价值在 X 生态（原生读/监控 X）与 Cursor 联动（36氪，2026-10-13）。

一句话：**Today 是「它先替你想一遍」，Grok Bot 是「它替你上岗干活」。**

### 4.2 适用人群差异

| | Today AI | Grok Bot |
|---|---|---|
| 最适合 | 手上信息散落在邮箱/日历/文档里、想有人帮你盯死线和变化的学生/职场人；国内网络环境 | 计算机方向、需要遥控跑代码/批量处理网页、关注 X（推特）生态、能接受折腾审批卡的人 |
| 不适合 | 只想问一次性问题、不愿连接任何账号、受不了它偶尔记错你的人（02 分册 §1） | 想要「打开 App 就顺」的人——社区实测它稳定性差、时不时卡死，要会重置云电脑（腾讯云教程，2026-10-09） |

### 4.3 能力差异（硬核对表）

| 能力 | Today AI | Grok Bot |
|---|---|---|
| 长期记忆 | ✅「记忆」Tab 全量可管；实测会记住「晚饭后想散步」这种随口话（阑夕，2026-09-24） | ✅ 每个 Bot 独立记忆，可指令遗忘；但长任务上下文装不下，要每天提醒（官方 guides 自承） |
| 主动推送 | ✅ 早晚报+节奏卡片，强项 | ⚠️ 靠「例行任务」定时跑，没有基于你日程的主动归纳 |
| 云电脑 | ✅ 24h 云端 VM，跑代码实测 15 分钟出活 | ✅ 云端 Linux VM，支持 git clone/venv/装依赖/跑 main；重度用户一周额度用掉 99% 的主流玩法就是这个（抖音重度用户，2026-10-10） |
| 接你的国内应用 | ✅ 邮箱/飞书/钉钉/腾讯文档/微信（极客公园，2026-10-01；2026-10-08） | ❌ 国内应用基本不接；手机端也不能操控你手机里的 App（36氪实测，2026-10-13） |
| 多 Bot 协作 | ❌ 单一长对话 | ✅ 2–6 Bot 群 + @交接 + 模板市场 + Teach a Task 录屏示教（10 分钟） |
| 教它新技能 | 社区 Skill 生态（深度研究、会议纪要等可装） | Marketplace 连接器 + MCP（与 Cursor 同标准）+ Skill + 录屏示教 |
| 安全审批 | 发邮件/改日历/付款前先问你；邮箱任务全程只读（抖音实测，2026-10-10） | 独立审查 Agent 按自然语言规则判；高危动作弹审批卡（只放行一次/总是/拒绝）；无人值守审批约 10 分钟过期 |
| 用的什么模型 | 黑箱；实测复杂编程题转给 Claude Opus 5 跑（2026-10-08） | 黑箱路由（被点名的有 Grok 自家、Claude Opus 5.5、Midjourney、Suno），用户选不了（36氪，2026-10-13） |

### 4.4 成本差异

- **Today AI（国内）**：现阶段基本零成本——免费基础版 + 注册送 1 亿 Tokens + 1 个月 Pro；海外才收费 $20/$200 两档（官网，2026-10；晚点，2026-10-16）。
- **Grok Bot**：免费额度 7 天重置（跑通可以），但重度用必须付费——最低门槛 The X Subscription Premium $30/月；写代码的人走 Cursor Pro $20/月最划算（AI Tool Analysis，2026-10-17；腾讯云教程，2026-10）。

### 4.5 风险差异

| 风险 | Today AI | Grok Bot |
|---|---|---|
| 主要翻车 | 「很笃定地说错」（配置/路径类硬知识）；记忆记错且错记忆会放大；日程缓冲算错；单一长对话不适应（02 分册 §7） | 稳定性差要重置云电脑；登录墙=你的时间墙；群聊有审批盲区；共享云电脑=共享风险面（03 分册 §13） |
| 隐私暴露 | 连接越多越懂你、暴露面越大；微信接入能力边界实测只支持「在微信里收发消息」，**不能假设它读你的微信聊天**（02 分册附录诚实清单） | 它登录用的是**你的身份**；敏感账号（网银、学校统一身份认证）建议先不连；凭证必须走官方遮蔽输入框，永远不要贴进聊天（03 分册 §14） |
| 特有风险 | 产品太新（国内版上线不到一个月），功能随时可能改；教程生态尚未形成 | 新旧网络口径冲突；模型路由黑箱，值不值 $30 要自己试一周 |

### 4.6 不冲突的用法：一个学生怎么同时养两个

资源够（两个 App 都装）时，社区实测出来的分工是自然形成的：

- **Today 管「生活面」**：早晚报、死线提醒、邮箱账单、飞书盯稿、复习笔记累积——这些依赖你接国内账号的事，它有连接器优势。
- **Grok Bot 管「干活面」**：X 上的技术动态、云电脑跑代码、多 Bot 流水线出报告、Teach a Task 教它点网页——这些需要「一台一直开机的电脑」的事，它有云 VM 优势。
- **别让两个产品接同一个邮箱**：同一封账单邮件两个 agent 同时盯、同时提醒，会双重打扰；分工原则是「一个数据只接给一个 agent」。
- **先养一个再养第二个**：03 分册的 30 天养成路线本来就是「第 1 周只养一个 Bot」；Today 侧同理（02 分册 §5.8「一周养成节奏」）。两个一起上，你连纠错都来不及。

### 5.1 决策树（按四个条件分支）

```
你想要 personal agent，先问第一个问题：你的网络条件？
│
├── A. 只有国内网络，不想折腾代理
│   │
│   ├── 预算：0 元
│   │   └── ✅ Today AI 国内版（免费 + 1 亿 Tokens）；

│
├── B. 有稳定外网 + 海外支付方式
│   │
│   ├── 预算：0 元
│   │   └── ✅ Grok Bot 免费套餐（7 天重置）先跑通；Meta Muse（美国首发、区域受限）

│   │   ├── 主要想盯 X 生态/遥控跑代码 → The X Subscription Premium $30/月
│   │   └── 偏职场工作流 → Lindy Team $29.99/人/月（需海外支付）
│   │

└── C. 不确定要不要养
    └── 最低成本试错：Today AI 装国内版（30 分钟跑通，养一周再决定）；
        Grok Bot 装免费额度跑 30 天养成路线（03 分册附录 A）；
        两个都不满意再考虑自建。
```

### 5.2 一页纸选型结论

1. **国内学生、图省事、想白嫖**：Today AI 国内版，没有第二选项。免费、中文、接飞书/微信/邮箱，30 分钟上手（官网，2026-10）。
2. **想遥控跑代码、盯 X、写 Cursor 联动**：Grok Bot，先免费额度试，值回票价再上 Cursor Pro $20 或 Premium $30（AI Tool Analysis，2026-10-17）。
3. **计算机专业、要简历项目、在意数据主权**：花一个周末把 OpenClaw 跑在自己笔记本上（DeepSeek API，充 ¥10 起步），这本身就是一个「个人智能体」项目经历（04 分册 §7）。
4. **只想用 AI 问答**：那你其实不需要 personal agent，继续用豆包/DeepSeek 就够（02 分册 §1 明确说过）。
5. **所有选项的共同坑**：别一上来就接主邮箱/网银/学校统一身份认证；先用小号练手一周；发消息/付款/删除三类权限永远开「先询问」（02 分册 §8；03 分册 §14）。
