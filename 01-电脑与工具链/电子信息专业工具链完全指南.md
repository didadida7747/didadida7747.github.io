# 电子信息工程专业工具链完全指南

> 适用对象：本校电子信息工程专业大二学生
> 机器配置：联想拯救者 Y7000P（i7 / RTX 4060 8GB / 16GB 内存 / 1TB SSD）
> 定位：电脑基础薄弱同学的"装什么、去哪下、跟谁学、怎么排优先级"一站式手册

---

## 〇、写在最前面：你的电脑能扛住多少

你的 Y7000P 在本科生里属于"游戏本级"配置，跑本科到研究生阶段的绝大多数 EDA/嵌入式/仿真软件都没问题，但有三个硬约束要心里有数：

| 资源 | 现状 | 注意事项 |
|---|---|---|
| CPU | i7（6~8 核） | Vivado/ADS 综合、HFSS 求解主要吃 CPU 多核 |
| 内存 | **16 GB** | 这是最大短板。Vivado 全装 + 开工程建议 32 GB；本科阶段只装 Artix-7 Kintex-7 器件包，不装 Versal/Zynq UltraScale，16 GB 能跑 |
| 显卡 | RTX 4060 8GB | 对 EDA 几乎无加成（EDA 基本不吃 GPU），8GB 显存只影响 AI 类工具，不影响本指南 |
| 硬盘 | 1TB SSD | **最大问题**。Vivado 全装 100GB+、ADS 80GB+、MATLAB 全家桶 60GB+，**必须规划分区，绝不能全塞 C 盘** |

**磁盘规划建议**（联想拯救者一般 C 盘是系统盘，先在"磁盘管理"里看一下 D 盘多大）：

- `C:\`（系统+常用小软件）：保留 80~120 GB 空闲
- `D:\EDA\`：Altium、KiCad、立创EDA、Multisim
- `D:\Embed\`：Keil、STM32CubeIDE、Arduino、IAR、串口工具
- `D:\FPGA\`：Vivado、Quartus、ModelSim
- `D:\Math\`：MATLAB、Octave
- `D:\RF\`（后期按需）：ADS、HFSS、Ansys 学生版
- 所有软件安装路径**一律不要中文、不要空格**，例如 `D:\EDA\Altium` 而不是 `D:\软件\Altium Designer`

## 一、EDA 设计工具（电路设计与 PCB）

### 1.1 Altium Designer（AD）—— 行业主流，必学

| 项目 | 说明 |
|---|---|
| 授权 | **付费商业软件**（年费约万元级），学生可申请 21 天免费试用；本校实验室/机房一般有教育版 |
| 官网 | https://www.altium.com/altium-designer |
| 适用课程/场景 | 电路 CAD、电子线路课程设计、电赛板子绘制、毕设 PCB；行业内中小公司最主流 |
| 配置要求 | Win10/11 64 位，CPU i5 以上，内存 16GB，磁盘 20GB（你机器完全够） |

**版本建议**：学生用 **AD 22 / AD 23 / AD 24** 即可，不要盲目追最新版（25/26 对新硬件优化但教程少）。本校课程若指定版本就跟着课程走。

**安装注意事项**：
- 安装路径全英文、无空格；
- 杀毒软件/Windows Defender 在安装时临时关闭，否则会拦截驱动文件；
- 首次启动要加载元件库，**不要装在 C 盘**；
- 元件库别用默认的旧库，去 Altium 官方 Content Store 下载或用立创商城的立创库导入。

**学习路径**：
1. 先画一个 555 定时器小板子（原理图→PCB→Gerber）走通全流程；
2. 再画 STM32 最小系统板（包含电源、下载口、复位、LED）；
3. 最后尝试双层板布局布线、铺铜、DRC 检查、出 Gerber 给嘉立创打样。

**学习资源（B站真实可搜）**：
- **凡亿教育**（B站官方号）：AD 入门 100 讲、Cadence Allegro 实战，行业培训机构出品，规范讲得最细；
- **硬木课堂**：《Altium Designer 22/23 零基础入门实战教程》，从工程创建到 Gerber 输出一条龙；
- **郭天祥**：老牌电子讲师，《新概念 51 单片机》作者，早年 AD 教程经典易懂；
- B站搜索关键词："Altium Designer 零基础"、"AD24 PCB 实战"。

## 三、嵌入式开发

### 3.1 STM32 开发环境三方案对比（重点）

| 方案 | 优点 | 缺点 | 适合谁 |
|---|---|---|---|
| **Keil MDK-ARM v5** | 行业事实标准、教程最多、调试体验好、正点原子/野火全系教程基于它 | 商业软件（MDK-Lite 免费版 32KB 代码限制，做项目不够）、ARM Compiler 收费 | 初学者、跟正点原子/野火教程 |

### 3.2 Keil uVision5（MDK-ARM）

**工程创建流程**：新建 Project → 选芯片型号（如 STM32F103ZET6）→ 选运行环境（RTE: CORE + Startup + 对应外设库）→ 写 main.c → Build → Download（ST-Link 烧录）。

### 3.6 ST-Link 驱动与烧录调试流程

1. **装驱动**：下载 ST-Link USB 驱动（ST 官网：https://www.st.com/development-tools/st-link-v2.html ），插上 ST-Link 后设备管理器应出现 "ST-Link Debug"；
2. **Keil 里配置 Debug**：魔术棒 → Debug → 选 "ST-Link Debugger" → Settings → 能看到 IDCODE 说明连接成功；
3. **烧录算法**：Flash Download → 勾选 "Reset and Run" → 选对芯片 Flash 容量（如 256KB）；
4. **调试**：Ctrl+F5 进入 Debug，F10 单步、F11 步入、F5 运行，左侧 Watch 窗口看变量。

## 四、FPGA 开发

### 4.1 Xilinx Vivado —— AMD/Xilinx 工具链（必学）

| 项目 | 说明 |
|---|---|
| 授权 | **Vivado ML Standard 免费**（支持 7 系列 Artix/Kintex/Zynq-7000，学生完全够）；Design Edition 付费 |
| 官网下载 | https://www.xilinx.com/support/download.html （中文站：https://china.xilinx.com/support/download/index.html ） |
| 适用课程 | FPGA 原理与应用、数字逻辑课程设计、电赛 FPGA 题、IC 设计入门 |
| 配置要求 | **安装包巨大**！WebPACK 安装完 80~120GB；CPU 多核；内存 16GB 跑 Artix-7 够，别装 UltraScale 器件 |

**安装避坑（重点）**：
1. **一定要用 Web Installer 在线安装器**，然后只勾选你需要的器件：Artix-7 / Kintex-7 / Zynq-7000。**不要全选**，否则磁盘爆炸；
2. 安装路径必须全英文无空格：`D:\FPGA\Xilinx\Vivado\2024.1\`；
3. 临时目录也不能有中文；
4. 安装时**关闭杀毒软件**；
5.  licensing：第一次启动选 "Load Vivado ML Standard License"，自动生成免费 license。

**开发流程**：创建工程 → 选芯片（如 XC7A35T）→ 写 Verilog → 添加约束文件(.xdc，分配引脚) → Run Synthesis → Run Implementation → Generate Bitstream → 下载器(JTAG) 烧录 .bit 到 FPGA。

**学习资源（B站真实 UP 主）**：
- **小梅哥爱漂流**（B站）：《小梅哥 2024 FPGA Verilog 数字逻辑设计与验证——基于 Xilinx Artix-7》，公认 0 基础手把手最好的免费系列，搜"小梅哥 FPGA"；
- **正点原子** B 站官方号：FPGA 系列教程，配套开发板，工程实战导向；
- **米联客**：高速接口（PCIe、DDR3）进阶；
- 在线练 Verilog 语法：**HDLBits**（https://hdlbits.01studio.org/ ，中文站），刷题神器。

## 五、信号处理与通信仿真

### 5.1 MATLAB 在数字信号处理中的应用（大二核心）

信号与系统 + 数字信号处理两门课都靠 MATLAB：
- **FFT 频谱分析**：`fft()`、`fftshift()`、画双边/单边谱；
- **滤波器设计**：`fir1()`、`filterDesigner` 工具箱界面（直接拖窗函数出系数）、`butter()`；
- **采样/混叠**：`stem()` 画离散序列；
- **通信原理**：`comm.RectangularQAMModulator`、眼图 `eyediagram()`、误码率仿真。

**练手建议**：用 MATLAB 录一段自己的声音（`audiorecorder`），做 FFT 看频谱，再设计低通滤波器滤掉高频——这是 DSP 课设经典题。

### 7.1 大型软件安装路径规划

### 7.2 许可证 / 授权管理

| 软件 | 获取方式 |
|---|---|
| MATLAB / Simulink | 本校正版平台 http://校园网内网系统 ，全校 Campus-Wide License |
| Office / Windows | 同上正版平台，CARSI 登录激活 |
| MathType | 正版平台 |
| Keil MDK | 官网申请学生 license（学校邮箱），或用 MDK-Lite |

| Quartus Lite | 官网免费下载即用 |
| KiCad / Octave / LTspice / 立创EDA / Arduino | 完全免费，直接下 |
| ADS / HFSS / Multisim / LabVIEW | 优先用实验室机房，个人申请试用版或学生版 |

**原则**：本校能下正版的（MATLAB、Office、MathType）一律走正版；开源免费的直接用；商业软件**不要用盗版破解**，一是法律风险，二是毕设/求职时公司只认正版流程。

---

### 7.3 环境变量常见问题

- **ARM GCC / 工具链**：装 Keil/CubeIDE 时会自动配好 PATH，**不要手动改**；
- **Java**：Vivado 启动需要 Java runtime，安装 Vivado 时会自动装捆绑版，不要自己乱装 JDK 导致冲突；
- **串口工具找不到 COM 口**：设备管理器看端口号，没识别就是 ST-Link 驱动没装；
- **中文路径报错**：几乎所有 EDA 工具都怕中文路径，工程文件夹也放 `D:\Projects\STM32\LED\` 这种纯英文。

---

### 7.4 多版本共存

- **Keil 多版本**：Keil v5 和 v4 可以共存，装在不同目录；但同一个 pack 只装一份；
- **Vivado 多版本**：可以同时装 2021.1 和 2024.1（不同目录），但**磁盘吃不消**，本科阶段一个版本就够；
- **MATLAB 多版本**：不同 R20XXx 可以共存，但占空间，建议只装一个最新学生可用版本。
