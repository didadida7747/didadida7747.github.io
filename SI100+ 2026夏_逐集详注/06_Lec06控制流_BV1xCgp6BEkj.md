## 内容脉络（知识点详解）

### 什么是控制流 [0:03]
- 控制流 = 程序中决定执行顺序的过程。Python 默认从上到下逐行执行，即顺序结构；调用函数时会从调用处跳到函数第一行、执行完再跳回调用处；本课再讲另外两种：条件结构与循环结构。

### 条件结构：if / if-else / elif [1:34]
- 场景引入：中午吃饭先看卡里有没有钱——有钱自己去吃，没钱和朋友一起吃。翻译成 Python：`if 卡里有钱:`（还记得冒号是开启新代码块）…… `else:` 和朋友去吃。if 相当于"如果"，else 相当于"否则"。
- [2:21] if 基本语法：`if condition:`，condition 是布尔表达式，会返回 True/False；结果为 True 就进入下面由语句（statements）组成的代码块。示例：x=10，`if x > 0:` 输出 "x is a positive number"；配流程图：程序顺序执行到菱形判定区"X 大于 0 吗"，yes 走分支输出后回到主链路继续顺序执行。
- [4:39] if-else：条件成立执行 if 块（statement 1），不成立跳过 if 块执行 else 块（statement 2），两条线路最后都回到主路线。
- [5:25] 更多分支：卡里有钱→食堂吃饭；没钱但有现金→去全家买方便面；实在没招→找同学一起吃。`elif`（else if）= "上面的条件不成立、但满足紧跟着的条件"就执行对应语句。
- [6:11] 语法结构：1 个 if + 任意多个 elif（各自对应不同 condition 和 statement）+ 可选的 else 兜底；else 可以不写——比如哪里都没钱又拉不下脸找同学，选择不吃饭（条件全不满足就什么都不执行）。示例 x=0：大于 0 不满足、小于 0 也不满足，else 输出 "x is zero"。
- [7:44] 命中即停：x=0 时 `elif x < 1` 成立并输出后，虽然 `x == 0` 也成立，Python 却不会再进行下面的比较——很好理解（elif 包含 else 和 if，条件满足了就不满足 else 了）；这和 Lec.04 讲的布尔表达式短路现象很像。
- [8:32] 嵌套 if（nested if statement）：可以用多个 if/elif/else 嵌出复杂的 if 网络，但不建议在实践中这么做。例：判断 x 的大小（x=50，依次问 X<2、X<10、X<20……直到 huge），嵌套写法与平铺写法等价——"X小于二、X小于十、X小于20 这些语句地位是等价的，没有任何道理让剩下的语句待在其他代码块里"，同级 elif 链显然更清晰合理。
- [10:03] 例题：2024 四川内江高三一模数学题——输入 x，x≥1 走上面那条路、x<1 走下面那条路，最后输出 f(x)。讲者建议翻译成 Python 时封装成函数（"后面很多 example 都会以函数形式呈现，建议大家多用函数封装逻辑"）：中间的范围对黑箱来说不重要，输入 x、拿到输出即可。

### 更多类型：列表 [12:23]
- 引入四种类型的 一句话：列表（list）= 把一大堆东西按顺序装在一个变量里；元组（tuple）= 列表的不可修改版；集合（set）= 没有重复元素的列表；字典（dict）= 根据有含义的索引快速找到值。课上详讲前三种，字典在 ipynb 里自学（optional）。
- [13:55] 创建：`fruits = ["apple", "banana", "cherry"]`——左右中括号容纳元素，逗号分隔；`fruits = []` 是空列表；`type(fruits)` 是 list。
- [15:30] Python 不要求列表元素类型相同：`[2, 25.0, "banana"]` 三种类型放一起合法。
- [16:16] `list()` 创建空列表的理解：`int()` 不传参返回 0、`str()` 不传参返回空字符串——任何强制类型转换不传参就返回对应类型"等价于空"的值；list 也是类型（只是没那么"基本"），`list()` 就返回空列表，本质是创建了列表类型的字面量。
- [17:50] 访问：下标（索引）从 0 开始，千万别当 1、2、3 数！fruits[0] 是 apple、fruits[1] 是 banana、fruits[2] 是 cherry；fruits[-1] 是最后一个元素 cherry（可理解为 N-1）。
- [18:35] 修改：访问到后重新赋值即可，`fruits[0] = "watermelon"`。
- [19:22] 追加：`fruits.append("orange")`——用的正是上节课的"方法"：对应类型的变量加点访问方法；VS Code 提示 "append object to the end of the list"；打点还能列出该类型所有方法。
- [20:10] 指定位置插入：`fruits.insert(1, "mango")` 插到索引 1（第二个位置）。
- [20:56] 删除三种方式：`fruits.remove("banana")` 删除指定值——课堂互动：若列表里有两个 banana 删哪个？（同学猜"都删/第二个/第一个"，三种答案集齐）实测只删除第一个匹配的元素；[22:37] `del fruits[1]` 按索引删除（del 是 delete 缩写）；`fruits.pop()` 移除最后一个元素并把该元素返回出来，可以赋给新变量（pop = 弹出）。
- [23:23] 切片：中括号里用冒号隔开多个值，最多两个冒号，三个位置分别是 from、to、step（从哪到哪、步长多少），左闭右开。`fruits[1:3]` 取索引 1、2（满足 1 ≤ index < 3，注意不是 ≤3）；一边为空时 from 默认 0、to 默认到末尾；`fruits[:-1]` 相当于 0 到 N-1；`fruits[::2]` 步长 2（跳过 mango）；`fruits[::-1]` 步长 -1 即逆序输出。所有切片调用都不改变原列表——切片返回的是对应类型的一个字面量。
- [27:17] `len()` 获取列表长度，返回 int 类型（用 Pylance 悬停可见）。[28:02] `+` 连接两个列表（fruits + more_fruits）；`*` 整数 把列表内容复制 N 遍（和字符串一样）；`in` 判断元素是否在列表中（"apple" in fruits → False）。

### 列表 vs 字符串、嵌套列表、元组、集合 [28:49]
- 字符串和列表非常像：字符串同样可以下标取单个元素（s[0]）、用 from:to:step 切片（s[::-1] 逆序）、加法串联、乘整数重复 N 遍；区别是列表用 append 添加元素，字符串用加法串联（没有 append）。两者下标都从 0 开始。
- [30:22] 嵌套列表（nested list）：list 本身也是类型，可以成为元素；`matrix` 每个元素各是一个列表时，`matrix[1]` 返回一个列表，可以继续取值 `matrix[1][2]` = 第二个列表的第三个元素（=6）——二维数组取值。
- [31:08] 元组：和列表很相似，唯一区别是不能被修改，用小括号括起内容，逗号分隔；注意单元素元组必须在第一个元素后面加逗号——`(10,)` 是 tuple，`(10)` 的类型其实是 int（type 验证过），加逗号 Python 才知道你要创建元组。
- [31:54] 集合：无序、不重复元素的序列，可做交集、并集、差集等操作（与高中集合相似）；用大括号创建，但不能直接 `{}` 创建空集合，只能通过 `set()` 强制转换创建空集合。
- [32:41] 字典：ipynb 里用 IPython display 库引入 IFRAME 函数举了个很好玩的例子（非常 optional），鼓励运行、探索后发 Piazza。

### while 循环 [33:28]
- 循环 = 让代码反复执行某个操作，直到满足某个条件为止。演示用"很内向吃饱了也不说话"的梗：定义全局变量 hungry 并赋值（10），`while hungry > 0:`（格式与 if 很像：关键词 + condition + 冒号 + 代码块）一直"吃"。
- [34:15] while 与 if 的区别：if 执行完代码块后顺序往下走；while 会在代码块结束后跳回 while 的判断语句再次判断 condition，直到条件不成立才执行后面的代码。
- [35:01] 关键提醒：为了不进入死循环（无穷循环），必须在循环体内对先前的判断条件有所改变——否则 hungry 永远满足条件、无限进入代码块。
- [35:48] optional：notebook 里介绍了用调试（打断点小红点）观察程序运行状态，鼓励自己玩。

### break、continue 与进制转换例子 [36:35]
- break（破坏）：只要执行到就直接终止当前循环——无论后面还有没有代码、条件是否仍成立——跳转到代码块下面原本顺序执行的位置；continue（继续）：跳过当前循环里后面还没执行的代码，直接进行下一次循环（while 跳回 condition 判断，for 进入下一次迭代）。
- [37:20] 例子：进制转换——计算机基础课讲过的短除法：每次除以 2 直到商为 0，把余数从下往上读。按建议封装成函数 `decimal_to_binary`（十进制转二进制）：函数内先建空字符串 binary_num；`while n > 0` 反复"除二取余"：先算余数（n % 2），重点："新的余数应该加在 binary_num 的前面，不要把两个调换过来，否则顺序就不对了"（因为结果是从下往上读的）；再做 n 整除 2；最后 return。调用算 10 的二进制得 "1010"，注意结果 binary_num 是字符串类型。

### for 循环 [39:40]
- "练习时长两年半"例：创建 skills 列表，元素为 唱、跳、rap、篮球；for 遍历输出"喜欢唱跳rap篮球 music"。`for x in 容器:` 的作用是遍历〔字幕多处转写作"便利"，疑为：遍历〕任何容器：列表、元组、字典等等都可以；字符串也可以遍历（字符串和列表非常像）。
- [40:26] 字符串遍历：for char in "123456"（6 个字符）配 `end="!"` 依次输出 1!2!…！执行过程：先令 char = 第 1 个字符、输出……直到 char 为 "6" 输出后遍历结束。注意：在 for 循环中创建的变量在循环结束后仍然可用，离开循环时它的值是最后一次遍历到的元素（"6"）。
- [41:58] for 的 break/continue 行为与 while 一样：break 时即使还没遍历完也立刻结束循环去执行后面的代码块；continue 跳过本次迭代后续代码直接进行下一次遍历。
- [41:58] 经典危险例子：定义列表 [1,3,5,7,9,11]，for i in 列表 遍历，判断值为 5 就 remove(5)，输出 i 并以空格结尾。课堂竞猜（无限循环/1 3 9 11/1 3 5 9 11 等）后实测：7 被跳过了——遍历的同时修改了列表导致错位。结论："一边迭代一边修改是很危险的，大家一定要避免在遍历某一个可迭代对象的时候去修改这个可迭代对象里的一些值"；鼓励 search the friendly web 查原理发 Piazza。
- [44:30] 嵌套 for：`for i in [1,2,3]:` 里再 `for j in [1,2,3]:`（j 的代码块再缩进一层）输出 i×j；带着模拟执行讲了一遍（i=1 时 j 从 1 遍历到 3、输出换行、再 i=2……），建议到 notebook 用调试观察 i、j 的变化。

### range 与格式化输出 [46:01]
- "太小了我想要 100 个的循环怎么办"——range 三种用法：range(stop)、range(start, stop)、range(start, stop, step)，与切片完全一样、左闭右开（右边不包含）。range(5) 直接看输出是 range 0~5，type 是 range 类型；想看具体内容可以强制类型转换成列表（如 list(range(10)) 转成列表再看）。
- [47:35] 应用：判断 1~100（注意 range 左闭右开，是 1~100 不是 1~101）所有数字的奇偶并依次输出（1 是奇数、2 是偶数……）。代码里出现了字符串前面加 f、以及大括号包住 `i:2` 的写法——涉及格式化输出，课上不展开，让大家去查 Python 官方文档〔字幕"pattern的官方文档"，疑为：Python 官方文档〕里格式化输出的内容。

### 循环变量与作用域 [48:22]
- 提一嘴变量重名：for/if 不会创建单独的作用域（上节课讲过），循环里对 num 赋值的作用域和外层一样，会直接修改外面全局变量的值——这和函数内赋值（不影响全局）不同。总建议：写项目时尽量避免重复命名，用有区分度、合适的命名。
- [49:57] 通常惯用 i/j/k 作循环变量，但在 project 中也不建议——因为不知道它在遍历什么；希望大家用有实际意义的变量作循环变量。

## 讲者的观点与建议
- [44:30] "一边迭代一边修改是很危险的……大家之后的这个写代码中都要避免这样一个操作"——遍历可迭代对象时不要修改它本身。
- [8:32] 嵌套 if 能表达复杂逻辑但不建议实践使用：条件"地位等价"时应写成同级 elif 链，更清晰直接、也更合理。
- [49:57] 惯例的 i/j/k 循环变量在 project 中也不建议用——看不出在遍历什么；命名要有实际意义、避免重名（for/if 不创建新作用域，循环内赋值会改到全局变量）。
