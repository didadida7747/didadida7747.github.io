## 四、已核实的关键事实（可直接用于最终文档）

### Claude（官方，2026-10-09，platform.claude.com）
| 模型 | 输入 / 输出（$/百万 token） | 上下文 / 输出上限 | 备注 |
|---|---|---|---|
| Fable 5.1 | 10 / 50 | 1M / 128K | 最强、最慢；缓存读 $0.25；要求 30 天数据保留 |
| Opus 5.5 | 4 / 20 | 1M / 128K | 默认 effort 为 medium；缓存读 $0.20 |
| Sonnet 5.5 | 2 / 10 | 1M / 128K | 缓存读 $0.10 |
| Haiku 5.5 | 0.10 / 0.50（提示 ≤100K）；0.50 / 2.50（>100K） | 1M / 128K | 超过 100K 整个请求涨 5 倍 |

- 缓存写入：5 分钟 1.25 倍，1 小时 2 倍。**缓存读取倍率因模型而异**：通用 0.1 倍，Opus 5.5 和 Sonnet 5.5 为 0.05 倍，Fable 5.1 为 0.025 倍。
- Batch 5 折，可与缓存叠加。1M 上下文无长上下文溢价（Haiku 5.5 除外）。
- Web search 每千次 $10；Web fetch 无额外费用；US 数据驻留乘 1.1。
- 思考不能关闭（Fable 5.1、Opus 5.5）；5 系列不支持预填充；Fable 5.1 和 Opus 5.5、Sonnet 5.5 禁用强制 `tool_choice`。
