# 保研 / 考研 / 留学深造预案（本校 · 2025 级）

> 主线仍是**本科直接就业（核心软件 / AI 应用 + 后端）**，本文件是 **Plan B（备选预案）**，也是"什么情况下该切换赛道"的决策手册。
> 口径：政策依据《本校推荐优秀应届本科毕业生免试攻读硕士学位研究生工作实施办法（修订）》（本校教〔2021〕，各学院另有当年实施细则）。**所有比例、名额、加分每年微调，行动前以教务处 / 你所在学院当年文件为准。**

---

## 一、先看决策树：你到底要不要深造

```
                        你的主线：本科就业（AI 应用 / 后端）
                                      │
          ┌───────────────────────────┼───────────────────────────┐
   想做算法 / 研究岗？          想要更高平台 / 名企研发？            想出国工作 / 看世界？
   （核心算法岗多需硕士）       （顶尖大厂研发硕士占比高）           （你有国外工作目标）
          │                           │                           │
      优先【保研】            先冲【保研】，就业也并行          【留学】为主线
          │
  绩点能进专业前 ~20%？
   ├─ 能 → 全力保研（性价比最高：不用统考、夏令营提前锁定）
   └─ 不能但有硬核竞赛/科研 → 走"突出特长"通道（门槛可降到均绩 70）
              └─ 仍不够 → 【考研】（大三下启动）或回归就业
```

**核心判断**：
- **保研是"锦上添花且不冲突就业"的最优解**——大三暑假夏令营就出结果，没保上仍可无缝转秋招 / 考研，所以**只要绩点有希望，就按保研标准准备，进可深造、退可就业**。
- 考研是"高风险一年豪赌"，且和秋招时间冲突，通常作为保研失败后的兜底。
- 留学服务于你的"国外工作 / 看世界"目标，要提前 1–2 年规划 GPA 和语言。

## 二、保研（推荐免试攻读研究生）详解 ⭐

### 1. 本校保研的基本盘（数据分层看）
- **官方招生口径**：学校各专业保研比例"基本在 20% 左右"；保研 + 考研 + 出国，每年继续深造比例超过 50%。
- **第三方测算（非官方，参考）**：2025 届整体保研率约 27%，2026 届预计约 28%，推免总名额约 1800 人（含工程硕博专项、支教团等）。
- **拔尖 / 实验班显著更高**：拔尖班满足条件保研率可达 100%；2024 届实验班总体推免率约 63%、升学率约 73%。
- **学校层面升学**：2025 届本科生升学占比约 54%（就业质量报告）。
- 👉 结论：**普通专业把"专业前 20%"作为现实目标，越靠前越稳**；你若在拔尖 / 实验班则按更高比例规划。

### 2. 门槛：先拿到"入场券"
- **"一般类别"**：本科前三年**必修 / 专业主干课平均学分绩 ≥ 80 分，或专业排名前 20%**，且所有课程合格。
- **"突出特长"**（竞赛 / 科研特别强）：主干平均学分绩可放宽到 **≥ 70 分**，且课程合格；需按《本校本科生竞赛成绩优胜者表彰 / 特长认定》标准认定。
- **研究生支教团**：成绩需在专业前 50%。
- **硬伤**：补考 / 重修通过的课程，推免排名时**按 60 分计**；挂科、学术不端会直接出局。
- 学业成绩认定一般截止到**推免当年 7 月 31 日**（即大三结束的成绩）。

### 3. 综合测评怎么打分（满分 130）
> 各学院细则略有差异，以计算机学院 / 2021 版办法为典型：

| 模块 | 满分 | 构成 |
|---|---|---|
| **学业成绩** | 100 | 前三年主干必修课加权平均学分绩（学院提前公示课程清单） |
| 综合素质测评 | 15 | 思想品德、社会实践、学生工作、志愿服务等 |
| **"突出特长"加分** | 15 | **高水平竞赛、科研论文、专利、创新成果**（拉开差距的关键） |
| 合计 | 130 | 按综合测评成绩全院 / 全系排名，从高到低分配名额 |

👉 **学业成绩是大头（100/130），绩点是基础；特长加分（15）是同分段逆袭 / 冲刺顶尖院校的胜负手。**

### 4. 最值钱的加分项（结合你的能力）
- **高水平学科竞赛**（认可度最高）：
  - **全国大学生电子设计竞赛（电赛）**——本校 2025 年国奖总数全国第一，资源就在身边，省一 / 国奖是硬通货。
  - **中国国际大学生创新大赛（原"互联网+"）、"挑战杯"**——国赛获奖含金量大、加分高。
  - **数学建模（国赛 CUMCM / 美赛 MCM）**、**蓝桥杯**、**集创赛（全国大学生集成电路创新创业大赛）**、嵌入式设计、智能车竞赛、FPGA 竞赛等。
- **科研与论文**：进实验室跟老师做项目，发表会议 / 期刊论文（本科生有 EI / 核心或高水平会议在投即很亮眼）。
- **专利 / 软著**：发明专利、实用新型、软件著作权（结合你的 STM32 / AI 项目）。
- **大创项目**：国家级 / 省级大创立项并结题（省级经费 ≥5000、校级 ≥2000，见赚钱调研 05）。
- 社会实践、学生工作、志愿服务等（综合素质 15 分，按学院规则攒）。

> 各学院对"竞赛等级 → 加多少分"有明确对照表，**务必在大二就找本院最新《推免实施细则》和《竞赛 / 特长认定目录》**，照着目录精准投入，别闷头打了不被认可的比赛。

### 5. 保研的完整时间轴（以 2029 届 / 你这一届推算）
| 阶段 | 时间（大致） | 要做的事 |
|---|---|---|
| 绩点积累 | 大一 ~ 大三（前 6 学期） | 刷绩点排名、过四六级、攒竞赛 / 科研 / 大创 |
| 进实验室 | 大二起 | 联系导师 / 进课题组，争取论文、专利、助研 |
| **夏令营** | **大三暑假（约 6–8 月）** | 投递目标院校夏令营 → 参营笔试面试 → 拿"优秀营员"（≈ 预录取） |
| 材料准备 | 大三下学期末（5–6 月） | 成绩单、排名证明、四六级、获奖证书、论文专利、个人陈述、推荐信 |
| **预推免** | 大四开学初（约 9 月上中旬） | 夏令营没拿到满意 offer 的，再参加各校提前面试 |
| 本校 / 学院推免 | 9 月中旬 | 学校按综合测评排名确定推免资格名单并公示 |
| **国家推免系统** | 9 月底 – 10 月 | 教育部"推免服务系统"填报志愿、接受复试 / 待录取，**走完才正式落定** |

### 6. 保本校 vs 保外校、学硕 vs 专硕
- **保外校（"外推"）**：顶尖目标为 C9（清北复交浙、中科大等）、中科院各所；同档次热门为"两电一邮"（电子科大、北邮）及东南、上交等。本校是行业名校、生源口碑好，外推认可度高。
- **保本校**：本校的信息与通信工程、计算机、电子科学与技术、网络空间安全等学科实力强，导师熟、名额稳、性价比高。
- **学硕 vs 专硕**：学硕偏研究、读博衔接顺、考英语一 / 数学一；专硕偏工程、招生名额多。**直博**名额少但省时间，适合确定走研究路线者。
- 本研贯通 / 拔尖班一般不单独安排外推名额，按各自培养协议执行。

## 三、考研（保研失败 / 绩点不够时的主战场）

### 1. 是什么、考什么
- 全国硕士研究生统一招生考试，**每年 12 月下旬初试**，次年 3–4 月复试 / 调剂。
- 初试四科（典型）：**政治（100）+ 外语（英语一 / 二，100）+ 业务课一（数学一 / 二 或 专业课，150）+ 业务课二（专业课，150）**。
  - 电子信息 / 计算机常见：政治 + 英语一 + 数学一 + 专业课（如信号与系统 / 通信原理，或计算机统考 **408**：数据结构、计算机组成原理、操作系统、计算机网络）。
  - 学硕多考英语一 / 数学一（难），专硕多考英语二 / 数学二（相对易）。

### 2. 时间轴（若决定考研）
| 时间 | 动作 |
|---|---|
| 大三下学期（3–6 月） | 定院校专业、查招生简章 / 专业课目录；数学 + 英语基础轮 |
| 大三暑假（7–8 月） | **黄金强化期**：数学强化、专业课一轮、政治起步 |
| 大四上（9–11 月） | 专业课二轮、真题、政治背诵、英语作文；**9 月考研报名** |
| 12 月 | 冲刺、模拟、**下旬初试** |
| 次年 2 月 | 出初试成绩，判断复试 / 调剂 |
| 次年 3–4 月 | 复试（笔试 + 面试 + 机试）、调剂系统、拟录取 |

### 3. 风险与提示
- **本校是考研热门，热门专业分数线高、竞争激烈**；考本校有信息和导师优势，考外校（尤其跨校跨专业）难度更大。
- **考研与秋招几乎完全冲突**（9–12 月），一心考研就要承担"没考上又错过秋招"的风险，需提前想清楚、必要时留春招兜底。
- **保研失败转考研时间极紧**（9 月底才确定），所以大三上就应保持数学 / 专业课手感，给自己留切换余地。
- 资源：**王道考研**（408 / 数据结构 / 操作系统 / 计网体系最全）、数学（武忠祥 / 张宇 / 李永乐）、英语（真题 + 单词）、政治（肖秀荣）。

## 四、留学（服务"出国工作 / 看世界"目标）

### 1. 申请看什么
- **GPA（4 分制）**：海外院校最看重，按本校算法换算（见课程地图第五节）；想申好学校，**均分 / GPA 从大一就要稳**。
- **语言**：托福 / 雅思（理工科一般雅思 6.5–7.0、托福 90–100+，名校更高）。
- **GRE**：部分美国理工科项目要求 / 建议（计算机热门项目竞争激烈，高分加分）；英 / 欧 / 港新很多不强制。
- **软背景**：科研 / 论文、实习（大厂 / 海外）、竞赛、项目、推荐信、个人陈述（PS）。

### 2. 时间轴（以大四毕业秋季入学为例）
| 时间 | 动作 |
|---|---|
| 大一 ~ 大三 | 保 GPA、过四六级、攒科研 / 实习 / 竞赛 |
| 大二下 ~ 大三 | 考托福 / 雅思（成绩有有效期，可刷分）；需要则考 GRE |
| 大三暑假 | 确定国家 / 院校清单、联系推荐人、启动文书 |
| **大四上（9–12 月）** | **网申高峰期**（美国多为 12 月 – 次年 1 月截止；英港新 rolling，越早越好） |
| 大四寒假 – 春 | 收 offer、面试、办签证、申请宿舍 |
| 毕业后当年秋季 | 入学 |

### 3. 地区与费用（粗略，差异大）
- **美国**：计算机 / 电子就业和薪资天花板最高、OPT/STEM 有 3 年实习期，最利于"国外工作"；但学费生活费高（硕士一年总花费常达数十万人民币），奖学金少。
- **香港 / 新加坡**：一年制硕士、离家近、英文授课、花费低于美国，金融与科技就业好。
- **英国 / 欧洲**：英国一年制、欧陆（德国 / 荷兰 / 北欧等）部分英文项目学费低甚至免学费、工科强、工签政策友好。
- **奖学金**：研究型硕士 / 博士（PhD）多带奖；授课型硕士奖学金少，可关注国家留学基金委 CSC（多绑定回国服务）、各校 merit scholarship。
- 👉 留学决策本质是"**用钱换平台和海外工作机会**"，需结合家庭预算；博士全奖是预算有限又想出国的一条路，但更看重科研。

## 五、四条路径横向对比

| 维度 | 就业（主线） | 保研 | 考研 | 留学 |
|---|---|---|---|---|
| 结果确定时间 | 大三暑假实习 ~ 大四秋招 | **大三暑假夏令营（最早）** | 大四下（最晚） | 大四上陆续出 offer |
| 额外时间成本 | 边学边做项目 | 前三年绩点 + 竞赛（与就业高度复用） | 大三下 ~ 大四上全职备考约 1 年 | 提前 1–2 年备 GPA / 语言 |
| 金钱成本 | 低 | 低（学硕有奖学金 / 补助） | 低（备考 + 学费） | **高（尤其美国）** |
| 风险 | 看行情与个人准备 | 低（没保上仍可秋招） | **高（一年一考、与秋招冲突）** | 中（申请 + 签证 + 海外就业） |
| 对算法 / 研发岗 | 本科可做应用 / 后端，核心算法受限 | **硕士打开算法 / 研发门** | 同左 | 同左 + 海外机会 |
| 关键硬指标 | 项目 + 实习 + 刷题 | **绩点前 20% + 竞赛特长** | 初试分数 + 复试 | **GPA + 语言 + 软背景** |
| 与你目标匹配 | 应用 / 后端直接落地 | 进可顶尖院校、退可就业 | 兜底 | 对应"国外工作"目标 |

## 六、大二（现在，2026 秋）就该做的事——所有路径通用

> 好消息：**保研、留学、名企就业的前期准备高度重合**，现在做的事对每条路都有用，不存在白忙。

1. **死磕绩点（第一优先级）**：按课程地图把数理、C、电路等高学分课考高，目标先摸到专业前 20%、主干均绩 80+。绩点是保研 / 奖学金 / 留学 / 部分名企的通用货币。
2. **四六级**：大一 / 大二尽早四级高分、大二冲六级（六级是保研和不少岗位的隐性门槛）。
3. **打一项标志性竞赛**：结合你的 STM32 / PCB 强项，**10 月前后关注电赛实训基地招新并报名**，或冲数模、蓝桥杯、集创赛——对着本院推免加分目录选。
4. **进实验室 / 接触科研**：大二起联系导师或课题组，争取大创立项、助研、论文 / 专利的可能。
5. **把作品沉淀到 GitHub**：STM32/PID/PCB 项目、RAG / 后端小项目写好 README，既是求职作品集，也是保研面试和留学文书的素材。
6. **（留学可选项）保持英语、了解语言考试**：暂不急着考，但把英语底子维持好，大三考托福 / 雅思不慌。
7. **拿到并读懂规则文件**：本院最新《培养方案》《推免实施细则》《竞赛特长认定目录》《奖学金评定办法》，建立自己的"规则台账"。

## 七、决策检查点（每学期末自问，及时转向）

| 检查点 | 关键问题 | 倾向动作 |
|---|---|---|
| 大一下末 | 绩点能否进专业前 20%？兴趣在就业还是深造？ | 能则按"保研 + 就业双线"准备 |
| 大二下末 | 排名位置？有无 1 项像样竞赛 / 科研？六级？ | 排名靠前 → 强化竞赛冲夏令营；靠后但有特长 → 走特长通道；明显不够 → 主攻就业 / 评估考研 |
| 大三上末 | 能否拿到夏令营入场券？是否确定要读研？ | 准备夏令营材料；同时不放弃暑期实习（双线） |
| 大三暑假 | 夏令营结果 vs 暑期实习转正？ | 拿到满意 offer → 保研；没有 → 秋招或转考研 |
| 大四 9–10 月 | 推免系统 / 秋招 / 考研报名三选一收口 | 按当时结果锁定最终路径 |

## 八、关键口径与信息来源（便于自查更新）

- 推免总办法：《本校推荐优秀应届本科毕业生免试攻读硕士学位研究生工作实施办法（修订）》（本校教〔2021〕86 号，教务处 / 学生工作处可查）。
- 各学院每年发布《推荐 XX 届优秀应届本科毕业生免试攻读研究生实施办法 / 细则》（含主干课程清单、加分对照表）——计算机学院、通信工程学院、电子工程学院、人工智能学院等官网均有。
- 学籍与成绩：《本校学籍管理规定（2019 版）》；《本校本科生平均绩点（GPA）计算方法》。
- 就业 / 升学数据：本校《毕业生就业质量年度报告》（就业信息网，每年发布）。
- 招生口径：本校本科招生信息网《报考常见问题解答》（保研比例约 20%、深造率超 50% 的官方表述）。
- 第三方保研率（约 27%–28%）为机构测算，**非学校官方数据**，仅作趋势参考。

> 维护建议：每年 9 月各学院新细则发布后，更新本文件中的门槛、加分与时间轴；个人排名、已获奖项、学分缺口建议另建一个私人进度表（可参考 03 资料包的追踪表思路）。

*深造不是逃避就业的避风港，而是为"需要硕士门槛的岗位"或"更高平台 / 海外机会"做的主动选择。现阶段最优策略是：**以就业能力建设为体，以保研标准（绩点 + 竞赛 + 作品）为用**，双线并行、到大三再根据结果从容收口。*
