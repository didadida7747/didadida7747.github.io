## 定位
面向 C++/Python 背景同学的 Java 速成：环境（IDEA+Gradle+JDK21）→基本语法→面向对象→异常→常用标准库→线程入门，附三道代码填空作业。讲师自述一年未以 Java 为主力语言、细节或有不准。

## 内容脉络
- [00:01–02:52] 简介与环境：Java 特点是一次编写到处运行、完全面向对象；装 JDK（推荐 21），推荐 IDEA（学生认证免费专业版），演示新建 Gradle 项目。⏭️可跳过：IDEA 新建项目的逐步点击。
- [02:52–05:42] 基本语法：三种注释，文档注释可用 javadoc 生成 API 文档（软工会用）；main 方法是入口；package 对应目录结构且必须是源文件第一条语句；import 导入其他包（同包不必导，星号通配全部）。
- [05:42–09:06] 基本类型：四种整型（byte 一字节、-128~127，后文缓存池呼应）；float 字面量须加 F、long 须加 L（int/double 是默认类型，不加编译不过）；boolean 全小写（区别 C 的 bool）；char 占 16 位，可表汉字等 Unicode 字符；打印可直接与字符串拼接。
- [09:06–11:03] 引用类型：不存数据本身、存地址；数组推荐方括号紧跟类型（int[] a），C 风格会有 warning；数组也是对象、有 .length；类、接口、枚举都是引用类型。
- [11:03–13:25] 字符串：String 不可变，+ 拼接是创建新对象（== 验证）；== 比地址、equals 比内容；可变的 StringBuilder（非线程安全、快）与 StringBuffer（线程安全、慢）按场景选。
- [13:25–16:18] 运算符：与 C++ 基本相同，重点讲 >> 算术右移（高位补符号位）与 >>> 逻辑右移（高位恒补 0）；负数算术右移保号、逻辑右移得大正数，补码计系概会系统讲。
- [16:18–19:14] 输入输出：print/println（自动换行）/printf（格式化同 C++）；输入先 new Scanner，nextInt/nextDouble 等各取所需；类型不符抛 InputMismatchException。⏭️可跳过：[19:14–20:43] 控制语句与 C++ 逐字相同，讲师自己也说没啥好讲的。
- [20:43–23:40] 面向对象基础：所有代码必须在类中；每个 .java 文件恰好一个与文件同名的 public 类；垃圾回收管内存、无指针、传参只有传值；修饰符规则看表不必背；不写构造函数默认给无参构造；无析构函数（finalize 已废弃）；构造参数与成员同名用 this. 区分。
- [23:40–27:00] static 与 final：static 成员属于类本身、内存只有一份、实例共享（计数器例子），静态方法不能访问非静态成员；类内大括号代码块在构造函数前自动执行（冷门）；final≈C++ const，与 static 搭配定义全大写常量，final 方法禁止子类重写（演示编译报错）。
- [27:00–31:33] 组合、继承与抽象类：组合=一个类的对象作成员变量（车有引擎），讲师说实际价值不大；extends 继承、子类构造用 super 调父类（类比 Python）、重写 makeSound；现实里没有一只动物，Animal 应实现为 abstract 抽象类——不能实例化，抽象方法无方法体、必须子类实现，≈C++ 纯虚函数。
- [31:33–34:24] 接口与菱形问题：interface 定义方法签名，implements 的实现类必须实现全部方法；Java 类只能单继承，为避免菱形问题（A 的方法经 B、C 两条路径到 D 产生二义）；接口可多实现，同名方法由实现类提供唯一实现，故无二义；示例把 Dog 向下转型为接口调 fly。
- [34:24–41:32] 异常处理：连报错都是对象；异常分 Error（严重，不建议处理）与 Exception；后者分受检异常（编译期强制处理，如文件读写）与非受检 RuntimeException（空指针/越界等，不处理交 JVM 终止——OJ 上 RE 常客，讲师顺带建议别用指针手写数据结构）；try-catch 捕获，或方法签名 throws 抛给上层，层层甩锅到 main 仍无人接则终止；finally 必执行；throw 抛具体对象 vs throws 声明类型要区分；可自定义异常继承 Exception。
- [41:32–46:17] 标准库：Math 求根随机数等；BigInteger/BigDecimal 任意精度（C++ 高精度需字符串模拟，Python 天生支持）；Arrays 工具类 sort/equals/binarySearch（先排序才能二分）；ArrayList 泛型动态数组，add/remove/contains，排序借 Collections.sort。
- [46:17–49:13] LinkedList：双向链表已实现好（对比 DSA 课在 OJ 用 C++ 手写链表的指针地狱）；插入删除性能优于 ArrayList，头尾操作最优；同时实现 Deque 接口，可模拟栈与队列。
- [49:13–53:04] HashMap 与 HashSet：HashMap 存键值映射，≈C++ map、Python dict；键唯一值可重复，重复 put 覆盖；遍历用 keySet（泛型只能写 Integer 的原因后文揭晓）；HashSet 不重复、加重复返回 false，ArrayList 转 HashSet 去重是讲师点名要记的应用。
- [53:04–56:52] Object 类：所有类的基类；toString 默认输出类名@哈希码、难读，通常重写；equals 比内容、通常重写；equals 相等则 hashCode 必须相等（未放 P2 却 contains 为 true 的演示）。
- [56:52–1:02:54] 包装类与缓存池：基本类型不是对象，包装类使其可参与集合泛型（int→Integer 等）；valueOf 转包装对象、parseXxx 解析基本类型；缓存池 -128~127 返回同一对象（127 比较为 true、128 为 false）；集合泛型写 int 编译报错；自动装箱/拆箱即隐式类型转换。
- [1:02:54–1:08:06] 线程入门：创建两法——继承 Thread 或实现 Runnable 接口（讲师偏好后者）；五状态：新建/就绪/运行/阻塞/死亡；start 启动（run 别直接调）、sleep、join、yield、isAlive；两线程交替输出且顺序每次不同，演示调度不确定性。
- [1:08:06–1:10:58] 作业：三道代码填空（数组/字符串/线程各一），补全 TODO 的 begin/end 之间，数据规模小、无复杂度要求，克隆仓库跑测试脚本，每题 10 个样例。
