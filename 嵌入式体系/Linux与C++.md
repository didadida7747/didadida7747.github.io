# 05：Linux 与 C++

## 时间

9 月，每周 10–14 小时；项目一发布前不提前切换主线。

## 离开条件

Linux C++ 程序可以用 CMake 从空目录构建，GDB 能定位一次可复现问题；主机端能解析项目一协议测试向量并报告错误。

## 四周路径

1. Shell、权限、Git、GCC、GDB。
2. RAII、STL 容器、错误处理和数据模型。
3. CMake、测试和协议解析库。
4. 真实串口工具：统计、日志、断线。

资料使用 `R-LINUX-01`、`R-LINUX-02`。C++ 练习必须服务 `40-项目/02-STM32-ROS2桥接/`，不另开刷题仓库。
