# 媒体库(Jellyfin)与反向投屏

## 一、拯救者当"家庭影音库":Jellyfin + 三端客户端

把电影/剧集/动画放在拯救者硬盘上, iPad 和一加随时点播,相当于自建私人Netflix。

### 服务器端:Jellyfin(免费开源,无订阅)★
- 定位:[GitHub ≈56k★](https://github.com/jellyfin/jellyfin),无账号无广告,硬件转码不收费(Plex/Emby 的转码要订阅)。
- 安装:Windows 官方安装包直装(或 Docker,见 [05-3](#/doc/d378));
- 配置要点:
  1. 控制台 → 媒体库 → 添加电影/剧集文件夹,自动刮削海报与元数据;
  2. 控制台 → 播放/转码 → 启用硬件加速:**NVIDIA(NVENC)**(拯救者独显)或 **Intel QSV**(核显,多路转码更省电),两者都行;
  3. 局域网内大多数格式客户端"直接播放"不触发转码;转码主要服务于外网访问或格式不兼容场景。

### 客户端

| 设备 | 首选 | 备选 |
|---|---|---|
| iPad | **Infuse**(颜值/解码口碑最佳,可直连 Jellyfin/SMB/WebDAV;免费版可播大部分格式,Pro 订阅/买断见官网 [firecore.com](https://firecore.com)) | Jellyfin 官方 iOS 客户端(全免费) |
| 一加 | Jellyfin 官方 Android 客户端(免费) | Findroid(第三方原生界面,社区口碑好) |
| 电视/盒子 | Jellyfin 官方/第三方客户端 | — |

- Plex / Emby 对比:体验打磨好、客户端成熟,但硬件转码等核心功能绑订阅(Plex Pass / Emby Premiere);要零成本选 Jellyfin,要开箱即用且愿付费再考虑。

### 音乐(进阶)
- **Navidrome**:开源自建音乐服务器([GitHub](https://github.com/navidrome/navidrome)),资源占用极低,兼容 Subsonic API;iPad 用 play:Sub、一加用 Subtracks 等客户端连接,支持 FLAC 无损与按网络转码。

## 二、反向投屏:手机/iPad 的画面投到拯救者

### 一加(Android)→ Windows
| 方案 | 价格 | 特点 |
|---|---|---|
| **scrcpy** ★ | 免费开源 | 画面+声音镜像、键鼠反控、可录屏;延迟约几十毫秒,体验天花板。见 [02-1 详细步骤](#/doc/d369) |
| Phone Link 屏幕镜像 | 系统自带 | 免装第三方,每次需手机端确认,画质延迟一般 |
| AirDroid Cast | 免费+订阅 | 浏览器网页接收(电脑零安装)、支持跨网投屏;免费账户限局域网 |
| 乐播投屏 | 免费+VIP | 老牌多屏互动,面向电视/会议大屏;免费版有画质/水印限制 |
| Win11"投影到此电脑"(Miracast) | 系统功能 | 需在可选功能装"无线显示器";有消息称 24H2 起被逐步弃用,不可靠,不作规划 |

### iPad → Windows(AirPlay 接收端)
Windows 无原生 AirPlay,需第三方接收端(2024-2026 仍可用):
- **LonelyScreen**:轻量老牌,安装后 iPad 控制中心"屏幕镜像"直接选它;免费版有弹窗,付费解锁录制。
- **5KPlayer**:免费,内置 AirPlay 接收,功能更全。
- **AirDroid Cast**:也支持 iPad 的 AirPlay 通道,跨网场景更方便。
- ⚠️ AirPlay 镜像延迟普遍 1-2 秒,适合**演示/观影/看文档,不适合游戏**。
- ❌ "iPad 有线投 QuickTime"仅限 macOS,Windows 没有官方有线方案。

## 三、直播/录屏联动(简要)
- **OBS Studio**([obsproject.com](https://obsproject.com),免费开源):NVENC 硬编码录屏/推流几乎无性能损耗;虚拟摄像机输出给腾讯会议/直播伴侣;可在 OBS 里把 Sunshine 串流窗口或 scrcpy 手机窗口作为信号源做解说录制、合流直播。

## 四、这套玩法的完整形态

```
拯救者(家里,常开)
 ├─ Sunshine   → 游戏/桌面串流给 iPad(手柄掌机)和一加
 ├─ Jellyfin   → 影音库给 Infuse/官方客户端点播
 ├─ Navidrome  → 音乐库随身上车
 ├─ Syncthing  → 照片/文件三端自动同步
 └─ Tailscale  → 出门在外,以上全部照样能用(见 05-1)
```
