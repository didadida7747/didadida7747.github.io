# 男生穿搭与极简护肤（学生党 / 痘肌友好）

## 一句话简介
男生形象提升的真相：不是买贵衣服，而是"版型合身 + 配色干净 + 皮肤干净 + 头发整齐"。175cm/65kg 偏瘦体型，用基础款 + 胶囊衣橱，500 元就能搭出一整个季度；护肤只要"洁面 + 保湿 + 防晒"三步，每月 100 元内搞定油痘肌。

## 分阶段学习路径

### 阶段一：穿搭入门（第 1–4 周）
- **目标**：建立"胶囊衣橱"概念，知道什么版型适合自己。
- **做什么**：
  - 身高 175/65kg 偏瘦 → 选**合身略宽松**的基础款，避免 oversize 把人穿没；
  - 配色：全身不超过 3 个色，主色（黑/白/灰/藏青/卡其）占 80%；
  - 裤子选直筒/微锥，别穿紧身裤；上衣看肩线是否对齐自己肩点。
- **周期**：2–4 周。

### 阶段二：胶囊衣橱搭建（第 2–3 个月）
- **目标**：12–15 件单品搭出 30+ 套造型。
- **做什么**：
  - 春秋：外套 2（夹克/卫衣）+ 内搭 4（T 恤/衬衫）+ 裤子 2–3 + 鞋 2（小白鞋 + 板鞋/帆布鞋）；
  - 夏：白 T 3 件 +  Polo 1 + 休闲短裤 2 + 牛仔裤 1；
  - 冬：羽绒/棉服 1 + 厚卫衣 1 + 高领内搭 1。
- **预算友好品牌区间**：
  - **百元档**：优衣库、GU、名创优品（基础 T）、网易严选、凡客；
  - **100–300 元档**：马登工装、BDCT、小考拉、听风、Refactor、PSO Brand、回力/飞跃（鞋）；
  - **300–600 元档**：Levi's 基础牛仔裤、Timberland/添柏岚大黄靴（打折时）、New Balance 复古鞋；
  - 避免：满印花、大 logo、廉价亮面 PU 皮、紧身弹力裤。

### 阶段三：护肤极简 + 形象管理（第 1–2 个月）
- **目标**：油痘肌稳定，皮肤不油不爆痘；头发干净利落。
- **做什么**：
  - **早晨**：氨基酸洁面 → 保湿乳 → 防晒（必做）；
  - **晚上**：氨基酸洁面 → 保湿乳；
  - **痘痘**：红肿痘局部点涂水杨酸/壬二酸类产品（如宝拉珍选壬二酸、The Ordinary 水杨酸，平价可选皮宝/稀拉克儿等，按说明用）；痘印靠时间 + 防晒，别乱买美白精华；
  - **理发**：每 3–4 周修一次，两侧短、上面自然，学生党 20–40 元快剪足够；发际线高就别推太高。
- **周期**：护肤 28 天一个代谢周期，坚持 2–3 个月见效。

## 装备 / 产品入门建议（预算档位）

### 穿搭
- **0 元**：先整理现有衣柜，按"能穿/不能穿"分类；扔掉起球、发黄、变形的衣服。
- **200–500 元**：优衣库白 T × 3 + 直筒牛仔裤 × 1 + 小白鞋 × 1。
- **500–1000 元**：加一件夹克/卫衣 + 休闲裤 + 帆布鞋。
- **1000–2000 元**：胶囊衣橱完整搭好，覆盖春秋。

### 护肤（每月 50–100 元）
- **洁面（30–60 元）**：氨基酸复配洁面，如芙丽芳丝、珂润、至本、旁氏米粹。
- **保湿（50–100 元）**：清爽型保湿乳/凝露，如珂润润浸保湿乳、至本特安修护乳。
- **防晒（50–100 元）**：SPF30–50 清爽型，如碧柔水感、妮维雅防晒、安热沙小金瓶（贵但耐用）；油皮选"摇摇乐"质地。
- **痘痘局部（可选，50–150 元）**：水杨酸/壬二酸精华，只点涂痘痘，别全脸涂。
- **别买**：男士控油磨砂洁面（越洗越油）、须后水、男士专用"劲爽"系列（大多香精重）、几十块的"美白祛痘"网红精华。

## 常见误区 & 避坑

1. **以为穿贵 = 穿得好** → 版型不对，5000 块也像睡衣。合身 > 品牌 > 价格。
2. **oversize 乱穿** → 偏瘦身材 oversize 会更像"偷穿爸爸衣服"；选肩线对齐的略宽松款。
3. **全身黑/全身大 logo** → 像销售；基础款 + 小细节才显质感。
4. **护肤买一堆** → 学生痘肌只做三步，多一步都是负担；红肿痘反复半年以上去**正规医院皮肤科**，别信网红药膏。
5. **天天用皂基洁面** → 越洗越油、屏障受损爆痘。
6. **不涂防晒** → 痘印变黑、皮肤老化的最大元凶；男生也要涂。
7. **发型不理** → 衣服再好看，油头 + 长刘海 = 0 分；每周洗头 3–4 次，理发 3–4 周一次。
8. **白鞋脏了不刷** → 干净的小白鞋比贵皮鞋加分。

## 在西安 / 学校怎么操作（建议自行核实）

- **买衣服**：小寨赛格、大悦城、赛格国际购物中心；平价去唯品会线下店、优衣库（小寨/曲江大悦城）；具体店铺以商场最新入驻为准。
- **理发**：学校周边 20–40 元快剪店足够；想换发型先存 3 张参考图给理发师看。
- **皮肤科**：交大一附院、陕西省人民医院皮肤科是正规选择，痘痘严重优先就医，挂号费 10–30 元比网红产品靠谱。

## 快速开始（本周就能做）

1. 今晚把衣柜里起球、发黄、紧身的衣服扔掉/捐掉，剩下的按颜色挂好。

3. 周末去优衣库/名创优品试 3 件白 T 恤，挑肩线合适的买 2 件。
