# 健身增肌（瘦人增重方向）

## 一句话简介
针对你这种 175cm / 65kg、偏瘦体型的男生，增肌的核心是"力量训练渐进超负荷 + 热量盈余 + 充足蛋白 + 睡眠恢复"，而不是狂做有氧。坚持 3–6 个月，体重、围度、体态都会有肉眼可见的变化。

## 适合谁 & 投入成本

| 维度 | 说明 |
|---|---|
| 金钱成本 | 0 元徒手起步；入门投入 100–400 元（弹力带/哑铃）；校园健身房通常每学期几十到几百元 |
| 时间成本 | 每次 45–70 分钟，每周 3–4 次；吃饭和睡觉是"隐形训练时间" |
| 设备门槛 | 宿舍可徒手 + 弹力带/可调哑铃；进阶去健身房 |
| 宿舍友好度 | 高（注意熄灯后别扰民，跳跃类动作垫个瑜伽垫） |

## 分阶段学习路径

### 阶段一：零基础打基础（第 1–4 周）
- **目标**：学会动作模式，建立训练习惯，先增重 0.5–1kg。
- **做什么**：跟着视频学标准深蹲、俯卧撑、臀桥、弹力带划船、平板支撑；每周 3 次全身训练；每天比平时多吃 300–500 大卡（多吃主食 + 鸡蛋/牛奶/鸡胸）。
- **周期**：约 4 周。

### 阶段二：分化训练（第 5–12 周）
- **目标**：每周 3–4 练，推拉腿（PPL）或上下肢分化；负重逐步增加。
- **做什么**：宿舍用哑铃做推（胸/肩/三头）、拉（背/二头）、腿（深蹲/硬拉模式）；有条件进校园健身房练杠铃深蹲、卧推、划船。蛋白质吃到约 1.4–1.8 g/kg 体重（每天约 90–120g）。
- **周期**：约 8 周。

### 阶段三：进阶雕刻（3 个月以后）
- **目标**：薄弱部位补强，追踪围度，饮食精细化。
- **做什么**：记录训练日志（重量×组数×次数），保证"渐进超负荷"；可考虑商业健身房学生卡；系统学习营养补剂常识（蛋白粉只是方便的补充，不是必须）。
- **周期**：长期。

> 提示：以上为通用建议，有腰/膝旧伤或不适请先就医；个体差异大，出现关节刺痛应停练该动作。

## 装备 / 器材入门建议（预算档位）

- **0 元徒手党**：俯卧撑、深蹲、臀桥、平板支撑；宿舍单杠（门框款 20–40 元，注意安全承重）、双杠臂屈伸（操场/宿舍楼下）。
- **100–300 元档**：弹力带套装（30–80 元）+ 一对可调哑铃或注水哑铃（100–200 元）+ 瑜伽垫（20–40 元）。
- **300–800 元档**：15–20kg 可调哑铃 + 弹力带 + 护腕护膝；这一档在宿舍已足够练 1 年。
- **校园健身房**：通常学期卡几十到几百元（建议自行核实现价与开放时间），杠铃/卧推架/高位下拉都能用，性价比最高。
- **商业健身房学生卡**：年卡多在 1000–2500 元区间，开学季常有学生特惠（建议自行核实）；谨慎办"一次性两年卡"，先月卡/季卡试水。

## 常见误区 & 避坑

1. **只练胸不练背** → 圆肩驼背加重。推拉腿要平衡，划船/引体向上不能少。
2. **狂做有氧想"长壮"** → 偏瘦者有氧过量会进一步消耗热量，增肌期以力量训练为主，跑步每周 1–2 次即可。
3. **吃不够** → "我吃很多就是不胖"多半是实际热量盈余不足，用 App 记 3 天饮食就知道了。
4. **动作没学会就上大重量** → 腰、肩、膝最容易伤；先空杆/轻重量练 2 周。
5. **迷信补剂** → 蛋白粉 ≠ 类固醇，它只是方便的蛋白质来源；饮食跟不上，喝粉也没用。
6. **练完不睡** → 肌肉在睡眠中生长，大学生别熬夜打游戏抵消训练。

## 在西安 / 学校怎么练（建议自行核实）

- 学校操场单双杠、田径场是免费场地；学生体育课程、社团（健身/截拳道类）信息以学校最新通知为准。
- 商业健身房学生卡：开学季多比价，询问是否有宿舍接送、月付选项。
- 学校医院/校医院可做基础体检；如有训练疼痛持续，优先去正规医院骨科/康复科。

## 快速开始（本周就能做）

1. 今天起每天多喝 1 盒牛奶 + 1 个鸡蛋，食堂每餐多加一份主食。
2. 在 B站搜"卓叔增重 瘦子家庭训练计划"，挑一个全身训练视频跟练 20 分钟。
3. 下载 Keep，建一个"增肌"计划，本周完成 3 次训练并记录体重。
