# 00 · 导览：这套手册是什么、怎么用

> **版本基线**：Claude Code v2.1.310（2026-10）· Codex CLI 0.164.0（2026-10-23）· 内容调研截止 **2026-10-24**
> 命令随版本更新很快，使用时以官方文档为准；已知失效/更名命令见 §07.4。

---

## 0.1 一句话定位

**Claude Code 和 Codex 不是两个孤立的工具，而是同一物种——"终端 Agent 框架"——的两个优秀实现。**

本手册不按工具分成两本字典，而是把 Agent 框架拆成 **8 个能力域**，每个域里两工具对照展开：命令怎么用、机制差在哪、能不能联动、学生什么时候用得上。学的是"框架解剖学"这套可迁移的心智模型——以后再出 Gemini CLI、ZCode、OpenCode 等任何新框架，你都能在半小时内对号入座。

## 0.2 读者画像与起点

本手册为以下画像量身定做（也是本机探查出的真实现状）：

- **本校大二电子信息专业**，需要把工具力对接到课设、竞赛、科研、实习（→§09 学生实战手册）；
- **两个工具都已高频使用**（本机 `.claude` 148 个会话、`.codex` 241 个会话），但停留在"会聊"层，没用透命令体系；
- **原理强于实操**：已有 Claude Code 源码精读笔记（`16_AI源码与AI交互研习库`），缺"落地层"；
- 已有 `codex-learning` 六章入门（30分钟上手→工作流→CLI速查→进阶→练习→排错），本手册是它的**高阶续篇**，入门内容不再重复；
- 已装 **ZCF 框架**，用它配的命令自己还没完全搞清（→§11 专章）；
- Windows 环境 + ZCode/GLM 国产通道，成本敏感（→§09.6 学生预算策略）。

## 0.3 全书脊柱：Agent 框架统一解剖图

整本书按这 8 层展开，任何命令都能归到某一层：

| 层 | 回答的问题 | Claude Code 对应物 | Codex 对应物 | 详见 |
|---|---|---|---|---|
| ① 交互层 | 怎么跟它说话 | `@` `!` `/` `:` 前缀、双击 Esc、Shift+Tab | `@`/`/mention`、`/vim`、`/tui`、leader key | §02 |
| ② 模型与推理层 | 用哪个"脑子"、想多深 | `/model` `/effort` `/fast` `/advisor` | `/model`、`model_reasoning_effort`、`/personality` | §02 |
| ③ 上下文层 | 对话怎么存/压/回退 | `/compact` `/context` `/rewind` `/branch` `/fork` | `/compact` `/fork` `/undo` `/resume` | §02 |
| ④ 记忆与指令层 | 长期规则放哪 | CLAUDE.md 三级分层 + rules + auto memory | AGENTS.md 嵌套就近覆盖 | §02 |
| ⑤ 权限与安全层 | 自主权给多少 | 7 种 permission mode + 沙箱 + hooks（33 事件） | approval_policy × sandbox_mode + profiles | §03 |
| ⑥ 扩展层 | 怎么接外部能力 | skills/commands、plugins、MCP | skills、plugins、MCP（兼 server） | §04 |
| ⑦ 编排层 | 怎么并行/多代理/云端 | subagents、teams、worktree、`/batch` | spawn_agent、codex agents、Cloud、worktree | §05 |
| ⑧ 验证与自动化层 | 怎么审查/无人值守/CI | `/code-review` `/verify`、`claude -p`、Agent SDK | `/review`、`codex exec`、codex-action | §06 |

外围支撑章：**§07 命令速查总表**（纯索引）、**§08 场景速查**、**§09 学生实战**、**§10 练习**、**§11 ZCF 与本机配置**、**reference 来源索引**。

## 0.4 三种读法

| 读法 | 路线 | 适合时候 |
|---|---|---|
| **通读** | 00 → 01 → 02 → … → 11 | 假期/周末整块时间，建立体系 |
| **查阅** | 直接翻 §07 总表 → 按提示跳 § 哪章 | 干活中"这个命令咋用来着" |
| **练习** | 以 §10 的 12 个练习为线索，练到哪查到哪 | 每周固定练 1-2 个，最推荐 |
