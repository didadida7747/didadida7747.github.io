# 03 · 脚本获取与日常管理

## 一、四大脚本市场（按可信度排序）

### 1. Greasy Fork —— 首选

- 地址：https://greasyfork.org （中文界面：`/zh-CN`）
- 国内镜像：https://greasyfork.icu 、https://greasyfork-zh.org （原链接路径不变，替换域名即可）
- 特点：
  - 全球最大的用户脚本分享站，支持中文、速度快、脚本多；
  - **代码公开、禁止混淆和压缩**，任何人可查看源码；
  - 有自动化静态检查 + 格式与代码策略审核 + 社区举报人工下架机制；
  - 脚本页显示安装量、评分、评论、版本历史、许可证。
- 安全提示：Greasy Fork 不对每个脚本做人工逐行审计，平台相对可信 ≠ 每个脚本都可信。判断方法见 [05](/01-电脑与工具链/篡改猴Tampermonkey使用指南/05-安全与合规指南)。

### 2. GitHub —— 重要补充

- 许多高质量脚本直接以 GitHub 为发布源，项目通常有 README、issue 区、star 数，可信度更高，例如 Bilibili Evolved。
- 安装方式：
  - 打开仓库里的 `.user.js` 文件，点击 **Raw**（原始视图），Tampermonkey 会自动识别并弹出安装页；
  - 新版 Tampermonkey 也支持从 GitHub Release 下载 URL 安装。
- 找脚本的搜索技巧：GitHub 搜索 `userscript`、`油猴`、`tampermonkey + 网站名`，按 star 排序。

### 3. OpenUserJS —— 备选

- 地址：https://openuserjs.org
- 历史较早的脚本站，资源较少、速度较慢、无中文界面，作为 Greasy Fork 找不到时的补充。

### 4. 油猴中文网 —— 国内社区

- 地址：https://bbs.tampermonkey.net.cn
- 国内油猴脚本交流论坛，有脚本发布、问题反馈、恶意脚本曝光板块（如曾曝光"FCQ 木马脚本"）。
- 注意：论坛是 UGC，**没有 Greasy Fork 的代码策略约束**，从论坛附件/链接装脚本前更要仔细看源码和评论。

### 其他

- **脚本猫市场**：安装脚本猫扩展后自带的中文市场，规则与 Greasy Fork 类似，其文档同样提示只从可信站点安装。
- 各种个人博客、网盘、不明"脚本合集"：**风险最高的来源，默认不装**。

## 二、安装脚本的三种方式

### 方式 A：市场一键安装（推荐）

1. 在 Greasy Fork 搜索脚本名称或功能关键词；
2. 进入脚本页，先看：安装量、评分、评论数、最近更新时间、作者；
3. 点"安装此脚本（Install this script）"→ 跳转篡改猴脚本审查页（**这页会展示完整源码和申请的权限，花几秒扫一眼**）→ 点"安装"。

### 方式 B：GitHub Raw 安装

1. 打开 `.user.js` 文件 → 点 Raw；
2. 自动弹出安装页 → 安装。

### 方式 C：手动新建/粘贴

1. 猴子图标 →"添加新脚本"；
2. 清空模板，粘贴代码（或自己写）；
3. Ctrl+S 保存，脚本立即出现在列表中。
4. 本地文件开发：开启"允许访问文件网址"后用 `@require file:///路径` 引用本地文件（见 [06](/01-电脑与工具链/篡改猴Tampermonkey使用指南/06-脚本开发入门)）。

## 三、管理面板怎么用

猴子图标 → 管理面板：

| 选项卡 | 作用 |
|---|---|
| 已安装脚本 | 全部脚本列表；点开关临时启用/禁用；点名称进入编辑；右侧可看运行次数、最后更新 |
| 获取脚本 | 各脚本市场入口 |
| 实用工具 | **导出/导入备份**（Zip 或 JSON）、检查全部脚本更新、导出到文件 |
| 设置 | 见 [02](/01-电脑与工具链/篡改猴Tampermonkey使用指南/02-安装与初始化配置) 的初始化建议 |

单个脚本的编辑页里可以单独调整：
- 该脚本的运行 URL（包含/排除匹配）；
- 关闭它的自动更新；
- 手动检查更新。

## 四、脚本管理的核心原则（性能与稳定）

脚本是在网页上"做加法"：再轻量的脚本也要随页面执行，脚本多了浏览器必然变慢、网页更容易出 bug。

1. **谨慎对待全局脚本**。
   - 特定网站脚本（`@match https://www.zhihu.com/*`）只在对应站点加载，开销可控；
   - 全局脚本（`@match *://*/*`）每开一个标签页就运行一次，数量要少而精。
2. **看脚本体积**。
   - 几 KB、几十 KB 的脚本即使全局运行，影响基本可忽略；
   - 接近 MB 级（脚本上限约 2 MB）的大脚本，建议安装后**默认禁用**，需要时再启用。
3. **用"禁用"代替"卸载"**：不常用但偶尔需要的脚本，装好后关掉开关，需要时再开（配合"自动刷新页面"设置一键切换）。
4. **定期清理**：每月看一次列表，卸载重复功能、长期不更新、自己不再需要的脚本。
5. **同功能只留一个**：同类脚本叠加（如多个去广告、多个 B 站增强）会互相冲突，表现为按钮重复、排版错乱、功能失效。

## 五、备份、迁移与恢复

- **备份**：管理面板 → 实用工具 → 导出，可选：
  - 导出为 Zip（含全部脚本，推荐）；
  - 导出为 JSON（含脚本和配置）。
- **迁移到新电脑/新浏览器**：安装 Tampermonkey → 实用工具 → 从 Zip/JSON 导入。
- **建议**：把备份文件存进你的网盘或学习资料库目录，换设备、重装系统时一键还原。
- 开启了浏览器账号同步的用户，扩展本身会随账号同步，但仍建议季度手动导出一份。

## 六、故障排查速查

| 症状 | 排查顺序 |
|---|---|
| 某网页突然打不开/白屏/排版崩 | ①猴子图标里逐个禁用该页脚本 → 刷新；②定位到具体脚本后检查更新，仍有问题则卸载并到脚本页评论区反馈 |
| 某个脚本突然失效 | 网站改版是常态 → 检查脚本更新；Greasy Fork 脚本页看最近评论（作者通常会修） |
| 两个脚本功能冲突 | 二选一，保留维护更活跃的 |
| 脚本装了但没运行 | 看 @match 是否匹配当前 URL；注意 `http` 与 `https`、`www` 与无 `www`、移动端域名差异 |
| 所有脚本都不运行 | 检查扩展总开关是否被关闭、浏览器是否在"停用扩展"状态、是否刚更新浏览器导致 MV3 兼容问题 |
| 脚本要求的跨域请求被弹窗询问 | 弹窗会显示目标域名，确认与脚本功能一致再允许；不认识就拒绝（详见 [05](/01-电脑与工具链/篡改猴Tampermonkey使用指南/05-安全与合规指南)） |
