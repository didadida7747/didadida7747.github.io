# 02 · Anki 间隔重复实操

> Anki = 把「间隔重复」外包给算法的工具：你只管每天打开，它自动把快忘的卡推到你面前。**一次投入配置，四年复利**（六级、408、八股、大模型概念全用得上）。

## 二、制卡二十规则（质量 > 数量）

出处：SuperMemo 官网 supermemo.guru/wiki/20_rules_of_knowledge（制卡圣经；知乎搜「二十条规则 SuperMemo 中文」有译版，未核验）。最常用四条：

1. **最小信息原则**：一张卡只考一个点。"TCP 三次握手的作用+过程+为什么不是两次"拆成 3 张卡；
2. **避免列表**：列表卡永远背不全——改成"清单中第 N 项是什么"或挖空；
3. **原子化 + 双向**：重要概念做正反两张（"X 是什么" / "这个定义对应什么概念"）；
4. **看不懂就删**：复习时答不上且无印象的烂卡，当场改写或删除，别让垃圾卡污染队列。

## 四、把 Anki 织进日常（避免"三分钟热度"的标准做法）

1. **绑定既有习惯**：每天两个固定时段刷卡——早八前 10 分钟 + 睡前 10 分钟（新卡放早上，复习放睡前）；
2. **每日上限**：新卡 ≤ 30 张/天（贪多必崩），复习全清；
3. **来源即时制卡**：错题、听不懂的概念、面试答不上的八股——**当场**做成卡，攒周末批量补 = 忘得差不多了；
4. **周末清零原则**：允许中断，恢复时别补"负罪感刷卡"，直接按队列继续；
5. **毕业前不删库**：六级、考研（Plan B 备选）、面试八股共用一个库，靠标签分区（`CET6` / `408` / `LLM` / `面试`）。

## 五、不会制卡时的偷懒方案

把材料丢给 AI：「把以下内容按最小信息原则做成 Anki 问答卡（一卡一点、正反两面），输出 CSV（Front,Back,Tag)」→ 导入 Anki → **自己过一遍删烂卡**。AI 生成 + 人工筛卡 = 效率与质量的最优解（AI 工作流详见 05 篇）。
