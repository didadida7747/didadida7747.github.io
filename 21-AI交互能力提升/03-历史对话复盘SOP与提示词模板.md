# 03 · 历史对话复盘 SOP 与提示词模板（核心分册）

> 这是整套指南的主线：**把你过往的 AI 对话记录变成"病历"，让一个新的 AI 当医生，诊断你的提问习惯，开出可执行的改进处方，再用 30 天实验验证疗效。**
>
> 全流程 8 步，预计首次操作 60–90 分钟，熟练后每月 1 小时。

---

## 总览：复盘闭环（8 步）

```
①导出记录 → ②解析整理 → ③隐私脱敏 → ④分批投喂
                                      ↓
⑧节奏化再复盘 ← ⑦30天实验 ← ⑥改进清单 ← ⑤AI诊断（模板A/B/C/D）
```

这是一个 PDCA 循环：**没有第⑧步，前七步只是一次性感动；有了循环，每个月的你都比上个月更会用 AI。**

---

## 第一步：导出对话记录

| 产品 | 能否导出 | 入口 / 格式 | 说明 |
|---|---|---|---|
| ChatGPT | ✅ 一键全量 | Settings → Data controls → **Export data** → 邮箱收 ZIP（通常 24h 内） | ZIP 内含 `conversations.json`（全部对话，图结构）和 `chat.html`（可直接浏览） |
| Claude | ✅ 一键全量 | 左下角头像 → Settings → Privacy → **Export data** → 邮箱收下载链接 | 网页版/桌面版支持，**移动端不支持**。[官方说明](https://privacy.anthropic.com/en/articles/9450526-how-can-i-export-my-claude-ai-data) |
| Gemini | ✅ 一键全量 | [Google Takeout](https://takeout.google.com) → 取消全选 → 勾选 "Gemini" 与 "My Activity → Gemini Apps" → 导出 ZIP/TGZ | HTML/JSON 格式。[官方说明](https://support.google.com/gemini/answer/16920332) |
| 豆包 | ⚠️ 仅按对话导出，无全量 | 打开对话 → 长按单条消息 → 更多 → **导出文件**（txt / Word / PDF）；或"分享"多选后导出；表格可导出 CSV | 建议优先导出你印象深的 10–20 段对话 |
| Kimi | ⚠️ 代码会话可导出 | Kimi Code / CLI 内输入 `/export` 或 `kimi export`，导出 Markdown / ZIP；普通网页版靠复制或分享 | [说明](https://www.kimi.com/code/docs/kimi-code/whats-new.html) |

> 注：ChatGPT 帮助中心导出文章当日直接抓取被拦截，但入口与 ZIP 结构已经多源交叉确认。
> **导出 ≠ 删除**：Google 官方明示，下载数据不会从服务器删除原记录。

## 第二步：解析整理成"可读文本"

导出的 JSON 是给程序看的，直接投喂又乱又费 token，先整理：

1. **ChatGPT 用户**：
   - 最简单：双击打开 ZIP 里的 `chat.html`，在浏览器里按对话复制；
   - 更彻底：用开源工具 [chatgpt-conversation-extractor](https://github.com/slyubarskiy/chatgpt-conversation-extractor) 把 `conversations.json` 批量转成线性 Markdown（可处理数千条对话，保留代码块）。
2. **想要量化数据**（对话数量、token、时间线）：本地 CLI 工具 [llm-logparser](https://pypi.org/project/llm-logparser/)；可视化可用 [convoviz](https://pypi.org/project/convoviz/)；多份导出（ChatGPT+Claude）聚合、搜索、脱敏可用 [4echo](https://save4o.com/)。
3. **统一整理成下面的格式**（手动复制的豆包/Kimi 对话同样按此排版）：

```
## 对话01 ｜ 2026-09-28 ｜ 主题：STM32 报告修改 ｜ 结果：成功/失败/凑合
### 我：
（你的原话，逐字保留，不要事后润色——润色了就诊断不出问题）
### AI：
（回答摘要即可，关键的错误回答保留原文）
### 我：
……
```

4. **抽样策略（第一次不用全量）**：选最近 2–4 周的对话，挑 10–20 段，**成功的和失败的都要**——成功对话里藏着你的好习惯，失败对话里藏着改进点。按主题归类（学习答疑 / 写作 / 编程 / 查询 / 情绪倾诉）。

## 第三步：隐私脱敏（不可跳过）

历史对话里常夹杂手机号、身份证、学校/公司名、他人姓名、病历、账号密钥。**发给任何云端 AI 之前必须脱敏。**

### 3.1 替换对照表

| 原内容 | 替换为 |
|---|---|
| 真实姓名、网名昵称（第三方的） | 【姓名A】【人物B】 |
| 学校、公司、机构名 | 【学校】【公司】 |
| 手机号 | 【手机号】 |
| 身份证号 / 护照号 | 【身份证号】 |
| 邮箱 | 【邮箱】 |
| 银行卡号、支付账号 | 【银行卡号】 |
| 宿舍号、家庭住址 | 【地址】 |
| API 密钥、密码、token | 【API密钥】 |
| 病历、成绩、合同金额等 | 【敏感信息】或整段删除 |

原则：**复盘只需要"你的提问方式"，不需要对话涉及的具体业务内容。** 与提问方式无关的敏感大段内容，直接删。

### 3.2 自动脱敏（可选，适合理工科同学）

把整理好的文本存为 `对话原文.txt`，用 PowerShell 跑一遍（手机/身份证/邮箱/卡号自动替换，姓名学校等仍需手动）：

```powershell
$raw = Get-Content -Path 'E:\你的路径\对话原文.txt' -Raw -Encoding UTF8
$clean = $raw `
  -replace '\d{17}[\dXx]', '【身份证号】' `
  -replace '1[3-9]\d{9}', '【手机号】' `
  -replace '[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}', '【邮箱】' `
  -replace '\b\d{12,19}\b', '【银行卡号】'
[IO.File]::WriteAllText('E:\你的路径\对话脱敏.txt', $clean, (New-Object Text.UTF8Encoding $false))
```

跑完务必再**全文搜索一遍**姓名、学校、公司、地址手动替换。也可以直接用本地工具 llm-logparser / 4echo 的脱敏功能，全程不联网更安全。

### 3.3 顺手关掉训练开关

ChatGPT：Settings → Data controls → 关闭 "Improve the model for everyone"，关闭后后续对话不用于训练。（[参考](https://cloud.tencent.com/developer/article/2754781)）

## 第四步：分批投喂（隐私优先的投喂设计）

1. **新开一个专门的"复盘"对话**，使用你手上能力最强、上下文窗口最大的模型；需要深度归因时选思考型（reasoning）模型。
2. **隐私增强玩法（推荐）**：借鉴成熟的复盘流程设计——**第一次只给"元数据"**（每段对话的日期、主题、轮次、使用的工具，不给正文），让 AI 先提出抽样方案、说明它打算分析什么，你确认后再粘贴对应正文。
3. **分批**：一次投喂 5–10 段（或控制在窗口容量内）。每批先让它输出简版问题表，全部喂完后再让它跨批次汇总，避免"边看边忘"。
4. 材料放前面、指令和问题放最后（Anthropic 实测这样回答质量更高）。

---

## 第五步：用提示词模板让 AI 诊断

以下 4 套模板覆盖不同复盘粒度，**全部可直接复制**。把【】中的内容换成你的实际情况。

### 模板 A：AI 交互教练 · 批量诊断（主力模板，首次复盘必用）

```
# 角色
你是一名资深"AI 交互教练"，专门诊断人类与大语言模型对话时的提问问题，
风格客观、直接、不讲客套，打分不许虚高。

# 背景
我觉得自己虽然和 AI 对话很多，但交互水平不高。下面粘贴我与 AI 的若干段
历史对话，已做脱敏处理（【姓名】【学校】【公司】等是占位符，无需还原）。

# 任务
只评价"我（用户）"的提问方式与对话习惯，不要评价回答内容本身的对错，
除非该错误源于我的指令。

# 分析维度
1. 目标清晰度：我是否说清了要什么、验收标准是什么？
2. 上下文完整度：是否提供必要背景（我是谁、给谁用、场景、已有材料）？
   有无无关冗余信息？
3. 指令具体度：是否存在"帮我看看""大气一点""高级一点"这类模糊表述？
4. 输出约定：是否指定格式、长度、结构？
5. 迭代质量：输出不满意时，我是精准指出问题并补充信息，还是重复原问、
   新开对话、与 AI 争吵？
6. XY 问题：我是否直接要"我以为的解法"，却没交代真正要解决的问题？
7. 对话管理：是否把多个不相关主题混在同一对话？该开新对话时没开？
8. 验证动作：涉及事实、数字、代码时，我有没有要求来源或自行核验？
9. 坏味道：讨好诱导、错误前提、一次塞太多任务、把 AI 当搜索引擎等。

# 输出格式
1. 总览：这批对话的整体提问质量评分（/10），并给出三条理由；
2. 问题清单（表格）：编号 | 出现位置（引用我的原话）| 问题维度 |
   为什么是问题 | 严重度（高/中/低）；
3. TOP3 改进点：只选三个杠杆最高的，每条给出"改写前 → 改写后"的示例；
4. 一个我做得好、值得保持的点；
5. 最后问我：要不要就 TOP3 中的某一条做专项练习。

# 对话记录
（在此粘贴……）
```

### 模板 C：AI 眼中的我 · 使用习惯画像（月度 / 学期 / 年度复盘）

```
# 角色
你是我的"AI 使用习惯画像分析师"，结论必须基于证据，禁止脑补。

# 任务
以下是我过去【一个月 / 一学期 / 一年】与 AI 的对话记录（已脱敏）。
请生成一份"AI 眼中的我"使用画像。每个结论都要引用我的对话原文作为证据；
证据不足的维度直接写"证据不足"。

# 分析维度
1. 使用概览：对话数量、主题分布、活跃时间段；
2. 任务类型：我主要让 AI 做什么（写作 / 编程 / 翻译 / 信息查询 / 学习答疑 /
   情绪倾诉），估算占比；
3. 提问成熟度：结构化指令占比、平均迭代轮次、是否常一次没效果就放弃；
4. 上下文习惯：给背景的频率、是否多主题混杂、长对话是否做小结；
5. 验证习惯：是否核实事实、是否盲信输出；
6. 依赖度与讨好：我是否频繁寻求确认？AI 是否迎合过我的错误前提（举例）；
7. 情绪与关系：我对 AI 的语气，是否把它当情绪出口；
8. 能力盲区：哪些事我本该自己做却外包给了 AI；
9. 成长信号：与记录早期相比，我的提问方式有没有进步（举正反例）。

# 输出格式
1. 画像正文（按 9 个维度，每条结论附原文引用）；
2. 雷达评分表（9 个维度各打 1–5 分，用 Markdown 表格）；
3. 本周期三条最重要的改进建议，按杠杆排序；
4. 一句最想提醒我的话（可以直接、不客气）。
```

## 第六步：生成个人改进清单

拿到诊断结果后，不要停在"说得真对"，立刻做归类：

1. 打开 [05-自评与改进清单](/21-AI交互能力提升/05-AI交互能力自评与改进清单)，先按 9 个维度给自己打分（凭印象 + AI 诊断对照）。
2. 把 AI 列出的问题分成两类：
   - **话术类（马上能改）**：如"以后提问必须带输出格式""模糊形容词换成具体参数"——当场就能用；
   - **习惯类（需要训练）**：如"不迭代就放弃""多主题混聊""盲信不验证"——进入第七步做实验。
3. 把"改写前 → 改写后"的示例存进你的 prompt 库或笔记软件，下次直接套用。

## 第七步：设计 30 天实验（每次最多 3 个）

借鉴成熟复盘流程的克制原则：**一次只选 1–3 个最值得改的点，目标是消除无效投入，而不是全面改造自己。**

| 实验编号 | 要改的习惯 | 触发场景 | 新做法（含固定话术） | 第一个具体行动 | 成功衡量指标 | 检查频率 |
|---|---|---|---|---|---|---|
| 例1 | 指令模糊 | 每次找 AI 写东西前 | 用 RTF：角色+任务+格式写全再发 | 把 RTF 模板贴在便签置顶 | 30 天内结构化提问占比 ≥ 80% | 每周日统计 |
| 例2 | 不迭代就放弃 | 第一版不满意时 | 至少追问 3 轮，每轮指出具体问题 | 第一次不满意时不关闭对话 | 失败对话平均迭代 ≥ 3 轮 | 每次对话后 |
| 例3 | 盲信事实 | AI 给出数据/法条时 | 要求附来源，自己点开核对 |  | 当月零起因盲信导致的错误 |  |

要点：

- 每个实验只设计**一个最小动作**，并写清"做到了长什么样"（可计数、可判断）；
- 对自定义指令、prompt 库、工作流的修改，先写成"完整新版本"，自己确认后再替换，别边想边改；
- 30 天后复盘实验效果：有效 → 固化为默认习惯；无效 → 换方法，不硬撑。

## 第八步：节奏化再复盘（让闭环真正转起来）

| 频率 | 动作 | 工具 | 耗时 |
|---|---|---|---|
| 每次对话后 | 10 秒回想：这次提问哪里能更省轮次？ | — | 10 秒 |
| 每周 | 周复盘：流水账 + KISS 追问 | 模板 D | 15 分钟 |
| 每月 | 抽样 20–30 段对话做批量诊断，更新自评分数 | 模板 A + 05 自评表 | 1 小时 |
| 每学期 / 每年 | 全量画像，归档改进清单，对比上一期变化 | 模板 C | 2 小时 |

把每次结论**追加到同一个"AI 改进日志"文件**里（日期 + 本期 TOP 问题 + 实验结果），半年后回看，你会清楚看到自己提问方式的进化轨迹——这份日志本身就是最好的学习证据。

## 常见问题

- **Q：复盘 AI 会不会也讨好我、打分虚高？**
  A：模板已要求它引用你的原文作为证据、明确禁止虚高。仍不放心就让两个不同厂商的模型交叉复盘，结论一致才采信。
- **Q：对话记录太多，整理不动？**
  A：第一次只抽样最近两周的 10–20 段；用第二步的工具自动转换；先完成再完美。
- **Q：我主要用豆包，没法全量导出怎么办？**
  A：先手动导出/复制印象深的对话完成第一次复盘；今后养成两个习惯——重要对话及时导出归档，需要大规模复盘的任务优先用支持一键导出的产品。
- **Q：脱敏后 AI 看不懂上下文怎么办？**
  A：占位符保持一致（同一个人始终叫【人物B】）即可，AI 只需要理解关系和结构，不需要知道真名。
