# iPad 当手绘板 / 当摄像头

## 一、iPad 当 Windows 的手绘板(压感)

把 iPad 变成拯救者的"数位屏",Apple Pencil 直接在电脑版 Photoshop / Clip Studio Paint / Krita 里画画。

### 结论表

| 方案 | 价格 | 压感/倾斜 | 连接 | 备注 |
|---|---|---|---|---|
| **EasyCanvas**(推荐) | 内购(买断/订阅档,以 App Store 为准) | ✅ 支持压感+笔倾斜 | USB 有线 / 无线 | 韩国 devguru 出品,国内知名度最高,口碑"省一台数位屏的钱" |
| Duet Pro | 约 $6/月订阅 | ✅ 压感 | USB | Duet Display 的高档位,副屏+数位板二合一 |
| Weylus | **免费开源** | 笔输入可用 | WiFi(浏览器) | [GitHub ≈9.6k★](https://github.com/H-M-H/Weylus),Windows 侧体验不如 Linux 完善,胜在零成本 |

### 上手要点(EasyCanvas)
1. iPad App Store 搜 **EasyCanvas** 安装(订阅/内购见当期页面);
2. 电脑端按官方引导安装驱动与 PC 端程序;
3. 数据线连接后打开 PC 绘图软件,iPad 即变成液晶数位屏;
4. 在软件里把输入设备选为 EasyCanvas 虚拟数位板即可出现压感。

### 避坑
- **Astropad Studio 是 Mac 专属**,没有 Windows 版,别买错。
- **SuperDisplay 仅支持安卓平板**(网上文章常把它列进 iPad 方案,是错的)。
- 免费路线 Weylus 的 Windows 压感与跟手性明显弱于 EasyCanvas,画着玩可以,生产建议付费方案。

## 二、iPad 当 Windows 的摄像头/麦克风

网课、会议、直播时用 iPad 的高素质摄像头给拯救者当"外接摄像头"。

| 方案 | 价格 | 状态 |
|---|---|---|
| **Camo**(Reincubate) | 免费版够用(基础画质);Pro 约 $40/年解锁高分辨率/多机位 | ✅ 明确支持 iPad↔Windows,电脑端 Camo Studio 在 [Microsoft Store](https://apps.microsoft.com/detail/9pgm3qb3pdrd) 免费 |
| EpocCam(Elgato) | — | ❌ 已停售并停止一切更新,官方建议改用其硬件 Facecam |
| 连续互通相机 | — | ❌ Mac 专属,Windows 无解 |

### 上手要点(Camo)
1. iPad 装 Camo App,电脑装 Camo Studio,数据线连接(比 WiFi 稳、低延迟);
2. 在 OBS / 腾讯会议 / Teams 里把摄像头选为 **Camo** 虚拟摄像头;
3. 免费版即可用于会议;想要 4K、人像居中、多机位再考虑 Pro。

### 延伸
- 一加手机同样能给拯救者当摄像头(DroidCam / Iriun,免费更彻底),见 [02-2 文件与实用玩法](#/doc/d370)。
- 想让"摄像头画质更好"这件事一步到位:iPad 后置镜头 + Camo Pro + 落地支架,是 Windows 生态里性价比很高的会议方案。
