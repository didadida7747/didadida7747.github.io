## 一、这份资源库能帮你什么

你不需要"什么都学"，而是：**先挑 1 个主攻 + 1 个调剂，坚持 3 个月看到成果，再决定要不要扩展。**

- 🎹 你点名的 **钢琴**、📷 **摄影** 做得最详尽，可直接照着从零开始。
- 其余每个技能都给了"**分阶段路径 + 精选资源表 + 装备预算 + 避坑**"，不用再自己到处踩坑。
- 所有资源优先**免费 / 学生党可负担**，并标注了宿舍场景与西安本地落地方式。

## 三、怎么选：给"选择困难"的你

**按目标选：**
- 想**有一技之长、长期深耕** → 钢琴 / 摄影
- 想**变帅变精神、提升形象** → 健身增肌 + 穿搭护肤
- 想**社交、认识人** → 吉他弹唱 / 球类 / 摄影
- 想**做内容、搞副业** → 摄影 → 视频剪辑 → 平面设计（一条龙）
- 想**提升学业与求职竞争力** → PPT + 演讲口才 + 英语口语
- 想**减压、独处充电** → 钢琴 / 书法 / 跑步 / 绘画
- 想**走出去、探索西安** → 摄影 + 露营徒步骑行

**推荐组合（个人建议）：**
- 🌙 晚间宿舍：钢琴（耳机）/ 书法 / 手账
- ☀️ 白天户外：摄影 / 跑步 / 骑行
- 🧊 寒假集中突破：视频剪辑 / 英语口语 / 板绘

## 四、如何使用本资源库

1. **从 README 选 1 个主攻技能**，点进对应 md。
2. 先看「**适合谁 & 投入成本**」和「**装备入门建议**」，确认门槛能接受。
3. 按「**分阶段学习路径**」走，**只收藏不练 = 没学**；每个 md 末尾有「本周就能做」的快速开始。
4. 资源表里的 B站/抖音/小红书内容，**直接搜名称即可找到**；GitHub 资源按"所有者/仓库名"搜索。
5. 学一段就**产出作品**（弹会一首曲子 / 拍一组照片 / 剪一条视频），作品是坚持下去的正反馈。
6. 本地社团、场地、机位等信息，标注"建议自行核实"的，请到**学校社团招新、官方公众号、地图 App**确认最新情况。
7. 想新增或改写技能文档时，先读 `_模板与规范/编写规范与模板.md`（统一结构与自查清单）。

## 五、通用学习原则（适用于所有技能）

- **先完成再完美**：别在"买什么装备"上纠结一周，先用手头的东西开始。
- **每天 20 分钟 > 周末 3 小时**：技能靠高频重复，宿舍场景尤其适合碎片化。
- **跟一个体系走到底**：入门阶段别同时看好几个 UP主，选一个跟完再博采众长。
- **用作品驱动**：定一个小目标（期末弹会一首、月底出 9 张图），倒推练习。
- **加入社群**：社团、约拍、约球、乐队——同伴是最强的坚持动力。
