## 🎯 学习路线建议

### 计算机/电子信息专业（本校推荐）💻

1. **编程基础**：B站翁恺C语言 → 侯捷C++ → 嵩天Python
2. **计算机基础**：李治军操作系统 → 计算机网络（B站搜索）→ 数据结构
3. **AI/机器学习**：李沐深度学习 → 吴恩达Machine Learning → 五道口纳什LLM
4. **项目实战**：GitHub项目 → LeetCode刷题 → 参加竞赛

### 英语提升

1. **听力**：英文播客（Hidden Brain/Planet Money）→ TED演讲 → 美剧
2. **口语**：英语流利说 → 跟读TED → 找语伴
3. **词汇**：墨墨背单词 → 阅读外刊
4. **阅读**：The Economist → 英文原版书

### 通用技能

1. **PPT/Excel**：B站旁门左道PPT → 实战练习
2. **视频剪辑**：B站欧鹰李老师 → 剪映/PR实操
3. **写作**：阅读优秀文章 → 刻意练习 → 知乎/公众号输出
4. **演讲**：TED模仿 → 录音复盘 → 抓住机会上台

## 💡 学习小贴士

1. **免费优先**：先利用国家高等教育智慧教育平台、B站、Khan Academy等免费资源
2. **系统学习**：选一门课跟到底，比收藏100门课有用
3. **做笔记**：用Notion/飞书/印象笔记整理学习笔记
4. **实践输出**：学完就用，写博客、做项目、教别人
5. **碎片时间**：通勤听播客/有声书，排队背单词
6. **整块时间**：周末用2-3小时系统学习难的内容
7. **不要贪多**：一次专注1-2个学习目标，完成再开新的
8. **利用证书**：Coursera/中国大学MOOC的证书可以写进简历
