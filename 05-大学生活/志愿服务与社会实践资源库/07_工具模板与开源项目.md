# 07 · 工具模板与开源项目

> 动手层:做问卷、写报告、出海报、管团队,以及——**用你的专业给公益做工具**(电子信息学生最被低估的志愿嫁接点)。2026-10-06 检索/核实。

## 1. 调研与问卷工具

| 工具 | 链接 | 特点 | 核实状态 |
|---|---|---|---|
| 问卷星 | [wjx.cn](https://www.wjx.cn/) | 高校实践队最常用;官方整理过社会实践常用调研模板,选题到数据分析可套用 | 检索确认 |
| 腾讯问卷 | [wj.qq.com](https://wj.qq.com/) | 支持 AI 生成问卷与 AI 报告、Excel 导入、模板库 | 检索确认 |
| 调研家 SurveyPlus | 站内搜索"调研家" | 免费档友好,企业级模板 | 仅元数据 |
| Canva 可画 | 站内搜索"Canva 可画" | 调研问卷、海报、报告配图模板 | 仅元数据 |

**推荐流程**:选题 → 腾讯问卷 AI 起草 → 人工改题项 → 线上发放+线下走访 → 平台自带统计 → 按模板写报告。

## 2. 调研报告与实践报告写作

- **官方范文库**:[三下乡官网·实践报告厅](https://sxx.youth.cn/)——历年全国团队的真实调研报告(如留守儿童"童伴计划"、离校未就业群体 1052 次入户调查等),先读 3 篇同类范文再动笔。已核实。
- **通用结构**(多来源通行):题目 → 摘要 → 前言(背景与目的) → 正文(调研背景/方法/数据分析/结论) → 结束语 → 参考文献 → 附件。
- **写作红线**:数据要真实可溯,问卷样本量、访谈人次如实写;编数据在推免政审与评优审查里是致命伤(红线分析见[08](/05-大学生活/志愿服务与社会实践资源库/08_避坑安全与伦理))。

## 3. GitHub 开源项目(给公益做工具=专业志愿)

| 仓库 | 链接 | 是什么 | 对你的价值 | 核实状态 |
|---|---|---|---|---|
| FederationOfTech/Coalesce | [github.com/FederationOfTech/Coalesce](https://github.com/FederationOfTech/Coalesce) | 100% 开源志愿者管理平台:招募、onboarding、管理一体化 | 学架构;给校内青协搭轻量版就是作品集项目 | 仅元数据 |
| raoufswe/VolunteerPoint | [github.com/raoufswe/VolunteerPoint](https://github.com/raoufswe/VolunteerPoint) | 志愿者与组织方匹配的 Web 应用 | 同上 | 仅元数据 |
| andreacanton/volunteer-hub | [github.com/andreacanton/volunteer-hub](https://github.com/andreacanton/volunteer-hub) | 公益服务出勤/签到管理 | 小而精,适合改造后给社区用 | 仅元数据 |
| SourceForge: Volunteer Management | [sourceforge.net](https://sourceforge.net/) 搜"volunteer management" | PHP/MySQL 工时与岗位追踪老系统 | 历史参考 | 仅元数据 |

**专业嫁接的具体路径**(电子信息学生专属):
1. 给结对社区搭"银发数字课堂"预约与签到小程序(课程表、报名、志愿时长联动);
2. 给校青协做志愿活动扫码签到工具(对接志愿汇的人工签到做辅助台账);
3. 给公益组织做数据看板(捐赠、受助人、项目进展可视化)。
这三类都是"公益+技术"双重叙事,比刷榜式的课程设计值钱得多;作品集方法见[04-阅历与实践·动手项目](/05-大学生活/大学生活规划指南/04-阅历与实践)。

## 4. 团队协作小工具箱

- 文档协作:腾讯文档/飞书(实践队共享台账、物资清单);
- 物资清单模板:站内搜"三下乡 物资清单"取高校公开模板,按"证件/药品/教学/生活"四类打勾;
- 纪实素材:照片按"天-场景"命名当天归档,新闻稿与结项材料直接取用。
