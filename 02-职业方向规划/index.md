## 二、当前方向结论

- **后端为基本盘**：岗位最多、需求最稳，是就业的安全垫（Python + Go 双语言）。
- **AI 应用做差异化**：大模型应用开发（RAG / Agent / AIGC 工程化 / LLM 后端）本科友好，是主攻点。
- **算法岗**：核心岗多需读研，本科不作主投。
- **AI Infra**：人才紧缺，但需 C++ / CUDA 硬功底，作为进阶选项。
