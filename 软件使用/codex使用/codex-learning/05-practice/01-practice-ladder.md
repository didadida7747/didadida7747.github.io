# 练习阶梯

目标：每次练一个能力点，不把学习变成“大而空的项目”。

## Level 1：只读理解

任务：

- 让 Codex 读当前项目。
- 输出项目结构、运行命令、风险文件。
- 不允许修改。

验收：

- 是否引用具体文件。
- 是否识别项目真实用途。
- 是否承认不确定项。

## Level 2：文档小改

任务：

- 改 README。
- 增加安装/启动说明。
- 修正文档路径。

验收：

- diff 很小。
- 没有修改代码。
- 中文清晰、路径准确。

## Level 3：静态网页

任务：

- 建一个简单 HTML/CSS 页面。
- 或优化已有页面的标题、布局、按钮。

验收：

- 能在浏览器打开。
- 移动端不重叠。
- 没有多余依赖。
- 视觉不是模板味。

## Level 4：脚本改进

任务：

- 给已有脚本增加 `--help`。
- 改错误提示。
- 增加日志或输入校验。

验收：

- 运行命令有输出。
- 错误输入被处理。
- 不破坏原有功能。

## Level 5：修复可复现 bug

任务：

- 给出 bug 现象和复现步骤。
- 让 Codex 先定位，再修。

验收：

- 修复只涉及必要文件。
- 有测试或最小复现验证。
- 总结里说明根因。

## Level 6：补测试

任务：

- 找一个小函数或模块。
- 让 Codex 参考现有测试风格补测试。

验收：

- 覆盖正常、异常、边界。
- 测试能跑。
- 没有为了测试而改业务逻辑。

## Level 7：真实仓库小功能

任务：

- 新增一个设置项、导出按钮、筛选项或小页面。
- 只做一个模块。

验收：

- 有计划。
- 有 diff。
- 有测试/构建。
- 有提交说明。

## Level 8：进阶沉淀

任务：

- 生成 `AGENTS.md`。
- 把一个重复流程做成 Skill。
- 给项目接一个低风险 MCP。

验收：

- 新规则能被下一次任务复用。
- 权限范围清楚。
- 能说明什么时候不该用。
