# 特殊人群用药:儿童、孕产妇、老人、司机、运动人群,各有各的规则

> 一句话定位:梳理儿童、孕产妇、老年人、肝肾功能不全者、驾驶员/高空作业者、运动人群的用药要点与禁忌,并教你如何帮父母管理慢病用药。
>
> ⚠️ 免责声明:本文为科普整理,不构成医疗建议;具体诊疗与用药请遵医嘱/咨询药师;出现急重症立即拨打 120。

---

## 🎯 核心速览(TL;DR)

1. **儿童不是缩小版成人**:剂量多按体重/年龄计算,部分药物儿童禁用;退热首选对乙酰氨基酚(≥2~3 月龄)或布洛芬(≥6 月龄)的儿童剂型。
2. **儿童禁用/慎用示例**:尼美舒利口服制剂禁止用于 12 岁以下儿童(国家药监局规定);病毒感染期儿童慎用/避免阿司匹林(瑞氏综合征风险);喹诺酮类(诺氟沙星等)一般 18 岁以下避免使用(影响软骨发育,以说明书为准)。
3. **低龄儿童别随手用复方感冒药**:成分多、剂量难控,优先单一成分、儿童专用剂型;**药品绝不放饮料瓶里**,防止当饮料误喝。
4. **孕产妇:**备孕/怀孕/哺乳,看病先说"我在备孕/怀孕/哺乳";任何药(含中药、保健品)用前问医生;孕期最敏感是孕早期(约 3~12 周)。
5. **老年人:**同时吃 5 种及以上药即"多重用药",跌倒、低血压、低血糖风险升高;定期带全部药盒(含保健品)复诊,请医生/药师"清点做减法";肾功能减退常需调剂量。
6. **驾驶员/高空作业:**吃了含氯苯那敏(扑尔敏)的感冒药、抗过敏药、安眠药、部分降压药降糖药后,易嗜睡——"药驾"危险,国家药监局已发布相关警示。
7. **运动人群:**含麻黄碱类成分的感冒药 + 剧烈运动,心率血压升高、风险加大;哮喘吸入剂(如沙丁胺醇类急救吸入剂)属合规治疗用药,该带就带,别硬扛。
8. **帮父母管药:**一个分药盒 + 一张"用药清单表" + 复诊时全部药盒拍照,三件套解决 90% 的乱。

## 一、儿童用药

### 1.1 基本原则

- **剂量按体重/年龄算**:说明书上"儿童用量"一栏通常是"每公斤体重 × 每日剂量"或按年龄段给;用自带的量杯、滴管、专用量勺,别用家里吃饭的勺子估。
- **优先儿童专用剂型**:混悬液、滴剂、颗粒剂,便于按体重取量。
- **一个原则:儿童用药不确定就问医生/药师,不凭经验和"上次剩的药"。**

### 1.2 儿童禁用/慎用药物(常见示例)

| 药物 | 结论 | 原因 |
|---|---|---|
| **尼美舒利**(口服退热药) | **12 岁以下儿童禁用**(国家药监局规定) | 严重肝损害等风险(曾有"退烧药事件") |
| **阿司匹林/赖氨匹林**(退热) | 病毒感染(流感、水痘等)时儿童避免使用,低龄儿慎用 | **瑞氏综合征**风险(急性脑病 + 肝脂肪变性);例外:川崎病等必须医生指导使用 |
| **喹诺酮类**(诺氟沙星、左氧氟沙星等) | 一般 18 岁以下避免使用(以各药说明书为准) | 动物实验提示影响软骨发育 |
| **含可待因的止咳药** | 12 岁以下儿童禁用(国家药监局规定,部分更严格) | 呼吸抑制、成瘾风险 |
| 低龄儿童**复方感冒药** | 婴幼儿尤其不推荐自行使用 | 成分叠加、剂量风险;多数指南建议 6 岁以下儿童用药前咨询医生 |
| 成人剂型"减半" | ❌ 禁止 | 剂量不是"减半"这么算的 |

> 补充示例(以说明书为准):阿苯达唑(驱虫药)2 岁以下禁用。儿童退热:对乙酰氨基酚一般适用于 ≥2~3 月龄,布洛芬一般 ≥6 月龄——月龄不足或体重过低者必须就医。

### 1.3 防误食:儿童药物中毒的头号原因就是"自己拿到的"

- 药品**不放饮料瓶、零食罐**,不用"这是糖"来哄孩子吃药(孩子会记住"药=糖")。
- 药箱放高处 + 上锁;访客的包(里面有药)也要放高处。
- 万一误食:带上药瓶/残留物**立即就医或拨打 120**,不要等症状、不要自行催吐。

### 1.4 就医红线

- 3 个月以下婴儿发热,直接就医(不自行退热)。
- 高热不退超过 3 天、精神差/嗜睡/抽搐、呼吸急促、尿量明显减少、皮疹不退——就医。

## 二、孕产妇用药

### 2.1 总原则:不是"绝对不能吃药",而是"不能瞎吃药"

- **备孕/已孕/哺乳,是任何就诊时的第一句话**:看牙、开感冒药、打疫苗之前,先告知状态。
- 孕早期(约受精后 3~12 周)是器官形成期,对致畸因素最敏感;孕中晚期用药影响相对不同,但不等于随便。
- **不该吃的硬扛着、该治的病不治,同样伤母婴**:如孕期感染、妊娠高血压、妊娠糖尿病不治疗,风险可能远大于规范用药。

### 2.2 分级知识:一眼看懂"孕期用药分级"

国际上曾广泛使用 FDA 的 A/B/C/D/X 五级分类(现已逐步被更细化的标签规则取代,但国内资料和药品说明书仍常见,值得了解):

| 级别 | 含义 | 通俗理解 |
|---|---|---|
| A | 有对照研究证实孕期使用安全 | 最放心 |
| B | 动物实验未见危害/人体未证实危害 | 相对安全,常用(如多数指南认为对乙酰氨基酚相对安全的定位即属此类层面的参考) |
| C | 动物实验有不良影响,缺人体证据 | 利大于弊时才用,须医生评估 |
| D | 人体证据显示有危害 | 危急重症、无替代时才用 |
| X | 已证实致畸/危害 | **孕期禁用**(如部分维A酸类、沙利度胺等) |

> 注意:分级不是唯一标准,孕周、剂量、个体情况都会影响判断——**结论永远是"问产科医生/药师"**。

### 2.3 高频场景要点

| 场景 | 要点 |
|---|---|
| 备孕 | 按医嘱补充**叶酸**(通常建议孕前 3 个月开始至孕早期,剂量遵医嘱);戒烟酒;把正在吃的药告诉医生评估 |
| 孕期感冒/发烧 | 先物理降温+就医评估;高热本身对胎儿不利,该用退热时医生会选相对安全的方案,不自行买复方感冒药 |
| 孕期止痛/其他 | 阿司匹林及多数 NSAID 在孕晚期禁用/慎用;任何止痛药先问医生 |
| 哺乳期 | 药物可经乳汁分泌;就诊说明哺乳,医生会选乳汁分泌少、婴儿暴露低的药;哺乳后服药、间隔下次哺乳是常见做法,具体遵医嘱 |
| 中药/保健品 | "天然"不等于安全,部分中药孕期禁用;同样需要告知医生 |

## 三、老年人用药

### 3.1 最大风险:多重用药

- **同时服用 5 种及以上药物即视为"多重用药"**(业界通行定义):老人辗转多个科室看病、亲友互相推荐药、再加上保健品,很容易攒出一大把。
- 风险:药物相互作用、跌倒、低血压、低血糖、意识模糊、肝肾负担——"药源性伤害"本身就是老年人的常见病。
- 解法不是"记住每种药",而是**定期请专业人员清点**。

### 3.2 老年人用药四原则

1. **能少则少**:定期复诊时把所有药(含中药、保健品)摆在医生/药师面前,问三个问题——"这个还在需要吗?这个和那个冲突吗?这个剂量要不要减?"
2. **从低剂量起**:很多药物老年人需"低起始、慢加量"(如部分降压药、安眠药),肾功能减退者多数经肾排泄药物需调减剂量——这必须由医生决定。
3. **防跌倒设计**:安眠药、部分降压药、降糖药容易引起头晕跌倒,提醒老人起床遵循"醒后躺半分钟、坐半分钟、站半分钟再走"。
4. **不自行停药也不自行加药**:尤其是降压药、抗凝药、抗癫痫药,突然停药可能诱发反跳或更危险的事件。

### 3.3 帮父母管理慢病用药:三件套

| 工具 | 做法 |
|---|---|
| **分药盒(7 天 × 早中晚)** | 每周日晚按医嘱分好一周的药;老人只需"按格吃",不必每天对药盒研究 |
| **用药清单表**(一张纸/手机备忘录) | 列:药名、剂量、服药时间、开给哪个病、开药医生;贴冰箱上,复诊时带上 |
| **复诊带全部药盒(或拍照)** | 空盒、正在吃的、保健品、中药全部带上;医生/药师清点后做"减法" |

> 👨‍👩‍👧 大学生能做的:寒假回家帮父母做一次"药盒大清点";帮他们把散装药、过期药、亲友推荐的"三无药"分离出来;教会用手机设置服药闹钟。

## 四、肝肾功能不全者

- **肝功能不全**(如慢性乙肝、脂肪肝、长期饮酒者):很多药经肝代谢,用药种类和剂量需医生重新评估;**对乙酰氨基酚过量最伤肝**,肝病患者使用前务必咨询医生;自行叠加"保肝偏方"反而可能伤肝。
- **肾功能不全**(如慢性肾病、糖尿病肾病):经肾排泄的药物(部分抗生素、降糖药、止痛药等)易蓄积中毒,剂量需按肾功能调整;造影检查、某些止痛药(长期用 NSAID 类)都可能加重肾损伤,均需医生权衡。
- 通用做法:**就诊主动说明肝/肾病史;所有长期用药定期复查肝肾功能;不自行购药加药。**

## 五、驾驶员与高空作业者:警惕"药驾"

### 5.1 哪些药吃了会"困"

常见引起嗜睡、注意力下降的药物(以说明书为准):

| 类别 | 常见示例 |
|---|---|
| 一代抗组胺药(抗过敏) | **氯苯那敏(扑尔敏)**、苯海拉明 |
| 含氯苯那敏的**复方感冒药** | 常见感冒灵类、"夜片"等 |
| 镇静催眠药 | 地西泮、唑吡坦类等(处方药) |
| 部分抗癫痫/抗抑郁药 | 医嘱管理 |
| 部分降压药 | 个别人服后头晕 |
| 降糖药 | 低血糖发作时无法专注驾驶 |

国家药监局已就含马来酸氯苯那敏的药物发出嗜睡警示(2026 年报道其纳入"药驾"相关警示范围),世卫组织也列出过影响驾驶能力的七大类药物。

### 5.2 实操建议

- 说明书"注意事项"出现"服药期间不得驾驶机、车、船、从事高空作业、机械作业"字样的,**服药后至少 6 小时内不上路**(以说明书为准,部分药物更久)。
- 考试周、军训、需要长时间开车/骑车通勤的人,买感冒药、抗过敏药时主动告诉药师:"我白天要上课/开车,要不含嗜睡成分的"(如第二代抗组胺药氯雷他定、西替利嗪,嗜睡发生率较低)。
- 第一次吃某种新药,不确定是否犯困:先在自己安全的环境试一次,再决定是否骑车/开车。

## 六、运动人群(大学生高频场景)

| 场景 | 要点 |
|---|---|
| **感冒了还想打球/跑步** | 感冒本身 + 剧烈运动有心肌炎等风险(病毒感染后剧烈运动是诱因之一,医学上普遍建议感染期休息);若吃的复方感冒药含**麻黄碱类成分**(收缩血管缓解鼻塞,如伪麻黄碱),会升高心率血压,叠加运动风险更大——病中不运动,是省命的懒 |
| **哮喘学生** | 哮喘急救/控制吸入剂(如短效β2受体激动剂急救吸入剂)是**合规治疗用药**,不是"兴奋剂";随身携带、按医嘱使用;运动会前可按医生建议预防性使用;同学看到有人用吸入剂,正常对待 |
| **健身人群** | 不买"运动员专用""增肌神药"来路不明的补剂/药丸(可能含禁药成分或伤肝伤肾);止痛药遮痛继续练,容易把小伤练成大伤 |
| **体测/考试** | 不靠"考前吃药提神"(含咖啡因/麻黄碱类)硬顶;心脏不适立即停止运动就医 |

## ⚠️ 常见误区

- **误区:给孩子吃成人药,掰半片/减半量就行。** → 真相:儿童剂量按体重,有些药儿童根本禁用(尼美舒利、阿司匹林退热等);请备儿童剂型并遵说明书/医嘱。
- **误区:孕妇不能吃药,硬扛对胎儿最好。** → 真相:该治的病不治(高热、感染、妊娠高血压等)同样伤害母婴;正确姿势是"告知医生 + 规范治疗"。
- **误区:老人吃很多种药是"保养"。** → 真相:5 种以上即多重用药,跌倒、低血压、低血糖、肝肾功能受损风险显著升高;要定期请医生/药师"做减法"。
- **误区:吃安眠药/感冒药后开车,只要"感觉不困"就行。** → 真相:主观感觉不可靠,反应速度已下降;以说明书警示为准。
- **误区:哮喘吸入剂是激素/兴奋剂,能不用就不用。** → 真相:吸入剂是哮喘规范治疗的核心,剂量小、局部作用,该用不用反而危险;急性发作时的急救吸入剂能救命。
- **误区:给父母买一堆保健品就是孝顺。** → 真相:保健品与多种药物有相互作用风险,还会加重"多重用药";带他们去正规复诊比买补剂有用得多。

## ✅ 行动清单

- [ ] 家里有娃的:检查退热药是否为儿童专用剂型;把阿司匹林、尼美舒利类从儿童可及范围移走
- [ ] 检查家里药品是否放在饮料瓶/食品罐里,立即换回原包装
- [ ] 给家里 12 岁以下的娃和 18 岁以下的弟弟妹妹列一张"禁用药"贴纸贴在药箱内
- [ ] 备孕/家中有备孕者:确认叶酸补充计划(遵医嘱)并在任何就诊时主动说明备孕状态
- [ ] 寒假/假期回家:帮父母整理一张"用药清单表" + 配一个 7 天分药盒
- [ ] 下次复诊提醒父母:**带上所有药盒(含保健品)或全部拍照**
- [ ] 自己下次买感冒药时对药师说:"我白天要上课/骑车,要不含嗜睡成分的"
- [ ] 有哮喘/过敏性疾病的同学:确认急救药随身带,并让室友/家人知道放在哪
