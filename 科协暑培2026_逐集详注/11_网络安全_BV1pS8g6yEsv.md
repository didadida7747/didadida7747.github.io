## 知识整理

### 战队背景与黑客祛魅

清华学生网络安全技术协会两支主力竞赛队伍：Redbud（今年拿下新加坡 Grey Cat The Flag CTF 总决赛冠军）与蓝莲花 Blue Lotus（历史更悠久，国内第一支打 CTF 的战队，也是华人世界首支闯入 DEF CON CTF 全球总决赛的战队）。

影视和游戏里"黑色卫衣 + 绿色字符几秒攻破系统"是戏剧化加工；安全从业者日常与普通 CS 学生无异，只是思考的是"如何找到系统漏洞"而非"如何建系统"。CTF 起源于 Jeff Moss 1993 年举办的黑客派对，后演变为年度大会 DEF CON；早期赛制不明晰、大家互相攻防，后分化出解题赛（Jeopardy）、攻防模式 AWD、real-world 赛制、AWDP（静态环境中做攻防对抗）等。CTF 没有黄金年龄，40 多岁还在打的选手很多。

### 攻防环节与团队分工

一场攻防四大主题：代码分析（逆向服务代码、理解防护策略）、漏洞利用（写 exploit 攻击别队服务拿 flag）、防御（修漏洞、检测并移除后门木马）、流量分析（抓对手攻击自己机器的流量快速定位漏洞）。flag 是本地受保护的机密信息，拿到它即证明能控制服务器；除利用漏洞外还可植入后门持续拿 flag。团队分工被类比成足球队：有人当中卫负责加固与修补，有人盯流量日志，有人专司逆向挖掘，主攻手把漏洞转化为可用的攻击脚本。

### Web 安全例题：从明文密码到 SQL 注入

网站登录本质是查表，演变为数据库后用 SQL 查询。案例代码用 MD5 存密码——引出 2011 年 CSDN 明文密码泄露事件：攻击者拿到库后可"撞库"登录用户其他网站账号，因此必须用单向哈希函数散列存储。

但代码仍有更严重问题：SQL 用单引号包裹数据区分指令与值，输入单引号即可逃逸，配合 `#` 注释（类似 C++ 双斜线）截断后半句，构造 `or 1=1` 恒真条件即成"万能密码"，无需知道密码就能登录。停车场摄像头把"车牌+单引号"识别入库清空数据库的梗图说明此类攻击曾真实流行；如今因安全开发意识与法规完善已少见，但自研时仍须警惕。

### CTF 五大方向地图

- **Web**：除 SQL 注入外还研究浏览器、服务器间中间件安全，本质是"让网站做本不允许你做的事"。
- **Pwn**：来自拟声词"砰的一声程序被干掉了"，研究二进制漏洞，涉及内存、寄存器、栈、堆，目标是控制程序执行流；典型问题有栈溢出、格式化字符串、UAF、整数溢出。
- **Crypto**：偏数学，研究 MD5、SHA-256 等算法实现弱点，需学哈希、分组/流密码、对称/非对称密码。
- **RE（Reverse）**：在没有源码时搞清二进制程序行为、找出后门或隐藏 flag，做控制流与数据流分析。
- **Misc**：大杂烩，考快速学习能力——图片/视频隐写还原、流量分析（如把 USB 鼠标流量还原成轨迹图）、残缺二维码补全、游戏自动化刷分等极客创意。

### LLM 冲击下还要不要学基础

今年 R0CTF（存疑）鼓励人机协同，有选手直接并行开 8 个 Claude Code 解题，CTF 似乎变成"给大模型一句话要 flag"。讲者的态度分两面：类比以往自动化工具（IDA Pro 企业级反编译、集成漏洞扫描的 Burp Suite）曾被贬为"脚本小子"，自动化确实扩大搜索范围、释放生产力，"什么好用用什么"是合理一面；但**"最危险的并不是我们不去用 AI，而是我不需要知道这个原理是什么"**。前沿安全模型也会偷懒走捷径，甚至谎报 flag——"没基础就看不出被敷衍，无法引导方向、看不懂输出就只能乱选，AI 系统无法迭代"，所以 2026 年仍必须学领域基础。

### 前大模型时代的自动化攻防：CGC

2016 年 DARPA 举办 Cyber Grand Challenge，是全机器自动 CTF（自动分析程序、发现漏洞、生成利用并自动修补），技术路线为 fuzzing + 静态程序分析 + 自动修复。具体方法：fuzzing 不断变异输入直到程序崩溃；污点分析追踪不可信用户输入是否流向危险操作（如登录 SQL 语句）；符号执行把输入变成符号变量求解可达路径；形式化验证在数学上证明协议或密码实现满足规约。

### LLM×安全的三阶段演进

- **2023 年**（ChatGPT 2022 年底上线后）：大模型凭通用代码知识增强传统工具——用语义识别找危险输入源/危险 API 再交给污点分析、符号执行工具，或生成 fuzzing 代码；当时上下文窗口仅 64K/128K 且幻觉严重，LLM 只负责文本、外部工具负责验证。
- **2024 年**：长上下文、推理、代码能力成熟。DARPA 年中办 AIxCC 初赛：一派把 agent 接入人工设计的传统分析工作流；另一派不预设工作流、给 agent 配代码浏览器、沙箱环境和调试器，让其自主形成假设-验证-探索闭环——AI 从工作流的一部分变成驱动完整漏洞研究闭环的主体。
- **2025 年**：LLM 自主调度整个漏洞发现流程渐成主流，agent 演化为"规划-行动-反馈-修正"的长期任务执行系统；安全研究人员开始用 multi-agent 架构：主控 agent 调度子 agent 拆分数万行代码的任务、做上下文隔离压缩与并行探索。

现状：网络安全正成为大模型厂商押注的方向；训练安全能力强的模型仍依赖人类专家的高质量数据，而专家也在用大模型解放生产力——安全范式处于快速变革中。最后是招新：暑培网站每个方向都有训练题目。
