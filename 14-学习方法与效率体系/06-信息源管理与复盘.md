# 06 · 信息源管理与复盘

> 两件事：**管好流进脑子的信息**（信息饮食——垃圾信息多吃也会"肥胖"），**管好流出去的总结**（复盘——不做复盘，经验不会变成能力）。

---

## 一、信息饮食原则

1. **定源不漫游**：信息来源固定为几张清单（下表），新来源先挂"观察名单"一个月再转正；
2. **定时定量**：资讯集中在每天一个时段（如晚饭后 20 分钟），其余时间关推送；
3. **摄入分层**：每天 1 篇深读 > 刷 50 条标题；收藏夹每周清空一次（读掉或删除）；
4. **区分三类信息**：**决策类**（影响行动，如 DDL/政策）→ 当天处理；**认知类**（长知识）→ 进笔记；**娱乐类** → 只去 06_闲翻杂读，不上主力时间。

## 四、稍后读的正确用法

工具任选（浏览器书签夹/滴答清单" someday"列表/Folo 收藏），关键是**流程**：
```
刷到 → 一句话写进清单（标题+为什么想读）→ 每周日清空：读掉或删掉
```
> 禁止"直接收藏不写理由"——两周后你不会记得为什么收藏它。

## 五、复盘模板（即拷即用）

### 周复盘（每周日 15 分钟，与 GTD 回顾合并）
```md
## 本周复盘 YYYY-Www
### 1. 三条主线各自推进了吗（√/× + 一句话）
- 绩点： 
- 自学/项目：
- 六级：
### 2. 本周做对的一件事（复制它）
### 3. 本周卡住的一件事（原因 + 下周的具体改法）
### 4. 时间花销对账：学习/娱乐/睡眠 大致比例，符合预期吗
### 5. 下周三个最重要结果（Outcomes，不是任务清单）
```

### 学期复盘（每学期末 1 小时，配合 05库 的四年手册）
```md
## 学期复盘 2026-2027-1
1. 硬指标：绩点/六级/竞赛/项目 各项实际 vs 目标
2. 方向校准：这学期的新信息是否改变求职/深造判断
3. 保留：下学期继续做的 3 件事
4. 停止：这学期证明无效的 2 件事
5. 新增：下学期新增的 1 件事（只允许 1 件，防摊薄）
```

> 复盘的输出直接对接 [`05库-大学四年自我提升全景手册`](#/doc/d098)（每学期末复盘）与 [`03库-求职作战追踪表`](#/doc/d072)。
