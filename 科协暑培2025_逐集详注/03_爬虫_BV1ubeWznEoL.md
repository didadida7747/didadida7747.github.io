# 2025科协暑培 · 爬虫（赵光烨, BV1ubeWznEoL, 约 45 分钟）

## 定位

三讲的收尾实践讲，用 Python 以网易云音乐飙升榜为案例讲爬虫：原理与合规 → 基础版/进阶版实爬 → 高级技术与反反爬。需要 01 讲的 Python 基础；听过 02 讲 Web 基础再看动态加载与 API 部分事半功倍。方法论与工程建议密度高，适合完整听。

## 内容脉络

- [00:04] 开场：讲师来自 G3 字班（转写"G3期"），大一小学期 Python 大作业即写爬虫 + Django（转写"jungle"）建网页；Python 对爬虫的支持比 C++/Java/JS 最全面。
- [00:31] 爬虫定义：自动化程序，模拟人类浏览——发 HTTP 请求 → 解析提取 → 批量存储；应用含搜索引擎、数据分析、市场调研、内容聚合与樱花动漫这类免费影视站。
- [01:27] robots.txt：网址后加 /robots.txt 查看；以 B 站为例分三部分——全体爬虫禁入路径、允许的搜索引擎/官方爬虫、其余一律不允许；技术上无法彻底阻止爬虫，故更像君子协定，但抓视频商用或侵权可能封 IP，樱花动漫经营者甚至被抓（新闻细节，存疑）。
- [04:20] 工作流程：发请求（构造 User-Agent/Cookie、选 GET/POST）→ 收响应（状态码 200/404/500）→ 解析（HTML 用 DOM 解析器得树状结构；JSON/XML 类似键值对字典）→ 提取（CSS 选择器/XPath 定位、正则匹配文本）→ 清洗 → 存储（CSV/JSON/TXT 或数据库）→ 发现新链接入待爬队列、去重后循环。
- [07:38] 四大核心组件：HTTP 客户端（requests 发请求，session 维持登录态、代理池、重试机制）；HTML 解析器（BeautifulSoup、lxml）；数据提取器（结构化表格/JSON、非结构化文章评论、时间戳作者等元数据）；存储引擎（文件→缓存二进制→数据库，规模越大越结构化）。
- [10:29] 案例开始（网易云飙升榜）：目标爬歌曲列表与评论，分基础/进阶/高级三版。
- [12:24] 基础版 base.py vs base_cookie.py：区别仅带不带 Cookie；带 Cookie 的返回里有用户 id/名称/头像——有的网站凭 Cookie 即视为已登录给更多内容，但网易云此处行数与数据几乎一样。
- [14:17] 基础版天花板：未登录看不到评论（显示 0 条）；更关键的是评论为动态加载——初始 HTML 里根本没有，F12 在 Elements 里能看到是因为浏览器后来执行 JS 插入。全讲最核心概念。
- [16:33] 基础版仍有用：能拿到排行榜 100 首歌名 + 相对路径网址，与 music.163.com 拼接即得详情页。
- [18:30] 进阶版（pro_music.py）：不爬肉眼页面，改访问网站 API 接口直接拿 JSON；API 涉及请求参数（数量上限、详情级别）与返回参数，评论 API 还有密钥加密。
- [20:26] 进阶版收益：一个 URL 一次拿到 100 首歌的名字/id/排名/创作者/专辑/时长毫秒/热度/发布时间；基础版则要访问 100 次详情页。
- [21:51] API 地址怎么找：此接口是问 AI 得知的，网上不好查；通用方法见下。
- [23:15] F12 抓 API 实操：Network 面板筛选 comment 刷新页面，点开请求看 Headers 的 request URL（尾部是安全验证参数），知道请求参数 + 过安全验证即可拿 response 里的评论；response 末尾是热门评论，与页面内容对得上。
- [25:40] Cookie 两种获取法：Network 主请求 Headers 里直接复制；或 Application 面板 Cookies 分类查看，更整洁。
- [27:38] 翻页与 limit：改 pro_comment.py 的 limit 值控制抓多少条评论（示例约 100 条最新评论，翻到第六页）。
- [29:10] 题外话——方法论：不会写就问会写的同学或问 AI，把需求写清楚，数百行级代码 AI 能成熟完成；讲师习惯让 AI 打框架再自己删改、多轮交流修错。
- [30:10] 高级技术一——浏览器自动化：Selenium + WebDriver 控制真实浏览器模拟滚动/点击/拖拽，能执行 JS 处理动态加载；适用 SPA 单页应用与重度依赖 Ajax 的网站；headless 模式用于无图形界面的 Linux 服务器。注意：网易云登录验证极严（二维码→密码→滑块→短信），高级版讲师没能写出可用演示代码，但鼓励尝试。
- [32:01] 高级技术二——反反爬：User-Agent 轮换（组合多个 UA 随机切换模拟不同设备）；请求头伪造——把 F12 看到的 headers 抄全，让服务器以为是真人。
- [33:25] 高级技术三至八：Cookie/Session 管理维护登录态、处理 CSRF 令牌与过期更新；验证码处理（图像识别应对文字/点选，行为验证应对滑动/拼图）；分布式爬虫（主控节点任务队列分发、负载均衡、故障转移与健康检查）；代理 IP 池（轮换避免单 IP 高频被封）；数据管道优化（哈希/时间戳增量去重、异常数据清洗标准化——讲师把每歌五六十行原始 JSON 精简到十来行）；风控（随机休眠 1~2 秒、指数退避、按响应时间自适应，监控 IP 被封与验证码增多）。概念罗列无代码演示，⏭️可跳过（实践中用到再回来查）。
- [40:36] 使用建议：先看 robots.txt，无法确定是否侵权就别做；哪怕允许爬也要控频率；善用 AI，不必强求从零手写。
- [42:54] 结尾案例：GitHub 开源项目 NeteaseCloudMusicApi 收集了网易云各类 API，后因网易发法律通知（项目虽开源非盈利但被人用于侵权）停止维护并删库——呼应合规主题；讲师推崇开源，鼓励爬感兴趣的数据做分析、开源成自己的项目。
