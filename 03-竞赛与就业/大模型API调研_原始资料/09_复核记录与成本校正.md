## 一、复核方法与可信度说明（必读）

- 复核方式：派 Haiku 子代理用 WebFetch 读取官方页面。**WebFetch 返回的是小模型整理后的摘要，不是页面逐字原文**，所以本轮复核的可信度定为“官方页·摘要级复核”，低于“主会话用浏览器直读官方页”的“官方页·直读”。
- 两级标签：
  - 【官方·直读】：主会话用浏览器直接读取官方页面（Claude、OpenAI、Gemini、Grok 官方页，来自 01、02、03 号）。
  - 【官方·摘要复核】：官方页面经 WebFetch 摘要读到，且与原稿一致或可交叉印证（本轮国产模型）。
- 复核失败的页面：`huggingface.co/moonshotai/Kimi-K3`、`huggingface.co/Qwen` 均返回 “Command failed with no output”，**未读到**。

## 三、对 07 号成本模型的校正

校正方法：用 Python 脚本按统一公式重算（脚本放在 `/tmp/calc/cost.py`，公式与假设见最终手册第三章）。**发现并更正以下错误**：

| 序号 | 07 号原写法 | 校正后 | 原因 |
|---|---|---|---|
| 1 | 算例 B：Sonnet 5.5 代码 Agent 有缓存“≈ $0.65/任务”| **≈ $0.44/任务**（读 70.3 万×$0.10 + 写 6.7 万×$2.50 + 输出 2 万×$10）| 原写法的读取、新增、写入三项重复计了新增内容 |
| 2 | 5.4：H100 $3.84/小时全月 ≈ $2,803 | **$3.84×720 小时 ≈ $2,765**；另按中位价 $3.38 ≈ $2,434 | 算术错误 |
| 3 | 5.4：盈亏点“1,400 MTok/月、约 540 token/秒”| 按 $2,765 与 $2/M 重算为约 1,380 MTok/月，约 530 token/秒；**仍是假设，吞吐未核实** | 随上条更新 |
| 4 | 8.5：OpenAI 全部“未核实”，GPT-5.6 Sol $5/$30 或 $4/$20 | **官方标准价 $4 / 缓存 $0.40 / $20**（促销价至少到 2026-11-21）；GPT-6 系列价格全部已核实 | 以 01 号补查为准 |
| 5 | 8.6：Gemini 大部分未核实 | **Gemini 3.8 Flash 官方价已核实**：促销 $0.75/$3.75，2027-01-01 起翻倍 | 以 03 号为准 |
| 6 | 算例未含 OpenAI、Gemini、Grok、国产 | 已补全（最终手册第三章） | 本轮新增 |
| 7 | 2.1：Anthropic 缓存读取 Haiku 5.5 0.1×、Sonnet/Opus 5.5 0.05×、Fable 5.1 0.025× 被当作“内部不一致” | **不是不一致**，官方页就是按型号不同；以 02 号为准 | 02 号已核实 |
| 8 | 2.1：Claude 1 小时缓存写入 2× 标“未核实” | **已核实**（02 号官方页：1 小时写入价 Opus 5.5 $8、Sonnet 5.5 $4 等）| 以 02 号为准 |

**算例未计入的因素（会使真实账单更高）**：①思考 token（按输出价计费、不可见；Fable 5.1、Opus 5.5、GLM-5.3、Kimi K3 的思考无法关闭）；②重试；③工具调用费；④Claude 新分词器可能让同样文本多耗 token（官方倍数未核实）；⑤Gemini 缓存存储费（前缀 2,000 token 的存储费折算后可忽略）。因此手册里的算例是**下限估算**。
