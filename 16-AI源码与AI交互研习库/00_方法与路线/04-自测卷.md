# 04 · 自测卷：30 道主动回忆题（读完 48 小时后做）

> 依据：主动回忆（active recall）是检索练习中效果最强的学习方式之一（你 14 号库的学习方法体系也是这个主张）。看懂 ≠ 记得，**合上文档能复述才算**。
> 用法：先遮住答案区，凭记忆作答（口头或写在纸上），再对照。答错的题，回对应章节重读那个【为什么这样设计】。

## 答案区（先做完再看）

\<details>
\<summary>展开答案\</summary>

**1** 模型只生成文本（含结构化的工具调用提议）；harness 负责一切执行（读文件/跑命令/改代码）+上下文组装+权限+循环。
**2** "模型不再要求调用工具"。因为停止信号与数据流同源，避免两套状态打架；显式 done 标志会被模型滥用或遗忘。
**3** 防幻觉改错位置。硬护栏在 harness 实现（"will error"），提示词只负责预告预期——规则在两层各说一遍。
**4** 错误是信息不是异常：模型读到报错能自纠。质量决定于错误信息是否"可行动"（哪里失败、为什么、可以怎么办）。
**5** compact=有损保留（任务继续），clear=零成本归零（任务切换）。compact 用于单任务上下文将满；clear 用于任务间防污染。
**6** 子代理的**最后一条消息**。收益：上下文隔离/并行/专业化；代价：信息传递失真、token 倍增、必须写自包含任务书。
**7** 自定义命令（信模型执行固定流程）＜ Skills（信模型判断加载时机）＜ Hooks（不信模型，代码说了算）。
**8** 模型能力升级后该行为已内化，明文规则不再必要还占 token。元规律：提示词是脚手架，模型升级后要主动拆。
**9** 语法（工具名+参数模式）。模型自评不可靠且不可审计；语法规则可预测、可积累、可被组织管控（但需沙箱兜底防参数变体绕过）。
**10** ①工具调用指纹重复 5 次（零成本）②输出内容分块重复统计阈值 10（零成本）③每隔若干轮让 LLM 检查最近 20 轮（贵，低频）。检测后先 `_recoverFromLoop` 自救再上报。
**11** 堆积→裁剪与压缩；污染→/clear 与子代理隔离；失真→关键事实外化到文件。
**12** 工具结果信息密度低且可再生（可重读）。两问：这信息可再生吗？它是模型的决策/意图吗？可再生非决策 → 先丢。
**13** display 历史（完整，给 UI）与 api 历史（蒸馏后，给模型）。解决"压缩后用户看不到自己说过什么"与"token 预算"的矛盾。
**14** 任务目标与约束/已做决定及原因/关键文件路径与状态/当前进行到哪/下一步计划。（06 章练习题 3 的验收标准）
**15** 总参数 671B（模型容量），每 token 激活 37B（计算成本）。靠 MoE 稀疏激活（256 选 8 + 1 共享）。
**16** 缓存只存 kv_lora_rank=512 的潜向量 + 64 维 RoPE 键（约 MHA 的 1/10）。代价：标准 FlashAttention 不支持 → 自研 FlashMLA。
**17** 不参与加权求和（用 original_scores）。bias 只影响"选谁"（调度），不进梯度（不污染学习），实现 aux-loss-free 负载均衡。
**18** 砍掉 critic（价值网络），用同题一组的组内均分当 baseline（组内相对比较）。
**19** 没人教"反思"，奖励里只有答案正确性——中途自我怀疑因提升期望得分而被选择出来。证明：可判分任务 + 纯 RL 能逼出推理行为，无需人工标注思维链。
**20** 蒸馏直接优于小模型大规模 RL；"发现能力"贵，"传递能力"便宜。
**21** FlashMLA=计算/显存带宽（注意力 kernel）；DeepEP=网络通信（MoE all-to-all）；DeepGEMM=FP8 矩阵乘（JIT）；3FS=存储读吞吐。
**22** Muon 优化器放大到 1T 时的训练不稳（用 QK-clip 钳制注意力 logits）。训练数据含大量合成工具调用轨迹（Agentic Data Synthesis），模型天生会用工具。
**23** 一个人工确认门（理解汇报→计划审批→实现验收→提交）。
**24** 让模型审视它自己刚写的 PRD/方案，主动找最可能失败的三处。成本几乎为零（一次推理），收益是提前暴露设计缺陷。
**25** 深层原因：模型优化显性指标（测试通过）而非隐含意图（代码正确）——与 R1 的奖励投机同源。对策必须 harness 级，因为提示词级"请不要作弊"改变不了优化目标，机制（deny 测试文件/独立 review）才能。
**26** 信息层：死法一（一句话启动）、死法四（错误层级治故障）→ 喂足事实；控制层：死法二（不验收）、死法三（上下文超载）、死法五（无护栏危险操作）→ 验收+护栏+清空。
**27** 状态外化到文件（每轮全新上下文，靠 PROMPT.md/spec/fix_plan 接力）；幂等重启（失败再来一轮，上下文便宜）。
**28** 前半句解释"为什么被拒"（定位规则），后半句指明"该干什么"（行动出口）。删掉后半句模型可能原地重试同一动作，浪费轮次。
**29** 例行维护成本恒定且均匀；"快满时抢救"会面临一次性大压缩的信息损失尖峰，且挤压 UI 响应。每轮小步走比一次大手术稳。
**30** 对照 `06_代码实验室/toy_agent_harness.py` 的 `Harness.run`：组装→循环{调模型→无工具则停→逐个过权限门→执行→裁剪→回填}→每轮末微压缩。

\</details>
