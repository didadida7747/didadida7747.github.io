## 1. 开始之前：必须建立的基本认知

### 1.1 先明确目标

不同的目标决定不同的训练方式，先从下面选一个当前阶段的主目标（可以随阶段调整）：

| 目标 | 核心手段 | 预期节奏 |
|---|---|---|
| **健康体态 / 体能提升**（推荐新手起点） | 力量训练 + 中低强度有氧 | 3 个月可见明显变化 |
| **增肌（变壮）** | 渐进超负荷力量训练 + 热量盈余 | 每月增重 0.5～1 kg |
| **减脂（变瘦）** | 力量保肌 + 有氧 + 热量缺口 | 每周减重 0.5～1 kg |
| **提升力量** | 大重量低次数复合动作 | 以三大项成绩衡量 |

> **新手建议**：无论最终目标是什么，前 3 个月都应以「学习动作 + 建立习惯」为主目标。动作学对了，后面增肌减脂都是顺水推舟。

### 1.2 三条铁律（比任何计划都重要）

1. **渐进超负荷（Progressive Overload）**：肌肉只在"被比上次多一点点的压力"刺激下才会生长。表现为重量更重、次数更多、组数更多或动作更标准——每次训练只求进步一点点。
2. **动作质量 > 重量**：用能全程标准完成的重量。宁轻勿假，借力完成的次数约等于零，还伤关节。
3. **恢复是训练的一部分**：肌肉在休息时生长，不在训练时生长。练得多不如练得对 + 睡得好。

### 1.3 必须先懂的核心术语

| 术语 | 含义 | 新手应用 |
|---|---|---|
| **组（Set）/ 次（Rep）** | 一组动作重复做 N 次 | 新手常见：每个动作 3 组 × 8～12 次 |
| **RM** | 最大重复次数。8RM = 最多能标准完成 8 次的重量 | 选「8～12RM 之间」的重量做增肌组 |
| **组间休息** | 两组之间的间隔 | 增肌 60～90 秒；大重量复合动作 2～3 分钟 |
| **复合动作** | 多关节参与的动作，如深蹲、卧推、硬拉、划船 | 训练的主角，性价比最高 |
| **孤立动作** | 单关节动作，如弯举、侧平举 | 训练的配菜，放最后做 |
| **热身组 / 正式组** | 小重量预热 vs 正式计数的组 | 每个动作先做 1～2 组 50%～70% 重量热身 |
| **DOMS** | 延迟性肌肉酸痛，练后 24～72 小时出现 | 是正常现象，不代表"练废了"，详见 6.3 |
| **力竭（Failure）** | 再也做不完一次标准动作 | 新手不必每组力竭，留 1～3 次余力更安全 |

## 2. 健身器材（器械）全景指南

### 2.1 器械分三大类，先认全再上手

```
健身器械
├── 固定器械（轨迹固定，新手友好）
│   ├── 史密斯机、坐姿推胸机、高位下拉机、坐姿划船机
│   └── 腿举机、腿屈伸机、腿弯举机、蝴蝶机夹胸等
├── 自由重量（轨迹自由，进阶核心）
│   ├── 哑铃（最灵活，从 2kg 到几十 kg）
│   ├── 杠铃（大重量主力，配深蹲架/卧推架）
│   └── 壶铃（摆动类、功能性训练）
└── 有氧器械
    ├── 跑步机、椭圆机、动感单车、划船机、登山机
    └── 跳绳（最便宜便携的有氧工具）
```

### 2.2 固定器械：新手前 4 周的主力

| 器械 | 练的部位 | 新手要点 |
|---|---|---|
| **坐姿推胸机** | 胸、肩前束、三头 | 背部贴紧靠垫，推起时肘不完全锁死 |
| **高位下拉机** | 背阔肌 | 拉向锁骨方向，想象"用肘部往下带"，身体不过度后仰 |
| **坐姿划船机** | 背部中部、二头 | 挺胸收肩胛，肘贴近身体向后拉 |
| **腿举机** | 大腿、臀 | 膝盖不内扣，下放到大腿约与地面平行即可 |
| **腿屈伸 / 腿弯举机** | 股四头 / 腘绳肌 | 孤立动作，放主项之后做 |
| **蝴蝶机夹胸** | 胸 | 轻重量找"胸肌发力"的感觉，肘微屈固定 |
| **史密斯机** | 全身均可 | 轨迹固定，深蹲/卧推初期可用，但别永久依赖 |

**为什么新手先练固定器械**：轨迹被固定，发力错了也不容易受伤，可以先专注建立「目标肌肉发力」的感觉（即所谓"念动一致"）。

### 2.3 自由重量：第 5 周起逐步引入

| 器材 | 定位 | 新手建议 |
|---|---|---|
| **哑铃** | 自由重量入门首选，动作种类最多 | 从 2～5kg 开始学动作，不追求重量 |
| **杠铃** | 力量训练的终极工具（深蹲/卧推/硬拉） | 必须先学会空杆动作模式，再用小片加重量；建议前几次有人指导或在镜子/录像自查 |
| **壶铃** | 摆动、爆发力与心肺 | 可选，非新手必需 |

> **哑铃三大新手动作**：哑铃卧推、单臂哑铃划船、哑铃肩上推举——覆盖推、拉、举三大模式。

### 2.4 有氧器械怎么选

| 器械 | 强度 | 关节压力 | 适合 |
|---|---|---|---|
| **椭圆机** | 中 | 极低 | 体重大、膝盖不适者首选 |
| **动感单车** | 中～高 | 低 | 快慢间歇很好用 |
| **跑步机** | 中～高 | 较高 | 体重正常 + 快走起步，别一上来就跑 |
| **划船机** | 中～高 | 低 | 全身参与，练背，新手可学 |

### 2.5 辅助小件（自购便宜、用处大）

- **弹力带**：热身、辅助引体向上、居家训练全能。
- **泡沫轴 / 筋膜球**：练后放松（详见 6.4）。
- **瑜伽垫**：垫上动作与拉伸必备。
- **护具**：手套/助力带（握力不够时）、护腕护膝（大重量后再考虑）。新手阶段**不需要腰带**。

### 2.6 器械选择结论

> **入门期（0～4 周）**：固定器械 + 自重 + 哑铃小重量。
> **成长期（1～3 月）**：哑铃复合动作为主，开始学杠铃空杆模式。
> **进阶期（3 月后）**：杠铃三大项成为训练核心，固定器械做补充收尾。

## 3. 一次训练的正确顺序

### 3.1 标准流程（总时长 60～75 分钟为宜）

```
① 一般热身（5 分钟）
   └── 快走/单车/椭圆机，身体微微出汗即可
② 动态拉伸 + 关节激活（5 分钟）
   └── 肩绕环、髋部绕环、弓步转体、弹力带肩外旋等
③ 专项热身（每个动作 1～2 组小重量，约 5 分钟）
   └── 正式动作的 50%～70% 重量做 8～10 次
④ 主训练：复合动作优先（30～40 分钟）
   └── 先大肌群 → 后小肌群；先自由重量/多关节 → 后固定器械/孤立
⑤ （可选）有氧 10～20 分钟
   └── 减脂目标者多做；增肌者可少量或另安排
⑥ 静态拉伸放松（5～10 分钟）
   └── 拉当天练到的肌群，每个部位 20～30 秒 × 2 组
```

### 3.2 主训练内部的排序原则（重要）

| 原则 | 原因 | 举例 |
|---|---|---|
| **先大肌群，后小肌群** | 大肌群动作耗能大、需要神经集中；小肌群先疲劳会拖累大动作 | 练胸日：先卧推（胸），后三头下压 |
| **先复合，后孤立** | 复合动作技术复杂、收益高，要在状态最好时做 | 背日：先高位下拉/划船，后弯举 |
| **先自由重量，后固定器械** | 自由重量对稳定性和技术要求高 | 胸日：先哑铃卧推，后蝴蝶机 |
| **弱的部位放前面** | 优先补短板 | 后背弱就把背放在状态最好的第一项 |

### 3.3 力量与有氧谁先谁后

- **目标增肌/力量**：先力量后有氧（有氧别超过 20 分钟中等强度），或者把有氧放在不练力量的日子。
- **目标减脂**：同样**先力量后有氧**——先消耗糖原，后有氧脂肪供能比例更高，且力量训练质量有保障。
- 结论：无论什么目标，力量训练都不该排在有氧之后。

### 3.4 训练时长红线

- 单次力量训练（含热身拉伸）控制在 **60～90 分钟**内；超过 90 分钟通常意味着内容太多或组间闲聊太久。
- 新手不需要一天练 2 小时——**练得对、睡得好、能坚持**才是变量最大的三项。

## 4. 训练计划：从入门到进阶的四个阶段

> 以下按「零基础、每周可练 3 次左右」设计。每个阶段结束达到进阶标准再进入下一阶段，**宁慢勿跳**。

### 阶段一：适应期（第 1～4 周）—— "学会动"

**目标**：建立动作模式、养成习惯、让身体适应训练刺激。
**频率**：每周 3 次（如周一/三/五），每次 40～60 分钟，全身训练。
**器械**：固定器械 + 自重 + 小哑铃。不追求重量，重量以「标准做完 12 次还有 2～3 次余力」为准。

**全身训练 A（三次都练同一个课表即可，或 A/B 交替）**

| 动作 | 组 × 次 | 组间休息 |
|---|---|---|
| 坐姿推胸 | 3 × 12 | 60～90 秒 |
| 高位下拉 | 3 × 12 | 60～90 秒 |
| 腿举 | 3 × 12 | 90 秒 |
| 坐姿划船 | 3 × 12 | 60～90 秒 |
| 蝴蝶机夹胸 | 2 × 15 | 60 秒 |
| 平板支撑 | 3 × 30 秒 | 45 秒 |
| （收尾有氧，可选）快走/单车 | 10～15 分钟 | — |

**阶段毕业标准**：能连续 4 周坚持每周 3 次；所有动作知道"练哪块肌肉、发不上力时怎么调整"。

### 阶段二：成长期（第 5～12 周）—— "开始加重量"

**目标**：引入自由重量复合动作，学习渐进超负荷。
**频率**：每周 3 次，全身训练 A/B 交替（每次 60 分钟左右）。

**全身 A（推为主）**

| 动作 | 组 × 次 | 备注 |
|---|---|---|
| 杠铃/哑铃卧推（或史密斯卧推） | 3 × 8～10 | 主项，先用空杆学动作 |
| 坐姿肩上推举（哑铃） | 3 × 10 | |
| 高位下拉 | 3 × 10 | 逐渐加重 |
| 腿举 | 3 × 10 | |
| 哑铃侧平举 | 3 × 12～15 | |
| 绳索三头下压 | 2 × 12 | |

**全身 B（拉 + 腿为主）**

| 动作 | 组 × 次 | 备注 |
|---|---|---|
| 坐姿划船 | 3 × 10 | |
| 哑铃单臂划船 | 3 × 10/侧 | |
| 高脚杯深蹲（哑铃） | 3 × 10 | 学深蹲模式的最佳起点 |
| 罗马尼亚硬拉（哑铃） | 3 × 10 | 学髋铰链模式，轻重量 |
| 二头弯举 | 3 × 12 | |
| 卷腹/悬垂举腿 | 3 × 15 | |

**进阶方法（本阶段核心技能）**：同一个动作，当你能在所有组内**标准**完成目标次数上限时，下次训练加重最小一档（哑铃加 1～2kg，杠铃加 2.5～5kg），次数回落到下限重新爬。这叫"双重渐进法"，够用一整年。

**阶段毕业标准**：高脚杯深蹲能用约 15～20kg 完成 3×10；空杆卧推/深蹲动作模式稳定（可录像自查）；训练日志连续记录 4 周以上。

### 阶段三：分化期（第 3～6 个月）—— "开始有形状"

**目标**：提高单肌群刺激量，使用上下分化或推拉腿。
**频率**：每周 4 次，**上下分化**（上肢日 ×2 + 下肢日 ×2）。

**上肢日（周一/周四）**

| 动作 | 组 × 次 |
|---|---|
| 杠铃卧推 | 4 × 6～8 |
| 杠铃/高位下拉（背阔） | 4 × 8～10 |
| 坐姿划船 | 3 × 10～12 |
| 哑铃肩推 | 3 × 8～10 |
| 侧平举 | 3 × 12～15 |
| 弯举 + 三头下压（超级组） | 3 × 12 |

**下肢日（周二/周五）**

| 动作 | 组 × 次 |
|---|---|
| 杠铃深蹲 | 4 × 6～8 |
| 罗马尼亚硬拉 | 3 × 8～10 |
| 腿举 | 3 × 10～12 |
| 腿弯举 | 3 × 12 |
| 站姿提踵 | 3 × 15 |
| 核心（平板/卷腹轮） | 3 组 |

**阶段毕业标准**：卧推/深蹲/硬拉分别达到自身体重的约 0.75 / 1.0 / 1.25 倍（参考值，男女有别，重在持续进步）；对训练容量、疲劳有了自己的感觉。

### 阶段四：进阶期（6 个月以后）—— "选择方向"

**频率**：每周 4～6 次。训练进入「推拉腿（PPL）」或五分化，开始考虑专项化。

**经典推拉腿循环（练 6 休 1 或一周两循环）**

- **推日**：卧推 / 上斜哑铃推 / 肩推 / 侧平举 / 三头
- **拉日**：硬拉或杠铃划船 / 高位下拉 / 坐姿划船 / 面拉 / 弯举
- **腿日**：深蹲 / 罗马尼亚硬拉 / 腿举 / 腿屈伸 / 腿弯举 / 提踵 / 核心

此时训练变量（容量、强度、频率、动作选择）应根据自己的目标周期化调整，建议跟随成熟的进阶计划（如 5/3/1、NSuns、GZCLP 等力量向模板）或咨询教练。

### 各阶段速查

| 阶段 | 时间 | 频率 | 分化方式 | 核心任务 |
|---|---|---|---|---|
| 一 适应期 | 第 1～4 周 | 3 次/周 | 全身 | 学动作、建习惯 |
| 二 成长期 | 第 5～12 周 | 3 次/周 | 全身 A/B | 加重量、学复合动作 |
| 三 分化期 | 第 3～6 月 | 4 次/周 | 上下分化 | 提容量、出形体 |
| 四 进阶期 | 6 月后 | 4～6 次/周 | 推拉腿/专项 | 方向选择与周期化 |

## 5. 训练频率：每周练几次、怎么分

### 5.1 总原则

- **最低有效频率：每周 2～3 次**。低于 2 次，进步会很慢、习惯也难建立。
- **每个肌群每周直接刺激 2 次**是目前证据和实践都支持的增肌最优区间；只练 1 次也能进步，但效率低。
- **休息日不是浪费**：肌肉修复与生长发生在休息日。
- **可持续 > 理论最优**：能坚持的每周 3 次，好过坚持不了的每周 6 次。

### 5.2 按可用时间选方案

| 你每周能练 | 推荐方案 | 分化 |
|---|---|---|
| 2 次 | 全身 ×2 | 每次都练全身，动作选 5～6 个复合动作 |
| 3 次（新手默认） | 全身 ×3 | A/B 交替或同一课表 |
| 4 次 | 上下分化 ×2 | 上/上/下/下 或 上/下/上/下 |
| 5 次 | 上/下/推/拉/腿 | 弱势部位可每周多打一次 |
| 6 次 | 推拉腿 ×2 | 适合恢复能力好、时间充裕者 |

### 5.3 频率相关的实操细节

- **两次训练至少间隔 1 天**（新手期全身训练尤其如此）；同一个肌群酸痛严重时不要硬练。
- 有氧可以放在力量训练日之后（15～20 分钟）或休息日（30～40 分钟中低强度），休息日做有氧叫"主动恢复"，反而促进恢复。
- 睡眠不足、工作学习压力大的时候，主动把频率降一档（6→4，4→3），比硬撑着练导致生病/受伤划算得多。

## 6. 恢复与修养：休息才是变强的时刻

### 6.1 恢复的四大支柱

| 支柱 | 要求 | 说明 |
|---|---|---|
| **睡眠** | 每晚 7～9 小时 | 最重要的"补剂"，生长激素在深睡时分泌。熬夜会直接吞掉训练成果 |
| **营养** | 见第 7 章 | 蛋白质吃够是恢复的原料 |
| **休息日** | 每周至少 1～2 天完全不练力量 | 可以散步、拉伸、做轻有氧 |
| **压力管理** | 训练量随生活压力浮动 | 学业/工作高压期降低训练量，不是放弃 |

### 6.2 训练间隔的安排逻辑

- 同一肌群两次训练之间留 **48～72 小时**。
- 新手酸痛期（练后 1～2 天）内不要重复练同一部位；酸着也可以练别的部位或做主动恢复。
- 连续 4～8 周训练后，可以安排一个"减载周"（deload）：同样动作但重量降到 60%，组数减半，让身体彻底回血——进阶期后尤其需要。

### 6.3 延迟性肌肉酸痛（DOMS）应对

- **是什么**：练后 24～72 小时出现的肌肉酸胀，是正常的训练反应，新手期和新动作后最明显，几周后会大幅减轻。
- **怎么处理**：轻度活动（散步、慢速单车）、拉伸、泡沫轴放松、保证蛋白和睡眠、多喝水。
- **不需要**：酸痛不是"练到位"的必要证明；追求第二天酸到下不了床是本末倒置。
- **危险信号（不是 DOMS，要就医）**：关节尖锐刺痛、单侧持续锐痛、肿胀、尿色异常加深（横纹肌溶解征兆，极端训练后出现，立即就医）。

### 6.4 泡沫轴与拉伸

- **训练后**：静态拉伸当天练的肌群，每处 20～30 秒 × 2 组。
- **休息日/训练后**：泡沫轴滚压大腿前后侧、臀部、背部、小腿，每处 30～60 秒，酸痛点可停留（酸胀可忍、尖锐痛避开）。
- **训练前不要做长时间静态拉伸**（会短暂降低力量输出），热身用动态拉伸。

### 6.5 过度训练的信号（出现两条以上就该降量）

1. 晨起静息心率连续数天比平时高 5～10 次。
2. 睡眠变差、越睡越累。
3. 训练表现连续两周下滑。
4. 持续性疲劳、易怒、食欲下降。
5. 小伤小痛不断（膝盖、肩膀、腰反复不适）。

**对策**：不是停练，而是把训练量/强度砍半 1～2 周，睡眠和饮食拉满，然后逐步恢复。

## 7. 饮食营养简明指南

### 7.1 一句话框架

> **蛋白质吃够、水喝够、蔬菜水果别缺；增肌小幅多吃，减脂小幅少吃；训练围绕一日三餐正常安排即可。**

### 7.2 三大营养素（每天）

| 营养素 | 量 | 来源举例 |
|---|---|---|
| **蛋白质** | 每公斤体重 1.5～2.0 g（70kg → 105～140g） | 鸡蛋、鸡胸、鱼虾、瘦牛肉、牛奶、豆制品、乳清蛋白粉 |
| **碳水化合物** | 训练日主食别怕吃 | 米饭、面、燕麦、红薯、全麦面包 |
| **脂肪** | 占总热量 20%～30%，别谈脂色变 | 坚果、橄榄油、鱼类、蛋黄 |

### 7.3 增肌 vs 减脂

- **增肌**：每天比消耗多摄入 200～500 kcal，体重每月涨 0.5～1kg 为宜；涨太快多长脂肪。
- **减脂**：每天少 300～500 kcal，每周掉 0.5～1kg；**减脂期必须保持力量训练**，否则掉的是肌肉。
- 不需要极端节食或疯狂增食——小幅调整、每周称重（同一时间、空腹）看趋势。

### 7.4 训练前后怎么吃

- **练前 1～2 小时**：正常一餐或一根香蕉 + 一点碳水即可，不必空腹也不必大餐。
- **练后**：一小时内吃一顿含 20～40g 蛋白质 + 碳水的正餐；来不及就先喝一勺蛋白粉 + 香蕉，回头补正餐。
- **蛋白粉只是食物**：蛋白质吃不够时用它补缺口，不是神药，也不是必需品。

### 7.5 补剂优先级（新手视角）

1. 基本吃好、睡好（免费，收益最大）
2. 肌酸（研究最充分、便宜、安全，每天 3～5g，任意时间）
3. 蛋白粉（方便补蛋白）
4. 其他（维生素 D、鱼油等按个人饮食情况）
5. 脂肪燃烧剂、各种"黑科技"——不需要。

## 8. 安全须知与常见错误

### 8.1 安全红线

1. **杠铃大重量必须有保护**：深蹲在架内做（保险销调好）、卧推有保护者或用史密斯/哑铃替代。
2. **疼痛分级**：肌肉酸胀灼烧感 = 正常；关节尖锐痛、刺痛、放射痛 = 立即停止该动作。
3. **动作幅度循序渐进**：深蹲下不到平行就先蹲到自己的幅度，随柔韧性提高加深，别硬蹲。
4. **不憋气**：发力时呼气、还原时吸气（瓦式呼吸进阶后再学）。
5. **器械用完归位、卸片**，既是礼貌也是安全。

### 8.2 新手常见错误 Top 10

| # | 错误 | 后果 | 纠正 |
|---|---|---|---|
| 1 | 只练胸和二头（"海滩肌"） | 体态前倾、背部薄弱受伤 | 推拉平衡，背部动作 ≥ 胸部动作 |
| 2 | 深蹲/硬拉不敢学或乱学 | 下肢发展停滞 | 从高脚杯深蹲、哑铃罗马尼亚硬拉起步 |
| 3 | 每次练到力竭 | 疲劳堆积、动作变形 | 大多数组留 1～3 次余力 |
| 4 | 频繁换计划 | 永远在"新手期" | 一个计划至少执行 8～12 周再评估 |
| 5 | 不记录训练重量 | 无法渐进超负荷 | 手机备忘录/训练 App 记录每组重量次数 |
| 6 | 组间刷手机休息 5 分钟 | 训练变成磨洋工 | 计时，增肌组间 60～90 秒 |
| 7 | 不热身直接上大重量 | 拉伤风险 | 雷打不动执行第 3 章流程 |
| 8 | 靠"酸痛感"判断效果 | 过度追求酸痛、动作变形 | 以重量/次数是否进步为准 |
| 9 | 熬夜 + 咖啡因续命 | 恢复崩盘 | 睡眠是第一优先级 |
| 10 | 两周没看到腹肌就放弃 | 前功尽弃 | 以 12 周为单位看变化，拍同角度对比照 |

### 8.3 什么时候应该请教练（或至少请人看一次动作）

- 开始接触杠铃深蹲、卧推、硬拉时（阶段二末～阶段三）。
- 出现反复出现的关节疼痛时。
- 愿意付费的话，前 4～6 节课纠正动作模式，性价比很高。

## 9. 进阶方向与长期发展

### 9.1 训练满一年后的常见方向

| 方向 | 核心关注 | 适合谁 |
|---|---|---|
| **健美/形体训练** | 肌肉体积、对称度、体脂 | 想要好看、全面发展形体者 |
| **力量举** | 三大项总成绩 | 喜欢变强、喜欢量化目标者 |
| **功能性/体能训练** | 综合运动能力（CrossFit、壶铃等） | 喜欢多样性、不喜欢枯燥者 |
| **专项运动体能** | 为球类、攀岩、跑步等服务 | 有主运动项目者 |

### 9.2 训练日志：普通人最重要的"进阶工具"

每次训练记 4 个信息即可：

```
日期 | 动作 | 重量 × 次数 × 组数 | 当日状态备注
例：9-2 | 杠铃卧推 | 40kg×8×3 | 最后一组略吃力，肩热身充分
```

- 每周复盘：哪些动作进步了？哪里卡住了？
- 卡住的动作连续 3 次无进步 → 换同类动作、加辅助动作或休息一周（减载）。

### 9.3 平台期处置清单

1. 检查睡眠和蛋白质是否达标（80% 的平台期在这）。
2. 检查是否每次都力竭、疲劳堆积 → 安排减载周。
3. 尝试改变该动作的次数区间（8～12 换成 5～8 或 12～15）。
4. 增加或更换辅助动作。
5. 仍无起色且已训练 1 年以上 → 考虑更结构化的周期化计划。

### 9.4 心态

- 健身是以「年」为单位的事：3 个月像样，1 年换个人，3 年脱胎换骨。
- 和昨天的自己比，不和健身房里练了五年的人比。
- 中断了就从中断处继续，"重新开始"本身就是这项运动的一部分。
