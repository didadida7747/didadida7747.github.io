# 怎么用这套资料：先读我

> 这套库不是"资源收藏夹"，而是一套**带批注的教材**。每一篇文档的写法都是：
> 机制怎么运作 → 【为什么这样设计】→ 【换成你会怎么做】→ 【你能偷走什么】。
> 收藏夹看完就忘，批注看完能长出判断力。

## 一、这套库能帮你解决什么问题

你现在的问题可能是这样的：

- 会用 AI 编程工具，但说不清"它背后到底发生了什么"，所以工具不听话时只能干瞪眼；
- 知道 prompt 重要，但看别人的 prompt 只觉得"写得真好"，说不出好在哪；
- 想读源码，但面对 10 万行的仓库不知道从哪个文件下手，读了三行就退出来刷手机了。

这套库针对的就是这三件事：

1. **01/02 章**：把 Agent（以 Claude Code 为标杆、以开源同类为参照）的 harness 拆开给你看，让你知道"AI 编程工具 = 一个循环 + 一堆工具 + 精心设计的上下文"，仅此而已，但每个零件都有讲究。
2. **03 章**：模型侧（DeepSeek 为主）的源码与论文批注，让你知道"模型本身是怎么造出来的"。
3. **04 章**：别人跟 AI 的真实交互记录拆解——这是性价比最高的教材，因为它是"考试真题+高分答案"。
4. **05 章**：分平台的资源地图（GitHub/B站/抖音/小红书/YouTube/X/HN），供你持续追更。
5. **06 章**：一个我自己写的、**两百多行、能直接跑**的迷你 Agent harness，把 01 章讲的所有设计理念变成你可以亲手改的代码。读完概念来这儿动手。

## 二、推荐的三条阅读路线

### 路线 A：实用主义（2 小时见效）
适合：想马上把 Claude Code/Codex 用得更好的人。
1. `01_ClaudeCode_Harness精读/07-系统提示词全文批注.md` —— 看懂它的"出厂人设"
2. `04_别人与AI的交互记录/01-经典案例拆解.md` —— 看高手怎么下指令
3. `04_别人与AI的交互记录/03-提示词模板库.md` —— 抄了就用
4. `01_ClaudeCode_Harness精读/08-从Claude-Code学到的10个工程模式.md`

### 路线 B：系统学习（7 天，见下面的打卡表）
适合：想真正搞懂 Agent 这一层的人。

### 路线 C：深潜源码（2-4 周）
适合：想自己写出 Agent / 想进 AI 基础设施方向的人。
1. 精读 01 章全部 + 02 章的 Gemini CLI/Aider 源码批注
2. 打开 `06_代码实验室/`，跑通 toy harness，做完练习题
3. 按 `03_模型源码_DeepSeek与朋友们/04-Karpathy入门三件套.md` 的路径读模型源码
4. 挑一个真实需求，用自己改的 harness 干活

## 四、使用这套库的两个约定

1. **别跳过"思考题"**。源码阅读和看小说的区别就在这里：带着问题读，答案才会挂进你的知识树。
2. **批注观点 ≠ 标准答案**。所有【为什么这样设计】都是基于公开资料的合理推断 + 我的分析，官方源码闭源的部分（Claude Code 本体）尤其是。重要的是推理过程，你可以不同意，最好有自己的判断。

## 五、这套库的时效性说明

- 写作基准时间：2026 年 10 月。AI 领域版本迭代极快，**设计理念比版本号长寿**：主循环、上下文管理、工具设计这些"骨架"两年内不会大变，具体命令名、阈值数字请以官方文档为准。
- 文档里凡是我不确定的细节，都会标"（推断）"或"（随版本变化）"，你应当用 05 章的信息源去核实最新状态——这个核实动作本身也是练习。
