# 02 · 安装与初始化配置（全平台）

## 一、桌面端（Windows / Mac）

### Chrome / Edge（推荐，最省事）

1. 打开扩展商店：
   - Chrome：Chrome 网上应用店，搜索 `Tampermonkey`；
   - Edge：Edge 附加组件商店（`edge://extensions` → 获取 Microsoft Edge 扩展），搜索 `Tampermonkey`。
2. 点击"获取 / 添加到浏览器"，确认权限后安装。
3. 浏览器右上角出现黑色猴子图标即成功；建议点击"固定扩展"图标把它钉在工具栏。
4. Edge 商店的 Tampermonkey 国内可直接访问，通常无需特殊网络。

> 商店打不开时的备选：通过扩展镜像站下载 CRX，例如 https://www.crxsoso.com 搜索 Tampermonkey，下载后在 `chrome://extensions` / `edge://extensions` 打开右上角"开发者模式"，把 CRX 拖入页面安装。注意：镜像站只解决下载问题，扩展本体请核对名称、开发者为 **Jan Biniok**，避免下到仿冒扩展。

### Firefox

附加组件商店（about:addons）搜索 Tampermonkey 或 Violentmonkey 安装；Firefox 也可以装原版 Greasemonkey。

### 验证安装

1. 点击猴子图标 → 能看到"管理面板"；
2. 打开管理面板显示已安装脚本列表（初始为空）；
3. 任意网页点猴子图标，能看到"当前标签页正在运行的脚本"。

## 二、手机端

### Android

- **推荐：狐猴浏览器（Lemur Browser）**：基于 Chromium，可直接安装 Chrome/Edge 商店的扩展，内置扩展商店，对国内网络友好。安装浏览器后在其扩展中心搜 Tampermonkey 即可。
- **Firefox 安卓版**：现已支持直接安装绝大多数扩展，菜单 → 附加组件 → 搜索 Tampermonkey。
- Kiwi Browser 等支持扩展的 Chromium 系浏览器也可，但部分项目更新停滞，优先级靠后。

### iOS / iPadOS（iOS 15+）

1. App Store 搜索 **Tampermonkey**（付费 App，适用于 iOS 15+ / macOS 11+ 的 Safari）；
2. 安装后到 系统设置 → Safari 浏览器 → 扩展 → 打开 Tampermonkey 开关，并授权其对网站的访问权限；
3. Safari 中打开 Tampermonkey，设置脚本存放文件夹；
4. 免费替代：App Store 的 **Userscripts**（开源），同样在 Safari 扩展中启用，脚本文件放在 iCloud 自建目录里管理。
5. 装好后在 Safari 打开 Greasy Fork 脚本页，点"安装"，底部上拉菜单选 Userscripts/Tampermonkey 完成安装。

## 三、第一次必做的初始化设置

点击猴子图标 →"管理面板"（Dashboard）→ 切到"设置"选项卡。

### 1. 配置模式改为"初学者"或"高级"

- 默认"新手"模式会隐藏大量选项；切到"初学者"即可看到完整功能，不需要一开始就上"高级"。

### 2. 打开"自动刷新页面"（初学者模式下可见）

- 启用/禁用脚本后当前网页自动刷新，免去手动 F5，切换脚本状态非常方便。

### 3. 脚本更新设置

- 在"常规"或"脚本更新"相关设置中，保持**自动检查更新开启**（默认开启），可设置检查频率（如每天）。
- 意义：脚本被发现是恶意代码后，Greasy Fork 下架脚本，你的本地副本在下次更新时会同步移除；安全补丁也能及时拿到。

### 4. 配置安全黑名单（可选但推荐）

- 在设置中找到"安全"（Security）相关的黑名单/Negative 列表，把**绝不允许任何脚本运行的敏感站点**加进去，例如：
  - 银行、支付类：网银域名、`pay.qq.com`、支付宝等；
  - 学校统一身份认证、教务系统域名；
  - 公司内网系统；
  - 密码管理器网页版。
- 官网原话："只有偏执狂才能生存"——把所有不该使用脚本的网站列入黑名单。

### 5. 关闭不必要的脚本运行环境（按需）

- 不希望脚本在隐身模式运行：到浏览器扩展管理页，关掉 Tampermonkey 的"在无痕模式下启用"。
- 如果不用本地文件调试，不必开启"允许访问文件网址"（开启后会增加本地脚本开发能力，但也扩大了攻击面，需要时再开，见 [06](/01-电脑与工具链/篡改猴Tampermonkey使用指南/06-脚本开发入门)）。

### 6. 打开云同步（可选）

- Tampermonkey 支持通过 Chrome/Edge 账号同步或其自带同步在多设备间同步脚本；部分高级同步能力属付费版。
- 免费替代方案：定期用管理面板"实用工具"选项卡导出备份（见 [03](/01-电脑与工具链/篡改猴Tampermonkey使用指南/03-脚本获取与管理)）。

## 四、卸载

- 桌面：浏览器扩展管理页 → 移除 Tampermonkey 即可，所有脚本随扩展一起停用；卸载前建议先在"实用工具"里导出脚本备份。
- 手机：卸载对应浏览器/App 即可。

## 五、常见安装问题

| 问题 | 处理 |
|---|---|
| Edge/Chrome 商店打不开 | 换 Edge 商店（国内通常可直连）；或用 crxsoso.com 镜像下 CRX 开发者模式安装 |
| Greasy Fork 网页打不开 | 用镜像站：把 `greasyfork.org` 换成 `greasyfork.icu` 或 `greasyfork-zh.org`；脚本编号路径保持不变 |
| 点了"安装"没反应 | 检查扩展是否被浏览器禁用；确认 Tampermonkey 图标钉在工具栏；脚本页会提示"允许篡改猴打开此类链接"，确认即可 |
| 装完脚本不生效 | ①看猴子图标里当前页是否有该脚本；②硬刷新 Ctrl+F5；③看脚本是否启用；④看脚本 @match 是否匹配当前网址（注意 http/https、www） |
| 浏览器提示扩展危险/被停用 | 确认是否官方版本；Manifest V3 过渡期请升级到商店最新版，不要从论坛下载来历不明的 CRX |
