# 周末一日游路线（从本校长安校区出发，直接抄）

> 整理于 2026-10 ｜所有路线均可 2-4 人组队；预算按人均计（不含购物）。
> 交通细节（地铁口 / 末班车）出发前用高德核对一遍。

---

## 路线 1：秦岭入门线（最推荐，长安校区专属福利）

**南五台半日**：上午 8 点打车出发（约 25 分钟）→ 爬山 4-5 小时（学生票约 22 元）→ 下午 4 点前下山 → 韦曲吃晚饭。
**预算**：约 60-80 元/人（车费拼摊 + 门票 + 饭）。
变体：想免费 → 换成**圭峰山**或**沣峪口踩水**（见 [秦岭爬山入门](#/doc/d400)）。

## 路线 2：骑行 + 人文线

西沣路向南 → S107 环山路骑行 → 太乙驿补给 → 折返；中午**长安唐村·南堡古寨**吃农家饭 + 稻田拍照（人均约 50 元），顺路**常宁宫**转一圈。
**预算**：约 80 元/人。季节限定：秋天稻浪、春天桃花（王莽）。

## 路线 3：古城慢生活线（市区）

地铁进城 → 上午**陕西考古博物馆**（若在长安区方向则反向安排）或小寨/陕历博 → 下午**碑林 + 书院门**或**西安博物院 + 小雁塔** → 傍晚**洒金桥/回民街**觅食 → 晚上随机应变（livehouse / 脱口秀 / 夜市，见 [演出与Livehouse](#/doc/d396)）。
**预算**：约 80-150 元/人。注意陕历博、考古博物馆需**提前预约**。

## 路线 4：安静散心线（一个人也行）

上午**香积寺** → 骑行/打车**兴教寺**（玄奘塔）→ 下午**樊川公园**白沙滩发呆 → 晚上韦曲吃饭回校。
**预算**：约 30-50 元/人（几乎全是交通费）。

## 路线 5：雨天 / 冬天室内线

剧本杀（大学城店，人均 60-120 元）→ 火锅/烤肉 → 私人影院或密室。全程室内，详见 [剧本杀·桌游·密室·VR](#/doc/d391)。

## 路线 6：冬季限定

上午**翠华山滑雪**（学生票约 99 元起）→ 傍晚**东大温泉**泡汤回血（见 [冬滑雪温泉·夏玩水漂流](#/doc/d399)）。
**预算**：约 200-300 元/人。

## 路线 7：夏季玩水线

沣峪口溪水浅滩 + 农家乐烧烤（人均 50-80 元）→ 傍晚沿环山路兜风回校。**汛期先查天气，山洪预警不下水。**

---

## 组装自己的一日游的公式

```
上午（体力活：爬山/骑行/景区）
＋ 中午（环山路农家乐 或 韦曲/郭杜商圈）
＋ 下午（安静活：公园/古迹/咖啡馆）
＋ 晚上（商圈：KTV/电影/夜市）
```

预算梯度：0-50（公园骑行线）｜50-150（爬山+农家乐）｜150-300（滑雪温泉/市区文艺全天）。
