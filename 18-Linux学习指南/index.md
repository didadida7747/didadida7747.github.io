# Linux 从零到实战 · 学习指南（WSL2 + Ubuntu 24.04）

> 一份为**准零基础、想走后端开发 / 服务器运维方向**的本科生写的 Linux 完整自学指南。
> 环境基于 **Windows 11 + WSL2 + Ubuntu 24.04**，无需装双系统、无需先买云服务器。
> 内容形式：15 章"老师面对面讲"式的 Markdown 教程 + 全平台资料推荐 + 可视化 HTML 路线图。

---

## 推荐学习方式：文档驱动（阅读为主，视频仅在卡住时选看）

这套指南**默认按"读文档"的路径设计**，适合觉得"看视频太慢、想自己掌握节奏"的你：

1. **主线**：按顺序读 01–15 章正文——它们本身就是写给你看的讲义，每章都有讲解、可复制命令、输出说明和练习；
2. **深入**：每章末尾的"配套资料"里，**文档类排在前面**（官方文档、`man` 手册、MIT 缺失的一课、TLCL、鸟哥、菜鸟、GitHub 高星文字教程），概念没吃透时就顺着这些文字资料读；
3. **动手**：读完一章立刻到练习站（OverTheWire Bandit、Linux Journey、Killercoda 等）上手；
4. **视频是"救火队员"，不是主课**：只有当某一章看文档反复看不懂、想快速看一眼某个操作的实际演示时，再到该章配套资料末尾的"卡住时再看（可选视频）"或资料合集的"补充 · 卡点时选看"区挑对应视频，看完就回到文档主线，不用从头刷视频课。

> 完整资料清单与"文档/视频/实战"三种搭配方案见 [资料推荐合集.md](/18-Linux学习指南/资料推荐合集)。

## 这份指南适合 / 不适合谁

**适合**：
- 几乎零基础、想系统学 Linux 的计算机/电子信息相关专业同学；
- 用 Windows 电脑、想在后端开发 / 运维 / 竞赛部署中用上 Linux 的人；
- 想要一条"从零到能部署项目"的完整路线，而不是零散命令清单的人。

**不适合**（本指南有意不覆盖）：
- 嵌入式 Linux、开发板、驱动、内核裁剪与交叉编译方向；
- 想学习 Linux 桌面美化、日常办公替代 Windows 的需求；
- 已经是熟练运维、想直接上 Kubernetes 进阶内容的读者（可把第 13 章当起点再查进阶资料）。

## 学习约定

- 所有命令均在 **Ubuntu 24.04 (WSL2)** 下核对；代码块中 `$` 开头表示普通用户命令、`#` 开头表示需要管理员权限（通常要加 `sudo`），**`$`/`#` 是提示符，不要复制**；
- 标记 ⚠️ 的地方是可能造成数据丢失或系统故障的危险操作（如 `rm -rf`、`--unregister`、改 `fstab`），务必读清楚警告再动手；
- 外部链接均为 2026-10-13 实际检索核实的地址；若个别链接日后失效，按资料名称在对应平台搜索即可。
