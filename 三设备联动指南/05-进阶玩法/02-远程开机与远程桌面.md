# 远程开机(WoL)与外网远程方案

## 一、让拯救者"随叫随到":远程开机

### 前置知识
- 笔记本睡眠状态(S3)下 WoL 最可靠;**完全关机(S5)后多数机型收不到魔术包**。所以"远程开机"的正确姿势是:平时让电脑**睡眠**而不是关机。
- ⚠️ **WoL 魔术包是二层广播,不能穿过 Tailscale/VPN 隧道**——必须局域网内有常驻设备代发。这是最常见的误区。

### WoL 三步设置(拯救者本机)
1. BIOS 里开启 Wake on LAN(开机按 F2/Fn+F2 进入,选项名因机型而异);
2. Windows 设备管理器 → 网卡 → 属性 → 电源管理:勾选"允许此设备唤醒计算机"+"只允许幻数据包(魔术包)唤醒";
3. 控制面板 → 电源选项 → **关闭"快速启动"**(不关它,关机状态网卡不监听)。

### 谁来发魔术包(按省事程度排序)
1. **最省事:拯救者自己"睡眠当常驻"**——合盖不休眠+自动睡眠(功耗约 1-2W,电池=天然 UPS),iPad 用 Tailscale 直接唤醒+连接。睡眠中的电脑自身网卡仍可响应(按上面三步设置后,部分场景可直接 `tailscale` 唤醒,不行就走方案 2/3)。
2. **标准方案:[UpSnap](https://github.com/seriousm4x/UpSnap) 开机面板**——家里任一常开设备(NAS/树莓派/另一台电脑/Docker)跑 UpSnap 网页面板,人经 Tailscale 访问它、点一下发 WoL;官方有 [Docker 示例](https://github.com/tailscale-dev/upsnap-docker-example)。若日后上了"家庭服务器"(见 05-3),把它挂上去即可。
3. **硬件土办法:智能插座 + BIOS"来电开机"**(AC Power Recovery)——台式机普遍支持,**拯救者笔记本 BIOS 未必开放此选项,需进 BIOS 验证**;或用向日葵开机插座(配套硬件方案)。

### 日常电源设置建议(让拯救者当"准服务器")
- 控制面板 → 电源选项 → "选择关闭盖子的功能" → 接通电源时:关盖=不采取任何操作;
- Lenovo Vantage / Legion Space 开启**电池养护模式**(固件锁定充电 60%-80%),长期插电防鼓包;
- 注意:开源工具 LenovoLegionToolkit 已于 2025-07 归档停更([GitHub](https://github.com/BartoszCichecki/LenovoLegionToolkit)),可继续用旧版但别指望更新。

## 二、外网远程方案对比

> 六方案（RDP+Tailscale / RustDesk / ToDesk / 向日葵 / Parsec / Moonlight+Sunshine）的**完整对比表与适用场景见 [01-iPad×拯救者/03-远程桌面.md](#/doc/d368)** 与 [06-速查表]（2026-10-05 去重，以那边为唯一版本）。本篇只管**远程开机（WoL）**与外网可达的前提。

**外网远程的两个前提**：① 电脑不在身边也能被唤醒——WoL 打通；② 内网穿透——Tailscale 组网或自建 DERP（见上表 03-远程桌面 与 05-1 的 Tailscale 节）。


### 推荐组合
- 电脑升级专业版 → **Tailscale + RDP**(办公)+ **Moonlight**(游戏),一套打天下。
- 保持家庭版 → **Tailscale + RustDesk**(可自建中继)+ Moonlight。
- 什么都不想配 → ToDesk/向日葵(免费额度内够应急)。

## 三、验证清单
- [ ] BIOS WoL 已开、网卡魔术包已勾、快速启动已关
- [ ] 合盖插电不关机、睡眠可被唤醒
- [ ] 养护模式充电阈值已设
- [ ] Tailscale 下 iPad 能连上(RDP/RustDesk/Moonlight 至少一种)
- [ ] 异地热点环境实测一次"唤醒+连接"全流程
