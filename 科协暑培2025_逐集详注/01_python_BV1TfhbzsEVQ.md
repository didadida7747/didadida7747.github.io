科协暑培 2025 三讲中的 Python 入门讲，覆盖语言基础、容器、函数、面向对象、模块、异常处理与 conda 环境。适合只学过 C、想快速建立 Python 全景的初学者；已有 Python 基础（如上过小学期）的同学可当检查表按时间戳跳看。

## 内容脉络

- [00:01] 开场：面向已学小学期 Python 或选了其他语言的同学做基本介绍，讲义用 Jupyter 写，代码可现场运行。
- [00:59] 历史与特点：Python 2/3 不兼容但日常都用 Python 3，conda 默认下载 Python 3；语言简单直观，据称是全球使用最广泛的语言。
- [01:55] 解释型语言：对比 C++ 需编译成 .exe 的中间状态，Python 直接执行 .py、运行到哪里执行到哪里，没执行到的函数不会被转成机器码。与 C 基础重复，⏭️可跳过（"解释 vs 编译"概念课程已覆盖）。
- [03:19] 报错阅读：traceback 逐层递归告诉你文件/行/函数，最底一行是错误类型（如 ZeroDivisionError）；中间的库调用帧可忽略，重点看最底下。新手实用点。
- [04:45] 强大的库：AI 方向的 NumPy（转写"N派"）、PyTorch 等都经 Python 调用。
- [05:15] 优劣：开发效率高 vs 执行慢；追求效率（数据结构作业）用 C++，功能型任务用 Python。
- [06:13] 运行一——交互式解释器：终端输入 python 即时执行；也可检验 conda 环境里某库（如 pandas，转写"peter"，存疑）是否装好。
- [08:05] 运行二——脚本文件：`python example.py` 直接运行，不生成中间文件。
- [09:06] print 与 input：print 可接多参数，默认空格分隔、自动换行，sep/end 可自定义；交互式解释器直接输入表达式即回显；input 返回字符串，需强制类型转换。
- [12:01] 语句与入口：行尾不强制分号；`if __name__ == "__main__"` 相当于 C++ 的 main，仅文件被直接运行时其下语句才执行；长语句用反斜杠或括号换行。
- [13:27] 分支与循环：if/elif 用缩进（四空格，tab 即可）划界，逻辑运算用 and/or/not；while 同 C++，但没有 do-while。
- [14:55] for 与 range：`for i in range(5)` 枚举 0~4；range(start, stop, step) 左闭右开，step 可为负；for 更多用于遍历容器（string/list/tuple 等），enumerate 可同时拿索引与元素。
- [17:48] 数据类型：整数超限自动扩容，不像 C++ 会溢出回绕——写数据结构作业少一类"莫名其妙的 bug"；布尔 True/False 首字母须大写。
- [19:43] 字符串：单双引号等价不能混用；`\n` 转义；前缀 r 得原始字符串；没有 char 类型，单字母也是字符串；f-string 大括号插变量。
- [22:05] 动态类型：变量类型随赋值改变；Python 又是强类型，自动转换有限——int("3") 按值转而非 ASCII 码，字符串 + 是拼接，乱转会 ValueError。
- [25:28] 运算符：`/` 真除法、`//` 取整、`**` 幂；is 比地址、== 比值；所有 None 同一内存故用 is None 判空；小整数 -5~256 有缓存，`x is 3` 为 True 而 `x is 666` 为 False（面试向细节）。
- [28:22] list 与切片：元素可异构、可嵌套；`a[1:3]` 左闭右开，负索引 -1 为倒数第一，`[start:stop:step]` 省略默认到头，`[::-1]` 反转；string 不可变，`s[0]='h'` 报错。
- [32:43] list 增删改：append/insert/extend 原地修改，`+`/`*2` 返回新列表；pop 按索引、remove 按值、clear 清空；可按切片批量替换。
- [35:06] tuple：小括号、不可变；函数 return 多值即元组，`a,b,c = f()` 解包、变量交换同理。
- [36:32] set 与 dict：set 大括号、无序、自动去重，in/not in 判断、add/remove；dict 键值对，`d[k]` 不存在抛 KeyError，`d.get(k, default)` 给默认值提升鲁棒性；key 必须可哈希，记"set 不能当 key"即可。
- [40:24] 生成式（推导式）：一行构建容器——列表推导、带 if 过滤、字典推导 `{i: i*i}`；比 C++ 逐元素赋值简洁。
- [41:50] 函数：def + 冒号 + 缩进划界；无 return 则无返回值（body 暂空用 pass）；四种参数——位置参数按序传；关键字参数可乱序但须放在位置参数之后（建议要么全带等号要么全不带）；默认参数不传则用默认值；*args 收任意多个位置参数，**kwargs 以键值对收集。
- [46:33] 面向对象：class + 缩进；可类外补挂类属性，实例未单独赋值时共享类属性；`__init__` 构造函数；成员变量前加双下划线即私有，类外访问报错、类内方法可访问；继承略过。
- [50:45] 模块：import 后需 `math.sqrt` 前缀；`import x as m` 起别名；`from math import sqrt` 直接用函数名；内置模块（装好即有，仍需 import）与第三方模块（需先 pip install）的区别。
- [53:35] pip 与清华源：`pip install xxx`；国外包可能卡住，加 `-i` 换清华源；不必背，问 AI 即可。
- [55:28] 自定义模块与包：一个 .py 即模块；文件夹要做包必须有 `__init__.py`（可为空），否则不被当作包；引用用点表示从属，不是路径斜杠。
- [58:25] 如何学一个库：读官方文档（费时）、看样例/经典项目、看 IDE 提示；最推荐问 AI——直接说需求即可让 AI 选库给用法。
- [1:00:19] 异常处理：try/except/else/finally；场景是长跑任务（爬虫过夜、训练实验的重复循环）外层包 try，单条报错不影响整体。
- [1:03:16] 断点调试：breakpoint() 进入 pdb 交互终端，可查看变量值；可设条件断点；c 继续、q 退出。
- [1:06:35] 文件操作：推荐 with open，缩进块结束自动关闭；模式 r 只读、w 只写（会清空原文件，小心别毁实验结果）、a 追加；read/readline/readlines 三种读法。
- [1:08:54] conda 环境管理：不同项目包版本可能冲突污染，conda 给独立隔离环境；`conda create -n example python=3.9`（不指定版本可能非最新）；`-` 是缩写、`--` 是全称；activate/deactivate 切换；包只装进激活的环境。
- [1:13:14] requirements.txt 与协作：一人导出依赖清单上传 GitLab（转写"GITAB"），协作者 `pip install -r requirements.txt` 一次装齐；暑培项目本身有该文件可参考。
- [1:15:17] 结尾：附往年数培资料、科协技能引导文档、官方文档与 CSDN 等资源。
