## 🎯 使用建议

### 按场景选择

| 场景 | 推荐内容 |
|------|----------|
| 🚶 通勤/散步 | 播客、有声书 |
| 🏠 宅家放松 | 纪录片、B站长视频 |
| 🧘 睡前/冥想 | 人文播客、治愈有声书 |
| 💻 想学习技能 | B站教程、MOOC、GitHub项目 |
| 🎧 练英语听力 | 英文播客、TED演讲 |
| 🍚 下饭/摸鱼 | B站中短视频、趣味纪录片 |

### 按心情选择

- **想深度思考** → 哲学播客、人文UP主、TED经典
- **想轻松愉快** → 趣味科普、克拉克森的农场、故事FM
- **想涨知识** → 历史UP主、科技纪录片、计算机课程
- **想治愈放松** → 自然纪录片、水彩绘画、治愈有声书
