# 联想拯救者电脑保养手册

> 适用对象：已经使用约 1 年、缺少电脑维护经验的联想拯救者笔记本用户。  
> 执行原则：先备份、少折腾、不拆机；看不懂的高级设置保持默认。  
> 说明：不同型号的软件名称和菜单可能略有不同，以电脑中实际显示为准。

## 一、先记住 8 条原则

1. 电脑必须放在坚硬、平整的桌面上使用，不要放在床、沙发、被子或腿上堵住进风口。
2. 玩游戏、渲染、训练模型等高负载任务时接通原装电源，并保持出风口周围至少 10 厘米无遮挡。
3. 日常不要长期把电量用到 0%；经常插电使用时开启“电池养护/保养模式”。
4. 不安装“驱动大师”“系统加速”“垃圾清理神器”等第三方管家软件。
5. 驱动优先通过 Windows 更新、联想电脑管家、Lenovo Vantage 或拯救者领域更新。
6. BIOS 更新期间绝不能关机、拔电源或强制重启。
7. 清洁前必须关机、拔掉电源；液体不能直接喷在电脑上。
8. 重要文件至少保留两份，电脑硬盘里的唯一一份不算备份。

## 二、今天就做：一年后的首次保养

按下面顺序执行，预计需要 40～60 分钟。

### 1. 先备份重要文件

- [ ] 将桌面、文档、图片、课程资料、项目代码和聊天软件接收的重要文件复制到移动硬盘或可信云盘。
- [ ] 随机打开 3～5 个备份文件，确认不是空文件且可以正常打开。
- [ ] 项目代码如果使用 Git，确认未提交的重要修改也有副本。

### 2. 检查磁盘空间

1. 打开“设置 → 系统 → 存储”。
2. 查看系统盘（通常是 C 盘）剩余空间。
3. 尽量让 C 盘至少保留 15%～20% 的可用空间；最低不要长期低于 30 GB。
4. 可以删除“临时文件”、回收站内容和确认无用的下载文件。

不要手动删除 `Windows`、`Program Files`、`ProgramData` 或不认识的系统文件夹。

### 3. 完成正规更新

- [ ] 打开“设置 → Windows 更新”，检查更新并重启。
- [ ] 打开电脑自带的联想软件，例如“联想电脑管家”“Lenovo Vantage”或“拯救者领域”，执行硬件检测和驱动检查。
- [ ] 普通驱动可以按提示更新；电脑当前稳定时，不必为了版本号最新而到处下载驱动。
- [ ] BIOS 只有在联想官方工具明确推荐、修复了与你相关的问题或系统确有需要时再更新。

更新 BIOS 时：接上原装电源，电量保持在 30% 以上，关闭其他程序，更新完成前不要碰电源键。拿不准时跳过，交给联想官方售后。

### 4. 开启电池养护模式

如果电脑大部分时间插电使用：

1. 打开联想电脑管家、Lenovo Vantage 或拯救者领域。
2. 在“电源”“电池”或“设备设置”中寻找“养护模式”“保养模式”或“Conservation Mode”。
3. 开启后，电量通常会限制在约 55%～80%，具体数值由型号决定。这是正常现象，不是充不满。

如果经常带电脑外出，需要最长续航，可以在出发前关闭该模式并充满，回到长期插电环境后再开启。

### 5. 清洁外部和散热口

准备：干净的超细纤维布、软毛刷；如使用罐装压缩空气，应短促、低压吹气。

1. 正常关机，不要只合上盖子。
2. 拔掉电源和所有外设，等待 5 分钟。
3. 用干燥软布擦机身和屏幕。顽固污渍可将布微微蘸湿，不能滴水。
4. 用软毛刷轻扫键盘缝隙和机身进、出风口表面。
5. 发现风口有浮尘时，只从外部轻轻清理，不要把工具伸入内部。

禁止事项：

- 不把酒精、清洁剂或水直接喷到屏幕、键盘和接口上。
- 不用湿巾大力擦屏幕，不用纸巾反复摩擦屏幕。
- 不用吹风机热风吹，不用家用吸尘器贴着风口猛吸。
- 电脑小白不建议自行拆后盖、拔电池、拆风扇或更换硅脂。

### 6. 做一次运行状态观察

完成清洁后开机，分别观察 10 分钟日常使用和 20～30 分钟游戏/高负载使用：

- [ ] 风扇转动时没有明显刮擦声、持续异响或剧烈振动。
- [ ] 没有突然关机、蓝屏、花屏或充电断断续续。
- [ ] 游戏帧率没有比刚买时明显下降，键盘表面没有出现异常烫手区域。
- [ ] 出风口能感觉到热风排出，左右风扇表现没有明显异常。

游戏时 CPU 短时达到 90℃上下不一定代表故障，拯救者不同型号的功耗和温度策略不同。比单次温度更重要的是：温度是否比过去明显升高、性能是否持续下降、风扇是否异常、是否自动关机。

## 三、正确的日常使用方法

### 放置和散热

- 使用坚硬桌面；需要改善散热时，可使用稳固的笔记本支架抬高后部。
- 支架不能挡住底部进风口。普通支架通常已经足够，不必盲目购买高转速散热底座。
- 夏天尽量在通风或空调环境中运行高负载任务。
- 不在电脑旁放水杯；必须放时，放到不容易碰倒且不会流向电脑的一侧。
- 合盖或装包前确认电脑已睡眠稳定或完全关机，避免电脑在包内继续发热。

### 性能模式

拯救者通常可用 `Fn + Q` 切换模式，指示颜色和名称以实际型号为准。

| 使用场景 | 建议模式 |
|---|---|
| 上网、写文档、看视频 | 安静或均衡模式 |
| 编程、普通软件、多任务 | 均衡模式 |
| 游戏、渲染、模型训练 | 接通原装电源后使用性能模式 |
| 电池供电、外出使用 | 安静或节能模式 |

不要为了“保护电脑”而完全禁止风扇高速转动。高负载时风扇加速是在保护硬件。

### 电池习惯

- 长期插电：开启电池养护模式即可，不需要每天拔插电源。
- 外出用电池：电量降到约 20% 时及时充电，偶尔低于此数值不用紧张。
- 不需要每月故意用到 0% 再充满；深度放电反而增加电池损耗。
- 避免在高温环境中一边满电充电一边长时间高负载运行。
- 连续数周不用电脑：关机后让电量保持在约 40%～60%，放在阴凉干燥处，每 1～2 个月检查一次电量。

电池属于消耗品，使用一年后容量下降是正常现象。若电池鼓包、触控板或外壳被顶起、闻到异味、局部异常发热，应立即关机断电并送官方售后，停止继续充电。

### 开关机习惯

- 每周至少正常重启一次，让系统完成更新并释放长期占用的资源。
- 短时间离开可睡眠；装包、长途携带或数天不用时选择关机。
- 程序卡住时先按 `Ctrl + Shift + Esc` 打开任务管理器结束无响应程序；只有系统完全无反应时，才长按电源键强制关机。

## 四、软件维护与安全

### 每月一次

1. 执行 Windows 更新并重启。
2. 用联想官方软件检查驱动和硬件状态。
3. 打开“Windows 安全中心”，确认病毒和威胁防护正常，执行一次快速扫描。
4. 打开“设置 → 应用 → 启动”，关闭确认不需要开机自启的软件。
5. 整理下载目录和回收站，检查 C 盘剩余空间。
6. 检查重要文件的备份是否仍能打开。

### 软件安装原则

- 软件尽量从官网、Microsoft Store 或可信的开源项目主页下载。
- 安装时逐项看清复选框，取消捆绑软件、浏览器主页修改和多余开机启动项。
- Windows 自带安全中心对普通用户通常已经够用，不要同时安装多个杀毒软件。
- 不使用注册表清理、内存加速、驱动全自动更新或“极限优化”工具。
- 显卡驱动没有故障时不必频繁更新；新游戏需要支持或旧驱动出现问题时再更新。

## 五、保养时间表

| 频率 | 要做的事 | 预计用时 |
|---|---|---:|
| 每天 | 硬桌面使用、不堵风口、远离液体、观察异常声音和发热 | 1 分钟 |
| 每周 | 正常重启一次；备份本周新增的重要文件 | 10 分钟 |
| 每月 | Windows 更新、联想官方检测、快速病毒扫描、检查磁盘空间 | 20 分钟 |
| 每 2～3 个月 | 关机断电后清洁屏幕、键盘和风口表面 | 15 分钟 |
| 每 6～12 个月 | 比较温度、噪声和性能变化；检查电池、接口和内部积灰情况 | 30 分钟 |
| 出现异常时 | 停止高负载使用，备份数据，按下表判断是否送修 | 视情况 |

## 六、内部清灰、风扇和硅脂维护

这一部分属于完整保养项目，但不等于都要自己动手。你是电脑小白，建议由联想官方售后或可信的专业维修人员操作。

### 1. 内部清灰

笔记本内部需要关注的不是机壳表面灰尘，而是：

- 风扇叶片上的积灰。
- 散热鳍片与出风口之间形成的灰尘堵塞。
- 主板、接口和扬声器附近的浮尘或异物。
- 风扇轴承是否异响、松动或转速异常。

一般可以每 12～18 个月检查一次。家里灰尘多、养宠物、经常吸烟，或电脑常在床上使用时，可提前到 6～12 个月检查。环境干净、温度和噪声没有明显变化时，不必为了日期强行拆机。

需要内部清灰的信号：

- 相同游戏、相同室温下，温度比以前持续高出约 10℃或更多。
- 风扇比以前更容易高速运转，但游戏性能反而下降。
- 出风量明显变小，左右出风差异很大。
- 能从风口看到成团灰尘，或风扇出现异常声音。

内部清灰通常需要拆后盖并断开内置电池。操作不当可能损坏卡扣、风扇线、主板元件或造成静电损伤，所以本手册不建议电脑小白自行操作。

### 2. 硅脂和其他导热材料

“硅脂”只是常见叫法。不同拯救者型号可能使用普通导热膏、相变导热材料、液态金属或特定厚度的导热垫，不能在不知道原厂方案时统一换成普通硅脂。

不要把“每年换一次硅脂”当成固定任务。是否更换应根据温度、性能和导热材料状态判断：

- 使用约 1 年，温度和性能正常：通常只检查积灰，不需要拆散热模组换硅脂。
- 使用 2～3 年以上，清灰后仍明显高温或降频：可以让专业人员检查导热材料。
- 散热模组已经被拆下：重新安装时通常必须按原厂规格处理导热材料。
- CPU 与 GPU 温差异常、温度快速冲高并持续降频：可能存在接触、涂覆或散热模组问题，需要专业检测。

错误更换的风险包括：

- 普通硅脂性能不如原厂相变材料，短期看似正常，之后温度反而上升。
- 导热垫厚度错误会把散热器顶起，导致 CPU 或 GPU 接触不良。
- 液态金属具有导电风险，溢出可能导致主板短路。
- 螺丝受力顺序或力度错误，会造成接触不均甚至损伤芯片周边。

因此，不要自行购买“高导热硅脂”就直接更换，也不要让维修人员在未确认型号和原厂材料前随意替换。

### 3. 交给售后时怎么说

可以直接向工作人员提出以下要求：

> 我的拯救者已经使用约一年，请检查风扇和散热鳍片积灰、风扇异响、电池状态及高负载温度。先清灰并检测，不要在未确认原厂导热材料类型和确有必要前更换硅脂、相变材料或导热垫。

维护前后最好记录：

- 相同室温、相同性能模式和相同软件下的 CPU、GPU 温度。
- 游戏帧率或跑分是否恢复。
- 风扇噪声、出风量和是否仍有异常。
- 实际使用的导热材料品牌、类型以及导热垫厚度。

拆机前先询问是否影响保修，并确认服务人员是否熟悉你的准确型号。部分机型的散热材料和结构不同，不能只凭“都是拯救者”来处理。

### 4. 其他内部硬件检查

在内部维护时可以一并检查，但没有异常就不要随意更换：

- 电池是否鼓包、渗漏或固定不牢。
- 风扇轴承和排线是否正常。
- SSD、内存和无线网卡是否固定牢靠。
- SSD 散热片或导热垫是否移位、破损。
- 转轴固定处、后盖卡扣和螺丝是否损坏。
- 主板是否存在液体、腐蚀、烧灼或异常灰尘痕迹。

## 七、什么时候需要送官方售后

出现以下任一情况，不建议电脑小白继续自行处理：

- 电池鼓包、外壳被顶起、有异味、冒烟或异常烫手。
- 风扇有刮擦、撞击、尖锐啸叫，或一侧风扇疑似不转。
- 频繁自动关机、蓝屏、花屏，或开机反复失败。
- 充电接口松动、冒火花、充电反复中断，或原装适配器异常发烫、有破损。
- 进水、饮料泼入、摔落或受到明显撞击。
- 清理外部风口后，温度和性能仍比以前明显恶化。
- 屏幕转轴异常紧、松动或开合时发出破裂声。

进液后不要反复开机测试，也不要继续充电。立即拔电源、关机，擦去表面液体并尽快联系官方售后。不要用吹风机加热，也不要自行用米吸水。

联想官方服务可通过电脑内置联想软件、联想官网服务页面或官方客服电话查询。送修前先备份数据，记录故障现象，并确认当前是否仍在保修期内。

## 九、最简执行版

如果不想记太多，只坚持下面 6 件事：

- [ ] 永远放在硬桌面使用，不堵住底部和侧后方风口。
- [ ] 长期插电就开启电池养护模式，高负载时使用原装电源。
- [ ] 每周备份重要文件并重启一次。
- [ ] 每月做 Windows 更新、联想官方检测和磁盘空间检查。
- [ ] 每 2～3 个月关机断电，用软布和软毛刷清理外部。
- [ ] 每 12～18 个月根据积灰、温度和噪声决定是否请专业人员内部清灰；不要按年份强制换硅脂。
- [ ] 遇到鼓包、进水、异响、频繁蓝屏或自动关机，停止折腾并送官方售后。
