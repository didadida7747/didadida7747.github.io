# 电子信息 / 计算机核心课程学习地图（本校 · 2025 级）

> 适用：本校 电子信息工程（电子信息类）2025 级本科生，主线为「核心软件 / AI 应用 + 后端」就业
> 作用：把四年要上的课按「地基 → 核心 → 方向」分层，说清每门课**重不重要、难在哪、用什么资源学、和求职 / 保研什么关系**
> 口径：课程名称与学分以你所在学院**当年培养方案**为准（电子工程学院、通信工程学院、集成电路学部等开课清单略有差异）；本图按电子信息类通用主线整理。

## 〇、一张图看懂课程层次

```
第四层  专业方向课（大三）  通信原理·DSP·电磁场·自控·图像处理·雷达·操作系统·网络·软件工程
                         └── 决定你往哪个方向走，也是面试 / 考研专业课
第三层  专业核心基础（大二下~大三上，最重）
        信号与系统 · 模拟电子 · 数字电路 · 微机原理(STM32) · 数据结构与算法
                         └── 电子信息的"心法"和求职笔试的"硬通货"，绩点和保研的主战场
第二层  专业入门（大一末~大二）
        C语言程序设计 · 电路分析基础 · 工程图学 · 各类实验课
                         └── 编程与电路的第一级台阶，入门体验决定后面信心
第一层  数理公共基础（大一为主）
        高等数学 · 线性代数 · 概率论与数理统计 · 场论与复变 · 大学物理 · 英语
                         └── 一切的地基，学分最重、最拉绩点，也是 AI / 考研数学底座
```

**记忆口诀**：数理是语言，电路与信号是心法，编程与数据结构是饭碗，方向课是标签。

## 一、第一层：数理公共基础（大一，学分最重）

> 这一层课的共同特点：**学分高、前后衔接强、靠平时刷题、考前突击难救命**。它们直接决定大一绩点排名，而大一排名是保研盘子里最稳的一块。

### 高等数学（上 / 下）
- **权重 / 难度**：学分通常最高一档（两学期合计 10+ 学分）；难度 ★★★★。
- **为什么重要**：绩点第一大户；信号与系统、电磁场、DSP、自动控制全靠微积分；考研数学（数一 / 数二）半壁江山；AI 里的梯度、优化也要它。
- **学什么 / 难点**：极限、导数、中值定理、不定 / 定积分、多元微分、重积分、曲线曲面积分、级数、微分方程。
- **资源**：
  - 教材：同济大学《高等数学》（主流指定教材）。
  - B 站：**宋浩**（讲得细、适合零基础同步跟）；考研拔高可看**武忠祥**（强化课，适合学完一轮后）。
  - 刷题：课本例题 + 课后题 + 学校往年期末题（找学长学姐 / 打印店）。
- **方法 / 坑**：每章学完立刻做题，别攒到期末；中值定理证明、级数敛散、三重 / 曲线曲面积分是你正在攻的硬骨头，配合画图和物理意义理解，别死背公式。

### 线性代数
- **权重 / 难度**：学分高；难度 ★★★（入门抽象，入门后套路强）。
- **为什么重要**：**机器学习 / AI 的核心数学语言**（矩阵运算、特征值、线性变换）；图形学、控制理论、信号处理都用；考研数学必考。
- **学什么 / 难点**：行列式、矩阵、向量组与秩、线性方程组、特征值与特征向量、二次型。
- **资源**：
  - 教材：同济《线性代数》。
  - B 站：**宋浩** 线代（同步）；**3Blue1Brown《线性代数的本质》**（建立几何直觉，强烈推荐，看完"秩 / 特征值"会通透）。
- **方法 / 坑**：线代最怕"只会算不懂为什么"，先看本质系列建立直觉，再刷题；矩阵初等变换是基本功，要练到又快又不出错。

### 概率论与数理统计
- **权重 / 难度**：学分较高；难度 ★★★。
- **为什么重要**：机器学习（概率模型、贝叶斯、分布假设）、随机信号分析、算法分析的基础；考研数学一大块。
- **学什么 / 难点**：随机事件与概率、随机变量及分布、数字特征、大数定律与中心极限定理、参数估计与假设检验。
- **资源**：浙江大学 盛骤《概率论与数理统计》（主流教材）；B 站 宋浩 / 考研向 余丙森。
- **方法 / 坑**：把"分布"当主角学，常见分布（二项、泊松、均匀、指数、正态）的条件和数字特征要背熟；数理统计部分概念多，理清"用样本推断总体"的逻辑。

### 场论与复变函数
- **权重 / 难度**：学分中等；难度 ★★★。
- **为什么重要**：电磁场与电磁波（梯度 / 散度 / 旋度）、信号与系统的复频域（拉普拉斯、Z 变换）、DSP 的直接前置。
- **方法 / 坑**：复变的留数、场论的"三度"是重点，结合后续专业课学更有方向感，别孤立地背算子公式。

### 大学物理
- **权重 / 难度**：学分高；难度 ★★★。
- **为什么重要**：电磁学部分给模电、电磁场提供物理直觉；也是不少专业必修、计绩点。
- **方法 / 坑**：重点跟**电磁学**（电场、磁场、电磁感应），力学热学按要求过关即可；公式多但题型固定，刷往年题性价比高。

### 大学英语（四六级）
- **权重 / 难度**：学分高；难度因人而异。
- **为什么重要**：**四级是很多学校毕业 / 学位的隐性门槛，六级是保研、求职（尤其大厂 / 外企）、留学的加分 / 硬指标**；看英文文档、论文、报错信息是程序员日常。
- **行动**：**大一尽早把四级高分过掉，大二上冲六级**，越往后越没时间；背考研 / 四六级核心词 + 刷真题听力阅读。口语 / 听力训练见 `09_课外技能学习资源库/07_表达类/英语口语.md`。

## 二、第二层：专业入门（大一末 ~ 大二）

### C 语言程序设计
- **权重 / 难度**：专业第一门编程课，学分高；难度 ★★★（对零基础是思维转换关）。
- **为什么重要**：嵌入式 / 单片机（STM32）的主力语言；后续 C++、数据结构、操作系统的地基；**也是你区别于"只会调包"的内功**。
- **学什么 / 难点**：数据类型、分支循环、函数、数组、指针（最大难点）、结构体、文件、内存与栈堆。
- **资源**：
  - 教材：谭浩强《C 程序设计》（很多学校指定，入门够用，但部分写法偏老）。
  - 中国大学 MOOC：**翁恺《C 语言程序设计》（浙江大学）**——公认讲得好。
  - B 站：**鹏哥 C 语言**（比特，偏就业、讲得细，含指针 / 内存）。
  - 刷题：PTA（本校很多作业就在类似 OJ）、洛谷入门题、力扣简单题。
- **方法 / 坑**：**指针和内存是分水岭**，务必动手在 VS Code / Dev-C++ 里调试，画内存图；别只看视频不敲代码。你 99 文件夹里的 `dec2bin.py` 等作业就是练手，保留好。

### 电路分析基础
- **权重 / 难度**：专业核心地基，学分高；难度 ★★★。
- **为什么重要**：模电、高频 / 射频、信号处理的地基；电赛硬件方向必备。
- **学什么 / 难点**：基本定律（KCL/KVL）、等效变换、电路定理（戴维南 / 诺顿）、一阶 / 二阶动态电路、正弦稳态相量分析。
- **资源**：邱关源《电路》（经典教材）；B 站 **石群电路**（讲得系统）、各类"电路"同步课。
- **方法 / 坑**：相量法、动态电路的三要素是重点；多画等效电路、列方程，别凭感觉。

### 工程图学与计算机绘图 / 实验课
- **定位**：学分中等，重在规范与动手。
- **提示**：**实验课（电路信号与系统实验、电子线路实验等）别水**——一是锻炼动手和排错，二是实验报告 / 平时成绩计入绩点，三是电赛、嵌入式、PCB 的实操自信从这里来。你已有的 STM32 / PCB 基础可以在实验课上拉开差距。

## 三、第三层：专业核心基础（大二下 ~ 大三上，绩点 + 保研 + 求职主战场）

> 这一层是电子信息类学生的"分水岭"，课程硬、学分重、互相咬合。**想保研，这一层门门要高分；想就业，数据结构 + 一门扎实的系统课（微机 / 操作系统）是硬通货。**

### 信号与系统 ⭐（电子信息"第一心法"）
- **权重 / 难度**：专业核心，学分高；难度 ★★★★★（抽象、数学密度大）。
- **为什么重要**：DSP、通信原理、自动控制、图像处理的总前置；**考研 / 保研面试高频考点**；串起你学过的微积分、线代、复变。
- **学什么 / 难点**：信号与系统分类、**卷积**、傅里叶级数 / 变换、拉普拉斯变换、Z 变换、系统稳定性与频率响应。
- **资源（含本校自家精品课）**：
  - 教材：郑君里《信号与系统》（清华，常用）；奥本海姆《信号与系统》（国外经典，讲直觉）。
  - **B 站：郭宝龙《信号与系统》——本校国家级精品课程 / 资源共享课，本校老师、贴合本校大纲，首选跟这个。**
- **方法 / 坑**：四大变换（傅里叶 / 拉普拉斯 / Z / 卷积）是主线，**自己动手推导 + 整理变换对照表**；每章配大量计算题，卷积图解、零极点判稳必练。

### 模拟电子技术基础（模电）
- **权重 / 难度**：专业核心，学分高；难度 ★★★★★（公认"魔鬼课"，挂科率高）。
- **为什么重要**：硬件、电源、信号链、电赛的地基；理解真实器件非理想特性；保研 / 考研专业课。
- **学什么 / 难点**：半导体器件、二极管、**三极管放大电路（静态 / 动态分析）**、场效应管、**集成运放与反馈**、功率放大、直流电源。
- **资源**：
  - 教材：童诗白 / 华成英《模拟电子技术基础》（清华，主流）。
  - B 站：**华成英 模电**（清华，配套教材、最权威）；同步辅导可搜"模电"名校课。
- **方法 / 坑**：**反馈组态判断、运放电路、三极管微变等效是三座大山**；"先静态后动态"的分析顺序要形成肌肉记忆；配合实验课拿示波器看真实波形，能极大降低抽象感。

### 数字电路与逻辑设计（数电）
- **权重 / 难度**：专业核心，学分高；难度 ★★★（比模电友好，套路清晰）。
- **为什么重要**：衔接 STM32 / FPGA / 数字逻辑设计；理解计算机硬件怎么由门搭起来；电赛、集创赛常用。
- **学什么 / 难点**：数制与码制、逻辑代数、**组合逻辑（译码 / 编码 / 数据选择）**、触发器、**时序逻辑（计数器 / 移位寄存器）**、脉冲电路、可编程器件入门。
- **资源**：阎石《数字电子技术基础》（清华）；B 站 **王红 数电**（清华，配阎石教材）。
- **方法 / 坑**：时序逻辑的"状态转移图 / 表"是核心；用卡诺图化简、同步时序分析要熟练；有兴趣可上手 Verilog + FPGA，和你嵌入式背景互补。

### 微机原理与系统设计（单片机 / STM32）
- **权重 / 难度**：专业核心；难度 ★★★（偏工程，动手多）。
- **为什么重要**：**你已经在做 STM32 + PID + PCB，这是你当前最强的差异化能力**；电赛、嵌入式岗、智能车、集创赛的核心。
- **资源**：
  - B 站：**江协科技 STM32 入门教程**（免费、体系完整，学生党口碑最好，也是你赚钱调研里对标的对象）；**正点原子**（资料 / 例程全，适合查）。
  - 动手：一块开发板 + 数据手册 + 逐外设点灯（GPIO→中断→定时器→PWM→ADC→串口→DMA）。
- **方法 / 坑**：别只抄例程，**每个外设理解寄存器 / HAL 在干什么**；结合你的 PID 项目做一个闭环小系统（电机 / 平衡 / 温控），就是简历和电赛作品。

### 数据结构与算法（计算机方向求职核心）
- **权重 / 难度**：学分高；难度 ★★★★。
- **为什么重要**：**后端 / AI 应用岗笔试面试第一筛**（大厂手撕代码）；也是你从"电子"跨到"软件"的钥匙；考研 408 之一。
- **学什么 / 难点**：复杂度分析、线性表 / 栈 / 队列、串、树（二叉树、BST、堆）、图、查找、排序，以及递归 / 双指针 / 动归 / 回溯等算法思想。
- **资源**：
  - 教材：严蔚敏《数据结构》；**王道《数据结构考研复习指导》**（应试体系最全）。
  - 中国大学 MOOC：浙江大学 **陈越《数据结构》**。
  - B 站：青岛大学 **王卓 数据结构**（讲得细，适合入门）。
  - 刷题：**力扣 LeetCode**（按标签刷，Hot 100 / 剑指 Offer）、CodeTop（按目标公司查高频题）。
- **方法 / 坑**：**数据结构是"练"出来的，不是"看"出来的**；边学边在力扣刷对应标签，先保数量（200 题打底）再求套路；递归和动归是难点，画图 + 拆解子问题。

## 五、绩点（GPA）怎么算、怎么用

### 两种算法，别混淆
1. **平均学分绩（百分制，校内排名 / 保研用这个）**
   - 一门课学分绩 = 课程成绩（百分制）× 学分数
   - **平均学分绩 = ∑(课程成绩 × 学分) ÷ ∑课程学分**
   - 即"学分加权平均分"，学分越高的课对排名影响越大。
2. **平均绩点 GPA（4 分制，主要用于出国 / 留学申请）**
   - 课程绩点公式：`4 − 3×(100 − X)² / 1600`（60 ≤ X ≤ 100）
   - 100 分 = 4.0，60 分 = 1.0；如 90–94 对应 A（3.9 档）。
   - 平均 GPA = ∑(课程绩点 × 学分) ÷ ∑学分。
   - 依据《本校本科生平均绩点（GPA）计算方法》。

### 绩点策略（性价比排序）
- **优先保高学分必修课**（高数、英语、电路、信号、模电、数电等），它们在加权里权重最大。
- **必修 / 主干课不能挂**：保研看的就是前三年主干必修；一旦补考 / 重修通过，**推免排名时该课按 60 分计**，基本告别保研。
- 考查课 / 选修课别完全不管，按"用最小努力拿高分"处理，很多也计加权或影响奖学金评定。
- 每学期末对照培养方案，自查已修学分和排名，别等大三才算账。

## 六、通用学习方法（理工科硬课通用）

1. **平时 > 突击**：数理和"电子三剑客"（电路 / 模电 / 信号）靠累积，考前一周救不回来；每周固定时间消化 + 做题。
2. **课本例题 + 课后题 + 往年真题三件套**：本校期末题型相对稳定，往年题（学长学姐、打印店、校园群）是最高效的备考资料。
3. **建立知识框架，而非孤立背公式**：每门课用一张 A4 纸 / 思维导图梳理主线（如信号的"四大变换对照表"）。
4. **动手验证抽象知识**：模电用示波器看波形、信号用 MATLAB / Python 画频谱、C 语言用调试器看内存——动手一次胜过看十遍。
5. **用好本校资源**：本校的信号与系统（郭宝龙）、通信原理（樊昌信）、DSP（高西全）、操作系统（汤小丹）等都是本校名家 / 名课，听本校老师的课最贴大纲。
6. **组队但不依赖**：实验、备考可以和同学讨论，但作业和代码要自己过手，否则绩点和能力都是空的。
7. **每门课留好资料**：课件、自己整理的笔记、错题、项目代码分类归档，既是复习资产，也能沉淀成 `09_课外技能学习资源库` 里的原创内容。
