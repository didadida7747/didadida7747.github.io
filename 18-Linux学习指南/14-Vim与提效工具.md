# 第 14 章 Vim 与提效工具

> 学完这章，你在终端里改配置文件不再"手抖得像用鼠标拖"——Vim 让你盲打改代码，tmux 让你断网也不丢会话，一堆快捷键让你命令行速度翻倍。

## 本章你将学会

- 搞懂 Vim 的四种模式，能用它改完一个配置文件
- 记住最常用的移动、编辑、搜索、替换命令
- 用可视模式批量改东西，用分屏同时看两个文件
- 配一份最小 `.vimrc`，知道插件管理器是什么
- 用 Tab 补全、`Ctrl+R` 历史搜索、`!!` 等快捷键加速终端
- 用 tmux 开多个会话、断网重连不丢东西
- 知道 fzf、ripgrep、bat 这些现代工具是干嘛的（不强制学）

## 14.1 为什么要学 Vim

你可能会问："我用 VS Code 不好吗，为什么学 Vim？"

答案是：**服务器上没有图形界面。** 你 SSH 登录一台云服务器，就是个黑窗口，连个鼠标都没有。要改 nginx 配置、改 `.bashrc`、看日志，你总得有个能用的编辑器。Linux 下最通用、最强大的就是 Vim（或者它的近亲 nano）。

而且 Vim 的设计哲学是"手不离开键盘主键区"——熟练后你改代码比用鼠标快得多。

先有个心理准备：Vim 上手**特别反人类**（它最出名的操作是"怎么退出"），但一旦过了前 2 小时的门槛，会回不去。

---

## 14.2 Vim 哲学与四种模式

Vim 和普通编辑器最大的区别是**它有模式**。同一个按键，在不同模式下作用完全不同。四种核心模式：

| 模式 | 干什么 | 怎么进 | 怎么出去 |
|---|---|---|---|
| **普通模式 Normal** | 移动、复制、删除——刚打开文件默认在这 | `Esc` | —— |
| **插入模式 Insert** | 真正打字 | 普通模式下按 `i`/`a`/`o` 等 | `Esc` 回普通模式 |
| **可视模式 Visual** | 选中一段文字 | 普通模式下按 `v`/`V`/`Ctrl+v` | `Esc` |
| **命令模式 Command** | 保存、退出、搜索替换 | 普通模式下按 `:` | 回车执行 / `Esc` |

> 📌 **注意：** 不知道自己在什么模式了？**按一下 `Esc`**，回到普通模式永远是安全的。新手 90% 的慌乱都是因为"我刚才按了啥怎么键盘不对了"——`Esc` 一下就好。

退出 Vim 的三种方式（世界名梗）：

| 按键 | 含义 |
|---|---|
| `:wq` 回车 | 保存并退出（write + quit） |
| `:q!` 回车 | **不保存强制退出**（改坏了想溜） |
| `:w` 回车 | 只保存不退出（可以一直按 `:w` 存盘） |

## 14.3 移动：手不离开主键区

普通模式下，光标移动用这几个键（设计初衷是当年的键盘没有方向键）：

| 按键 | 移动 |
|---|---|
| `h` | 左 |
| `j` | 下（像个钩子往下） |
| `k` | 上 |
| `l` | 右 |

按单词跳：

| 按键 | 移动 |
|---|---|
| `w` | 下一个单词开头（word） |
| `b` | 上一个单词开头（back） |
| `e` | 当前/下一个单词结尾 |

行内跳转：

| 按键 | 移动 |
|---|---|
| `0` | 行首 |
| `^` | 行首第一个非空字符 |
| `$` | 行尾 |

文件级跳转：

| 按键 | 移动 |
|---|---|
| `gg` | 文件第一行 |
| `G` | 文件最后一行 |
| `数字G` | 跳到第 N 行（比如 `10G` = 第 10 行） |
| `Ctrl+d` | 下翻半屏 |
| `Ctrl+u` | 上翻半屏 |

**数字 + 动作 = 重复 N 次**，这是 Vim 的核心语法：

```bash
3w      # 往后跳 3 个单词
5j      # 往下跳 5 行
10dd    # 删 10 行（见下文）
```

## 14.4 进入插入模式

普通模式下按下面哪个键进插入模式，取决于你想在哪开始打字：

| 按键 | 从哪开始插入 |
|---|---|
| `i` | 光标**前**插入（insert） |
| `a` | 光标**后**插入（append） |
| `I` | 当前行**行首**插入 |
| `A` | 当前行**行尾**插入 |
| `o` | 当前行**下面**新开一行插入 |
| `O` | 当前行**上面**新开一行插入 |

记住这 6 个就够用一辈子。`Esc` 回普通模式。

## 14.5 编辑：删、复制、粘贴、撤销

| 按键 | 作用 |
|---|---|
| `x` | 删除光标处一个字符 |
| `dd` | 删除（剪切）整行 |
| `yy` | 复制整行（yank） |
| `p` | 粘贴到光标**后**（put） |
| `P` | 粘贴到光标**前** |
| `u` | 撤销（undo） |
| `Ctrl+r` | 重做（redo） |
| `r` | 替换光标处一个字符（r + 新字符） |
| `cc` | 删除整行并进入插入模式（改一整行） |
| `>>` | 当前行右缩进 |
| `<<` | 当前行左缩进 |

> 💡 **小技巧：** `dd` 其实是"剪切"——你删了一行，`p` 就能把它粘贴到别处。所以"移动一行" = `dd` 剪切 → 光标挪到目标行 → `p` 粘贴。

**复制到系统剪贴板：** 默认 Vim 里的 `yy`/`p` 只在 Vim 内部。要复制到 Windows 那边（比如贴到浏览器），需要装 `vim-gtk` 或者用可视模式选中后按 `"+y`（`"+` 指系统剪贴板）。初学先知道有这回事，不用强求。

---

## 14.6 可视模式：批量选中

| 按键 | 进入什么可视模式 |
|---|---|
| `v` | 按字符选（拖蓝） |
| `V` | 按行选（整行拖蓝） |
| `Ctrl+v` | **按列块选**（竖着选几列，神器） |

选完之后按：

- `d` 删除选中
- `y` 复制选中
- `:s/old/new/` 对选中区域替换

**列块批量注释（最常用）：**

1. `Ctrl+v` 进入列块模式
2. 用 `j/k` 选中要注释的几行行首
3. 按 `I`（大写 i），输入 `#`
4. 按 `Esc`——所有选中行行首都加上 `#` 了

## 14.7 搜索与替换

**搜索：**

| 按键 | 作用 |
|---|---|
| `/关键词` | 向下搜索，回车 |
| `?关键词` | 向上搜索 |
| `n` | 下一个匹配（next） |
| `N` | 上一个匹配 |
| `:%s/old/new/g` | 全文把 old 换成 new |

替换的语法是 `:s/旧/新/标志`：

| 写法 | 作用 |
|---|---|
| `:s/foo/bar/` | 当前行第一个 foo 换成 bar |
| `:s/foo/bar/g` | 当前行所有 foo 换成 bar（g = global） |
| `:%s/foo/bar/g` | **整个文件**所有 foo 换成 bar |
| `:%s/foo/bar/gc` | 每个都问你一下（c = confirm，怕换错就加它） |

## 14.8 `.` 命令：重复上一次操作

`.` 是 Vim 里被低估的神键——**重复你上一次的修改动作**。

比如你删了一行（`dd`），挪到另一行按 `.`，又删一行。改了个词（`cwxxx Esc`），挪到下一个地方按 `.`，又改成一样的 xxx。

配合 `n`（下一个搜索匹配），你能做到：搜索 → 改一处 → `n` 跳下一处 → `.` 再改 → `n` → `.`……手指就这两个键，批量改完。

## 14.9 分屏：同时看两个文件

| 按键 | 作用 |
|---|---|
| `:sp 文件` | 水平分屏（上下） |
| `:vsp 文件` | 垂直分屏（左右） |
| `Ctrl+w` 然后 `h/j/k/l` | 在分屏之间切焦点 |
| `:q` | 关闭当前屏 |

改代码时一边看日志一边改源码，分屏是刚需。

## 14.11 最小 `.vimrc` 配置

Vim 默认配置很素。在你家目录建个 `~/.vimrc`，写几行最基本的：

```bash
$ nano ~/.vimrc
```

```vim
" ---------- 基础 ----------
set nocompatible          " 不兼容 vi（用现代 Vim 功能）
set number                " 显示行号
set cursorline             " 当前行高亮
set showmatch              " 括号配对高亮
set hlsearch               " 搜索结果高亮
set ignorecase             " 搜索时忽略大小写
set smartcase              " 但如果你输了大写就区分大小写
set tabstop=4              " Tab 显示为 4 个空格
set shiftwidth=4           " 缩进宽度
set expandtab              " Tab 自动转成空格（避免不同编辑器混乱）
set autoindent             " 自动缩进

" ---------- 按键 ----------
let mapleader=" "         " 把 leader 键设成空格（最顺手）
```

重启 Vim 就生效。

### 插件管理器（概念）

想给 Vim 加"文件侧边栏、代码补全、主题"这些功能，要装插件。主流是 **vim-plug**：

```bash
$ curl -fLo ~/.vim/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

然后在 `.vimrc` 里：

```vim
call plug#begin()
Plug 'preservim/nerdtree'      " 文件侧边栏
Plug 'vim-airline/vim-airline' " 底部状态栏
call plug#end()
```

打开 Vim 跑 `:PlugInstall` 就装好了。初学先别急着装插件——**先把原生 Vim 用熟**，等你觉得"我缺个 X 功能"再去搜对应的插件。

## 14.12 Shell 本身的快捷键

其实你不进 Vim，终端本身就有一堆黑科技快捷键。记住这几个，效率翻倍：

| 按键 | 作用 |
|---|---|
| `Tab` | 自动补全命令/文件名（按两下列所有） |
| `Ctrl+R` | **搜索历史命令**（输入关键词，翻出以前跑过的） |
| `Ctrl+A` | 光标跳到命令行开头（A = beginning） |
| `Ctrl+E` | 光标跳到命令行结尾（E = end） |
| `Ctrl+U` | 删掉光标到行首的内容 |
| `Ctrl+K` | 删掉光标到行尾的内容 |
| `Ctrl+W` | 删掉光标前**一个单词**（打错命令时神器） |
| `Ctrl+L` | 清屏（等同 `clear`） |
| `Ctrl+C` | 中断当前命令 |
| `Ctrl+D` | 退出当前 shell（等同 `exit`） |

**历史命令相关：**

```bash
$ history              # 看所有历史命令
$ !!                  # 上一条命令再跑一遍（最常用在"忘了加 sudo"：sudo !!）
$ !关键字              # 跑最近一条以"关键字"开头的命令
```

> 💡 **小技巧：** 你输了一条很长的命令，最后发现权限不够——别重打，直接 `sudo !!`，它会把上一条命令补到 sudo 后面执行。

**Tab 补全的隐藏用法：**

- 按一次 Tab：补全
- 按两次 Tab：列出所有可能

比如你输入 `git che` 按两下 Tab，它列出 `git checkout`、`git cherry-pick` 等所有以 `che` 开头的子命令。

## 14.13 tmux：断网不丢会话的分屏终端

### 为什么需要它

场景：你 SSH 登录云服务器，跑了一个训练任务，跑了 2 小时。**突然网断了 / 你本地电脑合盖了 / 你手滑关了终端**——SSH 一断，那个任务直接被杀。

**tmux** 解决这个：它是个"在服务器上跑的终端管理器"。你 SSH 进来开个 tmux 会话，跑命令，然后 **detach（离开）**——tmux 会话在服务器上继续活着，你关 SSH 也没事。下次重新 SSH 进来 **attach（接回）**，刚才那些窗口、日志、命令全都在原地。

类比：tmux 就像服务器上的一个"桌面"，你 SSH 是远程桌面客户端——你断开连接，桌面还在。

### 三个概念

| 名词 | 类比 |
|---|---|
| **会话 session** | 一个完整的"桌面"（你可以开多个工作：一个写代码、一个看日志） |
| **窗口 window** | 一个会话里的标签页（类似浏览器 Tab） |
| **窗格 pane** | 一个窗口里再分成几块（左右/上下） |

### 安装与基础命令

```bash
$ sudo apt install -y tmux
```

**prefix 键：** tmux 所有快捷键都先按一个"前缀键"，默认是 `Ctrl+b`（先同时按 Ctrl 和 b，松开，再按后面的键）。

| 命令/按键 | 作用 |
|---|---|
| `tmux new -s 名字` | 新建会话（-s 给它起名字） |
| `Ctrl+b` 然后 `d` | **detach：离开会话（会话还在后台跑）** |
| `tmux ls` | 列出所有会话 |
| `tmux attach -t 名字` | 接回某个会话 |
| `tmux kill-session -t 名字` | 杀掉会话 |

**会话里的窗口/窗格：**

| 按键（先按 Ctrl+b） | 作用 |
|---|---|
| `c` | 新建窗口（create） |
| `,` | 重命名当前窗口 |
| `n` / `p` | 切到下一个 / 上一个窗口 |
| `"` | 当前窗格水平切分（上下分） |
| `%` | 当前窗格垂直切分（左右分） |
| `方向键` | 在窗格之间切焦点 |
| `x` | 关闭当前窗格 |

**实战流程：**

```bash
# 1. SSH 登录服务器
$ ssh ubuntu@你的IP

# 2. 开个叫 work 的会话
$ tmux new -s work

# 3. 在里面跑你的任务（比如训练）
$ python train.py

# 4. 按 Ctrl+b 然后 d， detach——你可以安全关电脑了
[detached]

# 5. 下次重新 SSH 进来
$ ssh ubuntu@你的IP
$ tmux attach -t work
# 神奇：train.py 还在跑，输出还在！
```

> 📌 **注意：** tmux 不是必学，但**你一旦要在服务器上跑长任务，它就是救命的**。本地 WSL 里其实也可以用（你想同时开一个写代码、一个跑服务、一个看日志）。

## 14.14 现代工具简介（可选，不是必学）

下面这些工具是"老派 Unix 工具的现代替代品"，性能好、输出带颜色、参数更友好。**先把上面的基础用熟，再考虑装。**

| 工具 | 替代谁 | 优点 | 安装 |
|---|---|---|---|
| **fzf** | Ctrl+R 的增强版 | 历史命令、文件可以模糊搜索、上下键选 | `sudo apt install fzf` |
| **ripgrep (rg)** | grep | 快 10 倍，自动读 .gitignore | `sudo apt install ripgrep` |
| **bat** | cat | 带语法高亮、行号 | `sudo apt install bat` |
| **fd** | find | 文件名搜索，简单直观 | `sudo apt install fd-find` |
| **eza** | ls | 带颜色、图标、git 状态 | `sudo apt install eza` |
| **zsh + oh-my-zsh** | bash | 更好看的提示符、插件 | `sudo apt install zsh` 然后装 oh-my-zsh |

举个例子感受一下：

```bash
# 老派：在项目里找所有用到 requests 的地方
$ grep -rn "requests" .

# 现代：快得多，输出还带颜色
$ rg "requests"
```

> 💡 **小技巧：** 这些工具学一个加一个。别一天内全装上配得花里胡哨——你会在配环境上浪费一下午，正事没干。

### 一次配好你的"偷懒工具箱"

把 12 章的 alias 和本章的快捷键组合起来，你会发现终端速度飞起。在 `~/.bashrc` 末尾加这几行（按你喜好挑）：

```bash
# 常用 ls
alias ll='ls -alF'
alias la='ls -A'
alias l='ls -CF'

# 常用 cd
alias ..='cd ..'
alias ...='cd ../..'

# git 偷懒
alias gs='git status'
alias ga='git add'
alias gc='git commit -m'
alias gp='git push'

# 系统更新一行搞定
alias update='sudo apt update && sudo apt upgrade -y'

# 看 IP 偷懒
alias myip='curl -s https://ifconfig.me; echo'
```

```bash
$ source ~/.bashrc
```

以后你打 `gs` 就等于 `git status`，打 `update` 自动更新系统。**配置文件是慢慢长出来的**——你用了两周发现"这个命令我每天敲 10 遍"，再给它加 alias。

> 📌 **注意：** alias 只在交互式 shell 里有效，写进脚本里用不了。脚本里还是要写全命令。

## ⚠️ 危险操作与安全红线

> ⚠️ **警告：** Vim 里 `:w!` 会强制覆盖只读文件，`:q!` 会丢弃所有修改。搞清楚你在执行哪个再回车。

> ⚠️ **警告：** tmux 会话 detach 不是退出。你 detach 了它还在后台跑，跑满的话用 `tmux ls` → `tmux kill-session -t 名字` 清理。

> ⚠️ **警告：** 改 `.vimrc` 改错了 Vim 起不来？临时绕开配置打开：`vim -u NONE file`。

---

## 常见报错与排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 进了 Vim 退不出来 | 不知道在哪个模式 | 连按 `Esc`，然后 `:q!` 回车 |
| 打字出来是字母乱跳 | 还在普通模式 | 按 `i` 进插入模式 |
| 复制出来的东西缩进全乱 | 用了系统剪贴板粘贴 | 进插入模式后 `:set paste` 再粘，粘完 `:set nopaste` |
| tmux attach 进去黑屏 | 之前那个窗格在跑东西 | 按 `Ctrl+b` 然后 `w` 看窗口列表 |
| Ctrl+R 找不到历史命令 | 命令没进历史 | 你可能用了 `history -c`，或者命令以空格开头（bash 忽略） |
| 方向键在 Vim 里变成 ABCD | 用了太老的 vi | 用 `vim` 不是 `vi`，或 `set nocompatible` |
