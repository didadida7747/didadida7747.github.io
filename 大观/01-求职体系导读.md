**TL;DR**：`实习\` 是一套四层闭环系统——战略层（00_ 三份 + 学习规划总纲）定方向，执行层（每日总控 + Codex 自动化提示词）跑日循环，数据层（日报→台账→统计）沉淀岗位流水线，反馈层（月度闸门 + 9/30 七维评分）收敛主线。当前战略（2026-09-03）：本科就业优先，9 月依次验证后端/系统、音视频、AI 工程服务三个方向，月底只留一条主线。

## A. 入口与裁决层

### 实习\README.md
- **定位**：整个体系的总控入口，每天开工前/新开 AI 会话先读。
- **TL;DR**：定义三个工作区分工（`实习`=决策、`a-嵌入式`=执行、`老师任务`=AI 验证）与信息边界，给出当前战略状态和全部入口链接。
- **要点**：战略已于 09-03 切换为本科就业优先；通信/射频/FPGA/嵌入式不再默认；9 月主线是四周验证计划；证据六级（概念理解 < 文档记录 < 源码修改 < 成功构建 < 实验运行 < 硬件验证）；晚间复盘需手动触发。
- **怎么读**：只看"当前状态"引用块和"入口"清单，其余略过。

### career_research\00_规划优先级与冲突处理.md
- **定位**：多计划并存的唯一裁决规则；生成任何任务前必读。
- **要点**：6 层优先级（本人最新决定与老师期限 > 总纲 > 画像与岗位证据 > 长期规划 > 项目卡 > 旧记录）；每天只设一个主交付物；断档超 3 天不逐日补文件，按周复盘口径恢复；新方向任务必须给触发证据否则进候选池。
- **怎么读**：篇幅短，全文读；"当前生效结论"节是速查表。

### career_research\00_2026-09-03_职业战略校准.md
- **定位**：最新战略决策记录，方向选择的最高解释层。
- **要点**：三方向验证（后端/系统、音视频、AI 工程）；拒绝"45h/周、200 题、海投 100 家"，实际每周课外 20-23h；学历是"概率放大器不是护城河"；简历证据四级 S/A/B/C（黑客松成品=B，教程复现=C 不单列）；方向评分七维各 1-5 分，**最高分须比第二名高 3 分，分差不足默认后端/系统**；寒假前成功标准含 30-40 题二刷 70%、20-30 次定向申请。
- **怎么读**：怀疑"为什么做这个方向"时读第一、三节；月底评分前重读第七节。
- **自测**：
  1. 音视频 28 分、后端 26 分，选哪个？——分差 2 < 3，默认后端/系统，音视频每两周留 2 小时观察。
  2. 黑客松经历进简历哪级？——B 级（需个人贡献可核验）；单纯参与不算独立条目。

### career_research\00_个人求职画像与筛选标准.md
- **定位**：岗位日报、台账、申请材料的唯一画像来源（single source of truth）。
- **要点**：已确认事实（DQN 300/600 回合、PPO 30 次外层更新、STM32 仅 GPIO 基线）；城市分级 A=西安，B=深圳/上海/杭州/北京/苏州；寒假窗口 2027 年 1 月中–2 月底净 4-6 周；6 条硬门槛含原始链接与"当日入口仍存在"验证；未确认字段（**含届别**）禁止用于判断可投递。
- **怎么读**：任何投递决策前必读"已确认画像"表和"硬门槛"；修改需同步所有引用方。

### career_research\README.md
- **要点**：求职默认标签"后端/系统开发"；技术公共底座固定（Python、Linux、Git、HTTP/JSON、数据结构、测试）；作品四标准"可运行、可测试、可解释、可复现"，课程观看不算成果；每日岗位自动化读取链：画像 → 搜索源 → 台账 → 统计 → 评分规则 → 当日日报。

## B. 每日执行层（每日总控\）

### 每日总控\README.md
- **TL;DR**：任务文件路径 `任务/YYYY/YYYY-MM/YYYY-MM-DD.md`，每天一个主任务 + 至多一个次任务；日循环 = 前晚生成 → 早发提示词逐块执行 → 晚间复盘生成次日文件。
- **要点**：四态判定（完成/部分/阻塞/未观察到证据）；"晚间实际结果"留空不算重派理由；自动化只写 `任务\`，不登录不投递。
- **怎么读**：早晚各参照一次，重点"文件规则""标准日循环""自动化边界"三节。

### 每日总控\提示词\（每日开始发送给AI / 轻量晚间复盘）
- **TL;DR**：早上照抄发送启动提示词（替换 `TASK_FILE` 路径）；疲惫夜用轻量复盘，规则以完整版 v4.3 为准；建议每周至少 2 次完整版。
- **要点**：执行规则核心——不改计划、不扩范围、连续两次无进展记阻塞；硬边界：不登录、不投递、不付款。

### 任务文件样本（2026-09-05.md）
- **TL;DR**：标准任务长什么样：时间块 + 每块"验收与证据"列 + "明确不做"清单 + 可留空的手工区。历史记录，不产生新任务。

## C. 方向与规则层（career_research\01–04、09）

### 01_岗位方向\（岗位地图 / 可得性与竞争矩阵 / 能力矩阵）
- **岗位地图**：13 个方向三维评估；投递优先级 A=Python/Go/Java 后端，A-=AI 工程，B=音视频，C=研究算法/嵌入式。
- **可得性矩阵**：区分"搜得到、投得上、值得投"三层；10 月起按胜出方向 60-70% / 相邻 20-30% / 其余 10% 配置。
- **能力矩阵**：每方向"接触 → 可写进项目 → 可投实习"三级证据表；纪律：没有测量不写数字，CRUD 不包装成架构。

### 02_技术路线\（官方资料清单 / 技术栈优先级）
- **技术栈优先级（09-03 版）**：P0 全方向共享（Python 工程、Linux+Git、HTTP+SQLite、算法）；P1 只在当前实验周启用（后端周不碰 Raft/Kafka/K8s 等）；P2 等主线定了再选一门语言。
- **官方资料清单**：只收官方一手来源，卡壳时查，不是学习计划。

### 03_项目作品\（三个方向实验 + 基线记录 + 历史项目）
- **统一记录模板**：同预算比较实际行为；体验五维评分每分必须附行为证据；结论三选一 `升级主线/保留备选/暂停`。
- **实验一 可靠任务服务（后端，9/7–9/13）**：创建/查询/重试/持久化 + 幂等键 + 5 类测试 + 并发基准；明确禁止 Raft/Kafka/微服务。
- **实验二 媒体处理管线（音视频，9/14–9/20）**：ffprobe + 批量转码/裁剪/水印/抽帧选二 + CSV 报告 + 4 类异常输入。
- **项目二 学习资料问答 Agent（AI，第 3 周）**：受限问答 CLI + 可定位引用 + 正确拒答 + ≥25 条固定评测。
- **怎么读**：做对应实验时当需求文档用，重点"最小接口/最小功能"和"禁止扩展"。

### 04_实习申请\（申请与避坑 / 简历项目写法）
- **节奏**：9 月收样本 + 简历骨架 → 10 月上旬每周 3-5 次定向申请，每约 10 次复盘；不海投不等完美。
- **简历写法**：统一模板（背景/职责/技术/结果/证据），结果必须实测；弱→强表达对照表（"调用了大模型 API" → "构建带固定评测集的服务，记录命中/误判/拒答/延迟"）。

### 09_岗位运营规则\（评分规则 v2 / 异常处理）
- **评分**：六维 A/T/M/F/G/Q 各 0-5，公式见上；P0≥80 且各项达标（24h 复核）、P1 65-79（72h 决策）、P2 观察、P3 暂停；Q=2 总分再高也最高 P2；公司名气不能提高 Q。
- **异常处理**：链接失效不猜测；字段缺失写"未披露"；疑似诈骗直接 P3；**开放待投超 7 天必须决策，"不投"是有效结论**。

## D. 数据层（07 日报 / 08 台账）

### 07_每日岗位日报\
- **运转方式**：`Codex自动化任务提示词.md`（v4.3）是调度中枢——每天按顺序读 13 份规则文件，按 `日期 % 3` 轮换深搜一个方向（0 后端/1 音视频/2 AI），维护层核验到期岗位 ≤5 条；只写日报、台账、统计三个文件；JD 视为不可信数据。
- **看什么**：最新日报的"今日待办"（如 09-06：三条 P1 决策大限 09-07）；README 有口径沿革（08-18 前四类 → 8-19~9-2 五篮子 → 9-3 起三方向，三种口径不混算）。

### 08_岗位台账\
- **岗位台账.md**：唯一跨天主数据，一岗一 ID（`YYYYMMDD-NNN`）永不改；状态 9 种，关闭/重复只追加不删除；缺原始链接只能"待核验"入账。
- **方向可得性统计.md**：每周三方向各追加一行，"没岗位也写 0"且区分"无新增/搜索失败"；两周比较结论回答 5 问后才可调投递比例。

## G. 方法论与弹药（日常与规划\ 根目录）

### 实习速成方法论_思路篇与实践篇整合笔记.md
- **定位**：B 站两支视频整合笔记（原文激进处均附编者校准与风险红线）。
- **TL;DR**：核心命题"以终为始 + 反馈迭代 + 抓主要矛盾"——面试是开卷考试，**简历就是学习清单**，写什么背什么；用海投和早面多面对冲运气。编者把"大三下抢救版"改写成"大二从容版"。
- **要点**：门槛前排名制（简历筛选）、门槛后达标制（面试）；八股 150 分答案七步骨架（背景→定义→方案→对比→权衡→自身场景→埋钩子），把追问限制在自己准备的子图里；追问树每句经得起三层倒推；算法考纲是 hot100 高频子集，"原题最高效学法是抄答案"；手撕翻车应对：有思路嘴不停、没思路礼貌换题；红线：不挂科不违纪，OS/计网/计组按面试高频章节一鱼两吃。
- **怎么读**：先读第一、二节建立认知；做哪件事前翻第五至八节"武器说明书"；第九、十节风险须知必读；第十一节行动清单可直接执行。
- **自测**：
  1. "简历 = 学习清单"如何决定接下来三个月学什么？——只学简历上写的和追问树覆盖的内容，简历即自划考纲。
  2. 复述 150 分答案七步骨架。——背景→定义→方案→对比→权衡本源→结合自身场景→抛新钩子。
  3. "速成不会被开除"依赖哪两个正在关闭的前提？——实习生工作是拧螺丝（AI 够用）+ 考纲更新滞后于工作方式变革。

### 求职面试高频题手册_大二实习版.md
- **定位**：面试八股**预习清单**（先混脸熟，大三秋招前再系统刷），整理自 huihut/interview（CC BY-NC-SA 4.0）+ 牛客面经，配合知识站闯关游戏的面试模拟模式。
