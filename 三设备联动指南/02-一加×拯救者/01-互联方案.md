# 一加 ↔ 拯救者:互联方案(Phone Link / O+互联 / scrcpy)

> 结论:**国行一加(ColorOS)** 首选官方「OPPO互联(O+ Connect)」+ 系统「手机连接(Phone Link)」双开;**国际版(OxygenOS)** 依赖 Phone Link + scrcpy。想要电脑大屏反控手机、最强投屏体验,一律 **scrcpy**。

## 方案对比总表

| 方案 | 价格 | 开源 | 覆盖功能 | 适合 |
|---|---|---|---|---|
| **Phone Link**(微软"手机连接") | 系统自带 | 否 | 短信/电话/通知/照片/**屏幕镜像**/应用流 | 日常消息与通知接力,官方长期支持 |
| **OPPO互联 O+ Connect**(国行 ColorOS) | 免费 | 否 | 跨屏互联(手机投电脑+键鼠操作,ColorOS 16 起 PC 端最多 5 窗口)、文件拖拽互传、剪贴板、远控电脑 | 国行一加用户官方生态首选 |
| **scrcpy** | **免费开源** | [是(GitHub 15万+★)](https://github.com/Genymobile/scrcpy) | 投屏+声音+键鼠反控+录屏+多设备 | 投屏体验天花板,稍 geek |

三者不冲突,可以同时装:Phone Link 管"消息",O+互联/scrcpy 管"投屏操作"。

## 1. Phone Link(手机连接)

- 电脑端:Windows 11 自带「手机连接」(Phone Link);手机端需「链接至 Windows」App(一加预装或应用商店装)。
- **一加是微软官方支持"手机屏幕(投屏到电脑)"的少数非三星品牌**(2023 年 11 月起,OnePlus/OPPO/realme 系列均入列,来源:微软官方支持页 [Phone Screen 支持列表](https://support.microsoft.com/en-us/windows/apps/phonelink/setting-up-and-using-phone-screen-in-the-phone-link))。
- 功能:电脑收发短信、接打电话(需手机蓝牙)、看通知并快捷回复、浏览手机照片、运行手机应用/投屏。
- 要求:Android 10+、两端同一 Wi-Fi;国行无 Google 服务不影响。
- 避坑:每次连接投屏,手机端需手动点一次"允许投屏"(安全设计,社区常见反馈);屏幕流画质/延迟不如 scrcpy。

## 2. OPPO互联 / O+ Connect(国行 ColorOS 官方跨端)

- 下载:[connect.oppo.com](https://connect.oppo.com)(Windows/macOS 客户端);手机端入口:设置 → 连接与共享 → 跨屏互联。
- 功能:手机画面投到电脑并用键鼠操作、最多同时开 5 个手机应用窗口(ColorOS 16)、文件/照片拖拽互传、剪贴板共享、新版支持远控电脑。
- 要求:同一 Wi-Fi、PC 网卡支持 Wi-Fi Direct,登录同一 OPPO/欢太账号或扫码连接。
- 国行/国际差异:**国际版机型的 O+ Connect 是限地区功能**,海外版常找不到入口;国行一加(一加 8 代之后机型)基本开箱即用。
- ColorOS 16(2025-10 发布)新玩法:一碰互联(NFC 碰一碰传文件,还支持与 iPhone/iPad 高速互传)、跨屏互联多窗口升级;与拯救者这种"非 OPPO 系电脑"的碰一碰覆盖情况需实测。

## 3. scrcpy(开源,投屏+反控王者)★

- 定位:电脑上显示并操控安卓手机,USB/WiFi 均可;**无需 root,手机端不用装任何 App**,2.0 起自带声音转发(Android 11+)。
- 下载:[GitHub Releases](https://github.com/Genymobile/scrcpy/releases)(Windows 解压即用);嫌命令行麻烦可装 GUI 套壳 **QtScrcpy**。
- 一加上手步骤:
  1. 设置 → 关于手机 → 版本信息 → 连点"版本号"7 次,开启开发者模式;
  2. 开发者选项里打开 **USB 调试** 和 **USB 调试(安全设置)**(ColorOS 反控必开);
  3. 数据线连接,手机弹窗授权;
  4. 双击 `scrcpy.exe` → 手机画面+声音出现在电脑,键鼠直接操作。
- 无线模式:先 USB 连一次,执行 `scrcpy --tcpip=手机IP` 后拔线;或 `scrcpy --tcpip` 自动切换。
- 实用参数:`--max-size 1280` 降分辨率提流畅度、`--turn-screen-off` 投屏时熄手机屏、`--record file.mp4` 边投边录。
- 优势:延迟几十毫秒、画质可调、支持多设备同开;这也是把手机游戏/短视频搬上大屏的最佳免费方案。

## 4. 通知/短信同步的第三方补充

| 工具 | 状态 | 说明 |
|---|---|---|
| KDE Connect | 免费开源([GitHub](https://github.com/KDE/kdeconnect-kde)) | 通知镜像+快捷回复+剪贴板双向+文件互传;Windows 版在 Microsoft Store,官方明示非 Linux 平台"非官方支持",稳定性一般 |
| AirDroid | 免费+订阅 | 局域网免登录传文件、远程管理、投屏,国内官网 [airdroid.cn](https://www.airdroid.cn) |
| Pushbullet / Join | 不推荐 | 维护停滞/依赖 Google 服务,国行一加直接排除 |

Phone Link 已覆盖通知场景大半,KDE Connect 作为开源补充(还能顺带解决剪贴板,见 [03-2 接力](/三设备联动指南/03-三端协同/02-剪贴板-通知-浏览器接力))。
