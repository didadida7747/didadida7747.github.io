# STM32 工作流 · 用 AI 协作学透 STM32

## 三条工作流

### 学习流

1. 从学习路径找主题入口
2. 用提示词五件套的「主题学习」把问题喂给 AI
3. 把 AI 输出整理进自己的笔记
4. 做一个最小实验验证
5. 把踩坑沉淀成检查单

### 开发流

1. 用「驱动代码草稿」提示词生成代码框架
2. 人工审核寄存器、初始化顺序、中断/DMA 关系
3. 在板上验证
4. 验证通过后，把可复用部分抽成片段

### 调试流

1. 先记录现象（现象、复现步骤、日志、已排除项）
2. 用「固件故障排查」提示词让 AI 列排查树
3. 验证每一步，不要直接照抄修复方案
4. 最后把结果归档成案例

## 每天最低使用动作

想把这套系统跑起来，每天至少做这 4 件事：

1. 学一个主题并整理一页笔记
2. 写或验证一段最小代码
3. 记录一个坑或一个判断依据
4. 把今天可复用的内容抽成片段或模板

## 验收标准

满足下面几条，说明这个工作流已经开始发挥作用：

- 你能快速找到某个主题的入口资料
- 你能用固定模板和 AI 对话，而不是临场随缘提问
- 你能从模板工程起步，而不是每次从零新建
- 你能区分"AI 草稿"和"板上验证代码"
- 你能把一次排错沉淀成下次可搜索的资料
