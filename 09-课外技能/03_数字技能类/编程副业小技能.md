# 编程副业小技能

## 一句话简介
面向计算机/电子信息专业同学，把专业课之外的"工程能力"变成**能跑起来的小作品**：爬虫自动化、个人网站/小程序、Chrome 插件、独立小产品。重点不是再学一遍语法，而是**用现成轮子做东西、上线、攒作品、甚至接单赚点零花钱**。点到为止，不重复《数据结构》《操作系统》那些专业课。

## 适合谁 & 投入成本
| 项目 | 说明 |
|---|---|
| 金钱成本 | 0 元起步（GitHub 学生包、免费托管）；想接单变现几乎零成本，域名/服务器一年几十元 |
| 时间成本 | 每个小方向 2–4 周能出一个 Demo；真正做到能接单水平约需 2–3 个月业余练习 |
| 设备门槛 | 一台能装 Python/Node 的笔记本即可，宿舍网络完全够用 |
| 宿舍友好度 | 极高，纯敲代码，安静不吵人；适合没课的下午和晚上 |

## 分阶段学习路径

### 阶段一：入门（第 1–4 周）——做出第一个"能跑的小东西"
- **阶段目标**：不再只刷 LeetCode，而是能写一个**解决自己真实痛点**的脚本或小工具。
- **该做什么**：从 Python 爬虫/自动化小脚本入手（比如自动抢课、自动整理课程表、批量重命名）；把代码传到 GitHub 建个仓库。
- **周期**：约 3–4 周。

### 阶段二：进阶（第 2–3 个月）——做出"别人能用"的作品
- **阶段目标**：做一个有界面、能部署上线的小作品，比如个人博客、一个小工具网站、一个 Chrome 插件。
- **该做什么**：学一点前端基础（HTML/CSS/JS）；用 GitHub Pages / Vercel 免费部署；写一份像样的 README。
- **周期**：约 6–10 周。

### 阶段三：课外副业方向（3 个月后）
- **阶段目标**：把作品变成作品集，尝试接小单（爬虫、小程序、简单网站），或做独立小产品靠流量/付费变现。
- **该做什么**：整理 GitHub 主页；在接单平台注册；把 1–2 个作品写成技术博客发到掘金/知乎引流。

## 装备 / 器材入门建议
- **0 元党**：一台现有笔记本 + Python/Node 环境 + GitHub 学生包（教育邮箱免费领，含 Copilot、免费私有仓库等），完全够做出个人网站、爬虫脚本。
- **100 元内**：可买一个 `.com` 域名（约 50–70 元/年）挂在个人博客上；服务器初期用 Vercel / Cloudflare Pages / GitHub Pages 免费额度即可，**不要一上来就买云服务器**。
- **500 元档**：等真正开始接单、有稳定小收入后，再考虑买轻量云服务器（学生机约 100 元/年）部署正式项目。
- **宿舍提示**：爬虫注意控制请求频率，别把宿舍校园网 IP 打挂；部署在海外平台（Vercel/Netlify）时上传代码用国内网络可能偏慢，属正常现象。

## 常见误区 & 避坑
- ❌ **一上来就追新技术栈**：副业是为了出作品和赚钱，不是为了学最新框架。先用你专业课已学的语言做出来，再谈优化。
- ❌ **爬虫乱爬、不看 robots 和法律**：只爬公开、非敏感数据；不要抓用户隐私、不要高频请求打挂别人服务器；接单类爬虫需求尤其要确认合规性。
- ❌ **接单方面先做后签**：任何单子都要先付定金（通常 30%–50%）、写清需求边界，否则容易被白嫖或无限改需求。
- ❌ **只写代码不写 README**：GitHub 作品没人看，90% 是因为 README 写得像代码注释。花时间写清楚"这是什么、解决什么问题、怎么跑起来"。
- ❌ **沉迷刷教程不做项目**：看 100 集教程不如做一个能上线的小东西。副业方向的核心是"完成 > 完美"。
- ❌ **把专业课丢了去搞副业**：大一大二先把数据结构、操作系统、计网这些基础打牢，副业是放大器不是替代品。

## 在本校 / 西安怎么练
- **校内场景**：本校有各类程序设计竞赛、开源社团、黑客松（hackathon）活动，是快速组队做作品的好场合；建议主动找一个技术氛围好的实验室或开源小组。（具体社团/实验室名单建议自行核实，以学校最新信息为准。）
- **实战练手**：先解决自己/同学的真实痛点——抢课助手、课表导出、宿舍电费查询脚本、考研资料整理工具，这些都是天然的副业雏形。
- **本地资源**：西安有软件园、高新区，部分企业会招大学生远程兼职开发；可关注学校就业网和"程序员客栈"等平台的西安本地需求。（具体机会建议自行核实。）

## 快速开始（本周就能做）
1. 用教育邮箱去 GitHub 申请学生包（GitHub Student Developer Pack），免费领 Copilot 和一堆开发者福利。
2. 选一个自己的真实痛点，用 Python 写一个 50 行以内的小脚本（比如批量重命名、自动整理下载文件夹），传到你的第一个 GitHub 仓库。
3. 花一个下午跟着 GitHub Pages 官方文档，搭出第一个 `你的用户名.github.io` 主页，写上一句话自我介绍。
