# 飞花令与雅趣玩法

> 一个人能玩，两个人能斗，一群人能开趴体。整理日期：2026-10-03。

## 一、飞花令

### 规则（诗词大会改良版，最易上手）

1. 定一个"令字"（如"花"），双方轮流说出**含有该字的诗句**；
2. 说不出或重复即败；每句须带明确作者或出处更佳；
3. 传统版更严格：令字须落在第几位有讲究（如第一人"花"须在第一字），家用建议用改良版。

### 高频令字卡（附例句起手）

| 令字 | 例句 |
|---|---|
| 花 | 花间一壶酒（李白《月下独酌》）｜感时花溅泪（杜甫《春望》） |
| 月 | 举杯邀明月（李白）｜明月几时有（苏轼） |
| 风 | 夜来风雨声（孟浩然）｜东风夜放花千树（辛弃疾） |
| 云 | 行到水穷处，坐看云起时（王维）｜白云千载空悠悠（崔颢） |
| 春 | 春眠不觉晓（孟浩然）｜报得三春晖（孟郊） |
| 夜 | 夜半钟声到客船（张继）｜今夜月明人尽望（王建） |
| 江 | 唯见长江天际流（李白）｜江枫渔火对愁眠（张继） |
| 山 | 空山新雨后（王维）｜一览众山小（杜甫） |
| 酒 | 劝君更尽一杯酒（王维）｜明月几时有，把酒问青天（苏轼） |
| 愁 | 缘愁似个长（李白）｜问君能有几多愁（李煜） |

### 变体玩法

- **单人版**：定一个字，一周内积累 20 句含该字的诗，记在手账或备忘录。
- **AI 对令**：把规则发给任意大模型（"我们玩飞花令，令字'月'，你先来，我说过的句子不能重复"），通勤路上就能斗两局。
- **主题局**：只许说带颜色的诗句（"白""青""红"）、只许说写食物的、只许说写天气的。

## 二、对联

- **入门三规则**：字数相等、词性相对、平仄相谐（上联末字仄声、下联末字平声）。
- **练习法**：从"无情对"和经典对句入手——出句"海阔凭鱼跃"，对句"天高任鸟飞"；日常看到好上联就试对一句。
- **进阶**：搜韵的对联校验、诗词吾爱的对联工具可检查平仄（见 [01-诗词创作与格律工具](#/doc/d137)）。
- **集句联**：从不同诗里各取一句拼成对联，是高级玩法（如集杜甫对王维）。

## 三、灯谜与文字游戏

- **灯谜**：元宵节限定快乐；常见谜格先认识两个——"秋千格"（谜底两字倒读）、"卷帘格"（谜底倒读如卷帘）。微信搜 `灯谜` 有大量小程序，各地文化馆元宵活动多有线上猜谜。
- **藏头诗**：给朋友名字写藏头诗是最讨喜的祝福；可用 AI 起草再自己改，格律自查用搜韵。
- **诗词接龙**：下句首字 = 上句尾字（或尾字谐音），聚会破冰零门槛。

## 四、线下雅集灵感

- **家庭诗词之夜**：飞花令 + 灯谜 + 抄诗展示，配上 [01-古风音乐](#/doc/d131) 当 BGM。
- **国风音乐会**：自得琴社《琴为何物》朝代系列常年在全国巡演，官网 zideqinshe.com"演出"页查排期；各地大剧院与票务平台搜 `国风音乐会`、`国潮`、`国乐`。场次变动频繁，购票前以官方渠道为准。
- **节气茶会**：按 [02-汉服与生活美学](#/doc/d135) 的茶、香、花入门资源，办一场应景的小茶会。
