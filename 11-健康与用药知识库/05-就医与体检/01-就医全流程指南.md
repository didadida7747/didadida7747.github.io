# 就医全流程指南:从"不知道挂哪科"到"看完病心里有底"

> 一句话定位:写给从没独立看过病的大学生(和他们的家人)——按症状找对科室、备齐材料、说清病情、看懂医嘱、用好医保,一次讲完整条路。
>
> ⚠️ 免责声明:本文为科普整理,不构成医疗建议;具体诊疗请遵医嘱。

---

## 🎯 核心速览

1. **先判断轻重缓急**:可能危及生命的情况(胸痛、意识不清、大出血、严重外伤、高热不退等)直接**急诊**,不要排队挂门诊。
2. **不知道挂哪科**:先用医院公众号/App 里的"智能导诊"输入症状;查不到就挂**全科/普通内科**,让医生帮你分诊。
3. **初诊挂普通号就够了**:初诊大多要开检查,检查结果出来前专家也做不了更多;带着完整结果再决定是否看专家。
4. **就诊前准备好 5 样**:身份证/医保码、既往报告和检查单、正在吃的药清单、过敏史、症状时间线。
5. **描述病情公式**:**部位 + 性质 + 持续时间 + 诱因 + 加重/缓解因素 + 伴随症状**。不要自己下诊断("我肯定是胃病"),只描述事实。
6. **离开诊室前问清 3 件事**:我得的可能是什么?药怎么吃、吃多久?出现什么情况必须回来复诊?
7. **医保要点**:在校参保后,**普通门诊一般先在校医院首诊**,需要转诊时先办转诊手续;假期回老家/实习地住院,提前在"国家医保服务平台"App 办**异地就医备案**。具体比例和限额以学校医保办和当地医保局当年文件为准。
8. **防医托**:在医院里主动搭讪的"热心病友""专家推荐"基本都是骗局;正规就医只走挂号—分诊—诊室这条官方流程。

## 正文

### 一、第一步:这病要不要马上去医院?

先做分级,再谈挂号。下面这个表帮你决定去哪、多快去。

| 级别 | 表现举例 | 该做什么 |
|---|---|---|
| 🔴 立即急诊(拨打120或直接去急诊科) | 胸痛持续不缓解、严重呼吸困难、意识不清或晕倒、抽搐、大出血、严重外伤/骨折、吞服异物或药物过量、高热(>39.5℃)伴精神差、剧烈头痛伴呕吐 | 别犹豫,去最近的有急诊的医院;在校内先联系辅导员/宿舍同学陪同 |
| 🟡 24小时内就诊 | 发热超过3天不退、剧烈腹痛、明显血尿/便血、呕吐腹泻严重到脱水、新发的肢体麻木无力 | 当天或次日挂门诊;拿不准就挂急诊让医生判断 |
| 🟢 择期门诊(几天内安排) | 感冒一周未愈、反复胃部不适、皮疹、关节轻度疼痛、体检指标异常需复查 | 按下文流程正常挂号;先去校医院 often 更省钱省时 |
| ⚪ 可先观察+自我护理 | 受凉后轻微鼻塞流涕1-2天、轻微肌肉酸痛、单次稀便无其他症状 | 多喝水休息观察;症状加重或超过3天不缓解再就医 |

> 经验法则:**"疼得睡不着、影响吃饭上课、症状每天加重"满足任意一条,就该去看医生了。**

### 二、症状→科室速查表(24个常见症状)

挂号最怕的是选错科室。先查下表,再用挂号平台上的"智能导诊"核对一遍;实在拿不准,挂**全科医学科/普通内科**(校医院可直接看全科)。

| 症状 | 首选科室 | 备选/说明 |
|---|---|---|
| 头痛、头晕 | 神经内科 | 外伤后头痛→神经外科;伴鼻塞流涕→耳鼻喉科 |
| 心慌、胸闷、心悸 | 心内科(心血管内科) | 突发剧烈胸痛→直接急诊 |
| 咳嗽、咳痰、气短 | 呼吸内科 | 长期干咳>8周也挂呼吸内科 |
| 发热 | 发热门诊 | 无发热门诊的医院→全科/普通内科;校医院可先看 |
| 胃痛、反酸、烧心、恶心 | 消化内科 | |
| 腹泻、拉肚子 | 消化内科 | 疑似食物中毒且多人同时发病→急诊 |
| 便秘、便血 | 消化内科 | 大量便血→急诊 |
| 皮疹、痘痘、荨麻疹、瘙痒 | 皮肤科 | |
| 关节痛、腰腿痛、扭伤 | 骨科 | 多关节对称痛、晨僵→风湿免疫科 |
| 颈肩痛、腰痛(慢性) | 骨科/康复医学科 | |
| 失眠、焦虑、情绪低落 | 精神心理科(精神科/心理科) | 校心理咨询中心可先咨询,但开药需精神科 |
| 痛经、月经不调、白带异常 | 妇科 | |
| 眼睛红、痛、视力下降 | 眼科 | 眼外伤、化学溅入→急诊,先大量清水冲洗 |
| 牙痛、牙龈出血、口腔溃疡 | 口腔科(口腔内科/口腔黏膜科) | 校医院一般有口腔科或转诊 |
| 耳鸣、听力下降、耳朵痛 | 耳鼻喉科 | |
| 鼻塞、流涕、鼻出血、打鼾 | 耳鼻喉科 | |
| 尿频、尿急、尿痛、血尿 | 泌尿外科 | 女性伴发热腰痛→肾内科 |
| 贫血、乏力、面色苍白 | 血液内科(或先看全科) | 多由体检血常规发现 |
| 甲状腺问题(脖子肿大、甲功异常) | 内分泌科 | 结节初查后可能转甲状腺外科 |
| 糖尿病、痛风/尿酸高 | 内分泌科 | |
| 外伤、摔伤、割伤 | 急诊/骨科 | 伤口小而深→急诊处理并评估是否打破伤风 |
| 被猫狗抓咬 | 急诊/犬伤门诊 | **24小时内接种狂犬疫苗,越快越好** |
| 儿童(<14岁)不适 | 儿科 | 带家人孩子就医时注意 |
| 说不清哪科、多种症状混杂 | 全科医学科/普通内科 | 校医院医生即全科,是最好的起点 |

**体检报告异常该挂哪科**(常见对应):转氨酶/胆红素升高→消化内科;肌酐/尿素升高→肾内科;血红蛋白低/血小板异常→血液科;血糖高→内分泌科;尿酸高→内分泌科;结节类→见《02-体检报告解读》。

### 三、就诊前准备清单(5样东西)

| 准备项 | 具体内容 | 为什么重要 |
|---|---|---|
| 1. 证件与医保 | 身份证;手机上激活好**医保电子凭证**(国家医保服务平台 App 或微信/支付宝搜"医保码") | 没有医保码,门诊结算全自费 |
| 2. 既往资料 | 以往的检查报告、出院小结、体检报告(电子或纸质) | 医生需要对比判断;很多检查可以不重做 |
| 3. 用药清单 | 正在吃的所有药:药名、剂量、吃了多久(照着药盒拍张照最省事) | 避免药物相互作用、重复开药 |
| 4. 过敏史 | 对哪些药物/食物过敏、过敏时什么表现(皮疹?休克?) | **这是安全问题,必须主动说** |
| 5. 症状时间线 | 按下一节的模板提前写好,就诊时照着念 | 门诊时间平均只有几分钟,别浪费在回忆上 |

> 提示:把这些存在手机备忘录的固定一条里(或用本知识库 07-行动工具 的模板),每次看病只需更新。

### 四、症状描述模板(就诊时照着说)

医生问诊的逻辑是固定的,你按这个顺序说,几分钟就能把关键信息给全:

> **"我最主要的不舒服是 ______(部位+症状),从 ______(天/周/月)前开始,感觉像 ______(刺痛/胀痛/隐痛/发热感),______ 的时候会加重,______ 之后能缓解,同时还有 ______(伴随症状)。我有 ______ 病史,对 ______ 过敏,目前在吃 ______。之前做过 ______ 检查(附报告)。今天最想解决的是 ______。"**

各要素举例:

| 要素 | 问什么 | 好的回答示例 |
|---|---|---|
| 部位 | 哪里不舒服? | "上腹部正中"(而不是笼统的"肚子疼") |
| 性质 | 什么样疼? | "烧灼感""绞痛""针扎样""闷胀" |
| 持续时间 | 什么时候开始?持续多久?发作频率? | "3天了,每次饭后疼半小时,一天2-3次" |
| 诱因 | 发作前做过什么、吃过什么? | "考前熬夜、吃了辛辣外卖后出现" |
| 加重/缓解因素 | 什么让它更糟/更好? | "空腹时加重,吃点东西好一些" |
| 伴随症状 | 同时还有什么不舒服? | "伴反酸、恶心,没有呕吐和黑便" |

**三个禁忌**:① 不要自己下诊断("我肯定是胃炎")——只描述事实,诊断交给医生;② 不要隐瞒(熬夜、饮酒、性生活史、既往流产、情绪问题)——医生见过太多,说谎只会耽误诊断;③ 不要说"网上说是绝症"开场——可以先陈述症状,最后再提你的担心。

### 五、挂号渠道与号别选择

**挂号渠道(按推荐顺序):**

| 渠道 | 适用情况 | 注意事项 |
|---|---|---|
| 医院官方公众号/App | 大多数三甲医院的主要渠道,提前3-7天放号 | 认准"医院官方"认证标志,谨防高仿 |
| 地方统一预约平台 | 部分城市有官方统一挂号平台 | 以当地官方公告为准 |
| 电话挂号 | 不会用智能手机时(给父母用) | 医院官网可查挂号电话 |
| 现场挂号/自助机 | 当天临时就诊、线上没号 | 热门科室当天常常没号,早去 |
| 校医院 | **在校看病的第一站**,便宜且近 | 直接带证件去,一般不用预约 |

**专家号 vs 普通号,怎么选:**

| 情况 | 建议 |
|---|---|
| **初诊**(第一次看这个病) | **普通号即可**。初诊核心是开检查、排除常见病,普通门诊医生完全能胜任,还更好挂 |
| 检查结果出来后诊断不明、治疗效果不好、或疑诊疑难疾病 | 再挂**专家号(副主任医师及以上)**,带上全部报告 |
| 慢病复诊、开药 | 普通号即可 |
| 想指定的专家没号 | 可先看同科室其他医生;或关注放号时间准点抢;不要买"黄牛号" |

### 六、就诊沟通技巧与看懂医嘱

**诊室里的沟通技巧:**

1. **先说最难受、最影响生活的问题**——医生会围绕它展开;次要症状放后面补充。
2. **回答问题要具体**,不确定就说不确定,不要为了"显得专业"编数字。
3. **听不懂就问**,不要不好意思:"您能再用通俗一点的话解释一下吗?"
4. **对处理方案有疑问可以商量**,但不要直接指挥开药:"网上说我要吃XX"不如问"您觉得我这个情况适合哪种方案?"
5. **如需要,可请医生把诊断和医嘱写下来**(病历上本来就有,可要求打印或拍照病历首页)。

**离开诊室前必须问清的 3 件事:**

| 问题 | 为什么 |
|---|---|
| ① 我这个可能是什么问题?严重吗? | 明确诊断方向,知道自己接下来观察什么 |
| ② 这些药分别怎么吃、吃多久?有什么副作用要注意? | 吃错剂量/自行停药是疗效差的最常见原因 |
| ③ 出现什么情况要马上回来?什么时候来复诊? | 划定"危险信号",避免小病拖大 |

**看懂处方与医嘱(常见缩写):**

| 处方常见写法 | 含义 |
|---|---|
| qd / bid / tid | 每天1次 / 每天2次 / 每天3次 |
| qn / q8h | 每晚1次 / 每8小时1次(严格间隔) |
| prn | 必要时服(按症状需要) |
| ac / pc | 饭前 / 饭后 |
| po | 口服 |
| "顿服" | 一次性把一天的量服下 |
| 医嘱"复查XX" | 到时间必须回来,别觉得好了就算了 |

> 拿到药当场核对:药名、用法写在药盒/袋上吗?和医生说的一致吗?不清楚的当场问药房窗口。

### 七、检查、报告与复诊管理

- **检查前**问三句:"这个检查是查什么的?""有什么注意事项(空腹/憋尿/停药)?""报告多久出、在哪取?"——CT/MRI/胃镜等大项目,先确认医保是否覆盖、是否需预约。
- **报告管理**:所有报告(纸质拍照存档,电子报告截图/下载)按**日期+项目**命名存进一个相册/文件夹。很多医院公众号可查历史报告,出院小结尤其要留好。
- **复诊纪律**:医生约的复查时间必须去;抗生素等处方药"感觉好了"也要吃完疗程;慢性指标(如肝功异常)复查前保持和上次类似的生活状态,结果才有可比性。
- **第二意见(再找一位医生看看)什么时候值得要?** ① 诊断重大疾病或建议手术/长期服药时;② 治疗一段时间明显无效时;③ 你对方案有很大疑虑时。带齐全部资料看同专科另一位正规医院医生即可,这不是"得罪医生",是正常权利。

### 八、大学生医保实操(在校生必读)

> ⚠️ 各地、各校政策差异很大且逐年调整,以下为通行规则;**具体比例、限额、流程以你参保当年"学校医保办/校医院/当地医保局"的官方通知为准。**

**1. 在校参保是什么**

大学生随学校参加**城乡居民基本医疗保险**(俗称"大学生医保"),按学年缴费,一般由学校统一组织,每年秋季开学集中办理。参保后享有:住院报销、门诊统筹、大病保险等基本待遇。**不参保则全部自费,且中途一般不能补办。**

**2. 普通门诊:校医院首诊 + 转诊**

| 环节 | 通行做法 |
|---|---|
| 平时小病 | **先去校医院**:带身份证/医保码,直接就诊结算,报销比例较高(各地常见约60%-70%,有年度限额,常见数百元) |
| 校医院看不了 | 请校医院医生**开转诊单/转诊手续**→到约定的定点医院就诊,费用仍可按规定报销 |
| 未经转诊自己跑大医院 | 门诊费用**通常不报销或报销很少**(急诊除外) |
| 门诊慢性病(如糖尿病) | 一般需另行申请"门诊慢特病"待遇,问校医院医保办 |

**3. 住院报销(通行概念)**

- 住院费用报销涉及三个关键数:**起付线**(以下部分自付)、**报销比例**、**封顶线**。等级越高的医院,起付线通常越高、比例略低。
- 入院时出示医保码,出院时**直接结算**,个人只付自付部分——这是"直接结算",不用跑腿报销。
- 大额费用还有**大病保险**二次报销,一般自动结算。

**4. 异地就医备案(假期回家/实习/外地上学期间用)**

| 步骤 | 做法 |
|---|---|
| 什么时候办 | 在参保地以外的地方需要住院或门诊就医前,提前办好 |
| 怎么办 | 下载官方**"国家医保服务平台"App**→首页"异地备案"→按提示选择备案类型(异地安置/常驻异地工作/异地转诊等)提交,审核通过后即可在当地联网医院直接结算;也可在"国家医保局"微信公众号、当地医保小程序办理 |
| 急诊怎么办 | 异地突发急诊住院,一般可按规定补备案或事后凭急诊证明报销,保留好票据病历 |
| 备案生效 | 线上备案通过后立即生效,长期有效,无需每次重复办理(具体以平台提示为准) |

**5. 报销材料清单(需手工报销时)**:医保电子凭证/社保卡、身份证、原始发票(收费票据)、费用明细清单、病历/出院小结、诊断证明。**发票原件千万别丢。**

**6. 校医院之外,还有这些校内资源**:校心理咨询中心(情绪问题,免费)、学生资助中心(大病可咨询临时困难补助)。

### 九、防范医托与过度医疗的基本意识

**识破"医托"(在医院里主动搭讪你的"热心人"):**

| 套路 | 破解 |
|---|---|
| "我亲戚这病就是在XX诊所得好的,我带你去" | 挂号大厅/门口主动搭讪的陌生人,一律不理 |
| "你要找的专家今天不坐诊,我知道他在别处出诊" | 专家停诊会在官方渠道公示;不信私下引荐 |
| "大医院看这病又贵又慢,XX门诊便宜" | 正规医院收费公开透明;便宜得离谱的地方更危险 |
| 自称病友、老乡,套取病情后推荐"神医" | 不透露病情,直接走开;可报告医院保卫处 |

**对过度检查/治疗的三个基本判断:**

1. 开出**大几千上万**的自费项目时,可以问:"这个检查是必须现在做的吗?医保报销吗?有替代方案吗?"——正当要求,医生会解释。
2. 一家机构反复让你"再做个更贵的检查才能确诊",而它同时卖"套餐",要警惕;拿上已有报告换一家公立医院再看。
3. **所有诊疗凭证(病历、票据、检查单)都保留**,既是报销凭证,也是维权依据。

### 十、陪家人看病要点(老人就诊,子女要做的 5 件事)

1. **提前把资料打包**:老人的身份证/医保卡、目前吃的所有药(拍药盒照)、既往出院小结和检查报告、过敏史——用一个文件袋或手机相册整理好。老人的用药常跨好几个科室、好几家医院,**带齐用药清单能避免重复开药和药物冲突**。
2. **代述病情但不抢话**:提前和老人聊清楚症状时间线(用本文第四节模板),就诊时补充关键信息;但让老人自己说感受,医生需要第一手信息。
3. **管好三件事**:记下医生说的用法用量、复诊时间、危险信号(必要时录音或拍照医嘱);老人回家后常忘或不愿说。
4. **帮老人跑腿而不是替老人决定**:重大检查、手术决策,和老人一起听医生解释、一起做决定;尊重老人意愿,同时核对费用和医保报销方式。
5. **留意认知与情绪**:老人近期明显健忘、性格改变、情绪低落,主动告诉医生(老人自己往往不会说);必要时挂老年科或精神心理科。

## ⚠️ 常见误区

| 误区 | 正解 |
|---|---|
| "大学生医保没用,交不交无所谓" | 一场阑尾炎住院自费可能上万;医保是参保人数百元/年换来的兜底,不参保生病全自费 |
| "看病必须挂专家号" | 初诊开检查用普通号即可;带着完整结果再看专家,一次顶三次 |
| "自己百度症状,直接要求开某药" | 网络信息无法替代查体和检查;可以带疑问,别带结论 |
| "校医院水平差,直接去大医院" | 校医院近、便宜、报销比例高;它看不了的会帮你转诊,这才是医保设计的正确用法 |
| "病历和发票随手就扔" | 手工报销、二次报销、保险理赔、复诊对比全靠它们;建个"就医档案"相册 |
| "医生开的药,好了就停" | 抗生素疗程不足易复发耐药;降压降糖药自行停药会反弹,停药前问医生 |
| "网上问诊能代替去医院" | 线上问诊适合复诊续方、报告解读;首次出现不明症状、急症,必须线下面诊 |
| "手术/大病听医生的就完了,不用问" | 有知情权和选择权;大决策前问清:除了这个方案还有什么选择?各自风险获益?
