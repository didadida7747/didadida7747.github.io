# 12 · 安全与反诈知识库（财产与人身安全）

> 定位：**11 健康库管"身体不倒"，本库管"钱不丢、人不出事、隐私不泄露"。**
> 全部内容联网搜集整理（2026-10-03 核验），反诈数据来源优先公安部 / 国家反诈中心 / 新华社 / 央视新闻。
> 数据时效提醒：反诈手法与数据以公安部、国家反诈中心最新通报为准。

---

## 一、本周就做（一次性动作，做完终身受益）

1. 📱 **装「国家反诈中心」App 并开启来电预警**（各应用商店搜"国家反诈中心"，认准官方开发者）。
2. 🔑 **重要账号全部开两步验证（2FA）**：微信、支付宝、QQ 邮箱、GitHub、Apple ID、一加/OPPO 账号——顺序按"丢了最疼"排。
3. 💾 **确认 3-2-1 备份跑起来**：论文/代码/笔记 = 移动硬盘 + 网盘 + Git 仓库（见 04 篇）。
4. 📍 **确认各设备"查找"已开启**：iPhone「查找」、一加「查找手机」、Windows「查找我的设备」。
5. 🏠 看一遍 [06-校园与出行安全](/12-安全与反诈知识库/06-校园与出行安全) 的宿舍用电清单，检查自己的插排和充电器。
