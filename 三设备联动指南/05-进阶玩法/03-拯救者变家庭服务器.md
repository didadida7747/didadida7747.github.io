# 拯救者变"家用主机/服务器"

> 游戏本当家用服务器其实很香:性能/核显转码远超入门 NAS,自带电池就是天然 UPS,还能一机三用(游戏主力/串流主机/服务端)。代价是要处理好"常开"与散热。

## 一、先当"准服务器"设置好

1. **常开**:关盖不动作 + 空闲自动睡眠(配合 [05-2 的 WoL 唤醒](#/doc/d377)),或干脆常亮;
2. **电池**:Lenovo Vantage / Legion Space 开养护模式(60%-80% 截止),长期插电防鼓包;
3. **散热**:游戏本进风靠键盘面与底部——**合盖长期运行会积热**,建议开盖外接屏、垫高、或外接风扇;定期清灰;
4. **系统**:Windows 更新重启会打断服务,把"活动时间"调宽,或按需用任务计划错峰。

## 三、运行路线对比

| 路线 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| **留在 Windows 直装/Docker Desktop** | 零学习成本,NVENC/QSV 全可用 | Windows 更新偶扰 | ★ 推荐 |
| WSL2 / Hyper-V 虚拟机 | Linux 环境干净、快照方便 | 显卡直通给 VM 麻烦;多占内存 | 想学 Linux 再用 |
| 装 Linux 双系统 | 折腾空间最大 | 独显混合模式驱动、双系统切换动 BIOS、重装有风险 | 除非明确想学,否则别 |

## 四、外网访问

- 所有服务配好 Tailscale 后,外出用 iPad/一加访问 `http://100.x.x.x:端口`(Jellyfin 8096、qBittorrent 8088、UpSnap 等)即可,见 [05-1](#/doc/d376)。
- 安全提醒:不要把服务端口直接暴露到公网;必须暴露时(qBittorrent WebUI 等)改默认端口+强密码。

## 五、风险提示

- 笔记本 7×24 长跑的可靠性不如真 NAS:硬盘做好重要数据**双重备份**(3-2-1 原则);
- 长期高负载注意温度墙与积灰;雷雨天气/长期出门建议物理断电;
- 游戏+服务混跑:打游戏时 Jellyfin 转码等后台任务会抢资源,重要场合可临时暂停服务。
