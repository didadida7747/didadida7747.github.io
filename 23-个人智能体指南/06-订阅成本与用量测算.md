## 5. 用量测算：1 亿 Tokens 到底能做什么？

> 以下为**估算**。官方未公布 Today 的 token 消耗规则（02 分册诚实清单第 6 条），数字只给数量级感受，按你的实际任务量变化很大。

### 5.1 先建立量级直觉

- **纯聊天**：一轮普通问答大约几千 token（短上下文）。1 亿 token 若全是纯聊天，按每轮 2k token 粗算 ≈ **5 万轮以上**——对纯聊天来说根本用不完。
- **Agent 任务是另一回事**：agent 每跑一步都要把系统提示 + 长期记忆 + 工具返回结果重新塞进上下文。04 分册的实测估算是 agent 场景输入远大于聊天，按 **2.5:1 输入输出比** 消耗；社区实测「手机派活→云电脑跑代码→日志回传」是最烧额度的玩法，重度用户一周能把免费额度用掉 99%（抖音重度用户，2026-10-10）。
- **单任务粗估**：一次「读一篇长文→出一份中文笔记」或「云电脑 clone 仓库+装依赖+跑通」这类任务，按上下文量级粗估消耗 **5万~30万 token**（估算，非官方）。

### 5.2 1 亿 Tokens ≈ 什么概念

| 用法 | 估算可支撑量 |
|---|---|
| 纯问答聊天 | 5 万轮以上（基本用不完） |
| 早晚报 + 每周 2~3 次长文笔记（轻度） | 按 04 分册轻度档（月耗约 7M token）粗算，**约 10~14 个月**（估算） |
| 重度云电脑跑代码 + 多 Bot 群流水线 | 单次任务 20万+ token，约 **几百次任务**，重度用户可能 1~2 个月用完（估算） |

> 结论给国内学生：**现阶段零成本白嫖**（02 分册 FAQ 原话）。轻度使用，1 亿 token 够用很久；但如果你把它当 Grok Bot 那样天天挂云电脑跑代码，它比你想象的费。

### 5.3 Agent 为什么比普通聊天费 token（三条原因）

1. **上下文反复重发**：每一步都把你的画像、记忆、历史消息、工具结果重新喂给模型，普通聊天只发你这一轮。
2. **工具调用本身吃输入**：浏览器返回的网页正文、git 日志、报错堆栈都是几千到几万 token 的输入。
3. **多 Agent 翻倍**：群聊流水线里，一个 Bot 的产出要再进下一个 Bot 的上下文，链路越长总消耗越高（04 分册排查表也指出「多 agent 同时跑 token 翻倍」）。

### 5.4 学生月度费用区间（自建派，04 分册 §5.2 实测估算）

| 用量档 | 月 token 量 | DeepSeek flash | 通义 qwen-long | Grok 4.20 | Claude Sonnet 5.5 |
|---|---|---|---|---|---|
| 轻度（每天 20~30 条消息，偶尔工具调用） | 输入 5M / 输出 2M | **¥13/月** | **¥6.5/月** | ≈¥80/月 | ≈¥215/月 |
| 中度（挂 Telegram 网关 + cron 日报 + 每周几次编程任务） | 输入 20M / 输出 8M | **¥52/月** | **¥26/月** | ≈¥320/月 | ≈¥860/月 |

**结论：学生自建用国产模型月花费 ¥5~60；换海外旗舰模型会跳到 ¥300+/月。**

### 5.5 具体任务成本算例（自建派按 API 单价硬算）

> 算法沿用 04 分册口径：一次 agent 任务按输入:输出 = 2.5:1 估算。下列为演示算例，真实消耗随上下文长短浮动。

**算例 A：一次「读 1 篇 1 万字英文论文 → 出中文笔记」**（粗估消耗：输入 20 万 token、输出 2 万 token）

| 用什么模型 | 这笔任务成本 |
|---|---|
| DeepSeek flash | ¥20万×1/1M + ¥2万×4/1M ≈ **¥0.28** |
| 通义 qwen-long | ≈ **¥0.14** |
| Claude Sonnet 5.5 | $20万×2/1M + $2万×10/1M = $0.6 ≈ **¥4.3** |

——同样一篇论文，国产模型不到 3 毛钱，海外旗舰 4 块多。这就是「默认国产模型、重任务才切旗舰」的算术依据。

**算例 B：「云电脑 clone 仓库 + 装依赖 + 跑通」**（日志/报错来回喂，粗估输入 100 万 token、输出 5 万 token）

| 用什么模型 | 这笔任务成本 |
|---|---|
| DeepSeek flash | ≈ **¥1.2** |
| Claude Sonnet 5.5 | $2 + $0.5 ≈ **¥18** |

——重度用户天天跑这个，用 DeepSeek 一个月 ¥30~50 打住；用 Claude 奔着 ¥500+ 去。这也解释了为什么 04 分册说「中度用量换海外旗舰会跳到 ¥300+/月」。

## 9. 费用 FAQ

**Q1：Today 送的 1 亿 Tokens 到底多久会用完？**
A：官方未公布消耗规则（诚实清单）。按 04 分册轻度档（月耗约 7M token）粗估够用 10~14 个月；但如果你天天挂云电脑跑代码（重度玩法一次几十万 token），可能 1~2 个月就见底。**保守心态：按「重度 2 个月、轻度一年」两头估。**

**Q2：Grok Bot 免费版会不会偷偷扣钱？**

**Q3：月付还是年付？**
A：先月付/免费额度试一个月，确认真用再年付。年付的便宜是实打实的：Macaron Classic 年付比月付便宜约 4 倍；X Premium 年付 $300 vs 月付累计 $360。但产品迭代极快、「可能已过时」的档位不少——**第一年别把年付当成理所当然**。

**Q4：为什么订阅制看起来不限量，我还要管 token？**

A：多 agent 同时跑——token 翻倍，且主进程变卡（04 分册 §8）。官方与社区都指出多 agent 编排是当前短板：先单 agent 跑顺，再拆团队，别一上来就拉五个。
