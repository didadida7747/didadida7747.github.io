竞赛规划资料包/

【二、核心产物使用】

1. 时间轴图谱（HTML）
   - 双击用浏览器打开，无需联网
   - 横轴12个月，四色泳道：红=保研、蓝=就业、绿=考公、紫=留学
   - 灰色虚线框 = 大创/科研项目（非竞赛但保研权重高）
   - 浅色虚线段 = 备赛周期，实色段 = 报名/比赛期
   - 实线边框 = 推荐赛事，半透明 = 可冲赛事
   - 点击任意赛事条 → 底部展开完整信息（名称/时间/备赛/年级/价值/避坑）
   - 顶部按钮可筛选/隐藏任意赛道
   - 同时间段多赛事自动错开行，互不遮挡

2. Excel清单
   - Sheet1「全部赛事明细」：94项完整数据
   - Sheet2「个性化推荐排序」：按你的标签计算优先级评分排序
   - Sheet3-6：按保研/就业/考公/留学分赛道
   - 红色行 = 推荐，黄色行 = 可冲
   - 首行冻结，支持筛选

【三、每周自动更新机制】

- 任务名称：竞赛资讯每周自动更新
- 调度：每周一 09:00（Windows任务计划程序）
- 执行脚本：自动化脚本/weekly_update.py
- 更新内容：
  1. 检查全部94个赛事官网可访问性（停办检测）
  2. 提取页面中的时间信息变更
  3. 访问异常的赛事标记"需人工确认"（不自动删除）
  4. 自动备份当前数据到「历史备份/」
  5. 重新生成HTML时间轴和Excel清单
  6. 输出日志到「更新日志/」
- 日志位置：历史备份与日志/更新日志/update_YYYYMMDD.log

【四、手动更新方法】

如需立即更新（不等周一）：
1. 打开命令行，cd到 自动化脚本/ 目录
2. 运行：python weekly_update.py
3. 等待5-10分钟（检查94个官网）
4. 完成后HTML和Excel自动更新

如需重新从原始分类数据整合：
1. python merge_competitions.py
2. python normalize_fields.py
3. python generate_timeline.py
4. python generate_excel.py

【五、数据说明】

- 共收录94项高含金量赛事+科研项目
- 覆盖：保研66项、就业81项、考公15项、留学24项（一赛可多赛道）
- 推荐35项、可冲58项、不建议1项
- 所有赛事均核实2024-2026连续举办
- 2027年未公布日期标注"参考惯例X月"，以官方最新通知为准
- 已剔除：付费水赛、山寨赛事、已停办赛事（如阿里全球数学竞赛、京东JDATA、滴滴DiTech、Google Kick Start/HashCode等）
- 数据来源：各赛事官网、教育部白名单、中国高等教育学会竞赛目录、高校教务处通知、大厂招聘官网

【六、注意事项】

- 大创（国创/校创）非传统竞赛，但保研综测权重高，大二下即可申报
- 企业赛通常免费，收费的企业赛大概率是山寨
- 蓝桥杯省赛价值有限，国赛二等奖以上才有实质认可度
- 电赛奇数年全国赛、偶数年专题赛交替
- 部分赛事官网可能临时不可达，以"需人工确认"标记，不代表停办
- 定时任务需要电脑在周一09:00处于开机状态；若错过，任务会在下次开机时自动运行（StartWhenAvailable）
