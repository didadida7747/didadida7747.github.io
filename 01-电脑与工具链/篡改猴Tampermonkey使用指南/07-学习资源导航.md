## 六、遇到问题时的求助路径

1. 脚本页的评论区（最常见问题都有人问过，注意看近期评论）；
2. 油猴中文网论坛发帖，附上：浏览器版本、篡改猴版本、脚本名、网址、控制台报错截图；
3. GitHub 项目的 Issues（英文/中文均可，按模板提供复现步骤）；
4. 自己 F12 看 Console 报错——对计算机方向的同学，这是最快的路径。
