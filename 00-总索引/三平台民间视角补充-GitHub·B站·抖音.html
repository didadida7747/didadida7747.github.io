OVERVIEW

总览：三个平台，三种「民间视角」

宏观报告回答「世界是什么样」；三平台民间视角回答「入行的人、干活的仓库、发视频的人，实际在过什么样的日子」。三者的可信度风险完全不同，筛选原则也完全不同。

GITHUB · 技术气象站

看维护方与活跃度，不看总 star

它是工程栈选择的底层证据：哪些框架在生产环境被真实使用、哪些仓库名义火爆实则停更。

筛选总原则：看最后提交时间、release 频率、是否 archived、contributor 数量与 star 增长曲线；star 绝对值是最不可靠的单一指标。

BILIBILI · 口述史

看身份与长期内容一致性

它沉淀了「大厂一天」「基层工资条」这类第一人称记录，但已被批量营销矩阵渗透。

筛选总原则：真实 vlog 是编号流水账；模板标题、推荐栏互推、结尾钩子（领资料/备考/课程）= 引流。先去伪，再取数。

DOUYIN · 岗位切片

警惕卖课 / 内推 / 加盟引流

它有最密集的工资条与日常切片，也有最成熟的灰产：培训贷、付费内推、AI 副业卖课。

筛选总原则：三秒自检——敢说具体公司名吗？主页有橱窗/私信引流吗？展示过程还是只给结论？只取数字，不取情绪。

一条贯穿三平台的元规律：「体量数字」最容易被操纵。GitHub 上 18 万 star 的仓库可以不再维护S10，B站上播放量十万的「入职大厂」可以是同模板互推矩阵S45，抖音上「半年 6 份 offer」可以是评论只有 12 个的卖课软广S60。读任何平台内容时，先问「这个数字是谁、为了什么目的、什么时候造出来的」。

1.2 2026 真实技术栈风向

  • 事实应用层 Python 主导；TypeScript 占据网关/可观测层；Rust 在基础设施（Qdrant、Chroma 内核、Goose）崛起S19S20S32。
  • 事实生产推理已是 vLLM + SGLang 双雄格局；网关用 LiteLLM；监控用 Langfuse；本机开发默认 Ollama + Chroma/pgvectorS23S26S14S13。
  • 事实中国团队在头部占据真实位置：Dify、RAGFlow、Milvus、NewAPI/One-API、SGLang——中文文档与中文社区是真实存在的，不是营销话术S02S11S18S16。
  • 报道降温与替代链：AutoGen/Semantic Kernel → Microsoft Agent Framework；TGI → vLLM；MetaGPT/Aider 停更；Roo Code 归档；AutoGPT 不维护S08S05S27。
  • 报道并购潮：Langfuse → ClickHouse（2026-01）；Helicone → Mintlify；Chroma → Replit（2026-10）S13S17S20。独立小工具公司的独立窗口在收窄。
  • 推断给你的本科组合栈：Python 应用 + LangGraph/CrewAI 编排 + RAGFlow 或自研 RAG + pgvector/Chroma + LiteLLM + Langfuse + Ollama/vLLM——这一整条链上每一环都有「本科可做的切入点」，且环环相接。

1.3 长期跟踪源与新手开源切入步骤

跟踪源

  • 趋势面板：GitHub Trending（Python 月榜）S33。
  • 清单索引：vinta/awesome-python、Hannibal046/Awesome-LLM、e2b-dev/awesome-ai-agents、microsoft/ai-agents-for-beginners、microsoft/generative-ai-for-beginnersS34。
  • 二手数据：ossinsight.io、star-history.com——看 star 曲线斜率而不是绝对值S35。
  • 直接盯组织：langchain-ai、langgenius、infiniflow、vllm-project、sgl-project、BerriAI、langfuse、All-Hands-AI、cline、milvus-io、qdrant。

新手切入五步

  1. 从你正在用的项目起步（Dify/RAGFlow）：本机 docker compose 跑通，改造一个小应用。
  2. 搜索 label:"good first issue" label:"documentation" is:open——文档类贡献胜率最高，不需要先读穿源码。
  3. fork → 分支 → 小改 → PR 关联 issue；Apache/基金会项目记得 git commit -s（DCO 签名）。
  4. 不写代码也能贡献：issue triage、复现 bug、Discussions 答疑、PR 中文翻译。
  5. 防坑：认准新组织名（ggml-org、FoundationAgents）；commit/release/archived 三信号先行；刷 star 看曲线与 contributor 数；license 风险（Dify 转售限制、NewAPI AGPL 传染、AutoGPT Polyform 限制）。

1.4 交叉验证小结：印证 / 修正 / 新信号

印证：应用层与 Agent 方向高增长——Dify 周增约 500 star、LangGraph 周 npm 下载约 370 万，与上份报告「AI 应用开发岗占招聘约六成」的判断同向S02S06。

印证并补充：算法岗硕博化是真的，但应用层工程岗本科可切入——这是两个难度梯队，不要把「算法要双 9」误读成「AI 整条路本科没戏」。

修正：「传统开发收缩」不是岗位消失，而是技能组合上移到 agent 基础设施——会部署运维整条栈（LiteLLM + Langfuse + vLLM）的工程岗在扩张，收缩的是只会写 CRUD 的那一段S14S13S23。

修正：「独立开发低成功率」在 2026 年更加严峻——个人明星项目集中死亡或公司化（Aider、Roo Code、AutoGPT），单打独斗窗口更窄；现实路径是进入国产头部开源社区攒贡献，把「个人作品」换成「被仓库记录在案的 PR」S30S31S10。

可执行动作（本周可做）：① 本机用 docker compose 跑通 RAGFlow 或 Dify；② 给其中一个仓库搜 good first issue，挑一个文档类 issue 开第一个 PR；③ 在 star-history 上看 3 个你关注项目的 star 曲线，建立「曲线斜率比绝对值重要」的手感。
