# 能力地图与寒假投递优先级

```text
C 工程化 + STM32 调试
        ↓
定时采集 / 输出控制 / UART 协议 / 故障恢复
        ↓
项目一：STM32 实时采集与设备控制器
        ↓
Linux + C++ + CMake + GDB
        ↓
项目二：STM32—ROS2 桥接
        ↓
课题组无人机 / RL baseline（后置加分层）
```

| 单元 | 离开条件（必须能做） | 时间与优先级 |
| --- | --- | --- |
| 01 C 工程化 | 独立写模块、环形缓冲/协议逻辑并定位内存问题 | 7–8 月 P0 |
| 02 STM32 与调试 | 使用定时器、PWM、DMA/中断、通信和看门狗并排错 | 7–8 月 P0 |
| 03 通信与协议 | UART 帧具备校验、超时、重同步和错误统计 | 8 月 P0 |
| 04 实时系统 | 测周期/负载，解释 ISR、主循环、队列和互斥边界 | 8–9 月 P0/P1 |
| 05 Linux 与 C++ | 用 CMake 构建可测试串口工具并使用 GDB | 9 月 P1 |
| 06 ROS 2 与机器人 | 完成 STM32 数据发布、命令下发、rosbag 和断线恢复 | 10 月 P1 |
| 07 AI 与强化学习 | 复现 baseline、改变一个变量并报告指标 | 11 月 P2 |

## 条件能力

SPI、CAN、编码器、PID、TF、PX4 等由岗位和硬件触发。项目或岗位明确要求时加入，不为了填技术栈制造无效 demo。
