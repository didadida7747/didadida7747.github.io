# 联想拯救者 Y7000P Windows 深度优化与日常效率指南

> 适用机型：联想拯救者 Y7000P（i7-14650HX + RTX 4060 + 16GB 内存 + 1TB SSD）
> 适用系统：Windows 11（22H2 / 23H2 / 24H2）
> 读者画像：电脑小白，本校电子信息工程大二学生
> 撰写日期：2026 年 9 月

## 一、Windows 系统深度优化

### 1.1 电源模式与拯救者野兽模式

**Windows 自带电源模式切换：**

1. 按 `Win + i` 打开「设置」
2. 左侧点击「系统」→ 右侧点击「电源和电池」
3. 找到「电源模式」下拉框，有三个选项：
   - **最佳能效**：插电也省电，适合图书馆写作业、看视频时用，风扇安静
   - **平衡**：系统自动调节，日常默认即可
   - **最佳性能**：CPU 不降频，适合跑仿真、编译、游戏时用

**拯救者野兽模式（更重要）：**

- 直接按键盘上的 `Fn + Q` 即可循环切换三种散热模式：
  - **安静模式**（图标像小猫/叶子）：风扇转速低，适合图书馆、深夜写作业，性能受限
  - **均衡模式**（图标像平衡/箭头）：日常默认，风扇和性能折中
  - **野兽模式**（图标像红色野兽/闪电）：CPU 满血释放，风扇全速，打游戏、跑大型软件时开
- 也可以打开任务栏右下角的 **Legion Zone** 软件，在首页点大图标切换。

> 小白建议：上课带电脑去图书馆按 `Fn+Q` 切安静模式，插电玩游戏切野兽模式。

### 1.2 虚拟内存（页面文件）配置

你的电脑是 16GB 内存，打大型游戏或开很多网页时可能吃紧。虚拟内存是在硬盘上划一块空间当"备用内存"用。

**推荐配置步骤：**

1. 按 `Win + S`，搜索「高级系统设置」，点击「查看高级系统设置」
2. 在弹出的「系统属性」窗口，点击「高级」选项卡 → 「性能」区域的「设置」按钮
3. 再点「高级」选项卡 → 「虚拟内存」区域点「更改」
4. **取消勾选**顶部的「自动管理所有驱动器的分页文件大小」
5. 选中你的 C 盘（通常是 SSD），选「自定义大小」：
   - **初始大小 (MB)**：填 `16384`（即 16GB）
   - **最大值 (MB)**：填 `32768`（即 32GB）
6. 点「设置」按钮 → 点「确定」→ **重启电脑**生效

> 说明：16GB 物理内存配 16~32GB 页面文件是游戏本的稳妥方案。如果你的 C 盘空间紧张（剩余少于 50GB），可以把最大值降到 24576。**不要把页面文件关掉**，很多游戏和软件会报错。

### 1.3 启动项管理

开机自启的软件越多，开机越慢、内存占用越高。

**操作步骤：**

1. 按 `Ctrl + Shift + Esc` 打开「任务管理器」
2. 点击左侧（或顶部）的「启动应用」标签页
3. 你会看到一列开机自启的程序，看「启动影响」这一列：
   - **高**：建议禁用
   - **中/低**：看你需不需要

**可以安全禁用的典型项目：**

| 程序名 | 能不能禁 | 说明 |
|---|---|---|
| 各种游戏平台（Steam、Epic、WeGame） | 建议禁 | 打游戏时手动打开即可 |
| 聊天软件（微信、QQ、钉钉） | 看需求 | 要收消息就留着 |
| 云盘（百度网盘、OneDrive） | 建议禁 | 用的时候再开 |
| 显卡控制面板（NVIDIA GeForce Experience） | 可禁 | 不影响打游戏 |
| 各种"助手""管家""更新程序" | 建议禁 | 没用还占资源 |
| 联想 Legion Zone | **不要禁** | 要靠它切野兽模式 |
| Windows 安全中心 | **不要禁** | 系统杀毒 |

**禁用方法**：右键点某一项 → 选「禁用」。随时可以再右键「启用」。

### 1.4 服务优化（谨慎操作）

按 `Win + S` 搜索「服务」，打开「服务」应用（图标像两个齿轮）。**双击某一项**，把「启动类型」改成「禁用」或「手动」，然后点「停止」→「确定」。

> ⚠️ **警告**：以下服务只列了你大概率用不到的。改之前看清楚名字，**拿不准的就别动**。改坏了随时可以改回「自动」。

| 服务名称（显示名） | 服务名 | 建议 | 说明 |
|---|---|---|---|
| 连接用户体验和遥测 | DiagTrack | 禁用 | 收集你的使用数据发给微软，禁用不影响任何功能 |
| Windows 错误报告服务 | WerSvc | 禁用 | 程序崩溃后上报微软，普通用户用不到 |
| 传真 | Fax | 禁用 | 现在没人用传真了 |
| 电话 | TapSrv | 手动 | 用于拨号上网/电话应用，不用就改手动 |
| 远程桌面服务 | TermService | 手动 | 不用远程控制别人电脑就改手动 |
| 传递优化 | DoSvc | 手动 | 局域网内给其他电脑传 Windows 更新，你只有一台电脑就改手动 |
| Windows  Insider 服务 | wisvc | 禁用 | 没参加微软预览体验计划就禁用 |
| PrintNotify | PrintNotify | 手动 | 打印机通知，没打印机就改手动 |
| Xbox 实时管理 | XboxGipSvc | 手动 | 不用 Xbox 手柄/应用就改手动（用手柄打游戏就别禁） |

**绝对不要碰的服务**（碰了系统会出问题）：
- Windows Update（系统更新）
- Windows 安全中心服务 / Windows Defender 防火墙
- 网络连接相关服务（Network Connections 等）
-即插即用（Plug and Play）
- 加密服务（Cryptographic Services）

### 1.5 游戏模式、硬件加速 GPU 计划、内存完整性

**开启游戏模式：**

1. `Win + i` → 「游戏」→「游戏模式」
2. 把开关拨到「开」
3. 作用：打游戏时 Windows 自动暂停后台更新、通知，把资源优先给游戏

**开启硬件加速 GPU 计划（HAGS）：**

1. `Win + i` → 「系统」→「屏幕」→「显示卡」（或「图形」）
2. 点击「更改默认图形设置」
3. 打开「硬件加速 GPU 计划」
4. **重启电脑**生效
5. 作用：让 GPU 自己管理显存，降低延迟，对 RTX 4060 有小幅提升

**内存完整性（核心隔离）——建议关闭以提升游戏性能：**

1. `Win + i` → 「隐私和安全性」→「Windows 安全中心」
2. 点「设备安全性」→「内核隔离详细信息」
3. 把「内存完整性」**关闭**
4. 重启生效

> 说明：内存完整性是安全功能，但会占用一部分性能（游戏帧率可能掉 5~10%）。你的电脑装了杀毒软件、不随便下奇怪软件的话，可以关掉换性能。如果经常下破解软件/浏览不明网站，就保持开启。

### 1.6 Windows 更新、存储感知、临时文件清理

**Windows 更新管理：**

1. `Win + i` → 「Windows 更新」
2. 点「高级选项」→「主动检查更新」调成「可调](不要选最积极)
3. 打开「活跃小时」：设为你通常用电脑的时间段（比如 8:00~24:00），系统不会在这个时间段自动重启更新
4. **不要用第三方工具彻底关闭 Windows 更新**，安全补丁还是要打的

**开启存储感知（自动清理垃圾）：**

1. `Win + i` → 「系统」→「存储」
2. 打开「存储感知」开关
3. 点进去设置：
   - 运行存储感知：选「每周」
   - 删除我的应用未使用的临时文件：开
   - 回收站文件删除：设为「30 天后」
   - 下载文件夹：设为「30 天后」（**注意**：如果你下载文件夹里有重要文件，改成「从不」）

**手动清理临时文件：**

1. `Win + i` → 「系统」→「存储」→「临时文件」
2. 勾选：Windows 清理传递、临时文件、缩略图、回收站（确认不要了再勾）
3. 点「删除文件」

> 小白建议：每个月清理一次即可。C 盘剩余空间保持在 50GB 以上。

### 1.7 显示设置（刷新率、HDR、缩放）

**你这块屏是高刷屏，一定要确认刷新率拉满：**

1. 桌面右键 → 「显示设置」
2. 拉到最下面点「高级显示器」
3. 「选择刷新率」→ 选最高的那档（Y7000P 通常是 144Hz / 165Hz / 240Hz，看具体批次）
4. 如果只选到 60Hz，检查是不是 Legion Zone 里把显示模式切到了混合模式，或者线插对了（笔记本屏不需要接线）

**缩放比例：**

1. 同一个「显示设置」页面
2. 「缩放」选 **125%** 或 **150%**（Y7000P 是 16 英寸 2.5K 屏，125% 最舒服，字不会太小也不会太大）
3. 不要选 100%，字太小费眼睛

**HDR：**

- 如果你的屏幕支持 HDR，在「显示设置」里可以打开「使用 HDR」
- 但**看视频、写作业时建议关掉**，因为 Windows 的 HDR 对 SDR 内容优化不好，日常用会发灰
- 只在玩支持 HDR 的游戏、看 HDR 片源时开

## 二、必装效率软件清单

> 以下所有链接均为官网，复制到浏览器地址栏打开即可。**不要从百度搜索结果里下载**，容易带捆绑软件。

### 2.1 Everything —— 秒搜全电脑文件

- **下载官网**：<https://www.voidtools.com/zh-cn/downloads/>
- **用途**：Windows 自带搜索慢得要命，Everything 能在 1 秒内搜遍你整个硬盘的所有文件名
- **核心功能**：
  - 安装后，在任意位置按 `Ctrl + 双击` 桌面空白，或打开 Everything 窗口直接输文件名
  - 支持拼音搜索：输入 `wjl` 能找到 `成绩单.pdf`
  - 支持模糊匹配：输 `zhang san` 能找到 `张三简历.docx`
- **小白入门建议**：
  1. 下载「Everything-1.4.x.x64-Setup.exe」（64 位安装版）
  2. 安装时勾选「加入右键菜单」和「随系统启动」
  3. 以后找文件不要再点进 C 盘 D 盘一层层翻，直接开 Everything 输关键词

---

### 2.2 Microsoft PowerToys —— 微软官方效率工具箱

- **下载官网**：<https://github.com/microsoft/PowerToys/releases>
- **用途**：微软出的免费开源增强工具集，把 Windows 变成 macOS 一样顺手
- **安装方法**：在 Releases 页面往下翻到「Assets」，下载 `PowerToysSetup-0.xx.x-x64.exe`，双击安装
- **必开模块**：

| 模块 | 作用 | 默认快捷键 |
|---|---|---|
| **FancyZones** | 窗口分屏：把屏幕用快捷键切成几块，软件窗口自动贴进去 | 拖窗口时按住 `Shift` |
| **PowerRename** | 批量重命名：选中一堆文件右键，一键改名 | 右键菜单 |
| **Keyboard Manager** | 改键：比如把无用的 `Caps Lock` 改成 `Ctrl` 或 `Esc` | 设置里配 |
| **Text Extractor** | 截图 OCR 取文字：图片上的文字直接抠出来复制 | `Win + Shift + T` |
| **Quick Accent** | 打特殊字符（á、é、€） | 长按字母键 |
| **File Locksmith** | 看哪个程序占用了文件 | 右键文件 |

- **小白入门建议**：先只开 FancyZones 和 Text Extractor，其他模块用熟了再开。FancyZones 里选「模板」→「Priority Grid」，写作业时左边放资料右边放 Word 特别爽。

---

### 2.3 Snipaste —— 截图 + 贴图神器

- **下载官网**：<https://www.snipaste.com/>
- **用途**：比 Windows 自带截图强 10 倍，能把截图钉在屏幕上当参考
- **核心快捷键**：
  - `F1`：截图（截完可以标注、画箭头、打码）
  - `F3`：贴图（把刚截的图钉在屏幕最前面，写作业时一边看题一边写答案特别方便）
  - `Ctrl + F1`：截图到剪贴板不弹窗
- **小白入门建议**：
  1. 下载 Windows 64 位便携版，解压到 `D:\Tools\Snipaste` 文件夹
  2. 把 Snipaste 发送快捷方式到桌面，设置开机自启
  3. 以后不需要按 `PrtSc` 然后画图里粘贴了，直接 `F1`
  4. 免费版个人使用完全够，不需要买 Pro

---

### 2.4 Listary —— 文件搜索 + 程序启动器

- **下载官网**：<https://www.listary.com/download>
- **用途**：在任意文件夹里直接打字搜索，还能快速启动软件
- **核心功能**：
  - 在任意打开的文件夹窗口，**直接敲键盘**就会弹出搜索框
  - **连按两次 `Ctrl`** 呼出启动器，输 `wechat` 就能打开微信，输 `dianlu` 就能找到电路课文件夹
  - 支持在「另存为」对话框里直接输路径跳转，不用一层层点
- **小白入门建议**：免费版够用。装好后什么都不用设置，默认连按两次 Ctrl 呼出。和 Everything 不冲突——Everything 搜文件名更猛，Listary 是在文件夹里快速跳转更顺手。

### 2.5 7-Zip —— 免费无广告解压软件

- **下载官网**：<https://www.7-zip.org/>
- **用途**：替代 Windows 自带的解压，支持所有压缩格式，无广告无捆绑
- **核心功能**：
  - 解压 `.zip` `.rar` `.7z` `.tar.gz` 等所有格式
  - 右键菜单直接「解压到当前文件夹」
  - 可以给压缩包设密码加密
- **小白入门建议**：
  1. 主页点「Download 7-Zip 26.xx (2026-xx-xx) for Windows x64」下载
  2. 安装时默认即可
  3. 以后下载的课件压缩包，右键 → 7-Zip → 解压到"xxx\"
  4. **不要再装好压、2345 压缩、WinRAR 破解版**，全是广告

### 2.6 Obsidian —— 本地笔记软件（推荐）

- **下载官网**：<https://obsidian.md/download>
- **用途**：用 Markdown 格式记笔记，文件全部存在你自己电脑上，不依赖网络，不会被封号
- **核心功能**：
  - 笔记之间可以互相链接（比如「模电笔记」链接到「三极管」概念页）
  - 左边文件树管理课程笔记
  - 支持插入图片、公式（LaTeX）、代码块
  - 完全离线可用，本校校园网再差也不影响
- **小白入门建议**：
  1. 下载 Windows 版安装
  2. 第一次打开选「新建仓库」，仓库位置选 `D:\Notes\大学笔记`
  3. 按课程建文件夹：`模拟电子技术/`、`数字信号处理/`、`C语言/`
  4. 文件名用 `2026-09-28 模电 第三章笔记` 这种格式
  5. 个人使用免费，不需要付费同步

> 如果你更喜欢在线同步、手机电脑同步，可以用 **Notion**：下载地址 <https://www.notion.com/zh-cn/desktop/windows>，免费版够用，但国内访问偶尔慢。

## 三、文件管理规范

### 3.1 推荐目录结构

**C 盘只放系统和软件，不要放个人文件！** 建议这样规划：

```
D:\
├── 大学课件\
│   ├── 2026秋\
│   │   ├── 模拟电子技术\
│   │   ├── 数字信号处理\
│   │   ├── 电磁场与电磁波\
│   │   └── 大学英语\
│   └── 2027春\
├── 作业与报告\
│   ├── 模电实验报告\
│   ├── 数电课程设计\
│   └── 数学作业\
├── 软件安装包\          ← 下载的 exe 安装文件统一放这
├── 工具\                ← 绿色软件（Snipaste 等）
```

**操作方法**：

### 3.2 文件命名规范

**不要用这些名字**：`新建文档.docx`、`最终版.docx`、`最终版2.docx`、`真的最终版.docx`

**推荐格式**：

```
日期_课程/项目_内容_版本.扩展名

例：
2026-09-28_模电实验_三极管放大电路_报告v1.docx
2026-10-05_数电课程设计_数字时钟_源代码.rar
2026-09-28_简历_本校秋招_v2.pdf
```

好处：Everything 搜 `模电` 或 `2026-09` 都能立刻找到。

### 3.3 OneDrive / 网盘同步策略

- **OneDrive**：Windows 自带，默认会把桌面、文档、图片文件夹同步到云端。**建议关掉自动同步桌面**，因为桌面东西多了会拖慢开机：
  1. 任务栏右下角点 OneDrive 云朵图标 → 设置 → 「同步并备份」→「管理备份」
  2. 把「桌面」「图片」的备份关掉，只保留「文档」可选
- **百度网盘**：不要设置开机自启，需要传文件时再打开。百度网盘后台上传会占带宽和硬盘
- **建议**：重要课程作业用 U 盘 + 网盘双备份。学校机房插 U 盘就能交作业

---

### 3.4 避免 C 盘爆满的方法

1. **软件安装时一律改路径**：装软件看到「安装路径」，把 `C:\Program Files\xxx` 改成 `D:\Program Files\xxx`
2. **微信/QQ 聊天记录转移**：
   - 微信：左下角「≡」→ 设置 → 文件管理 → 更改，把路径改到 `D:\WeChat Files`
   - QQ：设置 → 文件管理 → 更改到 `D:\QQ Files`
   - 这两个是 C 盘杀手，默认几个月就能占几十 GB
3. **微信自动接收的图片视频**：在微信设置里关掉「自动下载」
4. **定期检查**：`Win + i` → 系统 → 存储，看什么占了空间
5. **休眠文件**：如果不用休眠功能，可以关掉省几个 GB。管理员身份运行 PowerShell，输入 `powercfg /h off` 回车

## 五、浏览器高效使用

### 5.1 推荐浏览器

**主力推荐 Microsoft Edge**（Windows 自带，不用装）：

- 支持安装 Chrome 扩展（Chrome 网上应用店的扩展 Edge 都能装）

### 6.2 独显直连（MUX Switch）是什么？怎么切？

**通俗解释**：

你的 Y7000P 有两块显卡：
- **核显**（CPU 自带的 Intel 显卡）：省电，性能弱
- **独显**（RTX 4060）：费电，性能强

- **混合模式（默认）**：日常上网用核显，打游戏自动切独显。屏幕画面要经过独显→核显→屏幕，多一道中转，损失 5~10% 性能，但省电
- **独显直连**：独显直接连屏幕，跳过核显中转，游戏帧率提升 10% 左右，但续航变短

**切换方法**：

1. 打开 Legion Zone
2. 找到「显示设置」或「显卡模式」
3. 选「独显模式」（就是独显直连）或「混合模式」
4. **需要重启电脑才能生效**（老款 DDG1.0）；新款支持热切换不用重启
5. 也可以在「联想电脑管家」→ 游戏模式 → 显卡模式里切

**什么时候用哪个**：
- 去图书馆写作业、看视频、带电池出门 → **混合模式**（省电）
- 插电玩 3A 大作、跑 GPU 仿真 → **独显直连**（性能）

---

### 6.3 三种散热模式使用场景

| 模式 | 风扇噪音 | 性能释放 | 适用场景 |
|---|---|---|---|
| 安静模式 | 几乎无声 | CPU 约 35W | 图书馆、深夜写作业、看视频、打字 |
| 均衡模式 | 轻微风声 | CPU 约 60W | 日常上课、写 Word、上网课、编程 |
| 野兽模式 | 明显起飞声 | CPU 约 90W+ | 打游戏、跑大型仿真、渲染、编译 |

> 小白口诀：**上课安静，日常均衡，打游戏野兽**。按 `Fn+Q` 一键切。

### 6.4 键盘背光、摄像头、麦克风设置

- **键盘背光**：
  - `Fn + 空格` 调亮度（关→暗→亮三档循环）
  - 想要 RGB 变色：打开 Legion Zone → 光效 → 选颜色和动态模式（呼吸、彩虹、随音乐跳动等）
- **摄像头物理开关**：
  - Y7000P 键盘上有摄像头开关键（`Fn+F8` 或单独的物理拨片，看具体批次）

  - 网课、面试前测试：`Win + i` → 系统 → 声音 → 输入
  - 耳机插上去记得在右下角音量图标里选对输出设备

## 七、新手第一周必做清单

按顺序做完这 10 件事，你的 Y7000P 就能舒服地用四年：

1. **按 `Win+Q` 确认刷新率先拉满**到 144Hz/165Hz（显示设置里）
2. **装 Chrome 内核浏览器扩展**：AdGuard + Tampermonkey（Edge 自带浏览器即可）
3. **装四件套效率软件**：Everything、Snipaste（F1 截图）、7-Zip、PowerToys
4. **任务管理器禁用不必要的开机启动项**（Steam、各种管家、网盘全禁）
5. **把微信/QQ 文件存储路径从 C 盘改到 D 盘**（不然半年后 C 盘红）
6. **D 盘建好文件夹结构**（大学课件、作业、软件安装包、下载临时），浏览器默认下载改到 D 盘
7. **设置虚拟内存**（16384~32768 MB，放在 C 盘 SSD）
8. **打开游戏模式 + 硬件加速 GPU 计划**，内存完整性按需关
9. **记住 `Fn+Q` 切模式**：图书馆安静、宿舍均衡、打游戏野兽
10. **注册一个微软账号登录系统**，打开 OneDrive 同步文档（不要同步桌面）
