# 自学资源 · 大学不教的四件事

SI100+ Lec.01 末尾，老师给了四年间最值得带走的一句心法——**「自学多问 + GPT」**，并顺手推荐了一批「大学不教、但决定你上限」的资源。本栏目把这几份资料逐一建档：它是什么、为什么值得用、大二这年怎么用出效果。

## 建议的使用顺序

1. **先读《提问的智慧》**——最薄、见效最快，从今天向 GPT / 助教 / 群友提问前就照着做；
2. **再跟 MIT Missing Semester 2026 版**——九讲把 shell / Git / 调试 / 打包补齐，正好接上 SI100+ Lec00 的 uv 环境课；
3. **把 csdiy.wiki 当地图**——不从头读，按「必学工具 → 核心方向」查漏，选课、选方向、配教材时回来翻；
4. **NotTaught 考证页**——知道有这么个推荐即可，等拿到准确链接再补。

## 共同心法

四份资料其实是同一句话的四个切面：**大学教知识，不教「怎么学知识」**。工具（Missing Semester）、地图（csdiy）、提问（提问的智慧）、自驱（NotTaught 所指的那一类资源），凑齐了才算把「自学多问 + GPT」落到可执行。
