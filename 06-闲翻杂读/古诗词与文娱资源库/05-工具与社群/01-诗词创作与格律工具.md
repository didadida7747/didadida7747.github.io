# 诗词创作与格律工具

> 从"读诗"进阶到"写诗"的工具箱。整理日期：2026-10-03，标注"已实测"的站点经访问核验。

## 一、两大主力（写格律诗就用这两个交叉核对）

### 搜韵（sou-yun.cn，已实测）

诗词创作工具最全的一站，主体免费：

| 功能 | 入口（网页路径） | 用法 |
|---|---|---|
| 律诗校验 | sou-yun.cn/AnalyzePoem.aspx | 贴入作品即逐字标平仄 |
| 词格校验 | sou-yun.cn/AnalyzeCi.aspx | 可选《钦定词谱》或龙榆生《唐宋词格律》为基准，标出缺字、衍字、漏句 |
| 曲格校验 / 对联校验 | AnalyzeCouplet.aspx 等 | 对联平仄对仗检查 |
| 自动笺注 | sou-yun.cn/Labeling.aspx | 自动找用典出处 |
| 韵书在线查 | /QR.aspx 系列 | 平水韵、词林正韵、中原音韵、中华通韵 |
| 其他 | 词谱/曲谱、对仗词汇、典故词汇、**诗词地图**、免费微课 | 填词前先看谱再动笔 |

### 诗词吾爱（52shici.com，已实测）

老牌创作社区（2009 年至今），"诗词工具"栏目含诗律检测（逐字标平仄、指出失黏失对与出韵）、词谱、韵表、对联工具、繁简转换；社区有擂台赛与悬赏切磋。注册免费，支持微信登录；另有手机 App（iOS / Android）。

> **推荐工作流**：搜韵校平仄 + 诗词吾爱校韵部——两站对古入声字的处理最完整，交叉核对最稳妥。

## 入门路径建议

1. 先读王力《诗词格律》（见 [04-书单与鉴赏指南](#/doc/d126)），建立概念；
2. 从七绝写起，每次写完贴进搜韵校验，对照改；
3. 到诗词吾爱参加擂台赛，看别人怎么写、听点评。
