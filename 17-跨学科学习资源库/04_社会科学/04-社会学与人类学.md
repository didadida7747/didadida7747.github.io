# 社会学与人类学

> **一句话**：社会学研究群体如何塑造个体行为，人类学研究不同人群如何组织生活——合起来，就是把"我觉得"升级成"为什么大家都会这样"。
> **带走什么**：结构性思维。别急着用个人品质解释成败，先看位置与约束——就像排查故障时先看系统架构，再怪单个组件。

## 为什么电信工程人值得了解

1. **社会网络分析 = 图论 + 信息传播模型。**
   你熟悉的邻接矩阵、最短路径、中心性，在社会科学里叫社会资本、意见领袖、弱连接——谣言扩散和信号衰减在数学上是同一类问题。
2. **通信网络是社会关系的影子。**
   流量早晚高峰、春节人口迁徙图、外卖骑手的接单网络——运营商手里全是社会学数据，懂社会学的通信工程师，价值翻倍。
3. **人类学是用户研究的底层方法。**
   用户访谈、田野调查、"到现场去"——大公司的用户研究员干的就是人类学家的活，理工背景转 UX 研究的路径真实存在。
4. **理解"技术为何不被使用"。**
   基站为什么被抵制、老人为什么不用 App——技术的社会接受度问题，纯工程视角永远解释不了。
5. **它是对"个人主义归因"的解毒剂。**
   工程师习惯找单点故障，但社会问题多是结构性故障——这个视角能防止你掉进"只要够努力就一定行"的幸存者偏差。

## 可迁移的"学科内核"

- **结构性因素**：个人的选择嵌在位置与约束里。
  米尔斯称之为"社会学的想象力"：把私人困扰放进公共议题来看——失业是一个人的麻烦，失业率上升是社会的病。
- **社会事实**：涂尔干主张把社会现象当"物"来研究。
  用统计规律而非个例解释社会，由此开创了定量社会科学——这和"用均值说话、不用特例吵架"的工程精神一致。
- **嵌入性与弱连接**：经济行为嵌在社会关系里（格兰诺维特）。
  找工作靠的往往不是强关系，而是泛泛之交——你的通讯录就是社会资本，弱连接带来新信息。
- **他者视角 / 田野方法**：把熟悉的变陌生、陌生的变熟悉。
  悬置判断、长期观察——做用户研究、竞品分析、需求调研都是这个姿势。
- **理想类型**（韦伯）：用简化模型把握复杂现实。
  和工程建模是同一个动作：模型不必为真，但要有用——知道模型的边界，比记住公式更重要。

## 三档入门路径

- 🍵 浅尝（1-2 周）：
  1. 《乡土中国》——薄、中文、经典，读完你会突然看懂自己的亲戚网络；
  2. B站搜「乡土中国 导读」，看一条高质量讲书视频，把概念挂回自己的生活经验；
  3. 画一张你自己的"差序格局图"（以你为中心的亲疏圈子），这本书会立刻变立体。
- 📚 成体系（2-3 个月）：
  1. 概念线：《见树又见林》——把"个人困扰 / 公共议题"的框架立起来；
  2. 方法线：《天真的人类学家》看人类学家怎么"下田野"，再接阎云翔《私人生活的变革》看中国乡村七十年；
  3. 视频线：台大孙中兴《爱情社会学》公开课（B站有搬运），用最日常的题目感受社会学的提问方式；
  4. 观察线：找一个小场景（食堂、快递站、地铁通勤）连续观察两周并写笔记——这就是最小可行的田野训练。
- 🏔 深入（半年+，可选）：
  经典理论：涂尔干《自杀论》+ 韦伯《新教伦理与资本主义精神》，两本近代社会科学的奠基之作；政治人类学：詹姆斯·斯科特《国家的视角》《弱者的武器》；网络科学：巴拉巴西《链接》——最适合工程师的进阶桥梁，把社会网络与复杂网络接起来。

## 交叉玩法：电信工程 × 社会学与人类学

1. **社会网络分析（SNA）**：
   图论 + 传播模型 + 中心性指标，用于谣言治理、舆情预警、社交产品推荐。
   这是数据科学岗位里"最像社会学"的方向，工程背景直接可用。
2. **用户研究 / 数字人类学**：
   科技公司（包括运营商和设备商）的用户研究岗，大量使用田野访谈与观察法。
   理工背景 + 人类学训练的复合人才稀少而抢手，是低竞争的转型路径。
3. **网络科学**：
   巴拉巴西学派把社会网络、通信网络、生物网络放进同一个数学框架。
   小世界网络、无标度网络的核心论文都值得读原文——这是"工程师做社会科学"最顺的桥。
