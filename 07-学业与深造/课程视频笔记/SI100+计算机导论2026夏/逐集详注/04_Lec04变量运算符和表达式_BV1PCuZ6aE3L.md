### 标识符：命名规则与命名法
标识符（identifier）就是"名字"，可唯一标识一个对象。规则：

- 第一个字符必须是字母或下划线（如 SI100P、_tap 合法；`123abc`、`~` 开头不合法）；
- 其余部分由字母、数字、下划线组成；
- 不能含空格（`cat dog` 会被认成两个标识符）、不能含加减号（会被当成表达式）；
- 区分大小写：SI100p 与 SI100P 是两个不同变量；
- 违反命名规则不一定报错，但 VS Code 会给警告。

主流命名法：

| 命名法 | 形式 | 备注 |
| --- | --- | --- |
| 驼峰命名法 | 第一个单词小写、后续单词首字母大写 | |
| 匈牙利命名法 | 变量名前写明类型 | 如今不太主流，了解即可 |
| 下划线命名法 | 单词间用下划线分隔 | **PEP 8 规范〔ASR原文"PP8"〕中 Python 官方建议**，SI100B 期末 project 也建议统一 |
| 帕斯卡命名法〔ASR原文"pass卡命名法"〕 | 每个单词首字母都大写 | 相当于驼峰再加大写首字母 |

讲者的忠告：算法竞赛里 a~z、循环用 i j k 的命名习惯"在我们真正写项目的时候是一个非常不好的习惯"，过一周就不知道当时在写什么；命名要尽可能有意义并反映实际用途（如 age=25、height=175.5、name="Alice"、是否学生=True）。

### 关键字、缩进与注释
- **关键字**是对 Python 有特殊含义的词，不能作标识符；内置模块 `keyword` 记录了当前版本所有关键词（`import keyword` 可打印出来）。直接拿 `and` 当标识符会报"不合法的表达式"，因为解释器把它当成了表达式。
- **缩进**：Python 用缩进确定代码块（与 C/C++ 等用括号的语言不同）——同一列的语句属于同一代码块（如 a=10 与 b=10 在一个块里，缩进不同的 print 就不在）。VS Code 中 Tab 缩进、Shift+Tab 或删除键取消缩进。
- **注释**（comment）是不会被执行的文本，是对代码的解释。严格来说 Python 只有单行注释：`#` 开头直至行尾（编辑器里显示为灰色）。没有"官方的多行注释"，通常用三个单/双引号的多行字符串达成近似效果——它本质上是一个字面量（见下节）。VS Code 中 Ctrl+/（macOS 为 Cmd+/）注释/取消注释。
- 讲者反复强调：**一定要养成写注释的习惯**——即使在有竞赛基础的同学中也普遍不写，写项目时注释是"提醒未来的自己"和合作者的；"这在任何时候都是一个绝对的好习惯"。用 ABCD 命名的人多半也不写注释，逻辑一复杂就再也读不懂了。

### 字面值、赋值语句与变量
- **字面值（literal value）**：代码中写明的、临时使用的值，如 `x = 1.5` 中的 1.5；用完后解释器就把它释放掉（"用完就扔"）。三引号多行字符串能当"多行注释"，正因为它只是个用完即扔的字符串字面量。
- **赋值语句**：复杂计算需要保存中间步骤和结果，把字面值（及其计算结果）赋给变量的语句即赋值语句：`x = 1.5`，可理解为"令 x 等于 1.5 / 把 1.5 付给 x"。
- **变量**：存储数据的容器，可类比高中数学的未知数，可随时更改、存任意东西；名字即标识符，要有意义。
- **与 C/C++ 的差异**：C/C++ 可以只声明不赋值（`int a;`），而 Python 的变量声明必须伴随赋值（初始值可以为"空"，如空字符串），声明和赋值通常在同一条语句完成。
- 两个易错点：变量可被重复赋值（age 先后赋 15、20）；`age + 10` 这类表达式的结果是字面量，没有赋给任何变量就用完扔掉，**不影响 age 本身**。notebook 特性：代码块最后一行若以变量结尾，执行后会自动输出该变量的值（普通 Python 代码不能这么写）。

### 基本数据类型：数字、字符串、布尔
三大类：数字（number）、字符串（string）、布尔（bool）。类型不同用途不同：数字 25 可以做四则运算，字符串 "25" 更像编号/标识。

**数字类型**共四种，课程只讲两种：整型（int，正/负/零，无小数部分）和浮点型（float，带小数：3.14、0.001、2.0）。互动问题：整型 2 和浮点型 2.0 有区别吗？进入交互式终端验证（直接输入 `python`，macOS 为 `python3`；不行就先激活 uv 建的 `.venv`：Windows 执行 `.venv/Scripts/activate.ps1`，macOS `source .venv/bin/activate`）：

```python
type(2)      # int
type(2.0)    # float
type(2 / 1)  # float —— 只要涉及除法运算，结果总是浮点型
```

**字符串**：由一系列字符组成的文本数据，外面包引号，单双引号都行但两端必须一致；建议整个项目统一同一种引号风格（引号套引号的情况以后会遇到）。字符串的"运算"：

- 加法：`"SI" + "100P"` → `"SI100P"`（回答了"字符串能不能四则运算"的悬念：加法可以）；
- 乘整数：`"SI100P" * 3` 重复三遍变长字符串；字符串乘字符串不可行；
- 字符串里可以有引号，还涉及反斜杠转义——留作业：如何让字符串同时包含单双引号（搜索后发 Piazza）。

**布尔型**：只有 True / False 两个值，表示二元状态（如开关、是否），常用于条件判断和逻辑运算；**首字母必须大写**，小写 true 不是合法的布尔型。

### 浮点数误差：0.1 + 0.2 为什么不等于 0.3
神秘现象：

```python
x = 0.1
y = 0.2
print(x + y)         # 0.30000000000000004
print(x + y == 0.3)  # False
```

**原因**：计算机以二进制存储一切数据，浮点数采用类似科学计数法 M×2^E 的表示，现代计算机遵循 IEEE 754〔ASR原文"HOE的754"〕标准；运算都在二进制中进行——0.1 和 0.2 是在二进制形式上相加，而 Python 里的 0.3 实际存的也不是精确的 0.3（约 0.2999…），于是 0.1+0.2 ≠ 0.3。这就是**舍入误差**。课上放了"0.1+0.2 机器人验证码"漫画，并推荐了一个可视化浮点存储的网站（数据类型选 double——Python 浮点型即以 double 精度存储）。

**解决**：一般四舍五入保留小数点后有限位；精度要求高时用 `decimal` 模块高精度存储（如 `x = Decimal("0.1")`），用 decimal 计算 0.1+0.2 就能正常输出 0.3。

### 运算符全家与优先级
基本运算符：`+ - * /`、`//`（整除）、`%`（取余/取模）、`**`（指数）。

**整除是向下取整，不是向零取整**——整除保证余数为正数：

```python
5 // 3    # 1
-5 // 3   # -2   （因为 -5 = -2*3 + 1）
5 % 3     # 2
-5 % 3    # 1    （课堂提问，答对了）
```

**优先级**：求指数 > 正负号 > 乘除/整除/取模 > 加减；有括号先算括号内，同层级算优先级高的，相同则从左至右（同高中数学）。经典迷惑例子：

```python
-2 ** 2   # -4：指数优先级更高，先算 2**2=4 再求正负号
```

优先级全表可看菜鸟教程的文章。分步示例的推论：整个算式只要涉及除法，结果类型就是 float（现场验证过）。

### 基本输入输出与文件 IO
程序三件事：输入、处理、输出（IO = input/output）。IO 分**标准输入输出流**（绝大部分情况是直接与用户交互，目标是命令行控制台/终端）和**文件 IO**（目标是磁盘文件）。

**标准输入输出**：

- `input()`：输入前先输出提示语，再接收用户输入保存到变量；**注意 input 会把一切输入作为字符串处理**。
- `print()`：打印变量，结尾默认附加换行，可用 `end="..."` 改结尾（`end=""` 即不换行）；`print(x, y, ...)` 逗号分隔会自动以空格间隔依次输出。notebook 2.4.3 演示：输入 2026 后按自定义格式输出。

**文件 IO** 三模式：

```python
f = open("test.txt", "r")
content = f.read()      # 内容以字符串类型保存；f 是复杂对象，类型是什么留作探究发 Piazza
f.close()

f = open("test.txt", "w")   # 覆写模式：覆盖原内容（不是追加！）
f.write("hello world\nthis is text")   # \n 是换行符
f.close()

f = open("test.txt", "a")   # append/追加模式：从文件末尾写入、不覆盖原有内容
f.write(input())            # 如输入 2026，追加到文件末尾
f.close()
```

讲者说明：这种 open/close 写法并不是现在 Python 标准的文件操作方式，现在会用 `with`〔ASR字幕"用vs去管理"，疑为 with〕管理文件生命周期；SI100B 大概率不考文件 IO，真正要用时再查文档即可。

### 强制类型转换：从 A+B 问题说起
经典翻车现场——用户输入两个整数求和，输入 123、456 却输出 "123456"：因为 input 默认以字符串保存，a、b 都是 str，`+` 变成了字符串拼接。

```python
a = input()             # 输入 123（得到字符串）
b = input()             # 输入 456
print(a + b)            # '123456'：字符串拼接
print(int(a) + int(b))  # 579
```

**强制类型转换**的写法是 `typename(x)`，如 `int()`、`float()`、`str()`：

- `int("123")` 得到整型 123，而**原变量 a 的类型仍是 str**——转换会创建新值，不影响原变量的类型和值。可理解为 `int(a)` 用 a 创建了一个新的 int 类型的字面量（可扔掉或赋给新变量）；并非所有类型都能相互转换。
- 典型用途：字符串与数字互转（"4.2" ↔ 4.2）；以及"移除浮点数小数部分"——`int(5.9)` 是 5，这个用途很重要，之后课程会遇到相关题目。
- **大坑**：课堂提问 `int(-5.9)` 是多少？很多人猜 -6，实际是 **-5**——它是"非常暴力"地直接砍掉小数部分，**与向下取整不一样**，做题时要分清。
- 可以在 input 时直接转换：`b = int(input(...))`——input 创建字符串字面量，转成 int 字面量后再赋给 b，效果相同。

### 比较运算符、布尔运算与短路求值
**比较运算符**：`==` 判相等（一个等号在绝大部分语言里是赋值；也不要认为所有语言都用两个等号判相等，可搜索了解）、`!=` 判不等、`>`、`<`、`>=`。结果是一个布尔值，代表该比较是否成立。

**布尔运算**（对应高中"与或非"/真值表）：

- `and`：当且仅当左右两侧均为 True 结果才为 True（二元运算符）；
- `or`：左右任意一侧为 True 结果即为 True（二元运算符）；
- `not`：把右侧布尔值取反（一元运算符，只需一个变量）。

**短路求值**：`a and b and c ...` 中只要有任何一处为 False，整个表达式必然为 False，后面没必要再算；`or` 链同理遇 True 即停。参数从左至右求值，一旦可确定结果就不再继续——本质是"偷懒"，能有效加速运算，Python 解释器会做这种优化。验证：

```python
True or (1 / 0) or print(123)     # True：既不抛异常也不打印，后两项根本不求值
False and (1 / 0) and print(123)  # False：同理
```

（print 的返回值是 None——None 表示"空"，是 NoneType 类型。）提醒：把 print 或 1/0 塞进布尔链只为演示短路，属于"没有定义的行为"，不建议这么做。

**逻辑表达式**：判断多个条件是否满足某种逻辑关系并返回布尔值，由比较运算符和布尔运算符组成，如 `has_ticket and age > 18`（命名有意义所以可读性好）。notebook 2.5.5 示例：变量为 已登录=True、是管理员=False、通过审核=False、余额=2000；购买权限 = 已登录 且 通过审核 且 余额 > 1000×2，或者 是管理员——结果 False；把审核状态改成 True 后翻转为 True。
